# 王者荣耀实战知识库（S45）

把 B 站教学视频里的可执行判断，拆成四类可检索条目，每条都能溯源到「哪个视频、第几秒」。

**在线版**：见仓库右侧 About 里的 Pages 链接（或 `https://<用户名>.github.io/<仓库名>/`）。

## 里面有什么

| 类 | 回答什么问题 | 编号 | 当前 |
|---|---|---|---|
| A 英雄教学 | 这个英雄怎么玩、什么时候强 | `K-Axx` | 苏烈 4 条 |
| B 克制关系 | 打谁舒服、被谁克、为什么 | `K-Bxx` | 3 条 |
| C BP | 选人阶段该怎么定 | `K-Cxx` | 空（无合格素材，故意不写） |
| D 对局内 | 现在这一刻该干什么 | `K-Dxx` | 对线期 8 条 |

判定口诀：结论里出现「对面是谁」→ B；出现「第几分钟」→ D；只是「这英雄」→ A；只是「这版本/这阵容」→ C。

另有 `20_kb/95_信源名单.md`：教学 UP 主实测名单（判据 + 分档 + 取用顺序），附筛选方法。

## 一条内容是怎么进来的

1. 选视频：关键词 + 时长 8–45 分钟 + 本赛区内 + 排除切片/赛事/爆料
2. 取字幕：必须带时间戳（`player/v2` + 登录态）
3. 抽结论：每条结论必须能在字幕里回查到 `mm:ss`，查不到即判为编造，拒绝入库
4. 写条目：触发条件 → 判据 → 阈值 → 反例；不写成「定义/性质/方法」四条平行清单
5. 建索引：`30_index/index.jsonl`，一条知识点一行

## 结构

```
20_kb/       知识层（人读的唯一入口）
30_index/    检索索引（机器读）
40_scripts/  取字幕、分块、建索引、检索、建站
site_src/    站点源码（template.html / app.css / app.js）
site/        构建产物（单文件 index.html，Pages 直接托管）
```

## 本地构建

```bash
python 40_scripts/s5_index.py     # 从 20_kb 重建索引
python 40_scripts/build_site.py   # 20_kb + site_src → site/index.html
python 40_scripts/deploy.py       # 构建 + 提交 + 推送（Pages 自动重新部署）
```

改内容改 `20_kb/*.md`，改样式改 `site_src/app.css`，改交互改 `site_src/app.js`；`site/` 是产物不要手改。

## 边界

- 只发布结论与出处编号，**不发布字幕原文**（版权）。
- 版本以官方公告为准，不采信「版本答案」类内容。
- 不收录：自走棋、皮肤活动、电竞赛事集锦、非王者分区的混剪。
