# 澜：三件套那一段最猛，之后是替射手开路

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：两条——一份国一澜结构化教学（BV1xAtF6EEfC，阿泽与岸川共创，含操作设置、铭文出装、使用细节、全局思路四部分）、一份被貂蝉与老夫子克制的逆风带线实录（BV1x1421t7Dg，主播边打边讲，全程被追着打仍翻盘）。

## 1. 机制内核

1. **强化普攻（强普）范围小，是操作门槛的来源**：所以操作设置"千万不要无脑开近距离"，否则"很容易卡刀，A不到人"（BV1xAtF6EEfC @ 00:46、BV1xAtF6EEfC @ 00:48、BV1xAtF6EEfC @ 00:51）。
2. **打开索敌头像可以抬高操作上限**（BV1xAtF6EEfC @ 00:52、BV1xAtF6EEfC @ 00:54）。
3. **强普可以用来躲技能**：强普能躲宫本大招，"相当于可以直接鸟枪换大炮"，但"一定要注意不能A太早，A太早的话躲不了，一定要慢一点，等他往前冲的时候我们再A"（BV1xAtF6EEfC @ 02:17、BV1xAtF6EEfC @ 02:19、BV1xAtF6EEfC @ 02:23、BV1xAtF6EEfC @ 02:25、BV1xAtF6EEfC @ 02:27）。
4. **精准普攻可以锁第二个兵，强普一次刮三个，清线更快**（BV1xAtF6EEfC @ 02:29、BV1xAtF6EEfC @ 02:31、BV1xAtF6EEfC @ 02:33、BV1xAtF6EEfC @ 02:35）。
5. **被动提供加速，用于追击**："我们利用潜水的被动加速直接追击拿下露娜"（BV1xAtF6EEfC @ 05:32、BV1xAtF6EEfC @ 05:33）。素材只称为"潜水的被动加速"，未给数值与触发条件。
6. **二技能是主要输出手段，形态是"转圈"**：可以连摇两个二技能直接开转（BV1xAtF6EEfC @ 06:21），实录里的说法是"二技能转转转"（BV1x1421t7Dg @ 07:12、BV1x1421t7Dg @ 09:21）。
7. **一技能带减速，也可用于回拉**："一技能减速大招拉回来"（BV1x1421t7Dg @ 04:22）；"一个一技能拉过来，二技能转一圈咬死他"（BV1x1421t7Dg @ 07:30、BV1x1421t7Dg @ 07:32）。
8. **大招可以把人"带出来"**：抢 Buff 时"大招直接拉出来接惩戒走"（BV1x1421t7Dg @ 04:59）；保射手时"大招拉出来把雅典娜带过来"（BV1x1421t7Dg @ 13:52、BV1x1421t7Dg @ 13:53）。
9. **大招的推人需要身位，靠墙时推不动**："如果敌方靠墙的情况下，我们大招重合是推不过来的，想推的话就得再往前靠近一点才能推"（BV1xAtF6EEfC @ 02:47、BV1xAtF6EEfC @ 02:49、BV1xAtF6EEfC @ 02:51）。中路蹲草同理："你出水直接推他推不到，你必须得先往前走一步，靠近点才可以推到"（BV1xAtF6EEfC @ 02:54、BV1xAtF6EEfC @ 02:56、BV1xAtF6EEfC @ 02:57）。
10. **推塔慢，是明确的短板**："因为我们玩的是澜，他推塔速度比较慢，去了也没什么用"（BV1xAtF6EEfC @ 10:25、BV1xAtF6EEfC @ 10:26）。
11. **三件套之后强度随时间下降**，这是理解他"不要拖后期"的全部依据（BV1xAtF6EEfC @ 11:06、BV1xAtF6EEfC @ 11:07）。
12. **被貂蝉克制是机制层面的**：貂蝉二技能有"无敌帧"，"能躲我的二"（BV1x1421t7Dg @ 03:57、BV1x1421t7Dg @ 03:59、BV1x1421t7Dg @ 04:07）。

## 2. 对线 / 打法

澜是打野，无对线。以下为开局与刷野决策，素材基本只覆盖前 10 分钟。

- **开局第一件事是分析双方上野 2V2 强度**："首先玩打野，开局第一件事就是先分析双方上野的2V2强度"（BV1xAtF6EEfC @ 03:23、BV1xAtF6EEfC @ 03:24、BV1xAtF6EEfC @ 03:25）。这一局对面司空震 + 露娜、我方影 + 澜，2V2 占优，所以"开野路线直接选择红开往对抗路刷"（BV1xAtF6EEfC @ 03:28、BV1xAtF6EEfC @ 03:29、BV1xAtF6EEfC @ 03:31、BV1xAtF6EEfC @ 03:32）。
- **红开往对抗路刷的收益**：既能争空间之灵这个中立资源，又能坐传送阵快速转线，"不管是节奏还是刷钱效率，收益都远高于直接抓发育路"（BV1xAtF6EEfC @ 03:41、BV1xAtF6EEfC @ 03:42、BV1xAtF6EEfC @ 03:45、BV1xAtF6EEfC @ 03:47）。
- **1 分 04 秒看小地图，判断敌方打野有没有补中线**："如果他吃了中线，就说明他只刷了半片野区，那么他的刷野速度肯定就会延后"（BV1xAtF6EEfC @ 03:56、BV1xAtF6EEfC @ 03:59、BV1xAtF6EEfC @ 04:01、BV1xAtF6EEfC @ 04:03、BV1xAtF6EEfC @ 04:04）。
- **拿到这个时间差后的两个选择**：进他野区反野，或优先拿空间之灵 + 对抗路四级线权，再坐传送阵转中/发育路（BV1xAtF6EEfC @ 04:10、BV1xAtF6EEfC @ 04:13、BV1xAtF6EEfC @ 04:14、BV1xAtF6EEfC @ 04:19、BV1xAtF6EEfC @ 04:21、BV1xAtF6EEfC @ 04:22）。
- **对面没吃中线 = 两边刷野速度几乎同步**，所有资源都要靠争（BV1xAtF6EEfC @ 04:27、BV1xAtF6EEfC @ 04:29、BV1xAtF6EEfC @ 04:31）。
- **补线时不要急着出塔**：上路两人刚消失，"我们不着急出去，防止被蹲二包一，等兵线残血的时候再出去补尾刀"（BV1xAtF6EEfC @ 04:52、BV1xAtF6EEfC @ 04:54、BV1xAtF6EEfC @ 04:56、BV1xAtF6EEfC @ 04:58）。
- **用落地人数读对面打野位置**：小地图看到两发传送只有辅助安全落地，"所以这波有很大概率对面打野在反蹲"；这时"简单试探，有人直接后撤，优先保状态"（BV1xAtF6EEfC @ 05:00、BV1xAtF6EEfC @ 05:03、BV1xAtF6EEfC @ 05:05、BV1xAtF6EEfC @ 05:07、BV1xAtF6EEfC @ 05:09）。
- **传送阵抢不到就走过去，不要浪费时间**："吃完线上单只有三级，那传送阵我们肯定抢不到，所以选择步行过线"（BV1xAtF6EEfC @ 05:15、BV1xAtF6EEfC @ 05:16、BV1xAtF6EEfC @ 05:18）。"野区没资源就直接转中路吃线，任何一点经济都不放过"（BV1xAtF6EEfC @ 05:19、BV1xAtF6EEfC @ 05:21）。
- **敌方打野露头时先清完自己的野再去支援**（BV1xAtF6EEfC @ 05:25、BV1xAtF6EEfC @ 05:28、BV1xAtF6EEfC @ 05:29）。
- **敌方打野阵亡 + 第二片野区刚刷新 = 白拿一个 Buff**；但"现在野区保护机制还在，所以我们只拿一个蓝就好"（BV1xAtF6EEfC @ 05:36、BV1xAtF6EEfC @ 05:39、BV1xAtF6EEfC @ 05:41、BV1xAtF6EEfC @ 05:43）。
- **中线到位先别急着吃**：对面蓝区刚被反，"这波很可能过来入侵"，所以优先收蓝区（BV1xAtF6EEfC @ 05:53、BV1xAtF6EEfC @ 05:55、BV1xAtF6EEfC @ 05:56、BV1xAtF6EEfC @ 05:57）。
- **反红的视野位**：站在龙坑"尖尖的位置"，"在这里我们可以直接看到敌方Buff，但是在敌方视角却看不到我们的视野"（BV1xAtF6EEfC @ 02:36、BV1xAtF6EEfC @ 02:38、BV1xAtF6EEfC @ 02:40、BV1xAtF6EEfC @ 02:43）。
- **一级反野（BV1x1421t7Dg 的实战判断）**：面对雅典娜"直接去反他的红Buff"，理由是"雅典娜肯定想不到澜一级敢反他的红"；而且"他要是不反我的红，我就赚了"，被反也不亏（BV1x1421t7Dg @ 00:15、BV1x1421t7Dg @ 00:17、BV1x1421t7Dg @ 00:20、BV1x1421t7Dg @ 00:31、BV1x1421t7Dg @ 00:32）。
- **刷野节奏点**："刷完这两组野刚好1分30秒，还是能来得及蹭中线的"（BV1x1421t7Dg @ 01:23、BV1x1421t7Dg @ 01:25、BV1x1421t7Dg @ 01:26）。蹭线时"惩戒加速往后走，不要被打太多状态"（BV1x1421t7Dg @ 01:39、BV1x1421t7Dg @ 01:40）。
- **被克制时不要硬接**：澜不好打貂蝉和老夫子这类英雄（BV1x1421t7Dg @ 02:11、BV1x1421t7Dg @ 02:12），处理方式是"先发育，等我们的装备成型再说"（BV1x1421t7Dg @ 02:21、BV1x1421t7Dg @ 02:23）。
