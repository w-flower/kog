# 金蝉：一技能框住，二技能自己会追，伤害全在"一二一起放"

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。

## 1. 机制内核

1. **一技能"紧箍之咒"是移动牢笼**：扔出紧箍困住首个命中目标三秒，持续造成法术伤害，紧箍以固定速度跟随并获取视野，目标无法离开紧箍范围（BV1wVyHYSELz @ 01:53、BV1wVyHYSELz @ 01:59、BV1wVyHYSELz @ 02:03）。
2. **它克的是位移，不是所有逃跑手段**：对李白、镜这类远距离位移英雄依然强克制（BV1wVyHYSELz @ 02:23、BV1wVyHYSELz @ 02:27）；紧箍持续时间不受韧性影响，抵抗之靴、杨戬被动都压不住（BV1wVyHYSELz @ 02:29、BV1wVyHYSELz @ 02:32）。但净化可以解，芈月大招也能解（BV1qL4y1v7pk @ 01:27、BV1qL4y1v7pk @ 01:30、BV1qL4y1v7pk @ 01:34）。
3. **一技能伤害低、CD 短**：单看伤害很低，但机制恶心、CD 短，是抓边利器（BV1qL4y1v7pk @ 01:21、BV1qL4y1v7pk @ 01:23、BV1qL4y1v7pk @ 01:26）。新版限制范围比之前更大、限制能力减弱，补偿了基础伤害与冷却成长（BV1wVyHYSELz @ 02:07、BV1wVyHYSELz @ 02:11、BV1wVyHYSELz @ 02:15）。
4. **二技能"九环之杖"是主要输出**：放出九枚法器并生成持续五秒的法阵，每次命中激活一枚并造成伤害，全部激活或时间结束再炸一次；对小兵和野怪额外 50% 伤害（BV1wVyHYSELz @ 02:44、BV1wVyHYSELz @ 02:50、BV1wVyHYSELz @ 02:55、BV1wVyHYSELz @ 02:58）。
5. **二技能会自己找人**：法阵自动追踪携带紧箍的对象，附近的兵线和野怪也会被吸向法阵（BV1wVyHYSELz @ 03:02、BV1wVyHYSELz @ 03:05、BV1wVyHYSELz @ 03:08）。所以"金蝉打伤害就是靠一二技能的组合技"，单独扔二技能敌人不踩上去基本没伤害（BV1qL4y1v7pk @ 02:00、BV1qL4y1v7pk @ 02:13）。
6. **新版二技能前期被降温**：基础伤害降、前期冷却增加，后期冷却不变（BV1wVyHYSELz @ 03:21、BV1wVyHYSELz @ 03:28、BV1wVyHYSELz @ 03:30）。
7. **新版被动"锦澜宝衣"是格挡+免控**：每隔 60~48 秒随等级抵挡一次硬控；每隔 2~1 秒获得一层印记、至多九层，受伤消耗一层格挡固定数值伤害（BV1wVyHYSELz @ 00:52、BV1wVyHYSELz @ 00:56、BV1wVyHYSELz @ 01:00）。底层逻辑由百分比免伤改成类似铠开大的格挡，但数值没铠高、还要消耗印记（BV1wVyHYSELz @ 01:08、BV1wVyHYSELz @ 01:10、BV1wVyHYSELz @ 01:16）。
8. **被动内置 CD 长**：要盯状态栏冷却，或看身上锦澜宝衣特效还在不在（BV1wVyHYSELz @ 01:40、BV1wVyHYSELz @ 01:42、BV1wVyHYSELz @ 01:45）。
9. **老版被动只克"少段高爆发"**：对猴子、娜可、兰陵王这种高爆发少段伤害秒脆皮的英雄有用，蒙犽、嬴政、貂蝉、后羿这类就"可有可无"；电刀、面具、回响等装备被动也算多段，会把它磨掉（BV1qL4y1v7pk @ 00:32、BV1qL4y1v7pk @ 00:41、BV1qL4y1v7pk @ 00:57）。这条是旧版口径，新版已改成格挡+挡硬控（BV1wVyHYSELz @ 01:08）。
10. **新版大招"轮回之印"是伤害+击退+团队免控**：直接释放，造成法术伤害和击退，击退距离随法强成长、1000 法强到最大值（BV1wVyHYSELz @ 03:38、BV1wVyHYSELz @ 03:40、BV1wVyHYSELz @ 03:43、BV1wVyHYSELz @ 03:45）。紧箍内目标被击退到边缘会反弹并额外造成伤害，且总会被击退到最大距离（BV1wVyHYSELz @ 03:53、BV1wVyHYSELz @ 03:58、BV1wVyHYSELz @ 04:01）。同时给除自己外最多四名队友挡一次硬控、持续五秒（BV1wVyHYSELz @ 03:47、BV1wVyHYSELz @ 03:51）。
11. **新版大招取消了老版的强化机制**：不再强化一二技能，直接释放；二技能无需强化也会提升攻击频率；"二技能命中叠印记提升大招伤害"也被移除（BV1wVyHYSELz @ 04:02、BV1wVyHYSELz @ 04:07、BV1wVyHYSELz @ 04:13）。整体伤害比之前低不少，补偿是击退（BV1wVyHYSELz @ 04:17、BV1wVyHYSELz @ 04:21）。
12. **老版大招是另一套**：开大后十秒内强化被动/一技能/二技能，打人可叠"蛋"，蛋越多第二段伤害越高，且第二段要等一秒才能放（BV1qL4y1v7pk @ 02:21、BV1qL4y1v7pk @ 02:25、BV1qL4y1v7pk @ 03:12、BV1qL4y1v7pk @ 03:20）。与新版不可混用。
13. **法强在新版等于控制**：因为击退距离随法强成长，所以"当前版本法强可以提升控制能力"（BV1wVyHYSELz @ 04:30、BV1wVyHYSELz @ 04:33）。
14. **大招范围是矩形，斜放更远**：生效范围是一个矩形，斜向释放比正向释放的生效范围更远（BV1wVyHYSELz @ 06:31、BV1wVyHYSELz @ 06:34）。

## 2. 对线 / 打法

**通用 / 辅助**

- **一技能不要打人，要打兵线**：一技能是定点爆破，敌人会走位，"所以呢你就不要打人，一定要用来打兵线"（BV18Vxt6tE56 @ 00:39、BV18Vxt6tE56 @ 00:44、BV18Vxt6tE56 @ 00:47）。
- **前期二技能只对兵线野怪用**：前期二技能只能定住，对英雄意义不大，先用来清兵刷野（BV18Vxt6tE56 @ 00:58、BV18Vxt6tE56 @ 01:01、BV18Vxt6tE56 @ 01:03）。
- **二级后可以打人**：先用一技能再用二技能，二技能"就会一直跟着他走"（BV18Vxt6tE56 @ 01:05、BV18Vxt6tE56 @ 01:08、BV18Vxt6tE56 @ 01:12）。
- **辅助开局就是帮拿资源**：帮队友拿资源、帮打野快速刷掉野区（BV18Vxt6tE56 @ 01:25、BV18Vxt6tE56 @ 02:24、BV18Vxt6tE56 @ 02:26）。
- **出辅助宝石后什么线都能吃**：所有线都可以吃，只有某些英雄的四级线可以考虑留给队友，其余队友都不亏（BV18Vxt6tE56 @ 01:50、BV18Vxt6tE56 @ 02:01、BV18Vxt6tE56 @ 02:42、BV18Vxt6tE56 @ 02:46）。
- **该清线还是得清**："你玩张飞就不要清线了，你玩这种法师之前有用的可以清线"；上路兵线队友没想法，就只能自己清（BV18Vxt6tE56 @ 11:27、BV18Vxt6tE56 @ 11:38、BV18Vxt6tE56 @ 11:40）。
- **二技能可以探草、卡位**：法器的激活效果能探视野、减少被蹲（BV1wVyHYSELz @ 06:01、BV1wVyHYSELz @ 06:03）；对小兵野怪的强制位移在守塔时很实用——把二技能放在兵线后方，强制兵线移动出塔、触发防御塔护盾，让敌人无法配合兵线推塔（BV1wVyHYSELz @ 06:06、BV1wVyHYSELz @ 06:11、BV1wVyHYSELz @ 06:16）。
- **一技能的视野能决定下一步**：命中后获取目标视野，用来预测敌人动向，再决定追击、拿资源还是撤退防守（BV1wVyHYSELz @ 05:41、BV1wVyHYSELz @ 05:47、BV1wVyHYSELz @ 05:51）。
- **站位永远在队友后面**：打团站队友屁股后，不用像张飞、廉颇那样考虑"队友跟不跟"；"队友走多前，你就躲他们后面就行"（BV18Vxt6tE56 @ 05:43、BV18Vxt6tE56 @ 05:46、BV18Vxt6tE56 @ 06:03、BV18Vxt6tE56 @ 06:04）。
- **没技能就别平 A**："没技能的时候不要点平A"，一技能打一套然后拉开（BV18Vxt6tE56 @ 07:04、BV18Vxt6tE56 @ 07:09）。
- **能少死就少死**："哪怕卖一卖队友"，"不要为了救队友把自己带走"（BV18Vxt6tE56 @ 09:43、BV18Vxt6tE56 @ 09:48、BV18Vxt6tE56 @ 09:59）。
