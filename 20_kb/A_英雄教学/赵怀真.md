## 1. 机制内核

1. **被动是四格能量的四种攻击形态**：血条下方四格分别代表掌、拳、肘、靠；消耗后每 0.7 秒回一格（BV1Lv4y1o713 @ 00:07、BV1Lv4y1o713 @ 00:14）。这四段并非随便A，第一段是「一段伤害、对野怪双倍」，第二段是「快速打出两拳」，第三段「恢复生命值，血量越低恢复越多」，第四段「蓄力打出一次高额伤害」（BV11G4y157hB @ 00:30、BV11G4y157hB @ 00:39、BV11G4y157hB @ 00:42、BV11G4y157hB @ 00:45）。
2. **起手固定是掌形态，满能量还会前突**：不管有几格能量都从掌形态起手；满能量时掌形态「会向前突刺一段距离，就有点类似于露娜的第一次普攻」（BV1Lv4y1o713 @ 00:16、BV1Lv4y1o713 @ 00:21）。所以只要压住 0.7 秒的回能间隔、让掌形态始终满能量，就能做到「无限位移」（BV1Lv4y1o713 @ 00:26、BV1Lv4y1o713 @ 00:30）。
3. **两种掌形态都对野怪双倍伤害**：能量不满时掌形态变普通掌形态，但「不管是哪种掌形态，都有一个共同特点，可以对野怪造成双倍伤害」；卡住攻击间隔保持在掌形态，刷野速度就上去了（BV1Lv4y1o713 @ 00:45、BV1Lv4y1o713 @ 00:50）。
4. **普攻是直线穿透**：普攻只命中第一个目标，但「直线范围内的所有敌人都会受到伤害」，四种攻击形态都具备大范围直线攻击（BV1Lv4y1o713 @ 01:07、BV1Lv4y1o713 @ 01:11、BV1Lv4y1o713 @ 01:14）。因此可以「原地控A」，在远处就打到人，但要注意攻击距离，不然会突刺过去（BV1Lv4y1o713 @ 01:23、BV1Lv4y1o713 @ 01:29）；手短时手动清空能量、用普通掌形态，同样能远距离控A，「短手变长手」（BV1Lv4y1o713 @ 01:35、BV1Lv4y1o713 @ 01:40）。
5. **一技能是聚怪 + 两次回拉**：旋风扔出去再拉回来，「可以把敌人聚到一起，就有点类似于鬼谷子的二技能」（BV1Lv4y1o713 @ 01:51、BV1Lv4y1o713 @ 01:58）。用旋风末端命中，会把远处敌人拉到中心拉出第一段，再拉第二段就是「双拉」——远处敌人连续被向后拉两次（BV1Lv4y1o713 @ 02:01、BV1Lv4y1o713 @ 02:15）。敌人和红蓝 Buff 都能拉过墙（BV1Lv4y1o713 @ 02:19）。
6. **一技能第二段冲拳可以改回拉方向**：不移动方向键只能打出原地重拳；移动方向键会朝移动方向冲刺一段并伤害路径敌人（BV1Lv4y1o713 @ 02:35、BV1Lv4y1o713 @ 02:41）。冲拳还能让回拉方向小幅偏移，偏移后旋风碰到路径敌人就把附近敌人吸过去，即「二段控拉」（BV1Lv4y1o713 @ 02:49、BV1Lv4y1o713 @ 03:18）。这段冲拳本身可当小段位移、可穿墙（BV11G4y157hB @ 01:09）。
7. **一技能破隐只有一秒左右**：命中草里目标会短暂获得视野，可探草，也能让兰陵王、阿轲暴露（BV1Lv4y1o713 @ 03:37、BV1Lv4y1o713 @ 03:46）。但「一技能释放结束之后，破影效果也会消失」，实际只有一秒上下，「并没有想象中的那么厉害」（BV1Lv4y1o713 @ 04:00、BV1Lv4y1o713 @ 04:06）。
8. **一技能改敌人朝向**：可以改敌方技能朝向，例如吕布一技能、夏侯惇一技能第二段；但「对霸体无效」（BV11G4y157hB @ 00:57、BV11G4y157hB @ 01:04）。转向「不受我们的英雄站位影响，它会固定地朝自身的反方向进行转向」，即以敌人自身为基准（BV1Lv4y1o713 @ 04:25、BV1Lv4y1o713 @ 04:30）。
9. **二技能是招架不是纯输出**：向前位移一小段后进入招架，期间霸体 + 护盾，持续越久护盾越强、伤害越高（BV1Lv4y1o713 @ 04:48、BV1Lv4y1o713 @ 04:56）。四秒后自动爆炸（BV1Lv4y1o713 @ 06:13）；期间不能移动，可用再点二技能、放一技能或放大招提前取消（BV13YG26nEYb @ 00:44、BV13YG26nEYb @ 00:49）。位移可穿薄墙（BV13YG26nEYb @ 00:56）。
10. **二技能的弹反是一次性免控**：第一次受硬控时朝攻击方向反击，造成击退 + 眩晕，并「清除自身的霸体状态」（BV1Lv4y1o713 @ 05:02、BV1Lv4y1o713 @ 05:10）。如果敌人不在反击范围内，「敌人就不会受到控制效果，而我们自身的霸体状态也不会清除」，等于多一次免控机会（BV1Lv4y1o713 @ 05:20、BV1Lv4y1o713 @ 05:29）。这个效果只触发一次（BV13YG26nEYb @ 01:13）。
11. **一次弹反打出两个范围控**：反击是范围性的，对反击方向所有敌人都击退 + 眩晕（BV1Lv4y1o713 @ 05:35、BV1Lv4y1o713 @ 05:40）；并且「自身附近的小范围也会受到同样的控制效果」，所以一个二技能可以打出两段范围控制（BV1Lv4y1o713 @ 05:54、BV1Lv4y1o713 @ 05:59）。
12. **二技能能移动爆炸**：距离不够时「移动方向键并且点击普攻键」，二技能就朝目标移动再爆炸，任意方向都行（BV1Lv4y1o713 @ 06:29、BV1Lv4y1o713 @ 06:36、BV1Lv4y1o713 @ 06:47）。
13. **大招是双段免伤**：释放时霸体，受伤只吃 30%，剩下 70% 转成能量条存起来，上限 3500 伤害；存满后不再享受这 70% 免伤（BV1Lv4y1o713 @ 07:15、BV1Lv4y1o713 @ 07:24、BV1Lv4y1o713 @ 07:41）。但第二段发射冲击波「整个过程都具备这 70% 的免伤效果」，且无视能量条，「一共可以获得两次免伤效果」，这就是卡双免（BV1Lv4y1o713 @ 07:53、BV1Lv4y1o713 @ 07:59、BV1Lv4y1o713 @ 08:12）。吸收上限按等级走，被动格下面的条变红就代表吸满、不再免伤（BV11G4y157hB @ 02:01、BV11G4y157hB @ 02:16）。
14. **大招第二段是 AOE，且可轮盘锁人**：不锁也会自动锁定一个目标，但「通过轮盘锁定是可以不被人挡掉的」；第二段本身是 AOE，敌人聚成一点就都吃到（BV11G4y157hB @ 02:26、BV11G4y157hB @ 02:35、BV11G4y157hB @ 02:42）。锁定后最后再拖一下轮盘，打得更远更精准，「对线距离就是你的视野范围」（BV11G4y157hB @ 02:51、BV11G4y157hB @ 02:55）。
15. **飞行物可以替队友挡**：李信大招、强化普攻、二技能这类飞行物都能吸纳，吸纳后「不管是飞行物还是飞行物的伤害，都是由我们自己进行吸纳的，队友并不会受到伤害」；但不是飞行物的技能就没法替队友吸收（BV1Lv4y1o713 @ 08:32、BV1Lv4y1o713 @ 08:42、BV1Lv4y1o713 @ 08:55）。

## 2. 对线 / 打法

- **开局的思考顺序**：素材给的是「一野二边三色四中」——先想是否参与野区攻防，再看边路、再看视野、最后看中路（BV1wf7S6ZEiC @ 00:40、BV1wf7S6ZEiC @ 00:44）。
- **一级先看对抗路红区**：对面打野是猴子这种能拼惩的，而「猴子的拼惩镜也抢不过他的」，所以最优开局是去看野区、站对抗路红区视野（BV1wf7S6ZEiC @ 00:48、BV1wf7S6ZEiC @ 01:08、BV1wf7S6ZEiC @ 01:11）。正常辅助还要看河道草，防猴子偷（BV1wf7S6ZEiC @ 01:13）。
- **一级清线是他的强项**：「赵怀真他一级清线是很快的」，一技能聚兵配中单可以快速清线（BV1wf7S6ZEiC @ 01:23、BV1wf7S6ZEiC @ 01:26）。细节是「应该是我们先拉兵，女娲再溜一的，这样清线会快一点」（BV1wf7S6ZEiC @ 01:55）。
- **中路才是主场**：发育路没中立资源时射手可以自己玩，赵怀真「就要多游走，多打中轴」，靠一技能聚兵的特性在中路强度很高（BV1wf7S6ZEiC @ 04:28、BV1wf7S6ZEiC @ 04:33）。
- **转线只为一个目的**：哪里有中立资源就往哪里转，帮队友拿红隼、赤甲（BV1oZTozsEAF @ 00:55、BV1oZTozsEAF @ 00:57）。节奏模板是「一波野区一波中线」（BV1oZTozsEAF @ 01:48、BV1oZTozsEAF @ 01:52）。
- **开局二选一**：中线开、带中单往发育路转；或者直接跟射手。对面辅助是张飞这种「对线肯定是没有意义的」，就站中路河道视野、先帮中单抢线（BV1oZTozsEAF @ 00:27、BV1oZTozsEAF @ 01:01）。
- **提前做人数差**：对面玄策红开、自家宫本蓝开，就抢第二波线把中单带去对抗路，形成四打三，尽早解放马超（BV1oZTozsEAF @ 01:09、BV1oZTozsEAF @ 01:14）。
- **侧面进场**：从侧面进场「技能可以更好的命中，也可以打个出其不意」，一套爆发只要对面半血「基本就很有机会了」（BV1wf7S6ZEiC @ 06:06、BV1wf7S6ZEiC @ 06:08、BV1wf7S6ZEiC @ 06:12）。
- **卡位打断**：卡住沈梦溪的位置不让他过来，他丢炸弹就用一技能打断 + 晕眩，配队友直接打残（BV1wf7S6ZEiC @ 01:31、BV1wf7S6ZEiC @ 01:33）。
- **用二技能主动吃控**：预判猴子交大时「我们用二技能反控他」（BV1wf7S6ZEiC @ 02:49、BV1wf7S6ZEiC @ 02:53）；对张飞大招、玄策二技能过肩摔，主动上去接再反弹眩晕（BV1oZTozsEAF @ 03:39、BV1oZTozsEAF @ 03:41；BV1oZTozsEAF @ 02:13）。
- **用大招霸体接控再走到队友旁**：「利用赵怀真大招移动霸体的特性」吃张飞大招和玄策的控制，然后走到队友旁边（BV1oZTozsEAF @ 02:46、BV1oZTozsEAF @ 02:49）。
- **挤视野能力**：「赵怀真有二技能可以反控，挤视野能力是很强的」，可以直接二技能进场把人赶跑（BV1wf7S6ZEiC @ 09:40、BV1wf7S6ZEiC @ 09:45）。
- **续航是硬伤但版本给了红利**：素材直说「赵怀真辅助续航算他的硬伤」（BV1wf7S6ZEiC @ 04:11）；这个版本血包可以队友与辅助共享，「算是利好这些续航差的硬辅」，他吃到了红利（BV1wf7S6ZEiC @ 04:14、BV1wf7S6ZEiC @ 04:20）。
- **残血别贴脸**：血量残时「不贴近控制方向盘拉开」，打一套控制直接回家（BV1wf7S6ZEiC @ 11:46、BV1wf7S6ZEiC @ 11:48）。
- **召唤师技能跟阵容改**：这套阵容带晕眩 + 冰甲是为了让队友更好跟；如果需要拆火保护就带治疗，「主打就不需要队友跟」；2400 以下「对干他可以吸的分段」会带斩杀自己打伤害（BV1wf7S6ZEiC @ 12:03、BV1wf7S6ZEiC @ 12:06、BV1wf7S6ZEiC @ 12:11）。
- **对抗路/打野口径（上线初期素材，非当前辅助主流）**：作者习惯走对抗路，推荐闪现，也可斩杀或黄刀边惩；打野速度「也很可观」，虽然追击和跑图不突出，但打野同样强（BV11G4y157hB @ 00:10、BV11G4y157hB @ 00:15、BV11G4y157hB @ 00:17）。

## 4. 中后期 / 节奏

- **顺风先不换鞋**：疾跑鞋先用着，「让我们可以快速做视野和协防」；等到 10 分钟关键龙团再切鞋子打团。手速快可以在装备栏提前点好抵抗鞋，打起来瞬间换（BV1wf7S6ZEiC @ 10:34、BV1wf7S6ZEiC @ 10:39、BV1wf7S6ZEiC @ 10:43）。
