# 周瑜：火区铺到哪，塔就掉到哪

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：三份实战解说——中单对线西施的完整转线实录（BV1uP411N7gx）、黄刀打野的推塔节奏实录（BV1Dg411M7VH）、面向 1700 分以下的省标速成讲解（BV1nah7zVE76，含野怪刷新与发育节奏）。
> ⚠️ 三份素材都没有逐件讲出装顺序与铭文具体方案，也没有正面团战的站位细节；出装只给到"针对谁出什么"的散点，故本卡仍标 draft。

## 1. 机制内核

1. **火区是核心产能**：把火区铺开就能"连塔带兵一起打"，人跟塔同时吃伤害，所以他的推进不依赖兵线是否进塔（BV1uP411N7gx @ 02:05）
2. **火区给目标挂持续伤害**：贴塔或贴人时"挂上灼烧印记"（BV1uP411N7gx @ 02:19），对面"碰一下就残血"（BV1nah7zVE76 @ 04:40）
3. **火里能回血**：把火放在自己脚下，人站在火里回血，可以硬扛着换血（BV1uP411N7gx @ 04:49）
4. **一技能用来拉开距离**：被贴近时一技能推开，再一次拉开身位（BV1uP411N7gx @ 04:53）
5. **二技能接大是主要的开/反手组合**：既能"劝退"，也能接闪现后把人"全部收回来"（BV1uP411N7gx @ 04:34、@ 04:44）
6. **不吃经济也有输出**："你就算经济不怎么好，也能打出爆炸伤害"，这点和刺客野核英雄相反（BV1Dg411M7VH @ 01:07）
7. **推塔可以脱手**：给塔"挂上被动"之后人就能走，塔交给队友继续磨（BV1uP411N7gx @ 04:13）

## 2. 对线 / 打法

- **对线西施**：本身好打，但节奏必须先她一步，"不然坐牢的就是你了"（BV1uP411N7gx @ 00:00）
- **对面中辅前期没威胁就直接顶上去抢线**，并且不要和兵线站在一起（BV1uP411N7gx @ 00:06、@ 00:10）
- **对面辅助是鬼谷子**：别抢一级线，鬼谷子基本一级中线开，先看位置再后手吃线；对面站左边就从右边抢（BV1nah7zVE76 @ 00:16、@ 00:24）
- **对甄姬这类前期弱势中单**：先压一波状态再去做事（BV1nah7zVE76 @ 00:31）
- **抢完线不要犹豫，直接转下路**；转向途中先看自家兵线健康度，健康才过去（BV1uP411N7gx @ 00:57、@ 01:01）
- **放线的前提是有人补线**：必须看打野或上单能不能帮你吃这波，"上单在坐牢、打野野区被反你还放线"的话，中塔必掉（BV1uP411N7gx @ 01:35、@ 01:52）
- **对面打野刷得快就必须搞野区**：素材里对面是熊猫打野，"你如果让熊猫安稳发育的话，搞不好就要被平推了"（BV1uP411N7gx @ 00:14、@ 00:18）
- **压塔靠藏视野**：兵线到之前不露视野、不出塔外，等兵线出来直接上去抢，这样压塔效率最高（BV1uP411N7gx @ 02:50、@ 03:02）
- **推塔时盯小地图**：对面包过来就果断走，不要恋战（BV1Dg411M7VH @ 02:27）
- **打野位打法**：黄刀周瑜的刷野与游走比蓝刀快，如果定位就是压塔工具人，黄刀更合适（BV1Dg411M7VH @ 00:15、@ 00:21）

## 4. 中后期 / 节奏

- **正面团打不过就不接**：对面阵容打架凶时，"咱们正面团战肯定打不过的，这把要想赢只能玩转线"（BV1uP411N7gx @ 02:31、@ 02:34）
- **没兵线的团赢了也没意义**："没有兵线，打赢了也推不了塔"（BV1uP411N7gx @ 02:44）
- **转线路线可复制**：中路清完 → 上路过线 → 看中路补位再转中 → 清完兵线再转回上路（BV1uP411N7gx @ 02:39、@ 03:19、@ 03:30）
- **推塔优先于杀人**："我们的目的不是为了留人啊，推塔"（BV1Dg411M7VH @ 02:21）
- **拆完塔就脱手**：二塔挂上被动后交给队友，自己去下一条线过线（BV1uP411N7gx @ 04:11、@ 04:17）
- **兵线不好就控龙**：龙是塔之外的第二产能，打龙时同样要看小地图（BV1Dg411M7VH @ 01:02、@ 03:30）
- **外塔优先级**：素材原话是"我的眼里不允许有一个外塔的存在"，先清外塔再谈别的（BV1Dg411M7VH @ 03:16）
- **中期是出手窗口**：前期只发育不打架也能补评分，中期打两波团就够（BV1nah7zVE76 @ 03:43）
