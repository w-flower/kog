# 老夫子：靠二技能吃塔伤，靠红怒真伤一打多

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。

## 1. 机制内核

1. **二技能反弹普攻**：不但反弹伤害，还能触发装备法球效果，并触发红怒状态下的真伤效果——这是他一打多的根（@ 01:46~01:52、02:12~02:16）
2. **二技能免伤有次数上限、且吃释放时机**：正常释放免疫两次塔攻，第三次打下来免伤时间已结束；卡准时机最多能减免三次塔伤（@ 02:24~02:49）
3. **红怒是真伤来源**：进塔前先打满四层被动，进塔直接红怒（@ 03:17~03:22）
4. **一技能三种攻击方式，结果都是拉开 / 保持一个身位**：不管怎么放，最终都与敌人保持一个身位距离（@ 04:33~04:38）
5. **大招捆缚**：被捆目标无法离开大招范围，持续 5 秒，且敌人减少 20% 伤害（@ 06:25~06:32）

## 2. 核心技巧（这张卡的干货集中在这）

| 技巧 | 做法 | 依据 |
|---|---|---|
| **无兵线拆塔** | 进塔前先用小兵打出四层被动 → 进塔直接红怒 → 开二技能 → 拆塔 | BV1CG4y1q7tv @ 03:17~03:37 |
| **二技能抗塔最大化** | 按防御塔攻击节奏开二技能，把「两次」卡成「三次」 | @ 02:40~02:56 |
| **一闪拉人** | 不要用技能外侧命中，要用**内测整个技能范围**命中 | @ 05:30~05:34 |
| **大闪（越位大）** | 大招先向前跑两步，**在起跳之前**闪现改目标——大招锁定目标后才起跳，起跳后无法改目标 | @ 07:55~08:23 |
| **e 闪大（隔墙/塔下捆）** | 缩短敌方活动范围，让敌人很难跑出防御塔攻击范围，配合塔伤击杀 | @ 07:28~07:33 |
| **侧捆** | 贴视野外的侧向位置捆，避免正面被挡（实录用侧捆盘古） | BV1Fhtb6XEuK @ 06:35~06:38 |

## 3. 对线

- **先 A 前排兵，别抢后排兵**：直接去 A 后排兵会被对手连人带兵一起打；先 A 前排兵、把小兵和人对齐才是正解（BV1Fhtb6XEuK @ 00:07~00:37）
- **一定要抢线**：不抢线的话，自家野怪会被对面顺手拿走（@ 01:32~01:35）
- **别先出布甲**（@ 01:45）
- **对线元歌**：只要不被二技能刮中就行，大招躲不了——两者保证其一即可（@ 03:01~03:23）
- **对线重剑李信**：周围没有兵线野怪时，可以直接闪现躲他重剑一，让他刷新不了重剑（@ 05:27~05:31）
