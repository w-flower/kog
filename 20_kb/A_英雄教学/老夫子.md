# 老夫子：二技能刷得越快越肉，红怒真伤才是伤害来源

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。

## 1. 机制内核

1. **二技能是坦度的主要来源**：开启后 25% 移速、65% 伤害减免，持续 2 秒，一级 CD 7.5 秒（BV1CG4y1q7tv @ 00:11；BV1T24y1g7hK @ 00:54、BV1T24y1g7hK @ 01:08）。刷不出来就有 5.5 秒裸奔窗口（BV1T24y1g7hK @ 01:15）。
2. **被动红怒**：普攻叠印记，满五层加 60 移速、25% 攻速，普攻附带真实伤害，强化持续 5 秒（BV1CG4y1q7tv @ 00:20）。
3. **只有真伤那一下才减 CD**：强化普攻打出的白字真伤才减一二技能冷却；如果敌人被普攻的物理伤害直接打死、没轮到真伤，这一下就不减 CD（BV1T24y1g7hK @ 07:11、BV1T24y1g7hK @ 08:03；BV1sqNgziEr1 @ 08:11）。
4. **二技能反弹普攻**：二技能期间被敌人普攻，每个敌人可反弹一次（BV1sqNgziEr1 @ 02:22）；反弹那一下也算一次普攻，能再减 1 秒二技能 CD（BV1T24y1g7hK @ 03:45），并且能触发装备法球、红怒真伤和减 CD（BV1CG4y1q7tv @ 01:52）。
5. **敌人帮你刷二技能**：敌方普攻打到你身上会刷新二技能冷却，五个人同时 A 一下，5 秒 CD 瞬间刷好（BV1sqNgziEr1 @ 02:38、BV1sqNgziEr1 @ 03:07）。
6. **低怒开二很脆**：没状态时开二刷不了被动，只有红怒状态下平A才能刷二技能（BV1sqNgziEr1 @ 03:32）；所以赖神的结论是"满怒时再开出二技能"（BV1sqNgziEr1 @ 03:58）。
7. **二技能还有个被动**：每次普攻 25% 概率攻击两次，第二下只造成 50% 伤害与 50% 法球效果（BV1CG4y1q7tv @ 00:48），这是快速叠怒与刷 CD 的加速器（BV1CG4y1q7tv @ 00:57）。
8. **大招是捆缚不是爆发**：命中第一个目标捆在原地，目标无法离开大招范围，持续 5 秒，且敌人减少 20% 伤害（BV1CG4y1q7tv @ 06:25、BV1CG4y1q7tv @ 06:29）。
9. **大招有僵直、一技能有后摇**：大招成功那一下有 0.5~1 秒僵直（BV1T24y1g7hK @ 06:03），一技能同样有后摇（BV1sqNgziEr1 @ 07:21）。人多时这两个动作都会被白打（BV1T24y1g7hK @ 06:20）。
10. **大招判定是圆形、释放时会往前走一步**：半径约一个一技能的距离，可横向隔墙命中（BV1T24y1g7hK @ 12:32）；大招过程中人会不断向前贴甚至穿过目标（BV1T24y1g7hK @ 12:51）。
11. **一技能三种命中方式，结果都保持一个身位**：末端拉回、中心小幅拉回、近距离则向外推开（BV1CG4y1q7tv @ 04:33）。一技能还能改变牛魔、项羽这类本体冲锋技能的方向（BV1CG4y1q7tv @ 06:02）。

## 2. 对线 / 打法

- **先认短板**：前期弱、手短、怕风筝又怕控（BV15XCfBPEMt @ 00:29）。当前版本"对面基本上不可能没有控"，所以老头前期对线很难受（BV15XCfBPEMt @ 00:35）。
- **前 4 分钟节奏固定**：四级线看一眼对面中辅有没有漏，同时判断 2V2 强度，因为打野基本都抓对抗路（BV15XCfBPEMt @ 00:57）。
- **打有续航的英雄不要多换血**：老头自身没有续航，换血是亏的（BV15XCfBPEMt @ 01:26）。
- **清线不要急，先卡线**：等对面用完线后把线卡住；对面想吃线靠前，就一闪回拉接大招（BV15XCfBPEMt @ 01:34）。
- **裸电刀**：先出电刀可以让强势期更早到，也具备单杀能力（BV15XCfBPEMt @ 02:07）。
- **中路兵线可补但别贪**：老头可以适当补一波中线，但他"太容易被卡位置"，不像有位移的英雄（BV15XCfBPEMt @ 01:53）。
- **前中期想赢只有一条路**：叫打野来打 2v2、3v3 的人数差，"只要对面一块来了，我们就不要打"（BV1Hm42137V6 @ 02:30）。
- **队友喊你开团先看怒气**：队友没玩过老夫子，不知道叠被动的重要性，"所以你不能瞎开"（BV1Hm42137V6 @ 01:05）。
- **没大没闪被黏住就 A，不要跑**："因为你跑也跑不过，不如起叠被动"（BV1Hm42137V6 @ 02:57）。
- **怕甄姬、西施、海月**，这个版本推荐直接 ban 甄姬（BV1Hm42137V6 @ 02:25）；打海月、达摩这类控制多的阵容可以考虑带净化（BV1Hm42137V6 @ 04:21）。
- **阵容决定强度**：对面没控制、拉扯不了你，老夫子就"特牛逼"；对面全是拉扯型，就从神英雄变成屎英雄（BV1sqNgziEr1 @ 05:46；BV1T24y1g7hK @ 04:28）。
- **前中期不好打铠**（BV15XCfBPEMt @ 03:36）；打典韦则是"很克"，但二技能没用好的老夫子会感觉完全打不过（BV1T24y1g7hK @ 10:15）。

## 4. 中后期 / 节奏

- **带线与正面只能选一个**："他只能选一个，你要想清楚你们家这一把更需要的是带线，还是要有一个正面来占视野的英雄"（BV1sqNgziEr1 @ 23:50）。
- **中期就是多带线**：对抗路说白了就是对线、支援、带线防抓（BV15XCfBPEMt @ 03:43）。
- **带线是唯一的经济来源**，而且他低经济能打得过高经济，所以"他敢去带"（BV1Hm42137V6 @ 03:14、BV1Hm42137V6 @ 03:18）。
- **顺风不用去对面，逆风不用去正面**：逆风去正面没什么用，手短容易被摸状态，最好游离在双边线（BV15XCfBPEMt @ 05:31、BV15XCfBPEMt @ 05:37）。
- **带了线对面回守，就找机会回去捆**（BV15XCfBPEMt @ 05:44）。
- **打得过的时候要去闪捆留人**："不要总是一直去牵制，也不要总是不牵制"（BV1Hm42137V6 @ 03:36）。
- **5 分钟后抱团大于带线**，主要抢中立资源，带线是为了更好地打团（BV15XCfBPEMt @ 09:14）。
- **龙团两条路**：有线权就直接大闪捆人打人数差；没线权就推塔，不算太亏（BV15XCfBPEMt @ 02:19）。
- **团战里他是开启者不是收割者**："老夫子的收割能力是很差的"（BV15XCfBPEMt @ 04:48）。
- **3~4 层被动是分水岭**："有3~4层之前你是废物，有三四层以后你是神"（BV1sqNgziEr1 @ 20:23）。
- **没技能没气时在边缘找辅助混被动**，不要空手进人堆（BV1sqNgziEr1 @ 23:59）。
- **大优势可以先绑前排**：一边打前排一边攒被动，从"区"变"神"再转后排（BV1sqNgziEr1 @ 24:29）；常规团则优先捆前排叠二技能，再顺势摸后排（BV1Hm42137V6 @ 06:17）。
- **守不了家**：逆风时老夫子守家能力弱，身上有两三层被动才勉强能守（BV1sqNgziEr1 @ 12:02）；但他可以去止损、换节奏（BV1Hm42137V6 @ 04:43）。

## 5. 出装铭文

**出装（素材给的是散点，不是一条完整路线）**

- 第一件攻速鞋，第二件电刀，上限最高（BV1T24y1g7hK @ 02:13；BV1sqNgziEr1 @ 04:30）。
- 走抵抗鞋路线则更像坦边，靠大闪开团，上限低一些（BV1sqNgziEr1 @ 04:38）。
- 攻速鞋之后先买两个护甲，不要合成守护者之铠，"两个护甲的性价比最高"（BV1Hm42137V6 @ 01:31）。
- 对面控多：冰心之后换抵抗鞋；控不多：苍穹之后换抵抗鞋；换完补一个小匕首保持攻速（BV1Hm42137V6 @ 01:38、BV1Hm42137V6 @ 01:44）。
- 26% 冷缩加冰心"基本上就能无限二"（BV1T24y1g7hK @ 02:47）。
- 对面爆发高但不肉：永夜 + 不详；常规阵容：魔女 + 末世；控多减速多可把末世换影刃（BV1Hm42137V6 @ 01:49、BV1Hm42137V6 @ 01:58）。
- 很穷时中期可以不买苍穹，先买日冕吃 5% CD（BV1Hm42137V6 @ 02:12）。
- 张德军的新出装第三件直接黄盾，有续航不用回家（BV15XCfBPEMt @ 04:12）；苍穹 + 冰甲 + 极影的 CD 也够用（BV15XCfBPEMt @ 10:29）。
