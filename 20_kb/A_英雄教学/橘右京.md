# 橘右京：30 秒反野起手，一刀劈脆皮、两刀劈不死就别追

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份打野实战直播（BV15sJ263EtQ，全程游戏音效与歌词占多数，可用教学信息极少）；一份「无影爆刺流」出装实测（BV1hx4y197er，出装向，含完整铭文与容错结论）。
> ⚠️ **素材条数少、覆盖不全**：两份都不是系统教学，BV15sJ263EtQ 里能提取的有效句不到十条，BV1hx4y197er 主讲出装、对机制只是一笔带过。**技能机制、连招顺序、对线细节均未覆盖**，本卡只能算「出装 + 打野节奏」的薄卡，未覆盖项全部列入「待补」。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 前期。开局 30 秒就直接进对面野区，靠等级差滚人头（BV1hx4y197er @ 01:39） |
| **节奏职责** | 游走抓人：反野 → 不要急着回自家野区 → 转中路收人 → 再回野区（BV1hx4y197er @ 01:50、01:51；BV15sJ263EtQ @ 03:11） |
| **一句话** | 橘子虽然也打平A，但是一般都是以技能为主 |
| **依据** | 「橘子虽然也打平A，但是一般都是以技能为主」（BV1hx4y197er @ 03:52），所以堆平A的无尽流对他是「选择性的出，基本上用不到」（BV1hx4y197er @ 03:55） |

## 1. 机制内核

1. **伤害结构以技能为主、平A为辅。** 这是评测者给出的核心判断：橘子虽然也打平A，但一般以技能为主（BV1hx4y197er @ 03:52），因此把平A放大的无尽「基本上用不到」（BV1hx4y197er @ 03:57）。
2. **一技能燕返 + 二技能居合是收人手段。** 反野后中路打起来，「反手一个居合一个燕返收下」（BV1hx4y197er @ 01:51）。
3. **单刀爆发高，但一刀不死就断节奏。** 实战里「我刚才那一刀下去竟然没把露娜劈死」（BV15sJ263EtQ @ 05:40）——说明斩杀依赖单次技能命中，空了就接不上。
4. **对脆皮是「满血就是斩杀线」。** 这是原作者对无影爆刺流的宣传口径（BV1hx4y197er @ 00:46），但同一素材后段自己承认这套「缺少容错」（BV1hx4y197er @ 03:41），两个说法要一起看。
5. **1A 是基础衔接动作。** 素材里只留下这一句连招碎片（BV15sJ263EtQ @ 01:06）。

## 2. 对线 / 打法

素材是打野视角，没有对抗路对线内容。

- **30 秒直接入侵对面野区**，对象是带惩戒的司空震（BV1hx4y197er @ 01:37、01:39）；对手「可能都没想到被橘右京反野了」（BV1hx4y197er @ 01:41）。
- **反完不要急着回去。** 先看中路有没有打起来，中路一打就转过去收人（BV1hx4y197er @ 01:50、01:51）。
- **收完人头再回野区。** 「我要收波野区」（BV15sJ263EtQ @ 03:11）。
- **移速装能明显改善转线。** 「这把疾步鞋耍起来了」（BV15sJ263EtQ @ 03:44）。
- **鞋子的抗性判断要看局。** 同一局里主播说「也别抵抗了，这把抵抗没用」（BV15sJ263EtQ @ 03:47），这是单局结论，不能当通用选择。
- **蹲单点。** 抓落单的人先蹲，一刀秒掉小乔（BV1hx4y197er @ 02:14、02:19）。
- **兵线。** 素材只留一句「更（赶）清理中路兵线」（BV15sJ263EtQ @ 10:04），转写含错字，语义为清中线。

## 4. 中后期 / 节奏

- **装备成型后切脆皮几乎无压力。** 「到了大后期，等我们装备全部成型了以后，在我眼里已经没有肉了」（BV1hx4y197er @ 02:43、02:46），「全都是小脆皮」（BV1hx4y197er @ 02:47），顺手拿下狂铁（BV1hx4y197er @ 02:49），11-3 结束（BV1hx4y197er @ 02:52）。
- **但这套全输出装没有容错。** 同一局里被甄姬「轻轻弹了一下」，血量就剩 2/3（BV1hx4y197er @ 03:27、03:29）；评测者的结论是「这套出装是缺少容错」（BV1hx4y197er @ 03:41），「一旦吃到一点伤害就容易参不了团」（BV1hx4y197er @ 03:44、03:47）。
- **因此中后期必须补一件肉。** 「我建议大家补一件肉」（BV1hx4y197er @ 03:48）。
- **顺风局的数据不能当强度证明。** 主播自己也点出前期 5-0 的战绩「挺好看的」（BV1hx4y197er @ 03:21、03:23），随后才暴露容错问题——顺风样本不足以论证强度。

## 5. 出装铭文

**铭文（素材给全了）：**

- 蓝色：4 个狩猎 + 6 个隐匿，两者都加移速、提高机动性（BV1hx4y197er @ 00:59、01:00、01:02）
- 绿色：10 个鹰眼，加物理伤害与穿透（BV1hx4y197er @ 01:03）
- 红色：1 个祸源 + 9 个异变，祸源提供随缘暴击（BV1hx4y197er @ 01:03、01:06）

**出装：**

- 流派名叫「无影爆刺流」（BV1hx4y197er @ 00:11、00:38）。
- 小件顺序按「掐住橘子每一级、每一档的最高伤害阈值」来排（BV1hx4y197er @ 01:09、01:12、01:13），但**具体小件顺序字幕没有逐件念出**，视频称放在置顶（BV1hx4y197er @ 01:17、01:18）。
- 后期做了无尽，原作者意图是「兼顾技能伤害的时候，把平A的伤害也放大」（BV1hx4y197er @ 02:04、02:07）。
- 评测结论：无尽这类装备更适合平A型英雄，「橘子用不到」，建议补一件肉（BV1hx4y197er @ 03:49、03:50、03:52、03:55）。
