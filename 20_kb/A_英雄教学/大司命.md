# 大司命：前期没人单挑得过、靠经济碾压的数值怪

> 只讲英雄本身。官方定位战士，主分路对抗路（可打野）。
> 素材：诛樱《大司命单盾黑刀流 16.0 全局》（BV13yfLByERE，1900 分打野对局 + 出装铭文）、解说小龙《项羽细节对线大司命》（BV135Wkz7EmU，对手视角）。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 对线期就极难处理（出门 4800 血），关键装备成型后进入碾压期 |
| **节奏职责** | **一号位经济刷子**——前期保发育，装备成型后靠经济压制给对面血线压力 |
| **一句话** | **大司命这个英雄思路一定是大于一切的，有钱这个英雄就是厉害** |
| **依据** | BV13yfLByERE @ 11:02（原话）+ BV135Wkz7EmU @ 00:32（对手原话"这种大司命前期基本上没有人可以单挑的过"） |

## 1. 机制内核：肉度与成长性的双曲线

1. **出门坦度即巅峰**：对手视角实测"出门比辅助都肉"，4800 血比刘禅的 4446 还高（BV135Wkz7EmU @ 00:21）
2. **"你说他没有伤害吧他又肉，你说他肉吧他拆塔还快"**（BV135Wkz7EmU @ 03:53）——肉、伤、推塔三项全占，对手找不到针对入口
3. **腿短是唯一软肋**："大司命的腿是比较短的，要是打起来再过去肯定是来不及的"（BV13yfLByERE @ 07:29）——所以一切节奏都要**提前跑位**，团战前先找好绕后位置（@ 07:26）
4. **爆发不吃无尽**："就算在没有无尽的情况下也能打出 1000 多的爆伤"（@ 00:05）——伤害靠暴击铭文和机制，不靠暴击装堆
5. **续航靠吸血刀 + 铭文血量兜底**：吸血刀 800 点额外生命 + 铭文 600 点生命 = 1600 点容错，"没有这 1600 点血其实已经倒下了"（@ 10:22）

## 2. 对线/开局（打野位视角）

- **开局决策只看半区线权**：对面三路没线权才敢偷猪/反野；下路没线权时反野就是四打二变二打四的风险（BV13yfLByERE @ 00:57）
- **猪开就不贪线**："既然你选择了猪开就不能贪"，执意贪上路兵线 = 中线没吃到、小猪没反到、自家小猪还丢了（@ 02:07）
- **大野刀分钱不受 4 分钟保护限制**，出野刀前就提前往中线靠（@ 03:30）
- **八级打六级是随便打的**：经济优势下单杀不用任何操作（@ 04:51）
- 对线期的他没法正面处理：对手项羽的结论是"只能清线补线，队友支援咱再跟他搞"（BV135Wkz7EmU @ 04:21）；出护甲鞋 + 没穿透时"不可能打得动他"（@ 01:59）

## 3. 连招

素材未给出固定连招表，见待补。实战出现过：**二技能接大招反杀**（司马懿飞过来"接二技能接大招直接反杀"，BV13yfLByERE @ 04:39）；**提前换抵抗鞋**应对先手（@ 04:32）。

## 4. 中后期/节奏

- **真正的节奏点只有 10 分钟龙点**：10 分钟前"边刷边发育，没机会就发育"（BV13yfLByERE @ 06:50 附近的打野通用节奏 + @ 06:54）
- **经济领先的滚雪球公式**：追着对面打血线压力 → 对面没法带线吃野 → 对面经济停摆（@ 08:00）；"像我这样稳健的打法你是很难被翻盘的"（@ 08:15）
- **打完团必须收资源**：保持一号位经济（@ 07:48）；队友打赢了不追击，"我们就把兵线带好"（@ 05:44）
- **张飞没大才压塔，有大开龙**："张飞有大给你控到了，一个五杠零的大司命死了是非常亏的"（@ 05:56）
- **高经济可以无视塔伤越塔**（@ 08:35）

## 5. 出装铭文（BV13yfLByERE）

- **铭文**：10 兽痕 + 10 鹰眼 + 7 无双 + 3 祸源；底层逻辑是无双提供暴伤，祸源 + 兽痕保证暴击能出来——"暴击不出来一切都是虚的"（@ 00:12）
- **顺序**：大红刀起手 → CD 鞋 → 影刃 → 黑切 → 吸血刀 → 名刀（@ 00:33）。变体说明：这是"万盾飞天流"把盾装换成黑切的**单盾黑刀流**，黑切同样提供 CD（@ 09:19）
- **CD 鞋是节奏装**："CD 鞋可以跟上他们的技能刷新频率"（@ 04:15）；打完一波**提前算好复活时间换抵抗鞋**反杀（@ 04:32）
- **最后一件看情况**：铭文带无双，所以名刀、苍穹都能做来提容错（@ 10:43）
