# 公孙离：伞是位移，也是命

> 只讲英雄本身。分路思路见 `L_分路/03_发育路.md`。
> 素材：阿良《公孙离零基础保姆级教学》（BV1Qxd8BGEW5，1900 分局全流程）、是秋白《一个视频掌握公孙离》（BV1Uf4y1K7nj）。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 前期到两件套（末世 + 疾跑鞋做好就能单杀战士野；大后期伤害不如呆射） |
| **节奏职责** | **开节奏 / 自由人**——全射手唯一能主动进场、主动拉身位的一个 |
| **一句话** | **手上没技能，我就是个呆射** |
| **依据** | BV1Qxd8BGEW5 @ 04:05（原话"手上没有技能的时候就是一个呆射"）+ @ 08:19（两件套后可单杀战士野） |

## 1. 机制内核：三个技能都是"位移 + 一段伤害"，所以它是游射

公孙离的强不在于单次伤害，在于**每次技能都能换一次身位**。这推出三件事：

1. **伤害必须打满被动**——一套 1A2A 是最短的"打满四层"路径（@ 02:03）
2. **二技能是盾不是伤害**——它能**挡掉普攻**（@ 01:14、@ 01:37），所以对线期真正的核心技能是二技能，不是一技能
3. **回伞是唯一的"撤销键"**——大招回伞可以把自己从进场位置拉回来（@ 11:26），这是所有激进操作的兜底

## 2. 对线：劣势方永远不要先碰兵线

- **开局只分析两件事**：中路有没有线权、射辅对线强度（@ 00:11）
- 阿离打戈娅属于**全时期被压制**（@ 00:16）→ 这把的定位就是抗压
- **劣势方把线卡在自家塔前**，对面想压就上去打一套 1A2A（@ 01:51、@ 02:03）
- **永远不先手碰兵线**：先碰线 = 兵线位置前移 = 你离开塔的保护（@ 02:03）
- **换血的时机是"对面补刀"**：后排兵残血时，对面一定会前压补刀，这时二技能好了就打一套（@ 02:15）——这就是无伤消耗
- **红隼用二技能斩杀**：二技能挡普攻，保证稳拿前期红隼（@ 01:37）
- 对线期只干两件事：**控好兵线和周边野怪 / 用换血技能把对面打残**（@ 03:03）

## 3. 连招：起手式由对方的血量决定

| 场景 | 连招 | 为什么 |
|---|---|---|
| 对线换血 | **1A2A** | 最短的打满被动路径（@ 02:03） |
| 打脆皮 | **A1A 起手** | 快速打满被动，不给他反应（@ 07:54） |
| 打战士 / 高经济目标 | **A3 起手** | 用大招把每段技能当位移，一段一段拉断他的普攻（@ 07:54、@ 08:06） |
| 追杀残血 | 大招起手 | **只有追杀才允许大招起手**，其他情况先一二技能消耗，别 all in（@ 09:07） |

> 原话："大招起手只适用于你追杀对面，也就是说对面是残血或者没技能了。"

## 4. 中后期：边路是舒适区，清边转中

- **4 分钟以后只在两种情况下转线**：自家一塔守不住 / 推掉对面一塔（@ 04:51）
- **中期舒适区是边路**：一个人吃线，经济最高（@ 06:17）
- 循环：**清边 → 转中吃线 → 中没线就吃野怪**（@ 06:54）
- **移速是这套循环的引擎**：末世 + 疾跑鞋（都有血量加成）让你比对面更早抓到 timing（@ 06:05、@ 06:29）
- **后期团战必须手上有红 Buff**（@ 10:51）
- **压高地前先留一把撤退伞**（@ 11:26）

## 5. 弱点

1. **没技能就是呆射**：技能全交完时不要接团、不要救队友（@ 04:05）
2. **大后期打不过呆射**：伤害拼不过，只能靠身位和红 Buff
3. **吃移速装备**：不带疾跑鞋，中低分段的"清边转中"循环跑不起来（@ 06:29）
