# 云缨：三层枪意就是三套技能，循环刷 CD 才是本体

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。

## 1. 机制内核

1. **被动枪意最多三层，放技能就叠**：每释放一次技能叠一层，最高三层，普攻消耗枪意打出不同强化普攻（BV1gX4y1P7LJ @ 02:13）。**不需要技能命中**，对着空气放也能存（BV1wX4y1P7Px @ 01:50）。
2. **一层·坚毅（近身持续输出）**：范围很近，转枪造成四次物理伤害并获得护盾，四次伤害相当于四次普攻、可触发法球效果（BV1gX4y1P7LJ @ 02:26）。释放后可移动、还带加速，是"单挑还是打团都可以用一层反复刷技能拉扯"的那一层（BV1wX4y1P7Px @ 02:06）。
3. **二层·锐意摧城（回血 + 打后排）**：向前突刺三次，最后一次伤害最高，每次命中回血、"自己越残回的越多"，是残血反杀的重要手段（BV1gX4y1P7LJ @ 02:46）。代价是释放时人不能动，"会显得有点呆不丝滑"（BV1wX4y1P7Px @ 02:20）。
4. **三层·真意燎原（远程收割 + 穿墙）**：飞上天空向前劈砍，命中低血量目标有额外倍率，蓄力期间增加移速且可无视地形（BV1gX4y1P7LJ @ 03:01）。
5. **强化普攻减一二技能 CD**：一二层强普命中目标都会减少一二技能冷却（BV1qKWGzgEU4 @ 00:41）——这是"一二技能互相刷"循环的根。
6. **一技能断月（控制）**：挑起并下劈两段伤害，第一段击飞（BV1gX4y1P7LJ @ 00:52）。击飞时长半秒（BV1qKWGzgEU4 @ 02:03）；距离约三四个身位，闪现不能延长一技能距离，但可向后接闪做后撤步（BV1wX4y1P7Px @ 00:26）。
7. **二技能追云（位移 + 减速）**：蓄力持续加速，松开向前突刺并减速，蓄力越久位移越远、伤害越高，**可以穿墙**（BV1gX4y1P7LJ @ 01:04）。读条结束前不松手会自动打出位移+横扫，蹲草存印记时要在读条结束前取消；主动取消还会返还一点冷却（BV1qKWGzgEU4 @ 02:28）。
8. **大招两段 + 霸体免伤**：一段来回突进、对路径造成两次击飞，期间霸体并免伤；二段向前横扫并在原地留火，灼烧停留其上的敌人（BV1wX4y1P7Px @ 00:52）。**一段虽然来回两次，但只加一层印记**；二段也能加一层，且二段可以打断一段（BV1qKWGzgEU4 @ 03:01）。
9. **大招可接闪现**：蓄力中按闪是反向大闪；人飞出去途中按闪会改变二段落点，"机制就类似于韩信的二技能"（BV1wX4y1P7Px @ 01:12）。
10. **印记刷新机制**：每次释放技能都会重置印记消失时间，在归零前循环放一二技能就能一直存住印记（BV1qKWGzgEU4 @ 00:20）。

## 2. 对线 / 打法

素材只覆盖打野，按"开局—刷野—抓人"写：

- **开局**：正常发育路开抓对抗路，红开（BV1Gb7fzJEdo @ 00:21）。
- **抓人必须有依据**："你去抓任何一拨人……一定要有一套完整的依据"，即这波因为对面做了什么我们才去打（BV1Gb7fzJEdo @ 00:27）。
- **八级前对典韦有强度差**："典韦说实话他在八级之前是打不过云樱的"（BV1Gb7fzJEdo @ 01:13）。抓典韦要等他交完一技能——"他一技能能追人，但是不能跑"（BV1Gb7fzJEdo @ 01:29）。
- **刷野节奏公式**：蓝区刷了就打中上，红区刷了就打中下（BV1Gb7fzJEdo @ 02:49）；"野怪多的时候优先刷野、少打架，野怪少的时候多吃线、然后找机会打架"（BV1Gb7fzJEdo @ 04:28）。
- **不吃无意义的架**：下路对面苏烈视野站得很好，"我们去的话对面直接就走了"，这种浪费时间的事不做（BV1Gb7fzJEdo @ 02:33）。
- **逆风不帮低概率团**："打赢的概率很低很低，不帮兄弟，先把经济刷起来才有机会去赢"（BV1Gb7fzJEdo @ 06:56）。
- **带线选择**：上路线队友不敢带（除夏洛特），"他们 C 位比较脆，自己一人带一条线肯定会崩"（BV1Gb7fzJEdo @ 08:07）。
- **抓人姿态**：二技能捏住进场、先打先手，大招没大到就"抓紧往后拉"，再补一刀燎原（BV1Gb7fzJEdo @ 08:19）；有经济又有坦度时可以一打二一打三（BV1Gb7fzJEdo @ 08:32）。
- **越塔判断**：干将保持安全距离时不硬越，"这波越塔风险感觉还是有点大"，改点中二塔再反野（BV1Gb7fzJEdo @ 09:04）。
- **被反杀的教训**（素材自述）：为了叠三层被动硬追典韦，结果典韦回头 + 干将技能很准，直接暴毙（BV1Gb7fzJEdo @ 09:22）。

## 4. 中后期 / 节奏

- **经济领先就多打架**："有经济优势的话，多帮队友打架"（BV1Gb7fzJEdo @ 06:21）。
- **绕后是主要切入方式**：有优势时想办法绕对面后排，接 2A → 一挑 → 大招控两三个（BV1Gb7fzJEdo @ 06:19）；残局继续绕后追艾琳，"别让他跑了"（BV1Gb7fzJEdo @ 06:41）。
- **拆塔与反野连起来**：下路塔 4 分钟就能拆，拆掉后直接反对面野怪（BV1Gb7fzJEdo @ 03:41）；点完中二塔立刻反对面蓝，"把节奏连贯起来"（BV1Gb7fzJEdo @ 09:08）。
- **拿龙前的路线收敛**：拿完红只有两条路——不带中线就刷蓝，刷完蓝再考虑带中或上（BV1Gb7fzJEdo @ 07:50）；暴君前把自家红区刷一遍（BV1Gb7fzJEdo @ 09:45）。
- **结局判断**："这把只有我是顺风"，全队靠一个人压着打才勉强打成顺风（BV1Gb7fzJEdo @ 10:02）。
- **团战定位偏收割**：三层枪意性价比不高——"你需要放三次技能才能存出来一个，前面两次刷 CD 的机会就没了"，主要用于对面血量低于阈值时的收割，其他情况用一二层（BV1wX4y1P7Px @ 02:34）。
- 身板脆、很依赖技能、留人技能容易空——所以思路是"优先叠满 CD、增加坦度"（BV1gX4y1P7LJ @ 05:22）。
- 素材明确说削弱后**对抗路表现不好**，"现在他更适合打野发育"（BV1gX4y1P7LJ @ 05:33）。

## 5. 出装铭文

**打野主流（BV1qKWGzgEU4 @ 04:49）**

- 红刀三件套基本不变：红打野刀 + 暗影战斧，之后补冰痕之握（冰脉）。
- 冷却够了把冷却鞋换成抵抗鞋。
- 最后两件按阵容：追容错出血魔 + 魔女；追伤害出破军 + 苍穹。
- 铭文：十异变、十隐匿、十鹰眼（百穿）。

**另一份打野出装（BV1gX4y1P7LJ @ 05:38）**

- 红打野刀、抵抗鞋、暗影战斧、冰痕之握；想极致输出就把冰痕换宗师；后面破军 + 一件防装（不死鸟/反甲/魔女/不详/爆裂）。
- 走对抗路可把红刀换成碎星锤，或用末世 + 冷却鞋组合；但末世"非常脆、而且要近身肉搏"，对手灵活或装备碾压时效果打折。

**散点**

- 末世与碎星锤的取舍：一二层枪意能反复触发末世被动，打程咬金这类肉时末世伤害明显更高；打脆皮 2131 一套秒，"有没有碎星锤或者末世都没区别"（BV1wX4y1P7Px @ 03:04）。
- 打野红刀也减 CD，所以打野位可以不出冰痕；打野节奏快、没钱憋破军，中期可以直接半肉（BV1wX4y1P7Px @ 03:23）。
- 吸血刀：对面打自己"不疼"的时候才出（BV1Gb7fzJEdo @ 10:26）。
- 魔女：对面艾琳出法装、干将法装伤害高时，用来提高容错（BV1Gb7fzJEdo @ 10:33）。
- 铭文另一版：十隐匿、十鹰眼、八异变两红月（BV1wX4y1P7Px @ 03:33）。
- 娱乐向"边惩黄刀"套路（素材自评强度不确定，仅作记录）：黄刀 + 爆裂 + 不死鸟 + 夺萃，只放一层被动抓人，冷静鞋加黑切 30% CD 就够（BV1wX4y1P7Px @ 03:43）。
