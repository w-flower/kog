# 武则天：大招不是伤害技能，是四分钟那一波节奏的开关

## 1. 机制内核

1. **大招是全图支援 + 团控**：只要大招在身上，无论何时何地都能支援到队友（BV1A2516zEz9 @ 04:01）。
2. **但大招对灵活英雄容易空**：「面对灵活的英雄，你这个大招根本打不中」（BV1A2516zEz9 @ 02:13）。
3. **技能换状态永远对面吃亏**：武则天技能素质很高，对拼换血是自己占便宜（BV1A2516zEz9 @ 01:21）。
4. **先手能力强**：中期可以多主动找机会开节奏（BV1A2516zEz9 @ 04:51）。
5. **二技能可以预判打断**，但会被关羽二技能挡住，属于「能试但不保证」的手段（BV1A2516zEz9 @ 02:18）。
6. **强化一 + 大招具备秒人能力**：一个强化一加大招就直接秒了（BV1m12gBsEWJ @ 02:44）。
7. **【娱乐向】血书 + 狂暴的冷却换算**：血书每 2% 吸血提供 1% 冷却，狂暴给 30% 法术吸血，等于 15% 冷却缩减，且 7 秒内全技能享受、伤害提升 10%（BV1m12gBsEWJ @ 00:15）。
8. **【娱乐向】四件套卡满 CD**：血书 12% + 狂暴 15% + 面具 7.5% + 铭文 5.5% = 40%，狂暴因此取代了 CD 鞋的位置（BV1m12gBsEWJ @ 00:44）。

## 4. 中后期 / 节奏

- **中期的分工是「帮谁」而不是「去哪」**：射手有优势就保射手打推进，打野有优势就帮打野扩大优势，优先射手，因为只有解放射手才能推进（BV1A2516zEz9 @ 00:57）。
- **后期只做一件事**：保射手打（BV1A2516zEz9 @ 01:01）。
- **远程拆火**：下路被蹲时开大远程支援、接上控制拆火，对面双 C 动都动不了（BV1A2516zEz9 @ 04:09）。
- **中一塔推掉后野区随便进**，这是她大顺风局的滚雪球起点（BV1A2516zEz9 @ 04:29）。
- **容错靠装备**：这套出装优先出了面具，容错率比较高，否则差点被猴子秒（BV1A2516zEz9 @ 04:22）。
- **【娱乐向】多利亚把 CD 挪走**：有大招就去找中单；多利亚吃 CD 后大招相当于 18 秒一个（BV1m12gBsEWJ @ 04:01）。
- **技能命中率是所有加成的前提**：「前提是你的技能得放的准，否则给你再多的加成也是白搭」（BV1m12gBsEWJ @ 04:10）。

## 5. 出装铭文

**常规上分线（推荐口径）**
- 常规铭文出装一套；对面回血英雄多就提前出梦魇，换成对应那套（BV1A2516zEz9 @ 00:36）。
- 中单对线期优先面具，容错高（BV1A2516zEz9 @ 04:22）。
- 局势偏逆风时补一件肉装（BV1qvPzziEvE @ 07:19）。
- 对面控制多时把鞋换成抵抗鞋；否则被控到技能都开不出来（BV1qvPzziEvE @ 16:28）。

**娱乐向狂暴血书流（作者自述不推荐上分）**
- 核心四件：血书 + 面具 + 破茧之衣 + 法穿鞋；后两件看局势，可选时之预言、不祥魔女、不死鸟（法坦）或冰甲（BV1m12gBsEWJ @ 01:37）。
- 铭文两套，蓝色与红色不变，只换绿色；关键是凑够 450 点生命值，让血书 + 面具 + 破茧之衣刚好卡到破茧之衣 3000 的加成上限（BV1m12gBsEWJ @ 01:11）。
- 冰甲被动附 10% 韧性，再把鞋换成抵抗鞋、配狂暴被动，直接到韧性上限 60%（BV1m12gBsEWJ @ 01:50）。
- ⚠️ 该流派与常规线的分歧不在装备强度，而在定位：作者自己把它划为娱乐玩法（BV1m12gBsEWJ @ 00:04），上分请按常规线。
