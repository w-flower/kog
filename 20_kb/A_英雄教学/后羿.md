## 1. 机制内核

1. **价值锚点不是输出，是大招**：当前版本后羿"就是一个很难打出输出的英雄"，靠的是大招而不是伤害（BV1La2vB3Ewz @ 00:21）。所以几乎不用纠结"我是不是没打出伤害"。
2. **大招是开团手段**：中路或打野摇过来，就能在线上发起"几乎无解的先手"，让对面掉点后控资源进野区（BV1La2vB3Ewz @ 01:24）。
3. **大招命中给大幅加速，可以当自保**："现在大招命中之后，还可以给你一个大幅的加速效果"（BV1La2vB3Ewz @ 01:38）——被抓时射中就能直接走。
4. **空大代价极高**：空一发就进 45 秒 CD（BV1La2vB3Ewz @ 00:49）。这是"只放必中"的全部原因。
5. **被动叠层是前期的隐性强度**：开局先在野怪身上点三下，把"惩戒射击"叠满再上线（BV1P94z69E2U @ 00:58）。
6. **一技能吃"精准普攻"**：开启一技能后用精准普攻锁后排兵，同时盯前排兵血量（BV1La2vB3Ewz @ 03:06）。
7. **二技能两个身份**：对线期是"前期唯一的一个小爆发"，平 A 和二技能同时出手叠伤害抢中立资源（BV1La2vB3Ewz @ 03:20）；出了对线期就主要是探视野，"千万不要忽略"（BV1La2vB3Ewz @ 03:27）。

## 2. 对线 / 打法

**总原则**

- 一级学二技能上线，"千万别头铁出去"（BV1P94z69E2U @ 00:56）；先在野怪身上点三下叠满被动，再用二技能远程消耗 + 垫刀（BV1P94z69E2U @ 00:58）。
- 尾刀要比小兵自然死亡多拿 30% 经济，这是"拉开经济差距的第一步"（BV1P94z69E2U @ 01:09）。
- 站位不要和小兵叠在一起，否则被鲁班扫射"连人带兵一起打血亏"（BV1P94z69E2U @ 01:30）。
- 补刀不稳就把兵线控在塔外，稳稳吃尾刀（BV1P94z69E2U @ 01:37）。
- 打之前先把被动打出来：A 两下小兵或野怪，再放二技能上去平 A（BV1N7411W7UF @ 03:25）。
- 对面打野/中单从地图上消失就立刻缩回塔下，等他们露面再出来清线（BV1P94z69E2U @ 01:57）。
- 二技能换血时机的判断：对面打野蓝开、队友已给信号，就先猥琐站草丛边等对方辅助打野出线（BV1N7411W7UF @ 03:49）。

## 4. 中后期 / 节奏

**时间线（BV12U4D6dEiY 给出的三条硬标准）**

- **4 分半**：必须"一件成装加一双鞋子"（BV12U4D6dEiY @ 05:35）。第一件一定要出大件，第二件再出鞋子（BV12U4D6dEiY @ 06:20）。
- **7 分半**：两件成装加一双鞋子（BV12U4D6dEiY @ 08:27）。
- **10 分钟左右**（9:30~10:30）：三件套加一双鞋子（BV12U4D6dEiY @ 09:51）。破晓按时做出，意味着每分钟平均经济要 700 以上（BV1P94z69E2U @ 07:18）。

**前中期动作**

- 4 分钟前，"主要经济的来源就是一波兵线、一组野怪"；线能先手清就先手清，不能就后手清（BV12U4D6dEiY @ 00:37）。
- 4 分钟后按局势结束对线，注意力放到每一波中线上（BV12U4D6dEiY @ 05:52）。中线先手清不掉就后手清，清完有时间就去接敌方推过来的兵，没条件就用中一、中二野怪止损（BV12U4D6dEiY @ 07:46）。
- **中一塔是命门**："谁先被打开，谁先难受"（BV12U4D6dEiY @ 08:08），所以中期的动作要围绕中一塔攻防。
- 别为了盯团战错过清线：对面打架时先把中线清掉，"问题就解决了"（BV12U4D6dEiY @ 09:58）。

**中后期团战处理**

- 中期开始跟团打节奏：大招可以先手射脆皮开团，也可以留着等团战开启后定对面关键 C 位，或等对面切入时自保（BV1La2vB3Ewz @ 01:54）。
- **不要把大招当全屏技能用**：近距离射，判定范围大"几乎是必中的"；注意别射到霸体上、别被坦克挡掉（BV1La2vB3Ewz @ 02:07）。
- 后期就做两件事：跟中线、尾随队友（BV12U4D6dEiY @ 12:28）。
- 团战位置永远在边缘走 A，前排倒了立刻后撤别犹豫（BV1P94z69E2U @ 02:42）。
- **隐藏视野是核心手段**：故意后撤消失在视野里，对面火力只能倾泻到自家前排，等最大威胁进场交完技能再上前（BV1P94z69E2U @ 04:35）。
- 射手底层逻辑："前中期射手核心任务就是躲和避战"，装备成型后再带队友打一两波决定性团战（BV1P94z69E2U @ 07:58）。
- **反面教材**（素材自述）：状态不好时看到张飞吼住四人就上头跟输出，暴露视野被侧翼李白带走（BV1P94z69E2U @ 08:43）。
- **阵容取向**：喜欢打"对面呆射加软辅"，好射且射完对面走不掉（BV1La2vB3Ewz @ 01:14）；不适配保护型辅助，更想要能配合大招的开团型辅助（BV1La2vB3Ewz @ 02:31）；比起对面先手，更怕对面反手（BV1La2vB3Ewz @ 02:45）。
- **实录音配片段**：落后时队内反复喊"经济落后先发育"（BV1rFKy6kE9P @ 01:32）（BV1rFKy6kE9P @ 03:20）；打团前强调"把状态先补起来"、蓝 buff 该让就让，然后直接抓龙（BV1rFKy6kE9P @ 10:38）；高地阶段的选择是"守着打，等他们打过来，打赢一波就可以打反击"（BV1rFKy6kE9P @ 16:19）；队友要给后羿开好视野、"别让后羿被碰到就行"（BV1rFKy6kE9P @ 18:07）。
