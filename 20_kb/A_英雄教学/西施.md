# 西施：不靠装备吃饭，靠一技能拉到人就开团

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：三份——一份中单逆风翻盘实录，全程指挥口吻、逆风纪律讲得最细（BV1WyY9zZEGk）；一份系统教学，含铭文出装与三套连招编号（BV1PK411j76H）；一份与国一西施共创的技能+节奏教学（BV1uEY1zCEA3）。
> ⚠️ 素材仅 3 条、覆盖不全：三份全是中单视角，缺对抗路/辅助位西施的对照；出装存在两套完全不同口径（冷却鞋+回响面具 vs 疾跑鞋+梦魇冰杖），本卡分来源并列、未强行合并；部分数值（被动 40%、大招 8 秒）只有单一来源，未交叉验证。

## 1. 机制内核

1. **被动是距离收益**：离敌人越远伤害越高，最高提升 40%（BV1uEY1zCEA3 @ 00:17、BV1uEY1zCEA3 @ 00:19）；最远就是二技能释放的指尖处，约两个闪现的距离（BV1PK411j76H @ 01:33）。所以拉人时"我们也要同时跟着往前走"（BV1uEY1zCEA3 @ 00:27），往一技能控制的方向走位拉扯（BV1uEY1zCEA3 @ 00:23）。
2. **一技能是核心，第一段是拉到中心**：向指定区域丢法器，区域内单位被拉到中心（BV1uEY1zCEA3 @ 00:32）；五秒内再次释放，可以把敌人往指定方向拉一段距离（BV1uEY1zCEA3 @ 00:37）。命中后附带五秒印记（BV1uEY1zCEA3 @ 01:57）。
3. **一技能打兵/野是双倍伤害，但没有第二段**：对小兵和野怪释放"不能触发第二段控制，但可以造成双倍的技能伤害"（BV1uEY1zCEA3 @ 00:41；BV1PK411j76H @ 01:54）。这就是一级能两个一技能清一波线的原因（BV1uEY1zCEA3 @ 04:02）。
4. **一技能只拉最近的单位**：范围内有多个敌人时，"西施会选择拉距离自身最近的单位"（BV1uEY1zCEA3 @ 00:53），意味着人多时拉到的未必是你想拉的那个。
5. **一技能控制优先级很高**：能打断很多英雄的施法，"比如牛魔的大招、司马懿大招以及项羽的一技能"（BV1uEY1zCEA3 @ 00:59、BV1uEY1zCEA3 @ 01:05）。
6. **一技能有操作范围**：超出这个范围就控制不到敌人（BV1PK411j76H @ 01:50）。
7. **二技能是延迟爆炸的减速球**：丢出能量球，首次命中造成持续 1.5 秒减速（BV1uEY1zCEA3 @ 01:46）；只有内圈的敌人才吃持续伤害（BV1uEY1zCEA3 @ 01:50）；两秒后爆炸，中心位置双倍伤害（BV1uEY1zCEA3 @ 01:52；BV1PK411j76H @ 02:05）。
8. **二技能会追印记**：一技能命中后给敌人五秒印记，"而这个法球会朝有印记的敌人移动"（BV1uEY1zCEA3 @ 01:57、BV1uEY1zCEA3 @ 02:00）。
9. **二技能对英雄穿过去、对野怪停下来**：对英雄释放时球会直接穿过去，碰到野怪则停下，所以要"走位一下，避开野怪"（BV1uEY1zCEA3 @ 02:05、BV1uEY1zCEA3 @ 02:12）。
10. **二技能只有两秒，别放太远**：一是不要放得太远，二是拉的时候"不要往二技能的反方向拉"，否则球还没到敌人面前就爆了（BV1uEY1zCEA3 @ 02:15、BV1uEY1zCEA3 @ 02:22）。
11. **大招是"强化窗口"**：强化自身并提升视野，持续八秒（BV1uEY1zCEA3 @ 02:30、BV1uEY1zCEA3 @ 02:33）；释放后半秒获得额外 50% 移速（BV1uEY1zCEA3 @ 02:35；BV1PK411j76H @ 02:20）；期间一技能二段变两段、二技能冷却减半（BV1uEY1zCEA3 @ 02:39；BV1PK411j76H @ 02:12）。
12. **大招立刻刷新一次二技能**：可以先丢一个二技能，再开大刷新后丢第二个，"这样就能多出一个二技能的伤害"（BV1uEY1zCEA3 @ 02:46；BV1PK411j76H @ 02:09）。
13. **第二段能拖到大招结束之后**：在大招快结束前拉一次敌人，大招结束后"第二段依然可以释放"（BV1uEY1zCEA3 @ 02:56、BV1uEY1zCEA3 @ 02:58）——这是卡双拉的时间基础。
14. **控制最大化靠"等第一段到终点"**：要等第一段拉到终点后，再立刻接第二段，"就算是韩信这种位移多的英雄也没办法跑掉"（BV1uEY1zCEA3 @ 03:02、BV1uEY1zCEA3 @ 03:09）。
15. **闪拉是"先闪再一"，不是"一完再闪"**：闪现搭配一技能可以闪拉；"先闪现再接一技能，而不是放完一技能再接闪现"，另外二技能也不能闪二（BV1uEY1zCEA3 @ 01:27、BV1uEY1zCEA3 @ 01:39）。

## 2. 对线 / 打法

- **出门先买鞋再换装**："可以养成出门买鞋，然后换其他装备的习惯"，白嫖一段移速，比对面法师先到线上、先站住一边草丛（BV1uEY1zCEA3 @ 05:55、BV1uEY1zCEA3 @ 05:57）。
- **去中路的路上先看面板**：打开属性面板看对面出门买什么，能看出对手铭文情况和英雄血量，方便判断换血赚不赚（BV1uEY1zCEA3 @ 06:02、BV1uEY1zCEA3 @ 06:07）。
- **开局先认对面有没有净化**：对面没带净化、且是木兰苏烈大乔这类没位移的英雄，"我们是非常好拉的"（BV1uEY1zCEA3 @ 05:42、BV1uEY1zCEA3 @ 05:45）。大乔带的是闪现，拉到她"在没有净化的情况下是必死的"（BV1uEY1zCEA3 @ 07:16、BV1uEY1zCEA3 @ 07:19）。
- **前期站位围绕河道视野**：布防是为了"有效的防止被偷野怪"（BV1uEY1zCEA3 @ 06:20、BV1uEY1zCEA3 @ 06:22）；对面打野+苏烈这种入侵组合，先"把对面的位置找出来，做一波野区防守"（BV1uEY1zCEA3 @ 06:14、BV1uEY1zCEA3 @ 06:18）。
- **知道对面红开就去下路帮红隼**：清完线看到下路射手还在争红隼，就下去帮忙；可以拉视角看红隼血量判断对面射手位置（BV1uEY1zCEA3 @ 06:26、BV1uEY1zCEA3 @ 06:33）。
- **看不到人也能定位**：没有孙尚香视野，但"孙尚香的平A打到红隼身上时候会有效果"，据此拿到她的大概位置（BV1uEY1zCEA3 @ 06:36、BV1uEY1zCEA3 @ 06:41）。
- **拉到人后不要急第二段**：二技能减速到直接拉，拉到手"也不要着急的去拉第二段"，先多打几个平A，等对面下一个位移交完再打断，"这样孙尚香就必须得交闪现"（BV1uEY1zCEA3 @ 06:45、BV1uEY1zCEA3 @ 06:51）。
- **换到东西就走**：打出孙尚香闪现和苏烈被动"就已经很赚了，完全可以直接回中"；素材自己复盘"这里多上头导致艾琳被留…这一波其实算是比较亏的"（BV1uEY1zCEA3 @ 07:03、BV1uEY1zCEA3 @ 07:09）。
- **打木兰要等她的霸体**：等她重剑的时候再拉（BV1uEY1zCEA3 @ 08:58、BV1uEY1zCEA3 @ 09:00）；"要等木兰所有的霸体都交完后，才用第二段E技能"，期间保持距离丢二技能（BV1uEY1zCEA3 @ 09:46、BV1uEY1zCEA3 @ 09:51）。
- **推塔时往前卡位，但一技能要捏着**："你没有把握E技能能拉到人，那就不要去放E技能"，因为不放对面就不敢上来（BV1uEY1zCEA3 @ 09:59、BV1uEY1zCEA3 @ 10:06）。
- **蹲人要先确认队友跟得上**："确保队友能跟上输出的时候再动手"；素材点得很直白——很多人拉点很准，"但总让对面跑掉"（BV1uEY1zCEA3 @ 08:40、BV1uEY1zCEA3 @ 08:49）。
- **蹲草要卡视野**：卡视野就是利用地图视野盲区——"你能看到他的视野，但他却不能看到你的视野"，据此预判走位（BV1PK411j76H @ 06:32、BV1PK411j76H @ 06:41）。
- **先占中路一边草丛**：对面不漏视野时先把中路一侧草占住，"如果有人来踩视野的话，我们直接拉就可以抓到"（BV1WyY9zZEGk @ 04:24、BV1WyY9zZEGk @ 04:29）。
- **卡视野要分两段进草**：先等对面印记消失、先进小草，再等对面人离开、进中左草，这样才蹲得到（BV1PK411j76H @ 06:55、BV1PK411j76H @ 06:58）。
- **预判位移就是自保**：兰陵王的隐身、韩信的二一、花木兰一技能、达摩一技能这些位移，能预判到并拉走就能自保（BV1PK411j76H @ 05:39、BV1PK411j76H @ 05:51）。
- **命中率靠拉视野**："拉视野获取对方动向就非常重要"；不会拉三指就开镜头偏移，往需要的方向滑一下，再点小镜头回正（BV1uEY1zCEA3 @ 01:10、BV1uEY1zCEA3 @ 01:21）。

## 4. 中后期 / 节奏

- **4 分钟是两个节奏点**：暴君龙刷新 + 家里红刷新，"清完线一定不要乱跑"（BV1uEY1zCEA3 @ 08:13、BV1uEY1zCEA3 @ 08:19）。
- **踩不住河道视野就放龙**：队友不在、镜在上路漏了、打野不在，"那么这条龙只能给"（BV1uEY1zCEA3 @ 08:21、BV1uEY1zCEA3 @ 08:27）。
- **但红背必须踩**：防对面"开完暴君反我们家红"，所以要去踩红背（BV1uEY1zCEA3 @ 08:28、BV1uEY1zCEA3 @ 08:32）。
- **打野掉点必被进野区**："只要我们打野掉点…都会选择进我们家野区"，所以要赶紧协防，并"第一时间让对抗路也传送过来"（BV1uEY1zCEA3 @ 07:34、BV1uEY1zCEA3 @ 07:40）。
- **打团只用二技能减速限制**："利用好二技能的减速去最大程度的限制对面"，同时注意站位（BV1uEY1zCEA3 @ 07:54、BV1uEY1zCEA3 @ 07:56）。
- **她不吃伤害**："西施这个英雄是不需要去前面吃伤害的"（BV1uEY1zCEA3 @ 07:59、BV1uEY1zCEA3 @ 08:01）。
- **丢完二就往后拉**：打团保持安全距离，"丢完二技能就往后拉"，既不吃伤害又让伤害最大化（BV1uEY1zCEA3 @ 11:01、BV1uEY1zCEA3 @ 11:08）。
- **中期换抵抗鞋**："到了中期我们基本就不需要再保图了"，可以把鞋换成抵抗鞋提高韧性（BV1uEY1zCEA3 @ 09:53、BV1uEY1zCEA3 @ 09:57）。
- **双核局盯核心**："一定要多看核心射的位置，不要让你的核心输出掉点"（BV1uEY1zCEA3 @ 10:08、BV1uEY1zCEA3 @ 10:14）。
- **逆风第一原则：经济自己拿**："有线直接吃，有野怪就直接刷掉"，"我们一定要把经济掌握在自己手中，才能够找到机会"（BV1WyY9zZEGk @ 01:29、BV1WyY9zZEGk @ 01:39）。

- **见好就收**：打掉点就撤，"逆风局一定要见好就收"；抓死廉颇之后"赶紧把家里的蓝Buff也给拿下"（BV1WyY9zZEGk @ 03:31、BV1WyY9zZEGk @ 04:49）。

- **守家与让塔**：上路塔守不住就放，"这上路塔不要了，对面要转中的"（BV1WyY9zZEGk @ 05:01、BV1WyY9zZEGk @ 05:03）；但要往外卡位置"别让他推塔"（BV1WyY9zZEGk @ 06:46、BV1WyY9zZEGk @ 06:49）。
