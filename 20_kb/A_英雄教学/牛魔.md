# 牛魔：一技能飞斧能回收，控制和减抗一起打出去

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份巅峰千强打野牛魔实录（BV1bXsh6YEAM）、一份新版牛魔体验服实测（BV1pS8c6XEK5）、一份无限控制流出装与思路（BV1PoWu6bEcg，作者称由 126 段国服辅助研发）、一份输出流娱乐玩法（BV1vop76qEb8）。
> ⚠️ 四条素材都是「新版牛魔」口径（一技能改成可回收飞斧、加点从主二改成主一），与老版牛魔教学不通用；同时四条定位互不相同（打野、辅助控制流、输出流娱乐、体验服测试），本卡按「谁讲的、什么局」分开标注，不合并成一套。铭文只有一条给了具体配置，其余未覆盖；逐英雄对位与逆风守家细节也未覆盖。

## 1. 机制内核

1. **一技能改成飞斧、固定四秒回收**：斧头丢出去「四秒就自动收回来了，无论你CD怎么样，都是四秒的」（BV1pS8c6XEK5 @ 05:30、BV1pS8c6XEK5 @ 05:33）。回收不是看 CD，是固定 4 秒，这点素材特意纠正过一次（BV1pS8c6XEK5 @ 05:37）。
2. **飞斧有灼烧，可以捡起来再砍**：打野开局「29秒扔斧头灼烧，再捡起来砍一刀，然后直接扔斧头接E伤害拉满」（BV1bXsh6YEAM @ 00:33、BV1bXsh6YEAM @ 00:37、BV1bXsh6YEAM @ 00:39）。
3. **一技能叠二技能是核心联动**：「不能二技能冲过去，应该一技能加二技能，然后冲过去的时候，他会拾起斧头再劈出一刀」，这样刷野最快（BV1pS8c6XEK5 @ 05:39、BV1pS8c6XEK5 @ 05:43）。清线同理：「一技能过去，然后你二技能捡斧子又在劈一刀」（BV1pS8c6XEK5 @ 04:23、BV1pS8c6XEK5 @ 04:24）。
4. **一技能会被挡**：近战贴脸时「你也丢不出去的，这个丢的话会被人卡住的」；有小兵也会挡住，「让你丢的不远」（BV1pS8c6XEK5 @ 02:05、BV1pS8c6XEK5 @ 03:24、BV1pS8c6XEK5 @ 03:26）。
5. **一技能减物抗**：命中后最高降 120 点物抗，价值约等于半把暗影战斧（BV1vop76qEb8 @ 00:28、BV1vop76qEb8 @ 00:34）。
6. **加点变成主一**：「现在应该要主一了，不像以前要主二」（BV1pS8c6XEK5 @ 02:48、BV1pS8c6XEK5 @ 02:51）。
7. **二技能是位移 + 击飞 + 落地减速**：素材倾向开局学二，「加个击飞，然后落地有个减速会好一点」（BV1pS8c6XEK5 @ 01:42、BV1pS8c6XEK5 @ 01:45）。这个位移很关键，反蹲时「不要交二，因为这个位移很重要」（BV1bXsh6YEAM @ 02:02、BV1bXsh6YEAM @ 02:05）。
8. **被动给双抗**：「牛魔的被动是给自己和血量最低的队友增加双抗，所以前期强度还是比较高的」（BV1PoWu6bEcg @ 02:41、BV1PoWu6bEcg @ 02:44）。也正因为如此，身边得有队友才有加成（BV1vop76qEb8 @ 02:02）。
9. **被动 + 近卫的双抗能被魔女放大**：魔女斗篷新增被动「能把15%的额外法抗变成物抗」，而「牛魔的被动和近卫加的双抗都算在里面」，所以装备成型后是数值怪（BV1PoWu6bEcg @ 02:09、BV1PoWu6bEcg @ 02:11、BV1PoWu6bEcg @ 02:15）。
10. **大招前摇长是硬伤**：素材直说「如果策划愿意给牛魔大招降低前摇，那么上限将会更大」（BV1bXsh6YEAM @ 04:42、BV1bXsh6YEAM @ 04:45）；所以必须预判，「因为大招除了预判，不然很容易空大」（BV1bXsh6YEAM @ 03:50、BV1bXsh6YEAM @ 03:52）。
11. **二技能、大招都能接闪现**：「牛魔的二技能和大招都可以衔接闪现」；大招前摇长，所以准备开团时「先反方向释放，然后闪现拍过去」，打对面一个出其不意（BV1PoWu6bEcg @ 03:54、BV1PoWu6bEcg @ 03:57、BV1PoWu6bEcg @ 04:00）。

## 2. 对线 / 打法

- **前期站前面替射手挨揍**：「前期对线要注意往前站，替射手挨揍」，没事就走，一技能劈一斧子消耗（BV1PoWu6bEcg @ 02:59、BV1PoWu6bEcg @ 03:01、BV1PoWu6bEcg @ 03:02）。
- **二技能要捏住**：除非有必杀把握，不然二技能不要轻易放，前期 CD 长，「顶进去容易出不来」（BV1PoWu6bEcg @ 03:04、BV1PoWu6bEcg @ 03:07、BV1PoWu6bEcg @ 03:09）。
- **对面反野就去拖**：对面有老虎、兰陵王这种大概率反野的，「就去野区河道逛逛」，发现反野直接顶过去拖，拖到队友过来；野区保护机制 + 自身被动双抗，「对面八成是打不过的」（BV1PoWu6bEcg @ 02:46、BV1PoWu6bEcg @ 02:50、BV1PoWu6bEcg @ 02:56）。
- **弱势段别打先手**：冰霜冲击之前坦度不高、CD 也长，「稍有不慎就容易被集火阵亡」，所以尽量别先手（BV1PoWu6bEcg @ 03:13、BV1PoWu6bEcg @ 03:15）。这段时间就去中路边草蹲、藏视野，附近有队友就「大招接二技能连控，基本上都是必秒的」（BV1PoWu6bEcg @ 03:18、BV1PoWu6bEcg @ 03:21）。
- **开局公式与拿一血**：辅助开局公式「一野二边三色四中」，可以先去边路拿一血（BV1pS8c6XEK5 @ 00:53、BV1pS8c6XEK5 @ 00:57）。
- **塔下消耗**：塔边蓄力丢一下消耗、回来击飞A一下再丢（BV1pS8c6XEK5 @ 01:50、BV1pS8c6XEK5 @ 02:14、BV1pS8c6XEK5 @ 02:18）。
- **一技能的循环节奏**：「丢中再接二技能，或者等他回的时候再接二技能，等他差不多消失，然后你那个一技能又好了，又能再丢」（BV1pS8c6XEK5 @ 03:07、BV1pS8c6XEK5 @ 03:09、BV1pS8c6XEK5 @ 03:12）。
- **清线快是这版的质变**：「一接二技能快速清线」，「跟以前也是不一样的」（BV1pS8c6XEK5 @ 04:21、BV1pS8c6XEK5 @ 04:23）；素材总结「等于多了一个一技能劈出去、然后回收那两段伤害」（BV1pS8c6XEK5 @ 06:36、BV1pS8c6XEK5 @ 06:39）。
- **开团连法**：「一技能加形昭减速接大招，对面没位移，基本跑不掉」（BV1pS8c6XEK5 @ 07:26、BV1pS8c6XEK5 @ 07:29）。
- **打野牛魔的逻辑（BV1bXsh6YEAM 口径）**：强势点就是「前期无限打架」，逼对面打架的方式是「往对抗路刷打信息差」（BV1bXsh6YEAM @ 00:13、BV1bXsh6YEAM @ 00:19、BV1bXsh6YEAM @ 00:21）。强度相当于夏侯、元坦这类蓝领，「但是还能略胜一筹」，因为坦度、伤害、拆火、控制、信息差同时在线（BV1bXsh6YEAM @ 00:23、BV1bXsh6YEAM @ 00:30）。
- **蓝领不刷全野**：「玩牛魔这种蓝领，不需要野区全刷」，尽量多放小野给射手吃（BV1bXsh6YEAM @ 02:20、BV1bXsh6YEAM @ 02:22、BV1bXsh6YEAM @ 02:24）；但「能拿野刀就直接拿，不要让队友单吃」（BV1bXsh6YEAM @ 02:54、BV1bXsh6YEAM @ 02:57）。
- **打野要指挥**：开麦指挥苏烈往下靠、让中单来速刷，「因为信息差不仅信息对面还信息队友」（BV1bXsh6YEAM @ 01:16、BV1bXsh6YEAM @ 01:25、BV1bXsh6YEAM @ 01:27）。
- **输出流口径**：更适合打野而不是对抗路，因为被动双抗「身边有队友才会有加成」，走对抗容易变孤儿路（BV1vop76qEb8 @ 02:01、BV1vop76qEb8 @ 02:05、BV1vop76qEb8 @ 02:06）。
- **被瑶克制的旧账**：素材开头就提「以前牛魔就是很被瑶克制」，这一局是拿来试新版有没有改善（BV1pS8c6XEK5 @ 00:05、BV1pS8c6XEK5 @ 00:09）；新版是否真的解决，素材没有给出明确结论。

## 4. 中后期 / 节奏

- **后期靠坦度往前顶**：「靠自己的坦度往前顶就行，等到对面交完关键技能后，直接闪开，一锤定音」（BV1PoWu6bEcg @ 03:48、BV1PoWu6bEcg @ 03:50、BV1PoWu6bEcg @ 03:52）。
- **团战定位是吃技能**：「团战胜利有两种办法」——自己收割，或「自己吃完技能让队友收割」，牛魔「可以完美做到后面这种情况」（BV1PoWu6bEcg @ 03:28、BV1PoWu6bEcg @ 03:32）。
- **实战例子**：伽罗被勾，大招拍起三个接二技能 + 冰霜，「技能全吃，控制拉满」，队友跟上打出二换五（BV1PoWu6bEcg @ 03:34、BV1PoWu6bEcg @ 03:38、BV1PoWu6bEcg @ 03:43）。
- **成型后的坦度**：「神装小乔想打死我们得丢11次扇子」，暴击流铠开大「都得输出20秒左右」（BV1PoWu6bEcg @ 02:19、BV1PoWu6bEcg @ 02:22）。
- **装备替换**：中后期不需要星泉续航，可换形昭（减速、探视野）或救赎之翼（强化保人）（BV1PoWu6bEcg @ 02:31、BV1PoWu6bEcg @ 02:32、BV1PoWu6bEcg @ 02:34）。
- **打野节奏三件事**：龙点、边塔、反野轮着做。边路有线权、自己没惩戒而对面想抢龙时，「就直接趁这一波打龙团架，扩大我们的优势」（BV1bXsh6YEAM @ 03:39、BV1bXsh6YEAM @ 03:44、BV1bXsh6YEAM @ 03:46）。
- **中轴视野**：清完线「把中塔给挤出来」，因为这套阵容里中塔的重要性很高（BV1bXsh6YEAM @ 05:01、BV1bXsh6YEAM @ 05:04、BV1bXsh6YEAM @ 05:16）。
- **假视野与信息差**：先给上路一个假视野，等视野消失再看大乔站位直接开（BV1bXsh6YEAM @ 03:07、BV1bXsh6YEAM @ 03:09、BV1bXsh6YEAM @ 03:11）。

## 5. 出装铭文

**出装（无限控制流，BV1PoWu6bEcg 给出的顺序最完整）**

1. 辅助宝石 → 冷静之靴：「高冷却能让我们在前期就频繁用二技能打控制」（BV1PoWu6bEcg @ 01:25、BV1PoWu6bEcg @ 01:27、BV1PoWu6bEcg @ 01:29）。
2. 宝石升近卫：「荣耀近卫的双抗加上被动的双抗」让自己和队友都更肉（BV1PoWu6bEcg @ 01:33、BV1PoWu6bEcg @ 01:34）。
3. 星泉补续航；注意「除非队友快（死），否则尽量脱战再用」，被打到恢复效果会降低，且治疗量也算进评分（BV1PoWu6bEcg @ 01:38、BV1PoWu6bEcg @ 01:40、BV1PoWu6bEcg @ 01:44）。
4. 冰霜冲击：「主动技能群体控制，是我们无限控制流和高评分的关键」（BV1PoWu6bEcg @ 01:49、BV1PoWu6bEcg @ 01:56、BV1PoWu6bEcg @ 01:58）。此时冷静鞋 + 铭文冷却缩减到 27.5%（BV1PoWu6bEcg @ 01:51、BV1PoWu6bEcg @ 01:52）。
5. 看局势：对面法师猛先魔女斗篷，对面射手刺客凶先极寒风暴再魔女；之后冷静鞋换抵抗鞋（BV1PoWu6bEcg @ 02:00、BV1PoWu6bEcg @ 02:02、BV1PoWu6bEcg @ 02:06）。
6. 第六件优先霸者重装，进一步提升坦度与续航（BV1PoWu6bEcg @ 02:27、BV1PoWu6bEcg @ 02:28）。
