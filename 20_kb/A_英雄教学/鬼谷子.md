## 1. 机制内核

1. **二技能是核心**：周围成圈持续伤害，两秒后把敌人拉到身边并眩晕一秒（BV1xSeRzTE8H @ 00:24）。
2. **读条结束还有 0.3 秒延迟判定**：进度条消失后「拉到人的瞬间继续往前走，就能突破极限」再拉到另一个位置（BV1xSeRzTE8H @ 00:39）（BV1xSeRzTE8H @ 00:31）。
3. **强制锁定**：二技能结束会强制锁定敌方英雄，目标闪走甚至瞬移「也还是会被强制拉回」（BV1xSeRzTE8H @ 00:48）。
4. **一技能是隐身 + 减双抗**：进入 4 秒隐身、期间加 40% 爆发移速；4 秒内碰到对手（包括被二技能拉回的）造成伤害和减双抗，而且「不会打断隐身状态」（BV1xSeRzTE8H @ 01:40）（BV1xSeRzTE8H @ 01:43）（BV1xSeRzTE8H @ 01:47）。
5. **隐身有 0.5 秒延迟**：「一定要确保完全隐身了，再从草里出去」（BV1xSeRzTE8H @ 02:08）（BV1xSeRzTE8H @ 02:12）。
6. **大招带队友一起隐身**，友军加 30% 移速，只要在屏幕范围内都会被覆盖（BV1xSeRzTE8H @ 02:50）（BV1xSeRzTE8H @ 02:54）（BV1xSeRzTE8H @ 03:01）。
7. **一二技能不分先后，大招不行**：一二技能怎么放都不破隐，但「大招隐身后如果再接二技能就会立刻破隐」（BV1xSeRzTE8H @ 03:05）（BV1xSeRzTE8H @ 03:12）。
8. **移速可以叠，但顺序有讲究**：一技能和大招的加速能叠加，先大后一会把一技能的加速「直接吞掉」（BV1xSeRzTE8H @ 03:17）（BV1xSeRzTE8H @ 03:29）。
9. **大招兼职探视野**：释放后获得距离最近敌方英雄的视野，等于「鬼谷子跟这个敌人之间所有的草丛都没有人」（BV1xSeRzTE8H @ 03:44）（BV1xSeRzTE8H @ 03:48）。
10. **被动强普与刷新时间挂钩**：脱离敌方视野几秒后获得强化普攻，命中造成范围伤害和减速；在敌人面前用掉只需脱离 3 秒就刷新，在墙后（对面看不到）用掉要 10 秒（BV1xSeRzTE8H @ 04:05）（BV1xSeRzTE8H @ 04:18）（BV1xSeRzTE8H @ 04:22）。
11. **二技能碰人即破隐**：圈一碰到敌人就破隐，还会让对面看到头上的读条（BV1xSeRzTE8H @ 02:29）（BV1xSeRzTE8H @ 02:32）。

## 2. 对线 / 打法

鬼谷子不承担对线，本节按前期游走处理。

- **开局先判断对面会不会偷野**：判断会偷，就先给蓝区防守视野、再后清线；判断不会偷，就直接去边路抓（BV1NfeizEEiV @ 00:21）（BV1NfeizEEiV @ 00:28）。
- **抓不死也要打出东西**：配合元歌打不死有闪的狂铁，「不过能打个伞（闪），为打野出野区的第一波节奏配合也是可以的」（BV1NfeizEEiV @ 00:33）。
- **前期弱的阵容要放掉支援**，等节奏点再发力（BV1NfeizEEiV @ 00:55）。
- **跟打野的方向走**：打野去发育路抓，就跟去发育路（BV1NfeizEEiV @ 01:07）。
- **视野一旦暴露，第一件事是重新藏起来**，可以顺手帮打野刷野提速（BV1NfeizEEiV @ 01:12）（BV1NfeizEEiV @ 01:14）。
- **更好的选择是提前占位**：帮打野拿完蓝立刻去上路、站好即将开打的位置，「并没有继续帮打野刷野提速，这点很关键」（BV1NfeizEEiV @ 01:22）（BV1NfeizEEiV @ 01:26）。
- **拉之前一定切回视角看战局**，先确认对面的基本信息和位置（BV1NfeizEEiV @ 01:57）。
- **进场顺序先一后二**（BV1NfeizEEiV @ 02:02）。
- **距离不够就延迟闪拉**，别硬按（BV1NfeizEEiV @ 02:04）。
- **过线要提前开二技能**，让二技能结束的瞬间刚好拉掉漏兵（BV1NfeizEEiV @ 02:13）。
- **清完线给假视野**：先往上路走、再扭头（BV1NfeizEEiV @ 02:18）。
- **开局 28 秒开二除草**，能把蓝 Buff 隔墙拉出来，直接拖垮对面打野节奏（BV1xSeRzTE8H @ 01:34）。
- **只能靠卡视野拉，不能靠移速拉**：「他不能再凭借着移速去拉别人了，他只能凭借着卡视野打视野差去拉别人」（BV1K1PMzbEei @ 00:43）（BV1K1PMzbEei @ 00:46）。
- **单排很弱**：素材直说「鬼谷子如果单排的话，这个英雄是很弱的」（BV1K1PMzbEei @ 00:49）。

## 4. 中后期 / 节奏

- **大招用来读半图**：开大照出最近的人，就能判断某半图有没有人，护射手清线时特别有用（BV1NfeizEEiV @ 09:40）（BV1NfeizEEiV @ 09:45）。
- **10 分钟节点盯龙**：对面全往主宰靠时要阻止换龙；打龙射手和打野足够，辅助带人去照视野（BV1NfeizEEiV @ 10:26）（BV1NfeizEEiV @ 10:29）。
- **拿龙必须转推进**：拿了暴君要打架、入侵野区、推塔；「兵线没处理好，等于白白浪费了暴君」（BV1NfeizEEiV @ 11:18）（BV1NfeizEEiV @ 11:50）。
- **正确阵型是 131**：元歌带下、打野带上、中单带中、辅助占视野（BV1NfeizEEiV @ 11:39）（BV1NfeizEEiV @ 11:43）。
- **没闪就别硬接龙团**：鬼谷子没闪现「战斗力是有点弱的」，上路兵线有压力时更容易被一波（BV1NfeizEEiV @ 13:43）（BV1NfeizEEiV @ 13:50）。
- **高风险低回报的团不接**：素材对一波打赢的团仍评价「不是很建议大家去做这样的高风险低回报的事情」（BV1NfeizEEiV @ 14:27）。
