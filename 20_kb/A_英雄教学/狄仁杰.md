# 狄仁杰：单排最不需要队友的射手

> 只讲英雄本身。分路思路见 `L_分路/03_发育路.md`。
> 素材：小石头《S45 狄仁杰黑科技出装》（BV1WzbR6KEfX，巅峰 1800 局，讲的是"暴击吸血/抗伤流"这一派）、巅峰赛show《国服狄仁杰故氏》（BV1ogn56sE13）。
> **注意**：这条视频一半篇幅在讲匹配机制与队友，提取时只保留与英雄/出装相关的结论；可信度标 seed。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 全期（前期不吃队友、后期伤害爆炸，没有明显断崖） |
| **节奏职责** | **守节奏 / 独立发育**——单排时最不需要辅助跟的射手 |
| **一句话** | **会平A就行，大招全空也能打** |
| **依据** | BV1WzbR6KEfX @ 03:41（原话"你会平A就行了，就算你大招全空"）；@ 02:04（自带生存和自保能力） |

## 1. 机制内核：免控 + 吸血 = 能一直站着 A

狄仁杰的强度不是爆发，是**"打不死"**：

1. **二技能免控/净化解控**（@ 10:04、@ 17:00 两次靠它活下来）→ 有这个才敢站在原地输出
2. **边 A 边回血**：普攻 + 吸血直接构成续航（@ 07:30，56% 物理吸血配置）
3. **大招命中后伤害极其爆炸**（@ 02:31）→ 大招是"增伤开关"，不是主要输出
4. **一二技能可以免掉哪吒两层火焰**（@ 12:31）→ 这是具体到对位的用法

## 2. 出装（这条视频的核心，属"暴击吸血"流派）

| 位置 | 装备 | 理由 |
|---|---|---|
| 鞋 | **隐忍之足** | 提供抗性（@ 07:57） |
| 1 | **吸血刀** | 续航第一优先（@ 10:40） |
| 2 | **末世** | 打肉 + 吸血叠加（@ 08:11） |
| 3 | **破晓**（第二件大件） | **破晓这版多了 5% 暴击率，所以能第二件出**；哪天这 5% 被拿走就不能这么出了（@ 13:48、@ 14:07） |
| 4 | **逐日之弓** | 射程 = 输出环境（@ 17:00） |
| 5 | **不祥征兆** | 抗性，配合免控才敢站桩（@ 07:57） |
| 末 | 卖掉鞋子换 **制裁之刃** | 单挑时既回自己血、又让对面回不了血（@ 08:24、@ 21:47） |

**铭文**：10 夺萃 / 10 鹰眼 / 10 祸源（不带狩猎、不带红月，所以靠末世+破晓补攻速，@ 07:42、@ 15:01）

## 3. 对线与节奏

- **前期只发育**：不要想着单杀，能吃就吃，不能吃别贪（@ 11:33）
- **辅助不来是常态，不要无能狂怒**（@ 09:49）——这条对单排射手尤其重要
- **后期不要坐前排**：虽然你出肉，但要"当后排玩"，等对面切上来切到肉上再回血（@ 19:37）
- **一技能可以校正普攻方向**（@ 14:24）
- **点自己的技能 CD 给队友看**（@ 25:00 是辅助给的信息，反过来也成立：狄仁杰的技能 CD 是队友的决策输入）

## 4. 弱点

1. **没有位移**：所有生存都来自免控 + 吸血 + 抗性，被集火秒掉就没了
2. **大招空 = 少一大截伤害**（虽然"平A也能打"）
3. **这套出装是 B 站 UP 的"科研流"**，不是天梯唯一解；同分段还有法球流，没有对照素材
