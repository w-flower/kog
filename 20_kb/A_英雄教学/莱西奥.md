# 莱西奥：前期苟住别对拼，成型后跳起来抬大收割

## 1. 机制内核

1. **主要伤害是普攻**：无尽出来以后才有质变，性质和戈雅接近，但基础数值比戈雅高（BV14v4y1i7mW @ 08:32）。
2. **站着不动才吃满攻速**："你只要走的话，那个攻速就没了，就会 A 的很慢很慢"（BV14v4y1i7mW @ 05:46）；站着不动加的攻速蛮多（BV14v4y1i7mW @ 08:06）；打团最好当桩打（BV14v4y1i7mW @ 08:13）。
3. **二技能是位移 + 隐身**：二技能跳起来（BV1Pm4y1r7FD @ 09:18）；二技能有隐身，飞过去别人反应不过来（BV1cM411F7ct @ 02:13）；代价是 CD 挺长（BV1cM411F7ct @ 03:38）（BV14v4y1i7mW @ 04:44）。
4. **大招是收割，不是先手**：大招有斩杀伤害，先手伤害"相当相当的低"，收残血作用显著（BV14v4y1i7mW @ 08:44~08:52）。
5. **大招段免控**：二技能跳起后那一段大招"还是免控的，可以用来躲各种技能"（BV1Pm4y1r7FD @ 09:25）。
6. **极怕控制**：被控一下"直接寄"，二技能和三技能会被拽到地上，相当于白板（BV1cM411F7ct @ 08:32）；大招被打断就直接没伤害且直接落地（BV1cM411F7ct @ 03:12）。
7. **一技能不能存**：一技能不是孙尚香的一技能，没办法提前存（BV1Pm4y1r7FD @ 00:48）。
8. **平 A 可探草**：可以空 A 探草（BV1cM411F7ct @ 11:14）。
9. **连招吃攻速**：这套连招"是跟攻速有关系的"；攻速上来（快有破晓）后 A 得更快，落地能再 A 3 下、共打出七八发（BV1Pm4y1r7FD @ 13:45~13:52）。

## 2. 对线 / 打法

- **对线总纲**：三发炮弹去换血，打完赶紧走，等下一轮技能；换血成功、对面状态很差就往前压；换血失败、尤其遇到强势英雄就"老老实实留着一二技能在塔下发育"（BV1Pm4y1r7FD @ 00:21~00:37）。前期"真的很弱"，不用打那么激进（BV1Pm4y1r7FD @ 01:35）。
- **不要先点一技能**：射手见面不一定直接打起来，一技能又存不住，先点掉就没输出手段（BV1Pm4y1r7FD @ 00:51）。
- **不要一技能怼两个后排兵抢二**：打完三发一技能也很难抢二；就算抢到，学个二技能对贴脸作战没帮助（BV1Pm4y1r7FD @ 01:01）。
- **上线别 A 后排两个兵**，否则容易被卡线，A 前排兵或人就行（BV1KCWHe4Ez7 @ 00:40）。
- **被强势射手硬点时**：孙尚香、狄仁杰、黄忠、鲁班 7 号这类会直接点你状态，掉 2/3 到 3/4 血后塔下也危险（BV1Pm4y1r7FD @ 01:20）。
- **打不过就站着补刀**：两级打不过时"站着不动就好了，顺着这个一技能的伤害去补一下这个刀"（BV1Pm4y1r7FD @ 02:09）；保持满状态才是不被越塔最好的保障（BV1Pm4y1r7FD @ 02:26）。
- **4 分钟前别转线**：莱西奥是"半呆半游"，4 分钟前最好待在塔下补尾刀（BV1KCWHe4Ez7 @ 02:08）；补兵多 30% 经济，有必要就补好每个兵（BV1KCWHe4Ez7 @ 01:21）。

## 4. 中后期 / 节奏

- **转线两个必要条件**：第一，先拿到绝对线权；第二，中射辅清线要快（BV1Pm4y1r7FD @ 06:23）。清太慢的话防御塔会吃掉你发育路的钱，对面还有时间布局卡你的位置，转线就变成"为了吸血而吸血"（BV1Pm4y1r7FD @ 06:41）。
- **一塔该放就放**：7 分钟一塔白给都无所谓，因为一塔只是守野区的半边视野；掉了以后兵线会汇聚到二塔靠前，反而方便转两条线，而且从蓝区经过不绕远路（BV1Pm4y1r7FD @ 08:22）。射手到一定时间段"都是会放一塔，然后来刷双线促进发育"（BV1Pm4y1r7FD @ 08:58）；没有一塔，被越的风险也会降低（BV1Pm4y1r7FD @ 09:07）。
- **最好带小明转线压塔**：一直转线、一直压塔，下路吃完就去中路；小明让中期快速发育接管比赛，从而避开弱势期（BV1cM411F7ct @ 01:25）。
- **对面辅助/团队辅助**：小明最好，鲁班大师、张飞这种保护型辅助也可以（BV1cM411F7ct @ 04:38）；这英雄对辅助依赖挺大（BV1cM411F7ct @ 04:14）。
- **推塔节奏**：有辅助帮，2~3 分钟就能拿下一塔；推塔非常快，有机会就推塔（BV1cM411F7ct @ 02:24）（BV1cM411F7ct @ 05:01）。
- **顺风怎么打**：顺风起来很猛，可以无脑先手，二技能隐身飞过去对面反应不过来（BV1cM411F7ct @ 02:06）。
- **逆风怎么打**：除了吃钱就是等对面犯病；"你这个莱西奥就是厉害的，你不能先犯病"（BV1KCWHe4Ez7 @ 13:18）。
- **站位纪律**：站位尽量别靠前，手里捏着二技能，不要太想 A 人；除非对面交控制技能，否则不要轻易 A，被减速很容易死（BV1KCWHe4Ez7 @ 11:02）。
- **后期团战**：牢记"先看自身再决定这波团参不参"（BV1KCWHe4Ez7 @ 12:37）；手里两个复活甲才敢顶（BV1KCWHe4Ez7 @ 12:50）。
- **10 分钟节点**：经济都在射手身上，阵亡一次局势就可能改变，因为一死输出就不够（BV1KZ421W7pT @ 08:13）。
- **资源顺序**：上路一塔还在时，主宰先不要打，先拔一塔，再利用主宰跟对面打团（BV1KZ421W7pT @ 09:31）。

## 5. 出装铭文

- **两套铭文/出装并行**：一套用碎星锤、一套用破晓；用碎星锤必须带无双三个；用破晓不一定要出攻速鞋（BV14v4y1i7mW @ 03:57）。
- **鞋子不是硬性要求**：控制多就抵抗鞋，对线特别难、对面普攻多可以布甲鞋（BV14v4y1i7mW @ 04:12）；但主流口径仍是这版本出攻速鞋好抢线（BV1KCWHe4Ez7 @ 00:22）。
- **核心三件套**：无尽、影刃、破晓，出来伤害才比较高（BV1cM411F7ct @ 06:10）；吸血收益很高，做出饮血后团战"别人摸不死你，你可以瞬间就吸回来"（BV1cM411F7ct @ 07:47）。
- **铭文**：五夺萃五狩猎，绿色鹰眼，红色祸源（BV1cM411F7ct @ 00:22）。
- **前期过渡件**：清完线赶紧把速击之枪做出来，没有它伤害偏低（BV14v4y1i7mW @ 06:04）；小血刀出完再补一件 730 的过渡件（素材原话"730 的卫星"，名称待核）（BV14v4y1i7mW @ 07:12）。
- **破空流的一身肉**：布甲鞋 + 吸血刀 + 破空，1300 多血再加物理防御，马超一套标准小连招秒不掉（BV1KCWHe4Ez7 @ 12:13）。
- **破晓换装时机**：钱不够且打不了多少分钟时先留破风，硬拖到 17~18 分钟再换破晓也不迟（BV1KCWHe4Ez7 @ 11:26）。
- **完整出装顺序未覆盖**：BV1KCWHe4Ez7 明说本期录的是全局、没讲出装铭文和详细顺序（BV1KCWHe4Ez7 @ 07:16）。
