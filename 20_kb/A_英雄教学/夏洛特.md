# 夏洛特：靠"叠被动"把伤害叠出来

> 只讲英雄本身。对位见 `B_克制关系/`；局势见 `D_对局内/`。

## 1. 机制内核：三层印记 → 一次强化普攻

- 每次**技能命中**（英雄、小兵、野怪都算）叠 1 层印记
- 叠满 **3 层**获得一次强化普攻：**7 段范围伤害**，过程中自带 **35% 免伤**
- 强化普攻**用闪现不会打断**，穿插别的技能会打断

所以夏洛特不是"技能连招型"英雄，是**资源型**：她的强度取决于你能不能在打架前把印记叠到 3 层、以及强化普攻打不打空。

- 来源：BV1DL411h7Ui @ 00:25（三层印记 + 7 段 + 35% 免伤）
- 来源：BV1DL411h7Ui @ 01:24（闪现不打断强化普攻）

## 2. 叠印记的标准顺序（顺序错了就没伤害）

```
一技能（1层）→ 等一技能冷却剩 4 秒内 → 二技能（2层）→ 一技能（3层）
→ 普攻打出第一次强化 → 一技能（续层）→ 普攻打出第二次强化
```

**关键点**：一二技能可以空放但不空转——二技能永远留着两段位移；如果强化技能打空了，反而能清空读条重来（"卡被动"）。

- 来源：BV1684y1g7jA @ 01:20、@ 01:37（顺序与两次强化）
- 来源：BV1DL411h7Ui @ 04:20（卡被动续层）、@ 05:14（二技能两段位移）、@ 06:10（故意空掉强化技能清读条）

## 5. 分条说明

### K-A41 一技能起手，不要大招/二技能起手

- **触发条件**：每次进入连招
- **判断依据**：二技能是否还留着"绿色"（可用）
- **决策分支**：一技能起手 → 二技能 → 一技能……让二技能的位移始终握在手里
- **反例**：「先手大招开团」——大招交了，你的位移和霸体都没了，只剩站桩。
- **来源**：BV156QfBQEDd @ 01:58
- **可信度**：中高
- **状态**：active

### K-A42 打不到人时，斜着放

- **触发条件**：一技能/强化普攻直线打空
- **判断依据**：目标是否在你的正前方移动
- **决策分支**：调整方向斜着放，靠范围边缘命中
- **来源**：BV1DL411h7Ui @ 00:50
- **可信度**：中高
- **状态**：active

### K-A43 用"闪烁"穿过对面的技能（李白二技能这类）

- **触发条件**：对面交出判定型范围技能（如李白二技能）
- **判断依据**：你是否有强化普攻/闪现可用
- **决策分支**：锁头像 → 强化普攻前冲穿过技能 → 不吃伤害也不吃负面
- **反例**：「绕着走」——绕路就丢了输出窗口。
- **来源**：BV1DL411h7Ui @ 02:23、@ 02:43
- **可信度**：中（单一来源演示）
- **状态**：active

### K-A44 打架前先找兵线/野怪叠印记

- **触发条件**：准备接团或对拼前
- **判断依据**：附近有没有小兵/野怪可打
- **决策分支**：先叠到 3 层再进场；支援不了就闷头发育（经济领先对面边路）
- **来源**：BV1kqv8BGEuG @ 01:34；BV156QfBQEDd @ 01:14、@ 01:28
- **可信度**：中高
- **状态**：active

### K-A45 一技能、二技能的实际距离都比指示器远

- **触发条件**：估算能否开到人
- **判断依据**：一技能约远两个身位，二技能约远一倍
- **决策分支**：按实际距离判断，别被指示器骗；大招带霸体 + 减速，可用来硬吃控制进场
- **来源**：BV1684y1g7jA @ 03:06
- **可信度**：中（口述估算）
- **状态**：active
