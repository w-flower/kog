# 铠：一个"出装决定形态"的野核

> 只讲英雄本身。分路思路见 `L_分路/05_打野.md`；对位见 `B_克制关系/`。
> 素材：阿泽 × 国一铠浩宇（BV1VTdGBaEXg，2200 分逆风翻盘全局）、澜朋友零基础（BV1rZLv65EhP）。
> **版本提醒**：铠现在**尽量打野，不要打边路**（BV1rZLv65EhP @ 02:12）。下面所有内容都以打野位为前提。

## 1. 机制内核：大招给的不是伤害，是"每段减伤"

三段机制要分开看：

| 机制 | 内容 | 带来什么 |
|---|---|---|
| **大招** | 巨额物理攻击加成 + **每一段攻击格挡固定伤害** | 不是"变肉"，是"**多段伤害打不进来**" |
| **二技能** | 位移 + 强化普攻，**强普持续 5 秒** | 可以**提前存**，所以铠能"手里常备一发" |
| **一技能** | 命中给自己加速/攻速，命中敌人给减速 | 留人靠这个，不靠平 A |

**由此推出铠真正的强度来源：**

- 因为大招是**每段**格挡 → 铠极度克制**高频多段伤害**：澜、后羿的强化平A、嬴政大招（BV1rZLv65EhP @ 03:24）
- 因为大招给巨额攻击力 → **全肉只有一把红刀也能切后排**（全肉 + 红刀血量约 1.2–1.3 万，同时还能给自己减速/加速/百分比回血/加攻速/群体控制，BV1rZLv65EhP @ 04:40）
- 因为强普能存 5 秒 → 铠的爆发是"两段强普叠在一起"，不是一段

## 2. 三个必须练成肌肉记忆的细节

### 2.1 双强普：有二技能就放，手里永远留一发

强普持续 5 秒，有蓝 Buff 时二技能 CD 很短。所以正确做法是**二技能有了就按**，让自己手里始终挂着一次强普；靠近目标后 **2A** 连打两次强普（BV1VTdGBaEXg @ 02:20）。

清野时也一样，双强普能让清野更快。**这不是花活，是铠唯一的"爆发窗口"构造方式。**

### 2.2 一技能可以扔野怪和小兵

一技能不好标人时，**扔旁边的野怪或小兵**，一样能吃到移速和攻速（BV1VTdGBaEXg @ 02:32）。

进阶：像蔡文姬弹弹弹一样，**通过小兵把减速传到人身上**——同一句话里 UP 给的两个用法，第二个需要小兵和人在一条线上。

### 2.3 两个操作设置（直接影响上限）

- **普攻近距离优先选"主要"**：用来送方向盘穿墙（BV1VTdGBaEXg @ 00:45）
- **技能中断方式改成"拖动"**：这样团战里乱点也不会把大招提前取消（BV1VTdGBaEXg @ 00:45）

## 3. 出装与铭文

**顺序（阿泽/浩宇版）**：

```
野刀 → 二级野刀 → CD 鞋 → 暗影战斧 → 荆棘护手 → 反甲 → 宗师之力 → 破魔刀/魔女
```

逐件的理由（BV1VTdGBaEXg @ 00:57–01:52）：

| 件 | 理由 |
|---|---|
| 二级野刀 → **CD 鞋** | 冷却鞋 + 蓝 Buff 直接凑满 35% CD，大招好得特别快，前期打架能力更强 |
| **暗影战斧** | 核心装备。对面有猴子/机小满这种高爆发物伤 → **换护甲鞋**；法伤高或控制多 → **换抵抗鞋**；前期大逆风可先换鞋抗压 |
| **荆棘护手**（前期先出） | 加护甲，做完再升大打野刀发育 |
| **反甲** | 护手合成 |
| **宗师之力** | 提爆发 |
| **破魔刀 / 魔女斗篷** | 想伤害高选破魔刀；对面有炸弹猫这种消耗强的做法系，出魔女 |
| **名刀**（预购） | 大后期卖鞋换名刀 → 再换复活 |

**铭文**：蓝色 10 狩猎 / 绿色 10 鹰眼 / 红色 10 祸源（移速暴击铭文，BV1VTdGBaEXg @ 02:07）。

> **核心心法**：铠是"**每出一件新装备就是一个新的强度**"的英雄（BV1rZLv65EhP @ 01:44）。所以它不怕阵容——不适合做输出就直接做半肉，对面秒伤高就只留一把红刀。这也是为什么铠"几乎可以不看任何阵容直接拿"。

## 4. 全局思路：一条时间轴

这条轴来自 2200 分逆风翻盘局（BV1VTdGBaEXg @ 02:46 起），**注意它是逆风局**，所以节奏偏保守。

### 4.0 开局先分析阵容，再决定帮哪路

常规是"前期帮对抗路"，但这一把**中路边路强度都不如对面**，于是改成**帮发育路**（@ 02:46）。

**判据**：不是"打野该帮哪路"，是"**哪路打得过**"。打不过的路去了只是送。

### 4.1 0:00–0:30 占位与存刀

1. 开局**鞋子换野刀**，增加出门速度（@ 02:59）
2. **先占红背草**，防对面野辅入侵
3. **26 秒存第一刀强普** → 30 秒红 Buff 刷新，直接穿墙 A 过来开红

开野路线：**红 Buff + 小猪 + 猴子 → 蓝区双狼 + 蓝 Buff + 蜥蜴**（红开刷六野，@ 03:13）。

### 4.2 刷完第一轮：能抓就抓，抓不到就蹭线

帮发育路尝试抓人，抓不到就**蹭一波兵线**，然后回中路帮抢线（@ 03:25）。

**这条是打野的通用心法**：支援的收益不是"必须拿到人头"，是"**追到有人头，追不到有兵线**"，不管结果如何都有钱拿（@ 04:01）。

### 4.3 4 分钟前：一波野区一波线

以快速发育为绝对优先。**一波野区 + 一波线，经济高于连着刷两片野区**，而且耗时更短（@ 04:13、@ 07:21）。

### 4.4 抢线权的连锁：这是本卡最值得学的一段

@ 05:04 的完整链条：

```
盯小地图 → 中路视野没漏就绝不出去
→ 敌方中路在下路露头的瞬间，果断出来抢线
→ 中路二打一拿到线权 → 自家中单解放，提前动起来
→ 敌方打野只能后手清线
→ 抓住这个窗口入侵他的红区
→ 对面中路就算传送过来，也不可能比自家中路来得快
```

**这条链的核心**：抢线权不是为了兵线，是为了**制造一个 5 秒的窗口，让你的入侵合法**。单看"抢中线"没有意义，看"抢完能做什么"才有。

### 4.5 4–7 分钟：加速发育 + 推进反野

- 有优势就**先压边塔**——边塔掉了才有更多入侵机会（@ 06:06）
- 优势时**带队友吃对面野区**，滚雪球（@ 07:09）
- **不超过半图的团战都要跟**，且是**后手入场**（对面技能交得差不多了，@ 06:57）

### 4.6 让红的判断（很多人做错）

铠**不太吃红 Buff**：留人主要靠一技能减速，很少有机会直接 A 到人，所以中后期有没有红区别不大（@ 06:19）。

**让红的时间点取决于射手水平**：
- 射手会玩 → **5–6 分钟后就可以让**
- 射手一般 → **9–10 分钟再让**

### 4.7 7–10 分钟：为强化龙团做准备

- 主要任务是**抓掉点 + 加快推进**（@ 07:57）
- 没机会就**去边路带线**——铠单挑基本无敌，而且"一组兵线一片野"比刷两片野经济更高、耗时更少（@ 08:10）

### 4.8 10 分钟龙团：必须藏视野绕后

**这是铠最容易送的一波。** 铠不算灵活，打正面很容易被对面中射消耗掉状态，之后想参团就进不去了（@ 09:11）。

标准流程（@ 09:35）：

```
先藏好视野 → 等辅助/边路把团开起来 → 立刻绕后切 C
→ 打掉点形成人数差 → 再稳稳拿龙
```

### 4.9 顺风逆风的资源选择

**顺风优先拿暴君，逆风优先拿主宰**（@ 08:58）。

## 5. 铠弱在哪（要提前知道）

| 弱点 | 表现 | 应对 |
|---|---|---|
| **逆风纠结** | 出肉扛不住，出输出又切不到人（BV1rZLv65EhP @ 02:53） | 多憋两件装备，别在只有一件成品时就强开 |
| **怕灵活后排** | 对面"牛魔 + 马可"、"孙尚香 + 张飞"这类组合，切后排极难（@ 03:08） | 改打"保护 + 拆火"：和自家中路一起蹲对面打野切 C 的时机（BV1VTdGBaEXg @ 08:45） |
| **装备太多挑花眼** | 同一个局面有三四种能出的装 | 先定"这局我是切 C 还是吃伤害"，再选装 |

## 6. 一句话

**铠的强度不在操作，在"你什么时候存下那两发强普"和"你绕后之前有没有藏住视野"。**
