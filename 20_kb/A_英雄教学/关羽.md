# 关羽：马腿不断才有输出，先带线再游走

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：两份来源——阿泽 × 醉马（最高 2600 分、近 4000 场 70% 胜率）的结构化教学 + 一局 19 星实战（BV1UjAcz3Ehz）；老尚保姆级三合一教学（BV1Dv4y1P74u，基础 / 出装 / 实战）。
> ⚠️ 只有两份素材，条数偏少；且两套出装与铭文互相不同（疾跑鞋+黄盾+冰甲 vs 抵抗靴+荆棘护手+霸者；十异变 vs 九异变一祸源），本卡并列保留、不做取舍；两者都未给后期强度结论，**覆盖不全**。

## 1. 机制内核

1. **被动靠移动攒，松手就断**：能量条"会随着不断的移动进行增长"，但"一旦你方向键松开就会瞬间的断掉"；所以左手不能离开方向键，原地打转或来回跑都能维持（BV1Dv4y1P74u @ 00:25、BV1Dv4y1P74u @ 00:28）。
2. **冲锋状态四个动作全变**：普攻往前顶一下、一技能向前劈砍、二技能向前飞跃落地、大招出五个分身把敌人推开一段距离（BV1Dv4y1P74u @ 00:45、BV1Dv4y1P74u @ 00:51）。
3. **二技能落地给 50% 移速**：这是"踩一脚就跑"能做到无伤消耗的机制基础（BV1Dv4y1P74u @ 01:54）。
4. **大招期间靠普攻顶来刷被动，不要用一技能劈**：普攻顶 + 一技能旋转，"马上就可以再次顶对面"，被动使用次数多、控制更稳；反之"一技能劈砍一下，敌人就会被你推远了"，被动次数减少、控制变不稳（BV1Dv4y1P74u @ 02:16、BV1Dv4y1P74u @ 02:28）。
5. **断马腿 = 零作用**："关羽最怕的控制，被控制的话马腿就断了，你就没有任何的作用"（BV1Dv4y1P74u @ 07:43）。
6. **被动吃草回血，能量越高回得越少**：满被动只回 100；回血时"移动方向给他打断一下"，把能量降下来才能吃到高额回复（BV1UjAcz3Ehz @ 02:23、BV1UjAcz3Ehz @ 02:28）。
7. **马眼探草**：草里有人时马的眼睛会亮（BV1UjAcz3Ehz @ 02:33）。

## 2. 对线 / 打法

- **换血主动权在自己手里**：前期跑得快、机动性高，"换血主动权是掌握在我们手中"（BV1UjAcz3Ehz @ 03:05）。
- **对线大司命**：他一级进草，就用移速 + 一技能强势期消耗拉扯找单杀（BV1UjAcz3Ehz @ 02:43）；他直接抢线就只清线，注意"避免被他二技能拉到"；抢不过提前撤，"防止被他换血"（BV1UjAcz3Ehz @ 02:56、BV1UjAcz3Ehz @ 02:59）。
- **对线白起这类赖线强的**：一级先把兵线往后推，"这样清线会更加安全的"；不要一直守线，而是"把对线的无奈转变为游走支援"（BV1Dv4y1P74u @ 05:34、BV1Dv4y1P74u @ 06:56）。
- **打野节奏点**：队友蓝开必抓对抗路，"在一分25这个时间节点"去抢空间之灵（BV1UjAcz3Ehz @ 03:24）；对面打野没漏视野时，四级一定要小心（BV1UjAcz3Ehz @ 03:31）。
- **抢到资源先回撤**：此时"还没升四级"，要"等个兵线先升四级"（BV1UjAcz3Ehz @ 03:40）。
- **先记对面技能再动手**：这波记的是"大司命没闪、猴子没大招"，随后一二组合技抢四级、开大拆火把猴子推开、再找落单上单（BV1UjAcz3Ehz @ 03:45、BV1UjAcz3Ehz @ 03:51）。
- **假装进攻、实则撤退**：小地图看到打野来反蹲，就上去骚扰，"来勾引敌方边路上头反过来追你"，再配合打野反杀（BV1UjAcz3Ehz @ 04:06）。
- **帮守野区**：敌方中辅有进红区的意思就看情况去守；"对面人多就撤"，人少还敢反野就"利用关羽回推配合队友完成击杀"（BV1UjAcz3Ehz @ 03:15、BV1UjAcz3Ehz @ 03:18）。
- **输出优先级**：前期尽量"二技能踩踏加一技能挥砍"输出，"能不用一技能去打被动尽量不要"（BV1Dv4y1P74u @ 05:58、BV1Dv4y1P74u @ 06:02）。
- **针对真正的输出点**："对面的打野露露才是主要的输出"，任务是把他推开、"不让他去输出"（BV1Dv4y1P74u @ 06:23）。
- **被追时的逃生**："被追击时可以利用普攻的空A进行位移逃生"（BV1Dv4y1P74u @ 07:13）。

## 3. 连招

| 场景 | 连招 | 依据 |
|---|---|---|
| 常规消耗（作者推荐） | 冲锋二技能踩 → 一技能转一圈 → 直接撤走 | BV1Dv4y1P74u @ 01:48 |
| 两段伤害 | 冲锋普攻顶一下 → 一技能转一圈（实测 1167） | BV1Dv4y1P74u @ 01:35 |
| 单段爆发 | 冲锋一技能直接劈砍（实测 1287，更高但作者不推荐） | BV1Dv4y1P74u @ 01:41、BV1Dv4y1P74u @ 01:45 |
| 四级前线上消耗 | 冲锋二技能踩一脚 → 一技能刮一圈 → 直接撤离，反复磨血 | BV1Dv4y1P74u @ 03:07 |
| 四级后塔下杀 | 蹲草 → 敌人出现 → 大招往塔方向推 → 全程被动 + 普攻借塔收人 | BV1Dv4y1P74u @ 03:18 |
| 团战双控 | 大招 + 冰甲形成双重控制，再接反推 | BV1UjAcz3Ehz @ 01:27、BV1UjAcz3Ehz @ 07:23 |
| 绕后开团 | 开疾跑 + 大招 → 绕后 → 回推配合队友 | BV1UjAcz3Ehz @ 05:37 |

> **一技能往回劈**：马头"稍微超过敌人"，然后"方向键往后拉去劈砍"（BV1Dv4y1P74u @ 02:47）。用于清线把兵线往回推、让自己处于安全位置（BV1Dv4y1P74u @ 02:54），也用于追击时把人往回劈（BV1Dv4y1P74u @ 02:58）。
> 素材给的是两个作者各自的口径，"二技能踩 + 一技能转"与"普攻顶 + 一技能转"分别对应消耗与站桩两种需求。

## 4. 中后期 / 节奏

- **4 分钟前**：抢空间之灵、帮守野区、抓敌方技能真空期抢龙（BV1UjAcz3Ehz @ 04:40）。
- **4–10 分钟**：带线发育扩大经济优势，带完兵线"别闲着要游走起来"，主动支援、主动找机会（BV1UjAcz3Ehz @ 05:00、BV1UjAcz3Ehz @ 05:05）。
- **固定循环**："先带线再游走"；复活后第一件事还是先带线，带完再走（BV1UjAcz3Ehz @ 05:19、BV1UjAcz3Ehz @ 05:32）。
- **带线的真正收益是人数差**：牵制一个人回去守线，正面就形成以多打少，"像这波敌方大司命还在清线，而我们团战都已经打完了"（BV1UjAcz3Ehz @ 06:05）。
- **10 分钟节点**：暴君主宰强化，先"把边线处理好"，同时"提醒队友不要掉点"；实战里靠牵制三个人让队友拿下主宰（BV1UjAcz3Ehz @ 06:18、BV1UjAcz3Ehz @ 06:24）。
- **开龙时关羽不打龙**：要跑起来在周围干扰，重点是赶走有惩戒的敌方打野和敌方高爆发中路，"能不能杀掉无所谓，只要把他们赶跑"（BV1UjAcz3Ehz @ 06:56、BV1UjAcz3Ehz @ 07:07）。
- **大顺风开双龙，小优势开暴君**；开暴君时可去主宰那边消耗干扰（BV1UjAcz3Ehz @ 06:29、BV1UjAcz3Ehz @ 06:35）。
- **团战状态不好就边缘 ob**："拿到就赚，拿不到就算"（BV1UjAcz3Ehz @ 04:58）。
- **进场顺序**："一般我建议后手进场"，不要头铁（BV1Dv4y1P74u @ 07:40）。
- **切后排是本职**："基本上只要你发育正常，对面C位你都可以瞬间带走"（BV1Dv4y1P74u @ 07:51）。
- **10 分钟之后**：抓敌方掉点，再配合队友推进（BV1UjAcz3Ehz @ 07:12）。
