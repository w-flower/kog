# 貂蝉：二技能是唯一的保命牌，大招圈边才是她的输出位

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份同英雄 1V1 solo 专题（BV1P14y1W7yy）、一份国服连招+时间轴+设置拆解（BV1ERZvB1Ef5）、一份 1900 分实战复盘（BV13q4y1j7fn）、一份手法/设置/出装细讲（BV11KZxB4EAj）、一份团战跳法教学（BV1MB4y1i7Vz）。
> ⚠️ **素材口径偏科**：五条里有一条是纯 1V1 solo（同英雄单挑），本卡凡引用该条均标注"solo 语境"；5V5 的逐中单对位、团战切入目标选择覆盖很薄，已全部进「待补」，不要拿 solo 结论直接套排位。

## 1. 机制内核

1. **二技能是核心保命牌**：向指定方向跳，期间无法被选中，可躲掉王者里绝大多数技能和伤害（BV11KZxB4EAj @ 00:25）。
2. **二技能命中会减 3 秒 CD，放空则至少 5 秒空档**，即使满 40% 冷却也一样，这对貂蝉非常致命（BV11KZxB4EAj @ 03:59、BV11KZxB4EAj @ 04:06）。
3. **二技能的实际最远攻击距离约是指示器的两倍**，卡在这个范围内释放能百分百不断二（BV11KZxB4EAj @ 04:18）。
4. **二技能花球不选残血、随机攻击范围内目标**，改"绝对血量最少"也没用；但花球可以无视野自动追踪草里的敌人，也能追隐身（BV11KZxB4EAj @ 04:46、BV11KZxB4EAj @ 05:01、BV11KZxB4EAj @ 05:13）。
5. **一技能有明显的施法前摇且无法取消**，所以打团要遵循"让二原则"：宁可等二技能，也不要为了放一技能罚站（BV11KZxB4EAj @ 03:08、BV11KZxB4EAj @ 03:11）。
6. **大招内二技能 CD 是跳跃式减少**（0.8→0.5→0.3），看到 0.3 就可以直接放，不必等归零（BV11KZxB4EAj @ 02:06）。
7. **大招实际范围比技能特效更大**，站在圈边缘放二技能一样能吃到减 CD（BV11KZxB4EAj @ 02:34；BV1ERZvB1Ef5 @ 15:58）。
8. **二技能跳的三档难度**：前跳最简单但落点靠前、无法拉扯；侧跳最实用，指示器与水平方向约 30 度夹角更容易躲伤且防断二；后跳最难，要先迎着伤害回头再放（BV11KZxB4EAj @ 00:33、BV11KZxB4EAj @ 01:07、BV11KZxB4EAj @ 01:38）。
9. **大招起手和二技能起手是两回事**：大招起手接二技能没有后摇，二技能起手再开大有一段僵直；而且二技能起手那一下不享受大招内的冷却加成（BV1P14y1W7yy @ 08:22、BV1P14y1W7yy @ 08:53，solo 语境）。
10. **两个貂蝉的大招是交叉而不是重合**，这是拉扯能成立的物理前提（BV1P14y1W7yy @ 14:33，solo 语境）。
11. **solo 地图冷却比 5V5 快**：5V5 大招起手大约 13 跳，solo 地图连点器能到 24 连、手打 19~20 跳（BV1P14y1W7yy @ 10:30，solo 语境）。

## 2. 对线 / 打法

- **开局草鞋、预购冷静靴**，出完冷却鞋一定补小法典（BV13q4y1j7fn @ 01:07、BV13q4y1j7fn @ 02:56）。
- **第一波线只要不危及生命就必须拿下**（BV13q4y1j7fn @ 01:34）；清线时拉开距离用二技能清，别被消耗（BV13q4y1j7fn @ 01:26）。
- **4 分钟前不主动找人打架**：貂蝉前期弱，主动找架打是不对的（BV1ERZvB1Ef5 @ 05:25、BV1ERZvB1Ef5 @ 06:37）。
- **4 分钟前跟打野的节奏抓人**：自己去抓一套二一放完就该被揍了，跟着打野四打二才打得过（BV1ERZvB1Ef5 @ 04:50）。
- **帮打野刷野只帮不蹭**，打野升四之后再边帮边蹭（BV1ERZvB1Ef5 @ 05:59）。
- **清完线再考虑支援**，支援要看情况，不能盲目过去（BV13q4y1j7fn @ 02:17）；对面消失一定打"敌人消失"信号（BV13q4y1j7fn @ 03:19）。
- **升四级是前期最重要的事**（BV13q4y1j7fn @ 02:40）。
- **4 分钟后多去对抗路找节奏**："你把自己更偏向于一个对抗路来打"（BV1ERZvB1Ef5 @ 07:17）；因为中路手短，容易被长手法师消耗（BV1ERZvB1Ef5 @ 10:29）。
- **一级点一的争议**：solo 语境下"一级点二技能没有任何意义，点二技能绝对打不过一级点一技能的"，因为一技能能抢线、先到二级（BV1P14y1W7yy @ 63:11、BV1P14y1W7yy @ 63:24）。这条是 solo 结论，5V5 排位请勿直接照搬。
- **圣杯出来就是强势期**，要趁这个窗口发力（BV1ERZvB1Ef5 @ 09:35、BV1ERZvB1Ef5 @ 09:51）。

## 3. 连招

| 场景 | 连招 | 要点 | 依据 |
|---|---|---|---|
| 后期满 CD | **231 2 2 1 2 2 1 2 2 1** | 两个二接一个一，避免一技能后摇拖慢二技能 | BV1ERZvB1Ef5 @ 01:04 |
| 前期没 CD | **231 后 1 2 1 2 1 2（二一交替）** | 前期二技能冷却不够，只能一、二交替放 | BV1ERZvB1Ef5 @ 02:58 |
| 灵活变体 | **231 → 二二 → 看位置，危险就继续二** | 两个二之后不急着接一，位置不安全就再二 | BV1ERZvB1Ef5 @ 03:36 |
| 蹲草 | **二技能突脸接大 → 净化 → 二技能补伤害** | 突脸起手，净化保命，二技能收尾 | BV13q4y1j7fn @ 04:06 |
| 团战骗技能 | **边打边用二技能往后拉，把敌人勾进自己圈里** | 不要一个人猛冲，冲多了就出圈 | BV1ERZvB1Ef5 @ 10:12 |
| 近战对拼（solo） | **三角跳：只放二、不放一，围绕大招走正三角** | 放一有前摇，会被近战一刀刀砍在肉上 | BV1MB4y1i7Vz @ 00:31、BV1MB4y1i7Vz @ 00:38 |

- 团战进场前必须有明确目标，"不要等进去以后一顿瞎跳，哪个残血打哪个"（BV13q4y1j7fn @ 06:50）。
- 追人可以出大圈，打团不行：打团随便跳出大，死亡概率 80%（BV13q4y1j7fn @ 07:05、BV13q4y1j7fn @ 07:09）。
- 在大招里要贴着边缘跳，不要出大（BV13q4y1j7fn @ 07:31）。
- 后跳不断二的做法：先回头踩一下敌人脚下的红圈，再秒接二技能（BV11KZxB4EAj @ 04:29）；躲塔伤同理，等伤害进线内先回头再放二（BV11KZxB4EAj @ 01:38、BV1ERZvB1Ef5 @ 12:09）。
- 取消后摇：放二技能时持续拖动左手轮盘，不要松开（BV11KZxB4EAj @ 02:57；BV1ERZvB1Ef5 @ 16:25）。

## 4. 中后期 / 节奏

- **中后期带线发育 + 传送支援**：把自己当对抗路，打完线用传送去打架，"又当刘邦玩"（BV1ERZvB1Ef5 @ 08:32）。
- **带传送时中路线权不重要**：对面先清就让他先清，"你先走50步，我直接一秒钟走100步"（BV1ERZvB1Ef5 @ 09:19）。
- **后期就可以去打团**（BV1ERZvB1Ef5 @ 10:55）。
- **团战要会把敌人往圈里勾**：边打边二技能后拉，而不是一路往前冲（BV1ERZvB1Ef5 @ 10:12）。
- **左右跳而不是往脸上冲**：后方没人时不能前后跳（会空二），要左右跳；往前冲会导致跳的频率变低、反而粘不住人（BV1MB4y1i7Vz @ 01:18、BV1MB4y1i7Vz @ 01:26、BV1MB4y1i7Vz @ 01:40）。
- **前后跳是骗技能**：往前跳骗前面的技能，往后跳骗后面的技能（BV1MB4y1i7Vz @ 03:26）。
- **扎堆是貂蝉最好打的时候**：三个人站一起，一套下去直接毁天灭地（BV1MB4y1i7Vz @ 07:05）。
- **阵容适配**：适合打坦克阵容和没有位移的阵容；对面全是花里胡哨的位移英雄就会很难受（BV1MB4y1i7Vz @ 07:25、BV1MB4y1i7Vz @ 07:30）。
- **solo 语境的拉扯**：把对面拉到大招边缘，让他再跳就要出圈或断二；拉扯分控距与走路，跳完要走两步再跳，下一跳往哪跳就先往反方向走（BV1P14y1W7yy @ 16:06、BV1P14y1W7yy @ 16:55、BV1P14y1W7yy @ 18:26、BV1P14y1W7yy @ 18:46）。这套是 1V1 单挑逻辑，5V5 只能借"控距、别站桩"的思路。
- **solo 语境的微出圈**：表面出圈不怕，只要下一跳能回圈就不算真出圈（BV1P14y1W7yy @ 24:14）；solo 里还讲"偷血"——预判落点提前放二，死亡回放二技能占比 30% 多就是被偷血（BV1P14y1W7yy @ 40:36、BV1P14y1W7yy @ 41:31）。

## 5. 出装铭文

**出装（素材给了两条线，未给单一时序表）**

- 常规线：CD 鞋 + 圣杯快速拉满 40% 冷缩 → 吸血书后换抵抗鞋（冷缩仍是 40%）→ 破茧 + 时之预言拉容错 → 最后帽子提升爆发（BV11KZxB4EAj @ 06:34）。
- 实战线：草鞋 → 冷静靴 → 小法典 → 圣杯 → 吸血书 → 大书 → 帽子 → 冰心（BV13q4y1j7fn @ 01:07、BV13q4y1j7fn @ 05:03、BV13q4y1j7fn @ 14:05）。
- 若打野不要蓝（如梦奇打野），四级可直接拿蓝，圣杯可以不出、换吸血书（BV13q4y1j7fn @ 00:51）。
- 对面没出制裁/梦魇时，吸血书的收益很高（BV13q4y1j7fn @ 08:25）。

**铭文**

- 十梦魇、四贪婪、两狩猎、四长生、十怜悯；"虽然看起来很奇怪，但每一处都是极致细节"（BV11KZxB4EAj @ 06:25）。
