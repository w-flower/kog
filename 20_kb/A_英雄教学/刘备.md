# 刘备：用清野速度换经济差的野核

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 前期 |
| **节奏职责** | 开节奏 |
| **一句话** | 抓人必须顺路，经济差才是他的伤害 |
| **依据** | A 卡：喜欢抓人的打野上不了高分段 |

> 只讲英雄本身。分路思路见 `L_分路/05_打野.md`。
> 素材：奥特曼zz（国一刘备，三套出装 + 99% 胜率打法 + BP 全局解析）、打铠教学（BV1fj411U7tr）。

## 1. 机制内核：他要的不是人头，是"经济差"

刘备的操作难度不高，**难度全在"前期的打经济能力和意识"**（BV1mg4y1t7cn @ 03:10）。原因是他清野快、单体伤害高，但**位移差、留人差**——所以他没法像常规刺客那样靠抓人起节奏，只能靠**刷得比你快**，再用经济差去打必赢的团。

由此得出刘备的第一条铁律：

> **抓人必须建立在刷经济的路上，顺路抓。** 喜欢抓人的打野绝对上不了高分段（BV12N411t7x5 @ 00:42）。太执着于抓人，会导致你没有足够经济掌控这局，这也是上不了王者的原因（@ 01:34）。

## 3. 反野：先看辅助在哪，再决定反几组

BV12N411t7x5 @ 02:08 给了一条很具体的阈值：

- 对面**辅助（小明这类）没在下路漏视野** → 只反**两个小野**，别贪
- 辅助位置明确、对面打野在另一侧 → 可以整片反

**为什么用"辅助位置"当判据**：辅助是野区防守的第一双眼睛。他没漏 = 你不知道他在哪 = 你可能正踩在他的视野里。这条判据比"看对面打野在哪"更早、更保守。

## 4. 拆塔 > 刷野：中塔一掉，对面野区就是你的

这是刘备最反直觉、也最值钱的一条：

> "你永远不知道**一座中塔对（对面）打野的野区有多大影响**" —— 中塔一掉，对面野区就随便进（BV12N411t7x5 @ 03:41、@ 04:40）。

所以刘备的优先级不是"刷完野再推塔"，而是**看到能拆的塔就放下手头任何事去拆**（@ 03:41 原话："我可以放下手头任何的事情去拆塔"）。

**同一条逻辑的第二个推论**：11 分半以后**小野已经没用了**，别再浪费时间清，**把塔和兵线放在第一位**（@ 06:40）。

## 5. 刘备的弊端：留不住人 → 只能打兵线运营

**这是选刘备前必须知道的**（BV12N411t7x5 @ 05:58）：

> 刘备在这种情况下**很难留住人**，除非有队友帮你打个控制。

所以后期只有三条路可走：

1. **卡草 / 卡视野**，等对面自己走进来
2. **兵线运营**——带线创造拆塔机会
3. **等团已经打起来了，再打个出其不意**

到了 12 分钟，重点就变成"兵线运营 + 尽可能让对方掉点"（@ 06:40）。

## 6. 出装与铭文（三套，按打法选）

来源：BV1d94y1i7Ct（三套出装铭文，注意这是 S32 时期的视频，**装备名以游戏内为准，思路照用**）

| 套 | 顺序 | 适合谁 |
|---|---|---|
| **一（主流，容错高）** | 血刀野刀 → 鞋子 → **电刀** → 荆棘护手 → **冰脉**（不出黑切）→ 大打野刀 → 末世 → 最后一件看阵容 | 节奏好、会打经济、想 12 分钟内结束的人 |
| **二（跑图流）** | 小野刀 → 疾步之靴 → 升级打野刀 → 电刀 → 黑切（**先出陨星**）→ 末世 | 偏向运营、跑图快、要卡视野蹲人 |
| **三（黑切宗师流，老派）** | 小野刀 → 鞋子 → 升级打野刀 → 电刀 → 陨星 → 黑切 → 末世 → 爆裂之甲 → 大打野刀 | 不喜欢电刀、习惯老手感的人 |

**关键细节**：
- 不出黑切时**先做冰脉**，做冰脉前先补一个**荆棘护手**提高前期容错（前期掉点很伤）
- 大打野刀的目的是**物理穿透**，用来对付对面已经起来的坦度英雄
- 最后一件：两个以上法系 → 魔女/破魔刀；正常一个法系 → 爆裂之甲
- 换装节奏：**14 分钟内用爆裂换复活/名刀，14 分钟后用鞋子换**

**铭文**：**4–5 个夺萃**、5–6 个狩猎、10 个鹰眼、10 个异变（BV12N411t7x5 @ 06:19 也强调"三夺萃吸血真的吸不上来，建议 4–5 个"）。

## 7. 选他之前先看阵容（BP 视角）

BV1mg4y1t7cn 是一局 56 星的完整 BP 解析，其中三条判断可复用：

1. **对面是"中后期打团体系"（貂蝉 + 猪八戒这类高恢复高坦度 + 刘邦保 C）** → 你只能打**前 8 分钟**，靠压制对面双 C 的发育拖慢成型，再打经济落差的团（@ 02:55、@ 03:10）。
2. **指望"后期打团一波拿下"基本不现实**，除非对面双 C 不会玩——而你不能指望这个（@ 05:35）。
3. **有鬼谷子这类强开辅助时，一定要让他打先手**，你随后跟上接 `双一` 或 `121`；别自己抢先去开（@ 08:05）。

## 8. 一句话

**刘备不是"抓人型打野"，是"用清野速度把经济差堆出来，然后用这个差去打不需要操作的团"的英雄。**
