## 1. 她的价值不在治疗，在"多打少"

大乔的技能组本质是一套**调动能力**：二技能把人送回泉水再传回来，大招把队友拉到指定位置。所以她赢局的方式不是"奶住人"，而是**在局部制造人数差**——你 5 个人能同时出现在一个点上，对面只能到 3 个。

这也是为什么所有大乔教学里反复出现"传人""开大节奏""勾引"这些词：她的胜负手是**时机**，不是治疗量。

## 3. 分条说明

### K-A31 大乔的核心连招是"一三接大招"，不是单纯保人

- **触发条件**：要打一波有准备的团
- **判断依据**：队友是否跟得上（在附近、血量健康）
- **决策分支**：一技能 + 三技能打出控制与位移 → **立刻接大招**把人拉进战场 → 二技能留给自己或残血队友撤
- **反例**：「大乔就是奶妈，跟着 C 位跑」——她的收益来自调动，不是治疗。
- **来源**：BV14VuVzWEBE @ 04:56；BV1M81kYpEPE @ 08:14（"放一三连招，接大给队友加个盾传过来"）
- **可信度**：高（两个不同 UP 一致）
- **状态**：active

### K-A32 逆风局：断兵线拖发育，团战能接就接

- **触发条件**：己方逆风、对面在推塔
- **判断依据**：能否用二技能回家 + 传送反复截掉对面兵线
- **决策分支**：
  - 对面在推 → 断线、拖节奏、等队友复活
  - 队友开团了 → **能接就一定要接**（人数差团战是逆风翻盘的唯一机会）
- **反例**：「逆风就守塔」——守塔是等死，断线才是把时间买回来。
- **来源**：BV14VuVzWEBE @ 04:40；@ 04:51
- **可信度**：中高
- **状态**：active

### K-A33 大招前先"勾引"：让对面先上

- **触发条件**：己方人多、对面犹豫
- **判断依据**：对面有没有开团意图/强行进圈
- **决策分支**：先露一个身位把对面引进来 → 圈放好 → 大招把队友拉过来 → 反打
- **来源**：BV1M81kYpEPE @ 04:37（"这个就是大招的一个勾引节奏"）；@ 08:49（"勾引一下再进圈"）
- **可信度**：中
- **状态**：active

### （已移出）K-A34 开局：别跟射手，先帮中路抢线 + 做视野

这条是**游走位的通用开局排序**（「野→边→射→中」），不是大乔特有，已迁到 `L_分路/02_游走.md` 的 `K-L12`，判据原表在 `K-D08`。

### K-A35 圈要放在身后，靠"拉扯"活着

- **触发条件**：团战中持续输出阶段
- **判断依据**：自己的身位是否被对面突进够到
- **决策分支**：把圈放到队伍后方 → 边打边退 → 用二技能回血回蓝再进场
- **来源**：BV14VuVzWEBE @ 07:40
- **可信度**：中
- **状态**：active

## 4. 最容易崩的地方

1. **大招当传送门用**：开大是为了打团，不是为了"人到齐了"。没有后续动作的大招就是白送 CD。
2. **跟射手走**：等于把自己的地图影响力砍掉一半。
3. **不看对面绕后位**：对面强开团辅助大概率在绕后，大乔必须先把那个人探出来（原话："我们把他辅助探出来"）。

## 冲击巅峰千强补充（seed）

- **别「大圈套小圈」**：传过去满血又被传回家。
- **回血圈靠墙放防被推出去**：但**圈心不能落进墙体**，否则会被卡到别的位置。
- **一三技能打准了再摇大**：否则人早跑了。
- **血量回到约 4/3 时点大招基本满血归位**：这是回城的时机阈值。
