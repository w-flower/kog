# 蒙犽：红怒一开才是输出形态，没红怒的一技能连兵都穿不过

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：五条。两份系统教学（BV1YJ411G7pq 六十余局实战总结、BV1Wg411D7Ze 零基础大型教学）、一份巅峰千强国服晋级赛全局（BV1SZjS6eE79）、一份普攻运用专项（BV1PS42197Px）、一份 KPL 赛事解说（BV1FRJ26DEWA）。
> ⚠️ 赛事那条（BV1FRJ26DEWA）是解说视角，只提供了极少几条蒙犽本体信息（红怒额外伤害、平A 射程、伤害占比），本卡只从中取了这几条，不当作教学口径；关于"精准"是否对一技能生效，两份教学口径相反，已分别标注。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | **中期**。前中期靠红怒+一技能就能压线拿资源，但**大后期下滑**——"如果不出反甲的话，其实大后期的话，神装同样装备的情况下，大部分射手蒙犽是打不过的"（BV1YJ411G7pq @ 10:06-10:12）。赛事侧的数据也说明他是"打伤害"型而非"收割"型：伤害占比 37.1%、分均伤害 6366（BV1FRJ26DEWA @ 13:49-13:51）。 |
| **节奏职责** | **跟团打输出（follow）**。团战定位是"不要成为对面第一个目标，你要让对面打你的队友，再打对面"（BV1Wg411D7Ze @ 08:39-08:43），属于站在队友身后换血的角色。 |
| **一句话** | 红怒决定一切：没有红怒，一技能没有穿透、只能被对面白打；进入兴奋状态后一技能变 AOE 并快速回血，才是能压人的形态（BV1PS42197Px @ 01:00-01:26、BV1YJ411G7pq @ 03:53-04:08）。 |
| **依据** | "一技能在没有红怒之前是没有穿透的，并且我们的普攻射程要比阿离要长，所以开局一定不要盲目交易"（BV1PS42197Px @ 01:00-01:09）；"后期输出一定是靠普攻才是最稳定的"（BV1PS42197Px @ 04:39-04:41）。 |

## 1. 机制内核

1. **被动就是"红怒/兴奋"**：普攻加能量，**暴击加 10 点、不暴击加 5 点**，所以暴击率直接决定进兴奋状态的速度（BV1YJ411G7pq @ 03:05-03:13）。这也是铭文必带祸源的唯一理由（BV1YJ411G7pq @ 03:17-03:23）。
2. **兴奋状态的加成**：攻速提升、冷却缩减提升（每层 5% 攻速、1% CD）（BV1YJ411G7pq @ 02:29-02:36）；兴奋满了之后开始回血（BV1YJ411G7pq @ 03:28-03:31）。
3. **这个回血是"回血"不是"吸血"**：不受法球影响，出泣血之刃不会让回复变多——"这也是新手经常会犯的一个错误"（BV1YJ411G7pq @ 03:33-03:52）。
4. **改版后红怒多一段额外伤害**："改版后的蒙犽是在怒气满了之后会直接有一段额外的伤害"（BV1FRJ26DEWA @ 00:44-00:47）。
5. **但红怒会清零**："他红怒之后，他会把这个能量立马清零，那个伤害其实后面就有点低"（BV1FRJ26DEWA @ 13:01-13:04）。所以红怒不是常驻增益，而是周期性窗口。
6. **一技能是核心输出**：和普攻一样点能量但叠得更快；兴奋状态下变成 AOE 穿透，并带来非常快速的生命回复，"到后期的话基本都是靠他的"（BV1YJ411G7pq @ 03:53-04:08）。**没有红怒时一技能没有穿透**（BV1PS42197Px @ 01:00-01:03）。
7. **一技能不继承大部分法球**：像末世、冰矛、苍穹的精准这类攻击特效都吃不到，"你只要出的要想提高他的伤害，只能出物理装备，还有说出暴击装"（BV1YJ411G7pq @ 04:11-04:50）。
8. **存疑点：精准是否生效，两份素材相反**。BV1YJ411G7pq 说"苍穹的话，那个精准的伤害也没有用"（@04:39-04:44）；BV1Wg411D7Ze 则说"一技能是可以触发这个精准的，比如40精准的话，和40物理攻击力伤害是一样的"，并称破晓的被动"等于100攻击力"（@05:00-05:15）。本卡不替任何一方背书，实战以自己测得为准。
9. **一技能的代价**：释放时减少 50% 移速（BV1Wg411D7Ze @ 04:27-04:28），所以它是"站桩输出"而不是拉扯技能。
10. **二技能是消耗+减速**：一般放五个弹道，兴奋状态变九个（素材"九八打我"为口误）（BV1YJ411G7pq @ 04:58-05:08）；伤害不算高，"这个减速其实才是它比较核心的一个地方"（BV1YJ411G7pq @ 06:01-06:08）。还有弹射效果，可以打到本来打不到的人（BV1YJ411G7pq @ 06:24-06:38）。
11. **大招是伤害最高的技能，但要引导**：按得越久范围越大；范围内只要自己 A 到人（平A 或技能）或队友打到人，就会朝对面发导弹（BV1YJ411G7pq @ 07:25-07:46）。满怒气时"导弹就会变快一倍，就会发射更多的导弹"（BV1YJ411G7pq @ 08:01-08:08）。大招点按也可以（BV1Wg411D7Ze @ 05:27-05:39）。
12. **大招的位移属性**：开大带长时间加速，被突进时可以先用大招撤到安全位置再反打（BV1YJ411G7pq @ 08:21-08:35）。
13. **反甲黑科技**：开大状态下被反甲反伤，也会触发导弹——"敌人刺客我们都不用平A，你看他直接掉半血了"（BV1YJ411G7pq @ 09:35-10:00）。
14. **手短的短板**：平A 距离比技能长，"技能的话没有平A那么长，打不到"（BV1FRJ26DEWA @ 10:56-11:00）。对上猪八戒、张飞这类前排时，"摸不太到人"是他出场率低的原因（BV1FRJ26DEWA @ 10:50-10:56）。

## 2. 对线 / 打法

- **开局先用普攻，不要急着开一**："先运用精准普攻普攻输出，打对面状态"，等对面靠前、没有兵线挡住，再开一技能（BV1PS42197Px @ 01:09-01:15）。
- **误区要背下来**：没有红怒期间开一，"对面打的是你人，你打的是对面兵"（BV1PS42197Px @ 01:16-01:20）。
- **有红怒再用一技能清线兼回状态**，"就很容易拿到线上优势"（BV1PS42197Px @ 01:22-01:26）。
- **一级打不过就学二消耗**："由于我们一级拼不过孙权，所以我学二尝试打消耗"，打不满就直接后拉等清线（BV1SZjS6eE79 @ 00:38-00:47）。
- **一级看对面中辅位置**：对面往上靠就猥琐；1 分钟对面打野抢河蟹，看他身上 Buff 判断抓哪路（BV1Wg411D7Ze @ 06:11-06:35）。
- **清线和换血可以合并**："我们想清线，对面就会想打我们状态，那就可以借这个心理和兵线站一起打，我们的同时也会打兵线"，兵线残了对面自然卡不住（BV1SZjS6eE79 @ 01:53-02:02）。
- **兵线没进去就主动给压力**迫使对面清线，防止被卡线（BV1SZjS6eE79 @ 02:41-02:46）。
- **对面卡线就让他卡**："我们谨记对面中野不漏，就是在蹲我们的原则"（BV1SZjS6eE79 @ 04:30-04:35）。
- **红隼是前期连体的理由**：清完线转去打 30 秒刷新的红隼，"每个人都会获得25的外收益"（BV1PS42197Px @ 02:31-02:36）。
- **打鸟不影响打野升四**：当前版本野怪变多，不管打野红开还是蓝开，射手打一只鸟都不会影响他前期的升四节奏（BV1PS42197Px @ 02:52-02:58）。
- **2 分钟要打字提醒中野**："对抗路会刷新一个资源点，打字提醒中野下一波转成支援下路"（BV1PS42197Px @ 03:10-03:13）。
- **抢河蟹**：一技能可以瞬间把河蟹抢掉（BV1Wg411D7Ze @ 00:45-00:48）。
- **一技能打满要靠角度**：需要留出一个身位、指针稍微往上，"这样的话就能打满"；实战很难，但"打个一半其实也就差不多了"（BV1YJ411G7pq @ 05:24-05:57）。
- **蹲草反打**：把追你的刺客引到草边，二技能**对着墙放而不是对着人放**，反射伤害会高很多（BV1YJ411G7pq @ 06:43-06:56）。
- **一技能扫不到人时**：因为一技能减 50% 移速，用普攻接一技能（前摇之后更好中），二技能接一技能也可以（BV1Wg411D7Ze @ 04:24-04:34）。
- **无位移是硬伤**："他本身是个没有位移的英雄"，召唤师技能一定要带提升位移能力的（BV1YJ411G7pq @ 02:04-02:12）。

## 3. 连招

| 场景 | 连招 | 要点 | 依据 |
|---|---|---|---|
| 贴脸秒人 | **121** | 一技能起手→二技能→一技能，素材原话"121直接把敌人直接秒了" | BV1Wg411D7Ze @ 00:52-00:54 |
| 消除转枪头 | **普攻→一技能** / **二技能→一技能** | 一技能起手会先转枪头，用普攻或二技能垫一下可以省掉这段空转 | BV1Wg411D7Ze @ 04:04-04:19 |
| 蹲草反打 | 引敌→**二技能对墙反射** | 不要对着人放，对着墙伤害更高 | BV1YJ411G7pq @ 06:43-06:56 |
| 开大留人 | **二技能减速→开大→一技能/普攻输出** | 二技能减速保证导弹下下命中 | BV1YJ411G7pq @ 08:46-09:02 |

## 4. 中后期 / 节奏

- **4 分钟是第一个转线点**："龙点发育路有线权，且中路视野被队友站出来的情况下，哪怕是单射，我们也是可以转线的"（BV1SZjS6eE79 @ 03:51-03:57）。
- **3 分 47 秒的标准动作**：带辅助转中稳拿线权 → 提前站出龙坑视野；"哪方占住龙坑视野，就意味着哪方拿龙的概率大幅度上涨"（BV1SZjS6eE79 @ 03:59-04:08）。
- **推塔优先级**："三路塔能推中，我们就优先选择推中"（BV1SZjS6eE79 @ 05:38-05:40）。
- **不打无收益团战**："这游戏打架是建立在守塔推塔野区双龙上的"，记住"不打无收益团战就行"（BV1SZjS6eE79 @ 07:50-07:56）。
- **有资源先吃资源**："有资源一定要先吃资源，没资源了再往前压进"（BV1PS42197Px @ 06:31-06:33）。
- **6 分钟开始接红**："反完蓝6分钟开始拿红，让打野吃蓝，去带兵线发育，我们射手拿红打团"（BV1PS42197Px @ 05:04-05:07）。
- **中后期换抵抗鞋**："一般这时候出抵抗鞋，因为疾跑鞋前中期性价比太高了"（BV1Wg411D7Ze @ 01:12-01:14、BV1PS42197Px @ 07:21-07:22）。
- **后期进攻节奏是四一分推**："一定是我们打两路"，因为"一路线胜人被对面抢清掉，三路线容易少人被反打"，两路进攻是最优解（BV1PS42197Px @ 08:24-08:31）。
- **团战站位是核心资产**："我的站位是非常靠后的，我是不会被鬼谷子拉到、不会被甄姬控到的"；等对面关键技能交完才打得激进（BV1Wg411D7Ze @ 09:29-09:51）。
- **团战只打前排**："团战能打到谁就打谁，打前排就行了"；对面走太远就不追（BV1Wg411D7Ze @ 08:31-09:00）。
- **后期要靠普攻**："记住蒙犽的误区就是有E就按"，后期"放弃一技能，用普攻输出直接带走两个，再开E清线，同时恢复状态"（BV1PS42197Px @ 04:36-04:46）。
- **后期天花板要认清**：神装对拼打不过大部分射手，除非补反甲（BV1YJ411G7pq @ 10:06-10:12）；所以他的价值在中期滚经济与团战持续伤害，而不是末期一打多。

## 5. 出装铭文

**铭文**

- 十祸源、十鹰眼、十隐匿（BV1YJ411G7pq @ 00:38-00:41；BV1Wg411D7Ze @ 00:17-00:22）。
- 祸源不是为了暴击伤害，而是为了更快暴击叠能量、更快进入兴奋状态（BV1YJ411G7pq @ 03:17-03:23）。

**鞋子**

- **攻速鞋没有必要**：出攻速鞋只有 6% CD，直接出 CD 鞋就有 15%（BV1YJ411G7pq @ 02:46-03:02）。
- 疾跑鞋是另一派主张：500 块、80 基础移速，"大大加快蒙犽的发育和转线能力，主要是刷钱"；中后期换回抵抗鞋（BV1Wg411D7Ze @ 01:01-01:14）。

**第一套：暴击输出装**（BV1YJ411G7pq @ 01:04-01:28）

- 顺序：小陨星（10% CD + 物穿）→ CD 鞋 → 暗影战斧 → 无尽 → 红叉。
- 破军可以后置；也可以先出苍穹保命再出破军。

**第二套：防刺客装**（BV1YJ411G7pq @ 01:30-01:45）

- 隐忍之足（对面控多可换韧性鞋）→ 后续走血魔之怒；"如果对面输出不是那么高，你也可以换成苍穹"。

**容错路线**（BV1Wg411D7Ze @ 01:51-02:22）

- 铁剑 → 鞋子 → 抵抗鞋 → 无尽 → 影刃 → 荆棘护手 → 穿云弓 → 暴烈 → 破晓；最后一件看情况补保命或破军。
- 破军不拖节奏的小技巧：先出大剑，"如果需要打架的话，你马上苍穹不着急……打架的话你就等个破军"（BV1Wg411D7Ze @ 02:26-02:33）。

**碎星锤 vs 破晓**（BV1Wg411D7Ze @ 01:16-01:48）

- 主张破晓：破晓的 35% 攻速可转成 7% CD（碎星锤只有 10% CD），且精准对一技能生效，"破晓纯纯部属性是非常是好萌芽的，一点都不会浪费"。

**针对性装备的触发条件**

- 暴烈："对面有反甲的时候"性价比最高，因为反甲反到蒙犽身上的伤害也能叠暴烈被动（BV1Wg411D7Ze @ 03:14-03:28）。
- 魔女：对面有反甲/电刀这类法伤，或曜、雅典娜这类混伤大招时（BV1Wg411D7Ze @ 03:30-03:47）。
- 不详：对面是一套秒的类型（猴子、兰陵王、元歌、阿轲），"触发不了几层暴烈被动"（BV1Wg411D7Ze @ 03:50-04:01）。
- 反甲：作为功能性最后一件，"如果我们不出反甲的话，其实大后期……大部分射手蒙犽是打不过的"（BV1YJ411G7pq @ 10:06-10:12）。

**召唤师技能**

- 主推闪现、疾跑；"进化"（净化）极端情况可用但不推荐，因为本身无位移（BV1YJ411G7pq @ 01:57-02:12）。

## 待补

- 大招引导时长与伤害/范围的对应关系（只提到"越久范围越大""尽量拉满"）

- 反甲黑科技的适用边界（哪些对局值得为它让出一个格子）
- 巅峰赛与 KPL 两种环境的强度差异（赛事素材只给了伤害占比与分均伤害两个数）
