# 王昭君：把人冻住只是开始，冻住之后的每一段伤害才是收益

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：五条，一条双国服昭君的技巧长讲（BV1pG4y1e7BU）、一条技能机制讲解（BV1sk4y1g7j3）、两条中单实战（BV1sr9bBxEqL 对妲己、BV1CMu56iENJ 对小乔）、一条 1900 分辅助位实录（BV17QYs6nE9A）。
> ⚠️ 五条素材都以中单/软辅打法为主，**大招压塔的点位图、辅助位完整出装、多数对位的强度结论未覆盖**，故仍标 draft。

## 1. 机制内核

1. **被动一·冰冷**：所有技能和强化普攻附带冰冷，减 50% 移速、35% 攻速，持续 2 秒（BV1pG4y1e7BU @ 00:56）。另一份素材记的是 50% 移速 + 37% 攻速（BV1sk4y1g7j3 @ 00:28），两份数值有出入，以实战手感为准。
2. **冰冷会衰减，但可重置**：技能刚打上去是满额，随后百分比不断下降；用技能或强化普攻可以重置衰减，所以"一定要去穿插强化普攻"（BV1pG4y1e7BU @ 01:16~01:34）。
3. **减攻速随等级成长**：一级 35%，满级 63%（BV1pG4y1e7BU @ 01:36~01:43）。这是她克制近战和攻速型射手的根。
4. **被动二·强化普攻**：每平 A 两下，第三下打出三根冰柱，法强越高伤害越高（BV1pG4y1e7BU @ 01:49~01:59）；空 A 也能叠（BV1pG4y1e7BU @ 02:01）。
5. **被动三·脱战护盾**：脱战（5 秒内不造成也不承受伤害）获得护盾（BV1pG4y1e7BU @ 02:29~02:45；BV1sk4y1g7j3 @ 01:06~01:10）。护盾厚度看法强，护盾强度看双抗（BV1pG4y1e7BU @ 02:59~03:08）。
6. **护盾爆炸的范围被严重低估**：破盾伤害范围"甚至和大招的范围一样"，补伤害不必贴脸（BV1pG4y1e7BU @ 03:38~03:46）；破盾附加的冰冷只对物理攻击生效，法术攻击打护盾不触发（BV1pG4y1e7BU @ 03:51~04:02）。
7. **一技能·双向视野**：无论是否命中都获得视野，视野范围比伤害范围还大（BV1sk4y1g7j3 @ 01:35~01:40）；但视野是相互的，探到对面时自己也暴露（BV1pG4y1e7BU @ 05:50~06:02）。
8. **二技能·核心中的核心**：0.8 秒延迟后冰冻 2.5 秒，被冻目标吃到的每段伤害都额外加成，强化普攻三段直接变六段（BV1sk4y1g7j3 @ 02:51~03:05）。
9. **二技能能打断施法并让技能进 CD**：对牛魔、项羽这类有抬手技能的英雄，冻住会打断施法"而且技能会直接进入冷却"（BV1pG4y1e7BU @ 07:13~07:23）。
10. **大招·刷新护盾**：5 秒暴风雪、约 0.5 秒一段、吃满 9 段（BV1pG4y1e7BU @ 07:41~07:46）；开大立刻刷新被动护盾，可用来连吃两次护盾爆炸（BV1pG4y1e7BU @ 07:49~08:00；BV1sk4y1g7j3 @ 02:09~02:17）。

## 2. 对线 / 打法

- **一级点一还是点二**：常规点一；"如果觉得自己有自信拿一血"，就升二配合冰冻增伤和强化普攻打线上优势（BV1pG4y1e7BU @ 11:46~11:55）。
- **用空 A / A 兵刷强化普攻消耗**（BV1pG4y1e7BU @ 02:01；BV1pG4y1e7BU @ 11:56）；强化普攻有后摇，一技能可以插在后摇里放，手感更顺（BV1pG4y1e7BU @ 11:59~12:07）。
- **蹲草绝对不要空 A**：普攻特效出草会被看到，"昭君的被动即使是在草丛也很容易被队友发现"（BV1pG4y1e7BU @ 02:06~02:27）。
- **一级换血靠护盾**：有护盾时换血不亏（BV1sr9bBxEqL @ 00:39）；对妲己这类，"被动打人不打兵"可以直接压血量（BV1sr9bBxEqL @ 00:35）。
- **补尾刀即可**：王昭君对经济要求不高，漏了也没关系（BV1sr9bBxEqL @ 00:44~00:47）。
- **四级前把兵线卡在塔外**，能拿满兵线经济（BV1sr9bBxEqL @ 00:56~01:01）。
- **前期耗蓝**：补两个回蓝项链撑续航和赖线（BV1pG4y1e7BU @ 12:08）。
- **没位移，就用技能探草**：二级、四级两个抓人节点，以及小地图上敌人失踪时，必须探明附近野区盲区（BV1pG4y1e7BU @ 12:14~12:21）；每个草都探、探过的还要再探（BV1sr9bBxEqL @ 06:43~06:53）。
- **四级前别硬追支援**：移速慢，支援速度不理想，把信号打足更划算（BV1pG4y1e7BU @ 12:23~12:32）；前期真正的核心是"打对面状态，让对手无法支援"（BV1pG4y1e7BU @ 12:34~12:37）。
- **支援路线要算打野开野**：不知对面打野怎么开时按默认路线判断，避开可能被反蹲的一路，跟自家打野同侧抓（BV1sr9bBxEqL @ 01:37~02:04）。
- **蹲草别贴墙**：贴墙站会被技能探到，离墙远一点方便闪现跑（BV1sr9bBxEqL @ 02:47~03:01）。
- **打妲己**：四级前她不虚你但需要快清线，抓她清线的一技能后摇直接冻（BV1sr9bBxEqL @ 03:03）；她四级后不硬碰，先吃兵线再给信号退（BV1sr9bBxEqL @ 02:16~02:22）。
- **清线比不过就"盯对位"**：自己抢线带节奏能力不行，就盯着对位不让他轻松支援——"本着自己做不了事的原则，也不让对面做事"（BV1CMu56iENJ @ 00:39~00:46）。站位贴兵线边缘，对手打兵你就躲、打状态就拖他节奏（BV1CMu56iENJ @ 00:59~01:03）。
- **辅助位**：哪里有作用就去哪，别死板（BV17QYs6nE9A @ 02:51~02:57）；玩软辅"一定要禁钟馗"，因为自己就是被开团的点（BV17QYs6nE9A @ 05:51~06:02）；站位靠后，"你要在前排被开的话就很被动了"（BV17QYs6nE9A @ 06:18~06:26）。

## 4. 中后期 / 节奏

- **团战站位**：跟射手、辅助站一起；二技能在团战开启前不要交，捏着就是对刺客的威慑，除非有必中把握（BV1pG4y1e7BU @ 12:45~13:01）。
- **大招分割战场**：放在敌方前排与后排之间（BV1pG4y1e7BU @ 13:03~13:06）；也可用来封路，"我大招往这一放，他就不从那个方向回家了"（BV17QYs6nE9A @ 04:04~04:13）。
- **野区是她的主场**：墙体加技能限制，敌方没位移很难保命（BV1pG4y1e7BU @ 13:07~13:14）。
- **大招推进**：逆风清兵、顺风压塔（BV1pG4y1e7BU @ 13:17~13:22）；正确压塔方式是兵线快到敌方塔下时开大、让队友先撤，再趁机点塔（BV1pG4y1e7BU @ 13:25~13:35）。
- **压塔时大招不要和墙重合**："大招不要和墙有一点重合，最好覆盖所有范围"，否则那部分等于无效（BV17QYs6nE9A @ 09:43~09:48）。
- **有人数优势先拿龙推塔**，大招留到推高地时压位置（BV1sr9bBxEqL @ 05:41~05:47）。
- **9 分钟经济领先时**该追求消耗而不是急着撤（BV1pG4y1e7BU @ 08:59~09:09）。
- **推水晶别松懈**：算对面复活时间差，闪现进水晶放大减速再退，多拖几秒（BV1pG4y1e7BU @ 10:22~10:45）。

## 5. 出装铭文

- **铭文**：十梦魇、十狩猎、十心眼，合计 88 法穿、攻速、10% 移速与 42 法强，补前期移速与攻速（BV1pG4y1e7BU @ 13:41~13:47）；蓝色也可换调和（BV1pG4y1e7BU @ 13:49）；不必特意堆攻速阈值，中后期不靠平 A 打伤害（BV1pG4y1e7BU @ 13:50~13:56）。
- **工具人套**（二技能没自信时）：冷静鞋 → 面具 → 圣杯 → 冰心 → 冰杖 → 日暮 → 辉月；后期冷却叠满把冷静鞋换抵抗鞋。核心是控制与消耗，冰杖与其适配度极高（BV1pG4y1e7BU @ 13:59~14:27）。
- **爆发套**（二技能炉火纯青时）：冷静鞋 → 回响 → 帽子 → 虚无或日暮 → 大书 → 辉月；护盾可到近 900 点，但吃经济、自身脆、吃意识（BV1pG4y1e7BU @ 14:27~14:50）。
- **对面回血猛**（程咬金+蔡文姬、桑启、扁鹊）：第二件直接做梦魇，属性性价比高且不拖成型（BV1pG4y1e7BU @ 14:52~15:04）。
- **定位取向**：出装"都是偏功能和容错，不推荐纯法装"（BV1sk4y1g7j3 @ 06:27~06:33）。另有素材把出装放在评论区，正文未展开（BV1sr9bBxEqL @ 01:08~01:17）。
