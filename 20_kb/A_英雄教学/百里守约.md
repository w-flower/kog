# 百里守约：大后期在塔外点人，贴墙就是隐身的刺客

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份成体系的射手指南（BV1Tf421q7jN，机制、保命、出装都有，实战样本偏少）；一份队伍语音实录（BV1UDYTzTE6f，几乎全是队友指挥与野区节奏）。
> ⚠️ **素材覆盖不全**：第二份（BV1UDYTzTE6f）是打野/中单视角的团队语音，能确认守约在场的只有零星几句（BV1UDYTzTE6f @ 05:30、05:55），**守约本人的操作细节无法提取**；**铭文在两份素材中完全没讲**，出装也只到「鞋子换装」为止，本卡以第一份为主、第二份只作节奏补充。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 大后期。「你先看他大后期点坦克」（BV1Tf421q7jN @ 00:28）、「等到你大后期」（BV1Tf421q7jN @ 01:11）、「这是大后期」（BV1Tf421q7jN @ 01:55） |
| **节奏职责** | 跟团打输出；条件允许时切换成隐身绕后切后排（BV1Tf421q7jN @ 03:34、03:37） |
| **一句话** | 刺客和射手合二为一 |
| **依据** | 贴墙/贴眼行走隐身 + 三个大招 + 一个闪现，共四个保命技能（BV1Tf421q7jN @ 01:27、01:41、01:44） |

## 1. 机制内核

1. **版本从 CD 流改成平A流。** 以前靠二技能狙击打伤害，所以做冷静之靴；现在靠普攻打伤害，所以做极速战靴（BV1Tf421q7jN @ 00:04、02:08、02:11、02:13、02:16、02:17）。
2. **射程是他最大的资源。** 大后期点坦克「手多长」，这个距离白起「根本嘲讽不到你」（BV1Tf421q7jN @ 00:28、00:30、00:31）。
3. **四个保命技能可轮转。** 一波团战三个大招，加一个闪现（BV1Tf421q7jN @ 00:39、00:42）；大招约两秒一次（BV1Tf421q7jN @ 00:45）；注意数量是三发变两发、两发变一发（BV1Tf421q7jN @ 01:17、01:18、01:20、01:21）。
4. **隐身来自墙与眼。** 贴墙走、在眼或墙边上走都是隐身的，放完眼之后也是隐身（BV1Tf421q7jN @ 01:27、01:29、01:31、01:33、01:36）；下一次普攻或扔技能才显影（BV1Tf421q7jN @ 01:37）。
5. **可以无伤点塔。** 大后期站在防御塔攻击范围外，没有兵线也能点塔（BV1Tf421q7jN @ 01:06、01:11、01:12、01:14）。
6. **大招与闪现都能穿墙**（BV1Tf421q7jN @ 04:00）。

## 2. 对线 / 打法

- **打马可波罗就用手长欺负他手短。** 他敢过来转，直接闪现或大招拉身位（BV1Tf421q7jN @ 00:47、00:50、00:52、00:53、00:54）。
- **两种打法二选一。** 一是用被动隐身绕后切后排，3~4 枪带走一个（残血两枪就够）；二是正面发起进攻，大后期能点谁点谁（BV1Tf421q7jN @ 00:57、01:01、01:05、03:34、03:40、03:48、03:50）。
- **被近身不要硬拼。** 「如果敌方英雄冲你过来了，你有四次保命的机会」，直接拉开（BV1Tf421q7jN @ 03:52、03:54）。
- **团队协同（第二份实录，非守约操作）：** 卡兵线（BV1UDYTzTE6f @ 01:53）；中路给假视野后「退回来给他们放出来」（BV1UDYTzTE6f @ 04:01、07:11、07:12）；塔前堵线（BV1UDYTzTE6f @ 04:48、04:49）；拔中一塔（BV1UDYTzTE6f @ 05:32）；经济领先后「别浪」（BV1UDYTzTE6f @ 08:00）；把枪线堵住（BV1UDYTzTE6f @ 08:14）；红区可以进（BV1UDYTzTE6f @ 08:15）。
- **进攻节奏点。** 打 10 分钟时把对面「放出来打」（BV1UDYTzTE6f @ 09:29、09:30、09:51、09:52），同时把野区清干净（BV1UDYTzTE6f @ 10:02、10:04）。

## 4. 中后期 / 节奏

- **大后期是绝对主场**：手长到坦克摸不到，坦度在他的普攻面前不成立（BV1Tf421q7jN @ 00:28、00:31、03:48、03:50）。
- **无兵线也能磨塔**，推塔节奏不必等兵线（BV1Tf421q7jN @ 01:11、01:14）。
- **团战里四个保命技能要留着滚着用**，不是一次性交完（BV1Tf421q7jN @ 01:24、01:26、03:55）。
- **敌方冲脸的解法是位移而不是对拼**（BV1Tf421q7jN @ 03:52）。
- **顺风不要浪。** 经济领先时的指令就是「别浪」（BV1UDYTzTE6f @ 08:00、08:01）。

## 5. 出装铭文

**鞋子：** 攻速流做极速战靴（BV1Tf421q7jN @ 02:17）；重置前是 CD 流的冷静之靴（BV1Tf421q7jN @ 02:12）。

**前期三件：** 影刃、无尽、末世，三个顺序「看你自己喜欢」（BV1Tf421q7jN @ 02:19、02:23、02:27、02:32）；影刃和无尽「肯定是不分家的」（BV1Tf421q7jN @ 02:38）。

**末世优先于泣血之刃：** 末世是生命值百分比掉血，敌人越肉、血越高打得越疼（BV1Tf421q7jN @ 02:43、02:45、02:46、02:47、02:50）。

**穿甲：** 做破晓；本赛季被削弱，物理穿透从 40% 降到 30%（BV1Tf421q7jN @ 02:59、03:02、03:04、03:06、03:07）。

**最后一件：** 补破军，吃「生命值低于 50% 额外造成 30% 伤害」的被动，配合队友先消耗再一两个普攻收后排（BV1Tf421q7jN @ 03:11、03:13、03:29、03:32）。

**大后期换装：** 鞋子不要了，换装顺序为复活甲 → 逐日之弓 → 日渊（逐日之弓升级版）（BV1Tf421q7jN @ 01:57、01:59、02:00、02:02、02:03）。

**铭文：** 素材称「本赛季我认为最强的出装铭文」（BV1Tf421q7jN @ 01:48），但通篇只讲了出装，**铭文一个字没提**。见「待补」。
