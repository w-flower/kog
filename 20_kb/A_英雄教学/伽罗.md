# 伽罗：手长就是全部，急着输出的人先死

## 1. 机制内核

1. **长弓与短弓是两种模式**：长弓打团、打人、打塔；短弓赶路、回蓝；“长短交替刷野”伤害更高（BV15MwbztEWT @ 18:57）（BV1tBA2e5E2V @ 00:48）。
2. **长短弓伤害差不多**：“伽罗其实长短弓伤害差不多”，没长弓也能继续输出（BV15MwbztEWT @ 24:54）。短弓一下 425，长弓带灼烧（BV15MwbztEWT @ 20:40）。
3. **交替刷野的收益来自灼烧 + 平A 叠加**：长弓一下、短弓一下，既有法伤灼烧又有平A伤害，还能省蓝（BV15MwbztEWT @ 20:50）。
4. **大招圈内加暴击与移速**：“在大招里面暴击移速都会提高”（BV1tBA2e5E2V @ 00:53）。
5. **在大招边缘关大可以白嫖 0.5 秒**：国服语录“在大招的边缘去关闭大招，就可以白嫖多 0.5 秒的移速和暴击”（BV15MwbztEWT @ 30:14）。
6. **逃跑要先进大招再走**：否则“移速和爆率的三秒收益都会减半”（BV1tBA2e5E2V @ 00:57）。
7. **二技能是沉默、可探草、可封路**：对线用二技能探草（BV15MwbztEWT @ 18:11）；二技能“有一个沉默的控制”，等队友先控再补（BV15MwbztEWT @ 29:12）；正常很难命中，要“预判敌方闪现的位置”封走位（BV15MwbztEWT @ 22:29）。
8. **被动是“让敌人跑不掉的魅魔”**（BV15MwbztEWT @ 31:44）。素材对被动只给这一句概括，未拆数值。
9. **保命能力很差**：被开“是很难活的，只能是队友来保你”（BV1pbsH6FEF1 @ 06:33）。
10. **对线能力偏弱但极度吃对线**：“伽罗这个英雄是非常吃对线，但对线能力偏偏又不是特别强的英雄”（BV1tBA2e5E2V @ 02:51）。
11. **手长是唯一优势**：“伽罗唯一的优势不就手长了嘛”（BV15MwbztEWT @ 31:21），所以输出必须卡极限距离（BV15MwbztEWT @ 31:18）。

## 2. 对线 / 打法

- **一级学一还是学二看辅助**：辅助连体、能压就学一“上去点人”；被放养就学二，“不让你吃的兵线就用二技能补”（BV1hBut6WE5k @ 01:19）。平稳发育、无法稳压时点二速清线，靠清线速度差拿中立资源（BV1tBA2e5E2V @ 02:27）。
- **有优势卡线，没优势用远程技能清线**（BV15MwbztEWT @ 01:28）。优势时要“尽量拉长对线期”，不要早早清线把对面游射解放出来（BV15MwbztEWT @ 08:31）。
- **对线核心是压制力，不是补刀**：“线上能否打出对线压制力，才是一个射手、一个发育路真正的核心所在”（BV1tBA2e5E2V @ 03:21）；“有时候补刀反而没那么重要”（BV15MwbztEWT @ 02:53）。
- **四条防抓口诀**：三线交汇看中线、中单不在就在边、残血回家必放线、射手安全要当先（BV15MwbztEWT @ 03:24）（BV1tBA2e5E2V @ 03:53）。
- **平A卡最远距离，点塔用长弓**（BV15MwbztEWT @ 01:38）；“伽罗就是玩这个手长”（BV15MwbztEWT @ 31:31）。
- **对拼前先算小兵仇恨**：两个远程兵一起 A，“五轮都打了你 720 点血”，射手初始血量才 3000 出头（BV1BjLM6tEYs @ 01:43）。决定死战就布甲出门，不要短剑（BV1BjLM6tEYs @ 01:36）。
- **前期状态大于一切**：被打到半血以下就“马上闪现血包加上恢复”，刚好回满（BV1hBut6WE5k @ 00:44）。
- **4 分钟后不要一个人守下路**：“你一个人在下路吃线的话，是很容易被越被抓的”（BV1pbsH6FEF1 @ 04:00）；塔的保护机制消失后，“与其被对方直接在上路越塔，不如直接主动出击来到中路”（BV1hBut6WE5k @ 04:11）。
- **辅助不来就“人挪活”**：不要死守下塔，转中、转对抗路、吃野区都行；“你本来就一个人对线就坐牢……万一又坐牢又要死”（BV15MwbztEWT @ 14:06）。
- **不敢吃线时用二技能补**，不要硬上（BV15MwbztEWT @ 29:21）。
- **打红隼前先用二技能探草**（BV1pbsH6FEF1 @ 01:13）；当着对面开红隼要先压退对面射辅，再考虑拿（BV1BjLM6tEYs @ 02:43）。
- **中路蹭线靠有线权的一侧草丛站**；没优势就“躲在塔下吃，不要出去”（BV1hBut6WE5k @ 03:24）。

## 4. 中后期 / 节奏

- **10 分钟前是打野的时间**：射手前期“本来就没啥用”，支援太远“容易人财两失”（BV15MwbztEWT @ 04:07）。
- **中期进入自由人节奏**：6 到 7 分钟开始，围绕“有红的那半区”找节奏；游射可以先偷偷去对抗路打一波掉点再回来（BV15MwbztEWT @ 17:23）（BV15MwbztEWT @ 10:44）。
- **中期不要死守边路**：自家没有中路线权时，在下路清线就是“陷阱经济”，要么被越塔、要么被围殴（BV1pbsH6FEF1 @ 05:22）（BV1BjLM6tEYs @ 04:57）。
- **跟着兵线打，不追人**：“你跟着兵线打，你才可以做推进”；推塔对面自然会回来守（BV1pbsH6FEF1 @ 11:50）（BV1pbsH6FEF1 @ 14:01）。
- **中一塔要尽早拆**：对面守中塔就是为了拖后期，“稍微付出点代价也是要赶紧拆掉的”（BV15MwbztEWT @ 11:59）。
- **推塔选边**：小地图上谁凸出来就敲谁；两边都凸，敌方蓝区刷新推下、红区刷新推上（BV15MwbztEWT @ 12:45）。
- **9 分钟以抱团为主**：这个节点的团战“直接就影响了 10 分钟拿龙的一个权利”（BV1hBut6WE5k @ 07:39）。
- **团战站位**：站在队友后面，“手长的同时视野也长”（BV15MwbztEWT @ 32:54）；永远保证前面有自家队友（BV1BjLM6tEYs @ 09:19）。
- **看自家前排而不是对面残血**：前排残血要跑就立刻跑，“你只需要保持你一直可以 A 人就可以了”（BV1BjLM6tEYs @ 09:26）。
- **输出时盯有威胁的单位**：小乔的攻击距离、龙的击飞、朵莉亚/杨戬大招落点，都要先算（BV1BjLM6tEYs @ 09:44）。
- **敌人不漏视野就不要吃线**：他看不到你，“自然而然就会把兵线推过来”（BV1hBut6WE5k @ 06:47）；实在不敢吃就留兵，等两波一起吃（BV15MwbztEWT @ 30:06）。
- **逆风可以出去带线牵制**：把下线带过去，迫使对面分人回防，再找人数差（BV1BjLM6tEYs @ 05:24）。
- **顺风终结思路**：“拿红和对方去打他，对方不和你打，那就去压他的塔”（BV1hBut6WE5k @ 08:36）。
- **后期四件事**：带线、推塔、拿野怪、打龙（BV15MwbztEWT @ 11:51）。
