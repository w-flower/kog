# 小乔：靠转线把节奏打出来，10 分钟龙团前不能掉点

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：5 份中单/小乔实战讲解——全局大局观（BV1eRR3YTERB）、2000 分对线火舞（BV1pY4y1c7Dc）、貂蝉对线实录（BV1284y1m7T7）、传送阵吃线流（BV1xEFGzoEYA）、转线复盘（BV1g44y1F7aN）。视角都是"中单怎么读地图、怎么转线"，不是技能数值课。

## 1. 机制内核

1. **技能命中单位就加速**——这是她的机动来源。"小乔的技能命中单位就可以加速"，途中打野怪、打兵线、打人都能触发（BV1eRR3YTERB @ 12:32~12:47）
2. **一技能是两段扇子，可用来算伤害抢资源**："算好伤害，一技能两段直接抢河蟹"（BV1284y1m7T7 @ 03:02）
3. **二技能击飞是起手与留人**：素材里反复出现"击飞接一/击飞接 E"的补伤害节奏（BV1pY4y1c7Dc @ 02:08；BV1284y1m7T7 @ 05:43）
4. **大招是范围落星，要预判落点**："流星最后一下砸出来"才能收人（BV1pY4y1c7Dc @ 03:54）；落点有延迟，"大招落一会儿"（BV1284y1m7T7 @ 07:24）
5. **大招人越多伤害越低**——这是最反直觉的一条，也是她不该无脑大闪的原因："不要问我为什么不大闪吹三个，因为这样可能一个人都杀不死，小乔伤害人越多伤害越低"（BV1pY4y1c7Dc @ 07:47~07:53）
6. **召唤师技能带狂暴**，用来把单点爆发拉满："开狂暴A加伤害"（BV1284y1m7T7 @ 00:42）、"开大狂暴一技能起手"（BV1xEFGzoEYA @ 00:04）

## 2. 对线 / 打法

- **对线火舞**：不要在外围绕，"火舞不是在草丛就是在草丛，丢下扇子试探一下就行"（BV1pY4y1c7Dc @ 00:47~00:49）；火舞一级抢线能力不强，注意站位别被消耗（BV1pY4y1c7Dc @ 00:52~00:53）
- **回线走位没把握就走蓝区**："火舞肯定在蹲回线"，走位不好扇子闪现都得交（BV1pY4y1c7Dc @ 01:06~01:14）
- **对线甄姬可以直接抢**："他一级只有一个球"（BV1eRR3YTERB @ 01:19）；但甄姬到二级后抢线能力就上来了（BV1eRR3YTERB @ 03:12~03:16）
- **对线貂蝉必须拉扯**："打这个貂蝉得拉扯一下，不然很难打"（BV1284y1m7T7 @ 01:21~01:23）；三级是可以欺负她的窗口（BV1284y1m7T7 @ 02:00）；核心是"就等你交二"（BV1284y1m7T7 @ 02:23）
- **没辅助不要出塔**："现在我没有辅助就不要出去"，被貂蝉打一波把经济追上来，双边阵容就很难赢（BV1284y1m7T7 @ 02:53~02:58）
- **假视野的用法**：清线时假装往上路走，视野消失再折回来——"即使你这比给假视野管用多了"（BV1pY4y1c7Dc @ 01:18~01:25）
- **蹲草站中段**："蹲人的时候站在草丛中段总是好一点的"（BV1pY4y1c7Dc @ 03:21）
- **对位移多的英雄别蹲**：蹲不到就"开大招上去逼他走位，别着急放技能"（BV1pY4y1c7Dc @ 06:07~06:12）
- **兵线就是最好的诱饵**：抓对面清线的心理打一套（BV1pY4y1c7Dc @ 04:05~04:07、BV1pY4y1c7Dc @ 09:45）
- **这版本不能放线**："放线掉中塔，然后会被卡中塔位置漏兵"（BV1xEFGzoEYA @ 04:18~04:23）；"小乔是法核，一掉一波线真的基本跟炸穿没什么区别"（BV1xEFGzoEYA @ 04:26~04:29）
- **卡视野抓回线**：队友拆塔后视野残留，先后撤，再盯兵线等人出来（BV1pY4y1c7Dc @ 03:40~03:45）
- **抢 buff 要卡惩戒**：张飞惩戒只有 1500，他至少三下平A，"卡第三下"用一二技能直接拿（BV1pY4y1c7Dc @ 05:09~05:15）
- **低段位多利用传送阵超前发育**（BV1xEFGzoEYA @ 07:16~07:20）；吃下路两波线后经济直接一号位（BV1xEFGzoEYA @ 06:38~06:40）
- **视野让队友占**：特别是辅助或肉一点的，"我们这里再着急也只能点集合，不能直接自己走进去"（BV1eRR3YTERB @ 10:51~10:57）

## 4. 中后期 / 节奏

- **9 分钟就要为 10 分钟龙团铺垫**："9分钟9分钟开始我们就要重点警惕了"（BV1eRR3YTERB @ 10:00~10:04）；这段时间"不能死"、要带线带视野、别掉点（BV1eRR3YTERB @ 10:23~10:28）
- **核心方法论是"控距"**：通过小地图 + 时间点判断对面位置，再算自己能做什么（BV1eRR3YTERB @ 05:10~05:22）；"这游戏你想要成为高手……第一控距，第二大局观"（BV1eRR3YTERB @ 14:40~14:41）
- **双边的线都漏了就别站出去**，很容易被开（BV1eRR3YTERB @ 10:30~10:33）
- **打团要防三个点**：张良大闪是极限开团、甄姬柱子加球是消耗、曹操是侧边绕后（BV1eRR3YTERB @ 07:33~07:50）
- **进攻打一套先往后拉扯**，因为队友还没到——"这就是生生世世冷静的控距"（BV1eRR3YTERB @ 11:12~11:22）
- **打野死了别让对面换龙**，同时可以直接把蓝吃掉（BV1eRR3YTERB @ 12:03~12:11）
- **边路带线要盯中路**："你边路带线，中路就很有可能会被冲"（BV1eRR3YTERB @ 13:56~14:05）
- **冲的时候注意草**：有人队友在打架他还在草里蹲你（BV1eRR3YTERB @ 14:15~14:27）
- **认清优势方再决定打什么**："他们清线守塔，我们去打来清线的英雄"（BV1g44y1F7aN @ 11:20~11:23）；很多局是"抓不住这种制胜点"才被拖输（BV1g44y1F7aN @ 11:27~11:29）
- **顺风看线的位置**：中路线到了就一定有人来清（BV1g44y1F7aN @ 08:07~08:11）
