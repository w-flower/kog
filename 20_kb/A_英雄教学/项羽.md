# 项羽：先把刀意攒在身上，再谈两刀切 C

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：国服项羽 21 条连招逐帧拆解（BV1nvrgBeEPx，连招大全）、悟行千山正面强开实录（BV163HV6ZE5X）、基础机制与对线实录（BV1GZouB9ETE）、七大盲区技巧（BV1gzUsBCEi8，机制向）、悟行项羽强度与出装分析（BV1LvWe6DE9P）。字幕中的「悟行千山／无形／雾行／大雾」为同一件装备的不同转写，统一写作悟行千山。

## 1. 机制内核

1. **被动：残血减伤**。生命值低于 30% 获得 40% 减伤，等于血量越低越难被秒（BV1GZouB9ETE @ 00:27）（BV1GZouB9ETE @ 00:31）。
2. **一技能是两段控制**：前推先击退、再击飞；「释放技能之后，下一次平 A 是暴击」（BV1GZouB9ETE @ 00:33）（BV1GZouB9ETE @ 00:36）。
3. **二技能同时做三件事**：减速周围敌人、减少周围敌人输出、给自己下一次平 A 回血。减输出比例在素材里有两个转写：BV1GZouB9ETE 记为「减少周围敌人 30% 的输出，持续三秒」（BV1GZouB9ETE @ 00:40），BV163HV6ZE5X 的字幕里被转写为「减少了对面 3% 的输出」（BV163HV6ZE5X @ 01:11），本卡以 30% 为准并保留差异。
4. **枪刃额外伤害**：对被枪刃命中的敌人「造成额外 50% 的伤害」，所以素材直接点出「和破军这件装备很配」（BV1GZouB9ETE @ 00:46）（BV1GZouB9ETE @ 00:53）。
5. **强化平A分两种**：一技能给的是竖刀，「他必定暴击」；二技能给的是横刀，「他必定回血」，各持续 5 秒（BV1gzUsBCEi8 @ 00:29）（BV1gzUsBCEi8 @ 00:34）（BV1gzUsBCEi8 @ 00:36）。
6. **存刀的关键是刷新持续时间**：一二技能各存一发强普后，「在第一发强普快结束时再放二技能，就会直接刷新这五秒的持续时间」，从而存下双刀、连砍四刀（BV1gzUsBCEi8 @ 00:38）（BV1gzUsBCEi8 @ 00:43）（BV1gzUsBCEi8 @ 00:48）。
7. **二技能还能重置普攻间隔**：正常平 A 有间隔，二技能可以「直接重置上一发普攻秒砍第二刀」，即 A2A 瞬发两刀（BV1gzUsBCEi8 @ 01:09）（BV1gzUsBCEi8 @ 01:16）。
8. **强化普攻有 0.5 秒延迟判定**：强普动作打完后 0.5 秒内有人靠近依然吃伤害，二技能横劈因此能「直接回血两次」（BV1gzUsBCEi8 @ 01:38）（BV1gzUsBCEi8 @ 01:55）。
9. **大招期间霸体 + 免疫死亡**：「就算你生命值为零，也不会死」；且「生命值越低，大招伤害越高」（BV1GZouB9ETE @ 00:56）（BV1GZouB9ETE @ 01:03）（BV1GZouB9ETE @ 01:06）。
10. **一技能是脱手技能**：即将被控时「虽然本体会被控，但技能可以正常释放」，冰冻这类高级控制也「技能效果依然存在」（BV1gzUsBCEi8 @ 03:00）（BV1gzUsBCEi8 @ 03:12）；大招霸体可以免掉昭君冰冻，但「东皇张良的压制效果他还是太权威了」（BV1gzUsBCEi8 @ 03:27）。
11. **CD 是这个英雄的命门**：因为输出全靠「释放技能之后的强化平 A」，所以素材要求「一定要把冷却 CD 堆到 4%」（BV1GZouB9ETE @ 01:33，字幕数字疑为 40% 转写）。

## 2. 对线 / 打法

- **一级学一技能**，不是二技能（BV1nvrgBeEPx @ 01:04）。
- **一级站河道草丛、从敌方身后绕过去**推兵推英雄；「如果能推到英雄和兵是最好的，如果推不到也没有关系」（BV1GZouB9ETE @ 02:26）（BV1GZouB9ETE @ 02:30）。
- **一推四是一级对线的核心**：找好角度一技能推到 1 个英雄 + 3 个兵，接下来「平 A 也是同时 A4 个人的」，可以很快升到二级（BV1nvrgBeEPx @ 01:13）（BV1nvrgBeEPx @ 01:36）（BV1nvrgBeEPx @ 01:39）。
- **对线消耗用 A2A1A**：先打一个「很无所谓的 A」，再二技能 A 一下，然后一技能往前进攻或往后后退都行——先 A 再放二技能是为了刷新平 A 冷却，「伤害是最大化的」（BV1nvrgBeEPx @ 02:18）（BV1nvrgBeEPx @ 02:32）（BV1nvrgBeEPx @ 02:46）。
- **控制对冲**：对面有可预判的控制（素材举夏侯惇起手式），在他控你的同时用一技能控回去（BV1nvrgBeEPx @ 03:56）（BV1nvrgBeEPx @ 04:01）。
- **打吕布不要出肉**：「出肉，你没有伤害，打不死他，直接纯输出」（BV1GZouB9ETE @ 03:03）。
- **肉装项羽没必要打对线**：「互相清线就行」，甚至可以当对面面清（BV163HV6ZE5X @ 06:11）（BV163HV6ZE5X @ 06:15）。
- **前期资源优先级高于硬开**：没悟行没冰甲时开团能力可忽略、纯肉也没有单杀能力，关键在对抗路中立资源的抢夺（BV1LvWe6DE9P @ 03:20）（BV1LvWe6DE9P @ 03:25）。
- **一级没打好就缩**：猥琐塔下等打野支援，或者等对面先失误（BV1GZouB9ETE @ 02:42）。

## 4. 中后期 / 节奏

- **悟行千山决定上限**：素材开篇就说「项羽出专精是他的巅峰时刻」，悟行千山能让他重回巅峰（BV163HV6ZE5X @ 00:00）（BV163HV6ZE5X @ 00:02）。
- **成型快是他的核心价值**：「经济 3000 就能打出别的对抗 6000 经济都不一定打得出的作用」，下限在对抗路「可以说仅此一位」（BV1LvWe6DE9P @ 00:57）（BV1LvWe6DE9P @ 01:01）。
- **但收割几乎为零**：「收割能力几乎可以忽略不计」（BV1LvWe6DE9P @ 01:05），且上限比不上元歌、哪吒、关羽、司空震（BV1LvWe6DE9P @ 01:50）。
- **大招接悟行不是瞬发**：能被闪现或其他位移躲掉，遇到马超、公孙离、火舞、司空震会头疼；「多位移的英雄，项羽开不了，那就开他们的队友」（BV1LvWe6DE9P @ 01:12）（BV1LvWe6DE9P @ 01:23）。
