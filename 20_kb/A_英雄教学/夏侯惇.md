## 1. 机制内核

1. **被动是"能不能打"的开关**：生命值低于50%时受到伤害激活，8秒内每次普攻/技能命中目标都回大量血（BV1gT411F78X @ 01:32、BV1gT411F78X @ 01:34、BV1gT411F78X @ 01:36）；强化结束进冷却，冷却随等级成长（BV1zxWe6dE46 @ 00:35）。
2. **没被动就别硬上**：对线时被动图标是暗的就不要上，等有被动、势均力敌再换血，亏的一定是对方（BV1gT411F78X @ 01:40、BV1gT411F78X @ 01:44、BV1gT411F78X @ 01:46）。
3. **残血逃跑要回头打东西**：可以回头打兵线、野怪或追你的人，用命中把血吸回来，争取反打（BV1zxWe6dE46 @ 00:53、BV1zxWe6dE46 @ 00:54、BV1zxWe6dE46 @ 00:57）。
4. **一技能一段是刃风**：路径伤害＋减速，命中解锁二段；二段重击地面，范围伤害＋击飞，并附带基于目标最大生命值的撞击伤害（BV1zxWe6dE46 @ 01:00、BV1zxWe6dE46 @ 01:03、BV1zxWe6dE46 @ 01:06、BV1zxWe6dE46 @ 01:10、BV1zxWe6dE46 @ 01:12）。
5. **一段命中兵野也能解锁二段**：对线或支援时先用一段打兵线、野怪，把二段击飞留着，等对面靠近再出其不意（BV1zxWe6dE46 @ 01:15、BV1zxWe6dE46 @ 01:18、BV1zxWe6dE46 @ 01:23）。
6. **二段是矩形，斜着放更远**：正着打距离不够，偏一个角度就能命中（BV1gT411F78X @ 00:19、BV1gT411F78X @ 00:23、BV1gT411F78X @ 00:28）。
7. **二段前摇长、但保存久**：可以先把二段解锁，再用大招贴脸，到了再放，命中率高很多（BV1zxWe6dE46 @ 01:30、BV1zxWe6dE46 @ 01:33、BV1zxWe6dE46 @ 01:37）。
8. **二段是强制击飞**：释放时即使自己被控，也不影响对面被击飞；打暗信这类放大的英雄可以对着放，大家一起起飞（BV1gT411F78X @ 00:41、BV1gT411F78X @ 00:44、BV1gT411F78X @ 00:50）。
9. **一技能是唯一探草手段**：朝草里打一段，解锁二段就说明草里有人（BV1gT411F78X @ 00:31、BV1gT411F78X @ 00:34、BV1zxWe6dE46 @ 01:26、BV1zxWe6dE46 @ 01:30）。
10. **二技能：护盾＋三次真伤强普**：范围法伤，获得基于额外生命值的护盾，接下来三次普攻附带真实伤害（BV1zxWe6dE46 @ 01:41、BV1zxWe6dE46 @ 01:44、BV1zxWe6dE46 @ 01:46、BV1zxWe6dE46 @ 01:49）。
11. **强普减大招CD**：每次强化普攻减少大招冷却，命中兵线野怪也算（BV1zxWe6dE46 @ 01:52、BV1zxWe6dE46 @ 02:08、BV1zxWe6dE46 @ 02:10）。
12. **强普能打多个目标**：二技能是范围伤害，强化普攻也能一次命中多个，所以大招扎进人堆后再开二，伤害能打满（BV1zxWe6dE46 @ 01:55、BV1zxWe6dE46 @ 01:57、BV1zxWe6dE46 @ 02:00）。
13. **存盾：打团前先放一个二**：二技能护盾持续五秒，后期冷缩起来后，打团前存一个、打起来再放一个，等于多约30%生命值的护盾（BV1gT411F78X @ 01:53、BV1gT411F78X @ 01:56、BV1gT411F78X @ 02:00、BV1gT411F78X @ 02:03）。
14. **存强普能连打六下**：后期三次强普的存留时间比二技能CD长；先放二留三次强普，二技能CD剩3秒左右大招进场，先打完三次再放二，能连打六次强普，同时快速回大招（BV1zxWe6dE46 @ 02:15、BV1zxWe6dE46 @ 02:19、BV1zxWe6dE46 @ 02:23、BV1zxWe6dE46 @ 02:30）。
15. **大招两种用法**：默认把自己拉向命中目标，期间霸体，抵达后范围伤害＋击飞；快速点第二段则原地不动，把范围内敌人拉向自己并击飞（BV1zxWe6dE46 @ 02:50、BV1zxWe6dE46 @ 02:53、BV1zxWe6dE46 @ 02:56、BV1zxWe6dE46 @ 02:58）。
16. **二段拉回是范围控制**：敌人靠近时可以一次拉回多个，但不能把敌人拉过墙，只能隔墙造成控制（BV1zxWe6dE46 @ 03:02、BV1zxWe6dE46 @ 03:05、BV1zxWe6dE46 @ 03:07）。
17. **位移可走弧线**：拉过去的过程中能拖摇杆选直线或弧线，弧线落点比直线长，追击时更容易贴到人（BV1zxWe6dE46 @ 03:10、BV1zxWe6dE46 @ 03:14、BV1zxWe6dE46 @ 03:20）。
18. **大招比指示器远、能穿墙**：实际命中距离比指示器长（BV1gT411F78X @ 02:21、BV1gT411F78X @ 02:24）；能从河道直接穿到三只小猪、从龙坑穿过去（BV1gT411F78X @ 02:30、BV1gT411F78X @ 02:33、BV1gT411F78X @ 02:35）。
19. **大招期间霸体**：别人要控你时可以丢大招躲控制、强制位移（BV1gT411F78X @ 02:48、BV1gT411F78X @ 02:50、BV1gT411F78X @ 02:53）。
20. **大招命中是玄学**：有时候特别准，有时候贴脸都能空；先放二技能减速50%再大，会准一些（BV1gT411F78X @ 02:55、BV1gT411F78X @ 02:57、BV1gT411F78X @ 03:00、BV1gT411F78X @ 03:03）。
21. **护盾多克吸血**：夏侯惇护盾多，对面八戒、射手的吸血打在盾上吸不回来（BV1wxNverERf @ 00:48、BV1wxNverERf @ 00:51、BV1wxNverERf @ 00:55）。

## 2. 对线 / 打法

- **二技能尽量盖多个兵**：利用范围伤害、护盾和强化普攻快速清线，抢到二级再找换血机会（BV1zxWe6dE46 @ 05:33、BV1zxWe6dE46 @ 05:37、BV1zxWe6dE46 @ 05:39）。
- **一段打兵、二段留人**：对线时先用一段命中兵线，保留二段威慑；对面忍不住上来补刀，再放二段击飞（BV1zxWe6dE46 @ 05:42、BV1zxWe6dE46 @ 05:45、BV1zxWe6dE46 @ 05:47）。
- **二段命中就接二技能＋强普**：压血线、卡对面发育，不要打完就走（BV1zxWe6dE46 @ 05:50、BV1zxWe6dE46 @ 05:51）。
- **半血先确认被动**：有被动就靠技能和普攻持续回血，没被动及时退（BV1zxWe6dE46 @ 05:55、BV1zxWe6dE46 @ 05:58、BV1zxWe6dE46 @ 06:02）。
- **1分30秒不要压太前**：这个节点打野快到了，被抓好一波就断节奏（BV1zxWe6dE46 @ 06:06、BV1zxWe6dE46 @ 06:07、BV1zxWe6dE46 @ 06:08）。
- **被多人打成残血，即便有被动也别反打**：前期坦度不够，被集火很难活；用附近野怪回血、赖线发育（BV1zxWe6dE46 @ 06:10、BV1zxWe6dE46 @ 06:13、BV1zxWe6dE46 @ 06:15、BV1zxWe6dE46 @ 06:17）。
- **线上有优势就换血**：有被动不要怕打，换血亏的是对面；没被动尽量不打（BV1gT411F78X @ 06:32、BV1gT411F78X @ 06:34、BV1gT411F78X @ 06:37）。
- **带斩杀打二级河蟹**：升二先拿河蟹，同时盯地图看对面中单、打野位置（BV1gT411F78X @ 05:31、BV1gT411F78X @ 05:33、BV1gT411F78X @ 05:35）。
- **骗打野上来**：发一句"上路没有闪现"，打野更愿意来；对面打野出现在中路时，先压一下对面给心理负担，再后撤蹲草，等对面交技能再动手（BV1gT411F78X @ 05:39、BV1gT411F78X @ 05:41、BV1gT411F78X @ 05:45、BV1gT411F78X @ 05:49）。
- **有优势要支援**：打出优势多去支援，把对抗路的优势变成全队优势；只守对抗路不支援、不推塔，队友崩了经济差太大（BV1gT411F78X @ 07:31、BV1gT411F78X @ 07:36、BV1gT411F78X @ 07:44、BV1gT411F78X @ 07:49）。
- **中期有被动就打到底**：没被动就用大招撤，等被动好了再回来（BV1zxWe6dE46 @ 06:26、BV1zxWe6dE46 @ 06:27）。
- **推掉一塔就解放**：击杀或逼退后进塔磨塔，尽早推一塔，然后全图游走支援（BV1zxWe6dE46 @ 06:33、BV1zxWe6dE46 @ 06:36、BV1zxWe6dE46 @ 06:47）。
- **对线多看法阵传送**：留意其他分路团战，用原初法阵及时传送，大招留人拿击杀助攻（BV1zxWe6dE46 @ 06:38、BV1zxWe6dE46 @ 06:40、BV1zxWe6dE46 @ 06:43）。
- **后期正面不要见人就飞**：先用一技能试探、观察己方输出位置，队友能跟上再突进控多人（BV1zxWe6dE46 @ 07:12、BV1zxWe6dE46 @ 07:15、BV1zxWe6dE46 @ 07:18）。
- **拉回用在逆风和蹲草**：逆风把敌人拉回来无伤消耗，避免自己过去被集火；蹲草拉回，队友不用前压就能输出（BV1zxWe6dE46 @ 07:23、BV1zxWe6dE46 @ 07:25、BV1zxWe6dE46 @ 07:33）。
- **打野不用怕中单消耗**：这是夏侯惇打野的优点；红开，按野区节奏走，不强行跟线上节奏（BV1EYZvYnECU @ 00:41、BV1EYZvYnECU @ 02:52、BV1EYZvYnECU @ 03:10）。
- **打野有经济就扛得住**：前中期黄盾＋大肉刀把刷野速度拉满，不需要先做不详（BV1EYZvYnECU @ 05:07、BV1EYZvYnECU @ 05:20、BV1EYZvYnECU @ 05:25）。
