## 1. 机制内核

1. **被动=双抗+攻速+回血三合一**：每次技能命中给一层物理防御，最多三层，是前期对拼资本（BV1gK411r7T2 @ 00:18、BV1gK411r7T2 @ 00:23）；每层 64 点双抗、三层 192 点（BV11tAqzzEsw @ 04:46）。层数在血条右侧显示，等级越高加成越多，所以补刀拿 50% 额外经验也是在买坦度（BV1Bf421v7RS @ 00:50、BV1Bf421v7RS @ 00:55）。
2. **三层被动衰减不一样**：只有第一层正常持续五秒，剩下两层每层只持续两秒（BV11tAqzzEsw @ 04:53），所以要用二技能不断续层（BV11tAqzzEsw @ 05:01）。只要冷却缩减超过 5% 且二技能到二级（三级起），就能用二技能无限续被动（BV11tAqzzEsw @ 05:04）。
3. **技能命中后 100% 攻速两秒**，后两次普攻变双拳，伤害更高还回血（BV1gK411r7T2 @ 00:27、BV1gK411r7T2 @ 00:30）。
4. **一技能是双重位移+击飞**，可储备两次（BV1Bf421v7RS @ 01:29、BV1Bf421v7RS @ 01:37）；实际生效范围比指示器远（BV1gK411r7T2 @ 00:55）。一闪的价值不只是加距离，更重要是改一技能朝向，好让大招直接给到对面后排（BV1gK411r7T2 @ 01:01、BV1gK411r7T2 @ 01:06）。
5. **二技能是主要破甲手段**：连续出拳、每拳减护甲，点满五拳能降 300 点防御，所以后期打 C 位有伪真伤效果（BV1gK411r7T2 @ 01:11、BV1gK411r7T2 @ 01:16、BV1gK411r7T2 @ 01:20）。重做版改成每秒五拳、持续四秒共 20 拳，每拳含"基础伤害+目标最大生命值百分比"两段，且每 100 额外物攻再加成（BV1Bf421v7RS @ 02:13、BV1Bf421v7RS @ 02:18、BV1Bf421v7RS @ 02:24）。
6. **二技能期间穿插一三技能才打得高**：二技能会自动打出储备的强普，一三技能触发被动再拿强普，所以要在二技能里穿插（BV1Bf421v7RS @ 03:02、BV1Bf421v7RS @ 03:09）。二技能期间放一技能并同时转轮盘，能瞬间改出拳方向，配一技能击飞更稳命中（BV1Bf421v7RS @ 02:52、BV1Bf421v7RS @ 02:58）。
7. **强普最多存两次**；一三技能没命中只给一层，命中给两发（BV1Bf421v7RS @ 01:15、BV11tAqzzEsw @ 05:45）。因此可以用被动层数反推草里有没有人（BV11tAqzzEsw @ 05:53）。
8. **大招分蓄力、踢出两个动作**：正常蓄力过程就已经打出控制（BV11tAqzzEsw @ 00:39）；提前在敌人进范围前放大，蓄力就不产生控制，会等第二动作再踢出去——这就是延迟效果（BV11tAqzzEsw @ 00:47、BV11tAqzzEsw @ 00:57）。
9. **上墙=眩晕一秒+一技能变飞踢**：击退到墙体额外伤害并眩晕一秒（BV1Bf421v7RS @ 03:56）；新版击退距离更远、更容易上墙（BV1Bf421v7RS @ 04:01）；上墙后一技能变飞踢，附带目标已损生命值比例的物理伤害，血越少踢得越疼（BV1Bf421v7RS @ 01:57、BV1Bf421v7RS @ 02:02）。
10. **大招有身后判定**：1.5 个身位内能踢到后方目标，可做身后上墙、隔墙反拉上墙，甚至隔墙反推 3211（BV11tAqzzEsw @ 03:08、BV11tAqzzEsw @ 03:13、BV11tAqzzEsw @ 03:21）。大范围也意味着"可以把身后敌人给踢过来"（BV1gK411r7T2 @ 02:04）。
11. **二段带 20% 类似斩杀，晚放更赚**："条件允许下尽量捏久一些，最后再放这个二段伤害"（BV1gK411r7T2 @ 01:43、BV1gK411r7T2 @ 01:49）。
12. **强制抵消**：一三技能即使被控（含王昭君冰冻）也能正常打出，可用来吃控（BV11tAqzzEsw @ 02:12、BV11tAqzzEsw @ 02:07）。二技能被控只临时打断，控制结束继续向前挥拳；也可再点二技能直接恢复行动，并按已释放时长返还部分冷却（BV1Bf421v7RS @ 03:21、BV1Bf421v7RS @ 03:39）。
13. **墙体判定比想象宽**：猪八戒大招、女娲方块、海月的幻境边缘都算墙体，都能上墙眩晕（BV1Bf421v7RS @ 04:14）。

## 2. 对线 / 打法

- **开局学二技能、买铁剑，提前卡兵线，一个二技能清一波兵**（BV1Bf421v7RS @ 05:45）；另一份实录是"出门铁剑，二技能打后排兵去抢二级"（BV1gK411r7T2 @ 04:45），也有开局买布甲的版本（BV14zc9zJEhj @ 00:25）。
- **抢线先蹲草等兵线上来，二技能朝后打接普攻抢二再对拼**（BV1gK411r7T2 @ 00:35）；对抗路蹲这个草，对面是边惩英雄还能反打一波（BV1gK411r7T2 @ 00:45）。
- **拿到线权不要跟有续航的狂铁浪费时间**，换血没意义，直接打小野帮打野提速（BV14zc9zJEhj @ 00:31）；但帮速刷只帮到 1 分 05 秒，再帮就要亏兵（BV14zc9zJEhj @ 00:46）。
- **卡线只卡一个兵**，卡两个扛得痛（BV14zc9zJEhj @ 01:05）。
- **按对手换第一件小件**：对面马超或坦边爆发不强，预购陨星，四级前伤害非常高（BV1gK411r7T2 @ 04:49）；对面木兰孙策这种比较刚的，先做荆棘护手（BV1gK411r7T2 @ 04:57）。
- **现版本对抗路偏"坐牢"**：对面打野多抓几次就很容易逆风，所以出肉刀打野更舒服，有专精装后抓人成功率和伤害都更稳（BV1gK411r7T2 @ 07:07、BV1gK411r7T2 @ 07:16、BV1gK411r7T2 @ 08:10）。
- **一技能抬手那一下能抢野**："等你一技能抬手的那个动作的时候，这个野怪就是我的了"（BV1HkKG69Eh5 @ 01:10）。
- **对线吕布的关键在鞋**：吕布有布甲鞋时"确实杀不了"，换抵抗鞋之前大招都开不出来（BV1HkKG69Eh5 @ 04:08、BV1HkKG69Eh5 @ 04:20）；反过来我方换抵抗鞋后"你对线打不过我了"（BV1HkKG69Eh5 @ 04:25）。吕布出了抵抗鞋就不好上墙（BV1HkKG69Eh5 @ 04:43）。
- **打团前先把视野藏好**，打的就是出其不意（BV1gK411r7T2 @ 07:58）。
- **第二段一技能要谨慎**：没位移的情况下很容易在团战里被集火（BV1Bf421v7RS @ 06:25）。
- **对面红区刷新就去蹲**：假装往右、实际往左，直接进红区找打野，蹲草别动（BV1HkKG69Eh5 @ 06:27、BV1HkKG69Eh5 @ 06:35）。

- **后摇缓存的坑**：132 里大招按了却只出二技能、123 里二技能按了打不出来，原因是手速太快连拖两个技能，第二个被第三个覆盖；解决办法是手速慢一点（BV11tAqzzEsw @ 03:53、BV11tAqzzEsw @ 04:12）。反向利用：一技能过程中先拖大招、后拖闪现，闪现不算技能不会被吞，可以做到闪现后第一时间接大，"一大闪"比一闪大踢得更快（BV11tAqzzEsw @ 04:18、BV11tAqzzEsw @ 04:37）。

## 4. 中后期 / 节奏

- **前期收益结构**：一波兵线 + 一组野怪（BV14zc9zJEhj @ 00:19）；3 分 50 多秒做到"一件成装+一件鞋子"就是前期达标的标志（BV14zc9zJEhj @ 04:15）。
- **中期**：看小地图，避开对面打野去带另一边半区的边线；边线带不了就跟队友抢中线，再回边路清后手线（BV14zc9zJEhj @ 03:56、BV14zc9zJEhj @ 04:02）。
- **后期**：抱团打半图，大顺风直接接 5V5，不必靠带线做人数差——带线交给打野（BV14zc9zJEhj @ 07:35、BV14zc9zJEhj @ 07:44）。
- **出全肉就当好前排**：经济全让给队友，自己正面开团、拆火、给控制、给视野（BV14zc9zJEhj @ 07:10、BV14zc9zJEhj @ 07:13）。
- **开团的判断标准**：身边有队友、开的不是前排，就不要犹豫（BV1gK411r7T2 @ 07:52）。
- **打团前藏视野**是这套素材反复强调的一条（BV1gK411r7T2 @ 07:58）。
- **想打得稳就带专精装**，能大幅降低空大，而"空大对达摩真的很致命"（BV1gK411r7T2 @ 05:15、BV1gK411r7T2 @ 05:18）。
- **练法**：不需要复杂连招，去训练营专练一闪、一闪接大招，多找角度把手感练上来（BV1gK411r7T2 @ 08:22、BV1gK411r7T2 @ 08:26）。
