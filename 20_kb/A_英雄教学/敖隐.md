# 敖隐：技能型射手，伤害要"拆开打"

> 只讲英雄本身。分路思路见 `L_分路/03_发育路.md`。
> 素材：阿良《敖隐 1800 以下全局思路》（BV1ngLQ6HED4）、白《12 分钟敖隐篇全局精讲》（BV11SJt63EqT）、小石头《零基础精通敖隐》（BV1iPG16nEuD）。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 中期（有了无尽之后，3/4 血就是斩杀线；三件套后进入强势收尾） |
| **节奏职责** | **跟节奏**——有大招才有独立处理边线的能力，没大招老实跟团 |
| **一句话** | **三个技能拆开放，大招是保命不是开团** |
| **依据** | BV1ngLQ6HED4 @ 03:21（无尽后斩杀线 3/4 血）、@ 06:58（有大招才能单吃边线）、@ 09:28（大招主要用来跑路） |

## 1. 机制内核：技能型射手，站撸必死

- **二技能回血也回蓝**（@ 02:20）→ 这是他对线期不缺蓝、能持续换血的原因
- **强化水龙魂 = 回状态**：状态不好就用它回血回蓝（@ 02:09）
- **火龙魂伤害最高**：所以换血连招先用火龙魂那一下
- **三技能的 3A 是小控制**，专门克刺客/战士类打野（@ 07:34）
- **大招期间获得移速/射程加成**（@ 09:28）→ 所以大招不只是跑，还是"边跑边打"

## 2. 对线：EA 抽状态，被强辅助针对就换打法

- **一级公式**：EA 抽一下对面状态然后后撤（@ 00:37、@ 00:49）
- **遇到一级强的辅助（墨子、盾山、少司缘）不适用这套**，会被反压（@ 00:49）
- **一打一看三段**：一级劣势、二级均势、三级大优势（@ 00:00）
- **换血用 1A3A**：火龙魂打伤害 + 水龙魂回血，一次换血同时赚伤害和血量（@ 02:33、@ 02:45）
- **兵线被辅助推进去了就卡不住**——这是中低分段常态，别怪自己（@ 03:12）

## 3. 连招：技能拆开、中间插普攻

```
对拼：1A → 等 CD → 2A → 3A（每段之间穿插普攻）
```
- 原话："三个技能拆开放，在连招之中穿插普通攻击"（@ 03:33）
- **伤害打满的关键是"不要一次交完"**，每段之间要有平A
- 3/4 血是斩杀线（做出无尽后），到这个血量可以直接往前顶（@ 03:21）

## 4. 中后期：清边转中，抽前排不追脆皮

- **有大招 → 优势定位**：可以一个人吃边线，经济最高（@ 06:58）
- 循环：**吃边线 → 转中，中没线就吃野怪**（@ 07:12）
- **10 分钟前的任务是刷出三件套**，没三件套别去带线（@ 08:16）
- 后期**只抽前排状态**，不追脆皮（后期射手有名刀，一套秒不掉，@ 12:08）
- **大后期最忌连续掉点**：一个人掉点，队友去救，然后全崩（@ 11:19）

## 5. 细节：两个必须记住的对位处理

- **打玄策往侧面躲钩**：不要直线后退，他二技能有身后判定（@ 01:45、@ 06:12）
- **打婉儿注意二技能回笔**：回笔碰到一技能的笔墨会爆炸，要往上拉（@ 01:25）

## 6. 弱点

1. **没技能时不能站撸**（@ 01:13）——技能型射手的通病
2. **一级怕强辅助**：墨子/盾山/少司缘这类一级压制型，EA 套路失效
3. **大招是唯一保命牌**，交掉之后的 20 秒内极脆
