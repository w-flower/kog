## 1. 机制内核

1. **被动：身后必暴击，正面必不暴击**（BV1bA41147mn @ 00:18~00:22）
2. **"身后"的范围比想象大**：除正面外其他位置都算身后，**打侧面也必定暴击**——所以进场不要刻意绕后，"直接攻击敌人侧面"更快更安全（BV1kZPWziEXZ @ 00:28~00:37）；侧面稍靠后就算背后（BV1SX4y1c786 @ 00:37~00:48）
3. **暴击率转暴击伤害**：每 1% 暴击率转 0.5% 暴击伤害（BV1bA41147mn @ 00:22~00:28）；阿轲天生暴击效果低于其他英雄，所以铭文必须带十个无双（BV1SX4y1c786 @ 01:07~01:15）
4. **对非英雄单位伤害上限 1500**，对英雄无上限（BV1bA41147mn @ 00:31~00:40）
5. **二技能是核心**（BV1bA41147mn @ 00:51~01:18）：
   - 标记命中后自身 +40% 攻速（BV1bA41147mn @ 00:51~01:02）
   - 标记目标对阿轲造成的伤害 -30%（BV1bA41147mn @ 01:02~01:06；BV1SX4y1c786 @ 02:44）
   - 对标记目标的攻击附带减速——**两份素材数值冲突**：一份说 50%（BV1bA41147mn @ 01:09~01:18），另一份说 5%（BV1SX4y1c786 @ 02:40~02:43），实测前不要采信具体数字
   - 只要敌人在指示器范围内，二技能**必定到身后且暴击**（BV1kZPWziEXZ @ 00:49~00:55；BV1SX4y1c786 @ 00:55~01:04）
6. **二技能是"瞬移"而非位移**：从 A 点直接到 B 点，中间没有单位和碰撞体积，可无伤穿过李白二技能圈、张良一技能墙、墨子的炮、安琪拉的火球（BV1kZPWziEXZ @ 00:56~01:16；BV1SX4y1c786 @ 02:49~03:00）
7. **一技能**：移动中可以释放，相当于两下平 A、略高于平 A（BV1bA41147mn @ 00:42~00:49）；两次攻击之间有间隔（BV1kZPWziEXZ @ 02:10~02:13）；可触发冰痕/宗师被动（BV1kZPWziEXZ @ 02:00~02:08）；可对塔生效——前提是塔下有小兵或敌方英雄（BV1kZPWziEXZ @ 02:34~02:47；BV1SX4y1c786 @ 01:47~02:00）
8. **一技能的隔空打人**：贴脸打第一个敌人时，若目标身后两身位内还有第二个敌人，且三者在同一直线，一技能伤害和宗师/冰痕被动会同步打到后面那个（BV1kZPWziEXZ @ 02:49~03:13）；普攻也具备同样效果（BV1kZPWziEXZ @ 03:16~03:21）
9. **大招**：隐身 + 回血 + 加速，破隐后 3 秒攻击加成（BV1bA41147mn @ 01:22~01:29）；学了大招后**击杀或助攻立刻刷新所有技能**（BV1kZPWziEXZ @ 03:21~03:30）；刷新后大招提供 160 攻击力（BV1kZPWziEXZ @ 03:50~03:55）
10. **大招影子**：隐身后每 0.5 秒在路径上产生一道影子，总共六次（BV1kZPWziEXZ @ 01:28~01:40；BV1SX4y1c786 @ 03:17~03:27）——影子会暴露位置
11. **大招起跳瞬间不隐身，落地后才隐身**（BV1kZPWziEXZ @ 04:16~04:21）；释放可被控制打断（BV1bA41147mn @ 01:32~01:38）
12. **对野怪暴击有上限**，所以不太吃打龙后的羁绊，适合开双龙（BV1SX4y1c786 @ 01:16~01:25）

## 2. 对线 / 打法

- **刷野要打背刺**：Buff 刷新后第一时间二技能突刺到 Buff 身后，立刻回头往外走，A 两下后 Buff 回头，你再正身往前——这样百分百暴击（BV1SX4y1c786 @ 01:28~01:39）；练熟 55 秒出蓝区（BV1SX4y1c786 @ 01:43~01:45）
- **二技能不要对着"屁股"直放**：对手背对你时直放伤害会低一截，正确做法是往左右两边拉（BV1SX4y1c786 @ 02:09~02:28）
- **蓝开为主**，因为蓝开减 CD（BV1SX4y1c786 @ 05:41~05:44）；主一、有大点大（BV1SX4y1c786 @ 05:40）
- **尽量后选**；对面选前期强势打野也不是完全守不了——野区有守护之灵，加上二技能命中后的免伤，"其实我们还是比较肉的"（BV1SX4y1c786 @ 05:45~06:00）；镜、老虎这类前期很难快速秒掉阿轲，但前提是自家中路/辅助/边路不差太多（BV1SX4y1c786 @ 06:03~06:10）
- **河蟹看阵容**：真不能拿大概率就不拿（BV1SX4y1c786 @ 06:12~06:15）
- **第一波 GANK 大概率抓对抗路**，多注意己方辅助位置或猜对面打野位置（BV1SX4y1c786 @ 06:16~06:22）
- **前期少抓中**：伤害不够、中路线短、逃生位置多、容易被支援（BV1SX4y1c786 @ 06:22~06:28）
- **经济是命门**："阿轲一定要多注意自身经济的补充，能控则控"；很多阿轲发育不起来就是"太频繁的去抓人，忽视了控龙和刷野"（BV1SX4y1c786 @ 06:29~06:40）
- **抓刘邦**：他没四级可以 GANK 一波，有四级直接走（BV1jM411J7uU @ 02:11~02:15）
- **经济分档**（分均）：达不到 800 很难带飞；700 勉强顺风；10 分钟 7000 是顺风、8000 小优、9000 除防装外都能随便杀、分均 1 万"在你面前都没有坦克"（BV1jM411J7uU @ 00:01~00:44）

## 3. 连招

核心是"一秒五刀"，所有变体都在这个骨架上换顺序。

| 场景 | 连招 | 依据 |
|---|---|---|
| 近距离爆发（一秒五刀） | **3A12A**：大招靠近 → 普攻起手 → 一技能取消普攻后摇 → 秒接二技能取消一后摇 → 再 A 取消二后摇 | （BV1kZPWziEXZ @ 04:37~04:46） |
| 远距离突进 | **32A1A**：大招 → 二技能光速突脸 → A → 一 → A | （BV1kZPWziEXZ @ 04:48~04:53） |
| 隐身近身 | **A12A**：一技能可取消平 A 后摇；隐身接近时对手会回头，这时接二能到身后再暴击 | （BV1SX4y1c786 @ 04:49~05:00） |
| 对手有位移/闪现 | 先打 **A1**，等他位移后再跟二 | （BV1SX4y1c786 @ 05:02~05:08） |
| 打无位移/战士 | **2A1A**，同样一秒五刀，还能减二技能 CD（后期 2A 打完下一个二就好了） | （BV1SX4y1c786 @ 05:10~05:20） |
| 蹲草（对手脸探草） | **1A2** | （BV1SX4y1c786 @ 05:28~05:30） |

- **先不交大**是蹲草默认：留着逃生，或对面位移逃了再开大追（BV1SX4y1c786 @ 05:35~05:38）
- **打 2A1 时一技能不要乱按**，原素材说会导致"吞刀"，但句子里缺了具体动作，需实测（BV1SX4y1c786 @ 05:22~05:25）

## 4. 中后期 / 节奏

- **影子管理是第一优先级**：从对手视野盲区进，接近后"等我们的影子跳了一次，以后下次跳跃之前直接二技能切入"，让影子少跳（BV1SX4y1c786 @ 03:36~03:47）
- **卡第二道影子**：在第二道影子即将产生的瞬间接二技能位移，把影子藏掉，"敌方视角就是上一秒很远的距离有一个残影，下一秒就被瞬间突脸"（BV1kZPWziEXZ @ 01:42~01:56）
- **别在草里起跳**："抓人时千万不要直接在草丛里大招跳出来，这样视野必露"，要先在草里跳完再出草（BV1kZPWziEXZ @ 04:16~04:29）
- **大招可隐身进塔边草**，小地图也看不到，用来秒中路脆皮（BV1kZPWziEXZ @ 03:56~04:02）
- **隐身接惩戒不破隐，但会显形 1 秒**：可以先开大隐身抢龙，再借加速和二技能撤（BV1kZPWziEXZ @ 04:03~04:15）
- **中路右下角视野小**，从这个角度进场 GANK，对手几乎看不到影子跳动（BV1SX4y1c786 @ 04:08~04:26）
- **走位要多歪多扭**，让对手误判真实位置（BV1SX4y1c786 @ 04:32~04:40）
- **后期反甲处理**：对面出了反甲，先手开他会掉血线、掉完就不具备切 C 能力；要么先切 C 再用吸血刀/末世处理他（BV1jM411J7uU @ 01:16~01:44）
- **不要双无尽**：伤害越高反甲反得越多，"本来反2000，买把无尽反4000"（BV1jM411J7uU @ 02:53~03:38）
- **打不动就补碎星锤**（BV1jM411J7uU @ 07:35~07:36）；对面是闪现蒙犽这类不好切的，就先抓落单的（BV1jM411J7uU @ 07:48、BV1jM411J7uU @ 10:08~10:10）
