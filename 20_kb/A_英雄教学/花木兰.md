# 花木兰：熬过四级前的弱势，用经济把对面碾死

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：五尖枪《边路教学第十八期——花木兰(3)篇》（BV1ENNMzSEmR，前期抗压/刷钱/节奏全局思路）、绿绿国一木兰《花木兰对线曹操 16.0 评分全局》（BV1p7FrekE3S，对线细节与连招实录）。

| **节奏职责** | **发育型战边，首要思路是提高经济**（@ 02:54~02:59）——靠过线快做中边两路转线刷钱（@ 02:47~02:53） |

## 1. 机制内核

1. **四级是强度分水岭**：四级前弱势，四级后可用小规模团战优势打开突破口（@ 02:26~02:36）
2. **过线速度快**是转线刷经济的本钱：三角资源法 + 中边两路转 + 偶尔蹭打野的野怪，经济就提上去了（@ 02:44~02:53）
3. **二闪是现版本主流**：现在的二闪比对面的二一闪、以前的一闪 21A 更稳定且不易失误，但每种对局情况不同，按实际情况用（@ 03:09~03:18）
4. **轻剑 1A2 起手**：实录连段"1A2，中间推开一下，蓄力拍一下，减速一下"（BV1p7FrekE3S @ 05:54~06:01）；重剑跟"平 A 推推再蓄力拍一下"（@ 06:03~06:08）
5. **大招 CD 快好了再转**："等大招 CD 快好了然后再转"，不要急着交（@ 05:03~05:06）

## 2. 对线

- **兵线卡在塔前度过四级**：打野不开对抗路时，把兵线卡塔前不好刀，让你安稳到四级，遇到急性子的还能反打反杀（BV1ENNMzSEmR @ 01:56~02:03）
- **河灵时间差**：中野来抢资源时快速过线打河灵——对面边惩来抢就漏兵，不来抢的话他出完野刀打兵线伤害很低，你有足够时间抢下河灵（@ 02:06~02:20）
- **对面选边惩坦克针对你**：第一时间召唤打野一起拿小鸟，高分段打野自己就会心领神会（@ 00:28~00:48）
- **开局必看面板**：现在打野出野区点基本是抓对抗路，第一时间看对面打野有没有到四级（@ 01:25~01:33）
- **经济压制后不怕边惩**：前期出完陨星、经济压制后可以强行打他血线然后拿资源（@ 03:31~03:38）
- **卡线抓惩戒**：对面为跑路交了惩戒、后排两兵残血时，就去卡他的线（@ 03:47~03:53）
- **对线曹操实录**（BV1p7FrekE3S）：卡他第一个兵——"他只要想过来吃第一个兵，那他就死定了"（@ 01:15~01:19）；吃完这波线他的猪就刷新了，直接反野，猪没刷就反红（@ 01:37~01:51）；先把他大招骗出来，下波再杀（@ 02:23~02:25）

## 4. 中后期/节奏

- **4 分钟龙点是特殊团**：不许贪线贪发育，必须过去支援，否则全局崩盘（BV1ENNMzSEmR @ 04:22~04:31）
- **半靠站位**：踩在中轴，可以快速转上下两路；队友打赢且有进红趋向就赶紧去红区支援（@ 04:47~05:06）
- **支援有效果 → 反野双倍经济**：红区归我们管后反掉对面野区经济，"既能让对面亏钱又能让自己赚钱"（@ 05:31~05:44）
- **连续带两波上路兵线再转下**：对面复活要管你带过的线，你去别的路就形成人数差，优势一点点扩大（@ 05:47~06:03）
- **打团抓机会有底线**：差个闪现就走，不强行接（@ 06:30~06:32）；反 Buff 带线按这套打就是一号位经济（@ 06:38~06:43）
- **压高地之前一定要打龙**："不管什么局，在你压高地之前一定要打龙，只会一味的无脑压经济活该被翻盘"（@ 07:00~07:08）；双龙一开、突破口一找到游戏就结束（@ 07:16~07:19）
- 切射手的同时顺便给队友拆火（@ 07:31~07:35）
