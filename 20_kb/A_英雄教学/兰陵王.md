# 兰陵王：暗影里的倒计时，抓对人比连招更值钱

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：单份新手向教学口播（BV1bm421L7Ma），按出装—选人—开局—抓人—连招—中期—后期的顺序讲，中间夹着实机片段。
> ⚠️ 只有单份素材，无对局数据、无技能数值；出装只讲件序，铭文只给两套取向、没给具体铭文名。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 前期——"兰陵王是一个倒计时英雄，他越到后期越没用"（BV1bm421L7Ma @ 08:58~09:00）；前期"本身伤害就很高，不太依赖装备"（BV1bm421L7Ma @ 02:52~02:54） |
| **节奏职责** | **游走抓人**：隐身之后"跑的比较快，你可以全地图抓人"（BV1bm421L7Ma @ 03:08~03:11） |
| **一句话** | 兰陵王是一个倒计时英雄，越到后期越没用 |
| **依据** | 抓人成功率高于其他打野、收益更大，而持续伤害低（清兵、打野、打龙都慢），所以时间该花在抓人而不是刷经济（BV1bm421L7Ma @ 02:55~03:11） |

## 1. 机制内核

1. **破隐三秒攻速**：解除隐身之后三秒内攻速增加，下方图标就是攻速效果（BV1bm421L7Ma @ 02:17~02:24）；图标转到半圈时再点一次隐身，上一段攻速刚结束、下一段破隐刚好接上，可以无缝续攻速（BV1bm421L7Ma @ 02:24~02:36）
2. **二技能标记**：标记到敌人后，对其普攻或放技能都能造成眩晕并给自己回血（BV1bm421L7Ma @ 07:09~07:16）
3. **二技能只命中第一个英雄**：飞镖能穿小兵和野怪，但打中英雄就停下，性质与安琪拉一技能一样，被辅助挡掉后后续连招可能打不死人（BV1bm421L7Ma @ 07:35~07:46）
4. **多次回血**：标记多个敌人后分多次打出眩晕可以触发多次回血；一次攻击把所有单位的眩晕都打出来，只回一次（BV1bm421L7Ma @ 07:56~08:08）
5. **二技能爆炸破隐**：二技能爆炸会解除隐身，所以放完二技能想跑，最好估着还差一秒爆炸时再开隐身，否则刚隐身就又显形（BV1bm421L7Ma @ 08:11~08:32）
6. **大招范围大于位移**：一旦放大招就解除隐身，而大招的伤害范围比位移距离更远（BV1bm421L7Ma @ 06:03~06:11、06:27~06:32）
7. **探草**：脚底下出现加速标志，就代表前面的草丛里有人（BV1bm421L7Ma @ 13:39~13:47）

| **选人** | 能禁英雄时优先禁蔡文姬，其次李元芳和百里守约；其他的没必要 | BV1bm421L7Ma @ 01:37~01:45 |
| **开局** | 出生第一时间点隐身，打蓝打红都可以，靠破隐攻速打完 Buff | BV1bm421L7Ma @ 02:13~02:36 |

| **抓人实例** | 本已从下路走到中路准备打蓝 Buff，看到对面下路二人组打得很激进，果断转头回下路，靠稳定控制与伤害拿下人头 | BV1bm421L7Ma @ 03:24~03:36 |
| **避战：以一敌二** | 打野位擅长的单体爆发、不擅长对群，以少敌多顶多杀一个，伤害分摊到多人身上可能一个都杀不掉 | BV1bm421L7Ma @ 03:38~04:05 |
| **避战：不跟对面打野单挑** | 单挑能打过的打野"极其的少"，要做的是偷袭残血或脆皮，不在正面战场硬刚 | BV1bm421L7Ma @ 04:05~04:23 |
| **避战：不打肉盾** | 清兵打野慢 + 大招 CD 长，打肉盾打不死，等于把时间和技能浪费掉，是收益最低的打法 | BV1bm421L7Ma @ 04:25~04:38 |
| **软柿子法则** | 谁一抓一个准就反复抓他；抓了两次都抓不死，说明这个人会玩，就不抓 | BV1bm421L7Ma @ 04:40~04:57 |
| **心理战** | 隐身快结束时就近找草丛蹲下，对面看不到感叹号就想象不到你在草里，这时候一套 231 成功率相当高 | BV1bm421L7Ma @ 06:41~07:03 |

## 3. 连招

| 场景 | 连招 | 依据 |
|---|---|---|
| **最稳妥（贴身）** | 走到敌人身边 → 二技能挂标记 → **普攻**打出眩晕 → 接一三技能打伤害的同时拉开距离 | BV1bm421L7Ma @ 05:18~05:26 |
| **出其不意** | 231：感叹号刚亮，人已经贴到脸上，低分段很多玩家反应不过来 | BV1bm421L7Ma @ 05:44~06:01 |
| **收残血** | 32：直接大招扑过去，再接二技能；对方血量低、不太缺伤害又赶时间时用 | BV1bm421L7Ma @ 06:16~06:35 |
| **后期有冰甲** | 先贴身 → 冰甲定住 → 再放技能，绕开"飞镖可能空"和"进场被控"两个问题 | BV1bm421L7Ma @ 11:01~11:16 |
| **团战摸后排** | 隐身绕后，等队友跟对面打起来，找战场最外围的人，一套 213 收掉后跑路 | BV1bm421L7Ma @ 10:08~10:33 |
| **抢龙** | 龙剩 1 万血左右时 231 接惩击 | BV1bm421L7Ma @ 13:24~13:28 |

- **231 的风险**：不管有没有打到人，只要放大招就解除隐身，二技能空了就可能回不来（BV1bm421L7Ma @ 06:03~06:15）
- **二技能空了**：第一时间不会显形，直接走就行（BV1bm421L7Ma @ 05:36~05:42）

## 4. 中后期 / 节奏

- **中期的判定**：边路没人清兵线、射手和辅助都聚在中路打架，就是中期（BV1bm421L7Ma @ 08:39~08:50）
- **顺风 / 均势**：赶紧推塔，想办法破掉中路一塔二塔（BV1bm421L7Ma @ 08:51~08:55）；但不要冒进——这时候脆皮开始抱团，杀掉一个也容易被剩下的人集火，顺风局死一次对面经济就追上来一大截（BV1bm421L7Ma @ 09:03~09:14）
- **逆风**：尽量避战，去边路带线；有人来抓就大招拉距离 + 隐身跑路（BV1bm421L7Ma @ 09:17~09:26）。跑法是先往一个方向跑，进隐身之后立马掉头；追的人也回头，就再来一个 90 度转弯（BV1bm421L7Ma @ 09:27~09:43）
- **团战不能先手**：隐身摸到敌人身边、一套二一再用三技能撤出来的想法"千万不要有"，因为很容易死；正确顺序是隐身绕到后方，等队友开打，再收战场最外围的人（BV1bm421L7Ma @ 09:52~10:33）
- **后期（冰甲到手）**：射手法师三四个大件、打野接近六神，兰陵王会穷一点，但此时冰甲通常已经到手（素材原话"我相信你一定已经买出了那件装备"），进场方式随之改变（BV1bm421L7Ma @ 10:44~11:16）
- **后期伏击**：防御塔推得差不多、战线拉长后，可以在敌方脆皮从泉水复活赶往前线的路上伏击，直接在家门口截杀（BV1bm421L7Ma @ 11:20~11:36）
- **推高地**：一进塔就会被防御塔照出来，能做的是站在塔外围，看谁位置靠前就 231 摸奖；最好有队友先吸引塔的仇恨（BV1bm421L7Ma @ 11:44~12:07）。对面不敢靠前或二技能空了，就用破隐的三秒攻速跟队友一起拆塔（BV1bm421L7Ma @ 12:10~12:16）
- **守高地**：刺客不擅长守家，靠隐身绕到敌人后方不停亮感叹号施压，找配合机会，或者去断对面下一波兵线（BV1bm421L7Ma @ 12:18~12:33）
- **大后期**：所有人六神后是兰陵王最难打的时候，对面抱团紧就一点机会都没有；只能等队友先手吸引注意力再摸脆皮，能一换一就是赚（BV1bm421L7Ma @ 12:39~13:01）
- **风暴龙王**：敌方拿了龙王后，闪电能劈到隐身的兰陵王——不会显形，但会暴露位置（BV1bm421L7Ma @ 13:02~13:15）；反过来兰陵王抢龙很容易，爆发高，成功率在 70% 左右（BV1bm421L7Ma @ 13:18~13:30）

## 5. 出装铭文

**出装顺序**（BV1bm421L7Ma @ 00:48~00:56）：

1. 小的红色打野刀
2. 抵抗鞋
3. 暗影战斧
4. 升级打野刀

- 讲者称这三件是"几乎每一个刺客或者战士型打野都可以"的起手（BV1bm421L7Ma @ 00:56~01:01）
- **第四件冰霜冲击（冰甲）**：可以让周围敌人眩晕接近一秒，是这套方案的关键件（BV1bm421L7Ma @ 01:01~01:09）
- 第五件破军补伤害，第六件名刀司命，确保进场后在被打死之前把伤害打出来（BV1bm421L7Ma @ 01:10~01:17）
- 这套只有三件攻击装，"但是伤害是完全够的"；不够就把名刀司命换成碎星锤（BV1bm421L7Ma @ 01:20~01:29）

**铭文**：两套可选——"战刺穿透攻速"或"战刺穿透攻击"（BV1bm421L7Ma @ 01:47~01:51）。讲者更偏向攻速：攻击提高的是爆发伤害，攻速提高的是持续伤害，而兰陵王清兵打野偏慢，补攻速才不至于打得很痛苦（BV1bm421L7Ma @ 01:54~02:08）。
