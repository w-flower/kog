## 1. 机制内核

1. **四个能量格**：血条下方两个黄格代表两次一技能、两个蓝格代表两次二技能，一般一二技能各存两次（BV1BZ421N7kX @ 00:48~01:03；BV1b24y1w7H4 @ 01:11~01:27）
2. **一技能 = 位移 + 拉人**：跑步向前，把扇形范围内敌人拉到自己身前（BV1b24y1w7H4 @ 00:21~00:27）；可自动锁定草丛里甚至隐身的单位（BV1b24y1w7H4 @ 00:34~00:39）；最远拖拽距离约为指示器 1.5 倍（BV1b24y1w7H4 @ 00:47~00:49）；**不能穿墙**（BV1BZ421N7kX @ 01:13~01:16）
3. **二技能 = 翻跟头**：位移 + 霸体 + 回血 + 免伤 30%，**可以穿墙**（BV1BZ421N7kX @ 01:07~01:09、BV1BZ421N7kX @ 01:13~01:16）
4. **组合技窗口只有 1 秒**：用一或二之后 1 秒内接一或二才出组合技，放晚了就是两个普通技能（BV1BZ421N7kX @ 01:19~01:28）
5. **四套组合技**（BV1b24y1w7H4 @ 01:41~02:25）：
   - **一一**：拉人后腾空跃起，落地 1 秒范围击飞，中心圈多一半伤害，附带敌方最大生命值 8% 伤害（BV1b24y1w7H4 @ 01:41~01:53）
   - **一二**：拳脚连用，最后一下飞踢附带敌方最大生命值 12% 伤害并回血（BV1b24y1w7H4 @ 01:57~02:09）
   - **二二**：跳空中无法被选中，回复自身 15% 已损生命值，期间可拖左轮盘选落点（BV1b24y1w7H4 @ 02:10~02:25）
   - **二一**：跳到敌人身后回旋踢，附带目标已损生命值 18% 斩杀伤害；击杀后回血并返还半个二技能（BV1b24y1w7H4 @ 02:27~02:44；BV1BZ421N7kX @ 01:41~01:51）
6. **回旋踢方向可控**：核心是"你站在敌人的哪边就会把敌人往哪边踢"（BV1b24y1w7H4 @ 02:55~03:01）；踢的距离不受抵抗鞋影响（BV1b24y1w7H4 @ 02:46~02:51）
7. **强化组合技**：每打完一套，脚底出一个被动，其他三个组合技变强化，属性延长 25%（BV1cN786PEnS @ 05:54~06:09）
8. **强化双 E 落地触发扫堂腿**，多一段伤害；无控时自动放，拖左轮盘可以放更快，即"卡双 A"（BV1cN786PEnS @ 06:11~06:28）
9. **强化二一斩杀收益更高**：素材称强化二一踢死时能量回复明显多于普通二一（BV1cN786PEnS @ 07:14~07:26）；团战多拿强化二一收割才能持续游龙（BV1cN786PEnS @ 07:27~07:29）
10. **大招**：自带疾跑效果，立刻获得一二技能各一个并把存储上限提到 3，对附近敌人造成伤害（BV1BZ421N7kX @ 02:00~02:09）；持续 10 秒、+20% 移速、减 50% 减速效果（BV1b24y1w7H4 @ 03:58~04:03）；开启瞬间能量条蓄满一层（BV1b24y1w7H4 @ 03:53~03:55）；有大招可连打六次组合技（BV1b24y1w7H4 @ 04:06~04:08）
11. **强化技能无法空放**，必须有敌方单位；且强化技能都带一小段位移，可穿很多墙（BV1b24y1w7H4 @ 03:26~03:35）
12. **免伤上限 90%**："因为免伤的上限是90"（BV1vJ4m1s7he @ 09:06~09:10）
13. **摸鱼状态**：能量回复速率 +25%，并随机回血（BV1b24y1w7H4 @ 04:49~04:55）

## 2. 对线 / 打法

- **清线刷野先用一技能聚怪**："先用一技能把多个单位聚集到一起，这样能更快发育"（BV1b24y1w7H4 @ 00:27~00:32）
- **对老夫子**：他不出来清线就直接过线升二，回去打野区里的野怪；他出来抢线权就打他状态（BV1oTWGzzEsz @ 00:26~00:33）
- **打老夫子要控住他的被动**："他被动叠满了有免伤了，我们就控他，让他的免伤续不起来"（BV1oTWGzzEsz @ 00:35~00:40）
- **抢二判断**：打前面两个小兵能升二，看小兵状态决定是否压上去（BV1oTWGzzEsz @ 00:41~00:52）
- **对坦边（白起/廉颇/夏侯惇）快速过线去支援**，别被消耗太多血量（BV1BZ421N7kX @ 04:11~04:17）
- **对爆发型（元歌/花木兰/蒙恬）先出荆棘护手 + 护甲鞋过渡**（BV1cN786PEnS @ 03:45~03:55）
- **4 分钟前打得过就吃野怪刷经济，不要老想着支援**；清完线没野怪再转中路或传送阵（BV1BZ421N7kX @ 03:59~04:07）
- **前期用 1A2**（一二之间平 A 一下）把伤害打满（BV1BZ421N7kX @ 02:58~03:03）
- **打爆发阵容带弱化**："打对面这种爆发型阵容，你带个弱化"（BV1vJ4m1s7he @ 06:37~06:39）
- **没大招别硬找李信**："咱们有大招的时候去找这李信玩就可以了，没大招的情况下就算了"（BV1vJ4m1s7he @ 02:31~02:33）
- **被姬小满盯上很难跑**（BV1oTWGzzEsz @ 03:29~03:31）
- **打出的节奏要立刻回线**，靠一技能加速 + 二技能位移，吃完中路兵回线上兵线一个不掉（BV1oTWGzzEsz @ 01:30~01:44）
- **优先吃传送之灵/传送阵**（BV1oTWGzzEsz @ 01:12；BV1oTWGzzEsz @ 04:06）
- **压高地先压边路**："你压高地时要先压边路不要先压中路，先压边路才能有兵线牵制"（BV1vJ4m1s7he @ 13:42~13:48）；因为对面清线习惯先清中路，边路就没技能守了（BV1vJ4m1s7he @ 13:59~14:09）

- **新手底线**：打完一套"留一个二二技能"方便撤离（BV1cN786PEnS @ 09:45~09:50）

## 5. 出装铭文

**铭文**
- 十隐匿、十鹰眼、九异变 + 一祸源；不需要 1.6% 运气暴击就换十异变（BV1cN786PEnS @ 00:17~00:26）
- 另一份给十隐匿、十鹰眼、十异变（BV1BZ421N7kX @ 00:39~00:40）

**第一套（新手/低分，容错高）**
- 两把铁剑（前期打河蟹省一段平 A）→ 冷静靴 → 暗影战斧 → 雪山圆盾 → 苍穹 → 破魔刀 → 冰心 → 碎星锤 → 复活甲/名刀（BV1cN786PEnS @ 00:28~02:30）
- 雪山圆盾 + 战斧 10CD + 苍穹 10CD，"大概6分钟左右CD就满了"（BV1cN786PEnS @ 00:40~00:51）
- 冰心 20CD，且"别人打你会减速"，利于拉扯（BV1cN786PEnS @ 01:44~01:56）
- 冷静靴后期换掉：控制多出抵抗鞋，控制少出护甲鞋（BV1cN786PEnS @ 01:59~02:05）
- 大后期伤害不够把鞋换破军，苍穹换复活甲换名刀（BV1cN786PEnS @ 02:23~02:30）

**破魔刀的判断**
- 对面超过三个及以上位置带法伤、且会玩、威胁大，局势均势或劣势时，**先破魔刀再苍穹**（BV1cN786PEnS @ 01:09~01:33）
- 理由是"不然你就会发现对面经济如果刷起来了，你根本挡不住对面的法术伤害"（BV1cN786PEnS @ 01:33~01:36）

**第二套（对线压力大）**
- 荆棘护手 + 护甲鞋 → 暗影战斧 → 苍穹 → 法伤高出破魔刀 / 对面做肉快先碎星锤 → 破军 → 冰脉或名刀 + 碎星锤（BV1cN786PEnS @ 03:45~04:21）

**破军的取舍**
- 全国 1 万名以内基本先出破军，高分局打节奏，前期"跟对面的射手爆了一换一"（BV1cN786PEnS @ 02:50~03:09）
- 1 万名以外第一套容错更高：CD 更快、更肉、"少出一件破军就等于多出了两件防御装备"（BV1cN786PEnS @ 03:10~03:24）
- "不要看国服榜上都是出的破军"——手法和进场能力不是同一回事（BV1cN786PEnS @ 03:29~03:43）

**其他散点**
- 陨星 → 冷静鞋 → 暗影战斧 → 荆棘护手 → 纯净苍穹 → 冰痕之握；法伤高先不死鸟，坦克多先碎星锤；10 分钟或满 40CD 换抵抗鞋；大后期冰痕换复活甲（BV1BZ421N7kX @ 00:21~00:36）
- 优势出完暗影战斧直接苍穹，劣势先荆棘护手过渡（BV1oTWGzzEsz @ 03:05~03:11）
- 对面不肉不用先出碎星锤，先爆裂（BV1vJ4m1s7he @ 07:41~07:45）
- 操作设置：打开"绝对血量"，残血 R1 飞踢能自动锁定（BV1cN786PEnS @ 05:17~05:22）
