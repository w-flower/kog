# 司马懿：先把野区吃成自己的，再决定要不要进场

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：王者营地《国服教学大全·江权巅峰前百司马懿第一视角复盘》（BV1D9vAziEZ7，**国服司马懿打野视角**，偏运营与决策复盘）；爱鸽 manaka《会玩的司马懿，不比阿古朵差》（BV1kG4x65E8L，**阿古朵玩家对位司马懿的视角**，非司马懿教学，只能从对手反应反推司马懿行为）。

## 1. 机制内核

1. **主要输出是强普，不是技能本身**："司马懿主要使用强普输出"，红 Buff 还能提升普攻伤害、加快刷野（BV1D9vAziEZ7 @ 00:55）（BV1D9vAziEZ7 @ 00:57）。所以他的伤害节奏是"技能位移 → 贴脸 → 强普"，而不是站桩放技能。
2. **技能可以当赶路用，这是新版的分水岭**："新版司马懿不再依赖能量，可以自由释放技能，用于赶路，吃掉更多资源"（BV1D9vAziEZ7 @ 02:20）（BV1D9vAziEZ7 @ 02:22）；总结第一条也是"多用技能配合强普以及大招去赶路"（BV1D9vAziEZ7 @ 05:04）。
3. **被动是"反侦测雷达"**："他是周围谁放技能，获取谁的视野"（BV1kG4x65E8L @ 03:58）（BV1kG4x65E8L @ 03:59）。这条有两面：既能让司马懿知道对面在哪，也意味着**对手不放技能就看不见他**——B 源玩家正是靠"在草里没放技能"躲开的（BV1kG4x65E8L @ 04:01）（BV1kG4x65E8L @ 04:03）。
4. **大招是位移 + 落点预判**："司马懿的大招落点正是孙权的撤退路线"，"这样做敌方想走就会被司马懿黏住"（BV1D9vAziEZ7 @ 02:33）（BV1D9vAziEZ7 @ 02:36）。
5. **大招的支援速度是独一无二的**："司马懿大招的特性，让他拥有着独一无二的支援速度，可以用来保护队友，快速形成多打少的局面"（BV1D9vAziEZ7 @ 03:46）（BV1D9vAziEZ7 @ 03:51）。
6. **两刀就能蒸发脆皮**："像元歌这样的脆皮英雄，只需要两刀就会被瞬间蒸发"（BV1D9vAziEZ7 @ 04:19）（BV1D9vAziEZ7 @ 04:21）。所以他的收割门槛是"两次强普内能收掉"，超过就不该上（BV1D9vAziEZ7 @ 05:32）。
7. **清野能"拉到下一只"**："每次把野怪打成丝血，就会往下一个野怪的方向去拉"，最后一只丝血时"直接一技能灵体快速赶路"（BV1D9vAziEZ7 @ 01:06）（BV1D9vAziEZ7 @ 01:10）（BV1D9vAziEZ7 @ 01:12）。这是他把刷野速度换成节奏的核心手法。

## 2. 对线 / 打法

- **红开，且与发育路反着开**："江权选择与发育路反着开，也就是红开"（BV1D9vAziEZ7 @ 00:51）（BV1D9vAziEZ7 @ 00:52）。
- **开局先站红 Buff 后草防反野**："先到红 Buff 后草丛，防止敌方反野"，确保安全后"强普过墙直接开刷"（BV1D9vAziEZ7 @ 01:00）（BV1D9vAziEZ7 @ 01:05）。
- **前期优先抓发育路**："司马懿前期建议抓发育路，射手更脆，有利于提升抓取成功率"（BV1D9vAziEZ7 @ 00:24）（BV1D9vAziEZ7 @ 00:26）。
- **能不能自由入侵，看对面阵容**："敌方阵容整体偏脆，且没有锁定型控制，司马懿可以自由入侵和支援"（BV1D9vAziEZ7 @ 00:35）（BV1D9vAziEZ7 @ 00:38）——这是条件，不是常态。
- **抓人的三条硬判据**（以抓不知火舞为例）：敌方三人正朝塔下撤退、元歌距离较远、火舞孤立无援；加上"血量被消耗""三级没有大招、缺少控制和位移去逃生"（BV1D9vAziEZ7 @ 01:40）（BV1D9vAziEZ7 @ 01:48）（BV1D9vAziEZ7 @ 01:51）。
- **打不过也有收益**："即便没能击败，也能消耗其大量血量，干扰其发育节奏，怎么算都是赚的"（BV1D9vAziEZ7 @ 01:55）（BV1D9vAziEZ7 @ 01:58）。
- **杀了打野就接管他的野区**："击败打野，自然要接管敌方野区"，强普过墙吃蓝区，"灵体快速逃生"（BV1D9vAziEZ7 @ 02:14）（BV1D9vAziEZ7 @ 02:16）（BV1D9vAziEZ7 @ 02:19）。
- **对手视角的补充（B 源，反推）**：司马懿会"瞄着本体一个大就冲过来"，所以对位刺客要"错开刷"（BV1kG4x65E8L @ 00:40）（BV1kG4x65E8L @ 00:42）；他"进塔两刀剁死小乔，潇洒离去"，说明他抓法师的窗口极短（BV1kG4x65E8L @ 00:49）（BV1kG4x65E8L @ 00:52）。

## 4. 中后期 / 节奏

- **4 分钟龙刷新前，技能不能先交光**："即便司马懿逃生能力很强，不会阵亡，但交完技能后，就等于将暴君拱手让人"（BV1D9vAziEZ7 @ 02:52）（BV1D9vAziEZ7 @ 02:55）。所以他在 3 分 50 秒的中路抱团里"一直观望，没有开团"（BV1D9vAziEZ7 @ 02:43）（BV1D9vAziEZ7 @ 02:45）。
- **队友残血才出手**：直到队友残血，"才上前打出一发普攻，阻止敌人追击"（BV1D9vAziEZ7 @ 02:57）（BV1D9vAziEZ7 @ 02:58）。
- **拿龙靠的是对面先交技能**："敌方在试探中已经交出大量关键技能，这让我方稳稳拿下暴君"（BV1D9vAziEZ7 @ 03:04）（BV1D9vAziEZ7 @ 03:07）。
- **对面抱团过密就不要落**："此时敌方过于聚集，江权大招落地后将处于一打四的局面，容易被集火控制"（BV1D9vAziEZ7 @ 03:18）（BV1D9vAziEZ7 @ 03:22）。这是"能打"和"该打"的分界。
- **什么时候必须开大**：队友被集火、中辅状态不佳、"想要救狂铁，只能靠司马懿的大招威慑逼退敌人"（BV1D9vAziEZ7 @ 03:29）（BV1D9vAziEZ7 @ 03:33）。
- **进场的前提是对面控制交完了**："敌方云缨交出了关键控制技能，并且敌方火舞撤退，此时剩下的射辅也没有控制，让司马懿可以安心进场输出"（BV1D9vAziEZ7 @ 03:35）（BV1D9vAziEZ7 @ 03:41）。
- **经济领先之后是"资源全吃"**："快速吃掉敌方野区资源和主宰，几乎掌控了全场资源"，然后带队友前压高地（BV1D9vAziEZ7 @ 04:25）（BV1D9vAziEZ7 @ 04:29）。
- **不贸然进团是总结里的第四条**："等待我方前排开团，注意观察敌方关键控制技能的释放，确保安全后开大跟团"（BV1D9vAziEZ7 @ 05:20）（BV1D9vAziEZ7 @ 05:26）。
- **保证自身节奏、避免阵亡是第五条**："持续吃野发育，拉开经济差距"（BV1D9vAziEZ7 @ 05:28）（BV1D9vAziEZ7 @ 05:30）——司马懿的节奏是"不死 + 吃野"，不是"每波都上"。
