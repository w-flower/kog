## 1. 他靠什么强

**不是靠数值，是靠"一个人就能完成开团"这件事。**

三段普攻的第三段带击飞，二技能能把人推走或挡下技能，大招蓄力可以接闪现。四件套叠起来，苏烈不需要等队友先手——他自己就是先手。

这也是他被归为"硬辅"而不是"保护型辅助"的原因：他的价值在**制造局面**，不在**收拾局面**。

- 来源：BV1yke26fEYB @ 00:33（"我们身为可以开节奏辅助"）
- 来源：BV1yke26fEYB @ 00:20（"作为精通上手的硬辅是很不错的选择"）

## 2. 机制怎么用出来（顺序不能反）

```
第 0 步：确认被动在不在（不在 → 下面全部不成立，见 K-A04）
   ↓
第 1 步：大招蓄力起手（提前调位置，不要正面硬冲）
   ↓
第 2 步：需要贴脸就大闪（蓄力完成瞬间交闪，不是先闪再蓄）
   ↓
第 3 步：三棍打出第三段击飞（前两棍只是铺垫，第三棍才是控制）
   ↓
第 4 步：二技能收尾——推回人群 or 推开对面的反打手
```

**顺序反了就是送**：先二技能推过去再开大，人已经被推走，大招蓄力打空，你自己留在原地。

- 来源：BV1yke26fEYB @ 08:07（"准备大闪"）；BV1yke26fEYB @ 08:24（"我们果断大闪跟上"）
- 来源：BV1yke26fEYB @ 03:21（"准备斩第三棍的击飞，然后闪A接二回推"）
- 来源：BV1yke26fEYB @ 02:52（"三棍击飞接二"）

## 3. 分条说明

### K-A01 苏烈的核心是"第三棍"和"二技能"，不是大招

- **适用版本**：S45
- **触发条件**：任何需要苏烈先手的局面
- **判断依据**：对面站位是否进入三段普攻的追击距离；二技能冷却是否可用
- **决策分支**：
  - 二技能可用 → 优先用它把对面的开团手**推离**，或者把落单的人**推回**队友方向
  - 二技能不可用 → 不要用大招硬开，改打三棍逼退
- **反例**：「辅助的大招就是用来开团的」——苏烈大招蓄力期间不能动，盲目蓄力等于把自己钉在原地等人集火。
- **来源**：BV1yke26fEYB @ 02:21；BV1yke26fEYB @ 03:48
- **可信度**：中
- **状态**：active

### K-A02 二技能有两个完全不同的用途，别只用一个

- **适用版本**：S45
- **触发条件**：二技能可用时
- **判断依据**：对面有没有正在进行的位移/突进技能
- **决策分支**：
  - **挡**：对面开团手（如孙策开大）冲过来时，用二技能挡在他和自己 C 位之间
  - **推**：抓落单时把目标推向队友方向，不是推离
- **反例**：「二技能就是个位移」——它同时是**拦截**手段。挡下一次开团的价值，往往高于推一个人。
- **来源**：BV1yke26fEYB @ 03:48；BV1yke26fEYB @ 02:21
- **可信度**：中
- **状态**：active

### K-A03 被动是资源，不是保命符

- **适用版本**：S45
- **触发条件**：每次准备进场前
- **判断依据**：被动是否可用（有 / 无）；队友是否在附近能"点灯"
- **决策分支**：
  - 有被动 → 可以硬吃一波伤害，打出被动后还能给附近的双 C 回血
  - 无被动 → **不许硬接**，只能打边缘消耗
- **反例**：「我是肉辅，先冲进去扛」——没被动时苏烈就是一个普通近战，进去等于送人头。字幕里出现过"没点到灯，不然可以二技能跑"，说明**被动依赖队友点亮**，队友不在时它根本不算数。
- **来源**：BV1yke26fEYB @ 04:00；BV1yke26fEYB @ 04:14；BV1yke26fEYB @ 06:31
- **可信度**：中高（"点灯"细节来自实战解说，非二手攻略）
- **状态**：active

### K-A06 被动要主动用，别舍不得

- **触发条件**：有被动且能吃一波关键伤害
- **判断依据**：这波吃了之后，队友能不能跟着打赢
- **决策分支**：该触就触；触发后给附近双 C 回血，是团队收益
- **反例**：「留着被动保命」——原话直接说"很多苏烈会舍不得触发被动，这点是错误的"。
- **来源**：BV17Vp9zXEx2 @ 03:32
- **可信度**：高（与原 K-A03 一致，互为印证）
- **状态**：active

### K-A07 开团前必须和队友沟通好"帮你踩灯"

- **触发条件**：准备先手开团
- **判断依据**：周围有没有队友能点亮你的被动
- **决策分支**：先打字/信号确认，再开团；没人踩灯就不要主动吃伤害
- **来源**：BV17Vp9zXEx2 @ 03:07
- **可信度**：中高
- **状态**：active

## 6. 新手最容易崩在哪一步

- **在第 0 步（确认被动）上**：忘记看被动，进场被判死一次之后整局都不敢开团，从"开节奏"退化成"挂机跟团"。
- **在第 3 步（三棍）上**：打两棍就急着交二技能，第三段击飞永远打不出来——苏烈的控制全在第三棍上。

## 冲击巅峰千强补充（seed）

- **大闪开团**：大闪是起手式。熟练之后可以**反向着大**——大招有偏心判定，对面会误判打不到。
- **一技能强化 A 的前后摇能被大招取消**：所以连招里大招不只是伤害，是**取消器**。
- **二技能只要边缘擦到脚下红圈就能推到**：前摇带**假霸体**，可以顶着控制推。
- **蓄大时把手指按在取消键上**：被打断不会自动放出去。
- **残血别贴墙**：灯会卡墙里，队友点不到。
- **怕大司命、甄姬造出来的墙**：撤退撞墙会直接停住。
