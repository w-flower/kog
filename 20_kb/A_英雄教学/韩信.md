## 1. 机制内核：他是"买时间"的英雄

韩信不是靠伤害赢的，是靠**位移次数**赢的。他的全部收益来自同一个公式：

```
多一段位移 → 多一次野区穿梭 → 对面少一次发育 → 你多一次经济领先
```

所以韩信的核心 KPI 不是人头，是**"对面打野这一轮的野区，有几组是你的"**。这条贯穿整张卡。

## 2. 开局反野：慢一步就全废

BV1jd4y1373j @ 00:00 讲得很具体：

- **反蓝就直接一技能跳过去**，不要走过去
- 关键在**一技能 CD 的卡点**：走到某个固定位置时，刚好能"无影步"卡过去
- **走得慢的后果**：被对面辅助或中单发现 → 对面提前反应 → 这一波从"反野"变成"送头"
- 对面打野如果在自家蓝开或红开，暂时不用管，先把蓝 Buff 拿下

**这条的可迁移点**：反野不是"我去了就行"，是"**我在对面还没反应过来的那 3 秒内到那里**"。所有反野教程里最难复制的东西就是这个时间窗。

## 3. 打不过的类型：拉开距离，不正面

**韩信打刘备前期一点优势都没有**——伤害不如他高，抓人不如他强（BV1jd4y1373j @ 00:31）。

处理方式不是"小心点"，是**换半区**：

> 他去下路，我就去上路。**离他远一点**，不要和他正面交战。（@ 00:49）

同类的还有兰陵王这类前期强势英雄。**判据**：一级/二级能不能打过。打不过就换图，别硬碰。

## 4. 压制链：一个蓝 Buff 能滚到什么程度

这是本卡最值得学的一段（@ 01:07 起）：

```
反掉他的蓝 → 他没有蓝，必须回家/回城
→ 对面辅助没法跟着他（打野没蓝，辅助跟也没用）
→ 河蟹变成你的
→ 你开龙，他去拉扯 → 龙开完，他的红 Buff 刚好刷新 → 直接把红也控下来
→ 他整片野区都拿不到
→ 10 分钟，一路高地
```

原话收尾："**节奏从哪里来的？其实节奏就是从那一个蓝 Buff 开始的。**"（@ 07:12）

**关键认知**：反野的收益**不只是那组野怪**。真正的收益是"**对面打野的行动被限定了**"——他必须回家，他必须补发育，他的辅助跟不了，这些"他不能做的事"才是雪球的起点。

甚至有一波 UP 自己承认"红蓝 Buff 一个没打着"（@ 02:12），但他的结论是：

> "虽然野区并没有空下来，反野并没有反到，**但是你节奏把握住了**。"

**这句话把反野的价值说透了**：反的是"节奏权"，不是"野怪"。

## 5. 不要去线上抓人

@ 03:04 的原话：

> "你不要没事就跑到线上去抓人。你抓到了有什么用啊？被我们后手带走之后，**他的野区也没有了**。"

逻辑链：你去线上抓人 → 你自己的野区空着 → 对面反你的野 → 你抓到一个人头，丢了一片野区，净亏。

**这条和韩信的机制直接相关**：韩信的经济来自野区穿梭，一旦离开野区节奏，他就变成一个"伤害不高、又不敢正面"的普通英雄。

## 6. 阿森的防守视野布局（打强势打野时）

对面是 1.87 万战力的裴擒虎（BV1bWnv6KEPw @ 00:17），开局的布置是：

1. 让队友**上半图去开蓝区视野**
2. **自己带辅助去红背**
3. 目的：**他不管是偷上半图还是强入侵下半图，你都防得住**（@ 00:34）

**这套布局的判据**：对面打野比你强时，第一件事不是"我要不要反他"，而是"**他反我，我能不能看见**"。

## 7. 反野时机的第二个判据：双方 Buff 的刷新是否同向

@ 02:09 的推演很干货：

> 对面打野红开，我也是红开，双方反向刷。所以**我的次开 Buff（蓝）和他的首开 Buff（红）是同时刷新的**。

由此推出：
- **我的蓝区和他的红区同时刷新** → 有窗口去他的红区（@ 03:31）
- 进野区时**不要交惩戒**，带着惩戒去，**先找人打，不摸 Buff 不拼惩戒**——因为队友第一时间还没到位（@ 03:47）

## 8. 一句话

**韩信赢的方式不是"打赢对面"，是"让对面这一轮少拿两组野"，然后把这两组野变成一路高地。**
