# 元歌：一个"本体不在场"的英雄

> 只讲英雄本身。分路思路见 `L_分路/04_对抗路.md`；对位见 `B_克制关系/`。
> 素材：公瑾「元歌显微级教学」（BV1G8etzKEKV）。这是**唯一一条可用素材**，所以这张卡覆盖"机制 + 连招 + 出装"，**不覆盖全局节奏**。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **节奏曲线** | 中期发力（前 4 级只能靠傀儡拉扯，4 级后有二段控制才敢打） |
| **节奏职责** | **开节奏 / 带线牵制** —— 不是"跟团"型英雄 |
| **一句话** | **傀儡是眼睛，本体是刀。** 傀儡打探、拉扯、挂控制；本体负责"在最安全的位置打出那一下" |
| **为什么是这个定位** | 傀儡被摧毁 = 本体眩晕 2 秒 + 20 秒不能召唤 (见 1.3)，所以元歌**不能硬拼**。他的强度全在"先看到、先挂住、再决定要不要杀" |

## 1. 被动与傀儡：三条必须先背的规则

### 1.1 碎片：普攻/技能命中敌方英雄就收集，50 个变一次敌方英雄

- 背包最多 **150 个**
- 每消耗 **50 个**可以变成**任意敌方英雄**
- 元歌的"恢复"技能被换成了碎片（不是回血键）
- **来源**：BV1G8etzKEKV @ 00:17、@ 00:34

### 1.2 变身只能持续 10 秒，但可以卡最后一秒延长

- 屏幕**变暗**说明只剩最后 2 秒
- **卡最后一秒接持续技能**可以延长变身时间：孙策的开船、马可的一三技能、嬴政的大招
- **来源**：@ 00:52

### 1.3 傀儡被打死 = 本体眩晕 2 秒 + 20 秒不能再召唤（最致命的一条）

- 眩晕 2 秒且**不能用四技能解除**
- 20 秒内**禁止召唤傀儡**
- **补救**：傀儡即将死亡时**秒按四技能位移**，或用 **332 连招**，可以免疫眩晕
- **来源**：@ 02:17、@ 02:33

## 2. 技能细节（每条都是"说明里没写"的）

### 2.1 一技能（丢/收傀儡）

| 细节 | 内容 |
|---|---|
| 回收收益 | 回收傀儡会加**护盾 + 最高 80% 移速** |
| 击飞 | 丢出和回收**都对路径上的敌人造成击飞** |
| 身后判定 | 丢和收都有**一个身位左右的身后判定** |
| **塔下消耗** | **傀儡攻击塔下的敌人，防御塔不会攻击傀儡** —— 越塔消耗的免费手段 |
| 傀儡能干嘛 | 吃经济经验、**继承本体的 Buff 效果** |
| **自动普攻** | 放出傀儡后身边有三个圈：**最内圈有攻击单位、且傀儡不出第二圈**，本体就会**自动普攻那个目标**（本体和傀儡同时输出） |
| 傀儡消失 | 傀儡出最大圈后脚下出现箭头，**攒到五个箭头傀儡直接消失**；走回圈内箭头归零 |
| **解控** | 本体被控制时，**收回傀儡即可瞬间解除** |

- **来源**：@ 01:09、@ 01:25、@ 01:43、@ 02:00、@ 02:17

### 2.2 二技能（四枚暗器）

- **二技能瞬间马上接一技能**：取消后摇，还能瞬间打出伤害和控制（一二都有严重前后摇）
- **指示器不准**：实际攻击距离比指示器**远一个身位**
- **不需要贴脸**：与敌人保持**半个闪现左右**的距离，四枚暗器才能全中、爆发拉满
- **可以二闪**：但闪现**只改释放位置，不改攻击方向**
- **来源**：@ 02:33、@ 02:53、@ 03:09

### 2.3 三技能（十字斩）

- **两条线的中心斩中**：伤害翻倍 + 有斩杀效果 + 减速
- **前摇很长，但代码是瞬发**：即使前摇时元歌被击杀，**三技能还是会打出来** → 极限反杀
- **本体往后撤退**：所以 **二三连招**是元歌最基础的高爆发连招
- **可穿墙 + 无影步**：卡视野反蹲、拉扯风筝都能用
- **侧斩**：单用一条线的末端攻击，**能延长双倍攻击距离** → 抢野怪、收割残血、远距离补刀
- **来源**：@ 03:26、@ 03:43、@ 04:02

### 2.4 四技能

- 释放时**无法被选中**，可躲伤害、穿墙逃跑，**吃到控制也能直接解除**
- **缺点**：不能像净化一样清除负面效果（扁鹊的毒、李元芳的标记）
- **来源**：@ 04:21

### 2.5 傀儡形态的三个技能

| 技能 | 内容 |
|---|---|
| 傀儡二技能 | **本体和傀儡互换位置** |
| 傀儡三技能 | 两段：一段**减速**，三秒内可放第二段**持续眩晕** → **133 是元歌最强的控制连招** |
| 傀儡四技能 | **带着本体一起位移**；本体位移时**像貂蝉二技能一样免疫伤害和控制**；**三三控制后接二技能换位也能卡出无敌和霸体** |

- **后摇取消**：傀儡三技能第一段施法后摇严重，**秒接平A 或收回傀儡**都能取消 → 中后期进场能防傀儡被秒
- **远程消耗**：**3A1** 可以瞬间打出高额消耗
- **来源**：@ 04:38、@ 04:56、@ 05:13、@ 05:31

## 3. 三套连招（他明确说"元歌真正的精髓只有三套"）

| # | 连招 | 用在哪 |
|---|---|---|
| **1** | 一（放傀儡）→ 四（突脸）→ 三三（减速+控制）→ 二（换回本体）→ 二三（打爆发） | 前中期**打消耗 + 秒脆皮** |
| **2** | 一 → 四突脸 → 三一段（挂减速）→ 二换位 → 一收回傀儡（打出控制）→ 三二（打满爆发） | 后期**秒脆皮、越塔**，速度极快 |
| **3** | 二一（起手控制）→ 挂减速 → 瞬间换位 → 收回傀儡（控制）→ 三（斩杀收割） | **蹲草 / 被贴脸反打** |

- **来源**：@ 05:50、@ 06:10、@ 06:29

**共同结构**：都是"**先挂控制 → 再打伤害**"。元歌的伤害全在"对方动不了"的那一秒里，所以顺序错了一整套就废。

## 4. 出装与铭文

**铭文**：10 异变 / 10 隐匿 / 10 鹰眼（@ 06:46）

**出装顺序**：

```
护手 → 布甲鞋 → 暗影战斧 → 苍穹 → 破军 → 冰痕 + 碎星锤
```

| 件 | 理由 |
|---|---|
| 护手 + 布甲鞋 | 大幅提升**前期对拼能力** |
| 暗影战斧 + 苍穹 | **爆发和容错同时拉满** |
| 破军 | 大幅提高爆发 |
| 冰痕 + 碎星锤 | 常规收尾 |
| **对面爆发高** | **冰痕换成防御装保命** |

原话批评了两种常见错法：冷缩不够（极其难受）、身板太脆（一碰就碎）。

## 5. 一句话

**元歌不是"操作英雄"，是"信息英雄"——你之所以打不出伤害，通常不是手速不够，是傀儡没先把对面按住。**
