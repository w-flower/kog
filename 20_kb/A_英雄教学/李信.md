# 李信：先把自己喂成疯狗，再去拆对面的家

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：仅一份——学长木兰导师《李信对线司空震无限单杀顶级对抗路，全局思路打法教学讲解！》（BV1dVWg62EKV，对抗路实录、口语解说）。
> ⚠️ **单素材、覆盖不全**：只有一局对抗路对线司空震的实录，没有技能数值、没有铭文、没有完整出装顺序，也没有逆风局与团战站位的系统讲解。以下全部结论只对这一份素材负责。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 中后期——「现在的司空震，别想了，难压了啊，因为现在李信的伤害变得比以前高多了」（BV1dVWg62EKV @ 02:33）；真正的质变点是名刀做出来之后，「等我有名刀，我再来搞你」（@ 03:54） |
| **节奏职责** | **单带**：吃兵线 → 吃野怪 → 再吃兵线，循环发育；「毕竟李信最擅长的就是偷塔」（@ 02:59） |

## 1. 机制内核

1. **一技能带免伤/霸体，是他敢一个人冲后排的底牌**：「我们一技能有免伤，来一技能有那个霸体无敌的」（BV1dVWg62EKV @ 04:02）。
2. **吸血极强，平 A 就能回满**：对手视角原话「而且吸血这么快，一下子就满血了，两个平 A 就满血了」（@ 06:43）；他自己也讲「我有攻速鞋，猛猛吸血」（@ 00:25）。
3. **平 A 型输出，攻速直接决定强弱**：把鞋子换掉后「一技能拉满 185，185 够了」（@ 07:19），全篇的核心成长线就是攻速（@ 07:13）。
4. **红叉（影刃）优于电刀**：「电刀没有红叉厉害，红叉加的属性多，单挑厉害，伤害更高」（@ 02:41）；具体差异是红叉会暴击、打野怪更快、移速和攻速也更高，而「电刀是没有暴击的」（@ 05:20、@ 05:27）。
5. **一技能减速是留人手段**：全场反复出现的动作是「减速 → 无畏冲锋 → 开大砍」（@ 03:24、@ 05:43、@ 06:16）。

## 2. 对线 / 打法

- **对线司空震：现在是他压不了你，不是你去抗压**——「以前的司空震你说可以压一下李信，现在的司空震，别想了」（@ 02:26）。
- **被卡兵线就直接 A 回去**：对方卡兵线时「A 你两下就老实了」（@ 00:56），不因为被卡线就让出线权。
- **线权优先于杀人**：他反复做的顺序是过兵线 → 抢野怪 → 再吃兵线（@ 01:17、@ 02:47）。
- **抢对面野怪是常态**：明确讲「这个野怪我要抢的」「你打归你打，我要抢你野怪」（@ 01:31、@ 01:40）；中单不来干扰就敢抢（@ 00:29）。
- **残血就撤，不硬拼**：抢完野怪没血「抢完就跑，快跑」（@ 00:33）。
- **敌方 C 位没位移可以省闪现，有位移就拿闪现去跟**：对面 C 位「没有位移」时直接冲，「有位移，我们有闪现能跟」（@ 04:51）；反过来「我要有闪现，这波死不了」（@ 04:44）。
- **对面有塔且自己没闪现时不上**：「这一波一防有防御塔，我们没闪现，不要乱搞，等下一波」（@ 07:39）。

## 3. 连招

| 场景 | 连招 | 依据 |
|---|---|---|
| 常规起手 | 一技能减速 → 无畏冲锋 → 开大砍 → 平 A 收尾 | BV1dVWg62EKV @ 03:24、@ 05:43 |
| 抓后排 | 减速 → 无畏冲锋贴脸 → 开大砍 | @ 04:20「一个减速无畏冲锋，好开大砍砍秒了」 |
| 追击 | 减速 → 闪现跟上 → 无畏冲锋 | @ 06:22「砍我砍闪现跟上减速，无畏冲锋」 |
| 抢野/对拼 | 瞬间贴脸减速 → 挂一技能 → 冲锋收割 | @ 07:53「直接瞬间到他们脸上减速，挂上一技能，直接从脸上瞬间爆炸」 |

- 素材里连招表述是口语化的动作串（减速/无畏冲锋/开大砍），技能名与按键对应关系未被讲解（见待补）。

## 4. 中后期 / 节奏

- **中期的主线就是刷**：「吃完兵线吃野怪，吃完野怪吃兵线，发育发育再发育」（@ 02:47）；有机会才去摸人头助攻，没机会就继续发育推塔（@ 02:53）。
- **名刀是切入许可**：名刀没好之前不去冒险，「等我有名刀，我再来搞你」（@ 03:54）；名刀在身上时才一个人冲敌方后排（@ 04:14、@ 04:34）。
- **一个人切两个后排是常规收益**：「一个人冲到敌方后排，瞬间解决敌方两个后排，而且我的名刀还有」（@ 04:34）。
- **有红 Buff 的黏人能力是他能追杀 C 位的另一半原因**：「而且有红 Buff 黏住啊，基本上他们很难跑掉」（@ 04:58）。
- **队友去打团时他去拿龙**：「队友去打架了，我们去打龙，给队友拿条龙」（@ 06:57）。
- **拆塔优先于杀人**：「你拦我我就把你杀了，你要不拦我的话，防御塔就给我了」（@ 05:14）。
