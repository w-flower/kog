# 嫦娥：靠意识不靠操作，前期发育、中期用野区滚雪球

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：新赛季打野嫦娥思路（BV1bH4y1S7Fx，实战口播，重反野与节奏）+ 巅峰赛嫦娥实录（BV1WHZuBGEDb，联手巅峰第一嫦娥 15KK，重对线与团战处理）。
> ⚠️ 两份素材都偏思路与片段，技能数值、帧级连招细节未覆盖；出装只给件序，且部分装备名是转写口音（已按原文保留）。

## 1. 机制内核

1. **一技能用于预判封路**：平 A 减速到之后接一技能，"一定要预判去封路，而不是对着人丢"（BV1bH4y1S7Fx @ 03:41~03:47）
2. **一技能可定身留人**：一技能定身把贴脸的狂铁留下（BV1WHZuBGEDb @ 02:11~02:15）；精准一技能收下露娜人头（BV1WHZuBGEDb @ 02:30~02:33）
3. **二技能能摆位做假象**：把二技能摆到红 Buff 上，给对面"我在打红"的假象，再一技能对着人丢完成击杀（BV1bH4y1S7Fx @ 04:00~04:06）
4. **大招是持续按键输出，且会被打断**：贴脸时"不断点大招展示手法"收人（BV1WHZuBGEDb @ 03:35~03:40、03:04~03:12）；大招按住露娜时被火舞一闪打断（BV1WHZuBGEDb @ 02:25~02:28）
5. **清野 / 抢野时一技能可变小野并给自己加速**：对面反野时用一技能处理小野、加速贴近（BV1bH4y1S7Fx @ 04:49~04:53）
6. **本体没有位移，靠移速装补机动**："嫦娥它本身没有位移"，巫术法杖和大打野刀都加移速，让抓人更快（BV1bH4y1S7Fx @ 07:19~07:27）

## 4. 中后期 / 节奏

- **前期到中期的转换点在野区压制**：打野对位压制住了，"三条兵线上都可以放心大胆的推兵线"，因为对面打野根本抓不了人（BV1bH4y1S7Fx @ 02:31~02:38）
- **推塔与野区连着走**：下塔推完推中塔，推完中塔直接过来把红 Buff 一收，整片野区对面一个野怪都刷不到（BV1bH4y1S7Fx @ 06:36~06:46）
- **打完龙先打人**：龙打完蓝也刷了，就先去蓝区打人，这个时间点是可以秒的（BV1bH4y1S7Fx @ 06:02~06:08）
- **团战抓时机**：对面起推进节奏但有人在下路露头，就直接夹过去打人数差（BV1WHZuBGEDb @ 02:52~02:59）；技能全在 CD 时先拉扯，等火舞残血再不断点大招收人（BV1WHZuBGEDb @ 03:01~03:12）
- **收尾阶段**：9 分 50 秒一技能起手、二技能接大闪，把敖影和曹操打残，再在水晶艰难收下（BV1WHZuBGEDb @ 03:44~03:57）
- **逆风处理素材未覆盖**，两份素材都是优势局的滚雪球过程（BV1bH4y1S7Fx @ 07:46~07:50）

## 5. 出装铭文

**打野线（BV1bH4y1S7Fx）**

- 铭文：五狩猎、五贪婪、十心眼、十梦魇（BV1bH4y1S7Fx @ 06:52~06:58）
- 出门：小打野刀 → 蓝宝石 → 鞋子 → 小蓝宝石 → 二级打野刀（BV1bH4y1S7Fx @ 06:59~07:04）
- 鞋：控制多出抵抗鞋，控制少出法穿鞋（BV1bH4y1S7Fx @ 07:05~07:09）
- 然后时之预言、巫术法杖，增加移速和伤害（BV1bH4y1S7Fx @ 07:10~07:13）
- 之后补法穿，再把大打野刀做出来（转写作"大的单剪刀"）——因为大打野刀也加移速，配合巫术能让嫦娥跑得很快、更好抓人（BV1bH4y1S7Fx @ 07:13~07:27）
- 最后一件吸血书；如果对面火甲（转写作"活甲"）增强、或者制裁与梦魇做得很早，就不再做吸血书（BV1bH4y1S7Fx @ 07:27~07:35）
- 打野嫦娥不出梦魇，任何情况下都不出，让辅助、射手、法师去出；只有打中路才考虑（BV1bH4y1S7Fx @ 07:37~07:46）

**中路（BV1WHZuBGEDb）**

- 铭文：十狩猎、十心眼、十梦魇（BV1WHZuBGEDb @ 00:35~00:37）
- 两套出装的分工：第一套适合熟练度高的玩家，伤害高、容错率低；第二套容错率高，适合打对面控制多的阵容；对面回血多，第三件补梦魇（BV1WHZuBGEDb @ 00:22~00:33）
