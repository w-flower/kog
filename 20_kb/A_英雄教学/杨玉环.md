## 1. 机制内核

1. **被动是双形态开关**：蓝环放技能额外造成伤害，绿环放技能额外回血；说白了"蓝色打伤害，绿色奶队友"（BV1W441197uH @ 00:30、BV1W441197uH @ 00:36、BV1W441197uH @ 00:41）。
2. **被动不限单位**：绿环可以奶队友，也可以奶小兵；蓝环对小兵、野怪同样生效（BV1ax37zUEBW @ 07:03、BV1ax37zUEBW @ 07:06、BV1W441197uH @ 08:23）。
3. **蓝环有视野限制**：蓝环伤害范围跟一技能差不多（BV1ax37zUEBW @ 06:01）；但只看得到的目标才吃蓝环伤害，草丛里看不见的目标不吃（BV1Ej411c7iS @ 07:16、BV1Ej411c7iS @ 07:24、BV1Ej411c7iS @ 07:33）。
4. **一技能是多目标弹道**：以自身为圆心，范围内最多打四个敌人、优先英雄，英雄不够四个才分给小兵野怪（BV1ax37zUEBW @ 00:24、BV1ax37zUEBW @ 00:37、BV1ax37zUEBW @ 00:40）；另一条素材按"最多三道音波"讲（BV1Ej411c7iS @ 00:14），两条口径不同。
5. **一技能对兵野有额外伤害**：同一发打人偶813、打蓝Buff 2000，所以清线刷野快（BV1ax37zUEBW @ 00:55、BV1ax37zUEBW @ 01:02、BV1ax37zUEBW @ 01:04）。
6. **强化普攻是核心资源**：放完一技能附带一次强化普攻，攻击距离比普通平A远很多（BV1ax37zUEBW @ 01:08、BV1ax37zUEBW @ 01:14、BV1W441197uH @ 02:55）；最多存五秒（BV1ax37zUEBW @ 01:38、BV1W441197uH @ 02:31）。
7. **强化普攻减全技能CD**：每次命中减少所有技能1秒冷却，可以像孙悟空存棍一样提前放一技能存着（BV1W441197uH @ 02:17、BV1W441197uH @ 02:31、BV1W441197uH @ 02:35）；对防御塔也有效（BV1W441197uH @ 02:45）。
8. **技能移动施法，强普有硬直**：所有技能都能边走边放、没有前摇，但强化普攻打出去会站住一下（BV1ax37zUEBW @ 02:21、BV1ax37zUEBW @ 02:38、BV1W441197uH @ 07:13）；所以一技能和平A要当两个技能分开用（BV1ax37zUEBW @ 02:46）。
9. **二技能只有圆环有伤害**：大圈与小圈之间形成圆环，圈内圈外都不掉血（BV1ax37zUEBW @ 03:31、BV1ax37zUEBW @ 03:40、BV1ax37zUEBW @ 03:43）；伤害延迟1.5秒生效，附带0.75秒眩晕（BV1ax37zUEBW @ 03:49、BV1Ej411c7iS @ 03:41、BV1Ej411c7iS @ 03:44）。
10. **二技能给移速**：释放时短时间加移速，素材给的数值是50%（BV1ax37zUEBW @ 04:09、BV1Ej411c7iS @ 03:32）。
11. **二技能可以隐身控**：草里放二，敌人看不到技能特效；但蓝环被动会先打一段伤害、把自己暴露（BV1Ej411c7iS @ 03:46、BV1Ej411c7iS @ 04:11、BV1Ej411c7iS @ 04:19）。先切绿环再放二，就不会提前暴露（BV1Ej411c7iS @ 04:31、BV1Ej411c7iS @ 04:39）。
12. **二技能阵亡后仍存在**：只要阵亡前打出了二技能，死后环还在，仍能造成伤害和控制（BV1Ej411c7iS @ 04:55、BV1Ej411c7iS @ 04:59）；二技能还能配闪现打二闪（BV1Ej411c7iS @ 05:05、BV1Z66NYHEF5 @ 06:41）。
13. **二技能命中=一套伤害**：眩晕到就必定能接一次一技能加强化普攻，后期一次强化普攻能打掉脆皮大半血（BV1W441197uH @ 03:13、BV1W441197uH @ 03:18）。
14. **大招是保命/抬血，不是输出**：开启期间无法选中，免疫伤害和控制，结束对自身和友方回血（队友50%）、对敌方造成伤害（BV1Ej411c7iS @ 05:09、BV1Ej411c7iS @ 05:19、BV1Ej411c7iS @ 05:22）。
15. **大招不免疫开大前已中的负面**：开大前被扁鹊毒、被减速，开大后效果还在，只是无法选中期间不掉血（BV1ax37zUEBW @ 05:00、BV1ax37zUEBW @ 05:05、BV1ax37zUEBW @ 05:15）。
16. **大招结束还有短暂无敌延迟**：头顶无法选中的状态消失后，短时间内仍能免疫接下来的控制和伤害（BV1Ej411c7iS @ 05:33、BV1Ej411c7iS @ 05:41、BV1Ej411c7iS @ 05:47）；大招还能重置防御塔的累加伤害（BV1Ej411c7iS @ 05:51、BV1Ej411c7iS @ 05:58）。
17. **绿环不加大招奶量**：很多人以为绿环能提升大招治疗，素材明确说这是错的；开大尽量用蓝环打伤害和回队友血（BV1W441197uH @ 04:37、BV1W441197uH @ 04:40、BV1W441197uH @ 04:44）。

## 2. 对线 / 打法

- **一级就对拼，别只盯兵线**：杨玉环一级兵线不如诸葛、鬼谷子快，但有碾压性技能，直接把诸葛亮、鬼谷子打残，断掉他们支援的念想（BV1ut411P76f @ 23:46、BV1ut411P76f @ 23:58、BV1ut411P76f @ 24:09）。
- **一级碾压要带辅助**：杨玉环一级能压诸葛亮，但对面有辅助、自己没辅助时就压不动（BV1ut411P76f @ 24:43、BV1ut411P76f @ 24:46）。
- **站侧边而不是正面**：一技能以自身为圆心，站队伍正面最多打两个，站到侧边才能覆盖四个（BV1ax37zUEBW @ 01:58、BV1ax37zUEBW @ 02:11、BV1ax37zUEBW @ 03:00）。
- **打兵同时打人**：用一技能四个球清兵，用强化普攻打对面血量（BV1ax37zUEBW @ 12:16、BV1ax37zUEBW @ 12:21）。
- **对线站小兵侧前方**：让对面少补一个兵，前期节奏就慢一截，至少拖慢他二级支援边路（BV1W441197uH @ 06:34、BV1W441197uH @ 06:37、BV1W441197uH @ 06:43）。
- **两三个一技能就压掉大半血**：线上打出压制后，二级就能游走，对面只能塔下或回家（BV1W441197uH @ 06:59、BV1W441197uH @ 07:02、BV1W441197uH @ 07:06）。
- **前4分钟一波线都不放**：4分钟后再无脑挂发育路，中线直接给打野吃，跟射手推塔，推完带射手转中（BV1ax37zUEBW @ 11:55、BV1ax37zUEBW @ 12:39、BV1ax37zUEBW @ 12:39、BV1ax37zUEBW @ 12:45）。
- **蓝Buff优先**：蓝Buff一刷就回自家拿，别让对面打野偷走，那等于丢一波节奏（BV1ut411P76f @ 33:19、BV1ut411P76f @ 33:22）；打野是李白、韩信这种明显吃蓝的，就直接不要（BV1W441197uH @ 05:30、BV1W441197uH @ 05:33）。
- **打龙优先于清线**：地图上看得到对面在骚扰、辅助也没给到安全视野，就先拿龙再清线，防止节奏断掉（BV1ut411P76f @ 29:29、BV1ut411P76f @ 29:41、BV1ut411P76f @ 30:02）。
- **抓完人不走河道**：在中路看不到辅助视野时，河道两侧草丛极可能有人，绕路走（BV1ut411P76f @ 35:44、BV1ut411P76f @ 35:52、BV1ut411P76f @ 36:03）。
- **反完蓝要回守自家蓝**：只反不守，自家野被换走等于白反（BV1ut411P76f @ 26:32、BV1ut411P76f @ 26:36）。
- **优势就打野区入侵**：杨玉环野区地形作战能力强，用野区勾引对面打架，打掉点再推塔（BV1Z66NYHEF5 @ 07:39、BV1Z66NYHEF5 @ 07:42、BV1Z66NYHEF5 @ 07:54）。
- **团战站角落，不要站正面**：让牛魔这类前排去吃技能，自己在侧边角落消耗，残血再大招收割（BV1ut411P76f @ 41:41、BV1ut411P76f @ 41:55、BV1ut411P76f @ 42:03）。
- **被突进先加速拉开再控**：敌方要切，马上开二技能加速拉身位，调整二技能位置反控，等前排吃完伤害再开大抬血（BV1W441197uH @ 09:00、BV1W441197uH @ 09:06、BV1W441197uH @ 09:09）。
- **不追残血**：鬼谷子、橘右京这类反打强，追深容易被反杀，残血钻草就不要好奇跟（BV1ut411P76f @ 45:09、BV1ut411P76f @ 45:25、BV1ut411P76f @ 45:41）。
- **压高地以推塔为主**：能杀人就杀，不能杀就先磨塔，不要站在塔前只消耗人；建议单独设置推塔键（BV1ut411P76f @ 39:50、BV1ut411P76f @ 40:13、BV1ut411P76f @ 40:46）。
- **法核还是全肉看阵容**：对面有突进、队友没前排就全肉；射手有自保、辅助不是开团位才出法核输出流（BV1Z66NYHEF5 @ 00:53、BV1Z66NYHEF5 @ 00:57、BV1Z66NYHEF5 @ 12:01、BV1Z66NYHEF5 @ 12:12）。

## 4. 中后期 / 节奏

- **大招不要拿来打伤害**：素材给的对比是大招约1900、一次1A接近2600，能1A就1A，打不到再开二加速1A，大招留给躲伤害和保命（BV1Ej411c7iS @ 08:25、BV1Ej411c7iS @ 08:28、BV1Ej411c7iS @ 08:34、BV1Ej411c7iS @ 08:43）。
- **没大招不要参团**：这时的杨玉环非常脆，容易被一套带走、没有反制空间；大招冷却期间用强化普攻减CD找回来（BV1W441197uH @ 04:23、BV1W441197uH @ 04:25、BV1W441197uH @ 04:30）。
- **大招优先保C位或保自己**：C位血量下降可以开大保一手，或者留给对面战士刺客进场时拖时间反打（BV1W441197uH @ 04:48、BV1W441197uH @ 04:51、BV1W441197uH @ 04:54）。
- **越塔最常用抗塔**：前排抗塔到不行就开大免疫塔伤，同时给队友加血（BV1ax37zUEBW @ 11:24、BV1ax37zUEBW @ 11:26、BV1ax37zUEBW @ 11:30）；大招还能把塔伤累加重置（BV1Ej411c7iS @ 05:51、BV1Ej411c7iS @ 06:01）。
- **后期可以奶兵推塔**：敌方清线的人阵亡、或者干脆不守塔时，绿环奶小兵，小兵活得越久对塔伤害越多；后期一个大招能把小兵血量抬满（BV1W441197uH @ 08:23、BV1W441197uH @ 08:37、BV1W441197uH @ 08:50、BV1W441197uH @ 08:52）。
- **顺风先抢中再转边**：中射辅三人连体过中路，拿到中线权再转边压塔或进野区；不要顺风让射辅两人在边路带线，中线先被对面清就很难打进攻（BV1Z66NYHEF5 @ 08:44、BV1Z66NYHEF5 @ 08:50、BV1Z66NYHEF5 @ 08:53）。
- **节奏断了先收，不要硬入侵**：队友阵亡两个就先抢中线、刷自家野，等队友复活再进对面野区（BV1Z66NYHEF5 @ 09:02、BV1Z66NYHEF5 @ 09:05、BV1Z66NYHEF5 @ 09:09）。
- **团战先算四件事**：人数、经济、装备是否成型、对面还有没有大招/技能，算完再决定接不接（BV1ut411P76f @ 38:29、BV1ut411P76f @ 38:36、BV1ut411P76f @ 38:43、BV1ut411P76f @ 38:48）。
