## 1. 机制内核

1. **被动侠客行**：普攻四次提升自身攻击力 5%，同时解除大招限制（BV15x41117f7 @ 02:37、BV15x41117f7 @ 02:41），持续五秒（BV15x41117f7 @ 02:54）。
2. **剑气与侠客行是两个计时**：前三道剑气各持续三秒，第四层解锁大招后持续五秒（BV1F4411P7GZ @ 01:30、BV1uL411q7u9 @ 06:01）；两刀间隔超三秒剑气就重新计数，且不能用"侠客行是否存在"反推剑气是否还在积（BV1F4411P7GZ @ 02:05、BV1F4411P7GZ @ 02:16）。
3. **一技能三段**：前两段位移带伤害，第三段回第一次释放的位置、无伤害（BV15x41117f7 @ 03:33、BV15x41117f7 @ 03:40）。
4. **第二段比第一段长**：多出约半个身位，第一段穿不过的厚墙第二段能穿（BV1F4411P7GZ @ 02:25、BV1uL411q7u9 @ 01:14）；一技能起始处没有伤害和眩晕，实际生效距离也比指示器长（BV1F4411P7GZ @ 02:41、BV1uL411q7u9 @ 01:23）。
5. **二技能是破甲开关**：环形伤害 + 减速 + 减甲（BV15x41117f7 @ 04:13），剑圈命中减 475 点物理防御，二技能没直接中但后续碰到剑圈也算第二段并减防（BV1uL411q7u9 @ 02:52、BV1uL411q7u9 @ 02:56）。
6. **二技能、大招期间都不可选中**，能躲技能躲伤（BV1F4411P7GZ @ 02:48）；两者都能让防御塔丢失目标、转移仇恨（BV1F4411P7GZ @ 02:57），二技能还能重置塔伤（800 变 500）（BV1uL411q7u9 @ 02:05）。
7. **大招五段、扇形远范围、释放不可选中**（BV15x41117f7 @ 06:12）。**目标越多伤害越低**：每多一个目标减 15%，最多减 30%（即衰减到 70%）（BV1F4411P7GZ @ 03:06、BV1uL411q7u9 @ 04:31）。大招范围比指示器大，紧贴身后的敌人也吃伤害（BV1F4411P7GZ @ 03:13）；向后放大招，敌人不在范围内也能被打到（BV1uL411q7u9 @ 04:47）。
8. **减甲窗口只有三秒**："二技能减甲的效果只存在三秒钟，所以有爆发要尽快的打出去"（BV1F4411P7GZ @ 03:26）。
9. **影子的朝向会暴露你**：影子面朝方向 = 第一次一技能的方向，敌人靠它定位（BV1uL411q7u9 @ 00:11、BV1uL411q7u9 @ 00:20）；但影子不提供视野，点一技能回去容易撞见草里的人（BV1uL411q7u9 @ 00:55、BV1uL411q7u9 @ 01:00）。
10. **加点两条线**：主一更灵活、主二爆发更高但更依赖二技能命中，高分局更推荐主一（BV1F4411P7GZ @ 03:19、BV1F4411P7GZ @ 03:31）。
11. **四层被动的攻击力加成也算进大招伤害**，所以"叠满四层再开大"本身就是增伤手段（BV1uL411q7u9 @ 04:22）。

## 2. 对线 / 打法

> 李白是打野，本节记开野与抓人节奏。

- **一般先学一技能**（BV15x41117f7 @ 16:36）。
- **红开路线**：站墙边 1A1 回原点，靠近红让它靠近你，慢慢往左上角拉野，惩戒 + 二技能破甲打大猪，两只猪一起 A；两段一技能赶路到大狼，约 55 秒出红区（BV1jQWd6EEeF @ 36:48、BV1jQWd6EEeF @ 36:55、BV1jQWd6EEeF @ 37:19）。
- **蓝开路线**：蓝 Buff 1A1 回原点，慢慢往左扯，卡血量惩戒 + 二技能破甲，人往下走用隔墙一技能，同样 55 秒左右出（BV1jQWd6EEeF @ 38:13、BV1jQWd6EEeF @ 38:28、BV1jQWd6EEeF @ 38:41）。
- **二技能不要交给双柱**：四级带蓝 Buff 时二技能 CD 十秒，交给大猪红 Buff 就没二技能了，留给红反而总时间更快（BV1jQWd6EEeF @ 39:11、BV1jQWd6EEeF @ 39:28）。
- **猴子最后刷**：不论抓下还是抓中，回中路都要路过那个位置（BV1jQWd6EEeF @ 39:44、BV1jQWd6EEeF @ 40:01）。
- **不推荐一级抢对方红**：双方都有惩戒不一定抢到，会玩的人看到李白就会防（BV15x41117f7 @ 16:49、BV15x41117f7 @ 17:35）。
- **前期以刷为主，帮优不帮劣**，自身经济和经验优先（BV1F4411P7GZ @ 10:22、BV1F4411P7GZ @ 10:27）。
- **别刻意拿人头**："你像我这几个人头，基本都不是刻意去拿的，都是对面送给我的"，刷野反野时顺手解决（BV1dduk6TEci @ 05:32、BV1dduk6TEci @ 05:39）。
- **兵线比人头值钱**："这波兵线比一个人头可值钱多了"（BV1dduk6TEci @ 08:22）；一个兵一个炮车比半个人头还值钱（BV1dduk6TEci @ 10:09）。
- **拉野是基础功**：打完狼不要站原地，往后拖，`狼`这个点要队友帮忙护，因为释放完技能那一瞬间李白只剩平砍最脆（BV15x41117f7 @ 25:01、BV15x41117f7 @ 25:39、BV15x41117f7 @ 26:04）。
- **对面是李白就抓空档**：刷完大招的空档期"任何一个英雄都能把他抓死"（BV15x41117f7 @ 26:23、BV15x41117f7 @ 26:39）；反过来队友有李白，野区别把狼清掉（BV15x41117f7 @ 28:18）。
- **守住野怪比抢人头重要**：对面李白时野区不要留野怪，龙和兵线也都能给他刷技能（BV15x41117f7 @ 27:41、BV15x41117f7 @ 28:00）。
- **越塔靠二技能**：先肉身抗第一次塔伤，再用二技能规避第二次并把目标转给小兵，重置塔伤后小兵从初始值累加，最少少挨两次塔攻（BV1uL411q7u9 @ 02:18、BV1uL411q7u9 @ 02:33）。

- 百穿（异变 + 隐匿 + 鹰眼）：李白靠二技能和大招打伤害，所以蓝色带隐匿加攻击而非狩猎（BV15x41117f7 @ 07:29、BV15x41117f7 @ 09:29）。

**出装**

- 新手套：追击刀锋（先做打野刀收益更高）→ 攻速鞋 → 小吸血刀 → 黑切 → 破军 → 冰矛，大后期复活甲 / 名刀换着用代替冰矛（BV1jQWd6EEeF @ 23:18、BV1jQWd6EEeF @ 23:25、BV1jQWd6EEeF @ 23:51、BV1jQWd6EEeF @ 24:31）；吸血刀、黑切之后先把打野刀升三级再做破军（BV1jQWd6EEeF @ 24:59）。
