# 元辅：对线靠手长，团战靠流刷盾，圣杯一做就是强势期

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份 14 分钟全局实战讲解（BV1yeUUBPE2F）、一份排位实录带出装与技能取舍（BV1qa41zGENU）、一份保姆级新手教学（BV1As44zKEZC）、一份扫盲向机制拆解（BV1Y1Jp6zEB5）、一份压塔节奏实录（BV1P3Gt6XEQV）。
> ⚠️ 五条素材口径不完全一致：BV1yeUUBPE2F 把二技能当核心（护盾/视野/跃迁），BV1qa41zGENU 却说"二技能永远当做一个最没用的技能去用"（@ 05:48）——本卡两说并列，不强行合并；具体数值（护盾量、流层数收益、CD）与大逆风处理均未覆盖。

## 1. 机制内核

1. **一技能（急流）= 全家的发动机**：周围的野怪、英雄、小兵越多，攒的流越多，最高九层，同时让二、三技能 CD 减半（BV1As44zKEZC @ 00:52）。本质是回血 + 击退 + 刷新技能，而且"周围的人和小兵越多，原辅一技能提供的回复也就越多"（BV1Y1Jp6zEB5 @ 04:53）。
2. **二技能 = 台子，不是单纯的盾**：生成圆圈，队友走进去获得护盾，护盾随流增厚，最多叠三层（BV1As44zKEZC @ 01:43）。台子可以升到三级，一到三级的护盾能累加，"厚度大概是张飞那个盾的两倍"（BV1Y1Jp6zEB5 @ 05:30）。
3. **台子还白送射程和闪现**：站在台上相当于常驻逐日，自己站台享受双倍射程（BV1Y1Jp6zEB5 @ 05:08）；台子还提供闪烁，但"如果你走的太慢，可能就触发不了这个闪烁"（@ 05:39）。
4. **二技能兼探草**：可以用来击退敌人和探草，所以探草要用二级台——"一级台子的视野范围很小，用一级台探到人是很危险的事情"（BV1Y1Jp6zEB5 @ 09:26）。
5. **三技能 = 群体奶 + 群体伤害 + 移速**：给队友群体回血、给敌方群体扣血，同时给队友提 10% 移速（BV1As44zKEZC @ 02:53）。但"只有在命中敌人时可以给自己回血，如果是空放则不回血"（BV1Y1Jp6zEB5 @ 06:14）。
6. **大招能借墙反弹**：撞到墙体反弹，实现多倍伤害和多倍治疗（BV1Y1Jp6zEB5 @ 06:19）。
7. **大招取消二技能后摇**：二技能后摇僵直很长，单放二技能没法快速机动；"三技能可以增加元辅移速，并且取消二技能后摇"（BV1Y1Jp6zEB5 @ 06:01），所以三二是位移连招。
8. **被动是四条属性自选一**：被动给法强，还能从血量/法穿/移速/冷却里选一种额外提升，可在泉水切换，"一般是前期带生命，中期带冷却"（BV1Y1Jp6zEB5 @ 04:36）。另一份素材把选项说成"加移速、加CD、加生命"，前期对线加生命或伤害都行，推塔游走时再换移速（BV1As44zKEZC @ 07:23）。
9. **一技能给大招减 CD，还送一个免费大**：一技能可以给自己大招减 CD（BV1qa41zGENU @ 05:19）；一技能攒能量，能量可以让第一个大免费用（@ 05:33），"一个一技能配大可以免费用一次"（@ 06:41）。
10. **二技能后期是三段**：元辅二技能有三段，可以叠加三段消耗（BV1As44zKEZC @ 05:57）。

## 2. 对线 / 打法

- **开局先套公式**：按"一野二边三射四中"的顺序判断——先看要不要参与野区攻防，再看边路能不能出一血，再看能不能帮射手拿红隼，最后看中路能不能抢线（BV1yeUUBPE2F @ 00:08）。元辅"没有留人手段，也拿不到一血"（@ 00:26），所以边路这一档经常直接跳过。
- **默认跟射手**：开局不用跟中单，"元辅最强大的点就是他的对线能力"（BV1P3Gt6XEQV @ 00:14）；另一份素材则因为怕对面东皇进野区而选择先抢中（BV1qa41zGENU @ 01:08），按对面打野动向二选一。
- **靠手长换血**：元辅手很长又有护盾，"可以像嫦娥一样，嘎嘎给对面换血"（BV1As44zKEZC @ 03:48）；换血手法是二一接强化普攻，不要拿两层护盾硬顶，因为"第二层的护盾量会少一半"（BV1yeUUBPE2F @ 02:43）。
- **站位在河道**：对线时站在河道放二技能，用台子的视野让对线更安全（BV1yeUUBPE2F @ 03:16）；如果对面中辅已经漏了视野，就没必要再放二技能看视野，直接等对面来补兵（@ 03:23）。
- **二技能别贴墙**：贴墙放会导致"走不出去，不能用位移过墙"（BV1yeUUBPE2F @ 02:11），这是实战里最常见的失误点。
- **开局先存流**：卡两个小兵、A 一下小鸡让流重新进 CD，再上线压人（BV1P3Gt6XEQV @ 00:33）；压深了要"多看小地图"，否则对面打野包过来没有撤退空间（@ 01:37）。
- **卡线是必修**：核心原理是让对手去推兵线，把线固定在自己塔前，对面想吃线就得冒塔和过河被抓的风险（BV1Y1Jp6zEB5 @ 10:24）；"元辅是一个对线期强势的辅助英雄"，所以理解卡线是必须的（@ 10:37）。辅助不要帮射手补刀，会打乱射手的补刀节奏（@ 10:45）。
- **ban 位**：先把邵思源 ban 掉，其次太乙，"就比较怕这两个"（BV1qa41zGENU @ 00:38）。

## 4. 中后期 / 节奏

- **圣杯到手就换挡**：7 分钟圣杯做出来后"技能有就放，不用省蓝"，靠二技能跃迁赶路（BV1yeUUBPE2F @ 07:45）。
- **4 分钟后蓄意抢中**："我们4分钟后能抢中，就要蓄意抢中"，把视野排好，每波都拿线权（BV1yeUUBPE2F @ 09:35）。
- **抢完中二选一**：去反野，或者用二技能跃迁 + 大招加速去支援队友（BV1yeUUBPE2F @ 09:45）。
- **强守塔阵容先拆边**："这种对面有强守塔英雄的情况，最好是先压对面的边路塔，然后再拆中路塔"（BV1yeUUBPE2F @ 11:24）。
- **三路齐压**：把三路兵线一起截掉再压，对面就有两条线以上的压力，很难反手（BV1yeUUBPE2F @ 11:35、@ 10:17）。
- **用盾替队友抗塔**：开二技能直接抗塔、让小兵少抗一下，队友强拆（BV1yeUUBPE2F @ 13:51、@ 12:06）；"利用护盾扛塔的行为，玩原辅要多做"（@ 12:37）。
- **站位要往前**：现在版本"元辅要玩的骚才能玩的好"（@ 12:44）；出冰甲后很肉又有韧性，可以站位靠前把视野做好，还能一直用大招消耗（@ 06:21）。
- **顺风滚雪球是软辅最强一档**："顺风滚雪球的能力是软辅最强的一档了"（@ 09:05）。
- **别为回血错过窗口**：为了回血去看红区，结果"错过了时机，让玄策拿到红了"（@ 10:58），该反野时优先反野。
- **龙团顺序**：队友阵亡、红区不好反时，"抢完中去拿暴君才是最稳妥的做法"（@ 09:24）。

## 5. 出装铭文

**核心路线（BV1yeUUBPE2F / BV1Y1Jp6zEB5）**

- 核心装是圣杯：改版后二技能要更经常释放，所以"出完小极影后就出圣杯"，7 分钟成型（BV1yeUUBPE2F @ 06:08）。
- 圣杯之后接冰甲，容错比较高；有了跃迁后可以用冰甲区域冰刃打控制，同时冰甲很肉、有韧性、不怕被控（BV1yeUUBPE2F @ 06:14）。
- 冰杖是替代方案：对面突进早、自家前排够的时候可以出（BV1yeUUBPE2F @ 06:30）；冰杖三次叠减速，元辅大招可以远距离快速叠满（BV1qa41zGENU @ 13:02）。
- 完整顺序：宝石 → 蓝宝石 → 秘法鞋 → 黄盾（辅助装）→ 大辅 + 圣杯 → 布甲鞋 → 大斧 → 救赎 → 雪山圆盾；之后劣势做冰杖、均势/优势做旭日斗篷、对面法伤高先做魔女（BV1Y1Jp6zEB5 @ 07:37）。
- 后期救赎可以换成形昭（BV1P3Gt6XEQV @ 10:14）。

**铭文**

- 坦辅调和一套即可（BV1Y1Jp6zEB5 @ 07:35）；也可出宿命 + 千血，因为元辅技能受生命值增益，宿命还带物理防御（BV1qa41zGENU @ 00:13）。
- 另一份素材直接建议用系统自带的三套推荐出装，新手出纯肉、要打伤害走法强流（BV1As44zKEZC @ 00:28）。

**鞋与召唤师技能**

- 蓝不够时别急着换鞋，等蓝回满再切 CD 鞋，CD 到 35 技能转得更快（BV1qa41zGENU @ 07:26、@ 08:07）。
- 抵抗鞋 + 冰甲的韧性，被木兰推了也"还是能开出技能"（BV1yeUUBPE2F @ 14:20）。
- 召唤师技能：新手带净化保下限（被控后三二拉开距离），高手带闪现提上限（BV1Y1Jp6zEB5 @ 08:17）。
