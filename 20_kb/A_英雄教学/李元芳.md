# 李元芳：一级先想办法到二，二技能决定玩得好不好

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份"破军流"实战复盘（BV1Yx421D7hC，赛季第一天打到 1500 分、对线孙尚香的一整局）+ 一份连招与对线理论（BV1dt411P7Yg，三种连招分类、被动侦查、技能细节拆解）。
> ⚠️ 两份都没有给铭文的具体内容；破军流只讲了开局两件（布甲/铁剑）、电刀与"破军是杀手锏"，完整出装顺序未覆盖。

## 1. 机制内核

1. **一技能是核心输出**：能"秒掉大部分的战士、脆皮"，期间增加攻速与射程，"让元芳自带逐日之弓"；该技能"可以对防御塔使用 拆塔速度非常快"（BV1dt411P7Yg @ 08:19~08:32）。
2. **一技能可以借物挂标**：打不到人时，"可以利用小兵或者野怪或者防御塔提升攻速、射程 打中敌方英雄"（BV1dt411P7Yg @ 08:34~08:42）。
3. **二技能是保命技能**：用于"逃生追击"，也能当封路手段——"往敌方撤退的那个位置身后放二技能"来减速封路（BV1dt411P7Yg @ 08:46~09:02）。
4. **二技能范围反直觉**："实际伤害距离比那个指示器多出两个身位"；反过来"同时跟敌人保持一个身位 或者位置和敌方英雄重叠 是没法造成伤害的"（BV1dt411P7Yg @ 09:04~09:25）。
5. **大招伤害不高，功能大于伤害**：主要作用是"叠加一技能的层数"、封退路、分割战场；内圈"可以造成双倍伤害"（BV1dt411P7Yg @ 09:41~10:02）。
6. **被动是移动侦察**：探草能直接看到蹲的人，也能"看到隐身的敌人"，如兰陵王、阿轲、鬼谷子、守约（BV1dt411P7Yg @ 07:52~07:56）。

## 2. 对线 / 打法

- **出门先不学技能**："我们一般出门不要学习技能"，到兵线先确认对位是谁，因为对面可能换路（BV1dt411P7Yg @ 12:36~12:43）；对面不知道你学一还是学二，"这个时候你可以就是吓跑他"（BV1dt411P7Yg @ 12:50~12:53）。
- **学一还是学二看对面反应**：一技能打上去能打残，"如果他跑了 二技能直接把兵线清掉 快速升到二级"；对面要刚到底就"学一技能 满层数的一技能"（BV1dt411P7Yg @ 13:05~13:29）。
- **对坦克直接学二**："是坦克的话 就直接学二技能 不用管 直接学二技能快速清线 他打不死你啊"（BV1dt411P7Yg @ 13:41~13:46）。
- **一级的唯一目标是到二**："元芳第一个目标就是要想办法升到二级"，因为一、二技能单独用都很难打出效果（BV1dt411P7Yg @ 11:25~11:45）；"到了二级之后 元芳就有质变的能力"（BV1dt411P7Yg @ 13:50~13:53）。
- **开局布甲防卡线**（对孙尚香）："开局预购一手布甲 这一步是防止有些孙尚香一级会卡你的线 出布甲可以硬吃他的伤害"（BV1Yx421D7hC @ 00:14~00:20）；对面不卡线就"正常出铁剑"（BV1Yx421D7hC @ 00:23~00:25）。
- **塔下补兵把兵线卡在外面**，否则"很容易就会和我一样补不到兵线"（BV1Yx421D7hC @ 00:31~00:35）。
- **第二波提前进草**："现在峡谷地图变大了 第一个小兵很容易被卡掉 提前来到这个草丛 可以避免被卡掉"（BV1Yx421D7hC @ 00:40~00:48）。
- **对面打野没露就别把线卡在外面**（BV1Yx421D7hC @ 00:56~00:58）；对面来抓就缩塔，"前期他们不来四五个人是不敢越塔的"（BV1Yx421D7hC @ 01:20~01:26）。
- **4 级前压着打**："元芳四级之前尽量压着敌方打"，很多战士要 4 级才有作用；但遇到"有控有位移的"橘右京要小心（BV1dt411P7Yg @ 15:19~15:35）。
- **对反打强的英雄不要先交二**：孙策、李信、橘右京、狂铁这类，"你二技能滚过去 人家一套打到你身上来"，"他满血的时候不要跟他杠"（BV1dt411P7Yg @ 01:07~01:32）。
- **该换线就换线**：遇到阿离、狄仁杰、百里守约，"尽量要求和队友换线"——阿离"可以用扇子挡住你的一技能"，狄仁杰二技能"可以直接把你那个标给解掉"，守约"不跟你对 他就在前面狙你"（BV1dt411P7Yg @ 15:38~16:09）。
- **抓中路别暴露视野**："你在下路清完一波线了 你就直接往中路走了 别人的中路只要有点意识 就知道你要去抓他"（BV1dt411P7Yg @ 18:57~19:06）。

## 4. 中后期 / 节奏

- **先推一塔再谈其他**：前期只要不对线很强的上单，元芳能把下路一塔耗掉大半；4 分钟炮车兵来了还推不掉，"一定要叫队友来帮忙"，"这样才能解放元芳"（BV1dt411P7Yg @ 16:42~16:55）。
- **推塔后直接进对面野区**："趁敌方打野GANK不在的时间可以偷野偷Buff"，既发育又"打断敌方的进攻节奏"（BV1dt411P7Yg @ 17:11~17:37）。
- **顺风围绕对面野区打**：大优势时"可以过来和廉颇快速把兵线带过去 对面是不敢守这个蓝的"；优势不大时"一定要优先过来给对面压力"（BV1Yx421D7hC @ 05:02~05:16）。
- **搜刮完野区再转**："队友来蓝区了 那我们就去对面红区 让对面拿不到野区资源 这样他们就没有翻盘的机会"（BV1Yx421D7hC @ 05:56~06:05）。
- **不要在线上待太久**："千万不要在长期带线线上待太久"，破塔后局势打不开就"和队友进行一个换路 我们去上路继续拆"（BV1dt411P7Yg @ 19:14~19:33）。
- **一次掉点就可能被翻**："你要知道你可是全队拿了最多人头、最多经济 没有你 队友那边打团是完全打不过"（BV1Yx421D7hC @ 04:47~04:53）。
- **不要一个人转线**："清完这波兵线 对面不漏就不要转线了 因为这个时候 对面大概率会在你回防的路上蹲你"（BV1Yx421D7hC @ 04:34~04:39）。
- **龙的处理**："优势局拿暴君 逆风局拿主宰"（BV1Yx421D7hC @ 06:07~06:09）；打野不喜欢开龙"我们自己也是可以开龙的"（BV1Yx421D7hC @ 03:01~03:03），"元芳打龙很快"（BV1dt411P7Yg @ 20:04）。
- **破军多数时候等不到**："很多时候其实等不到我们破军出来就已经赢了 破军算是杀手锏"（BV1Yx421D7hC @ 06:38~06:42）。
