# 李元芳：前中期节奏射手，推塔滚雪球终结比赛

> 只讲英雄本身。分路思路见 `L_分路/` 对应分路卡。
> 素材：天小奔《双16破军流李元芳全局教学》（BV1Yx421D7hC，破军流出装的全局实战思路）、西汪xhope《必学射手李元芳剖析打法思路》（BV1dt411P7Yg，连招理论 + 对线期心法）。

| 项 | 内容 |

| **节奏职责** | **推塔开节奏**——第一波节奏从推掉下路一塔开始，随后入侵野区、抓中路（BV1dt411P7Yg @ 16:21、@ 16:30） |

## 1. 机制内核：被动是侦查器，二技能是命

1. **被动能看到草丛和隐身单位**——"我直接能在草丛旁边就可以看到你在蹲草了"，所以元芳几乎不怕被蹲（BV1dt411P7Yg @ 04:36）；兰陵王、阿轲、鬼谷子、守约这类隐身英雄在被动面前也藏不住，"这些英雄要切元芳要付出很大的代价"（BV1dt411P7Yg @ 07:52）
2. **一技能是核心输出**——加攻速和射程，"让元芳自带逐日之弓"，还能对防御塔使用，拆塔速度非常快（BV1dt411P7Yg @ 08:19-08:29）；打不到人时可以借小兵、野怪或防御塔把攻速射程叠起来再打英雄（BV1dt411P7Yg @ 08:34）
3. **二技能是保命技，不是进场技**——"二技能是决定一个元芳玩的好和玩的不好的区别"，要练到能躲主宰击飞的程度（BV1dt411P7Yg @ 04:01、@ 04:08）
4. **二技能判定有陷阱**——实际伤害距离比指示器多出两个身位，但和敌方英雄位置重叠时反而打不出伤害（BV1dt411P7Yg @ 09:10、@ 09:21）
5. **大招伤害不高，作用是叠层和控场**——内圈双倍伤害，主要用来叠一技能层数、封撤退路、把敌方前排和 C 位分割开（BV1dt411P7Yg @ 09:41-10:11）

## 2. 对线：第一目标是抢二

- **一级二级区别很大**：学一技能清线慢但能压制敌人，学二技能清线快但交了就会被追着打——所以"对线期的第一个目标就是要升到二级"（BV1dt411P7Yg @ 11:10-11:28）
- **出门先不学技能**：到线上看清对线英雄再决定学一学二，对面不知道你学什么时"他是有点怂的"（BV1dt411P7Yg @ 12:35-13:03）
- **对线坦克直接学二**：他打不死你，快速清线就行（BV1dt411P7Yg @ 13:41）
- **四级前尽量压着打**：很多战士要四级才有作用；但橘右京这种有控有位移的要从一级就小心（BV1dt411P7Yg @ 15:19-15:32）
- **反打能力强的战士（孙策、李信、橘右京）不要用二技能贴脸**：满血不跟他杠，先用一技能把血线压到一半，算好一二技能伤害再 12AAA 带走（BV1dt411P7Yg @ 01:07-01:50）
- **遇到阿离、狄仁杰、百里守约尽量换线**：阿离用扇子挡一技能、狄仁杰二技能解掉印记、守约根本不跟你对线只在前排狙你（BV1dt411P7Yg @ 15:39-16:05）
- **对线孙尚香开局预购布甲**：防止一级被卡线，布甲可以硬吃她的伤害（BV1Yx421D7hC @ 00:14-00:20）
- **抓中路法师是元芳强项**：对面法师偷猪深入野区，二级元芳连他有闪现都能留住；213 一套可以直接带走大部分法师（BV1dt411P7Yg @ 14:34-14:41、@ 18:19）
- **对妲己这类点控法师不要先交二**：二技能必须留着躲控制技能（BV1dt411P7Yg @ 18:24）

## 3. 连招：按对方有没有位移分三种起手

| 场景 | 连招 | 为什么 |
|---|---|---|
| 无位移 + 一个闪现（姜子牙、嬴政） | **213AA** | 二技能近身、一技能套上，三技能往他**身后**放，防他闪现逃（BV1dt411P7Yg @ 00:26-00:52） |
| 反打能力强的战士满血 | **1 技能压血 → 12AAA** | 千万不要二技能滚上去送，压到半血算好伤害再进（BV1dt411P7Yg @ 01:22-01:50） |
| 蹲草遇脆皮 / 坦度一般的战士 | **1 技能先手 → 等他交位移 → 2 技能贴身 → 3 技能封路** | "一定要等他的位移"，交掉位移的那一刻再上（BV1dt411P7Yg @ 03:18-03:38） |
| 蹲草遇坦克 | **只套 1 技能消耗** | 技能别扔给坦克，除非他和队友脱节一个人探草（BV1dt411P7Yg @ 02:04-02:47） |
| 被刺客贴脸 | **大招往自己脚下扔** | 减速延缓进攻节奏，打得好还能反杀（BV1dt411P7Yg @ 10:35） |

> 原话："二技能一定要用作规避致命伤害，就比如花木兰的一技能、光信的大招。"（BV1dt411P7Yg @ 03:50-03:53）
> 被动侦查的正确用法："探草的时候一步一回头，二技能时刻捏着，看到人就退。"（BV1dt411P7Yg @ 07:06-07:20）

## 4. 中后期：推塔 → 入侵 → 抓中，别赖线

- **推完下路一塔才有节奏**：4 分钟炮车兵来了还推不掉一塔，一定叫队友来帮忙，"这样才能够解放元芳"（BV1dt411P7Yg @ 16:42）
- **一塔推完进敌方野区偷野偷 Buff**：趁对面打野在上路 GANK 时冲他家蓝 Buff，自己发育还打断敌方节奏（BV1dt411P7Yg @ 17:11）
- **下路线权在手就清线游走**：游走在中路和敌方野区之间，元芳抓中路能力很强（BV1dt411P7Yg @ 17:51）
- **不要长期赖在线上**：打法偏节奏型，一路破了局势打不开就和队友换路去上路继续拆（BV1dt411P7Yg @ 19:14）
- **顺风局围绕对面野区打**，连小的中立资源都不要放过（BV1Yx421D7hC @ 05:02、@ 05:32）
- **优势局拿暴君，逆风局拿主宰**；打野不开龙时元芳自己也能开，他打龙很快（BV1Yx421D7hC @ 06:07-06:09；BV1dt411P7Yg @ 19:50-20:04）
- **你是全队经济最高的点，一次掉点节奏就被逆转**：对面不漏视野就不要转线，回防路上大概率有人蹲；能秒你的敌人不交大招你就不过去，"宁可晚输出一会也不要开团就被秒"（BV1Yx421D7hC @ 04:39-04:48、@ 02:19-02:24）
- **保命顺序记死：先用二技能，再用闪现**（BV1Yx421D7hC @ 02:08）
- **清线手法**：敌人位置不明就用大招清线，出了电刀可以直接用电刀被动清（BV1dt411P7Yg @ 20:20-20:25）
- **破军是杀手锏不是刚需**：这套破军流"很多时候等不到破军出来就已经赢了"，越往后期拖这套出装越有利（BV1Yx421D7hC @ 06:38、@ 01:09-01:12）
