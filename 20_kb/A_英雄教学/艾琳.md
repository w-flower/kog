# 艾琳：靠手长白嫖血量，靠容错活到帽子成型

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：5 份，3 份法装全局（法装中分段、纯白艾琳巅峰赛、纯法核爆流），1 份 AD / 圣剑两套出装的横向对比与铭文，1 份"逆天开局 + 小明"的逆风处理。
> ⚠️ 五份都是实战解说，**大招层数上限、每层伤害、技能冷却这些机制数值没有一份讲清**；对线只覆盖马瑶、马可、狄仁杰、孙策等零散对位，没有完整对位表。

| **节奏职责** | **跟团**：以发育路经济为核，队友围绕她推进、她负责输出与收割（BV1aCbZzgE4g @ 03:51；BV1j4h3zpEHA @ 05:52） |

## 1. 机制内核

1. **伤害结构是法伤**：一技能远程、大招锁头，AD 流的大招依然算法伤，所以对面做完魔抗后大招会刮痧（BV1aCbZzgE4g @ 02:38~02:48）
2. **一技能是对线核心**：手长，"除了开大的黄忠，没有任何的射手比我们的手长"；纯法下一个一技能前期伤害就很高（BV1Z4PmeeEfF @ 00:25~00:41）
3. **二技能给后撤 / 滑步并免疫减速**，这是她比常规呆射多出来的一层容错（BV1Z4PmeeEfF @ 01:02；BV1j4h3zpEHA @ 03:18、@ 03:26）
4. **大招按层数打爆发与收割**：需要平时用一二技能和强化普攻叠层，成型后 CD 约十秒（BV1Z4PmeeEfF @ 03:14~03:18、@ 05:13~05:16）
5. **一技能 + 圆环可以补收人头**（BV1Z4PmeeEfF @ 00:58~01:00）
6. **容错主要来自法装**：吸血书提供续航和坦度，"不容易被秒"（BV1rvVYzyEY5 @ 07:57~08:05）

## 2. 对线 / 打法

**开局判断**

- 先看地图：对面辅助不跟射手就抢线，跟射手就直接清后线（BV1j4h3zpEHA @ 00:14~00:29）
- 一技能必须全中才抢得动线，空一发就往后拉（BV1j4h3zpEHA @ 00:47~00:51）
- 用 2v2 强度判断河灵能不能抢，打不过就让（BV1j4h3zpEHA @ 01:26~01:36）
- 这个赛季辅助基本发育路开，抢小鸟要先抢线再打（BV18Ba8e3E3q @ 00:33~00:43）
- 看对面射手第一件：狄仁杰出斗篷的话，前期完全不用怂（BV18Ba8e3E3q @ 00:24~00:32）

**对线与补刀**

- 打任何前期没有回复能力的射手 / 辅助，优先打人不打兵，把状态压低，4 级才有单杀机会（BV1Z4PmeeEfF @ 00:17~00:23）
- 一技能丢完就后退，用射程白嫖；就算没正中，一技能 + 魔道之石的伤害也很可观（BV1Z4PmeeEfF @ 00:30~00:38）
- 补尾刀：尾刀多 30% 的经验和经济（BV18Ba8e3E3q @ 01:35~01:37）
- 卡线：当敌方攻击目标是兵线而不是你时，"他注定打不过你"（BV1j4h3zpEHA @ 03:05~03:10）
- 4 分钟可以拆塔，但对面有盾时不好压（BV1j4h3zpEHA @ 02:26~02:29、@ 04:06~04:10）
- 前期尽量不转线，除非已经推掉对面一塔；中单 / 边路没漏视野时转线风险极大（BV18Ba8e3E3q @ 01:57~02:04、@ 02:39~02:42）

**逆风处理**

- 经济必须高于对面射手并稳居团队第一，"逆风一直跟着队友抱团你是不可能有前途的"（BV1aCbZzgE4g @ 03:10~03:33）
- 对面全做魔女时先补法穿（BV1rvVYzyEY5 @ 07:30~07:33）
- 逆天开局（两个射手、两个法师）时先稳住自己节奏，队友投降也不用管（BV18Ba8e3E3q @ 00:08~00:15、@ 04:10~04:24）

## 4. 中后期 / 节奏

- 10 分钟前要把大书做出来，8 分半做出来算优秀（BV1j4h3zpEHA @ 08:29~08:36）
- 帽子出来是最强强势期，要在这个窗口打架与拿资源（BV1j4h3zpEHA @ 05:29~05:31）
- 有优势就多拿资源，"不要浪费这些时间"（BV1j4h3zpEHA @ 05:16~05:20）
- 压塔不要站太靠前，一技能放完立刻往后拉（BV1j4h3zpEHA @ 11:38~11:44）
- 团战先点塔、等对面来找，兵线在自己手上才有主动权；大招留着打反手（BV1aCbZzgE4g @ 03:55~04:04）
- 10 分钟开龙；逆风也要强调龙，"很多次被翻盘都是因为打野顺风不爱开龙"（BV1rvVYzyEY5 @ 10:27~10:28；BV1aCbZzgE4g @ 03:34~03:47）
- 6 分钟清完线不能一直待在发育路，要换线（BV1rvVYzyEY5 @ 06:00~06:03）
- 输出环境差时大招 + 狂暴一起开（BV18Ba8e3E3q @ 05:40~05:42）
- 兵线差就提前开龙；对面少人时打凶一点（BV18Ba8e3E3q @ 07:03~07:05、@ 07:20~07:30）
- 可以放弃打龙先打掉点，"掉点打了那这个龙还不是一样是你的"（BV18Ba8e3E3q @ 09:28~09:41）
- 后期"我如果一死的话就直接一波了"，站位优先于输出（BV1rvVYzyEY5 @ 14:34~14:40）

## 5. 出装铭文

**流派选择（不是喜好，是阵容）**

- 输出环境不好 / 对面有宫本这类突进 → 圣剑（法装）；对面坦度高、自家法伤多、输出环境好 → AD；对面是凯、海诺这种圣剑打不动的 → AD（BV1aCbZzgE4g @ 00:35~00:52）
- AD 强在平 A，对线和打前排强于法装，但逆风与抗压不如法装（BV1aCbZzgE4g @ 01:44~01:47）
- AD 主加一技能，前期一技能伤害与法装差不多，但平 A 伤害远高于法装（BV1aCbZzgE4g @ 01:35~01:41）

**法装散点**

- 核心是吸血书：稳定、有续航、坦度高、不容易被秒，"吸血书的胜率就会比回响要高"（BV1rvVYzyEY5 @ 07:57~08:09）
- 对面没控制时吸血书 > 炽热；控制多才把吸血书换炽热（BV1aCbZzgE4g @ 02:08~02:13、@ 04:53~04:55）
- 其余散点：法穿鞋 / 抵抗鞋（BV1Z4PmeeEfF @ 01:17；BV1j4h3zpEHA @ 11:52）、帽子（BV1j4h3zpEHA @ 05:29）、大书（BV1j4h3zpEHA @ 08:29）、金身 / 辉月（BV1Z4PmeeEfF @ 05:03）、最后一件输出环境好辉月换巫妖、大后期换大书（BV1aCbZzgE4g @ 04:55~04:58）

**AD 散点**

- 影刃（不推荐逐日：逐日让艾琳太笨重，被动也不契合）；对面回血多出制裁，否则末世；最后一件破军 / 宗师 / 苍穹 / 爆裂都可以（BV1aCbZzgE4g @ 04:32~04:47）

**铭文**

- AD：十夺萃 + 十心眼 + 十祸源（BV1aCbZzgE4g @ 04:24~04:26）
- 法装：十贪婪 + 十心眼 + 十梦魇（BV1aCbZzgE4g @ 04:47~04:50）
