# 雅典娜：把"强普 + 护盾免控"用到极致的野核

> 只讲英雄本身。分路思路见 `L_分路/05_打野.md`。
> 素材：兜兜里有大伊万（1.9 万分国服 445 老师，巅峰千强对位国服阿古朵，BV1DSPtz4EM9）、445 本人百强带飞局（BV1Rkui6QExF）、零基础焚诀（BV1ip4EzeEZC）。

## 1. 机制内核：三个信息差

雅典娜的强度全在这三条"技能说明里没写清楚"的地方：

### 1.1 一技能：1 秒护盾 + 免控，命中刷新二技能并击退

- **能吃掉的控**：孙策大招、苏烈大招、钟馗钩子、老夫子大招（BV1ip4EzeEZC @ 00:14）
- **生效范围比指示器远**：二技能的**大圆**和英雄**脚下的小圆**相交就命中——**相切不行**（@ 00:32）
- 残血时**优先放一技能**（护盾能补血、能反杀，BV1Rkui6QExF @ 05:41）

### 1.2 二技能：位移 + 强化普攻，戳到敌人身后，血量越低伤害越高

- **强普触发后，无论闪现还是位移都会跟过去**（BV1ip4EzeEZC @ 01:14）
- **二技能是无影步，不暴露视野** → 可以用来卡视野、当踏板（@ 01:14）

### 1.3 大招：受的攻击越多，炸得越快越疼

- 开大期间受到的攻击会增加爆炸伤害、并**减少所需时间**，**最高 5 层**（BV1Rkui6QExF @ 00:45、BV1ip4EzeEZC @ 05:05）
- 所以大招要**在敌人攻击频率高的时候开**，才容易创造奇迹

**由此直接推出一个克制关系**：雅典娜**克制戈雅**这类攻击频率高的英雄（BV1Rkui6QExF @ 00:45）——他打得越猛，你的大炸得越早越疼。这条已记入 `B_克制关系/` 待补。

## 3. 核心连招：一切围绕"推塔键"和"踏板"

### 3.1 五个步骤（所有连招的母版）

BV1ip4EzeEZC @ 02:27 把它标准化了：

```
① 存枪 → ② 拉视野 → ③ 找目标 → ④ 选踏板 → ⑤ 等 CD
→ 完成后点【推塔普攻】或【补刀键】→ 接二一 → 戳 → 二戳
```

**"踏板"是雅典娜独有的概念**：野怪、小兵、防御塔都可以当踏板，用来刷新二技能、缩短距离、或让自己安全脱身。

### 3.2 三个常用变体

| 连招 | 做法 | 用在哪 |
|---|---|---|
| **二戳一（撕咬）** | 二技能戳 → 等一技能好 → 再戳，反复 | 对面有闪现/位移且**没有踏板**时，无限追击（@ 01:49） |
| **蹲草连招** | 只点一二技能，出伤最快 | 反过来，**不能点太快**（@ 02:27） |
| **踏板连招** | 存枪 → 用野怪当踏板 → 戳脆皮 | 脆皮常在小猪那回血，直接踏板戳过去（@ 02:10） |

### 3.3 防御塔技巧：戳进去，再戳回来

目标在防御塔左边时，可以做到**完美撤离**：

```
先点推塔键 → 二一戳 → 最后接补刀键
```

只要在防御塔范围内，**二技能接戳都能戳得到**，所以能"用防御塔再戳回来"（@ 03:11）。**越塔时多用一技能和大招规避防御塔伤害**（BV1DSPtz4EM9 @ 06:34）。

## 4. 刷野与发育：24 秒存枪，惩戒先放

- **24 秒存一枪**，两枪双珠一起戳（BV1DSPtz4EM9 @ 00:14）
- **惩戒一定要先放再接强普**，这样额外百分比伤害会更高（@ 00:28）
- 刷野时**留一枪赶路**，能提高刷野速率和连贯性（BV1Rkui6QExF @ 01:50）
- **锁后排兵再锁前排兵**，抢线效率最大、补刀率高（@ 01:16）

## 5. 全局：错开时间，不正面碰

### 5.1 三级过中，和对面打野错开野区刷新时间

BV1DSPtz4EM9 @ 00:28：

> 三级过中，和对面打野**错开野区刷新时间**，避免相同时间正面打架。利用时间差先手帮中过线，或者后手双边抓人。

**这是雅典娜的核心节奏观**：她不是"打得过才打"，是"**永远在对面不在的时候吃他的资源**"。

### 5.2 优势时的滚雪球顺序

@ 04:09 给的顺序很清楚：

```
团战打赢 → 第一件事看哪边有线
→ 有优势线就做推塔节奏 → 塔掉了挤出更多视野 → 有先手权 → 更好入侵野区 → 拉开经济差
```

### 5.3 推塔不用推完

@ 03:10：**推塔剩下一点血量可以让小兵磨掉**，省下来的时间可以多刷一到两组野，跟对面拉开经济差。

（**注意**：这条要看阵容。原话也说了"建议没有优势的不要这么做，本来拿了经济没作用就要变成罪人"。）

### 5.4 脚下的 Buff 会暴露你的野区

@ 03:24：**对面可以根据你脚下的 Buff 判断你的野区**。所以带线时要注意，必要时发信号让队友帮忙看红区。

### 5.5 三线不要同时漏

@ 07:18：要推进就得**运三线**。下路射手要**等上路过完再去清线**，**千万不要三路线同时漏**，否则容易被抓单。

## 8. 版本实话（445 本人说的，值得先看）

BV1Rkui6QExF @ 00:00 是一段自嘲，但信息量很大：

> 雅典娜**上限是低的**，胜率是被**献祭流**带起来的，国榜分是不高的，**强度是 T3** 的，机制是落后的，是**容易被打野对位**的。

**读法**：这段话是"劝退"式反讽（目的是防止国榜分被卷高），但它侧面确认了三件事：

1. 雅典娜的**上限不算高**，靠的是节奏和信息差，不是硬实力
2. 她的**胜率数据被"献祭流"抬起来了**，看数据时要区分打法
3. 她**怕被针对**——打野对位是她的弱项

**这条与本库的规矩一致**：强度判断必须挂来源和语气，不能直接当"T3 别玩"的结论用。
