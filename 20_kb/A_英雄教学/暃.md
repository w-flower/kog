# 暃：墙上换距离，下墙换爆发

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：三份——一份六个"魔鬼细节"的技巧合集，含操作设置与两套连招（BV1YLKAzhEG2）；一份"裸红刀破军"的科研流，给到数值对比与刷野路线（BV1xGQwBCEAR）；一份巅峰 2000 分逆风实战复盘，讲节奏和进场纪律（BV1Fzg26bEcp）。

## 1. 机制内核

1. **墙是位移倍率器**：在墙上时一技能的位移距离比墙下更远（BV1YLKAzhEG2 @ 00:45、BV1YLKAzhEG2 @ 00:46），所以"飞"这个英雄的位移强度取决于他站没站在墙上。
2. **二技能接一技能可以瞬突**：跳长墙时，若墙的长度大于二技能指示器的一半，就在释放二技能的瞬间马上接一技能，"速度越快越好"，能瞬间突进三倍距离（BV1YLKAzhEG2 @ 00:51、BV1YLKAzhEG2 @ 01:03）。一技能的距离"在开团以及逃跑时都有奇效"（BV1YLKAzhEG2 @ 01:05）。
3. **大招也能借墙超远位移**："在二技能跳的瞬间马上接大招"，就能打出超远位移，在超远收割时有用（BV1YLKAzhEG2 @ 01:09、BV1YLKAzhEG2 @ 01:15）。
4. **一技能给三次强化普攻**：释放一技能获得三次强普（BV1YLKAzhEG2 @ 02:37）。
5. **墙上强普多一段距离 + 弹射**：在墙上时强普"不仅会获得额外的攻击距离，还会具备弹射效果"（BV1YLKAzhEG2 @ 02:41、BV1YLKAzhEG2 @ 02:45）。这个弹射还能用来磨塔（BV1Fzg26bEcp @ 09:07）。
6. **强普能存**：强普持续七秒，而一技能冷却最短只要三秒左右，所以刷野、赶路、抓人都要"养成提前放一技能存强化普攻的习惯"（BV1YLKAzhEG2 @ 02:47、BV1YLKAzhEG2 @ 02:55）。
7. **大招实际判定远大于指示器**：看起来小，但"无论侧面还是背后，都有大范围的额外攻击判定"（BV1YLKAzhEG2 @ 03:02、BV1YLKAzhEG2 @ 03:12）。
8. **可以用侧判/背判刮人**：二技能飞的过程中，用大招的侧面判定和身后判定去刮对面，"在斩杀残血的同时快速脱离险境"（BV1YLKAzhEG2 @ 03:16、BV1YLKAzhEG2 @ 03:22）。
9. **大招无视不可选中**：李白二三技能、亚连与杨玉环的大招"等都躲不掉"（BV1YLKAzhEG2 @ 03:29、BV1YLKAzhEG2 @ 03:34）。
10. **大招+惩戒提高打野斩杀线**："大招搭配惩戒使用，能让飞对野怪的斩杀线大幅提高"，抢野抢龙都有用（BV1YLKAzhEG2 @ 03:37、BV1YLKAzhEG2 @ 03:41）。
11. **特定墙体全程隐身**：红 Buff 草、边路草、中路一塔草，可以全程隐身跳墙，"在反野和抓边以及反蹲时都有奇效"（BV1YLKAzhEG2 @ 01:22、BV1YLKAzhEG2 @ 01:29）。
12. **中路长草是隐身重点**：中路两边的长草丛"不仅可以上前隐身，而且在跳跃过程中和落地后都会全程隐身"（BV1YLKAzhEG2 @ 01:32、BV1YLKAzhEG2 @ 01:40）。
13. **一技能过草不露视野，但要卡末端**：一技能在草丛之间位移不会暴露视野（BV1YLKAzhEG2 @ 01:44）；但一技能"并不是全程瞬移"，正常释放会露视野，必须让"指示器的最末端被草丛覆盖"才能必定无影步（BV1YLKAzhEG2 @ 01:51、BV1YLKAzhEG2 @ 02:00）。
14. **卡墙要 45 度**：正常释放一技能和大招位移距离很短、容易放空；抓边路时让一三技能"跟墙体保持45度角卡墙释放"，位移会比正常远很多（BV1YLKAzhEG2 @ 02:01、BV1YLKAzhEG2 @ 02:15）。
15. **二技能要卡在敌人路径上**：调整二技能跳的方向，"保证敌方在二技能位移的路径上"（BV1YLKAzhEG2 @ 02:22、BV1YLKAzhEG2 @ 02:25）。
16. **养成"大招下墙"习惯**：先用大招下墙突进，"还可以留着一技能追杀和逃跑，容错率直接拉满"（BV1YLKAzhEG2 @ 02:27、BV1YLKAzhEG2 @ 02:34）。
17. **墙上被控时间加倍**：正因为如此，"抵抗鞋是必出的"（BV1xGQwBCEAR @ 03:14）。
18. **一技能有高额回复**：前期补状态非常快，可以少回家（BV1Fzg26bEcp @ 05:32、BV1Fzg26bEcp @ 05:34）。

## 2. 对线 / 打法

- **开局先要信息**："开局记得让法师看对面打野什么开"（BV1xGQwBCEAR @ 01:16）。
- **红开路线**：如果红开，2 分钟去收对面双野（转写为"双主"，具体野怪名不清）、顺手反一只野怪，"等于和对面打野拉开双倍经济差"，再顺手蹭一波中线（BV1xGQwBCEAR @ 01:18、BV1xGQwBCEAR @ 01:26）。
- **蓝开路线**：对面守约+墨子这种前期压制强的组合，就"开局选择蓝开打下路"，因为抓下路能找到更多优势（BV1Fzg26bEcp @ 00:23、BV1Fzg26bEcp @ 00:28）。对面阿古朵大概率红开抓发育路，打对抗路"也不是很好抢资源刷野"，因为没阿古朵快（BV1Fzg26bEcp @ 00:31、BV1Fzg26bEcp @ 00:38）。
- **蓝开不慢，缺的是细节**：暃蓝开和红开刷野速度差不多，"只不过缺一点细节，稍微拉扯一下野怪就好了…边打边往下个野怪那里走"（BV1Fzg26bEcp @ 00:40、BV1Fzg26bEcp @ 00:49）；飞到一塔、两段跳跳到小猪，比红开慢一两秒（BV1Fzg26bEcp @ 00:50、BV1Fzg26bEcp @ 00:54）。
- **开局就要规划路线**："所以开局就要规划自己的刷野路线，这样的话才比较好打"（BV1Fzg26bEcp @ 00:59、BV1Fzg26bEcp @ 01:03）。
- **刷到下路没机会就清残野**：对面没压塔给机会，就把剩余的野区（猴子）一起刷掉（BV1Fzg26bEcp @ 01:05、BV1Fzg26bEcp @ 01:08）。
- **过中线要带法师**："准备过中线，带着法师一起开节奏"（BV1Fzg26bEcp @ 01:12、BV1Fzg26bEcp @ 01:13）。
- **法师不在就别一个人抢线**：对面是强势英雄时"千万不要一个人就跑到中路去，一个人清线了"，容易被逮住打状态甚至坠机（BV1Fzg26bEcp @ 01:14、BV1Fzg26bEcp @ 01:27）。
- **前期死亡=丢下一波野区**："前期无论是被打状态或者是击杀了，都有可能会丢失下一波的野区的，直接亏损最大化"（BV1Fzg26bEcp @ 01:30、BV1Fzg26bEcp @ 01:35）。
- **打野不要一换一**："打野一定不要掉点，尤其是不要去一换一，一换一是最没有用的"（BV1Fzg26bEcp @ 03:14、BV1Fzg26bEcp @ 03:18）。
- **没大就别跳**："如果因为我们没有大招，跳上去的话，就必定会被换掉了"（BV1Fzg26bEcp @ 03:19、BV1Fzg26bEcp @ 03:23）。
- **龙团前先解放对抗路**：刷完野"先过对抗路的线，因为马上龙团了，把对抗路解放出来，直接去占龙坑的视野"（BV1Fzg26bEcp @ 03:27、BV1Fzg26bEcp @ 03:32）。
- **龙团别先手摸龙**：对面手长，"提前过去的话，肯定会被打状态的"，要"等龙半血的时候再考虑上去打"（BV1Fzg26bEcp @ 04:01、BV1Fzg26bEcp @ 04:07）。
- **站位不好就只抢不打**："如果站位不好打的话，只能看着抢，抢了就撤就行了"（BV1Fzg26bEcp @ 04:09、BV1Fzg26bEcp @ 04:11）。

## 3. 连招

**先改设置，再谈操作**（这一条决定大招能不能秒放）：

- 操作设置里"移动式追击一定要关闭"，否则经常卡顿抽搐（BV1YLKAzhEG2 @ 00:20、BV1YLKAzhEG2 @ 00:23）。
- 技能释放方式选"按下释放"，它只作用于大招、二段强下大招、恢复回城这类非瞄准技能；设好后"手指碰到就能秒放更快的大招"（BV1YLKAzhEG2 @ 00:27、BV1YLKAzhEG2 @ 00:37）。

## 5. 出装铭文

**三套口径，互不兼容，分来源列出。**

**A 套·常规暗影宗师（BV1YLKAzhEG2）**

- 铭文：八异变、两红月、五隐匿、五狩猎、十鹰眼，目的是"手感爆发以及移速能同时拉满"（BV1YLKAzhEG2 @ 04:13、BV1YLKAzhEG2 @ 04:17）。

- 最后两件看局势：大顺风直接破军+吸血刀；均势或逆风就苍穹+破军（BV1YLKAzhEG2 @ 04:33、BV1YLKAzhEG2 @ 04:43）。

**B 套·裸破军科研（BV1xGQwBCEAR）**

- 铭文：隐匿百穿、不带攻速；理由是"陨星无穿透…百穿前期的收益会更稳定且相对较高"（BV1xGQwBCEAR @ 00:43、BV1xGQwBCEAR @ 00:50）。
