# 张飞：有大招是开团核心，没大招是超级兵

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一条直播复盘（BV1g9W76YEob）、一条国服辅助全局复盘（BV1JK4h69Edr）、一条出装铭文+操作设置+技能总纲（BV1bhsozREKX）、一条顺风全局节奏教学（BV1ErLF6uEMp）、一条顶端局全局教学（BV1xhKAznEcQ）。
> ⚠️ 素材以辅助视角的复盘与全局教学为主，缺少大招伤害、怒气数值、逐英雄对位；BV1g9W76YEob 是直播口语，ASR 有失真（如“雾行千三”），本卡只按上下文能确认的部分引用。

## 1. 机制内核

1. **大招是两段**：第一段狂风把人推走；第二段对狂风末端的敌人造成眩晕，且“末端的这个敌人还会被控制，时间会更久一点”（BV1bhsozREKX @ 07:56）（BV1bhsozREKX @ 08:20）。
2. **怒吼期间 1.25 秒霸体无敌**：“任何伤害、任何技能都无法去选中它”（BV1bhsozREKX @ 07:40）。这是张飞能顶着技能开团的根本。
3. **狂风通道内获得 50% 加速**（BV1bhsozREKX @ 07:59）。所以大招既能开人，也能把自己送进去或送出来。
4. **大招可手动取消**，取消后获得类似一技能的击退，但“击退是小一圈范围的”，没有一技能完全体好（BV1bhsozREKX @ 08:48）。
5. **没大招是超级兵**：没大不仅打不了龙团，探草被勾还得用大招拆火，“你就白白浪费一个大招”（BV1bhsozREKX @ 13:36）。
6. **一技能是击退 + 清线手段**：一技能能同时打到四个兵，“抢线还是很快的”，而且斩杀线很高（BV1bhsozREKX @ 14:54）（BV1xhKAznEcQ @ 02:33）。
7. **二技能是套盾 + 位移**：前期盾“非常厚”，套给自己和队友后换状态很舒服（BV1bhsozREKX @ 15:16）。探草必须留二技能，“一个二技能就可以直接跳出来”（BV1bhsozREKX @ 13:10）。
8. **盾不是纯增益**：主动交盾对面就不打了；要“等他动手，我再去给这个盾”，否则技能交完对面直接绕过你打射手（BV1g9W76YEob @ 33:43）。
9. **大招别贴脸喷**：贴脸会把对面喷走，“队友是跟不上伤害的”；要卡末端距离把人控在原地，或从侧面、绕后开（BV1bhsozREKX @ 09:04）（BV1bhsozREKX @ 11:12）。
10. **无大招时用野怪刷被动**：“没有大招的时候，多利用野怪给自己刷新被动”（BV1ErLF6uEMp @ 05:12）；平A刷大也是常规手段（BV1xhKAznEcQ @ 05:00）。
11. **开大蓄力时可接闪现调位置**：素材原话为“摁大招的同时……可以移动大招”，并明确“他躲不掉”（BV1g9W76YEob @ 25:36）。该词经 ASR 转写为“雾行千三”，按上下文指针闪调整大招方向。

## 2. 对线 / 打法

- **硬辅不要连体**：射手对线时张飞应“直接去排河道草丛”，二技能留着，“就在那个河道挂机就行了”；射手掉状态才过去套盾，套完继续在旁边看（BV1g9W76YEob @ 11:07）。
- **河道没排干净不要往前乱顶**：“你往前乱顶，你硬辅很容易被留的”（BV1g9W76YEob @ 11:31）。
- **兵线交汇先蹲草**：等对面打野和中单露了、确认打野不在发育路，再套盾硬吃伤害往前打（BV1g9W76YEob @ 11:44）。
- **对守约这类消耗型**：开局连体就学二套盾挡狙，二级后学一“插一手”，兵线“没有必要摸”（BV1JK4h69Edr @ 05:20）。红隼争夺时站前面挡狙，别让射手为了换状态放弃红隼（BV1JK4h69Edr @ 05:56）。
- **开局从野区上线，先占中右草**，30 秒看对面首开 Buff，再回头帮中单过线（BV1JK4h69Edr @ 02:54）（BV1JK4h69Edr @ 06:54）。
- **一级学一还是学二看对面会不会反野**：可能反野就学一/先去另一侧占视野再抢中线（一技能打四个兵）；不可能反野就学二正常对线，“那个盾是非常厚的”（BV1bhsozREKX @ 14:07）。
- **射辅强度不如对面就去中路开**：抢不到红隼，就带中路过完线去抢对面赤甲（BV1ErLF6uEMp @ 00:21）。
- **前期弱不要贪拿不到的中立资源**：“前期弱就选择反手止损的思路过渡弱势期”（BV1xhKAznEcQ @ 01:25）。
- **越塔反打**：提前卡一波视野蹲草，等对面压进来，把人推进防御塔，二技能踩上去接一技能，再变人形态补推（BV1bhsozREKX @ 09:29）。张飞越塔“是非常恐怖的，是随便越的”（BV1bhsozREKX @ 10:31）。
- **压塔从侧面或绕后开**：正面喷会把守塔的人喷走，队友跟不上；侧面二技能踩、一技能推，队友才能跟上输出（BV1bhsozREKX @ 11:36）（BV1ErLF6uEMp @ 08:24）。
- **拆塔用护盾吃塔伤保小兵**：提前用盾吃两到三下塔伤，“为小兵抵挡一些伤害”，多换一到两秒拆塔时间（BV1xhKAznEcQ @ 08:27）（BV1xhKAznEcQ @ 09:53）。
- **不要为了救必死队友把自己搭进去**：套盾前先判断“他能不能活下去”，两个人都死就是自己的抉择问题（BV1ErLF6uEMp @ 04:15）。

- **喷不到人不如不喷**：素材里正面大招“把人家喷走了”，被明确判为“害队友”（BV1g9W76YEob @ 26:14）。

## 4. 中后期 / 节奏

- **3 分半到 4 分钟就要判断龙团**：看双方阵容、对抗路能否先传、是五打四还是四打五，判断能接就提前踩视野（BV1g9W76YEob @ 19:14）。
- **龙团站位是“三角形中心”**：把蓝 Buff、穿山甲、龙坑连成三角形，站中心点，既能看射辅动向、又能排红区、还能接应中路（BV1g9W76YEob @ 13:17）（BV1g9W76YEob @ 22:11）。
- **中轴视野最重要**：放掉中右草“等于你自己主动的放弃了这个主动权”，4 分钟暴君团就难打（BV1JK4h69Edr @ 14:00）（BV1JK4h69Edr @ 19:25）。
- **4 分钟前必须把大招刷出来**：“暴君有大和没大的张飞，对于暴君团的影响是非常大的”（BV1xhKAznEcQ @ 05:08）。
- **野区优先于射手**：控死对面打野的蓝区，“就算他是国服，露娜也得废”（BV1xhKAznEcQ @ 06:11）；辅助第一优先级“不是射手，而是野区”（BV1xhKAznEcQ @ 06:20）。
- **推进节奏是“边中边”**：推完一座塔立刻准备下一座，不能连推两座；“你推中一塔的同时，就已经要准备去推另一个塔了”（BV1g9W76YEob @ 62:25）。
- **资源价值排序**：野区大于边塔，中塔大于野区；中一塔一掉就能从中间钻对面红背、蓝背（BV1g9W76YEob @ 64:24）。
- **拿 Buff 做假动作**：假装要反 Buff，把对面人引过来守，大部队转去推边塔；张飞留在 Buff 旁“假装我要开大喷他”，实际卡二塔视野（BV1g9W76YEob @ 65:00）。
- **顺风必须敢压塔**：有暴君还不敢压，“只会让对面拖到后期，让对面的装备成型”（BV1ErLF6uEMp @ 11:12）。
- **没大招也能磨塔**：主动吃塔伤、给队友套盾，让队友摸塔（BV1ErLF6uEMp @ 13:25）。
- **开团前先等队友**：队友没到就开，“也没有人跟伤害，那我们这波团就不应该开”（BV1ErLF6uEMp @ 06:19）。
- **逆风防守**：盯自家 Buff 刷新、提前落位守 Buff 和守塔；对面打三线就出奔狼找机会冲单带边（BV1JK4h69Edr @ 20:56）（BV1g9W76YEob @ 60:20）。
- **辅助要指挥**：素材反复强调开麦把射手拽回、提醒队友不要上头，“你辅助不指挥他，你想关麦……那就不要玩辅助了”（BV1g9W76YEob @ 67:21）。

## 5. 出装铭文

**铭文**

- 千血常规全肉铭文（BV1bhsozREKX @ 00:18）。素材未给具体五色搭配与数值。

**出装（两套，按对面控制量选）**

- **常规肉装流**：学识宝石 → 近卫 → 第一件看情况：对面消耗多（猫咪、海诺）做旭日；对面吃移速（马可、马超、关羽、戈娅）做不祥；常规可做冰心（BV1bhsozREKX @ 00:38）（BV1bhsozREKX @ 00:53）。
- **第二件看对面法伤**：法伤高做魔女，不高可直接霸者（BV1bhsozREKX @ 01:17）。之后可补红莲斗篷（对面回血吸血猛）或冰霜冲击（不猛）（BV1bhsozREKX @ 03:15）。
- **叠 CD 流**：对面控制很少时做极影 + CD 鞋，前期“会玩的非常舒服”，CD 快，套盾、叠怒气、接大招都更顺（BV1bhsozREKX @ 01:40）（BV1bhsozREKX @ 02:55）。控制多则不能这么出，探草太脆容易被留（BV1bhsozREKX @ 02:10）。
- **鞋子最后换**：抵抗鞋（控制多）、护甲鞋（控制不多）、疾跑鞋（CD 已够）三选一（BV1bhsozREKX @ 03:26）。
- **不祥的优先级要看阵容**：对面马超和吃攻速的英雄（含露娜）时“不详的优先级要提高”（BV1xhKAznEcQ @ 12:35）。
- **辅助装差异**：近卫会给附近队友提供生命回复，极影给队友回蓝（BV1xhKAznEcQ @ 08:00）。
- **素材明确“辅助的出装基本是没有固定的，都是根据阵容出的”**（BV1xhKAznEcQ @ 12:41），因此不存在唯一六神。

**召唤师技能**

- 推荐带闪现（ASR 作“雾行千三”）而不是治疗：“带闪现可以打开团，带治疗只能打保 C”，并且开大时能用闪现调大招位置（BV1g9W76YEob @ 25:23）。
