# 女娲：等级越高，手越长

> 只讲英雄本身。对位见 `B_克制关系/`；局势见 `D_对局内/`。

## 1. 她为什么"越到后期越恶心"

被动是**每升一级，视野范围 + 技能施法距离一起涨**。所以女娲不是"后期伤害高"，是**后期她能在你打不到她的地方打到你**。

这条直接决定打法：前期她手短、没线权，必须稳住；等级一起来，她的压制半径就变了。

- 来源：BV18ns8zmE6j @ 00:22

## 2. 技能怎么用

| 技能 | 作用 | 关键细节 |
|---|---|---|
| 一技能 | 主要输出 + 保命 | **两段伤害**，开局学它清线 |
| 二技能 | 制造墙体 | 可存 3 个；两个方块合成长方形（距离再远也能合）；4 个方块合成大正方形 |
| 三技能 | 远距离传送 | 传送中**本体不能动、不能放技能**，会被打断；能照出范围内视野 |
| 大招 | 全图贯穿 | 远程收割；配合一二技能的击晕更佳 |

- 来源：BV18ns8zmE6j @ 00:22、@ 00:39、@ 01:04、@ 01:18

## 3. 连招（三条主线）

1. **221 推 → 大**：两块墙 + 一技能推 → 接大招收割
2. **一推 → 三个二技能打满控制 → 大**：需要场地宽、控制链完整
3. **绕后切 C：三技能起手 → 落地一推 → 二技能控 → 大**

- 来源：BV18ns8zmE6j @ 01:25、@ 05:02

## 4. 出装与铭文

**铭文（明确）**：10 狩猎 + 10 献祭 + 10 梦魇

**出装主线**：法穿鞋 → 输出装（原话是"最常规的出装，伤害真的非常爆炸"）

## 5. 分条说明

### K-A71 女娲前期没有线权，别抢

- **触发条件**：开局对线
- **判断依据**：对面中单是不是"一技能就能清完线"的类型（如安琪拉）
- **决策分支**：
  - 抢不过 → 一技能丢四个兵就往后走，**保血线**
  - 抢得过 → 正常推，但别越塔
- **反例**：「中单必须抢线」——女娲前期 CD 长、伤害低，被打掉状态后连野区防守都参与不了。
- **通用面**：「线权看对面清线速度」本身是中路通用判据，见 `K-L01`。这条留在英雄卡里的部分只有**女娲自己的强度曲线**（前期 CD 长、伤害低）。
- **来源**：BV18ns8zmE6j @ 02:41
- **可信度**：高（原话直接给了判断与后果）
- **状态**：active

### K-A72 支援靠三技能，但传送会被打断

- **触发条件**：边路打起来、需要支援
- **判断依据**：传送落点是否安全、自己是否会被打断
- **决策分支**：
  - 安全 → 三技能坐过去，落地一推二控
  - 有风险 → 走过去或用大招远程补伤害
- **反例**：「三技能当闪现用」——传送期间不能动，被看到就是一个活靶子。
- **来源**：BV18ns8zmE6j @ 01:04、@ 03:58
- **可信度**：高
- **状态**：active

### K-A73 多看小地图，绕后切射手比打正面团收益高

- **触发条件**：中路团战僵持
- **判断依据**：小地图上有没有落单的射手/后排
- **决策分支**：三技能传送到侧面 → 一推 → 二技能控制 → 平A/大招收掉
- **来源**：BV18ns8zmE6j @ 05:02（"女娲不要一直盯着正面的团战，多看小地图"）
- **可信度**：中高
- **状态**：active

### K-A74 二技能是"墙 + 控制"，不是伤害技能

- **触发条件**：任何要打控制链的时刻
- **判断依据**：当前场上还有几个方块（可存 3 个）
- **决策分支**：
  - 有 2 个 → 合长方形夹人
  - 有 4 个 → 合大正方形封路
- **反例**：「方块丢出去就行」——不会合的方块只是占位，合起来才有控制。
- **来源**：BV18ns8zmE6j @ 00:39
- **可信度**：中高
- **状态**：active

## 6. 对位情报（来自对手视角）

- 来源：BV1K8gDzwEho @ 00:00、@ 00:03

## 7. 最容易崩的地方

1. **前期硬抢线**：被打掉状态，野区防不了，节奏全丢。
2. **三技能传送到人堆**：传送中不能动，落地就是死。
3. **只顾正面团**：女娲最强的用法是"传侧面打后排"，站正面输出等于浪费被动。
