## 1. 机制内核

1. **被动·经验球**：对目标造成伤害后，目标 3 秒内死亡，就给自己一个经验光球（BV1234y1f777 @ 16:15~16:23；BV1nYiuBEEe8 @ 01:08~01:14）。
2. **能产出经验球的目标只有三类**：防御塔、敌方英雄、大小龙（BV1234y1f777 @ 16:24~16:37）。龙不需要自己击杀，死前 3 秒内摸过一下就行（BV1234y1f777 @ 16:35~16:47）。
3. **经验球按"个数"结算**：三猪一组算 3 个，所以"三猪对姜子牙的重要性极高"（BV1234y1f777 @ 17:53~18:16）；多足野怪（豹子、蜥蜴）同理可多蹭（BV1234y1f777 @ 18:40~18:49）。
4. **升级加法强**：升级后增加法术攻击，与回响的收益契合（BV1234y1f777 @ 07:13~07:21）。
5. **封神是核心产能**：给队友封神越早，自己后期操作空间越大（BV1S2Vo6LEPX @ 00:57~01:10）。合格线是 7 分钟 15 级封神（BV1nYiuBEEe8 @ 02:08~02:12），顺局 6 分 50 秒即可（BV1nYiuBEEe8 @ 03:54）。
6. **一技能·减速 + 减抗**：释放范围远，自己还会加速，"分分钟就把海月给拉扯麻了"（BV1234y1f777 @ 01:11~01:22）；减速是逐渐加深而非瞬发（BV1234y1f777 @ 08:26~08:30）。
7. **二技能·延迟控制**：非瞬发，"现在的二技能不是瞬发，搞得对面打我我还得预判"（BV1FUPteUEW2 @ 00:21~00:28）；抬起来也打不破安琪拉的护盾（BV1234y1f777 @ 03:28~03:36）。
8. **大招·蓄力爆发**：可接闪现改变落点（大闪），是收人头的主要手段（BV1FUPteUEW2 @ 02:11~02:18）。
9. **全部技能都是范围伤害**，所以清线、拆火、封路都行（BV1nYiuBEEe8 @ 01:57~02:00）。
10. **基础连招就是 123**（BV1234y1f777 @ 03:28~03:30）。

## 2. 对线 / 打法

- **四级前没线权**：正常开局思路是打对面状态、把对面限制在中路（BV1nYiuBEEe8 @ 00:30~00:37）；有辅助帮拿线权才快速清线转边控资源（BV1nYiuBEEe8 @ 00:37~00:40）。
- **对清线慢的英雄可进野区**：如对面是甄姬，配合打野偷蓝最多亏一个兵（BV1nYiuBEEe8 @ 00:23~00:27）。
- **打法保守时塔下清线**：面对韩信+关羽这类突脸，前期"就在塔底下清线"，河道根本不敢走（BV1FUPteUEW2 @ 00:29~00:37）。
- **中路克制关系**：
  - 绝对优势：海月——技能机制与施法范围克制（BV1234y1f777 @ 00:57~01:06）。
  - 难打：宫本（BV1234y1f777 @ 01:39）；露娜、马超这类强突脸（BV1234y1f777 @ 01:55~02:05），但与马超互相克制——他能冲脸秒你，你一技能也能让他跑不起来（BV1234y1f777 @ 02:07~02:18）；兰陵王（BV1234y1f777 @ 02:23~02:28）。
  - 特别怕：安琪拉。"姜子牙真的很害怕安琪拉"，123 连招抬起来打不破她的盾，她反手 213 直接秒（BV1234y1f777 @ 03:13~03:44）。
  - 烦：炸弹猫、貂蝉近身（BV1234y1f777 @ 03:54~04:07）；婉儿因四级越塔减伤，前期做事能力下降（BV1234y1f777 @ 02:56~03:07）。
- **对妲己**：她单抓能力强，不是姜子牙能比的，前期只能打她状态（BV1FUPteUEW2 @ 00:09~00:21）。
- **辅助位**：不要指望他探视野、抗伤害——"无论如何也做不到"，选出来就不探（BV1Hh9XBnE1T @ 00:53~01:44）；正确做法是躲在队友屁股后面当法师打（BV1Hh9XBnE1T @ 03:25~03:52），一局输出 28%~30% 以上是正常的（BV1Hh9XBnE1T @ 04:08~04:13）；给前排当挂件，挂减速、挂穿透、给他封神（BV1Hh9XBnE1T @ 06:02~06:16）。
- **一技能要留着**：能留就留，"比二技能更关键"（BV1Hh9XBnE1T @ 09:31~09:34）；不要把它丢给必死的残血，注意力放在对面脆皮（BV1FUPteUEW2 @ 03:38~03:47）。

## 4. 中后期 / 节奏

- **刷级是第一位**：开局先看打野开野方式；红开后"无脑吃三猪"，可一起吃也可自己吃（BV1234y1f777 @ 16:53~17:21）。
- **蹭球不蹭经验**：打野快到时给一个一技能刮到，立刻走开，3 秒内打野清完就能拿球（BV1234y1f777 @ 17:35~17:51）。
- **支援路上顺手打野怪**：走到打野旁边就帮忙打一下，升级更快（BV1nYiuBEEe8 @ 02:12~02:23）。
- **4 分钟 9~10 级是合格线**（BV1234y1f777 @ 13:24~13:40）。
- **别抢后期英雄的经济**：上路是吕布这类，就远远碰一下、3 秒内走人，不分别人的钱（BV1234y1f777 @ 18:57~19:17）。
- **4 分钟暴君**：队友开龙时帮忙占视野（BV1nYiuBEEe8 @ 03:03~03:07）。
- **中后期跟团**：跟大部队、跟团压塔（BV1nYiuBEEe8 @ 03:07~03:10）。
- **有优势就进野区控资源**，扩大雪球（BV1nYiuBEEe8 @ 03:50~03:54）。
- **后期可以自己带节奏**：17~19 级后不需要再蹭线蹭野，"就可以一个人瞎蹦跶了"（BV1S2Vo6LEPX @ 09:44~09:56）。
- **断走位很重要**：后期要主动断对面走位、别让他们舒服消耗（BV1S2Vo6LEPX @ 14:59~15:11）。
- **别先上**：压塔时"如果我们先过去，容易被集火秒掉"，先用大招封走位（BV1FUPteUEW2 @ 04:55~05:02）。

## 5. 出装铭文

- **第一件疾步之靴是绝对核心**：被动要求他不停跑图拿资源，会不会刷级是"姜子牙会玩的一个分水岭"；开局出法穿鞋/冷却鞋的可以直接判不合格（BV1234y1f777 @ 05:58~06:31）。
- **魔道之石分两条支线**：回响（伤害 + 探草）（BV1234y1f777 @ 06:40~07:02）或面具（前期成型快、四级就能一套秒中单）（BV1234y1f777 @ 09:42~10:13）。
- **冰杖是第二核心**：一技能是逐渐减速，冰杖提供前置减速过渡，显著提高二技能命中率（BV1234y1f777 @ 07:56~08:38）。
- **一套完整顺序**：疾步鞋 → 魔道之石 → 冰杖 → 法穿鞋 → 云灵木 → 帽子 → 日暮 → 辉月/大书（BV1234y1f777 @ 07:30~11:56）；日暮出来后可卖鞋（BV1234y1f777 @ 11:37~11:44）。
- **别堆双穿**：结算先固定数值再百分比，且一技能本身已有百分比减抗，双穿性价比不高（BV1234y1f777 @ 11:58~12:57）。
- **坐牢套两份**（对面兰陵王、火舞、不知火舞这类）：魔道之石 → 进化水晶 → 时之预言 → 帽子/辉月（BV1234y1f777 @ 13:06~14:47）；或魔道之石 → 进化水晶 → 回响（探草）→ 时之预言 → 云灵木 → 吸血书（BV1234y1f777 @ 15:02~15:35）。核心是"先保证生存，命中率后面再说"（BV1234y1f777 @ 14:05~14:13）。
- **另一套实战口径**：第一件冰杖/冰斧；对面有回血第二件梦魇，否则日暮；然后帽子 → 保命装；后期鞋换冷静鞋补 CD（BV1S2Vo6LEPX @ 00:19~00:57）。
- **辅助位出纯输出**："大辅助装虽然对团队好，但是不加咱们伤害"，所以不做（BV1Hh9XBnE1T @ 05:38~05:46）。
- **铭文**：88 法穿 + 移速（BV1S2Vo6LEPX @ 18:31~18:36）。
