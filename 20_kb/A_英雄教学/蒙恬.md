## 1. 机制内核

1. **一技能有内外侧两套判定**：外侧命中会击退并"回复大量兵势"，内侧命中只是"穿过目标造成相同的伤害"，不控制、不回兵势（BV17R4y197n7 @ 00:14）（BV17R4y197n7 @ 00:23）。另一份把这段描述为"顶端的敌人"被击飞、贴得过近只吃伤害（BV1hD4y1D7HR @ 00:57）（BV1hD4y1D7HR @ 01:08）——两说指向同一个"前端判定"。
2. **二技能是前踏一步再举盾**：进入防御姿态，举盾过程本身带击退，且"击退范围其实很大"，即使和目标重合也能推开（BV17R4y197n7 @ 00:29）（BV17R4y197n7 @ 00:37）。举盾前那一步可以穿过很薄的墙（BV1hD4y1D7HR @ 01:49）。
3. **防御姿态改变普攻**：普攻从横扫变成"向前戳一枪"，长按可蓄力（BV17R4y197n7 @ 01:50）（BV17R4y197n7 @ 02:01）。蓄力期间"处于霸体状态"，并"减免10%的正面所受伤害"（BV17R4y197n7 @ 02:07）（BV17R4y197n7 @ 02:09）。
4. **伤害看兵势，不看蓄力时长**：技能命中、受到伤害都会涨兵势，"兵势越多，造成的伤害也就越高"，满怒自动戳出并"回复自身8%的已损生命值"（BV17R4y197n7 @ 02:12）（BV17R4y197n7 @ 02:16）（BV17R4y197n7 @ 02:21）。另一份明确"蓄力时间长短跟你的伤害无关"，蓄力只为免伤和躲控（BV1hD4y1D7HR @ 02:41）——即蓄力→涨兵势→伤害，蓄力本身不直接加伤。
5. **防御姿态是一套独立技能**：一技能在攻/防两态"是完全不同的两个技能"，CD 独立计算，解盾后再用一技能会直接刷新（BV1hD4y1D7HR @ 04:46）。解除二技能还会给"一秒钟50%的移速加成"（BV17R4y197n7 @ 06:43）。
6. **一技能命中会减二技能 CD**：减少 2~4 秒，且按一技能等级成长——一级减 2 秒、二到四级约 3 秒、五级满级 4 秒（BV17R4y197n7 @ 05:21）（BV17R4y197n7 @ 05:41）。四级点出两级一技能正好减 3 秒；开大后士兵与本体各撞一个目标，可连减两次直接刷新（BV17R4y197n7 @ 06:10）（BV17R4y197n7 @ 06:27）。
7. **开大是"多四个单位"而不是单纯加伤害**：士兵路径会造成伤害并回兵势（BV17R4y197n7 @ 08:50）；可用来探草（BV17R4y197n7 @ 09:08）；士兵能挡钟馗的钩子和马可一技能（BV17R4y197n7 @ 09:24）（BV17R4y197n7 @ 09:31）。模型变大后，一技能"控制范围也会变广"，实际攻击距离也被拉长（BV1hD4y1D7HR @ 06:33）（BV1hD4y1D7HR @ 08:24）。
8. **免伤可以叠到 50%**：二技能 20% + 蓄力 10% + 方圆阵 20%（BV17R4y197n7 @ 06:57）（BV17R4y197n7 @ 07:04）（BV17R4y197n7 @ 07:11）（BV17R4y197n7 @ 07:15）。士兵全部阵亡后"方圆阵的免伤效果依然存在"，但攻击力加成会消失（BV17R4y197n7 @ 07:43）（BV17R4y197n7 @ 08:38）。

## 2. 对线 / 打法

- **一级学二技能**：进防御姿态后普攻是 AOE，"清兵会更加占据优势"（BV1hD4y1D7HR @ 09:30）。
- **二级后的标准动作是"撞了先接平A再顶"**：这样才"有一个额外的伤害效果"，并且能延长控制时间（BV1hD4y1D7HR @ 09:37）。
- **两个控制别叠在一起**：一技能顶出去后等控制条"差不多消失的时候再接二技能"，中间那 0.5 秒穿插一下平A；出了冰痕之握后，这一下平A的减速"对你接下来蓄力平A的动作是至关重要的"（BV1hD4y1D7HR @ 03:36）（BV1hD4y1D7HR @ 03:42）（BV1hD4y1D7HR @ 03:44）。
- **架盾后至少撑五秒再解**：因为一技能 CD 约 5~7 秒，解盾后可以"直接可以再接一技能，再打一段控制效果"（BV1hD4y1D7HR @ 04:41）（BV1hD4y1D7HR @ 05:17）。
- **蓄力平A要打出穿刺**：找一个角度"同时消耗对面的血量，就能补兵"，作者拿狄仁杰"连你的人和兵一起打"作类比（BV1hD4y1D7HR @ 09:51）（BV1hD4y1D7HR @ 09:58）。
- **打灵活英雄不要贪红怒**：对面是马超、关羽这类，"尽量是能戳到就戳到，不要去贪红怒"（BV1mL411Q7v6 @ 07:26）。
- **红怒回血按已损生命算**：血越少回得越多，半血时戳一下 358，再戳一下只剩 314（BV1mL411Q7v6 @ 07:48）（BV1mL411Q7v6 @ 07:57）。
- **对线期有两个减速手段**：大招士兵过来的路径"对敌方造成高额减速"（BV1mL411Q7v6 @ 08:29）；蓄力时前方方块内的敌人，在你受到攻击后也会被减速（BV1mL411Q7v6 @ 08:51）。
- **塔下换血靠士兵**：四级开大即可单拆一座塔，操作是背向防御塔开大、避免塔先打掉一个士兵，然后二技能让士兵"先小兵一步"进塔（BV17R4y197n7 @ 11:24）（BV17R4y197n7 @ 11:36）（BV17R4y197n7 @ 11:56）。

## 4. 中后期 / 节奏

- **开大时机分两种**：进团目的是"打控制和吃伤害"，就提前开大再冲锋；目标是脆皮、旁边没帮手，就"先开启一技能冲到他面前"再开大——位置合适可直接刷出半条甚至满兵势，"这一下平A基本上可以把他带走了"（BV1hD4y1D7HR @ 06:42）（BV1hD4y1D7HR @ 06:53）。
- **与对方模型重合时开大，兵势"直接就满了"**（BV1hD4y1D7HR @ 06:06）。
- **开大后千万别忘了加二技能**，否则"只是普通的平A"（BV1hD4y1D7HR @ 07:08）。
- **越塔三种做法**：①开大+二技能，士兵在前方"提前进入防御塔"吃伤害；②走位转个弯把士兵"甩进防御塔的攻击范围"；③有兵线时让兵线先进塔，士兵贴近敌方英雄、本体保持距离，因为改版后"士兵在防御塔之内就相当于小兵"（BV17R4y197n7 @ 09:56）（BV17R4y197n7 @ 10:13）（BV17R4y197n7 @ 10:29）（BV17R4y197n7 @ 10:44）。
- **塔内不要正面开大**：在塔的攻击范围内开大，塔会先打一下士兵；应"背向防御塔开启大招"保士兵血量（BV17R4y197n7 @ 11:24）。
- **藏兵术两种**：面向垂直于墙体、向后方开大，士兵与本体重合；或用过大招后"对准墙体使用二技能"，把士兵卡进墙里（BV17R4y197n7 @ 12:13）（BV17R4y197n7 @ 12:34）。
- **进草要人兵一起进**，否则"你的士兵就会暴露你的视野"（BV17R4y197n7 @ 09:14）。
