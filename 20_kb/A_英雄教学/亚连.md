# 亚连：靠"刮一下就走"把线权磨出来，做出永夜后当全队唯一的大肉

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：BV16exveoEfJ，一整局对抗路第一视角实录，边打边讲，含对线消耗、拉扯、拆塔与出装顺序。
> ⚠️ 素材是局内口播，技能名与部分装备名被念成简称（"刮""钩子""永夜""火甲"），数值与铭文未覆盖。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 中期——做出防御装后"抗伤强度拉满了"，此时全队只有他一个前排，能顶着人压塔（BV16exveoEfJ @ 06:38~06:57） |
| **节奏职责** | 守塔 / 抗压当前排——"咱这个阵容不够肉，就咱一个大肉"（BV16exveoEfJ @ 06:38~06:39）；下路一个人顶："我拆塔下路顶住就行了"（BV16exveoEfJ @ 04:52） |
| **一句话** | 一二打完就拉开，进草隐藏视野再刮一手 |
| **依据** | 对线期全程是同一个循环：先手打一套→立刻后拉→进草消失→等对方状态掉了再刮一次（BV16exveoEfJ @ 00:36~00:41、BV16exveoEfJ @ 01:06~01:12、BV16exveoEfJ @ 02:13~02:19） |

## 1. 机制内核

素材只讲到"怎么用"，没讲技能原理，以下仅记录可复现的用法：

1. **消耗靠"刮"**：一次接触只打一下就走——"刮一手进草"（BV16exveoEfJ @ 01:06）、"再刮一手拉开"（BV16exveoEfJ @ 02:19）
2. **有钩子类手段可以先手**："勾一手一二好"（BV16exveoEfJ @ 00:36）、"抛个钩子"（BV16exveoEfJ @ 02:16）
3. **有一套斩杀线判断**："看能不能一套231给他斩死"（BV16exveoEfJ @ 01:46）；同样的 231 也用来控："那我得231控死你了"（BV16exveoEfJ @ 04:27）
4. **大招能当先手控**："这大招直接控一手死"（BV16exveoEfJ @ 12:28）
5. 技能名、被动、具体数值素材均未提，不补

## 2. 对线 / 打法

| 场景 | 做法 | 依据 |
|---|---|---|
| **一级接触** | 一二技能打一套，立刻"拉开往后走"，只换一波血量 | BV16exveoEfJ @ 00:36~00:41 |
| **换血后** | 二三技能收尾再拉开，不给对面反打距离 | BV16exveoEfJ @ 00:59 |
| **消失视野** | 刮一下进草藏视野，等对方身上的标记/状态消失，再出来刮第二下 | BV16exveoEfJ @ 01:06~01:12 |
| **第二次消耗** | 一二转→进草→藏视野→抛钩子→再刮一手→拉开 | BV16exveoEfJ @ 02:11~02:19 |
| **连打带 A** | 刮一手接 A，再 2-3 接 A 收 | BV16exveoEfJ @ 02:25 |
| **对手打野红开** | 连喊两次"小心小心红开的""说了两次呀"，提醒队友别被抓；判断打野位置靠野怪："去打小鸟了哈→这波他家打野是不会来的，应该在中路" | BV16exveoEfJ @ 01:24~01:31、BV16exveoEfJ @ 01:57~02:02 |
| **对嫦娥** | 对面 2000 多经济也照打："我可以打得过，打不过也不至于被他打死" | BV16exveoEfJ @ 04:38~04:48 |
| **线权优先** | 先拿线权再支援："先把线权拿了，好支援一会" | BV16exveoEfJ @ 05:20~05:21 |
| **怕张良** | "最恶心的就是这个张良，他老掐我"——被压制就废，需要队友先处理 | BV16exveoEfJ @ 11:01~11:05 |
| **跟团先手** | 不自己开，等队友控住再跟："等队友控住，我直接跟他" | BV16exveoEfJ @ 11:29~11:33 |

- **目标就是拆塔**："直接二塔给他拆了"（BV16exveoEfJ @ 06:07）、"准备压中吧，请求集合来压中"（BV16exveoEfJ @ 06:17~06:18）
