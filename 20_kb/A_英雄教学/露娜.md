## 1. 机制内核

1. **印记是整套循环的燃料**：技能和第三次普攻都能挂印记，大招命中带印记目标即刷新（本卡按素材口径归并：BV1sc41117fM @ 04:23、BV1sc41117fM @ 05:42）。第三次强化普攻可存约五秒，且攻击范围是正常普攻的两倍，但双倍只对前方生效（BV1sc41117fM @ 04:31、BV1sc41117fM @ 04:38）。
2. **二技能带延时判定**：敌人用位移脱离二技能范围，二技能短暂的延时依然能命中，把跑掉的人吸回来（BV1sc41117fM @ 00:59、BV1sc41117fM @ 01:08）。
3. **第一次普攻自带靠近和穿墙**，能穿野区大多数墙体，甚至跟着敌方位移追过去（BV1sc41117fM @ 00:47、BV1sc41117fM @ 00:51）。
4. **大招有"站起来"的后摇**：没站起来就无法放下一发大招（BV11j411W7oe @ 01:05、BV11j411W7oe @ 01:11）。所以"大招流畅度跟冷却没关系，跟方向盘是否一致也没关系"（BV11j411W7oe @ 00:30、BV11j411W7oe @ 00:43）。
5. **取消后摇的两条路**：等站起来再放（稳但慢，不实用）；用走路 / 平 A / 技能替代后摇，任意方向拖方向键都行，不需要与大招方向一致（BV11j411W7oe @ 01:23、BV11j411W7oe @ 01:53；BV1sc41117fM @ 01:41）。
6. **技能缓存规律：两个技能一组**，第三个技能要等前一组放完才放，否则会出现大招回不来、甚至回头大招（BV11j411W7oe @ 03:08、BV11j411W7oe @ 03:18、BV11j411W7oe @ 03:26）。
7. **大招生效范围比指示器远**，大约一个闪现的距离，但只在正面和正后方延长，侧面不行；正后方的判定还比正前方略大（BV11j411W7oe @ 03:57、BV11j411W7oe @ 04:14、BV11j411W7oe @ 04:26）。结论是"一技能能打中的目标，大招也能打中"，所以只要一技能中了就一直点着大招（BV11j411W7oe @ 04:02、BV11j411W7oe @ 04:09）。
8. **这个延长还能当落点**：把大招十字中心放进墙体、终点距墙一个闪现，就能穿到墙另一边，逃命抓人都好用（BV11j411W7oe @ 04:47、BV11j411W7oe @ 05:14）。
9. **大招有身后判定**，两个印记靠得近就能多飞一次（BV1sc41117fM @ 03:39）。
10. **非常耗蓝**：没蓝 Buff 时要"把自己当成没有蓝的状态"，否则打起来蓝条不够用（BV1zyLSz8EcY @ 12:50、BV1zyLSz8EcY @ 13:04）。

## 2. 对线 / 打法

> 露娜是打野，本节记开野、拉视野与抓人。

- **蓝开并打信号**：单 Buff 开很正常，蓝开就让队友帮忙看红（BV1zyLSz8EcY @ 02:01、BV1zyLSz8EcY @ 02:04）。
- **往对抗路刷有地形优势**，抓不到还能用传送阵转发育路或中路吃线（BV1zyLSz8EcY @ 02:13、BV1zyLSz8EcY @ 02:20）。
- **必须拉对面打野视野**："每一个打野一定要有这个习惯，多去拉对面打野的视野，观察状态"（BV1zyLSz8EcY @ 02:32、BV1zyLSz8EcY @ 02:37）。看到敌方红开就知道他要刷蓝，再去判断他争传送门还是回中转发育路（BV1zyLSz8EcY @ 02:42、BV1zyLSz8EcY @ 02:49）。
- **前期大招 CD 长，线上补残血兵要挑时机**：队友不在就单走；队友在旁边且很可能打死这个兵，就别上，容易断大（BV1zyLSz8EcY @ 03:06、BV1zyLSz8EcY @ 03:13、BV1zyLSz8EcY @ 03:20）。
- **传中不传上**：传上对面有警惕性打不起来，传中他会觉得你没这么快（BV1zyLSz8EcY @ 03:25、BV1zyLSz8EcY @ 03:29）。
- **等队友先手**：队友升四他没升就不先手；他升四等他框完大招再飞（BV1zyLSz8EcY @ 03:42、BV1zyLSz8EcY @ 03:48）。
- **不要往塔那边飞**：玩露娜的前提是让自己活着、尽量不掉状态（BV1zyLSz8EcY @ 03:56、BV1zyLSz8EcY @ 03:59）。
- **前期可以不刻意打架，但必须知道对面打野在哪、做了什么**（BV1zyLSz8EcY @ 04:22、BV1zyLSz8EcY @ 04:25）。
- **入侵必留惩戒**："不能说你刷自己的野怪为了图快把惩戒用了"，否则反野失败（BV1zyLSz8EcY @ 05:49、BV1zyLSz8EcY @ 05:55）。
- **龙团消耗完就跑**，不要为一个人头一直秀（BV1zyLSz8EcY @ 06:08、BV1zyLSz8EcY @ 06:11）。
- **断步走 A**：用方向键取消普攻后摇，攻速明显更快，前期刷野很好用（BV1sc41117fM @ 00:27、BV1sc41117fM @ 00:44）。
- **跳板只挑有价值的**：蔡文姬、孙膑这类好当单纯跳板；不在没有实质收益的地方乱标记（BV1zyLSz8EcY @ 07:30、BV1zyLSz8EcY @ 07:57）。

## 4. 中后期 / 节奏

- **入侵要一波接一波**："第一次反了之后，第二次就要来反，第三次有机会你还要接着来，要不然前功尽弃"（BV1zyLSz8EcY @ 09:25、BV1zyLSz8EcY @ 09:29）；只有把对面打野经济压低了才有操作空间（BV1zyLSz8EcY @ 09:36、BV1zyLSz8EcY @ 09:39）。
- **优先保自己蓝区**，不给对面拿蓝——别人知道你会玩，第一时间就是击杀你或不让你拿蓝条（BV1zyLSz8EcY @ 08:42、BV1zyLSz8EcY @ 08:47）。
- **打团别花里胡哨**，盯着想击杀的那个人打（BV1zyLSz8EcY @ 09:01、BV1zyLSz8EcY @ 09:04）。
- **对面射手 + 加血辅助只打射手**，把技能交给辅助可能被换掉（BV1zyLSz8EcY @ 10:13、BV1zyLSz8EcY @ 10:29）。
- **有吸血书后状态可以刷回来**，没大危险就多打野怪、吃兵线回状态（BV1zyLSz8EcY @ 10:37、BV1zyLSz8EcY @ 10:44）。
- **先拿红 Buff 再打龙**：先打龙，对面复活后红区就控不住了（BV1zyLSz8EcY @ 10:49、BV1zyLSz8EcY @ 10:53）。
- **成型也要发育**，否则对面魔抗做出来、自己坦度不够都会崩（BV1zyLSz8EcY @ 11:13、BV1zyLSz8EcY @ 11:25）。
- **现在的露娜不是"前期露娜"**：前期确实脆，但只要二技能有续航就能抗很高伤害，而且能抗完再走（BV1zyLSz8EcY @ 12:03、BV1zyLSz8EcY @ 12:16）。
- **带线运营**：下路中路没二塔但上路一塔没推，就必须把兵线运营过来，三线一起推上高地才简单（BV1zyLSz8EcY @ 12:27、BV1zyLSz8EcY @ 12:36）。
- **没蓝 Buff 不打团**（BV1zyLSz8EcY @ 12:46）。
- **除队友不能当踏板，野怪和龙都可以**（BV1zyLSz8EcY @ 12:20）。

## 5. 出装铭文

**出装决策：BV12aE16XE6r 给框架，BV1A6pReyE21 给另一条实操**

- **前六件雷打不动**：中野刀 → 法穿鞋 → 吸血书 → 时之预言 → 韧性鞋 → 大野刀（BV12aE16XE6r @ 01:47、BV12aE16XE6r @ 01:53、BV12aE16XE6r @ 01:57）。
- 帽子流（最常规）：前六件 + 虚无法杖 + 帽子。理由是虚无是法穿里最好、帽子是法强里最契合，都是单属性性价比最高（BV12aE16XE6r @ 02:02、BV12aE16XE6r @ 02:11）。
- 不祥流（难入场/逆风）：前六件 + 法穿杖 + 不祥征兆，两件各在自己领域数一数二且互相独立（BV12aE16XE6r @ 03:24、BV12aE16XE6r @ 03:36）。
- 法伤特攻：前六件 + 破茧之衣 + 魔女。理由是两件被动都挂"额外生命值"（BV12aE16XE6r @ 04:08、BV12aE16XE6r @ 04:15、BV12aE16XE6r @ 04:30）。
- 保命顺序：这个版本推荐"复活甲直接换名刀，名刀之后再用金身收尾"，因为对面控制和拆毁技能太多，金身时间会被技能覆盖（BV12aE16XE6r @ 02:40、BV12aE16XE6r @ 02:58）。
- **破茧 vs 虚无的口径冲突**：BV12aE16XE6r 结论是"这个版本虚无法杖更好，更直接、效果更强劲，破茧已经很难契合露娜的生命属性"（BV12aE16XE6r @ 05:49、BV12aE16XE6r @ 05:54）；BV1A6pReyE21 则"无脑出破茧之衣"，理由是法伤/生命值高、法穿打人打龙都疼（BV1A6pReyE21 @ 04:02、BV1A6pReyE21 @ 04:21）。
- **切 C 才出虚无**：对面要切的 C 位出了魔女（镜出魔女、阿离/马可出魔女）就出虚无法杖；没出魔女还是破茧更疼且多 500 血；对面四个魔女就破茧 + 虚无打双穿（BV1A6pReyE21 @ 06:38、BV1A6pReyE21 @ 06:58、BV1A6pReyE21 @ 07:07）。
- **不建议先做小血书**：容易进"伤害不高、续航也不强"的暴毙阶段（BV1A6pReyE21 @ 03:00、BV1A6pReyE21 @ 03:07）；**也不建议早买大野刀**，你出的时候对面已在出魔抗（BV1A6pReyE21 @ 05:02、BV1A6pReyE21 @ 05:12）。
- **大后期卖鞋换帽子**，破茧也可再换帽子（BV1A6pReyE21 @ 07:23、BV1A6pReyE21 @ 08:13）。
- **前期出装的理由**：先弑神之书再做时之预言，是因为时之预言小件移除、被动改版后法强不够叠不满（BV12aE16XE6r @ 07:26、BV12aE16XE6r @ 07:34）；这两件是露娜前期撑强度的锁死装备（BV12aE16XE6r @ 07:52）。
- **圣剑流的评价**：BV12aE16XE6r 认为不好——"露娜刷野速度本来就不慢，你不需要额外提升"，且状态打空后必须回城，吸血书却能让半血也敢进对面野区（BV12aE16XE6r @ 07:56、BV12aE16XE6r @ 08:22、BV12aE16XE6r @ 08:29）。
