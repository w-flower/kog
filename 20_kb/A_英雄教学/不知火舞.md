# 不知火舞：能量就是她的状态

> 只讲英雄本身。**打谁舒服**看 `B_克制关系/`；**第几分钟该干什么**看 `D_对局内/`。

## 1. 她强在哪、卡在哪

**强在"一段控制换一个人"，卡在"能量不够就什么都做不了"。**

三个技能全带位移、全部可以接闪现，被动翻滚还能穿墙——所以她的上限不是伤害，是**位置**。但她没有蓝条只有能量，能量靠技能命中回复，空放技能等于把自己打空。所以火舞的每一次进场，本质是一次**能量结算**：够就杀，不够就是白给。

- 来源：BV1Fd4y1k7EY @ 03:02（"能量如果不足以支撑连招，一定不要草率进场"）
- 来源：BV1Td9EBKE9S @ 00:26（"准备冲进人堆时要至少保证自己有 150 点能量"）

## 2. 技能怎么落地（按使用频率排）

| 技能 | 真正的作用 | 关键细节 |
|---|---|---|
| 二技能（扇子） | 起手位移 + 减魔抗 | 命中即停、减速 0.5 秒、减最高 200 点魔抗持续 3 秒 |
| 被动·翻滚 | 位移 / 穿墙 / 取消后摇 | 每次放技能后可翻滚一次；强化普攻也能触发翻滚 |
| 被动·强化普攻 | 第五秒的一个额外突进 | 周围没敌人时可用方向键控制突进方向，赶路用 |
| 一技能 | 位移 + 击飞，开团用 | 实际命中范围比指示器远；**贴脸放反而会打空** |
| 大招 | 团控 + 减攻 | 命中一人回 25 能量；命中减目标 20% 物理攻击 2.5 秒 |

- 来源：BV1eg411z7u1 @ 00:05（二技能减魔抗 200 点/3 秒）；@ 01:00、@ 01:30（双被动）
- 来源：BV1Td9EBKE9S @ 02:16（一技能范围与贴脸打空）；@ 00:10（大招回能与减攻）

## 3. 基础操作（新手最先要练的三个）

**① 补刀键要打开。** 线上用小兵当位移跳板，野区用野怪——这是火舞"贴到人脸上"的常见方式，不开补刀键就只能空放技能靠近。

**② 二技能贴脸必中。** 背对目标释放也能命中，左右任意方向都命中。所以被近身时不要慌着跑，先扇子。

**③ 后摇用翻滚或别的技能接掉。** 所有主动技能的后摇都能靠"接被动翻滚/接强化普攻/接另一个技能"取消；翻滚自己的后摇靠左右轻晃轮盘取消。不会取消后摇的火舞，动作永远慢半拍。

- 来源：BV1Td9EBKE9S @ 00:42；@ 02:48（后摇取消）
- 来源：BV1eg411z7u1 @ 00:41（二技能任意方向必中）

## 4. 分条说明

### K-A11 二技能是"减魔抗"，不是"消耗"

- **触发条件**：任何准备打伤害的瞬间
- **判断依据**：目标身上有没有被扇子标记（减魔抗 3 秒）
- **决策分支**：
  - 有标记 → 接一技能/大招，这时伤害才是满的
  - 没标记 → **先补扇子再谈输出**，硬打等于把伤害打了个七折
- **反例**：「扇子是用来消耗血线的」——它同时是全套伤害的前置条件。
- **来源**：BV1eg411z7u1 @ 00:05；@ 07:47
- **可信度**：高（机制数值与连招由多个视频一致给出）
- **状态**：active

### K-A12 标准连招只有一条主线：扇子起手 → 一技能 → 接闪现

- **触发条件**：要单杀落单目标，或一闪开团
- **判断依据**：目标离你的距离是否在"一技能位移 + 闪现"的覆盖内
- **决策分支**：
  - 能一闪到 → 二技能 → 一技能 → **在二技能释放过程中**接闪现，打出"一闪"控制
  - 到不了 → 不要硬上，先用强化普攻或兵线位移缩短距离
- **反例**：「连招要背熟」——火舞没有固定连招，扭扭蛇原话是"火舞没有固定的连招，需要你自己灵活应变"，主线之外全靠判断。
- **来源**：BV1eg411z7u1 @ 07:47；BV1eg411z7u1 @ 08:20；BV1Fd4y1k7EY @ 01:57
- **可信度**：高
- **状态**：active

### K-A13 瞬秒连招：扇子 → 大招 → 强化普攻（减魔抗的窗口内把爆发打完）

- **触发条件**：目标血量在你的爆发线内，且身上已有扇子标记
- **判断依据**：扇子命中后 3 秒内能不能接上大招
- **决策分支**：扇子出手 → **在扇子飞行的过程中**就按大招 → 减魔抗生效瞬间打出大招伤害 → 补强化普攻
- **反例**：「等扇子命中了再按大招」——等命中再按，窗口已经过去一半。
- **来源**：BV1eg411z7u1 @ 09:29
- **可信度**：中高（单一来源，但步骤描述清晰可复现）
- **状态**：active

### K-A14 一闪开团和大招开团是两个东西，别混

- **触发条件**：要开团时
- **判断依据**：己方是均势/逆风，还是己方有前排能跟
- **决策分支**：
  - 势均力敌或逆风守高地 → **一闪开团**：进得去、控得住、还能退，打的是控制不是伤害
  - 己方前排能先手接住 → **大招开团**：把人推回来交给队友
- **反例**：「有闪就一闪上去打伤害」——一闪的定位是控，用它当输出来源，等于把唯一的退路交了。
- **来源**：BV1v541187YZ @ 13:44、@ 14:02
- **可信度**：中高
- **状态**：active

### K-A15 能量低于一条线就别进场

- **触发条件**：准备靠自己冲进人堆
- **判断依据**：当前能量是否够放满三段（视频给的门槛是 150）
- **决策分支**：
  - 够 → 直接进，靠命中回能滚起来
  - 不够 → 先扇子消耗/清线回能，或等强化普攻叠好再进
- **反例**：「我看别人进去就秒了」——别人进之前能量是满的。
- **来源**：BV1Td9EBKE9S @ 00:26；BV1Fd4y1k7EY @ 03:02
- **可信度**：中（150 这个数值只有一处口播，机制方向多源一致）
- **状态**：active

### K-A16 大招反拉：把她的大招当"拉进塔"的工具

- **触发条件**：目标在塔的射程边缘，且你敢吃一发塔伤
- **判断依据**：大招的拉回方向能否把目标拉进塔下
- **决策分支**：贴塔站位 → 大招命中把敌人拉回来 → 让防御塔补伤害
- **反例**：「大招是团控，留着打团」——单杀阶段把人大招拉进塔，是最省技能的杀法。
- **来源**：BV1eg411z7u1 @ 04:40
- **可信度**：中
- **状态**：active

### K-A17 用扇子探草：命中会回能

- **触发条件**：进草前、支援路上
- **判断依据**：扇子出手后能量有没有涨
- **决策分支**：能量涨了 → 草里有人，别进去；没涨 → 可以走
- **来源**：BV1Td9EBKE9S @ 00:10
- **可信度**：中高
- **状态**：active

### K-A18 对线期第一波线别靠前（对面是钩子类辅助时）

- **触发条件**：对面辅助是钟馗这类强制位移
- **判断依据**：自己是否站在对方钩子的射程内
- **决策分支**：第一波线**退到塔前接**，被勾进塔下会直接脱节
- **反例**：「中单要抢线权」——火舞一级清线慢，抢线是拿命换。
- **来源**：BV1Fd4y1k7EY @ 00:24；@ 01:09（清线慢所以先拿河蟹）
- **可信度**：中
- **状态**：active

## 5. 出装与铭文

**结论：暂不写入具体铭文组合。**

原因：标题带"出装铭文"的两期，一期是 2020 年（BV1v541187YZ），一期是 2024-06（BV12b421H7sY，S36）；2026 年那条（BV1Td9EBKE9S）字幕里只有一句"还有不知火舞的出装铭文"就结束了，**具体条目没有被 ASR 转录出来**。ASR 对铭文名（梦魇/心眼/狩猎）的识别错误率高，硬写等于编。

**能确认的只有一条思路**：出装要围绕"减魔抗 + 爆发"，因为她的伤害模型就是扇子标记后一套带走；对面出了魔女斗篷时，原话是"他现在这套装备就是秒他，但是他出了魔女咱们秒不掉"——遇到魔女要改路线，不要硬堆法强。

- 来源：BV1v541187YZ @ 12:19（魔女斗篷的应对）

## 6. 最容易崩的三个地方

1. **能量不够硬进团** → 进去放不出三段，等于送。
2. **不会取消后摇** → 一模一样的操作，别人打完能翻滚走，你还在原地收招。
3. **把一闪当输出用** → 交完闪现又没杀掉，接下来 90 秒你没有开团手段。
