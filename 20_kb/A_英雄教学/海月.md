# 海月：大招拉进去必须能杀，拉不掉就别拆火

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份国服海月 34 条细节合集（BV1aLDPBxE6S）、一份 2000 分实战复盘（BV1JjqzBiEMT）、一份幻境连招与出装实战（BV1UUxq6sEXQ）、一份新版本出装铭文详解（BV1c7u861Erm）、一份阿泽×国一晓峰的全局思路（BV1Z3DkBkEZo）。

## 1. 机制内核

1. **开大过程 70% 免伤，拉断也保留**："海月开大过程中会有一个 70% 的免伤效果，并且就算我们把大招拉断，这个 70% 的免伤效果依然存在"（BV1Z3DkBkEZo @ 02:08、@02:12、@02:14）；所以可以主动断大拿免伤，防御塔一下 540 会变成 160（BV1Z3DkBkEZo @ 02:16、@02:19、@02:22）。
2. **幻境内一技能是无限距离**："幻境里面一定要知道一技能是无限距离的……在外面才有，现在在里面是无限的"（BV1UUxq6sEXQ @ 04:26、@04:29、@04:32）。
3. **幻境内二技能给盾，有盾对面吸不了血**：狂暴、吸血刀、日暮都吃不到盾，"吸血是你得去吸生命值才行，不能去吸盾"（BV1JjqzBiEMT @ 04:58、@05:01、@05:12、@05:15）。这也是海月克司空震、克带狂暴英雄的原因（BV1JjqzBiEMT @ 05:02、@05:05）。
4. **出圈瞬间交闪，用无敌帧跑掉**："你可以出来的一瞬间通过无敌帧给跑掉，对面就锁不到你的头技能"（BV1JjqzBiEMT @ 08:15、@08:16、@08:18）；国服口径同样强调"下来就一定一定要闪"（BV1aLDPBxE6S @ 24:57、@24:59、@25:01）。
5. **幻境内撞墙等于一段闪现位移**：一个"左右一个闪现位移"，但撞到边缘会卡住，"一般不介意你们撞墙"，只有打不过时用来拉扯拖时间（BV1UUxq6sEXQ @ 04:43、@04:48、@04:57、@05:16）。
6. **二技能伤害不比一技能低**：一是二技能不用瞄准，可以多打几套；二是护盾让对面吸不了血（BV1aLDPBxE6S @ 20:48、@20:50、@21:00、@12:44、@12:48）。
7. **一技能没有探草效果**：必须靠日暮之流被动层数判断草里有几个目标（BV1Z3DkBkEZo @ 01:50、@01:52、@01:54、@01:57）。
8. **一技能正面打不到可以斜着放**（BV1Z3DkBkEZo @ 02:02、@02:05、@02:07）。
9. **进幻境后的落点有规律**：以画面中心为分界，远端拉进来就隔得远，贴脸拉进来就贴脸，"这样大家对自己的落点就有很深刻的认知了"（BV1aLDPBxE6S @ 05:21、@05:27、@05:41、@05:46）。
10. **大招是单体技能，人多会拉错**：开索敌头像显示后把大招拖到头像上，可以拉到任意目标（BV1Z3DkBkEZo @ 00:36、@00:40、@00:45、@00:48）。
11. **二技能带控制，可用来留人**：需要留人时先用二技能控住，让大招"拉得到他"（BV1aLDPBxE6S @ 07:07、@07:12、@07:20、@07:23）。

## 2. 对线 / 打法

- **四级前就是抢资源**："四级以前思路呢就是抢资源……既然百分百能命中，那如果我刷野怪的话会很快"（BV1aLDPBxE6S @ 01:08、@01:22、@01:25、@01:27）。
- **一级抢线的固定手法**：提前上线，见到人先给一发，"等兵线到面前的时候，我们其实三个一技能又好了"，留三个一技能清兵（BV1aLDPBxE6S @ 02:14、@02:16、@02:21、@02:23）；开局卡个三一、买小书（BV1Z3DkBkEZo @ 02:30、@02:32）。
- **清线细节**：比对面强时"先 A 一下尽量 A 到后排兵，再 A 一下"，三个一能清完；三个一清不掉炮车时"先放一个一技能打到所有兵上，然后再放三个E"（BV1UUxq6sEXQ @ 00:32、@00:34、@00:38；BV1aLDPBxE6S @ 25:07、@25:16、@25:21）。
- **对面辅助帮抢线就后手清**："如果对面有辅助帮忙抢线，那我们尽量后手清线，不要被对面打状态"（BV1Z3DkBkEZo @ 02:36、@02:38）。
- **线可以和打野一起吃**："如果打野不远的话，你可以就先别清，等打野一起吃"，两人一起吃中线再一起吃野区收益更高（BV1aLDPBxE6S @ 02:45、@02:47、@03:06、@03:10）。
- **打不打只看人数差**："这种二打二对海月来说是没优势的……如果没有人数差就不打架"（BV1aLDPBxE6S @ 01:41、@01:50、@01:56）。
- **四级拉人的判断**：对面阵容明显比我们强"就发育为主"，我们更强"就主动开团"（BV1aLDPBxE6S @ 03:23、@03:28、@03:35、@03:36）。
- **抓谁的清单**：坦边（白起）不抓；战士、刺客"打得过抓"；射手+软辅"最好抓"；射手+硬辅"有点难抓"；狄仁杰+硬辅"你就别去了"，因为二技能能解大招（BV1aLDPBxE6S @ 04:15、@04:16、@04:21、@04:23、@04:29、@04:33、@04:37、@04:39、@04:42）。
- **都抓不到就占视野**："我们可以占住中草的视野……然后可以盯着敌方的中野，要来了咱们直接把他拉走"（BV1aLDPBxE6S @ 04:52、@04:54、@04:57、@05:03、@05:06）。
- **一律绕后，不打正面**："因为我们没有位移，正面抓人你可能就被挣脱了"（BV1aLDPBxE6S @ 15:49、@15:52、@15:53）；"海月就不要去打正面，你正面是开不到人的"（BV1JjqzBiEMT @ 11:54、@11:55、@11:57）。
- **没大就不支援**："没大的时候，你就不建议你去支援去打架了"（BV1aLDPBxE6S @ 14:19、@14:20、@14:27）；替代动作是跟队友吃野、占河道视野（BV1aLDPBxE6S @ 14:44、@14:52、@14:56）。
- **转线用二技能加速**：回中路吃线时"放两个二技能来回来吃线……放个二跑得快"（BV1aLDPBxE6S @ 18:52、@18:54、@18:58、@19:01）。
- **中核打法（分段限 2400 以下）**："我左吃右吃，我走到哪吃到哪，我把自己当核心来打"（BV1aLDPBxE6S @ 19:25、@19:27、@19:29）；2000 分段同理，"只有吃了钱你才能塞得动"（BV1JjqzBiEMT @ 02:29、@02:36、@02:41）。

## 5. 出装铭文

**铭文（两种口径，未合并）**

- 口径 A：蓝色十狩猎、绿色十献祭、红色十梦魇，即法师常用的冷却铭文（BV1Z3DkBkEZo @ 01:40、@01:41、@01:42、@01:43）。
- 口径 B：绿色献祭是为了 7.5% 冷却，"海月这个大招冷却时间是非常久的"；蓝色还带两轮回，加 2% 法术吸血，与吸血书被动联动（BV1c7u861Erm @ 00:21、@00:25、@00:28、@00:36、@00:39、@00:42）。
- 两边共同点：绿色献祭（冷却）是必备，红色梦魇方向一致（BV1Z3DkBkEZo @ 01:42；BV1c7u861Erm @ 00:25）。

**出装（两条顺序在"梦魇与日暮谁先"上不一致，分别标注）**

- 顺序 A（BV1c7u861Erm）：两个咒术典籍 → 冷却鞋 → 日暮之流 → 梦魇 → 吸血书 → 换韧性鞋 → 帽子 + 贤者天书。理由是中路穷，"如果你先出梦魇再出日暮，因为日暮的小件都不加法穿"，先出日暮把法穿拉起来（BV1c7u861Erm @ 01:01、@01:08、@01:26、@01:38、@01:52、@02:06）。
- 顺序 B（BV1Z3DkBkEZo）：小书 → 冷却鞋 → 梦魇 → 日暮 → 吸血书 → 换鞋 → 虚无 / 帽子（BV1Z3DkBkEZo @ 00:57、@01:02、@01:04、@01:08、@01:13）。
- **换鞋时机与收益**：出完三大件冷却就够，可以换鞋；物伤多出忍足，法伤或控制多出抵抗鞋（BV1Z3DkBkEZo @ 01:15、@01:18、@01:19、@01:21、@01:22）；换抵抗鞋后即使没蓝 Buff 也有约 38% 冷却（BV1c7u861Erm @ 03:09、@03:19、@03:40）。
- **梦魇的取舍**：对面没回血英雄可以不出，"大部分都是出梦魇的"；蔡文姬、扁鹊、桑启、带狂暴的司空震、夏侯惇都要出（BV1c7u861Erm @ 02:36、@02:38、@02:41、@02:44、@02:48、@02:51）。
- **不出梦魇就回转回响**："这把对面没什么回血，直接这件出回响"（BV1c7u861Erm @ 07:54、@07:56），"能出回响就出回响"（BV1c7u861Erm @ 12:29）。
- **前期鞋子的另一种选择**：前期只打两套时"秘法之靴伤害高一点，没必要说我做冷静鞋"（BV1aLDPBxE6S @ 08:03、@08:05、@08:09）。
- **大书是伤害质变点**：做出大叔后"你的一技能伤害是非常爆炸的，两个一技能能直接把一个脆皮从满血打到残血"（BV1c7u861Erm @ 03:50、@03:55、@03:57）。

## 待补

- 铭文两种口径（十狩猎 vs 两轮回）的确切配比，以及蓝色剩余槽位
- 两套出装顺序谁更优的适用条件（现有只有"中路穷所以先出日暮"一条理由）
- 逐英雄对位强度：素材只给了白起、战士、刺客、软辅/硬辅、狄仁杰、杨玉环、司空震、女娲、公孙离等散点
- 幻境内撞墙的具体收益与失误代价（只有"一般不介意你们撞墙"）
- 后期分带 / 守高地 / 单带牵制的完整决策
- 常见 counter 与应对（如瑶附身躲大、有位移 C 位如何处理只给了"交闪"一条）
- 大招拉到人但杀不掉时的止损流程
