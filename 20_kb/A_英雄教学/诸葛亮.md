# 诸葛亮：经济刷不起来就没有伤害，团开起来才是他的回合

## 1. 机制内核

1. **被动是伤害主体**：技能命中叠印记，满 5 层召唤 5 颗法球自动打范围内敌人；范围内同时有野怪和英雄时优先打英雄（BV1mzCcBoEGb @ 00:15、BV1mzCcBoEGb @ 00:23）。法球对兵线伤害 +40%，对野怪 −40%；10 秒不放技能印记归零（BV1mzCcBoEGb @ 00:29、BV1mzCcBoEGb @ 00:35）。
2. **版本改动让刷野变快**：被动对野怪伤害由"降低40%"改为"只降低20%"（BV1BExk6nE4p @ 11:01、BV1BExk6nE4p @ 11:06），所以素材里敢说"诸葛亮现在刷野会更快"（BV1BExk6nE4p @ 10:55）。
3. **一技能是叠层与消耗的两用牌**：三颗法球，三颗命中同一英雄时后两颗只有 20% 伤害；每颗命中的单位加 1 层，最多 3 层（BV1mzCcBoEGb @ 00:45、BV1mzCcBoEGb @ 00:50）。它可以一闪、可以探草，没有身后判定（BV1mzCcBoEGb @ 01:02、BV1mzCcBoEGb @ 01:10）。
4. **二技能同时是位移、叠层和减速**：起点终点各一段伤害，5 秒内对同一英雄造成两次伤害即 3 秒极限减速；实际范围比指示器大半个闪现，一个二技能就能加两层印记（BV1mzCcBoEGb @ 01:19、BV1mzCcBoEGb @ 01:29、BV1mzCcBoEGb @ 01:36）。闪烁性质让它能无伤穿张良一技能、无视野进草（BV1mzCcBoEGb @ 01:44、BV1mzCcBoEGb @ 01:49）。
5. **大招是斩杀，不是消耗**：元气弹目标血越低伤害越高；击杀目标减 80% 冷却并直接满层被动，命中前目标已死同样减 80%（BV1mzCcBoEGb @ 01:57、BV1mzCcBoEGb @ 02:01、BV1mzCcBoEGb @ 02:05）。飞行中可被敌方队友挡，所以能"用二技能来调整弹道"（BV1mzCcBoEGb @ 02:11、BV1mzCcBoEGb @ 02:15）。
6. **全身上下只有两个位移，用完就没有自保**："你上去了没位移，这个英雄是很容易死的"（BV1xCaBzJE9N @ 11:18）。
7. **一技能要留一张跑路牌**："打团最关键的地方就是留个一技能，以确保自己跑路"（BV1V6U7BfEbc @ 02:38）。
8. **手短靠站位补**：因为有两个位移，站位反而要比其他法师更近，"就是你要联想到你这两个位移放出去过后，能不能跑得掉"（BV1xCaBzJE9N @ 01:44、BV1xCaBzJE9N @ 01:49）。

## 2. 对线 / 打法

**打野位**

- **开野先算对面辅助**：看到对面辅助是钟馗，就料定他会来反蓝，于是从红 Buff 草开局，先"诱导一下"让对面以为往上刷，实际往下刷（BV1BExk6nE4p @ 00:09、BV1BExk6nE4p @ 00:28、BV1BExk6nE4p @ 00:34）。
- **刷野路线**：红区刷完 → 吃中线 → 刷蓝区 → 吃上路线，然后靠传送阵回中（BV1BExk6nE4p @ 00:41、BV1BExk6nE4p @ 01:22、BV1BExk6nE4p @ 01:37）。
- **红开还是蓝开看双边强度**："我们要根据对面边路和打野的强度来弄"，边路 2V2 打不过就对抗路开（BV1V6U7BfEbc @ 00:28、BV1V6U7BfEbc @ 00:30）。
- **刷几组野怪跟开野点绑定**：发育路开刷五组，对抗路开刷六组——因为要发育（BV1V6U7BfEbc @ 01:25、BV1V6U7BfEbc @ 01:30）。
- **2V2 靠拉扯不靠硬刚**："等他们靠近一点再打"，后靠时用一技能拉，等对面交技能再上一套，边打边接普攻（有减速）（BV1V6U7BfEbc @ 01:45、BV1V6U7BfEbc @ 01:50、BV1V6U7BfEbc @ 01:55）。
- **怕高回复打野**：杨戬、曹操这种"回复性比较高的，就有点难搞了"（BV1V6U7BfEbc @ 01:01、BV1V6U7BfEbc @ 01:04）。
- **怕被偷 Buff 的打野**：玄策、老虎、飞、镜、铠这类有位移能偷的要特别小心（BV1V6U7BfEbc @ 00:47、BV1V6U7BfEbc @ 00:51）。

**中路传送位**

- **让辅助帮抢线**："玩诸葛亮一定要让辅助帮我抢"（BV1c19PB2EKB @ 00:19）。
- **一技能必须打到每一个兵**，否则抢线速度起不来（BV1xCaBzJE9N @ 00:30、BV1xCaBzJE9N @ 00:33）。
- **二级是贴脸最强档**："二级的诸葛，可以说是所有中单里面贴脸打架最强的一位"（BV1mzCcBoEGb @ 04:06）。
- **四级前强度高于貂蝉**（BV1mzCcBoEGb @ 03:40）。
- **传送强势期只有前 6 分钟**（BV1mzCcBoEGb @ 04:40）。
- **对海诺可以近身躲戳**：他戳一下就用二技能躲，不用拉距离（BV1xCaBzJE9N @ 01:20、BV1xCaBzJE9N @ 01:25）。
- **没状态就避战**："因为我没有状态"——前期不硬接（BV1c19PB2EKB @ 01:34）。
- **卡回防位置蹲人**：算好对面中单回防路线提前卡位（BV1c19PB2EKB @ 01:37、BV1c19PB2EKB @ 02:35）。
- **一技能用极限距离放**：站在"对面反打没有那种欲望"的距离消耗（BV1xCaBzJE9N @ 11:46、BV1xCaBzJE9N @ 11:50）。

## 4. 中后期 / 节奏

- **先刷野再抓人**："如果野区放着不刷，那就纯纯浪费经济"（BV1BExk6nE4p @ 05:17、BV1BExk6nE4p @ 05:22）。
- **开龙有三道判断**：看不到对面中单和打野的视野就不开，因为"效率非常低"还可能送命（BV1BExk6nE4p @ 04:35、BV1BExk6nE4p @ 04:41、BV1BExk6nE4p @ 04:48）；自己野刷完、对面位置全露才开（BV1BExk6nE4p @ 06:10、BV1BExk6nE4p @ 06:16）；对面打野死了开龙"零危险"（BV1BExk6nE4p @ 12:58、BV1BExk6nE4p @ 13:03）。
- **不要自己开节奏**："你不要自己想去开节奏哈，那么多后手你自己去开"（BV1BExk6nE4p @ 09:52）；作为收割位"就等团开起来就完事了"（BV1BExk6nE4p @ 10:05）。
- **经济高了要抱团**："你经济高了之后，一定要跟队友抱紧一点"，目的是第一时间支援（BV1V6U7BfEbc @ 07:03、BV1V6U7BfEbc @ 07:09）。
- **中期目标是对面野区**：对面野一刷新就进攻，不然"很可能会被对面发育起来"（BV1V6U7BfEbc @ 05:41、BV1V6U7BfEbc @ 05:45）。
- **刷对面的蓝比刷自家蓝划算**：差的是支援速度，自家蓝刷完再走过去"队友差不多已经打输了"（BV1V6U7BfEbc @ 06:39、BV1V6U7BfEbc @ 06:48）。
- **压塔等对面清线再放一技能**："这样百分百会命中的"（BV1V6U7BfEbc @ 06:04、BV1V6U7BfEbc @ 06:07）。
- **压二塔不要和射手/法师站同一点**，否则对面一闪开就是几个 C 位一起被带走（BV1V6U7BfEbc @ 08:21、BV1V6U7BfEbc @ 08:25）。
- **有传送就带线威慑**：优势时"对面没有任何一个人可以带线"，因为传过去就是二打一（BV1xCaBzJE9N @ 10:22、BV1xCaBzJE9N @ 10:34）。
- **传送要看局势**：3~4 个人去抓那条线，"你传送过去就多添一个人头"（BV1xCaBzJE9N @ 08:44、BV1xCaBzJE9N @ 08:47）；队友不跟就终止行动（BV1xCaBzJE9N @ 08:05、BV1xCaBzJE9N @ 08:09）。
- **滚雪球之后一直控对面野区**，不要回自家蓝区（BV1xCaBzJE9N @ 06:37、BV1xCaBzJE9N @ 05:53）。
- **打到后期要分推**：对面有海诺这类守塔强的，上高地打三路比打两路更容易推掉（BV1xCaBzJE9N @ 12:14、BV1xCaBzJE9N @ 12:30）。
- **魔女是最大克星**："经济刷起来之后也比较害怕魔女"（BV1BExk6nE4p @ 07:37）。
- **没炽热就不打架**："没有炽热就不打架，就一直吃，有炽热再去浪"（BV1c19PB2EKB @ 07:32、BV1c19PB2EKB @ 07:35）。
- **炽热容易被忘**：它是被动装备，出了也常常忘记自己有这个保命技能（BV1xCaBzJE9N @ 07:14、BV1xCaBzJE9N @ 07:19）。
