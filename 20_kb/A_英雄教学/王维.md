# 王维：靠"闪避 + 空山"换血的法师，越拖越强

| 项 | 内容 |

## 1. 机制内核：三层，缺一层就废

### 1.1 被动「雾我无相」：每 5~4 秒叠 1 层，5 层闪避一次伤害

- 闪避**按伤害量扣层**，最多闪避 `250 + 50% 法强` 的伤害
- 关键推论：**这是一个"防爆发"被动，不是"防消耗"被动**。对面一套打死你时它救你，对面慢慢磨你时它一层层被抠掉
- 所以王维**怕的是持续消耗型（干将、小乔这类先手磨血再收割），不怕一套爆发型**
- **来源**：官方技能面板（S45）

### 1.2 一技能「空山入障」：站在自己的圈里，被动回得飞快

- 持续伤害 + 20%~40% 减速，1.5 秒后引爆
- **王维自己在范围内 → 进入"空山状态" → 快速回复被动层数**
- 这是王维的全部续航来源。**掉出圈 = 失去闪避 = 变成普通脆皮法师**
- **来源**：官方技能面板（S45）

### 1.3 二技能「江流渺渺」：击退 + 分叉，穿过空山会引爆

- 主水流击退 0.75 秒，命中后分出最多 2 道支流追人（50% 伤害 + 减速）
- **水流经过空山会绕山而行，把敌人卷进山里，并提前引爆空山**
- 这是连招的真正核心：**二技能不是起手，是"把对面按进我的圈里"**
- **来源**：官方技能面板（S45）

### 1.4 大招「天地一念」：本体留在原地，雾气穿墙走

- 第一段：本体不动，雾气化身飞行 9 秒，**无视地形、不可选中**，飞行中可放一二技能（替换成「乘雾」加速 /「回岚」转向）
- 第二段：瞬移到雾的位置，落地范围伤害 + 3 秒锁定多段伤害，期间**持续空山状态**
- 这是位移 + 保命 + 进场三合一，**也是王维唯一能主动开团的手段**
- **来源**：官方技能面板（S45）

## 2. 对线：一级就是打不过，别硬抢

- 对**嫦娥**这类一级强线权中单：**一技能只打后排兵，不打人**（BV15EJk6fEwX @ 00:27）
- 目的不是消耗，是**别被卡线**。被卡线 → 掉状态 → 丢闪现甚至丢整片野区（@ 00:28）
- 对面去支援时**不跟**，往**反方向**去下路拿资源（@ 00:39 / @ 00:40）
- 判断流程完整版见 `L_分路/01_中路.md` 的 `K-L07`

## 3. 连招：先把圈铺好，再谈伤害

**基础三连（对线换血）**
```
一技能落在自己脚下偏前 → 走进去回被动 → 二技能把对面卷进圈 → 引爆 → 出圈
```

**反打（被突进时）**
```
一技能落脚下 → 等对面进来 → 二技能击退（把人推出圈/推进圈） → 大招第一段拉开
```

**核心纪律**：**不要在没圈的地方和人对拼。** 王维的伤害和续航都在圈里，圈外他就是一个没有位移的脆皮。素材里那句"空山"状态是他唯一能站住的原因，本库据此把它定为**"空山 = 血包"**，而不是输出手段。

## 4. 出装 / 铭文（按 S45 胜率与出场率取的主流方案，非教学结论）

| 类别 | 推荐 | 说明 |
|---|---|---|
| 鞋 | **秘法之靴** | 法穿 + 回蓝，可 5 分钟免费换鞋 |
| 大件 1 | **回响之杖** | 技能命中触发范围爆炸，配合王维多段伤害 |
| 大件 2 | **博学者之怒** | 法强乘数，被动闪避上限也随之抬高（闪避量吃 50% 法强） |
| 铭文 | **梦魇 ×10 / 狩猎 ×10 / 心眼 ×10** | 法强 + 移速 + 法穿，胜率与出场率都是第一 |

> 数据来源：S45 王维英雄数据页（胜率 50.67%，出场率 3.6%，禁用率 4.12%）。**这是统计口径，不是"版本答案"**，版本一动就要重估。

## 5. 弱点：三条，都是"掉出圈"的变体

1. **失去空山 = 失去一切**：被击退、被强制位移推出圈，被动回不上，直接变成普通法师
2. **弱前期被卡线后滚雪球**：一级清不动线，一旦被压到塔下，河蟹/河灵/自家红区全让出去
3. **大招是保命牌，交掉后极脆**：9 秒飞行结束回来后如果没圈，等于站在对面脸上
