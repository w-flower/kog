# 孙权：12 级前夹着尾巴发育，12 级后只看大招会不会被打断

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份零基础到进阶的系统课（BV1t9Eq6iE1g）、一份国一晋级赛巅峰前百实录（BV1FbHG6tE7W）、一份技能+16 条小技巧+两套出装（BV1gWi4BEEJg）、一份技能阈值与备战细讲（BV14o3DziELe）、一份三句话底层逻辑（BV1CdtV6JEoE）。
> ⚠️ 五条素材对被动减伤数值给了两套口径（"每层 3%、上限 15%"与"一级满层 10%、15 级 20%"），本卡并列保留、未擅自统一；逐射手对位表与辅助搭配仍缺。

## 1. 机制内核

1. **被动叠印记减伤**：普攻和技能都能给敌方英雄叠印记，最高五层，叠满后敌方血条变蓝、暴露视野并解锁大招（BV1t9Eq6iE1g @ 00:31、BV1t9Eq6iE1g @ 02:25）。
2. **减伤数值有两套口径**：一说每层降低 3% 输出、最高 15%（BV1t9Eq6iE1g @ 00:31）；另一说一级叠满是 10%、15 级是 20%（BV1gWi4BEEJg @ 00:20）。素材未说明差异来自版本还是测试条件，本卡不合并。
3. **野怪小兵不能叠被动**（BV1gWi4BEEJg @ 00:37）。被动持续 5 秒，叠满后敌方视野暴露 5 秒（BV1gWi4BEEJg @ 00:31、BV1gWi4BEEJg @ 00:35）。
4. **攻速提升所有技能的释放速度**（BV1gWi4BEEJg @ 00:40；BV14o3DziELe @ 00:44），所以攻速既是输出也是叠印速度。
5. **一技能是军旗+箭雨**：中心点伤害高于单次剑雨，命中减速 15%~30%（BV1t9Eq6iE1g @ 01:03）；范围内有两个及以上敌方单位时剑雨落下更快（BV1t9Eq6iE1g @ 01:11）；持续期间还给范围视野，可用来探草（BV14o3DziELe @ 01:26）。
6. **二技能是主要输出方式**：长按进入即时状态，每秒耗 50 能量、获得 35~70 移速，锁定范围内两个目标（BV1t9Eq6iE1g @ 01:39）；连射视为普攻行为，能正常触发暴击与法球（BV14o3DziELe @ 01:36），伤害比普攻高（BV14o3DziELe @ 02:04）。
7. **二技能的几个手感细节**：点按的射程比长按远；普攻后接二技能可以无缝衔接；能量少时可以 A2A 快速打普攻（BV14o3DziELe @ 02:04）。破阵状态下近战攻击间隔缩减 50%，但两段伤害只算一次普攻行为、只触发一次法球（BV1t9Eq6iE1g @ 02:04、BV1t9Eq6iE1g @ 02:14）。
8. **大招是追击+后撤步**：叠满印记后出现蓝线牵引，点大默认锁定被牵引目标，追击期间可用方向键调整位置，最后一段伤害最高，砍完进入破阵状态（BV1t9Eq6iE1g @ 02:41、BV1t9Eq6iE1g @ 02:51）。
9. **大招会清空印记，但期间伤害会给其他目标叠印**：所以场上只要有两个目标，就能做到无限大招（BV14o3DziELe @ 03:29）。
10. **大招只看控制不看人数**：能不能进场只取决于大招会不会被打断，不取决于对面几个人（BV1CdtV6JEoE @ 00:15、BV1CdtV6JEoE @ 04:18）。大招会被各种控制打断（BV1gWi4BEEJg @ 04:32），前两段可以抵消短控（BV1gWi4BEEJg @ 05:15）；冲刺段本身不会被控制打断（BV14o3DziELe @ 03:14、BV14o3DziELe @ 03:20、BV14o3DziELe @ 03:24）。
11. **后撤步三条件**：被锁定目标位移拉出范围、目标死亡、目标进入无法选中状态（BV1t9Eq6iE1g @ 09:11、BV1t9Eq6iE1g @ 09:16、BV1t9Eq6iE1g @ 09:23）。石化、冰冻、定身、沉默、压制之外的眩晕、击飞、缴械、嘲讽、恐惧都打断不了后撤步（BV1t9Eq6iE1g @ 09:33）。
12. **捡旗（素材写作"简旗/剪辑"）**：开大时会回收场上的军旗，若军旗在目标附近且在二技能范围内，会先位移到军旗处打一段伤害再追击目标；这段伤害可暴击、吸血、触发电刀末世（BV1t9Eq6iE1g @ 07:52；BV14o3DziELe @ 05:09）。可以隔空收残血（BV14o3DziELe @ 05:15），也可以用来调整冲刺落点躲技能（BV14o3DziELe @ 05:23）。
13. **取消后摇/取消后撤**：大招期间长按二技能约 0.5 秒可以打断大招，点按不行（BV1t9Eq6iE1g @ 10:26）；追击期间提前按二技能也能取消后撤步、更快出伤（BV14o3DziELe @ 04:25）。

## 2. 对线 / 打法

- **一级点一还是点二看局**：我方辅助连体且有抢线能力，学一技能、中心点挂后排兵抢线（BV1t9Eq6iE1g @ 03:24）；一级强度不如对面，学二技能方便补塔刀（BV1t9Eq6iE1g @ 03:28）。
- **弱势射手前期就两件事：卡线、补兵**。"只要保证自己可以吃到三个兵，对于抗压射手来说，这个就是顺风"（BV1CdtV6JEoE @ 02:49、BV1CdtV6JEoE @ 03:09）。
- **把兵线卡在塔前**：下路一个人清完线也没事做，去打小野还可能被抢，不如控在塔前慢慢打（BV1CdtV6JEoE @ 02:41）。
- **被压就用一技能把对面身位压回去**（BV1CdtV6JEoE @ 02:56）；平A 加点按二技能补塔刀非常好用（BV1CdtV6JEoE @ 03:04）。
- **补刀细节**：铁剑出门，兵线 400 血左右 A2 可以直接补（BV1t9Eq6iE1g @ 11:15）；后排兵进塔可让防御塔先垫一刀，再用精准普攻或二技能补尾刀（BV1t9Eq6iE1g @ 11:22）。
- **2V2 判断**：辅助有抢线能力且强度比对面射辅高才学一技能抢线，否则学二消耗（BV1t9Eq6iE1g @ 11:39）。
- **有线权才有红隼争夺权**（BV1t9Eq6iE1g @ 11:49）；抢到红隼后用一技能中心减速多摸几下伤害（BV1t9Eq6iE1g @ 12:06）。
- **多看小地图防 GANK**，对面进自家野区要第一时间去换节奏止损（BV1t9Eq6iE1g @ 11:31、BV1t9Eq6iE1g @ 11:56）。
- **盯好对位就是贡献**：前期孙权"几乎就是跟个小兵一样"，但不过去对面射手就会滚起来，所以只能盯住对面发育路、不让他支援（BV1FbHG6tE7W @ 02:42、BV1FbHG6tE7W @ 04:08）。
- **对线强势射辅**：可以先出布甲鞋（BV1gWi4BEEJg @ 08:17）；打真香这种连体组合，前期对拼拼不过就学二补刀（BV1t9Eq6iE1g @ 11:02）。
- **8 级才有一战之力**：8 级后、等对面技能真空期再后手进场，进之前先用一二技能把被动挂满（BV1CdtV6JEoE @ 03:44、BV1CdtV6JEoE @ 03:48）。
- **前期大招基本没伤害**，而且清印记会消掉免伤，不是收残血就不要大招进场（BV14o3DziELe @ 06:30）。

## 3. 连招

| 场景 | 连招 | 要点 | 依据 |
|---|---|---|---|
| 通用叠印 | **一二技能叠满 → 大 → 二技能补印 → 再大** | 孙权连招本身不复杂，核心是叠印—开大—补印—再开大 | BV14o3DziELe @ 05:35 |
| 后期团·前排脱节 | **一技能+普攻叠印 → 大接二技能秒取消 → 强化一瞄后排 → 开大进场** | 用取消大招拿到强化一，再瞬间叠满第二个人 | BV14o3DziELe @ 05:44 |

| 多目标团战 | **大 → 大（取消后撤步）→ 继续追** | 场上两个以上叠满目标时可连续开大，打满伤害且不后撤 | BV14o3DziELe @ 03:42 |
| 收残血/隔空 | **一技能丢到目标附近 → 点大捡旗 → 再追击原目标** | 先位移到军旗打一段，再回到原目标 | BV14o3DziELe @ 05:09 |
| 拉扯/撤退 | **大招砍完 → 后撤步按方向键选落点 / 长按二技能0.5秒取消后撤** | 后撤方向由左轮盘决定，可穿大部分墙体 | BV1gWi4BEEJg @ 03:51、BV1t9Eq6iE1g @ 10:18、BV1t9Eq6iE1g @ 10:26 |

- 大招默认向敌方正前方挥舞，可把一技能丢到敌方身后再开大，用来规避技能（BV1gWi4BEEJg @ 03:05）。
- 大招范围很大，能打到身后两侧的敌人，追击期间可用方向键调整站位打到更多人（BV14o3DziELe @ 03:51）。
- 二技能射击锁面板，一轮完整射击不吃不详/冰心的减攻速，也不吃影刃的加攻速；所以最好先 A 出影刃被动再放二（BV14o3DziELe @ 02:36）。

## 4. 中后期 / 节奏

- **12 级是分界线**：12 级前稳定发育，12 级后以战养战，"团战就是最好的发育方式"（BV1CdtV6JEoE @ 00:27、BV1CdtV6JEoE @ 00:33）。
- **两套形态按对面控制选**：控多且坦度高，第三件出破晓当射手打，大招只斩脆皮；控少，第三件补肉装当战士打，被动满了就上（BV1CdtV6JEoE @ 00:48、BV1CdtV6JEoE @ 00:52）。
- **7 分半是装备检查点**：正常要做出两件套，做不出来就是究极逆风（BV1FbHG6tE7W @ 08:09）；3 分半做出末世是标准节点（BV1FbHG6tE7W @ 03:52）。
- **10 分钟龙团前后是发力窗口**，也是 12 级的时间点（BV1CdtV6JEoE @ 00:40；BV1FbHG6tE7W @ 10:00）。
- **入场时机是这个英雄最考验的东西**：顺风是团战收割机，逆风经济不崩、找机会勉强能打（BV14o3DziELe @ 08:15、BV14o3DziELe @ 08:21）。
- **逆风就沉淀、等对面给机会**，顶分段对面很少给机会，只能慢慢等（BV1FbHG6tE7W @ 07:23）；"王者荣耀是一个回合制游戏"（BV1FbHG6tE7W @ 06:39）。
- **逆风出装换思路**：不做制裁，做逐风 + 破晓走极致输出（BV1FbHG6tE7W @ 10:14）；顺风能放大就做制裁，放不了大就把制裁换逐风（BV1FbHG6tE7W @ 10:26）。
- **顺风多用二技能上嘴脸，大招一亮就点大**（BV1FbHG6tE7W @ 12:09、BV1FbHG6tE7W @ 12:13）。
- **一波团刷起来就无人能敌**（BV1gWi4BEEJg @ 06:21）。
