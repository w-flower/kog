## 1. 机制内核

1. **被动二天一流，两层被动两种形态**：放一个技能得一层（一重式），叠满两层是二重式；血条下面的蓝色格子就是层数（BV1GkRpBsEQz @ 00:29）（BV1GkRpBsEQz @ 00:50）。
2. **一重式是双刀挥斩**；二重式会向敌方突进并造成伤害，身边黄色小圈就是它的位移距离（BV1GkRpBsEQz @ 00:43）（BV1GkRpBsEQz @ 00:56）。
3. **强化普攻命中就减一二技能 1 秒 CD**；两层强普分开打出，所以是"一秒一秒的减少"，不是一次减两秒（BV1GkRpBsEQz @ 01:05）（BV1GkRpBsEQz @ 01:16）。
4. **一重式的额外收益**：敌方血量低于 50% 时会向前正斩，造成额外伤害（BV1GkRpBsEQz @ 01:22）。
5. **二重式可以穿墙**，既能快速刷野，也能"把前方目标当做踏板攻击身后的 C 位"——这就是踏刀术，兵线、野怪、防御塔都能当踏板（BV1GkRpBsEQz @ 01:26）（BV1GkRpBsEQz @ 01:36）。
6. **一技能空明斩是指向性剑气**：伤害 + 减速，还能击落路径上的飞行物（后羿大招、小乔一技能）（BV1GkRpBsEQz @ 01:50）（BV1GkRpBsEQz @ 01:58）。
7. **一技能释放时自带霸体**：可免疫西施牵引、王昭君冰冻、孙策大招击飞，特殊一点还能免疫老夫子的拉与白起大招嘲讽（BV1jMooBYEZj @ 01:58）（BV1jMooBYEZj @ 02:05）。
8. **剑气不止挡飞行物**：西施二技能、李元芳大招这种扔在地上的技能也能直接清除，且是 360 度无死角格挡（BV1jMooBYEZj @ 02:24）（BV1jMooBYEZj @ 02:30）。
9. **二技能神速未命中时 CD 10 秒**，命中目标则获得护盾并减 50% CD；护盾厚度随生命值（BV1GkRpBsEQz @ 02:13）（BV1GkRpBsEQz @ 02:20）。
10. **减 CD 叠加后能无限二重式**："减少 50% 的 CD 以及被动强普打中目标后会减少一秒，冷却就能无限二重式衔接"（BV1GkRpBsEQz @ 02:24）。
11. **大招一决生死是范围锁定，不是单体**：范围内其他英雄同样吃击飞、伤害与重伤，且没有人数限制（BV1GkRpBsEQz @ 03:06）。
12. **大招重伤 5 秒，期间所有回复统一延后到 5 秒后返还**，"百分百克制"（BV1GkRpBsEQz @ 02:55）。
13. **大招会把目标向前击退一个身位**，所以在塔边缘可以把他击退出塔再集火（BV1GkRpBsEQz @ 03:24）。
14. **三个技能的实际距离都远于指示器**：一技能差一个闪现都能打中，二技能的伤害距离是显示距离的两倍，大招滑动打不中时可以改用点击（BV1GkRpBsEQz @ 03:36）（BV1GkRpBsEQz @ 03:48）（BV1GkRpBsEQz @ 03:58）。
15. **强化普攻不吃攻速**，所以伤害不靠攻速装，靠的是二重式与减 CD 的循环（BV1GkRpBsEQz @ 04:11）。

## 2. 对线 / 打法

- **开局看对抗路强弱**：前期 2V2 弱势（如对面上野老夫子+阿古朵）就"直接选择对抗路红开"，同时让辅助看蓝防反（BV1jMooBYEZj @ 02:42）。
- **蓝开还是红开**：宫本"蓝开比红开快个五秒钟"（BV1KF411k7Ay @ 01:05）；另一份则用蓝开做"开局刷七野"——蓝开、1 分钟吃中线、再刷到红区（BV1Qb421n7TT @ 00:43）。
- **红开则只能六野**：红开且 1 分钟吃中线再回蓝区，"你这把就是六野开局了"（BV1Qb421n7TT @ 00:55）。
- **0 到 4 分钟只做发育**："我们是在发育的过程中顺路去抓人，而不是特意的为了抓人而抓人"（BV1jMooBYEZj @ 03:43）。
- **清线先打两个后排兵**：让自家兵线去集火前排兵，清得更快（BV1jMooBYEZj @ 03:12）。
- **吃中线有两个好处**：拿中线经济；让自家中路比对面更早动起来，替你去其他路做事（BV1jMooBYEZj @ 04:17）。
- **补尾刀而不是全清**：等防御塔把兵打残再补，"这样子可以是我们经济最大化"，也让队友吃到兵（BV1KF411k7Ay @ 02:33）。
- **打赵云只躲二技能**："我们打赵云只需要躲掉他的二技能就行了，他的大招一技能我们吃满也不用怕"（BV1QC4y1z7iA @ 02:16）。
- **打狂铁看经济差**："只要经济不落后 1000 以上，我们是随便打他的"（BV1QC4y1z7iA @ 04:13）。
- **打梦奇是硬克制**：梦奇"砍一刀他就刷一个护盾，打又打不动，跑又跑不了"，只能靠前期节奏拉开经济差（BV1KF411k7Ay @ 00:06）（BV1KF411k7Ay @ 03:46）。
- **遇到后期阵容要前期打炸**：对面全是后期英雄时"前期要把握好节奏，把对面打炸，不让他们有拖到后期的机会"（BV1KF411k7Ay @ 00:49）。
- **不抢没把握的龙团**：敌方都在上半野区、视野早站好，"我们就没必要过去硬接这波龙团"（BV1jMooBYEZj @ 05:07）。
- **打团就近原则**："谁离得近就打谁，避免被拉扯"（BV1GkRpBsEQz @ 12:42）。
- **残血就撤，不死战**："血量不健康时就进行撤退，剩下的交给队友"（BV1GkRpBsEQz @ 12:52）。

## 3. 连招

## 4. 中后期 / 节奏

- **4 分钟保护机制消失、节奏变快**：这之后"可以更快的发育以及更好的入侵反野"（BV1jMooBYEZj @ 05:35）。
- **有机会再支援，不是先过去等**："我们打野是有机会之后再支援，而不是先支援过去，等在原地浪费时间"（BV1jMooBYEZj @ 05:50）。
- **野怪会等，兵线不等**："野怪还在，但是你中路兵线不吃，错过了就是错过，它是不可再生的"（BV1jMooBYEZj @ 06:04）。
- **暴君优先于主宰**："暴君永远大于主宰"，暴君给移速与攻击力，主宰只是兵线，只有压塔才需要（BV1QC4y1z7iA @ 04:42）。
- **优势拿暴君、逆风拿主宰、特别顺开双龙**（BV1jMooBYEZj @ 09:01）。
- **大招要捏给后排**：开到辅助"没必要上，我们要把大招留给敌方的后排双 C"（BV1jMooBYEZj @ 09:12）。
- **逆风核心是不掉点**："队友可以一直掉点，但是我们是核心，我们如果掉点，那这把是真的没得打"（BV1QC4y1z7iA @ 06:43）。
- **逆风视野要藏深**："我们不能随便露视野，不能让对面发现我们的行踪"（BV1QC4y1z7iA @ 06:50）。
- **逆风要赌资源**："逆风本来就缺资源，所以说我们要更要赌"，赌失败就直接走、千万别掉点（BV1QC4y1z7iA @ 07:15）。
- **假视野骗大招**：走开再回来，"赵云可能以为我走了……但是没想到我又回来"（BV1QC4y1z7iA @ 08:00）。
- **转折点靠霸体吃控制链**：一技能霸体打掉王昭君冰冻，强化普攻减 CD 频繁刷新技能，"把这三个都给干死"（BV1QC4y1z7iA @ 08:20）。
- **能推就推，推不了就换事做**："必定能破的防御塔，我们没必要两个人过来一起推塔"，留队友推、自己去拿龙或反野（BV1jMooBYEZj @ 07:59）。
- **中后期节奏公式**：抓到掉点就顺势推进；没兵线就反野；中路推不上去就换一路推（BV1jMooBYEZj @ 07:47）（BV1jMooBYEZj @ 07:54）。
- **后期就是带线打少人团**："后期确实只能这样打，对面正面团硬刚不过，只能带线牵制对面打少人团"（BV1KF411k7Ay @ 12:57）。
- **后期谁先急谁输**："这个时候千万不要心急，哪边先急了，哪边就输"（BV1KF411k7Ay @ 13:15）。
- **开团目标固定两个人**：蒙犽这类射手，以及想开团的达摩；先大招控开团位，再回头找射手（BV1Qb421n7TT @ 06:49）。
- **大龙后别掉点**："如果这个时候掉点的话，这个龙就白拿了"（BV1QC4y1z7iA @ 15:54）。

## 5. 出装铭文

**铭文（两份口径一致）**：蓝色十隐匿、绿色十鹰眼、红色十异变，即"隐匿百穿"（BV1jMooBYEZj @ 01:42）（BV1GkRpBsEQz @ 07:17）。带隐匿的理由是"地图变大，宫本跑图速度本来就慢，所以我们要用铭文去弥补移速"（BV1QC4y1z7iA @ 01:01）。不带吸血和攻速：这版本出吸血刀"团战中也吸不上多少血"，攻速阈值改了之后"根本就没有必要出攻速铭文"（BV1QC4y1z7iA @ 01:08）（BV1QC4y1z7iA @ 01:21）。

**出装顺序（阿泽/洗剪吹版，BV1jMooBYEZj @ 00:58）**：

1. 野刀出门 → 二阶野刀 → CD 鞋 → 升级大打野刀（BV1jMooBYEZj @ 00:58）（BV1jMooBYEZj @ 01:01）。
2. 中间先买"源流结晶"（5% 冷却），让三级野刀 + 源流结晶 + 蓝 Buff 的 CD 够连二技能（BV1jMooBYEZj @ 01:06）（BV1jMooBYEZj @ 01:11）。
3. 第三件血手，加容错与反打能力（BV1jMooBYEZj @ 01:08）。
4. 换鞋看对面：物伤多忍足，法伤/控制多抵抗鞋（BV1jMooBYEZj @ 01:16）。
5. 对面回复多，先补红莲再补黑切（BV1jMooBYEZj @ 01:21）。
6. 冰脉只在"逆风拿不到蓝的情况下才会做"（BV1jMooBYEZj @ 01:24）。
7. 最后一件黄盾补续航；后期可鞋换魔女/霸者，阵容缺伤害则鞋换破军（BV1jMooBYEZj @ 01:29）（BV1jMooBYEZj @ 01:32）（BV1jMooBYEZj @ 01:37）。
