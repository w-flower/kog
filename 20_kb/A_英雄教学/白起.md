## 1. 机制内核

1. **被动是挨打换续航**：受击叠紫色能量条，移速与回血同步变快，所以"白起非常抗揍"（BV1qW4y1C7dR @ 00:23、@00:26、@00:28）。
2. **一技能受击会概率自动反击**："白起受到伤害呢，有 20% 几率释放一技能进行反击"（BV1qW4y1C7dR @ 00:34、@00:35）。
3. **一技能蓄力过中线即满收益**："蓄力和蓄力满的伤害是一样的，所以蓄力时间只要过了中间就可以"（BV1qW4y1C7dR @ 00:40、@00:43）；蓄力越长伤害越高、回血越多，超过中间黄线即最大化（BV1zNwweNEaq @ 04:10、@04:13）。
4. **取消一技能会返冷却**：蓄力途中取消释放"还可以 CD 的"，打不到人时可以用来刷冷却（BV1qW4y1C7dR @ 00:47、@00:48、@00:50）。
5. **一技能回血不看目标数量**：命中一个和命中一群"恢复效果都是一样的"，且"命中英雄的回血量是命中小兵野怪的两倍"（BV1qW4y1C7dR @ 00:55、@00:57、@01:01）。
6. **一技能是 3D 判定**：脚底蓝圈与技能圈不是一回事，左侧攻击圈对齐就能命中，右侧即使重合也打不到（BV1zNwweNEaq @ 04:34、@04:38、@04:40、@04:44）；一技能可以取消普攻后摇，A1 瞬间两段伤害（BV1zNwweNEaq @ 04:54、@04:55）。
7. **二技能有延迟，钩子消失后还能拉人**："明明二技能钩子已经消失，但是短暂延迟之后还可以无形的把人拉过来"（BV1qW4y1C7dR @ 01:05、@01:07；BV1zNwweNEaq @ 00:29、@00:30、@00:36）；延迟还能覆盖两侧目标（BV1zNwweNEaq @ 00:32）。
8. **二技能实际范围比指示器远**：爪子参差不齐但实际范围一样，看起来打不到的空白位置能直接拉到（BV1zNwweNEaq @ 01:16、@01:20、@01:22、@01:26）。
9. **二技能拉人距离固定**：正常拉人会把目标拉到身边，拉的时候向后移动"并没有增加距离，距离是固定的"（BV1zNwweNEaq @ 05:24、@05:26、@05:29、@05:31）。
10. **大招嘲讽 = 强制对方普攻你**，最长 2.5 秒，"这个控制时长呢跟生命值挂钩的，每 1000 额外生命值增加 0.2 的控制时长"（BV1qW4y1C7dR @ 01:25、@01:29、@01:30、@01:32、@01:34）。
11. **大招落地瞬间满能量**：放完大招能量瞬间满格，回血与移速拉满（BV1qW4y1C7dR @ 01:40、@01:41、@01:43）。
12. **大招空中可以蓄力一技能**："我们大招在空中位移的过程中就可以蓄力一技能了，落地一技能伤害可以更快的打出来"（BV1qW4y1C7dR @ 01:47、@01:49、@01:51）。
13. **大招落地前就已产生控制**："其实在大招落地之前就可以提前产生控制效果，并不是落地之后才会触发嘲讽"（BV1zNwweNEaq @ 02:48、@02:52、@02:54）；所以能打断项羽、牛魔、苏烈这类蓄力读条技能（BV1zNwweNEaq @ 03:23、@03:26、@03:28）。
14. **大招边界命中也会嘲讽**：不是只有中心命中才生效，"边界命中敌人一样可以被嘲讽"，指示器给了距离短的错觉（BV1qW4y1C7dR @ 02:06、@02:07、@02:10、@02:14、@02:16）。
15. **大招可以往墙里扔延长范围**：技能落点可以进墙，但本体会被墙体卡出来，于是攻击范围被延长（BV1zNwweNEaq @ 03:45、@03:47、@03:50、@03:52）。
16. **嘲讽期间普攻无视草丛视野**：所以"千万不要草里嘲讽"，否则射手能在没有视野的情况下直接打到你（BV1zNwweNEaq @ 02:33、@02:35、@02:36、@02:40）。
17. **大闪与钩子方向**：大招可与闪现配合改变位置与朝向，也能改变二技能钩子的方向，"有时候也可以用来代替闪现去使用"（BV1qW4y1C7dR @ 01:53、@01:54、@01:59、@02:02）。

## 2. 对线 / 打法

- **前期的固定节奏**："一波兵线一组野怪，线能先手清就先手清，先手清不了就后手放进塔里清"，买布甲出门（BV1cec1zDEsu @ 00:17、@00:19、@00:20、@00:22、@00:24）。
- **对线期的唯一硬指标**："四分半一件成装加一件鞋子，大概是 2800 左右的经济"（BV1cec1zDEsu @ 02:42、@02:45）。
- **为什么主要收益优先**："主要收益能不能拿，是完全掌握在我们自己手里的，是不会受队友影响的"（BV1cec1zDEsu @ 02:31、@02:35、@02:36）。
- **没生命值就别打架**："前期我们生命值还没有叠起来的时候，就尽量不要跟对面打架，我们发育就好了"（BV1cec1zDEsu @ 01:35、@01:38、@01:40）。
- **带惩戒是为了经济**："白起带惩戒就是为了发育，不是说肉刀伤害有多高，白起是非常需要经济的"（BV1qW4y1C7dR @ 06:41、@06:43、@06:46）。
- **前期猥琐别送雪球**："前期猥琐一点，不要被玄策滚起来了"（BV1B8JX6wEo6 @ 00:32）。
- **一级伤害要记死**："白起一级的一技能伤害 495，我们只要计算好伤害就没他什么事了"（BV1qW4y1C7dR @ 06:11、@06:13）。
- **抢野靠算伤害**："你要计算好一技能伤害，这样才能够顺利抢到野怪"（BV1qW4y1C7dR @ 06:25、@06:27）。
- **四级后转发育路**："四级的白起是很强的"，去发育路找机会，大招接二技能配合射手（BV1qW4y1C7dR @ 05:32、@05:36、@05:37、@05:39、@05:41）。
- **打猪八戒的专版**：前期布甲鞋优先抢线，"因为对线猪八戒，你做活甲你也打不过"，先做黄盾（BV1iWk6B7Eks @ 00:00、@00:03、@00:07、@01:40、@01:42、@01:44）。
- **对抗路刷钱的最快路径**："拿出优势先打对线，然后有线权拆了外塔，然后再来下船或者往中传的打架"（BV1iWk6B7Eks @ 08:05、@08:08、@08:12）。
- **参团取舍**："队友不行，别去参团；如果是你不行，你就放线去参团"，"优先带好你的线，然后你再去参团"（BV1iWk6B7Eks @ 06:39、@06:41、@06:42、@06:57、@06:59）。
- **不漏视野不清线**："漏了漏了再去清线，不漏的话就千万不要清线"（BV1iWk6B7Eks @ 05:14、@05:16）。
- **大招要等队友**：没输出、需要队友补伤害时"等队友在旁边，我们在大招控对面"（BV1cec1zDEsu @ 05:40、@05:42、@05:44）；开团前"给队友信号让他别着急动手"（BV1cec1zDEsu @ 07:22、@07:23）。
- **捏住大招等位移**："这一波我们大招捏死一点，等对面的赵云交了位移再交大"（BV1cec1zDEsu @ 02:06、@02:07）。

## 4. 中后期 / 节奏

- **中期的唯一思路**："坦边中期的思路就只有一个，清中转边"，把一边的中路视野占出来配合队友抢线（BV1cec1zDEsu @ 04:16、@04:19、@04:21、@04:22）。
- **后期与中期几乎一致**："后期开始我们坦边的时候，其实跟中期差不多"，中线跟队友，边路线不需要坦边去管（BV1cec1zDEsu @ 09:55、@09:57、@09:59、@10:03）。
- **带线的经济价值**：实战 7100 经济时对面三人过来都杀不了，"你二塔断线都没事"，带完线回头正好接中路团（BV1iWk6B7Eks @ 08:46、@08:51、@08:56、@08:57）。
- **一直带上下线牵制**："就一直带上下线牵制他"，上下路都通关后再回中（BV1iWk6B7Eks @ 09:40、@09:42、@11:18、@11:20）。
- **传送的价值**："这把带传送的原因是因为对面手都挺短的，我们不需要带闪现就能开到对面的 C 位"（BV1cec1zDEsu @ 07:54、@07:56、@07:57）。
- **不带斩杀的理由**："带斩杀是为了 K 头的，但是改变不了我们是工具人的属性……我们吃这么多人头又带飞不了"（BV1cec1zDEsu @ 08:06、@08:08、@08:10）。
- **龙团流程**：先占暴君视野，"带完这一波线再准备去开龙"；对面少人且知道位置时才带远端线（BV1cec1zDEsu @ 10:30、@10:32、@10:38、@10:42）。
- **开团必须有队友接**：没有输出，"需要队友来补伤害"，所以大招要卡在队友到位之后（BV1cec1zDEsu @ 05:44、@05:45、@05:46）。
- **没大就去带线**："没大招去把线带"（BV1iWk6B7Eks @ 07:34、@07:36）。

## 5. 出装铭文

**铭文**

- 蓝色 6 隐匿 + 4 调和，绿色 10 虚空，红色 10 宿命；白起"肯定要先堆生命值"，且配合皮肤 120 生命加成"还能卡住生命值 1000 的阈值"（BV1qW4y1C7dR @ 03:03、@03:06、@03:07、@03:11、@03:13、@03:18、@03:20）。

**出装（主坦流，BV1qW4y1C7dR）**

- 开局小打野刀 → 打河蟹发育 → 先升级打野刀（不急着买鞋）→ 鞋 → 熔炼之心增强清线（BV1qW4y1C7dR @ 03:27、@03:29、@03:31、@03:33、@03:35、@03:37）。
- 对面控制不多、物理多：布甲鞋；法师控制多：抵抗靴（BV1qW4y1C7dR @ 03:40、@03:42、@03:44、@03:45）。
- 之后守护者之铠防单带 → 均势先合红莲斗篷 → 再出永夜守护 → 打野刀再升 → 最后补血手（BV1qW4y1C7dR @ 03:47、@03:49、@03:53、@03:55、@04:01、@04:03）。
- 逆风对法师多（司马懿/司空震/诸葛）：不祥征兆 + 永夜 + 不死鸟，卖鞋出血手（BV1qW4y1C7dR @ 04:06、@04:08、@04:12、@04:13、@04:15）。
- 物理多：不祥征兆 + 永夜 + 反甲，鞋最后也做成血手（BV1qW4y1C7dR @ 04:19、@04:22、@04:25）。
- 再配"秒换装"可以连换两到三件（BV1qW4y1C7dR @ 04:26、@04:28、@04:29）。

**出装（打猪八戒特化，BV1iWk6B7Eks）**

- 前期布甲鞋优先抢线；因为做火甲也打不过猪八戒，先做黄盾；之后补红莲斗篷（BV1iWk6B7Eks @ 00:03、@00:05、@00:07、@01:42、@01:44、@04:16）。
- 对两个法伤时"一个永夜够了"，之后按需要补冰甲或反甲，最后复活甲（BV1iWk6B7Eks @ 08:34、@08:41、@10:47）。
