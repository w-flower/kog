# 张良：把 2.2 秒压制连成 3.7 秒控制链

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：三份辅助张良实战（BV1xQGEzCEqH、BV1skP4z5EN4、BV1wzNMz4E8A）、一份连招与团战教学（BV1wnE2zcEJ2）、一份 2300 分反野与控链细节（BV189PNzxEwe）。
> ⚠️ 素材以**辅助张良**为主，中路张良只有出装与铭文一段；两套定位的实战差异未覆盖完整。

## 1. 机制内核

1. **大招是压制，且结束时自带眩晕**：压制 2.2 秒，大招最后还有 0.75 秒眩晕，一技能再 0.75 秒，整条链 3.7 秒（BV189PNzxEwe @ 02:31~02:39）。
2. **二技能是"小型防御塔"**：放下后自己攻击敌人；对小兵和野怪有 50% 额外伤害（BV1wnE2zcEJ2 @ 00:30~00:35）（BV1wnE2zcEJ2 @ 02:14~02:18）。
3. **二技能圈内自身加速**：站在自己二技能圈里可以加速，这是开局反野和拉扯的本钱（BV1skP4z5EN4 @ 00:26~00:30）。
4. **二技能中心放草里可以拿草丛视野**（BV189PNzxEwe @ 04:38~04:41）。
5. **一技能是眩晕墙，可封走位、可分割战场**：保人时放敌人前面，留人时拉最远放身后（BV1wnE2zcEJ2 @ 01:01~01:15）。
6. **被动真伤要靠持续普攻**：用技能打人或反野时一定要持续普攻，造成额外伤害且是真实伤害（BV1wzNMz4E8A @ 02:35~02:44）。
7. **四级前几乎压制所有近战**："绝大多数近战英雄都打不过张良的"（BV1wnE2zcEJ2 @ 00:52~00:55）。

## 2. 对线 / 打法

- **开局跟发育路、靠法阵快速过野**：张良正常跟发育路，用二技能快速清野拿资源；就算对面中辅去抢线权，也能在他们到之前把鸟拿掉（BV1xQGEzCEqH @ 00:54~01:12）。
- **反野的两个前提**：带法穿铭文（肉铭文反野太慢）；对面中单在中路就不要反，很危险（BV1wzNMz4E8A @ 00:12~00:26）。分段不高时对面不守野，可以偷 Buff，法穿铭文甚至能单杀对面打野（BV189PNzxEwe @ 00:26~00:38）。
- **帮打野刷野的三个细节**：一红只放一个二技能、不补多余平A；打小猪时二技能只放大猪身上，平A也打大猪，避免锁到小猪浪费伤害；蓝区只放一个二技能给蓝 Buff，马上去打蜥蜴，避免误抢队友 Buff（BV189PNzxEwe @ 00:43~01:03）。
- **不能打连体**："张良这个英雄是绝对不可能打野连体的，你只要连体在线上，那就是明牌"；转中游走才能给三线压力（BV1xQGEzCEqH @ 02:45~03:01）。原因是发育路射手没爆发，两秒压制内秒不掉人（BV1xQGEzCEqH @ 03:06~03:16）。
- **到四的时间点**：吃完发育路两波线 + 打野一半野区就能到四（BV1xQGEzCEqH @ 02:26~02:32）。反野开局则"找机会升四级"，没四之前抓不了人、出不了节奏（BV1wzNMz4E8A @ 01:37~01:39）（BV1skP4z5EN4 @ 01:22~01:25）。
- **四级前宁可不管射手**：一是有防御塔保护机制，二是自己没四出不了节奏，只做消耗和帮清线（BV1skP4z5EN4 @ 01:01~01:21）。
- **不要漏视野、不要去清线**：四级前清线会导致下一波线到不了四，漏视野对面就会狠压你的下路（BV189PNzxEwe @ 01:16~01:26）。
- **四级后不去发育路找节奏**，优先抓对抗路和打野：抓对抗路是藏视野，趁对面边路皇城 PK 时出去按住（BV189PNzxEwe @ 01:26~01:36）；抓打野两种方式，一是对面中单放线、只剩打野一人补线时喊中野三人出去按，二是强行入侵对面第二波野区的第二个 Buff（BV189PNzxEwe @ 01:36~01:48）。
- **有大招时故意消失视野**：按不到就立刻后撤消失，"一个有大招的张良消失视野威慑力是很足的"，对面打得过也不敢贸然清线（BV189PNzxEwe @ 03:03~03:23）。要漏视野等中路清完线再漏（BV189PNzxEwe @ 03:24~03:32）。
- **前期越塔要等**：不要急着闪现，等对面清线、辅助抗塔时再上，还有机会走；急着闪反而是白给（BV1wzNMz4E8A @ 02:12~02:27）。

## 4. 中后期 / 节奏

- **大招目标优先级**：团战只给前排，或者留着给对面打野；"千万不要跳过前排按后面的英雄，非常容易断大"（BV1wnE2zcEJ2 @ 02:46~02:52）。
- **队友是呆射时改打后手**：鲁班、后羿、黄忠这类，后期留大招保射手，非必要不放；二技能放射手脚下，一技能随时防突脸（BV1wnE2zcEJ2 @ 04:07~04:22）。
- **对面打野强势时大招只留给他**：素材里对兰陵王就是"只要他露视野就按他"（BV1wnE2zcEJ2 @ 04:22~04:33）。
- **被拉进团战中心时**：把一技能放自己身上，能陆续眩晕周围三个英雄（BV1wnE2zcEJ2 @ 03:15~03:25）；放完技能立刻撤出团战等 CD（BV1wnE2zcEJ2 @ 03:25~03:30）。
- **守龙 / 打龙**：两个二技能丢龙坑帮队友打龙，一技能放在抢龙必经位置——要么交位移要么绕路；手里始终捏着大招（BV1wnE2zcEJ2 @ 04:37~05:27）。
- **有优势先拿龙**：龙"相当于加了一件装备"，五个人都享受 Buff（BV1skP4z5EN4 @ 12:10~12:21）；当前版本黄龙收益比子龙大（BV1xQGEzCEqH @ 08:52~08:58）。
- **基本不回城**：回家浪费状态也浪费时间，出星泉后更不需要回（BV1skP4z5EN4 @ 02:12~02:16）（BV1skP4z5EN4 @ 03:22~03:27）。
- **跟着队友的节奏走**：不要另起节奏，队友打野带节奏就跟着他（BV1wzNMz4E8A @ 06:48~06:58）。

**中路张良（全输出）**：

- 开局回蓝项链 → 疾跑鞋（张良移速真的很慢）→ 回响、帽子、法杖三件套 → 按对面阵容补一件防装：法术高做魔女，物理高做不祥征兆（BV1wnE2zcEJ2 @ 05:35~05:52）。

**实战散点**：
