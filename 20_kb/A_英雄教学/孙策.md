## 1. 机制内核

1. **被动两个，都是前期强势的根**：每六秒一发强化普攻，额外物伤并回血，回血量与已损生命挂钩，血越低回越多（BV1wz421o7Az @ 00:52、BV1wz421o7Az @ 00:57）；每次受到物理/真实伤害或技能命中目标都叠一层，每层 20 护甲、最多十层，满级最多 480 点护甲，"相当于自带一件物抗装"（BV1wz421o7Az @ 01:01、BV1wz421o7Az @ 01:11、BV1wz421o7Az @ 01:15）。
2. **法伤不叠被动，其余都能叠**：抗塔也算，所以"感觉要被抓了，去扛一下塔刷新被动的掉落时间"（BV1wz421o7Az @ 01:19、BV1wz421o7Az @ 01:41）。
3. **一技能是下限定盘**：位移 + 路径伤害 + 原地水坑，一秒后伤害并击飞（BV1wz421o7Az @ 01:49），"大部分连招都是建立在一技能基础上"（BV1wz421o7Az @ 02:03）。只有终点才击飞，所以对手会贴脸规避二段一（BV1wz421o7Az @ 02:41）。
4. **一技能三段伤害都能叠被动**，路径伤害别浪费（BV1wz421o7Az @ 02:11、BV1wz421o7Az @ 02:16）。
5. **二技能是核心输出**：三段回砍，每段 15% 减速可叠加，伤害逐段递增，打空会损失大量输出（BV1wz421o7Az @ 03:03、BV1wz421o7Az @ 03:09、BV1wz421o7Az @ 03:13）。二技能会刷新普攻，普攻又能取消后摇，所以 A2A 比裸三段丝滑（BV1wz421o7Az @ 03:27、BV1CYrsYQEsL @ 05:47）。
6. **二技能放完才开始算 CD**，所以二技能起手能让真空期更短（BV1wz421o7Az @ 04:01）。
7. **大招 12 秒驾船、全程霸体、船速随时间提升**（BV1wz421o7Az @ 04:08、BV1wz421o7Az @ 04:13）；撞到除小兵野怪以外的东西就爆炸，伤害和击飞与开船时间挂钩（BV1wz421o7Az @ 04:17、BV1wz421o7Az @ 04:23）；爆炸期间命中的敌人瞬间叠层被动（BV1wz421o7Az @ 04:25）。
8. **别直接贴脸撞**：下船有非常明显的后摇，尽量用二段把船丢出去，好更快接技能（BV1wz421o7Az @ 04:34、BV1wz421o7Az @ 04:38）。二段下船位置由指示器控制，且下船能穿墙（BV1wz421o7Az @ 04:43、BV1wz421o7Az @ 04:51）。
9. **改版后撞完自动后撤一下，距离刚好接一技能击飞**（BV13exk63Eie @ 02:30、BV13exk63Eie @ 02:32）；并且可预输入一二技能，"进了再蓄力，后面就不用你点了"（BV1g1W36yEoP @ 00:36、BV1g1W36yEoP @ 01:14）。
10. **开船进入敌方 3000 码会暴露三秒视野，但对同一目标只生效一次**（BV1wz421o7Az @ 06:36、BV1wz421o7Az @ 06:56；BV1CYrsYQEsL @ 06:19）。
11. **附近队友可以点上传船**，但丢船或船上队友受控会强制下船（BV1wz421o7Az @ 05:53、BV1wz421o7Az @ 06:12）。

## 2. 对线 / 打法

- **抢线固定套路**：开局绕到河道草丛，用肉身吸引前排小兵仇恨，一技能砸后排兵别急，等小兵聚一起一次 A 三只（BV1wz421o7Az @ 07:21、BV1wz421o7Az @ 07:26）。
- **两套抢线计时**：一技能抢线约 36 秒、抢完被动八层（BV1NvwWzeEo9 @ 07:33、BV1NvwWzeEo9 @ 07:58）；二技能抢线约 35 秒，更保险、容错更高，但少一套技能（BV1NvwWzeEo9 @ 08:03、BV1NvwWzeEo9 @ 08:33）。
- **出门铁剑增加对线能力**（BV13exk63Eie @ 01:00）；鞋子出门换铁剑再预购布甲也是可用起手（BV1NvwWzeEo9 @ 07:23）。
- **0~4 分钟以发育为主**，优先堆装备提伤害，为中后期支援做准备（BV13exk63Eie @ 04:37）；发育结构是一组兵线 + 一组野（BV13exk63Eie @ 04:56）。
- **前期两种打法**：对线弱势英雄就压制找单杀；有线的主动权就去支援打架打人数差（BV13exk63Eie @ 04:45、BV13exk63Eie @ 04:52）。
- **1 分半要收**：这个点大部分打野出野区，往后撤或草里蹲（BV13exk63Eie @ 04:59）；等对面在别路露头再出来抢线（BV13exk63Eie @ 05:09）。
- **逆风/劣势把线卡在塔外**，补线不被打太多状态；代价是容易被多人越塔（BV13exk63Eie @ 05:34）。
- **贴脸时用卡墙一**：一技能贴脸难命中，就假装示弱往墙边走，把一技能往墙里放，让水坑留在身前原地击飞，反打很好用（BV1wz421o7Az @ 02:52、BV1CYrsYQEsL @ 07:15）。
- **一技能边缘接眩晕会跳起来，贴脸才无缝**：敌人站边缘要等落地再点眩晕，但容易让人跑掉（BV1NvwWzeEo9 @ 01:01、BV1NvwWzeEo9 @ 01:17）。
- **二技能侧斩**：每次二技能都会向前小碎步，塔外直接放会白吃塔伤，侧斩左右位移可无伤换血（BV13exk63Eie @ 03:09、BV13exk63Eie @ 03:19；BV1CYrsYQEsL @ 05:30）。
- **打司空震别硬拼**：法伤面前"孙策等于是没有被动的"，可能被开狂暴 A 死；没辅助帮就后撤闪现（BV1wz421o7Az @ 07:44、BV1wz421o7Az @ 07:42）。不好打的还有芈月、嫦娥等法系和亚连（BV1wz421o7Az @ 07:51）。
- **"这版本更线上对线"对孙策不适用**：地图变大让别的英雄支援成本变高，才凸显他大招的价值，"有机会千万不要在线上"（BV1wz421o7Az @ 08:00、BV1wz421o7Az @ 08:07）。
- **对线海诺不要硬碰**，把线一过就去打团打支援（BV1g1W36yEoP @ 02:35）。

## 4. 中后期 / 节奏

- **中后期打法高度重复**："带线支援、带线支援，就这样保持循环"（BV13exk63Eie @ 07:22）；就近原则，哪里有兵线去哪，有线就抢、有架就开大（BV13exk63Eie @ 07:42）。
- **拔掉对面一塔后可以提前截线**，不等两路兵线交汇，支援速度往前推一个节点（BV13exk63Eie @ 08:09、BV13exk63Eie @ 08:13）。
- **两种开船支援**：一是队友即将开团时提前到场，先手开团直接找 C 位爆掉（BV13exk63Eie @ 08:54、BV13exk63Eie @ 09:04）；二是自己状态不好、队友先打，等双方技能交得差不多再后手入场收割（BV13exk63Eie @ 09:09、BV13exk63Eie @ 09:22）。
- **开船支援不一定非要打人**，稳定控到资源（龙）也算支援（BV13exk63Eie @ 09:59）。
- **后期确实乏力**："孙策到了后期阶段，他是比较乏力的，没办法直接左右比赛"，此时的任务是卡位置、卖血量、主动开团，给双 C 创造推塔空间（BV13exk63Eie @ 10:10、BV13exk63Eie @ 10:14）。
- **团战定位是刺客**：除非自家打野或射手特别肥可以先去开团，其余时候"把自己当刺客玩"，多盯对面射手和法师（BV1wz421o7Az @ 08:55、BV1wz421o7Az @ 09:02、BV1wz421o7Az @ 09:07）。
- **逆风看阵容决定带不带线**：对面抓边能力差（吕布边路、橘子打野）就避开大部队带线牵制，被抓用大招跑路绕后；对面有镜、露娜这种抓边强的就不要带线，改抱团找机会（BV1wz421o7Az @ 09:17、BV1wz421o7Az @ 09:23、BV1wz421o7Az @ 09:27）。
- **幽灵船/回马船**：先把 3000 码视野一次性暴露掉，绕一圈回来再撞，敌方视角里是"视野消失又突然出现在脸上"（BV1wz421o7Az @ 07:00、BV1CYrsYQEsL @ 06:25）。
- **蹭助攻白拿钱**：开船白圈经过队友即算参与战斗，十秒内队友击杀就有助攻，防御塔助攻也能蹭（BV13exk63Eie @ 02:06、BV1CYrsYQEsL @ 04:33、BV1CYrsYQEsL @ 04:49）。
- **带人开团要记得队友没霸体**：对面有控制该绕就绕，队友被打下去下一波就没人敢坐（BV1wz421o7Az @ 06:18、BV1wz421o7Az @ 06:27）。
