## 1. 机制内核

1. **红刀盘古的经济定位**：素材自称"毕竟是红刀盘古"，兵线要让给自己多吃（BV18ajzzQEQJ @ 02:41）。
2. **二技能是缴械**：命中后让对手一段时间内打不出普攻——素材里的用法是"顶他一手二技能缴械平A一下"（BV18ajzzQEQJ @ 01:19）。
3. **缴械会被解**：净化、李白二技能这类无法选中、各种霸体都能解除（BV13k4y1E72R @ 05:16）。
4. **只有"手捏住"的动画出现才算缴械生效**，技能放出去但人走了就没缴到（BV13k4y1E72R @ 05:28）。
5. **一技能落地有砸地动作（后摇）**，跳起来瞬间按普攻可以取消（BV13k4y1E72R @ 03:54）。
6. **一技能的强化普攻可以跟人**，跟踪距离上限是"半个屏幕"（BV13k4y1E72R @ 04:52）（BV13k4y1E72R @ 05:01）。
7. **一技能可以直接跳到对面红 Buff**：站在龙坑能看到对面红，跳过去撞红 Buff，前期胆子大就能反（BV13k4y1E72R @ 04:29）。
8. **一三连招有硬性前置**：必须在一技能那个圈的范围之内，且只能在跳跃的空中按大招再按普攻（BV13k4y1E72R @ 05:55）（BV13k4y1E72R @ 06:14）。
9. **续航靠二技能回血**："我们两口二技能就能吸回来"（BV18ajzzQEQJ @ 05:17）。
10. **大招霸体可躲控制**：素材用"大招霸体躲牛魔"（BV18ajzzQEQJ @ 07:57）；但也提醒"有些时候大招可以躲一下，但其实这里不建议躲"，因为后续可能还有团战（BV18ajzzQEQJ @ 12:26）。
11. **盘古克大司命**："盘古直接可以把大司命克麻掉的……他输出是打不出来的，抗伤只能有抗伤了"（BV1VWXeBJEjy @ 08:35）。

## 2. 对线 / 打法

- **开局有两条路**：一是"速四去对抗路打 2V2"，二是反野；素材本人"正常选择一个反野的打法，用强势的英雄"（BV18ajzzQEQJ @ 00:43）（BV18ajzzQEQJ @ 00:50）。
- **反野先看中辅**："反野主要就是看对面中辅的防反野意识，以及对面打野有没有提醒"（BV18ajzzQEQJ @ 00:53）。
- **用视野判断野区空不空**：牛魔漏了、红没动，就"红区基本就没有人了"；元歌也漏，就知道"对面典韦在打蓝"（BV18ajzzQEQJ @ 01:01）（BV18ajzzQEQJ @ 01:08）。
- **反完蓝别贪猪**："这个猪就反不了了，因为我们如果反的话会浪费太多时间"（BV18ajzzQEQJ @ 01:23）。
- **反野后提醒队友守红**：对面打野发现红掉了，"很有可能要过来跟我们换"（BV18ajzzQEQJ @ 01:27）。
- **反野路线要顺**：从对面红区走到自家蓝区再刷到红区"节奏是顺的"；反完对面红直接回自家红区再刷蓝"会绕路"（BV18ajzzQEQJ @ 01:54）（BV18ajzzQEQJ @ 02:08）。
- **队友被单杀就自己吃线**："不需要给司空震卡线留给他了……我们正常自己把经济多吃一点"（BV18ajzzQEQJ @ 02:34）。
- **第二波红区不进**（稳健打法）：对面没掉人、上路不是优势、中上都没抢线权，且"典韦第二波野区刷新时间比我们早"（BV18ajzzQEQJ @ 03:04）（BV18ajzzQEQJ @ 03:15）。
- **一定要给队友报点**："队友的意识不一定跟你在一个层面上"，不提醒他就会无脑跟对面打（BV18ajzzQEQJ @ 03:37）。
- **没状态就不去吃对抗路线**："因为孙顺（司空震）他没状态嘛，你如果去跟他去抢这波上线再传中的话，很有可能会被打状态"（BV18ajzzQEQJ @ 04:15）。
- **高分段的草都有人探**："这个分段大家确实也都有探草意识"，卡视野失败就让出小草（BV18ajzzQEQJ @ 04:26）。
- **红刀不要站最前面**："我们红刀一定不要站在最前面，我们一定是拉扯一下走位"（BV18ajzzQEQJ @ 10:05）。
- **打团靠一三顶阵型**："一技能大招直接把对面阵型顶烂，一技能再撤出来，这波就是相当于帮队友留人和拆火了"（BV18ajzzQEQJ @ 14:44）。
- **残局要跟对面 C 位换**："我的打法就一定是要跟他换的……你只要跟他这波换掉了，那我们就有机会推了"，因为对面会少一个守家的（BV18ajzzQEQJ @ 15:02）。

## 4. 中后期 / 节奏

- **有装备就能压一切**：中期装备与经济在手，"不管是谁都能打得过"，可以直接把对面挤出来（BV18ajzzQEQJ @ 08:29）。
- **没视野别乱吃线**：中路三个人时可以吃，没视野时"当然不能去乱吃"，而且要边吃边走位躲干将的剑（BV18ajzzQEQJ @ 08:45）。
- **拆塔节奏是"边边中"**："我们的节奏就是边边中边边中"，下路一塔破了就往上路一塔拱（BV18ajzzQEQJ @ 09:45）。
- **龙点一换二也是赚**：只要"典韦死了、对面少个元歌，我们四打三一定是能够拿到这个暴君的"（BV18ajzzQEQJ @ 10:22）（BV18ajzzQEQJ @ 10:27）。
- **红可以放，龙不能放**："这个红不反了……因为反这个红你要浪费时间"，漏太久对面打野复活还能来争暴君（BV18ajzzQEQJ @ 10:31）（BV18ajzzQEQJ @ 10:38）。
- **10 分钟主动让红**："主播 10 分钟了，已经决定让红了"，自家蓝区红区让给射手（BV18ajzzQEQJ @ 10:53）（BV18ajzzQEQJ @ 13:02）。
- **兵线别送太早**："你这个中兵线过早的动过去，就是给对面送钱"，队友还没集结好（BV18ajzzQEQJ @ 13:10）。
- **顺风不轻易放龙**："这个龙我不是特别想放，因为我们顺风嘛，直接去给掉也不太好"（BV18ajzzQEQJ @ 11:30）。
- **打龙同时卡位置**：卡住对面位置让队友把暴君收掉（BV18ajzzQEQJ @ 14:36）。
- **大司命局的输出面板**：43% 输出、30% 抗伤、22 个人头，"直接拉满了"（BV1VWXeBJEjy @ 08:42）。
- **经济是全场第一**：另一份回放给的口径是"13.0 评分、金牌 MVP、领先对面打野 5000 经济"（BV196QUYhEkR @ 00:07）。

## 5. 出装铭文

**铭文**：整体沿用上赛季，改动是"加了两个宿命"，血条更舒服、前期打架更好；但他自己说"实际上跟十个红月的差别并不是很大"（BV13k4y1E72R @ 00:15）（BV13k4y1E72R @ 00:24）。

**出装顺序**（BV13k4y1E72R @ 00:36）：

1. 带刀（打野刀）→ 先补小鞋子的攻速件，而不是直接出整鞋——因为前期不爆发战斗时"你出攻速，你刷野的效率会更高"（BV13k4y1E72R @ 00:36）（BV13k4y1E72R @ 00:45）。
2. 出鞋子 → 电刀（BV13k4y1E72R @ 00:51）（BV13k4y1E72R @ 00:55）。
3. **电刀之后先出守护者之铠**，这一步被他称为"出的就非常关键"：专门恶心司空震、司马懿、露娜这种吃攻速的英雄（BV13k4y1E72R @ 00:56）（BV13k4y1E72R @ 01:12）。
4. 再补黑切，"伤害其实不会差很多"，但前期打架更猛（BV13k4y1E72R @ 01:41）。
5. 黑切后出不祥征兆 → 再出血手（BV13k4y1E72R @ 01:48）。
6. **不祥不是每局都出**：对面不吃攻速（蓝、鲁班、蒙犽）时作用不大，可换成爆裂之甲（BV13k4y1E72R @ 02:41）（BV13k4y1E72R @ 03:06）。
7. **血手是条件装**：对面有吕布、貂蝉这类真伤就没必要出血手，可改寒霜侵袭补攻速，或魔抗斗篷、苍穹（BV13k4y1E72R @ 02:05）（BV13k4y1E72R @ 02:08）（BV13k4y1E72R @ 02:17）。

**散点**：素材另提到"准备做长盾"（BV18ajzzQEQJ @ 02:48），但没说明是哪件装备，已列入待补；实战里会"换一手布甲鞋"来对抗物理伤害（BV18ajzzQEQJ @ 06:50）。
