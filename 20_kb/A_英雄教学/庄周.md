# 庄周：一级能反野，中后期是移动泉水

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份高分段传送流实战（BV1kZ7L68E67）、一份永动机流出装教学（BV1vGnc62E7F）、一份国服第一庄周的铭文与打法讲解（BV1tW411s797）。

## 1. 机制内核

1. **被动每隔几秒免疫一次控制，可遁入虚空**：这是他能进能出的根，用来追击、逃跑、扛塔（BV1tW411s797 @ 01:26~01:36）（BV1tW411s797 @ 05:22~05:30）。
2. **大招是全队解控 + 护盾**：不是只给自己，"大招其实是有一个盾，有一个解控的"（BV1kZ7L68E67 @ 03:18~03:23）；对象是全队友（BV1tW411s797 @ 02:13~02:18）。
3. **一技能远程减速**：射程较远，可以先手减速留人（BV1tW411s797 @ 02:46~02:51）。
4. **二技能伤害可叠加、越打越疼**：中后期"二技能一旦你利用了，他伤害是非常爆炸的"（BV1tW411s797 @ 02:51~03:01）（BV1tW411s797 @ 04:38~04:44）。
5. **前期很肉**：反野时"对面射手根本射不死我，对面辅助还是没有伤害的"（BV1kZ7L68E67 @ 01:50~01:56）。

## 2. 对线 / 打法

- **一级直接反野**：鱼一级有反野能力，辅助反野出门买法术书，赌对面辅助不来看野区，先反红再借队友技能打下猪血线、连猪一起反（BV1kZ7L68E67 @ 00:59~01:56）。
- **反完就回城，靠传送回线**：红区吃完直接回家，再用 TP 传回线上，节奏不掉（BV1kZ7L68E67 @ 02:02~02:31）。
- **辅助不要动兵线**：除非看到射手也在打兵，否则不轻易碰线（BV1kZ7L68E67 @ 02:31~02:37）。
- **对面敢上来清线就打一套**：这波打掉张飞的治疗和后羿的闪现（BV1kZ7L68E67 @ 02:40~02:48）。
- **不要一直跟着射手**：要看射手在哪，"你看这里射手他都不在下路，那我们去下路干嘛呢"，站岗没意义（BV1kZ7L68E67 @ 03:46~03:59）。
- **游走路线：下路 → 上路 → 传送回下路**，把队友都照顾到（BV1kZ7L68E67 @ 04:14~04:28）。
- **蹲草时辅助不要和射手站一起**：装作两人同草，实际分开站，否则对面会远离草丛（BV1kZ7L68E67 @ 05:37~05:55）。
- **血量阈值**：一半以下考虑撤退，一半以上选择进攻（BV1tW411s797 @ 03:46~03:55）。
- **单吃线必须补刀**：辅助单吃线时也要注意补尾刀（BV1kZ7L68E67 @ 07:01~07:07）。

## 4. 中后期 / 节奏

- **传送的三个用法**：①支援怕控的边路，落地给解控（BV1kZ7L68E67 @ 01:05~01:14）；②残血回家再传回最前线（BV1kZ7L68E67 @ 08:13~08:26）；③传送到残血兵上卡兵，逼对面等你传送结束再补兵，节奏就慢了——"这游戏其实比的是速率差"（BV1kZ7L68E67 @ 08:26~09:02）。
- **为什么带传送**：治疗救不了被集火的队友，闪现又不是所有英雄都契合，鱼属于不契合闪现的那类（BV1kZ7L68E67 @ 07:26~07:51）。
- **大招留到对面辅助交大之后**：对面张飞当面吼大时鱼手里还捏着大，能直接化解（BV1kZ7L68E67 @ 09:30~09:46）。
- **残血不用回家**：出完圣杯、霸者后一秒回 200~300，吃满对面大招和十下普攻跑掉，等十秒状态就回来（BV1vGnc62E7F @ 00:44~01:01）（BV1vGnc62E7F @ 03:03~03:12）。
- **团战站位**：跟在后排身边，有危险开大解控掩护队友，让他们全力输出（BV1vGnc62E7F @ 03:30~03:36）。

## 5. 出装铭文

**铭文（两套，按容错取舍）**：

- 调和 + 心眼 + 梦魇：法穿法攻流，"庄周的输出从前期就贼高"（BV1vGnc62E7F @ 01:09~01:17）。
- 调和 + 虚空 + 宿命各十个：千血铭文，加血量与冷却缩减，容错更高（BV1vGnc62E7F @ 01:26~01:29）（BV1tW411s797 @ 01:10~01:26）。

**出装顺序（永动机流）**：

1. 出门宝石 + 鞋子 → **近卫荣耀**。不出极影的理由说得很具体：以前蓝耗高才需要极影回蓝，现在全英雄蓝耗下降，前期蓝够用，近卫的双抗与血量更能保人（BV1vGnc62E7F @ 01:30~01:58）。
2. **布甲鞋 + 星泉 + 圣杯**：圣杯是核心，血条蓝条一起回，等于自带霸者，被动冷却还补上不出极影缺的那部分（BV1vGnc62E7F @ 02:09~02:33）。出完圣杯三秒一个二技能。
3. **红莲或反甲二选一**：对面程咬金、蔡文姬这类回血英雄多就红莲；对面有马可、鲁班这种高爆发就反甲（BV1vGnc62E7F @ 02:43~02:52）。同时把星泉换成形昭补留人（BV1vGnc62E7F @ 02:52~02:55）。
4. **霸者**：进一步堆坦度和回血，一秒回 200 多，不死不用回家（BV1vGnc62E7F @ 03:03~03:12）。
5. **不死鸟**：双抗，并和前面的回复装联动（BV1vGnc62E7F @ 03:19~03:24）。

**召唤师技能**：传送（BV1kZ7L68E67 @ 00:15~00:35）；国服讲解里的常规打法是治疗（BV1tW411s797 @ 03:56~04:01）。
