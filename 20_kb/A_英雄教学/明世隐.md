# 明世隐：链子既能给队友加伤害，也能把对面双抗扒掉

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份国服小明的五点细节（BV1bi5i6sEBa）、一份新版机制七技巧（BV1nz421m7bd，阿泽）、一份金牌/评分思路实录（BV1jMe66fEmT，作者自称省级小明）、一份输出流出装与思路（BV1rmx46LEGA）。
> ⚠️ 四条素材口径差别很大，本卡按「谁讲的、什么版本」分开标注，不合并：①BV1nz421m7bd 是改版后的机制（一技能红链只能连队友、二技能黄链只能连敌人）；②BV1bi5i6sEBa 仍按「黄链/红链」表述，属旧颜色口径；③BV1jMe66fEmT 是纯评分/娱乐局上分思路，并自己说明小明强度不高、适合娱乐与低星双排；④BV1rmx46LEGA 的「输出流」与常规辅助装是两条路。另外四条素材的条数不算少，但没有一条给全铭文数值与逐英雄对位表。

## 1. 机制内核

1. **新版是两条链分工**：一技能红链只能连队友，二技能改成黄链只能连敌人，「所以现在的小明可以同时签两个目标」（BV1nz421m7bd @ 00:24、BV1nz421m7bd @ 00:27、BV1nz421m7bd @ 00:29）。旧口径里的「一个黄链加红链」是改版前的颜色对应（BV1bi5i6sEBa @ 00:38），两条素材按版本分开看。
2. **链子会衰减**：改版后一、二技能「无论是连着队友还是连着对手，他都会逐渐减少，最多衰减到80%」，有 CD 就要重新连（BV1rmx46LEGA @ 05:18、BV1rmx46LEGA @ 05:28）。新版又说技能升级不需要重连、链子会自动调节属性（BV1nz421m7bd @ 02:23、BV1nz421m7bd @ 02:27），这是两版机制的差异。
3. **黄链减双抗、红链加伤害**：因为黄线可以减双抗、红线可以加伤害，明世隐带队友抓边的效率比一般软辅高（BV1bi5i6sEBa @ 03:21、BV1bi5i6sEBa @ 03:26）。
4. **二技能自带破甲**：主二能强化破甲，射手还没出破晓、没有穿透装时，「他就有不错的针对前排的一个能力」（BV1rmx46LEGA @ 07:05、BV1rmx46LEGA @ 07:17、BV1rmx46LEGA @ 07:19）。
5. **被动是每五秒一次的强化普攻**：「每五秒就会给你一个强化普攻」，二技能黏住时再用，伤害更高；粘不中就「当个回血技能」（BV1rmx46LEGA @ 09:10、BV1rmx46LEGA @ 09:13、BV1rmx46LEGA @ 09:21）。
6. **平A能给链上的队友回血**：打敌方目标或野怪，「也会给你这个一技能所连的目标加血」，前提是一技能必须连着人（BV1rmx46LEGA @ 09:24、BV1rmx46LEGA @ 09:35）。新版补充：没链子只能给自己回血，打英雄 100%、打野怪 50%（BV1nz421m7bd @ 01:39、BV1nz421m7bd @ 01:46、BV1nz421m7bd @ 01:49）。
7. **延长索敌**：目标超出链子范围时技能依然自动追踪，但「身上不会产生链子，也不能对他造成伤害」；放完链子立刻向前走、刚好进入范围就能连上，「这样就可以把链子延长一个闪现的范围」（BV1nz421m7bd @ 00:38、BV1nz421m7bd @ 00:48、BV1nz421m7bd @ 00:56）。
8. **强化普攻也延长攻击距离**：强化普攻「能延长攻击范围，并且还能造成额外伤害以及回复自身血量」，和延长索敌组合就能远距离换血，「这一下换血就可以打对面1/4的血」（BV1nz421m7bd @ 01:05、BV1nz421m7bd @ 01:12、BV1nz421m7bd @ 01:21）。
9. **链子有左右差异**：敌人碰到链子就受伤，但「左侧的链子攻击范围更大」，放到右侧范围就变小，所以连住之后「尽量站在敌人的左边」（BV1nz421m7bd @ 02:33、BV1nz421m7bd @ 02:36、BV1nz421m7bd @ 02:49）。
10. **双链重叠与重置伤害**：新版移除了链子的双倍伤害，两根链子重叠可以恢复；并且「只要二技能再练一次，依然可以重置伤害，造成双倍伤害」，所以在确保命中的前提下可以频繁用二技能重置（BV1nz421m7bd @ 02:54、BV1nz421m7bd @ 03:01、BV1nz421m7bd @ 03:32、BV1nz421m7bd @ 03:37）。
11. **大招是瞬发出伤**：旧口径说大招「第一是没有前摇的，第二他是没有动画的」，是全游戏最快的出伤，所以能拿来抢野、抢龙（BV1bi5i6sEBa @ 02:20、BV1bi5i6sEBa @ 02:24、BV1bi5i6sEBa @ 02:29）。新版口径变成「如果练一个目标伤害会有延迟，但如果你练两个目标伤害就会变成瞬发」（BV1nz421m7bd @ 04:10、BV1nz421m7bd @ 04:14），两条并列看。
12. **大招的代价取决链谁**：二技能连敌人放大招，是扣自己的血绕一圈打到对面；一技能连队友，则从敌方吸一圈再还给队友（BV1rmx46LEGA @ 10:05、BV1rmx46LEGA @ 10:15）。「同时连到队友和对手」，则「不仅出伤快，还不用掉自己的血」（BV1rmx46LEGA @ 10:25、BV1rmx46LEGA @ 10:30）。
13. **断链也能开大**：按出大招之后「哪怕链子断掉，也能正常命中」，位置不好就可以主动切断链子远距离保 C 或收割（BV1nz421m7bd @ 03:47、BV1nz421m7bd @ 03:52、BV1nz421m7bd @ 03:59）。大招过程中目标死亡返还 70% CD，但「两条链子击杀目标不会减70%」（BV1nz421m7bd @ 04:05、BV1nz421m7bd @ 04:22）。
14. **链子可以探草、破隐**：链子实际技能宽度「很粗」，扔到草外也能命中；对兰陵王、阿轲「可以直接破除隐身效果」（BV1nz421m7bd @ 01:59、BV1nz421m7bd @ 02:09、BV1nz421m7bd @ 02:17）。

## 2. 对线 / 打法

- **前期开局是自由的**：边路强就跟边路（例如吕布线上能拿一血，躲草丛里再出来帮他拿一血）；也可以跟中路帮过线、顺便看对面打野什么开；还可以带中路抓边、去帮射手、或者直接跟打野（BV1rmx46LEGA @ 03:34、BV1rmx46LEGA @ 03:41、BV1rmx46LEGA @ 03:51、BV1rmx46LEGA @ 04:01）。
- **前期不指望自己带节奏**：「小明前期其实能给的那种主动节奏没有那么强」，主要目的是保证自己不死、跟着发育（BV1rmx46LEGA @ 04:30、BV1rmx46LEGA @ 04:37）。
- **跟射手是为了后期**：跟射手连体保证射手发育，「在后期我们才能打出更多的作用」；具体是给视野、加法强、帮回血、建立线上优势（BV1rmx46LEGA @ 04:45、BV1rmx46LEGA @ 04:50、BV1rmx46LEGA @ 05:00）。
- **评分逻辑（娱乐/上分口径，需与实战口径分开看）**：王者认为辅助「一定要有开团和助攻」，所以评分看参团，结论是「哪里有人头我们就去哪」（BV1jMe66fEmT @ 04:25、BV1jMe66fEmT @ 04:35、BV1jMe66fEmT @ 05:08）。跟着人头最多的人走，参团率上去牌子就有（BV1jMe66fEmT @ 02:36、BV1jMe66fEmT @ 05:20）。
- **和射手分开走**：「弹了以后，一定要和射手分开走」，让射手吸引火力，自己被切的风险就低（BV1jMe66fEmT @ 02:56、BV1jMe66fEmT @ 02:59）。对拼同理，「你不能贴在队友身上，不能让对面一个技能打你两个人」（BV1bi5i6sEBa @ 03:56、BV1bi5i6sEBa @ 03:59）。
- **主动抓边是他少数主动节奏**：中期低分段会有人自己带边线，看到孙策在下路就「直接连着兰陵王，然后对孙策一顿输出」（BV1bi5i6sEBa @ 02:49、BV1bi5i6sEBa @ 03:02、BV1bi5i6sEBa @ 03:04）。
- **越塔要主动扛塔**：明世隐移速快，可以「站在塔的边缘去扛伤害」，等队友击杀或自己快死再往回走（BV1bi5i6sEBa @ 01:08、BV1bi5i6sEBa @ 01:12、BV1bi5i6sEBa @ 01:17）。
- **别太主动**：「最好还是不要太主动，就是等队友先上我们再上」，「不要主动去给这个链子，尤其蹲草的时候」（BV1jMe66fEmT @ 09:54、BV1jMe66fEmT @ 10:02、BV1jMe66fEmT @ 10:03）。
- **对拼并不弱**：素材认为「小明打任何二打二或者三打三的团，都是不虚的」，觉得弱是走位问题（BV1bi5i6sEBa @ 03:45、BV1bi5i6sEBa @ 03:50）。
- **追残血与残血反杀**：追残血用黄链子烫 + 被动超远攻击距离抽状态（BV1bi5i6sEBa @ 04:09、BV1bi5i6sEBa @ 04:11）；反杀则是红链连队友、黄链连对面，用被动A对面，伤害和回血一起给（BV1bi5i6sEBa @ 04:26、BV1bi5i6sEBa @ 04:30）。
- **灵活换链**：「谁在打伤害就是跟谁」，孙策、火舞这类爆发英雄打伤害时把链子转过去，打完再转回打野和射手（BV1bi5i6sEBa @ 04:56、BV1bi5i6sEBa @ 05:06、BV1bi5i6sEBa @ 05:19）。
- **走位是主要操作**：操作难度不高，注意力全放在走位上，预判王昭君冰冻、钟馗钩；「对面王昭君放闪现，那我们就肯定知道他接下来就要冰冻我们」，直接向后走位（BV1bi5i6sEBa @ 05:28、BV1bi5i6sEBa @ 05:38、BV1bi5i6sEBa @ 05:55）。
- **抗伤不现实，所以才有输出流**：「他就站在那里，真的对面连鸟他都不鸟他，直接越过去了」，所以要出输出、增加威胁（BV1rmx46LEGA @ 03:09、BV1rmx46LEGA @ 03:15、BV1rmx46LEGA @ 03:23）。

## 4. 中后期 / 节奏

- **后期打团打不过就抓单**：素材给的具体判断是阵容后期不强，正面进攻时「敌方墨子会空一炮，然后如果高渐离直接跟上会打出成吨的伤害」；所以最优解「不是去打团，而是去带、去边路抓一个，然后再打」（BV1jMe66fEmT @ 17:13、BV1jMe66fEmT @ 17:20、BV1jMe66fEmT @ 17:35）。
- **对面有龙就不接**：「这一波敌方有龙就不要打」，错过龙的时间（BV1jMe66fEmT @ 15:53、BV1jMe66fEmT @ 15:56）。
- **拖着打更赚**：越往后小明自己 C 的能力越高，因为他本来就在加法强、给队友回血（BV1rmx46LEGA @ 10:32、BV1rmx46LEGA @ 10:39、BV1rmx46LEGA @ 10:42）。
- **双链齐连是收割窗口**：两个链子都连到时「瞬间就给他秒」，出伤速度很快（BV1rmx46LEGA @ 10:46、BV1rmx46LEGA @ 10:49）。
- **团战站位**：躲队友身后、站位猥琐（BV1jMe66fEmT @ 18:33、BV1jMe66fEmT @ 18:38）。
- **资源取舍**：「不要圣母心，你不要见谁都想救」，大招留给大腿（BV1nz421m7bd @ 04:27、BV1nz421m7bd @ 04:30、BV1nz421m7bd @ 04:32）。
- **抢龙思路**：靠大招的最快出伤去抢 Buff/龙，先看好斩杀线（BV1bi5i6sEBa @ 02:31、BV1bi5i6sEBa @ 02:35）。

## 5. 出装铭文

**出装（两条完全不同的路线，按素材分别记录）**

- **常规辅助向**：出一件团队回血装，做到「永远不用回家」，这样不会错过团战，参团率自然上去（BV1jMe66fEmT @ 06:23、BV1jMe66fEmT @ 06:27、BV1jMe66fEmT @ 06:30）。素材只说「大家就用第一套吧」，没有给装备名（BV1jMe66fEmT @ 11:15）。
- **输出流（BV1rmx46LEGA 的路线）**：学识宝石 → 近卫 → 秘法之鞋 → 形昭 → 痛苦面具（BV1rmx46LEGA @ 08:10、BV1rmx46LEGA @ 08:12、BV1rmx46LEGA @ 08:29、BV1rmx46LEGA @ 08:41）。理由是痛苦面具按敌方生命值打法伤、需要法穿，法穿鞋 + 二技能破甲让伤害「一直在打接近真伤的伤害」（BV1rmx46LEGA @ 07:37、BV1rmx46LEGA @ 07:51、BV1rmx46LEGA @ 07:55）。
- 输出流面板：1 万多生命、1400 法强、800 多物抗、400 多法抗（BV1rmx46LEGA @ 00:41、BV1rmx46LEGA @ 00:43）。素材另提到一件译名不清的装备（ASR 作「无情天山」），无法确认对应装备，不做结论，列入待补（BV1rmx46LEGA @ 00:35）。

**加点**

- 建议主二：「增强自己的这个输出能力和自己的坦度」，同时强化破甲（BV1rmx46LEGA @ 05:39、BV1rmx46LEGA @ 05:41、BV1rmx46LEGA @ 07:11）。

**铭文**

- 新版素材只说「推荐两套，第一套伤害高，第二套比较肉」，没有给具体铭文（BV1nz421m7bd @ 04:37、BV1nz421m7bd @ 04:39）。其余三条素材也未给铭文数值。

**关于强度（必须保留的原话）**

- 「小明的这个胜率他就是不高，他这个英雄的强度也不是很高」，适合娱乐局和队友双排、低星炸鱼（BV1rmx46LEGA @ 01:07、BV1rmx46LEGA @ 01:13、BV1rmx46LEGA @ 01:14）；单排高分段「队友菜的时候你会非常难受」（BV1rmx46LEGA @ 01:49）。
