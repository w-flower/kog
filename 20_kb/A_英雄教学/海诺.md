# 海诺：不靠单杀，靠抽血线把对面抽崩

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。

## 1. 机制内核：印记 + 高频一技能 + 大招回溯

1. **大招不只是保命**——可以大范围给敌人挂印记，挂上之后一技能才能"扔三枪四枪"，守高地尤其好用（@ 03:08~03:26）
2. **印记自动追踪隐身单位**——敌方头顶有印记时，没有视野也能命中，兰陵王、阿轲隐身也会被自动追踪（@ 03:59~04:05）
3. **二技能是闪烁不是位移**——闪现同款效果，可直接穿过张良一技能这类直线技能，还能无影步：本体出了草丛头顶小眼睛也不暴露视野（@ 04:07~04:23）
4. **大招回溯可以回防御塔**——守高地神技，但塔血低于 1/3 就不要回了，收益不高（@ 03:29~03:37）
5. **一技能命中挂印记的目标减 2 秒 CD**——所以尽量多标目标，多挂一个就多减一点（BV1LK4y1z7X9 @ 06:05~06:17）
6. **CD 是这个英雄的命根**——"我一般玩的话最低 37CD"，再低就打不出频率（@ 12:51~12:55）
7. **远近形态切换**——切近战用一技能减速回血慢慢缠斗，敌方想跑就切远程收割（BV1U3HW6BEsd @ 16:31~16:43）

## 2. 对线

- 十献祭铭文对线最强，配前期出装能"压着杨玉环和孙膑打"（BV1LK4y1z7X9 @ 01:52~01:59、02:54~02:56）
- 被打一套时的换血反制：兵线上已经挂印记就切近战放一，"这样的话他换也换不过"（@ 02:32~02:40）
- **抢河蟹公式**：先给对面法师标一枪，再 A 一下河蟹叠第二个标记，标记一炸就能秒河蟹（@ 17:07~17:18）
- 3 分 30 秒左右放波线下路打压制，"把自己当做一个周瑜来打，打推塔压制"（@ 03:27~03:34）
- 开局反野猪：清完线看一眼对面是否红开，给队友信号，不是红开就把小猪反掉（BV1U3HW6BEsd @ 05:01~05:11）

## 3. 连招

| 场景 | 操作 | 为什么 |
|---|---|---|
| 抢线 | 精准普攻锁后排兵，让自家兵打前排兵 | 两个一技能清完中线还不漏尾刀（BV1U3HW6BEsd @ 03:38~03:47） |
| 半途支援 | **先把二技能落点藏在安全位置再打** | 被集火可以大招回落点跑路；没打过就大招跑路等下一波（@ 07:05~07:10、07:47~07:50） |
| 被集火 | 大招跑路 → 落地时对方头顶已挂满印记 → 开狂暴接着抽（@ 08:52~08:58、BV1LK4y1z7X9 @ 19:04~19:07） | 大招回溯顺带把敌方关键技能骗得差不多（@ 18:48~18:51） |
| 团战开团 | 别二闪硬上——实战里"二闪上去然后被秒了"（BV1LK4y1z7X9 @ 09:21~09:24） | 海诺不是进场英雄，靠一技能距离抽血 |

## 4. 中后期/节奏

- **中轴循环**：清中线 → 吃安全野怪/反野 → 用一技能抽敌方血线 → 回来吃线，无限循环（BV1U3HW6BEsd @ 09:07~09:10）
- 压血线的两个价值：一是让对面没办法接团，二是给队友创造越塔空间（@ 08:00~08:06）
- **海诺推塔速度慢，让队友推，自己压血线就好**（@ 11:27~11:31）
- 没大招的时候不能压太深，边撤边打，等大招冷却或队友下一波机会（@ 12:20~12:27）
- **边路传送流刷钱循环**（BV1PECJYyEcu）：传送 75 秒 CD，配合传送阵使用只要 45 秒（@ 01:09~01:47）；传送途中取消也能吃到钱（@ 03:27~03:36）；过完下线传中路、传完中路吃上路（@ 05:10~05:14）；红蓝双 Buff 加冰杖减速后"扎到就是大残"（@ 09:22~09:30、10:44~10:47）
