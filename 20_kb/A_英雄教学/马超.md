# 马超：低分段不跟你对线，清完中线再转边

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。

> ⚠️ 只有单份低分段视角，高分段打法被明确否定；出装铭文、连招细节、团战定位全缺，故标 draft。

## 1. 机制内核

1. **枪可以存、可以捡**：素材以"21 秒存枪，27 秒捡枪，枪已经存在兵线旁边"记录开局枪位（BV1EpGq6KEMx @ 00:14、BV1EpGq6KEMx @ 00:15；原文主语写作"项羽"，此处不改写）
2. **枪能把兵往回拉**："第一枪戳，第二枪往回拉，把这个近战兵拉到我们身上"（BV1EpGq6KEMx @ 00:20、BV1EpGq6KEMx @ 00:21）
3. **一技能贯穿可改方向**：防卡线时"一技能贯穿往旁边打"（BV1EpGq6KEMx @ 01:02）
4. **抢线的胜负点是二级**："抢线比的就是谁先到二级"（BV1EpGq6KEMx @ 00:28）
5. **机动性是保命底牌**：明知对面打野在对抗路还硬对线，"要不是靠着我们马超的一个高机动性"，这一波就是白给（BV1EpGq6KEMx @ 03:00）

## 2. 对线 / 打法

- **站位**：不要跟兵线站一起，"容易被项羽推"（BV1EpGq6KEMx @ 00:18）
- **补三个兵**：一枪戳、一枪往回拉，把近战兵拉到身上，"同时出三个兵"；不然近战兵抢不到，就升不了二级（BV1EpGq6KEMx @ 00:21、BV1EpGq6KEMx @ 00:23、BV1EpGq6KEMx @ 00:26）
- **两套 CD 找单杀**：先到二级 → 先打对面一套 CD → 等第二套 CD 再打一套，"就可以有单杀的一个机会"（BV1EpGq6KEMx @ 00:30、BV1EpGq6KEMx @ 00:31、BV1EpGq6KEMx @ 00:33）
- **线权换支援**：抢完线对面只能后手清线，就先做事、先打中立资源（BV1EpGq6KEMx @ 00:37、BV1EpGq6KEMx @ 00:40）
- **防卡线**：一技能贯穿往旁边打（BV1EpGq6KEMx @ 01:02）；原理是对面小兵打不过自家小兵，兵线一直往对面推，清兵点会离自家塔越来越远，被抓就更危险（BV1EpGq6KEMx @ 01:05、BV1EpGq6KEMx @ 01:09、BV1EpGq6KEMx @ 01:11）
- **一分钟那波线**：不知道对面打野什么开，就默认他往我们这里开，"一分钟的那一波线我们就不能清"（BV1EpGq6KEMx @ 01:23、BV1EpGq6KEMx @ 01:25）
- **卡线窗口**：1 分 36 秒到 2 分 15 秒最惨，对面打野首开 Buff 要到 2 分 15 秒才刷新，刷新前他可以不回去、一直卡你的线（BV1EpGq6KEMx @ 01:31、BV1EpGq6KEMx @ 01:37、BV1EpGq6KEMx @ 01:39）
- **镜像原则**：双方都红开，出野区时间接近，对面打野大概率就在对抗路（BV1EpGq6KEMx @ 02:27、BV1EpGq6KEMx @ 02:32、BV1EpGq6KEMx @ 02:36、BV1EpGq6KEMx @ 02:46）
- **打项羽**：素材原话"基本上是拿他没有一点办法的"（BV1EpGq6KEMx @ 04:53）

## 3. 连招

素材未覆盖连招细节。

只给到一个操作片段："第一枪戳，第二枪往回拉"用来拉近战兵（BV1EpGq6KEMx @ 00:20），完整连招、枪的层数与戳枪节奏都没讲。

## 4. 中后期 / 节奏

- **中期只做一件事**：带线打人数差（BV1EpGq6KEMx @ 05:49、BV1EpGq6KEMx @ 06:53）
- **利用刷钱心理**：低分段对面"真的会去清线"，就吃他们"吃线刷钱"的心理找机会（BV1EpGq6KEMx @ 05:51、BV1EpGq6KEMx @ 06:02、BV1EpGq6KEMx @ 06:05）
- **10 分钟龙点**：队友开主宰时，"一定要带上路这个远端线"，因为对面大概率偷龙（BV1EpGq6KEMx @ 06:59、BV1EpGq6KEMx @ 07:01）
- **反向利用教学**：对面就算不偷龙，也会按"逆风多带线"的思路来，正好在边路提前反蹲（BV1EpGq6KEMx @ 07:07、BV1EpGq6KEMx @ 07:19）
- **龙位处理**：龙不该放中路；原话"我们可以龙放下路"，人往中上给压力，等对面中上人多再转下路打声东击西（BV1EpGq6KEMx @ 07:34、BV1EpGq6KEMx @ 07:37、BV1EpGq6KEMx @ 07:42）
- **上高地**：本质是让对面同时清线又要打人，被兵线消耗技能（BV1EpGq6KEMx @ 07:46、BV1EpGq6KEMx @ 07:53）；"一定不要跟兵线站在一起"（BV1EpGq6KEMx @ 07:57）
- **抓机会**：这个分段对面意识不强，"一抓一个准"（BV1EpGq6KEMx @ 05:21）
