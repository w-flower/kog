# 空空儿：六段位移加偷装备，靠机动性把对面野区搅烂

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份 14 分钟全局实战讲解（BV1RpWEzXEnw）、一份带出装与自我复盘的实录（BV1BCsU6eEAG）、一份全局思路教学（BV1sokYBrEBW）、一份技能机制 + 打法思路拆解（BV1S9ZGYqEEG）、一份进阶连招与分身机制（BV1EVH16mEWc）。
> ⚠️ 五条素材口语化严重、ASR 错字多（"空空玩/坤坤/空耳/空亏"都是同一个英雄），且都是实战解说、没有系统数值表；两条素材对"红莲斗篷能否被分身继承"结论相反（BV1S9ZGYqEEG @ 06:30 说两个傀儡和本体都能烫，BV1EVH16mEWc @ 00:42 明确"红莲斗篷不能继承"），本卡并列标注未合并。

## 0. 大局观定位

| 项 | 内容 |
|---|---|
| **强势期** | 强度跟队友绑定："只要你的队友强，那你就全时期强势无敌"，队友菜就无力；"在没有大招的时候，确实是比较弱势的"（BV1S9ZGYqEEG @ 04:09、@ 04:21） |
| **节奏职责** | **游走/入侵**。六段位移、高机动性，主要价值是抢中、探视野、进对面野区，"本身自带的六段位移，极易在野区七进七出"（BV1S9ZGYqEEG @ 00:25、@ 04:50） |
| **一句话** | 只要队友强，全时期强势无敌（BV1S9ZGYqEEG @ 04:11） |
| **依据** | 机制是"强普偷装备 + 一二技能换位免伤 + 分身骗视野"三件套（BV1S9ZGYqEEG @ 01:13、BV1EVH16mEWc @ 01:03）；偷装备"逮着个打野耗，收益才是最大的"（BV1S9ZGYqEEG @ 04:53） |

## 1. 机制内核

1. **被动 = 移动蓄能 + 偷装备**：一边走一边蓄能量，大概每六秒松开方向轮盘获得一个位移加一次强化普攻（BV1S9ZGYqEEG @ 01:13）。
2. **强化普攻随机偷装备**：随机从敌方英雄身上偷，还能把偷来的装备给队友用，同时造成一点伤害和减速（BV1S9ZGYqEEG @ 01:20）；"偷装备是随机抽的，而不是指定"，别想着偷最贵的（@ 01:51）。
3. **偷来的装备按时长衰减**：价值越高用得越短——最便宜的回蓝项链能用很久，2000 块左右的装备"基本上就只能用几秒"（BV1S9ZGYqEEG @ 01:57）。
4. **一个人最多被偷两件**：先放一或二技能，再用被动位移上去强化普攻，可以一次偷两个；但第二件的持续时间会少很多（BV1S9ZGYqEEG @ 02:18）。重复偷不会刷新已有装备的持续时间（@ 02:12）。
5. **一技能**：丢出傀儡，傀儡会模仿本体行为，造成本体 25% 的伤害，并给自己提供换位、免伤、回血（BV1S9ZGYqEEG @ 01:27）。
6. **二技能**：同样丢傀儡，但自身向前位移，也可以换位回来，免伤回血伤害与一技能一致（BV1S9ZGYqEEG @ 01:33）；一二技能的免伤会相加，不会出现"只有一只傀儡提供免伤"（@ 02:06）。
7. **大招 = 击退 + 旋转拉扯**：开大瞬间击退一下敌人，随后本体与分身一起旋转造成伤害，并把敌人往内圈拉扯（BV1S9ZGYqEEG @ 01:39、BV1EVH16mEWc @ 01:39）。释放期间被动快速蓄能，"一个大招期间能蓄满两个被动"（@ 01:50）。
8. **大招期间必须换位**：可以用一二技能和分身换位，每次换位都会额外造成一次伤害，"想要打满大招伤害，就要在大招期间快速换位"（BV1EVH16mEWc @ 02:16）。怕换错就把大招拖到想换的那个分身上（BV1S9ZGYqEEG @ 01:45）。
9. **分身继承规则**：能继承部分装备与 Buff（电刀等攻击效果、红蓝 Buff），不能继承龙王 Buff（BV1EVH16mEWc @ 00:28、@ 00:45）；无攻击目标时跟随本体，遇分叉路走最近一条（@ 01:03）。
10. **分身可以骗视野**：把分身放到河道草、下路草的位置，"让对面误以为是我们本体走下来了"（BV1EVH16mEWc @ 01:26）。

## 2. 对线 / 打法

- **开局先套公式**：按"一野二边三射四中"的顺序思考（BV1RpWEzXEnw @ 00:38）；也可以常规中开去读对面打野和辅助的位置（BV1EVH16mEWc @ 04:08）。
- **开局就去偷打野刀**：空空儿"本身没什么伤害，只能扛伤害和偷装备"，所以边开抢中、跟射手连体都没什么用；"唯一有用的点就是去偷对面打野的打野刀，降低他的刷野速度"（BV1S9ZGYqEEG @ 02:33）。26 秒入侵野区，二技能位移 + 被动跳 + 强化普攻（@ 02:49）。
- **明确对线短板**：没有抢线能力（BV1BCsU6eEAG @ 01:55），前期伤害太低（@ 01:34），对线强度不高；跟射手连体"就像赌博一样，只要你射手不会玩，那就 game over 了"（BV1S9ZGYqEEG @ 05:07）。
- **主战场是中野**：更适合用强势阵容打入侵野区的节奏，围绕中单和打野打，用前中期强势压制对面弱势（BV1S9ZGYqEEG @ 04:37、@ 05:29）。
- **中路视野优先**：把对面法师压出中左视野，方便抢线（BV1RpWEzXEnw @ 03:43）；"中路线权是大于发育路线权的"，因为暴君在上路、发育路可以后清线再绕过来（@ 05:10）。
- **看小地图的纪律**：没在打架时主视线盯小地图、余光看主视角（BV1sokYBrEBW @ 01:55）；"看到老虎红心的动向，我们也往中走"（@ 05:42）。
- **记中立刷新**：赤甲大概 2 分 10 秒到 20 秒刷新（BV1RpWEzXEnw @ 03:28）；优先帮射手打掉中立资源，不给对面打野过来打的机会（@ 03:03）。
- **假视野**：当着对面的面给一个向上的假视野，等对面视野消失再果断转下（BV1RpWEzXEnw @ 03:55）。
- **阵容门槛**：最好自家有前排再玩，否则阵容很容易被冲烂（BV1BCsU6eEAG @ 01:01）；队友是弱势英雄时"千万别玩空空儿"，因为开局就是逆风（BV1S9ZGYqEEG @ 06:02）。

## 3. 连招

| 场景 | 连招 | 要点 | 依据 |
|---|---|---|---|
| 开局偷刀 | **二技能位移 → 被动跳 → 强化普攻** | 26 秒进野区，直接偷打野刀 | BV1S9ZGYqEEG @ 02:49 |
| 通用开团 | **超级位移 → 强普 → 眩晕 → 大 → 换位** | 强普必须打出去再接大，"不要直接接大招去浪费被动的偷" | BV1RpWEzXEnw @ 04:31、@ 08:29 |
| 打满大招伤害 | **大招期间快速换位** | 每次换位额外造成一次伤害 | BV1EVH16mEWc @ 02:16 |
| 321 斩 | **3 → 2 → 1 → 斩杀** | 素材原文写作"3200连招321斩"，斩完再被动瞬移离场 | BV1EVH16mEWc @ 02:32 |
| 121 起手 | **1 → 2 → 1 强化平A → 321 斩** | 素材给的慢速演示版 | BV1EVH16mEWc @ 02:49 |
| 超级跳 | 连招前置位移 | 用于超远距离开团和收割 | BV1EVH16mEWc @ 02:39 |
| 被老夫子捆 | **先交被动和技能 → 再开大 → 捆绑结束换位** | 直接开大被动会加速、技能全进 CD，反而换不走 | BV1RpWEzXEnw @ 10:36 |

- 换位的准确性：记不住"一右二左"就按住大招拖到想换的分身上（BV1EVH16mEWc @ 02:07）；实战里也可以二闪或"一技能反向闪"接近后排（BV1RpWEzXEnw @ 11:22）。
- 近期改动的技巧点："一定要把强普A出去，然后大招取消，抬手时间是差不了零点几秒的"（BV1RpWEzXEnw @ 08:29）。

## 4. 中后期 / 节奏

- **顺风先做视野不开团**：10 分钟龙点，"这个时间段就不要去开团，万一没打过翻盘"，做好视野等暴君刷新（BV1RpWEzXEnw @ 11:03）。
- **顺风滚雪球靠视野**：发挥机动性和视野优势，记对面野区刷新时间，集合队友进野区（BV1RpWEzXEnw @ 07:12）；"有星泉的空空儿滚雪球的能力是很强的"（@ 07:20）。
- **后期脆，先拉扯**："到了后期的团战里面，我们空空儿比较脆，如果不是绝对能收割的话，就要打拉扯"（BV1BCsU6eEAG @ 10:19）。
- **后期能带线**：伤害起来后可以帮忙带线、分担兵线压力，对面不多来几个人抓不住（BV1BCsU6eEAG @ 11:28）。
- **粘人靠红 Buff + 冰矛**："有红有冰矛的情况下，粘人能力是非常恐怖的"（BV1BCsU6eEAG @ 11:48）。
- **不切锁头位**："空空儿不太适合打这种锁头的切，远射孙尚香这种更好切一点"（BV1BCsU6eEAG @ 15:20）。
- **别越高地**：顺风推完二塔就收，"不能推对面的高地塔"，因为有人数差的风险（BV1RpWEzXEnw @ 09:08）。
- **后期鞋子处理**：六神后把鞋子换成复活甲增加容错（BV1BCsU6eEAG @ 15:49）；也有素材选择补冰矛加强粘人（BV1sokYBrEBW @ 16:03）。

## 5. 出装铭文

**路线 A：功能/坦度向（BV1S9ZGYqEEG @ 06:13）**

- 铭文：十宿命、十虚空、十调和（生命 + 防御 + 减 CD + 自然回复）。
- 核心装是红莲斗篷，且"红莲是必出的，千万别给他换了"——理由是清兵线太慢，有了红莲"两个傀儡和本体就可以同时烫人"（@ 06:24）。
- 召唤师技能：新手推荐治疗和弱化，"这英雄基本上什么技能都能带的"（@ 06:40）。

**路线 B：百穿伤害向（BV1BCsU6eEAG @ 00:40）**

- 铭文：五隐秘、五长生、十鹰眼、十异变，百穿；"这套铭文无论是前期还是后期伤害都挺高的"，缺点是太脆、容易被秒（@ 00:51）。
- 对面法伤多就把黑切换成破魔刀（@ 01:33）。

**路线 C：冷却/粘人向（BV1EVH16mEWc @ 03:07）**

- 星泉、冷却鞋、冰痕之握、末世一线，配"有奶有生命、有冷却、有伤害，减速还拉满"；最后一件看情况，队伍缺控就冰甲、对面回血多就制裁；鞋子做完、己方坦度足够时做破晓（@ 03:19）。
- 铭文：八宿命、二红月、十长生、十鹰眼（@ 03:33）。
- 召唤师技能：带终结补伤害还能切 C（@ 03:42）。

**散点与替换**

- 辅助装选择：残血状态买星泉直接用；满血就买形昭空放（BV1RpWEzXEnw @ 06:30）。另一份素材的操作是"先买形昭、没人的时候空放一下，再买星泉减小 CD"（BV1EVH16mEWc @ 08:41）。

- 需要补魔抗时补一件魔抗装（BV1sokYBrEBW @ 11:16）。
