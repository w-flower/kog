# 亚瑟：手短不是缺点，是逼你到处游走的理由

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：五份不同视角的实录/教学——BV1EyiqYNEpu 是 150 星游走亚瑟全局（辅助视角，主素材）、BV1ku4y1w7sP 是打野亚瑟对线澜的逆风局（打野视角）、BV11YgA6CETA 是对线廉颇的对抗路实录（对抗路视角）、BV1q64y1r7no 是 2200 分巅峰赛对抗路运营局（对抗路视角）、BV1YY411e7j5 是出装铭文与连招的技巧课（三位置通用）。
> ⚠️ 五份素材视角不同（游走 / 打野 / 对抗路 / 技巧课），同一结论在不同分路下不完全通用，正文逐条标明视角；铭文与装备的版本数值以素材原话为准，未做版本核对。

## 1. 机制内核

1. **一技能是灵魂技能，也是主加技能**：加 30% 移速、持续 3 秒，并把下一次普攻变为物理加成的额外伤害（BV1YY411e7j5 @ 00:58）；「这个是灵魂技能，也是亚瑟主加的技能」（BV1YY411e7j5 @ 01:13）。对抗路视角同样明确「亚瑟这英雄要主 E 的啊，不要主二，主二没用，主一厉害」（BV11YgA6CETA @ 00:40）。
2. **一技能带标记：目标最大生命 1% 的法术伤害，二技能与大招都能触发**（BV1YY411e7j5 @ 02:08）；「所以不要小看这个一技能，还附带 1% 的法术伤害」（BV1YY411e7j5 @ 02:26）。这是全肉亚瑟输出也不低的根（BV1YY411e7j5 @ 05:34）。
3. **一技能沉默才是他打得死人的原因**：克制用技能位移的英雄，「因为一技能有沉默，这个沉默的价值实在太大了」（BV1YY411e7j5 @ 07:57）；反过来「一技能一旦空掉的话，就会被对面吊起来抽」（BV1YY411e7j5 @ 08:28）。
4. **CD 拉满后一技能 3 秒一个，可以打二连沉默**：一技能 5 秒 CD，40% 冷却后变 3 秒，持续也是 3 秒，于是能连着拍两下（BV1YY411e7j5 @ 08:49）；「是亚瑟最实用的最基础的技巧」（BV1YY411e7j5 @ 09:21）。
5. **二技能是持续旋转，本身没有控制**：满级 5.4 秒、持续 5 秒，配合冷却鞋被动实测基本能无缝衔接（BV1YY411e7j5 @ 10:00、10:43）；但「他并没有控制」（BV1YY411e7j5 @ 01:43），脱离一技能加速后很容易被拉开（BV1YY411e7j5 @ 01:35）。
6. **大招是已损生命值的法术伤害，会被魔抗减免**：「亚瑟的大招的伤害是对方已损生命值的伤害，敌方血量越少，你大招伤害越高」（BV11YgA6CETA @ 10:13）；而「20% 伤害是会被那个魔抗减免的，你看上去 20%，实际上减掉之后可能就 15% 到 10%」（BV1YY411e7j5 @ 47:29）。
7. **没有位移，追人只能靠沉默与大招**：「我们亚瑟没有位移技能啊，只能通过沉默或者大招来追人」（BV1EyiqYNEpu @ 10:12）；补充口径是一技能本身带一小段位移（BV11YgA6CETA @ 04:12）。

## 2. 对线 / 打法

**游走视角（BV1EyiqYNEpu，150 星局）**

- 开局二选一：对抗路开或中线开；对方对抗路不带闪现就对抗路开（@ 00:16、00:21）。本局花木兰带闪现，所以选中开（@ 00:27）。
- 中开是为帮中路拿线权，因为打野老虎有入侵野区意图，怕他入侵时出事（@ 00:30）。
- 打野若改主意自家开，就跟着他刷；他要入侵就跟入侵，「他往哪边走我们就往哪边走」（@ 00:45）。
- 出学识宝石不影响打野发育，还能提高出野区速度（@ 00:59）。
- 不跟发育路的两条理由：只能吃一条线；手太短会被射手白嫖血量（@ 01:12）。中开/对抗路开/野区开就是用来过渡前期手短期的（@ 01:23）。
- 野区刷完再转发育路，因为「发育路的小兵呢是最值钱的」（@ 01:35）。
- 前几分钟是观察期，找出四个队友里最会玩的再重点跟（@ 02:26、@ 02:37）。
- 游走的收益是逼对面犯错：对面看到只有一个射手就越塔或压线，带队友一包就能收（@ 03:22）。
- 游走不是乱走，原则和打野一样——哪里经济多去哪里（@ 03:48）。
- 队友不爱带线、地图上到处是没人要的兵时，顺手带一两波，但先看地图别被抓，「不要死带」（@ 05:43、05:55）。

**对抗路视角（BV11YgA6CETA / BV1q64y1r7no）**

- 对线廉颇（千血铭文）：不要想杀他，只做消耗和抢线，然后去支援（BV1q64y1r7no @ 00:49）。
- 判断廉颇铭文先看属性面板血量：4400 血是千血铭文，3500 血是调和百穿（BV1q64y1r7no @ 00:34）。
- 亚瑟有续航、廉颇没有，所以只跟他打消耗（BV1q64y1r7no @ 01:36）。
- 千血廉颇完全打不动，凭血量和英雄优势还能反打（BV1q64y1r7no @ 01:23）；调和百穿的廉颇较脆，四级前比较好打，靠拉扯拿他兵（BV1q64y1r7no @ 02:06、02:19）。
- 四级前唯一任务就是升到四级，他打得疼就走，不跟他玩（BV11YgA6CETA @ 00:22、00:33）。
- 清完线立刻往中路靠，「一定要记住往中路打，不要往别的路打，往上路打太远了」（BV11YgA6CETA @ 01:44）。
- 对线期的核心不是操作而是把线过好，不让对面推塔；过线的空档再出去给沉默、给击飞（BV11YgA6CETA @ 02:29）。
- 一个兵的收益要算账：一个兵 40 块，但为它可能送掉 200 块的人头（BV1q64y1r7no @ 01:59）。
- 打河蟹要看兵线：下路兵线快到时去打河蟹会亏一两个兵，且老虎没视野可能被惩戒抢（BV1q64y1r7no @ 03:42）。
- 卡视野进草配合队友是最有效的支援方式：进草后一秒出现两人，一套技能配合云中君收掉老虎（BV1q64y1r7no @ 04:05）。

**打野视角（BV1ku4y1w7sP，对线澜的逆风局）**

- 速刷三野：先 A 蓝 Buff，再 A 两下小蜥蜴，拉在一起时同时开二技能（@ 00:19）。
- 清完一片野区直接去中路吃线，吃完正好买二级打野刀，再刷红区拿额外经验经济（@ 00:47）；前提是中单一个人在线，否则会影响中路发育（@ 01:09）。
- 前 4 分钟以发育为主；抓不到就继续刷，不要硬抓（@ 01:23、@ 02:58）。
- 残血是打野最致命的破绽：为掩护队友掉半管血，对面打野就会入侵（@ 03:17）。
- 逆风时不要再守野区那一亩三分地，能吃到就吃，吃不到就转去吃兵线（@ 05:20）。
- 逆风不主动找架打，经济落后时「你去抓别人就等于是送死」，要等对面犯错（@ 06:59、@ 07:07）。
- 全场经济第一优先：队友要打架由他们去，看到没人带的线就去带（@ 06:36）。

## 4. 中后期 / 节奏

- **10 分钟的暴君/主宰是唯一硬节点**：无论玩什么位置，10 分钟都要来拿主宰或暴君（BV1EyiqYNEpu @ 08:59），「因为这个东西才是真正决定游戏胜负的东西」（@ 09:05）；除非水晶正在被推，否则放下手里的事去拿（@ 09:14）。
- **辅助要主动占龙坑视野**：对面打野久不漏视野就先去看有没有偷龙，没偷就把视野占住，「这也是辅助的功能，就是有时候我们要帮队友占一下视野，当个路灯嘛」（BV1EyiqYNEpu @ 09:21、09:33）。
- **游走装移速是绕后的资本**：巨大优势局里「想绕后就绕后，想抓单我们就抓单」（BV1EyiqYNEpu @ 08:41）。
- **结束对线的时机在 7~8 分钟**：「跟鲁班 7、8 分钟，这种时间点差不多中期抱团了」（BV11YgA6CETA @ 04:40）；此后职责转成保最会玩的那个 C 位（@ 03:53）。
- **带线再参团，不要空手参团**：「一定要带完线再去参团，不然你打一波团，你中路又没线，你能干嘛，你又回家发呆」（BV1q64y1r7no @ 10:00）；兵线压过去对面就只能守（@ 11:10）。
- **兵线要双线压，不要五个人挤一条中路**：一条兵线上不去，双兵线（超级兵）才推得动（BV1q64y1r7no @ 11:22）；拿双龙再上，安全（@ 11:46）。
- **打团不要先手**：「亚瑟打团的技巧就是不要打先手，尽可能打后手，你是一个刺客，等对面放完技能上去沉默人家关键的 C 位」（BV1ku4y1w7sP @ 11:57）。
- **大优势也要先拿龙再上高**：带线上去万一被团灭，龙就归对面；先收主宰再团，即使团灭龙权也在自己这边（BV1ku4y1w7sP @ 11:14）。

## 5. 出装铭文

**铭文（BV1YY411e7j5，技巧课，三位置通用）**

- 主流一套：攻速百穿 96 穿 + 一个祸源 + 狩猎，「不管是上单还是打野，都是用这一套，性价比是对亚瑟最高的」（@ 02:38）。
- 纯肉一套：宿命 + 虚空 + 调和，很多坦克通用；亚瑟建议把调和换成狩猎，因为他非常吃移速（@ 03:03、@ 03:20）。
- 只有这两套可用，隐匿百穿没有攻速，不推荐（@ 03:51）。

**召唤师技能**

- 主流只有惩戒与终结；眩晕不推荐；闪现是用来针对马可、韩信、百里守约（BV1YY411e7j5 @ 04:00、@ 04:11）。
- 打野必惩戒；上单带惩戒是为了抢龙和抢河蟹（@ 04:40）。
- 对抗路/辅助带终结的理由是配合大招斩杀，且完美克制夏侯、张飞这类低血高盾英雄，打吕布也建议带终结（@ 06:34、@ 06:51）。
- 辅助位一定带终结，「你带的惩戒是没有用的」（@ 33:52）。

**游走装（BV1EyiqYNEpu + BV1YY411e7j5）**

- 出门学识宝石，不影响打野发育（BV1EyiqYNEpu @ 00:59）。
- 辅助起手两件：小宝石 + 疾步靴，移速 565，开一技能 642（BV1YY411e7j5 @ 26:48、@ 27:01）。
- 先做风灵文章（奔狼）而不是凤鸣指环，开主动可以拉到 800 移速，草丛窜出到脸上不到一秒（@ 28:04、@ 28:32）。
- 凤鸣指环 1000 块，能加队友攻击、冷却和攻速，可以优先于冰痕（@ 29:14）。
- 之后按阵容补冰痕（兵手，提供减速，增强 gank）、极寒风暴或魔女斗篷；极寒 30% CD 配极影升满 40%（@ 29:45、@ 30:11）。
- 辅助成型六件：极速鞋 + 极影 + 奔狼 + 冰痕 + 冰心 + 魔女（@ 31:21）。
- 救赎之翼不推荐（不加移速、盾脆），星泉也不推荐，奔狼性价比最高（@ 30:50）。

**对抗路装（BV1YY411e7j5）**

- 出门小刀，摸河蟹收线后去摸对面打野的鸟，第二波线后开始陪队友打架（@ 22:47）。
- 抵抗鞋 → 肉刀（迅猛利刃）→ 黑切 → 冰心，两件合计 35% CD，「35 CD 基本上是够用的了」（@ 22:06、@ 22:17）。
- 肉刀的收益：小鸟 + 河道之灵叠三层 150 血，附带 2% 最大生命法术伤害，750 块打出大烧甲效果（@ 24:24、@ 25:14）。
- 压力大就先做守护者之铠/冰心，再陨星（10% CD）→ 冰甲（30% CD）→ 补黑切；实在扛不住先魔女（@ 25:16）。
- 后期补血魔之怒 + 魔女斗篷，物防法抗兼顾（@ 22:31）。

**打野装（BV1YY411e7j5）**

- 打野刀 40 攻击 + 15 攻速 + 8% 移速，本身 60 攻击 15% CD，配黑切 15%，再用 10% 匕首补满（@ 13:30）。
- 第五件电刀是「亚瑟的灵魂装备，仅次于黑切」，移速 553、开一技能 623，能追着关羽杀（@ 15:34、@ 16:06）。
- 全输出流：黑切 + 抵抗鞋 + 宗师 + 贪婪之噬（三级红刀）+ 电刀，最后补一件肉（血魔/名刀/破魔刀/魔女）（@ 18:52、@ 19:04）。
- 逆风局可把宗师换成冰痕之握：更肉、防被澜秒，还能补冷却和坦度（BV1ku4y1w7sP @ 09:29）。
- 肉刀打野不推荐（除非上单），亚瑟打野必须出攻击，否则后期只剩一个软控（BV1YY411e7j5 @ 19:24、@ 20:27）。

**关键装备结论**

- 电刀的核心价值是攻速把「滑步」变「瞬移」：对面反应时间更短，而且能穿过张良的书页墙（BV1YY411e7j5 @ 35:07、@ 35:18）；攻速要拉到 30 以上，15 不够（@ 36:26）。
- 冰痕加强后 800 血 240 防，相当于一件红莲，还带 CD 和减速（BV1YY411e7j5 @ 15:23）；但打野好用、上单不好用（@ 13:15）。
- 烧甲/反甲不触发一技能 1% 最大生命的额外伤害，「烧甲对亚瑟是一个绝对积累（鸡肋）的东西」（BV1YY411e7j5 @ 45:49）。
- 痛苦面具可触发：二技能旋转、圣印伤害都能触发，一技能强化普攻不触发（BV1YY411e7j5 @ 44:00、@ 44:46）。
- 碎星锤不好用：亚瑟输出靠技能、不平 A，大招又是法术伤害（BV1YY411e7j5 @ 14:02）。
- 破军只在需要针对坦克时出，效果比碎星锤好；打脆皮时大招只是控制和位移（BV1YY411e7j5 @ 48:35、@ 48:49）。
