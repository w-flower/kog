# 芈月：不是去团战里赢，是把兵线变成对面的债

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：阿泽《国一芈月·焚诀篇》（BV1qp5S6rE88，与娜可晨晨联合创作，铭文出装 + 全局思路，对抗路国服视角）；阿泽《芈月必学五个技巧》（BV1wj411f7JS，技巧向、结构化讲解）；Box《巅峰1700 芈月全局思路》（BV1dmQgBQEp7，对线哪吒的完整实录）。
> ⚠️ 三源均为**对抗路单带视角**，缺逆风局与"被强开之后怎么办"的处理；出装铭文只有 BV1qp5S6rE88 一源，特此说明。

## 1. 机制内核

1. **二技能链子是全部输出的电源**：不买装备、链满也能拿到 240 点物攻 + 840 点法强，"这个数值提升是非常恐怖的"（BV1qp5S6rE88 @ 02:25）（BV1wj411f7JS @ 00:10）。所以她"为什么能打"，第一层是**属性窃取**：链住敌人不是减速，是把对面的攻击力搬到自已身上。
2. **链子不挑目标**：链英雄、野怪、小兵给的属性完全一样，"在实战中我们只要就近连接一个，就可以获得同样的属性加成"（BV1qp5S6rE88 @ 02:37）。这决定了她被抓时能链野怪应急，也解释了她为什么敢在没有兵线的地方站。
3. **链得多只加回血，不加属性**："他只是增加我们的回血速度，增加的属性伤害都是一样的"（BV1qp5S6rE88 @ 02:49）。所以"链一个就够用"，不必为了多链而走位冒险（BV1qp5S6rE88 @ 02:55）。
4. **链子断了加成还在**：链子结束后攻击加成不立刻消失，还有 3 秒额外持续时间，敌方物攻法强也同步多降 3 秒——"字面效果只能持续四秒钟，但实际效果可以持续七秒钟"（BV1wj411f7JS @ 00:23）。
5. **改版后是"渐减"不是"清零"，所以能续**：以前链断即清零，现在改成逐步减少层数，并且"这个逐步降低，是在链子断了三秒钟之后才会逐步降低"（BV1wj411f7JS @ 00:54）。3 秒额外时间正好够等二技能冷却，"只要二技能冷却结束，就可以再练一次，让自身一直处于一个高法强的加持状态"，这就是"无限强化"（BV1wj411f7JS @ 01:29）（BV1wj411f7JS @ 01:34）。
6. **链不中有三套兜底**：普攻 A 完秒接二（"A2 必中"）（BV1wj411f7JS @ 01:44）；近距离贴身随便放都中（BV1wj411f7JS @ 01:47）；必要时连小兵（BV1wj411f7JS @ 01:53）。
7. **被动看紫色能量条，不看身上的乌鸦层数**：被动最多 +30 点移速、+10% 治疗效果，但"这个被动效果是跟紫色能量条挂钩"，很多人误以为乌鸦层数就是满被动（BV1wj411f7JS @ 03:18）（BV1wj411f7JS @ 03:27）。
8. **二技能自带一个"永久红 Buff"**：被动效果是普攻自带 10% 减速，"相当于你整局游戏都比别人多一个红 Buff"（BV1wj411f7JS @ 03:34）。这是她唯一的风筝手段——素材另一处明确"他没有留人手段，就只能靠这个减速来留人"（BV1dmQgBQEp7 @ 06:40）。
9. **一技能是"看不见的位移"**：一技能位移不暴露自身视野，敌方视角和小地图都只看到技能特效（BV1wj411f7JS @ 02:38）；且"只要一技能任何一个部位进到草丛之内"，整段技能敌人都看不到（BV1wj411f7JS @ 02:56）；飞行距离远，可连续穿多个墙体（BV1wj411f7JS @ 03:13）。
10. **大招是"清负面 + 不可选中 + 重置塔伤"三合一**：可清除马可被动、扁鹊毒这类负面状态（BV1wj411f7JS @ 03:40）；不可选中但仍会被张良大招控住（BV1wj411f7JS @ 03:50）；还能"用来重置塔伤"（BV1wj411f7JS @ 03:52）。这三点合起来，才是她敢在塔下和人群里进出而不死的底牌。

## 2. 对线 / 打法

- **第一波的处理是"减攻再压"**：哪吒想抢线，先用二技能黏住减攻击力，再开狂暴一直平A；"如果选择硬抢线呢，是直接会被我们A死的"（BV1dmQgBQEp7 @ 00:11）（BV1dmQgBQEp7 @ 00:14）。
- **抢线可以拿小兵当充电宝**：对面后撤后，"我们再用二技能连小兵抢线，顺便呢回状态"（BV1dmQgBQEp7 @ 00:19）。
- **线上个人节奏就是"一波兵线 + 一组野怪"**：这是"我们的主要收益线"；"能先手清，那就先手清，先手清不了，那就放进塔里后手清"（BV1dmQgBQEp7 @ 00:58）（BV1dmQgBQEp7 @ 01:03）。
- **1 分半是第一个升级窗口**：四级线"清一个兵就能升到四级"，升四后要立刻把线权换成动作（BV1dmQgBQEp7 @ 01:17）。
- **2 分钟、3 分钟是转中吃中线的时间点**（BV1dmQgBQEp7 @ 01:30）。这类额外收益的"前提呢是不影响我们拿主要收益"（BV1dmQgBQEp7 @ 02:04）。
- **3 分钟那条线清不清，取决于对面打野在不在**：先站小兵后面不让对面舒服清线，等打野漏视野再抢；"如果不确定对面打野的位置呢，那这波线我们都不能清"（BV1dmQgBQEp7 @ 02:54）（BV1dmQgBQEp7 @ 03:31）。
- **越塔的标准动作**：二技能连住 → 一技能坐进去接大招 → 伤害不够再补平A（BV1dmQgBQEp7 @ 03:15）（BV1dmQgBQEp7 @ 03:20）。
- **强拆塔的标准动作**：二技能连住、开狂暴、顶着伤害拆，最后一个大招收尾（BV1dmQgBQEp7 @ 04:14）（BV1dmQgBQEp7 @ 04:19）。
- **对线压力大的两个英雄要换起手装**：对线夏洛特、曹操这种压力大的，"也可以选择第一件先出护甲鞋"（BV1qp5S6rE88 @ 00:47）。
- **对面打野有惩戒时不要抢野**："他有惩戒，我们肯定是抢不到的"，抢不到就直接回来补线，"虽然我们野怪拿不到，但是我们线上1V1是根本不怕"（BV1qp5S6rE88 @ 05:09）（BV1qp5S6rE88 @ 05:13）。

## 3. 连招

| 场景 | 连招 | 依据 |

| **单杀 / 抓人** | 先丢一技能 → 接二技能黏住 → 平A → 杀完一技能换位撤离 | （BV1qp5S6rE88 @ 04:27）（BV1qp5S6rE88 @ 04:30） |

## 4. 中后期 / 节奏

- **4—10 分钟的主线是"推进 + 加速发育"**（BV1qp5S6rE88 @ 08:07）。
- **边塔一掉，带线要先看小地图**：对面没漏视野就不出去，"等对面野辅漏视野之后，我们确认安全再出来清线，要不然的话就很容易被对面反蹲"（BV1qp5S6rE88 @ 08:15）（BV1qp5S6rE88 @ 08:20）。
- **最容易犯的错是"头也不回往前硬带"**：要记住"我们给的是兵线压力，而不是我们这个英雄的单挑压力"，把运营压力交给对面，别自己硬带给对面抱团抓你的机会（BV1qp5S6rE88 @ 08:31）（BV1qp5S6rE88 @ 08:33）。
- **4 分钟龙团，均势就不去**："如果我们自身属于均势状态，那么这波龙我们是不需要去支援的"，优先保证自身经济（BV1qp5S6rE88 @ 06:11）。
- **10 分钟强化龙团，均势可以"用兵线钓龙"**：9 分 40 秒提前带一波兵线出去，对面来管就直接传过去打龙，不来就继续推进（BV1qp5S6rE88 @ 11:36）（BV1qp5S6rE88 @ 11:40）。
- **龙团取舍有明确方向**："如果是顺风的话，就优先开暴君，逆风的话就优先开主宰"（BV1qp5S6rE88 @ 11:52）。
- **一技能是超远程换位支援**："先是拦住敌方两人，然后转身交一技能，直接换位"，等于凭空制造一波人数差（BV1qp5S6rE88 @ 11:14）（BV1qp5S6rE88 @ 11:19）。
- **团战定位要认清**："芈月这个英雄厉害的点其实是在单带打，团战稍微有点一般，因为手太短了，而且没什么控制"，"能A到谁就A谁，很多情况下都摸不到对面后排就被打残血了"（BV1dmQgBQEp7 @ 10:13）（BV1dmQgBQEp7 @ 10:19）（BV1dmQgBQEp7 @ 10:22）。
- **所以输出位不要第一时间进场**：第一波伤害让队友吃、自己保状态，等对面没技能再后手进场（BV1qp5S6rE88 @ 07:21）（BV1qp5S6rE88 @ 07:26）。
- **红 Buff 对她是质变**："红Buff这个东西对芈月提升很大，我们能拿的话就一定要拿"（BV1qp5S6rE88 @ 10:15）；有优势时"可以跟打野要红"（BV1qp5S6rE88 @ 08:43）。
- **对面掉点就立刻转推进**，不要继续在野区磨（BV1qp5S6rE88 @ 09:55）。

## 待补

- **逆风局处理**：三源全是顺风/均势局，没有"正面崩了怎么守"的素材。
- **被强开后的应对**：只讲了主动撤离（一技能+反向大），没讲被控住（张良大以外）的处理。
- **对线强度表**：只覆盖哪吒（实录）、亚连/影/老虎（只言片语）、夏洛特/曹操（只提到换鞋），其余对抗路英雄无素材。
- **团队配合细节**：只讲"提醒辅助来上""让辅助抗塔"，没有双排/五排的完整分工。
- **数值与冷却**：240 物攻 / 840 法强两源一致；但各技能 CD、被动层数上限、大招持续时间均未给出，不做推断。
- **版本口径**：三源均未在字幕中明确版本号，本文按 S45 归档；若技能数值有调整需回看原片。
