# 哪吒：带线不断、支援不停，用一条线换一波人数差

## 1. 机制内核

1. **大招能跨图飞**：打野没抢到龙，"飞过去挽回一点损失"（BV1j64y1e79q @ 00:53~00:59）；带线被马可包过来时"直接开大飞另一头"（BV1j64y1e79q @ 02:33~02:38）
2. **带线与支援是一体的**："技能给到对面攻击，又能跟得上队友的节奏"（BV1j64y1e79q @ 01:25~01:29）
3. **二技能用来拉扯**：对孙策"二技能拉扯一下"，他追上来时"倒二技能拉扯，躲他一技能"（BV1j64y1e79q @ 00:22~00:25、00:39~00:44）
4. **红 Buff 是留人手段**：杀掉马可后身上有红 Buff，"这个孙策也走不掉"（BV1j64y1e79q @ 00:59~01:03）
5. **跟位移要等对方先交**："留意二技能，等他交完位移跟上"（BV1j64y1e79q @ 01:03~01:04）
6. **带线后要靠草丛消视野**：清完兵线"找个草丛一躲"，把两路视野分出去管（BV1j64y1e79q @ 01:51~01:56）

## 2. 对线 / 打法

- **对孙策：不跟他打**。孙策抢二能单杀，所以尽可能不接战，清完线就走，用二技能拉扯（BV1j64y1e79q @ 00:15~00:25）
- **先确认草丛**：看孙策在不在草里，他漏了、不跟我们打，就先把线清掉（BV1j64y1e79q @ 00:25~00:32）
- **他追就拉扯**：倒二技能拉开，躲掉他一技能（BV1j64y1e79q @ 00:39~00:44）
- **带线时不要被抓**：清完兵线找草丛躲，注意两路视野（BV1j64y1e79q @ 01:47~01:56）
- **被包就飞走**：马可包过来时直接开大飞另一头（BV1j64y1e79q @ 02:29~02:38）
- **大后期拉视野**：23 分钟躲在中路二塔草丛里拉对面视野，因为对面都有奔狼、就想抓哪吒（BV1j64y1e79q @ 02:53~03:05）
- **被多人抓时**：一个人在带线，他们来抓，就直接往另一头飞（BV1j64y1e79q @ 03:11~03:13）
- **对面人走了再清线**：把这波线清掉；中路打不起来就清线，清完不着急，等队友过来再去下路（BV1j64y1e79q @ 03:15~03:31）

## 4. 中后期 / 节奏

- **龙团止损**：打野没抢到龙，飞上去带着队友打了一波一换四，"不是很亏"（BV1j64y1e79q @ 00:56~01:19）
- **跟团要跟到底**：东皇开团就跟上去，"没有回头箭，只能硬着脸上一上"，强行打了一波二换二，把对面的状态和技能打掉（BV1j64y1e79q @ 02:01~02:15）
- **关键节点是龙**：自己死掉风暴龙王就白给对面，"很可能输掉这把比赛"（BV1j64y1e79q @ 02:39~02:44）
- **23 分钟后的处理**：躲中路二塔草丛拉视野 → 对面扑空 → 清线 → 等队友集合再转下路（BV1j64y1e79q @ 02:53~03:31）
- **最后一波**：对面开奔狼、位置不好，自己有复活甲就上去卖一波吃技能，打出西施大招和曹操大招，队友收割拿下比赛（BV1j64y1e79q @ 03:51~04:10）
- **推塔**：团赢后可以推对面下路二塔（BV1j64y1e79q @ 01:40~01:45）
