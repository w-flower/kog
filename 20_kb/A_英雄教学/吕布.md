# 吕布：前期靠附魔压线，团战用大闪砸后排

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：三份来源——23 星排位直播实录（BV1mApc6zE4B，含大量抽奖口播，已剔除只留对局内容）、黄盾减速流出装教学（BV1ins36REdA）、红莲流思路 + 实录（BV1yzsn6YEZR）。
> ⚠️ 三份素材分属**三套互相冲突的出装流派**（裸破军 / 黄盾减速 / 红莲出肉），本卡并列保留、不做合并；素材只覆盖对线与出装，**机制数值与对位强度表覆盖不全**。

## 1. 机制内核

1. **附魔是伤害开关**：开启方式是"先来刀附魔"（BV1mApc6zE4B @ 01:53），拿到附魔后"两刀就给他带走了"（BV1mApc6zE4B @ 04:36）；贴身"走位吸一口"也能拿到附魔（BV1mApc6zE4B @ 03:45）。素材里"附魔"是主播口语，未拆技能判定与持续时间，见待补。
2. **真伤是引擎，铭文不该再去堆攻击**：素材点出的误区是"吕布有真伤就需要堆攻击铭文来放大伤害"，评价是这会让"脆弱的前期雪上加霜"；正确分工是"吕布的真伤和被动穿透式引擎"，铭文负责把车身做厚、撑到发力期（BV1ins36REdA @ 00:39、BV1ins36REdA @ 00:46）。
3. **黄盾把清线速度变成节奏权**：改版后"技能命中单位也能触发黄盾的被动效果"，于是二技能吸盾、一技能都能附带额外伤害，清线与刷野同时提速（BV1ins36REdA @ 02:16、BV1ins36REdA @ 02:19）。
4. **红莲的价值是免伤不是输出**：第一件红莲按生命值折算，"相当于常驻20多的免伤"，且抗性比苍穹更高（BV1yzsn6YEZR @ 00:39、BV1yzsn6YEZR @ 00:41）。
5. **大招一技三用**：逃生（"吃下赵云狂铁所有技能没死，轻松用大招逃生"，BV1ins36REdA @ 01:58）/ 进场（BV1mApc6zE4B @ 10:45）/ 塔下反打（BV1mApc6zE4B @ 06:02）。
6. **装备之间能叠乘**：冰痕强击的额外伤害"与黄盾对敌人的额外伤害是可以同时触发的"（BV1ins36REdA @ 03:10）；寒霜侵袭的减速"可以和冰霜的减速进行叠加"（BV1ins36REdA @ 04:30）。

## 2. 对线 / 打法

- **对司空震（带狂暴）**：先"来刀附魔"，他开狂暴就往后撤，把狂暴耗干——"等你狂暴快没了，我再揍你"（BV1mApc6zE4B @ 01:53、BV1mApc6zE4B @ 02:01）。
- **用卡线代替换血**：对面不敢接，就"兵线直接给他卡死"，连兵都吃不到（BV1mApc6zE4B @ 02:15）；反过来自己被压时，"那你兵线别吃了"就是对方的收益（BV1mApc6zE4B @ 02:07）。
- **开局白嫖移速（黄盾流）**：秒买鞋，走到高地塔附近原价卖掉换布甲，"白嫖30点移速"先到线；进边草等对手露头补刀的瞬间，一技能先手压血（BV1ins36REdA @ 01:13、BV1ins36REdA @ 01:19）。
- **别第一件憋荆棘护手**：当前版本二级装性价比不如从前，对线期第一件先出隐忍之足，靠被动减普攻伤害站住线（BV1ins36REdA @ 01:32、BV1ins36REdA @ 01:53）。
- **对暗信（红莲流）**：暗信回血强，但红莲克制回血（BV1yzsn6YEZR @ 01:06）；打法是"我们不开大就和他对拼，他放E我们再放"（BV1yzsn6YEZR @ 01:17）。这套前期不怎么怕暗信，普通边路随便打，坦边"打起来更是基本不掉血"（BV1yzsn6YEZR @ 01:22、BV1yzsn6YEZR @ 01:29）。
- **压线必须看小地图**：实录两次送人头都归因为"压得太深"加"忘记看小地图"，是他自己的复盘原话（BV1mApc6zE4B @ 03:05、BV1mApc6zE4B @ 02:47）。
- **别拿它打太灵活的阵容**："扛不住还走不掉"（BV1yzsn6YEZR @ 03:54）。

## 4. 中后期 / 节奏

- **破军是斩杀线开关**："我刚刚那一套直接他已经没了"，前提是有破军（BV1mApc6zE4B @ 06:19）；出完之后"一刀3000"（BV1mApc6zE4B @ 08:21）。
- **反方观点同时被记录**："我要是出肉装，我这把就要被摁着打"（BV1mApc6zE4B @ 08:29）——这正是红莲流与破军流的分歧点。
- **红莲流的定位是让经济 + 吃伤害**：对面四个核心时，这套出肉"完全可以给队友让经济"，中路经济也让，自己和中路住发育路、两条边线交给打野（BV1yzsn6YEZR @ 04:42）。
- **红莲流不负责切满血 C**："切满血C不属于我们吕布的职责"，只补伤害（BV1yzsn6YEZR @ 04:09）。
- **黄盾流的第一波质变**：黄盾+冰痕成型时物抗突破 900、生命值接近 1 万、冷却缩减达到 30%（BV1ins36REdA @ 03:19、BV1ins36REdA @ 03:21）。
- **开龙前的视野**：看见龙王击飞就直接跳（BV1yzsn6YEZR @ 04:19）。
- **压制手段**：二塔后面给压力（BV1yzsn6YEZR @ 05:02），"其实对面根本不管我都行，我来这纯粹装个样子"（BV1yzsn6YEZR @ 05:05）——即用站位牵制而不是硬拼。

## 5. 出装铭文

三份素材给了三套，各自冲突，按来源分开列。

**A. 破军流（直播实录，未给完整六件）**
- 起手"照样先直接裸出破军"，认为先出破军才有斩杀线（BV1mApc6zE4B @ 02:10、BV1mApc6zE4B @ 04:32）
- 完整六件未覆盖，见待补

**B. 黄盾减速流（给出完整顺序）**
- 铭文：红色十宿命；蓝色 + 绿色十虚空，吃生命值、物防、回血、移速与冷却缩减（BV1ins36REdA @ 00:57、BV1ins36REdA @ 01:01）。蓝色一栏转写为"词条"，名称无法确认，见待补
- 出装顺序：隐忍之足 → 黄盾 → 冷静鞋 → 冰痕 →（第五件）永夜 或 破军再永夜 →（第六件）寒霜侵袭（BV1ins36REdA @ 01:44、BV1ins36REdA @ 02:34、BV1ins36REdA @ 02:44、BV1ins36REdA @ 02:55、BV1ins36REdA @ 03:44、BV1ins36REdA @ 04:00、BV1ins36REdA @ 04:17）
- 换鞋逻辑：黄盾出完再"将布甲鞋换成冷静鞋"，用 15% 冷却换更频繁的护盾与黄盾触发（BV1ins36REdA @ 02:44）

**C. 红莲流（给思路，未给完整六件）**
- 第一件红莲；鞋子看局，爆发高就物抗鞋、控多就抵抗鞋，本人偏好冷静鞋（BV1yzsn6YEZR @ 01:45）
- "破军破魔刀是必备的输出装"，且"先做破军效果会更好"（BV1yzsn6YEZR @ 02:13、BV1yzsn6YEZR @ 02:16）
- 最后两件：不详（套减速）+ 永夜（给自己加速）（BV1yzsn6YEZR @ 02:26）
- 代价：小红莲移除后，橙装出来之前缺伤害，前期千万别上头（BV1yzsn6YEZR @ 02:51、BV1yzsn6YEZR @ 02:55）
