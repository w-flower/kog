## 1. 机制内核

1. **叠毒 + 大招斩杀**：叠毒后大招斩杀，五层以上就有斩杀机会（BV16suu6JE4x @ 06:08~06:10）；四级后"叠毒大招斩杀就可以转线了"（BV16suu6JE4x @ 03:43~03:46）
2. **技能都是范围 AOE**："扁鹊的技能都是范围AOE伤害"，所以抢线和打状态都能顺手做（BV16suu6JE4x @ 04:10~04:12）
3. **非常吃 CD**：出装要先出叠 CD 的小件，做痛苦面具之前一定要先补叠 CD（BV16suu6JE4x @ 00:46~00:51）
4. **大招不能一直捏着**：有的情况要当成打状态和叠毒来用（BV16suu6JE4x @ 03:33~03:37）；对面突脸多时不要想着大招斩杀，留给队友补状态当工具人（BV16suu6JE4x @ 06:21~06:26）
5. **反向二闪**：正常二闪容易打不中、或者人闪出去技能没放，反向二闪 90% 可以命中，失误几率很小（BV16suu6JE4x @ 01:17~01:31）
6. **大闪**：扁鹊可以大闪，技能特效不会显示、只停留在原地，但伤害已经打出来了（BV16suu6JE4x @ 01:32~01:42）
7. **开局白嫖移速**：开局买鞋，出高地卖掉换成小法点（BV16suu6JE4x @ 01:48~01:51）

## 2. 对线 / 打法

| 场景 | 做法 | 依据 |
|---|---|---|
| **发育优先** | 主要保证自身发育，其次才是帮队友控资源；"想玩好扁鹊就一定要自私一点" | BV16suu6JE4x @ 01:51~02:04 |
| **开局站视野** | 打野红开，帮忙占住蓝区视野 | BV16suu6JE4x @ 02:04~02:06 |
| **兵线交汇** | 对面是强线权英雄就打他状态；清线能力不强就尝试抢线，抢线时能消耗就消耗 | BV16suu6JE4x @ 02:06~02:15 |
| **快速清线** | 先用二技能把兵线推到一起，再用一技能清完 | BV16suu6JE4x @ 02:53~02:57 |
| **清完线转线** | 清完线转发育路控资源 | BV16suu6JE4x @ 02:16~02:18 |
| **射辅压线时** | 我方射辅压着对面打，就不用出去帮抢红隼，藏好视野卡杨玉环位置、打她状态 | BV16suu6JE4x @ 02:23~02:30 |
| **不救必败的边路** | 我方对抗路四级前太弱、打野又是红开，这波肯定打不了，没必要下去，等下波兵线 | BV16suu6JE4x @ 02:45~02:52 |
| **不越塔** | 4 分钟前不好越塔，"扁鹊太弱了" | BV16suu6JE4x @ 04:21~04:24 |
| **半靠中左** | 没资源就打半靠、站住中左视野，防止对面中单转线支援；有人从中左路过就打一套状态 | BV16suu6JE4x @ 03:12~03:20、03:58~04:04 |
| **蹭野区** | 边路没资源、打不起来时，去蹭一下野区经济 | BV16suu6JE4x @ 04:24~04:26 |
| **提前蹲人** | 上路兵线进塔、对面三人都在中路，判断虞姬大概率来清线，提前上去蹲 | BV16suu6JE4x @ 05:31~05:36 |

## 4. 中后期 / 节奏

- **4 分钟后的方向**：优先帮发育路解放；自己有优势了就可以放线去帮忙（BV16suu6JE4x @ 05:26~05:30）
- **推进节奏**：解放发育路后开始打推进，队友推塔时用一二技能压位置、恶心对面（BV16suu6JE4x @ 05:43~05:50）；出疾跑鞋就是为了中期跟得上队友（BV16suu6JE4x @ 05:50~05:53）
- **推塔站位**：躲在队友后面丢技能卡位置，同时打状态、叠毒（BV16suu6JE4x @ 06:03~06:08）
- **抢资源**：有大招时"扁鹊抢资源可是一把好手"，叠毒大招斩杀直接拿下（BV16suu6JE4x @ 04:04~04:08）
- **蓝条**：建议多叫几声哥哥，让打野让出 Buff（BV16suu6JE4x @ 05:55~05:58）
- **团战**：多注意站位、多拉扯、慢慢叠毒；对面突脸多就把大招留给队友补状态（BV16suu6JE4x @ 06:17~06:26）
- **开大清线的代价**：队友那边打起来就没有留人手段；但前期很少打架、以控资源发育为主，所以问题不大（BV16suu6JE4x @ 03:46~03:54）

## 5. 出装铭文

**铭文**：十狩猎、十献祭、十梦魇（BV16suu6JE4x @ 00:16~00:17）

**出装顺序**（BV16suu6JE4x @ 00:23~00:43）：

1. 开局小法点
2. 法穿鞋
3. 圣者法典叠 CD
4. 转线过程中换疾跑鞋（还在线上清线就没必要换，挂着即可）
5. 梦魇

- **第二件分支**：对面坦克多，先做痛苦面具，但之前一定要出叠 CD 的小件；坦克不多就先日暮，出完日暮再出冰杖（BV16suu6JE4x @ 00:43~00:55）
