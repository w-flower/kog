## 1. 机制内核

1. **被动假血**：受到伤害后产生灰色血条，即"假血状态"（BV1nG411g7sz @ 00:05~00:10）
2. **假血状态下，任何主动伤害都能回血**：按造成的伤害数值把假血转成真血（BV1nG411g7sz @ 00:13~00:22）
3. **转化比例**：对英雄 40%，对非英雄（小兵/野怪）20%（BV1nG411g7sz @ 00:25~00:27）
4. **这不是吸血**：头顶没有假血状态时，造成任何伤害都不回血（BV1nG411g7sz @ 00:30~00:36）
5. **按"技能绝对伤害"算，无视抗性与免伤**：一技能面板 1657，实际只打出 620，但回血 662——因为 1657×40%≈662（BV1nG411g7sz @ 00:48~01:20）；老夫子的免伤、高额防御都可以无视（BV1nG411g7sz @ 01:31~01:34）
6. **对非英雄的 20% 会先叠技能加成**：一技能对小兵 +30%、对野怪 +50%，所以 1657×1.5×20%≈497（BV1nG411g7sz @ 01:54~02:14）
7. **普攻也吃转化**：普攻附带额外伤害，回血 =（物攻 329 + 被动附加 157）×40% ≈ 193（BV1nG411g7sz @ 02:29~02:42）
8. **装备区分主动/被动**：肉刀、红莲斗篷这种带主动伤害的能触发回复；反甲这种"受到伤害后被迫造成伤害"的不能（BV1nG411g7sz @ 02:44~02:55）
9. **命中目标越多回得越多**，且没有回复上限（BV1nG411g7sz @ 03:01~03:08）
10. **一技能两段跳**：第二段落地 0.5 秒眩晕；第一段方向看技能方向，第二段看左侧轮盘（BV1nG411g7sz @ 05:32~05:49）；可穿薄墙（BV1nG411g7sz @ 05:54）；霸体覆盖整个释放过程（BV1nG411g7sz @ 06:46~06:51）
11. **一技能多目标会衰减伤害**：每多命中一个敌人衰减 20%，最多 60%，小兵不算；但**只衰减伤害、不衰减回血**（BV1nG411g7sz @ 06:53~07:08）
12. **二技能拉人**：1.5 秒 60% 减速；拉到墙体则自身和敌人一起被拉过去，并造成 0.5 秒眩晕（BV1nG411g7sz @ 03:16~03:29）；实际命中范围约一个身位，是"小范围控制"（BV1nG411g7sz @ 03:31~03:54）；放完给 3 秒强化普攻，能把敌人拉回身边（BV1nG411g7sz @ 04:45~04:52）
13. **大招放墙**：阻止敌人前进，且这堵墙可以当二技能的"墙体"用（BV1nG411g7sz @ 07:15~07:22）

## 2. 对线 / 打法

- **对司空震（同水平）不占优**：他打不动你，你也拿不到大优势；抢线怕被队友抓，对拼会被他拉扯（BV1trApzeEAM @ 00:36~00:56）
- **一级换状态要贴脸再交位移**，不然一技能容易被司空震一技能躲（BV1trApzeEAM @ 00:03~00:11）
- **卡线是坦边的核心动作**：兵线卡在塔前，对面打野想过来吃线也不容易（BV1trApzeEAM @ 01:08~01:15）；卡住之后司空震"一直处于一个比较危险的位置"（BV1trApzeEAM @ 01:53~02:00）
- **两个小兵打人痛就先拉出来**，吃一个、卡一个（BV1trApzeEAM @ 02:46~02:50）
- **下半图没资源就只卡线**：不要死、保持经济优势（BV1trApzeEAM @ 02:18~02:28）
- **对吕布没有细节**："对位这个英雄基本上没有什么细节，你直接打就打得过"（BV1yAh8zDEGP @ 00:15~00:19）；前期"稍微压一下他的状态就行"（BV1yAh8zDEGP @ 01:57~02:04）
- **对线期以发育为主**（BV1yAh8zDEGP @ 01:51）
- **对面打野蓝开，那波线不要抢**，用二技能补位把兵线放过来清（BV1yAh8zDEGP @ 01:15~01:19）
- **下半河道视野黑就别过河**，只在自己半张图打消耗（BV1trApzeEAM @ 04:47~04:53）
- **4 分钟龙团**：在侧边卡人就行，对面也不好抢（BV1trApzeEAM @ 03:28~03:55）
- **中期参团前先占中右视野**，队友打完回线才安全（BV1yAh8zDEGP @ 03:04~03:13）

## 3. 连招

这张卡的干货不在"连招表"，而在**把二技能/一技能/大招拼起来的位移控制组合**。原素材是按"技巧"组织的，照此归并：

| 技巧 | 做法 | 依据 |
|---|---|---|
| **二闪（后拉）** | 二技能打出的瞬间向**后**闪现，把身后敌人一起拉过来，延长攻击距离 | （BV1nG411g7sz @ 03:56~04:07） |
| **二闪（改向）** | 二技能打出瞬间向**侧**闪现，改变方向拉到侧面敌人 | （BV1nG411g7sz @ 04:11~04:18） |
| **二闪双控** | 先二技能控住一个，再闪现调整位置命中第二个，一个二技能控两个 | （BV1nG411g7sz @ 04:22~04:38） |
| **A 闪控拉** | 强化普攻瞬间向后闪现，延长控制距离，也可改方向 | （BV1nG411g7sz @ 05:01~05:18） |
| **跳拉** | 一技能接近目标 → 二技能打断一技能 → 用二技能把敌人拉到墙上 | （BV1nG411g7sz @ 06:13~06:34） |
| **反复横跳** | 一技能向前，同时向后拉方向键（一技能可穿薄墙） | （BV1nG411g7sz @ 05:54~05:59） |
| **消墙双推** | 大招 → 二技能拉到墙的一瞬间取消大招，额外多推一段 | （BV1nG411g7sz @ 07:30~07:40） |
| **隔墙晕人** | 墙体足够薄且贴得够近，直接二技能就能打出眩晕 | （BV1nG411g7sz @ 08:03~08:14） |
| **隔墙推人** | 面前放大招，贴墙用二技能，多推一段并眩晕 | （BV1nG411g7sz @ 08:17~08:38） |
| **移形幻影** | 大招 → 二技能勾墙瞬间取消大招 → 刚飞出墙时向前闪现，把敌人反拉回来 | （BV1nG411g7sz @ 08:53~09:11） |
| **侧拉** | 斜方向闪现，打出侧拉效果 | （BV1nG411g7sz @ 09:24~09:28） |
| **空气墙** | 大招中心点放进草里，敌方视角看不到墙体模型 | （BV1nG411g7sz @ 09:35~09:46） |
| **大招吞技能（负面）** | 对着地图墙放大招会加厚墙体，靠近再用一技能会被吞掉 | （BV1nG411g7sz @ 09:50~10:15） |

> 注意：二技能强化普攻"还可以改变敌人的技能方向"（BV1nG411g7sz @ 05:23~05:28），这是上面几个位移组合能打出意外效果的原因。

## 4. 中后期 / 节奏

- **10 分钟盯对面打野，不让他开龙**：跟队友说好"我们去盯镜"（BV1trApzeEAM @ 08:18~08:22）
- **队友要跟你保持距离**，"不然的话容易被镜当跳板给开了"（BV1trApzeEAM @ 08:24~08:26）
- **一个人在前面，只要不死就行**（BV1trApzeEAM @ 08:28）
- **大招框 + 二技能拉**是标准开团组合："直接二阶一贴脸诸葛亮，再收一个大招框住镜"（BV1trApzeEAM @ 08:39~08:41）
- **对面全是护盾时回不上血**——这是这套回血机制最硬的克制点："对面全是护盾，我们回不上来血量"（BV1trApzeEAM @ 07:08~07:12）
- **逆风就转攻为守**：掩护撤退、大招框一下、卡位置不让对面开龙（BV1trApzeEAM @ 12:11~12:26）
- **不要硬上**："我们就在旁边给压力就行，不用硬上，打一套就拉开"（BV1trApzeEAM @ 12:37~12:40）
- **坦边 vs 坦野**：路人局坦边更适配，坦野中期"切C能力不足"（BV1yAh8zDEGP @ 07:28~07:43）
- **不抢 C 的人头**："一个必杀的人头如果坦边去K了，不如把这个人头给射手打野或者中单"（BV1yAh8zDEGP @ 09:48~10:03）
- **第一次参团要谨慎**："我们要去用肉体感受一下他们的伤害，不能打得太激进"（BV1yAh8zDEGP @ 05:50~06:03）
- **黄盾续航**：打完一波团摸两下野怪就满血（BV1yAh8zDEGP @ 09:09~09:16）
