# 高渐离：开大减伤顶着进场，二闪贴脸的瞬间才算爆发

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：一份出装向教学（BV1iU4y1n7x9，两套出装 + 铭文 + 进场片段）；一份 1600 巅峰赛直播（BV1cJ411o7ND，以吃线、蓝区节奏为主）。
> ⚠️ **素材覆盖不全**：缺一技能/二技能/被动的机制描述，只有「怎么用」的片段；**两份素材的铭文完全不一致**（梦魇/狩猎/心眼 vs 狩猎/鹰眼/无双），素材未说明是版本差还是流派差，不代为裁定；直播那份大量内容是主播与弹幕互动，可提取的对局信息有限。

| 项 | 内容 |
|---|---|
| **强势期** | 中期。回响 + 帽子 + 大吸血书三件套成型后「是可以创造奇迹的」（BV1iU4y1n7x9 @ 04:39、04:42、04:45） |
| **节奏职责** | 开团/进场收割：「法刺就是要在合适的时机进场收割对面」（BV1iU4y1n7x9 @ 00:26） |
| **一句话** | 对进场时机的把握是衡量高渐离的重要标准 |

| **团战站位** | 后手进，不是先手进：先消耗、等团战爆发再切入（BV1iU4y1n7x9 @ 00:31、00:36） |

## 1. 机制内核

1. **大招减伤是进场资本。** 「开大减伤」后才敢一打三，边扛边打（BV1iU4y1n7x9 @ 01:05、01:07）。
2. **二技能内圈 + 二闪是贴脸手段。** 「带二技能内圈」（BV1iU4y1n7x9 @ 01:11），配合闪现瞬间贴到 C 位脸上，打出「二闪 a」（BV1iU4y1n7x9 @ 00:39、01:11）。
3. **平A是叠被动的手段，不是主要输出。** 走位靠前 1A 消耗，「往后拉平a叠被动」，同时拉开视野（BV1iU4y1n7x9 @ 00:31、00:35）。
4. **爆发靠技能连段衔接普攻。** 「一瞬间 12a 打出最高爆发」（BV1iU4y1n7x9 @ 00:12、00:15）。
5. **法穿到位后是质变点。** 一个会二闪的高渐离，出完法穿这个时间点，对面 C 位「基本都是一秒躺」（BV1iU4y1n7x9 @ 04:57、04:59、05:03）。
6. **进场时机 > 一切。** 素材开篇就把它定义为衡量高渐离的主要标准（BV1iU4y1n7x9 @ 00:07）。
7. **分段感受不能当英雄强度。** 主播说 1600 分段「随便吃线乱杀」（BV1cJ411o7ND @ 01:53、01:54），这是他个人对局环境的判断，不是英雄结论。

## 2. 对线 / 打法

- **吃线优先。** 「先搞波线」（BV1cJ411o7ND @ 01:48）、「多吃点线没错的」（BV1cJ411o7ND @ 02:20）、「不想打就吃线」（BV1cJ411o7ND @ 02:43）、「来中路带波线」（BV1cJ411o7ND @ 04:53）。
- **不该打的团不要进。** 「我不准备上了，上了会被反打的，不划算」（BV1cJ411o7ND @ 02:52、02:53、02:54）。
- **打蓝区要看对面阵容。** 对面有大乔时打蓝区「就不是很划算了」，因为大乔反打能力强，「我们打蓝区的话会把队友带崩了」（BV1cJ411o7ND @ 03:17、03:18、03:24、03:25、03:26）；对面没这种反打能力时才「打他蓝区的节奏就好了」（BV1cJ411o7ND @ 02:56、03:14）。
- **守高地/劣势时的站位。** 走位靠前 1A 消耗，往后拉平A叠被动，同时拉开视野（BV1iU4y1n7x9 @ 00:31、00:35）。
- **抗塔后先退。** 「抗塔了，先拉开范围，等待技能冷却」，回头一技能收掉三个拿四杀（BV1iU4y1n7x9 @ 00:19、00:20、00:21、00:24）。
- **极限距离消耗、躲控制，一打三不慌**（BV1iU4y1n7x9 @ 00:59、01:04、01:05）。
- **卡视野勾引是起手方式。** 「逃离（卡）视野以及在前面勾引」，等周瑜上钩再一瞬间打最高爆发（BV1iU4y1n7x9 @ 00:12、00:15）。

## 4. 中后期 / 节奏

- **进场时机是唯一标准**（BV1iU4y1n7x9 @ 00:07）。
- **后手收割：** 等团战爆发再进（BV1iU4y1n7x9 @ 00:36）；守高地时不要先手（BV1iU4y1n7x9 @ 00:31）。
- **进场前先把被动与技能都备好**，不要空手进场——素材里的击杀都是「等技能冷却」「拉到合适范围」之后才回头打（BV1iU4y1n7x9 @ 00:20、00:21）。
- **直播侧的节奏：** 中路带线（BV1cJ411o7ND @ 04:53）、刷前线（BV1cJ411o7ND @ 06:06）、开黑龙一波（BV1cJ411o7ND @ 09:59）。
- **劣势期的取舍：** 判断反打不划算就不上，宁可去吃线（BV1cJ411o7ND @ 02:52、02:43）。

## 5. 出装铭文

**铭文（两套不一致，如实并列）：**

- BV1iU4y1n7x9：10 梦魇 + 10 狩猎 + 10 心眼（BV1iU4y1n7x9 @ 01:42、01:44、01:45）。
- BV1cJ411o7ND：狩猎 + 鹰眼 + 无双（BV1cJ411o7ND @ 07:00、09:24）；觉得续航不够，可以补 3 个夺萃（BV1cJ411o7ND @ 10:02、10:03）。

**两套出装：闪现刺客流 / 狂暴战士流**（BV1iU4y1n7x9 @ 01:46、01:59）。

**召唤师技能怎么选：**

- 喜欢后手收割 → 闪现；喜欢先手一打五 → 狂暴（BV1iU4y1n7x9 @ 02:15、02:16、02:18、02:21）。
- 对面输出灵活、队友没有切后排能力 → 闪现；对面是刺客和突脸、或者队友能帮忙打控制 → 狂暴（BV1iU4y1n7x9 @ 02:22、02:25、02:27、02:27、02:30、02:32）。
- 「出装不是死的，要根据局势以及个人做不同的调整」（BV1iU4y1n7x9 @ 02:32、02:35）。

**闪现刺客流（BV1iU4y1n7x9 @ 04:22 起）：**

韧性鞋（对面没控制可考虑法穿鞋，但多数还是韧性鞋）→ 小吸血（前期不推荐直接合成大吸血书，因为「你是个刺客，不需要抗伤害」）→ 回响 + 帽子（追求最高爆发）→ 帽子之后合成大吸血书（BV1iU4y1n7x9 @ 04:22、04:26、04:29、04:32、04:33、04:36、04:39、04:42）。开局也可以先做大吸血书换保命能力（BV1iU4y1n7x9 @ 04:48）。

**法穿选择：** 首选法穿棒（BV1iU4y1n7x9 @ 04:53、05:13）。日暮之流也能出，但「打完一套被动才叠满，收益不高」，所以不是首选（BV1iU4y1n7x9 @ 04:54、05:03、05:05、05:07）。

**最后一件：** 对面不出魔抗 → 巫术法杖进一步提高爆发，也可以金色圣剑增加持续作战；对面出魔抗 → 日暮之流，「对面魔女穿的就跟没穿一样」（BV1iU4y1n7x9 @ 05:17、05:19、05:20、05:22、05:28、05:30、05:32、05:33、05:36、05:39）。

**后续换装：** 鞋子换金身 → 复活甲 → 名刀；手残党建议先复活甲再名刀，最后再补月神（BV1iU4y1n7x9 @ 05:55、05:57、05:58、07:03、07:06）。

**狂暴战士流（BV1iU4y1n7x9 @ 05:58 起）：**

小鞋子 → 进化水晶（保证四级能回一波血和蓝）→ 韧性鞋 → 大吸血书（狂暴战士要能抗能打）→ 时之预言 + 帽子 → 法穿棒 + 金身（BV1iU4y1n7x9 @ 05:58、06:02、06:04、06:12、06:16、06:18、06:19、06:21、06:33）。嫌时之预言太拖，可改成「韧性鞋 + 大吸血书 + 帽子」后直接出极寒风暴（BV1iU4y1n7x9 @ 06:21、06:24、06:26、06:28、06:30）。

**狂暴流的鞋子：** 没有闪现、没位移，所以「建议是不要卖鞋子」；只有后期太有钱或已经在守高地，才考虑把鞋子换掉（BV1iU4y1n7x9 @ 06:36、06:38、06:40、06:43）。
