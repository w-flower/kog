# 元流之子：数值超标的多形态万金油，靠坦度换输出空间

> 只讲英雄本身。官方定位为多形态英雄（法师/坦克等五形态），官方主分路对抗路。
> 素材：王者荣耀听说《中单狂暴流全局教学》（BV1GW421d7bj）、澜朋友《国服元刺教学》（BV1jk9nBXEFQ）、珈蓝《打野元流之子》（BV1Lb421n7P8）。本卡以中单/打野形态素材为主。

## 1. 机制内核：能量系统决定一切

1. **一技能是能量发动机**：空放可攒五格能量，场上每多一个队友/目标额外加能量，两个兵线才额外加一格（BV1jk9nBXEFQ @ 04:26、@ 04:33）。能量会消失，没队友时只能平 A 敌方单位或重放一技能刷新（@ 04:47）
2. **能量的作用**：平 A 加伤害；四层能量可以多放一次二技能，五层能量可以多放一次大招（@ 05:21）
3. **伤害核心是二技能不是大招**：不管有没有装备，二技能伤害都比大招高，还有回复（@ 05:29）。刺客形态"核心就是二技能，大招只是用来辅助的"（@ 04:01）
4. **一技能回血是坦度来源**：中单狂暴流里"一个二技能回 300 多，一个一技能回 700，加上技能吸血，完全是个坦克"（BV1GW421d7bj @ 00:59）；一技能靠近小兵一起吸可以多两个能量（@ 03:47）
5. **大招二阶爆发**：对面没位移时直接刷二阶大招，"满血墨子一套三秒钟直接秒"（@ 05:55）

## 2. 对线：开局装与抢线公式（中单形态）

- **开局选生命装 + 匕首，预购攻速鞋**——提升一级对拼抢线能力（BV1GW421d7bj @ 01:40）。法穿是三件开局装备里收益最低的，因为前期没魔抗（@ 01:29）
- **第一波线见人开狂暴清线**，用补刀键锁兵，被打了狂暴吸血吸回来（@ 01:46）；但对线周瑜、猫咪不能这么抢，抢不过还容易被反杀（@ 01:59）
- **有线权直接二级支援发育路**：这个版本取消河蟹后，第一波线权的中单都很强（@ 02:06）
- **第二波线可以放**：协助射手吃完红隼和兵线，让打野补中，再带辅助回红区，之后一起去对抗路抢四级传送阵（@ 02:31）
- **打野形态**：26 秒存一技能，和中单站一起多一层能量；能量尽量用在强化普攻上，刷野效率高（BV1Lb421n7P8 @ 00:24）；建议对抗路开，2 分钟能刷回上路（@ 00:41）

## 3. 连招

| 场景 | 连招 | 依据 |
|---|---|---|
| 中单先手 | **狂暴 + 大招接双二控制** | BV1GW421d7bj @ 03:26 |
| 中路蹲草消耗 | **一技能吸被动 → 双二接大招**，打掉半血 | BV1GW421d7bj @ 03:50 |
| 支援抓人 | **双二起手**（前期主要输出就是双二 + 平 A） | BV1GW421d7bj @ 02:24 |
| 刺客进场 | **二三大突进 → 强化二技能打后排**，第一个二技能可以空掉 | BV1jk9nBXEFQ @ 09:59 |
| 刺客拉扯 | 打完一套**等一技能能量再上**，打两套而不是一套 | BV1jk9nBXEFQ @ 04:15 |

> 刺客形态细节：二技能连打三下过程中除非目标消失/你用大招/被压制，否则不会被打断（BV1jk9nBXEFQ @ 05:47）；二技能有略微击退，贴野怪往墙外放可以隔墙打蓝（@ 06:31）；想释放流畅只能**滑动**二技能，点击、加移动键、点平 A 都会卡顿（@ 07:03）。

## 4. 中后期/节奏

- **中期公式**：有线权就找资源控；打野吃中时跟着打野吃野区，加快出野区速度（BV1GW421d7bj @ 07:10）；2 分钟后有线权往发育路支援（@ 07:42）
- **打团公式**：开大攒好被动往前滋就行，"打团是很无脑的，非常不需要手"（@ 06:10）；有抵抗鞋 + 狂暴，对面攻不动你，这个英雄"就相当于是一个有伤害有控制的前排"（@ 04:22）
- **坦度里程碑**：8 分钟 8000 血，"其他中单想都不敢想的坦度"（@ 05:18）；狂暴一开满血就是斩杀线（@ 09:06）
- **强度边界**：综合性能比狂暴婉儿强（有控制、能持续输出），但上限没婉儿高（@ 06:26）；怕多突进阵容，"面对多突进阵容基本上没有任何反打能力"（@ 00:24）

## 5. 出装铭文（中单狂暴流，BV1GW421d7bj）

- **铭文**：正常法师百穿穿透（@ 08:27）；**召唤师技能必带狂暴**，否则伤害吸血都不够（@ 08:31）
- **顺序**：生命装出门 → 匕首 + 攻速鞋 → 换法穿鞋 → 血书（拉满狂暴收益）→ 破茧之甲（5000 块吃满全部属性）→ **换鞋 CD 好了法穿鞋换回抵抗鞋**（不缺输出了，260 穿透下 C 位出不了魔抗）→ 时之预言 → 帽子（法术加成高收益大）→ 最后一件：对面魔抗低就穿透武器 + 回响/梦魇，魔抗高就双穿（@ 08:36–09:40）
- **打野/刺客形态**：野刀 → 鞋（控多抵抗鞋、正常冷却鞋）→ 不先做黑切先做三级野刀 → 黑切 → 苍穹（做完苍穹必须换抵抗鞋）→ 反甲 → 破军/魔女；第五件必做肉（BV1jk9nBXEFQ @ 01:41–03:28）；铭文常规隐匿百穿带一个红月（@ 03:55）。顺风能做破军就做破军（@ 01:31）
