# A 类：英雄教学

## 这一类回答什么

**"这个英雄怎么玩"**——只讲英雄本身，不涉及具体对手。

一个英雄卡要能回答四个问题，顺序不能乱：

1. **他靠什么强**（机制，不是数值）
2. **这个机制怎么用出来**（连招顺序，是顺序不是技巧清单）
3. **什么时候强、什么时候废**（强势期 / 弱势期）
4. **新手最容易在哪一步崩**（挂在具体节点上，不单列）

## 不写什么

- 不写"出装铭文三套方案"——那是配置，不是判断。
- 不写"这个英雄很强"——必须写成"在什么条件下强"。
- 不写对面是谁——那是 B 类。
- **不写换英雄照样成立的判断**——那是分路（L 类）或全局（D 类），见下。

## 分路归属（每张卡只留"这个英雄有什么不同"）

英雄卡标题里带分路，站点据此把英雄挂到对应分路页。**同一个结论如果在五个同类英雄身上都成立，它就不该在英雄卡里。**

判定方法：

```
这条结论换一个英雄还成立吗？
├─ 不成立 → 留在英雄卡（A 类）
└─ 成立
   ├─ 只对某个位置成立 → 提到 L 类对应分路
   └─ 五路都成立        → 提到 D 类底层判据
```
