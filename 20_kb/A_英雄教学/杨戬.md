# 杨戬：一技能咬住就走不掉，法相结束才是真疲软期

> 只讲英雄本身。分路思路见 `L_分路` 对应篇。
> 素材：5 条——老版核心技巧+对线出装（BV17v4y1w7Hw）、新版机制拆解两份（阿泽 BV1CQM2zkEKr、公瑾 BV1HKMgzBEDS）、对抗路实战（劳波 BV1HUcMz1EbY）、打野巅峰第一视角（BV1a26pBDE3J）。

## 1. 机制内核

1. **一技能是"放狗"，核心是标记加位移**：狗命中目标后可以再点一次位移过去，额外打出目标已损失生命 16% 的伤害，性质接近斩杀；如果这一下直接击败目标，一技能瞬间刷新（BV17v4y1w7Hw @ 00:19、BV17v4y1w7Hw @ 00:26、BV17v4y1w7Hw @ 00:30）。
2. **二段位移固定落到敌人身后**：这是双刃剑，能躲夏侯惇一技能、吕布的技能，也能在敌人贴墙时直接穿到墙后（BV17v4y1w7Hw @ 01:35、BV1CQM2zkEKr @ 06:50、BV1HKMgzBEDS @ 00:51）；代价是一二技能一起抢很容易空二（BV17v4y1w7Hw @ 01:39）。
3. **新版一技能补了容错**：狗空了也会在终点范围内自动追踪索敌，附近没目标还能把狗捡回来返还 50% CD（BV1CQM2zkEKr @ 04:45、BV1CQM2zkEKr @ 04:51）。老版没有这条，BV17v4y1w7Hw 里"一技能丢不准"只能靠秒点两下自动锁定解决（BV17v4y1w7Hw @ 00:42、BV17v4y1w7Hw @ 06:16）。
4. **一技能是视野工具**：标记敌人后五秒内都有视野（BV17v4y1w7Hw @ 01:32）；新版哮天犬本身就能给视野，但狗的边缘闻不到草，探草必须把最末端的箭头放进草里（BV1HKMgzBEDS @ 00:39、BV1HKMgzBEDS @ 00:45）；咬住后还能继续获得三秒视野，并起破隐效果，兰陵王也没法继续隐身（BV1CQM2zkEKr @ 05:03、BV1CQM2zkEKr @ 05:09）。
5. **二技能是"附魔+眩晕"**：砍一下造成伤害并眩晕减速，之后五秒内普攻带真实伤害，作用类似吕布一技能附魔（BV17v4y1w7Hw @ 01:50、BV17v4y1w7Hw @ 01:55）。命中野怪小兵同样附魔，且真伤对防御塔生效，所以推塔前先用二技能刮小兵（BV1HKMgzBEDS @ 01:23、BV1HKMgzBEDS @ 01:28）。
6. **二技能判定是半圆，侧放比正放远**：正着放打不到的人，侧着放就能打到（BV17v4y1w7Hw @ 02:03、BV1HKMgzBEDS @ 01:08）；新版还多一段身后判定，左边侧刮比右边更远（BV1CQM2zkEKr @ 06:02、BV1CQM2zkEKr @ 06:15）。
7. **二技能可二闪**：正向二闪吃手速，打不出来就用反向二闪，手指离闪现更近、拖动更快，成功率更高（BV1CQM2zkEKr @ 06:18、BV1CQM2zkEKr @ 06:30）。
8. **大招三段激光**：造成伤害并回血；老版口径是"加强后恢复效果非常可观，后期 CD 非常短"，可以直接当回血技能用、不要吝啬（BV17v4y1w7Hw @ 02:42、BV17v4y1w7Hw @ 02:48、BV17v4y1w7Hw @ 02:52）。新版大招看着细实际范围很大，偏得离谱也能中，前两道射线还能判定身后目标（BV1CQM2zkEKr @ 04:16、BV1CQM2zkEKr @ 04:23）。
9. **新版被动是一根韧性白条**：叠满共 90 层，自身进入霸体；此时攻击或被攻击都能变身法天象地，韧性上限突破到 90%，90 层持续 9 秒（BV1CQM2zkEKr @ 00:25、BV1CQM2zkEKr @ 00:38、BV1CQM2zkEKr @ 00:42）。
10. **抵抗鞋是"用 2.5 秒换更早免疫"**：不出抵抗鞋，90 层掉到 0 才停止变身，共 9 秒；出了抵抗鞋掉到 25 就停，只剩 6.5 秒（BV1CQM2zkEKr @ 00:48、BV1CQM2zkEKr @ 00:53）。但抵抗鞋自带 25 层，等于起手就 25，能更早吃到 70 层那段的免控（BV1CQM2zkEKr @ 01:13、BV1CQM2zkEKr @ 01:16）；公瑾的结论是这 25 层在中后期打团很关键（BV1HKMgzBEDS @ 03:14）。
11. **新版天眼是第五个技能**：技能命中叠层、最多三层，拉开小圈外自动发射激光，造成远程伤害并回血；先放二技能附魔，激光就变真实伤害（BV1CQM2zkEKr @ 02:50、BV1CQM2zkEKr @ 03:00、BV1HKMgzBEDS @ 01:45）。天眼层数没有时间限制，击杀圈内目标后层数完整保留（BV1CQM2zkEKr @ 03:10、BV1CQM2zkEKr @ 03:13）。
12. **被动叠满会强制变大，反而是负资产**：叠满后攻击英雄或吃到对方技能都会直接变大，鲁班二技能、瑶一技能这类远程技能也会触发（BV1HKMgzBEDS @ 02:34、BV1HKMgzBEDS @ 02:39）；所以开团前韧性最好只叠到 80 左右，让控制"打在身上跟没有一样"，同时保留随时变身的余地（BV1HKMgzBEDS @ 02:45、BV1HKMgzBEDS @ 02:49）。
13. **变身后一技能变慢**：新版变身后一技能施法时间大大延长，对面可以直接用位移躲掉（BV1HKMgzBEDS @ 01:00、BV1HKMgzBEDS @ 01:04）。

## 2. 对线 / 打法

- **一级先买护手、别掉状态**：开局布甲或铁剑看对位，一级先预购荆棘护手，到线上看敌方意图再补铁剑或布甲（BV1HUcMz1EbY @ 00:40、BV1HUcMz1EbY @ 01:03）；"一级切记不能掉太多状态，不然你四级前就没有对抗性了"（BV1HUcMz1EbY @ 01:11）。
- **一级抢线要抢后排兵**：带斩杀直接铁剑出门、预购三把铁剑，上线先清后排兵，清线速度比吕布快（BV17v4y1w7Hw @ 03:41、BV17v4y1w7Hw @ 03:44、BV17v4y1w7Hw @ 03:45）。
- **带惩戒就二技能起手升级**：铁剑出门，到线上直接二技能加惩戒迅速升二级，二级后过来跟对面打、不断压血线（BV17v4y1w7Hw @ 03:13、BV17v4y1w7Hw @ 03:16、BV17v4y1w7Hw @ 03:21）。
- **拿小兵当跳板**：对线时把一技能丢到对面小兵身上，借小兵位移接近英雄，这是杨戬对线的基本操作（BV17v4y1w7Hw @ 01:20、BV17v4y1w7Hw @ 01:25）。
- **先 A 后 E 取消后摇**：直接丢一技能再冲过去，武器会往前举一下、后摇明显，对面交闪就跑了；先普攻再放一技能，只挥一次武器，普攻命中且目标带标记（BV17v4y1w7Hw @ 00:52、BV17v4y1w7Hw @ 01:06、BV17v4y1w7Hw @ 01:10）。新版叫"无缝卡A"，原理相同，A 和 E 伤害独立计算、不会吞伤害（BV1CQM2zkEKr @ 05:26、BV1CQM2zkEKr @ 05:33）。
- **二技能起手最稳**："一般我都建议二技能起手，毕竟晕住敌人才能保障后续连招稳定打上去"（BV17v4y1w7Hw @ 02:15、BV17v4y1w7Hw @ 02:17）。
- **打站边直接硬刚**：对线吕布、老夫子、达摩这类站边，预购三把铁剑出门，鞋子不要急着出，先陨星加荆棘护手，操作没问题对线打不过你（BV17v4y1w7Hw @ 05:05、BV17v4y1w7Hw @ 05:09、BV17v4y1w7Hw @ 05:12、BV17v4y1w7Hw @ 05:16）。
- **打强战边先出肉再换血**：对面是木兰、孙策、夏洛特这种强战边，先荆棘护手再布甲鞋，利用二技能真伤换血等打野来抓（BV17v4y1w7Hw @ 04:12、BV17v4y1w7Hw @ 04:35、BV17v4y1w7Hw @ 04:38）。
- **打曹操这类要卡距离**：一级学一技能保持距离，不让他连人带兵一起打；一级赚到血量优势、对面下波不吃血包，就有很大机会二级单杀（BV1HUcMz1EbY @ 00:42、BV1HUcMz1EbY @ 00:46、BV1HUcMz1EbY @ 01:02）。
- **四级单挑一般、打小团很强**："杨戬四级这一波或许单挑能力不是很强，但是打这种小规模团战非常给力"，前期中野差距不大就建议四级打一波（BV1HUcMz1EbY @ 02:02、BV1HUcMz1EbY @ 02:06、BV1HUcMz1EbY @ 02:12）。
- **4 分钟龙团抓"对面交了关键技能"**：记到他刚把被动和一技能都交了，就大招连人带兵一起吸，利用一技能 CD 空档先挂二狗、顺便打开法天象地，等他交完一技能再闪现接哮天犬（BV1HUcMz1EbY @ 02:20、BV1HUcMz1EbY @ 02:24、BV1HUcMz1EbY @ 02:28、BV1HUcMz1EbY @ 02:36）。
- **对面没技能就主动摇人**：曹操没大没闪时点集合把人摇下来，别"要么当 M 闷着不说话，要么只会跟着队友混节奏"（BV1HUcMz1EbY @ 03:41、BV1HUcMz1EbY @ 03:47、BV1HUcMz1EbY @ 03:58）。
- **逆风龙团先清高地线**："二塔线可以不管，但是高地线一定要清"，不做豪赌（BV1HUcMz1EbY @ 06:26、BV1HUcMz1EbY @ 06:29、BV1HUcMz1EbY @ 06:32）。
- **打野开局先算野区攻防**：对面是宫本这种吃节奏的战士打野，通常八路开速刷抓边，可以出其不意直接反他的对抗路野区，但被看到就有被包的风险（BV1a26pBDE3J @ 00:19、BV1a26pBDE3J @ 00:37、BV1a26pBDE3J @ 00:44）。
- **90% 对局可以边路开**：杨戬前期强度高且依赖打架，速刷到四级抓边，拿一分钟河灵后用传送阵先抢边线、再传到别的路吃双线（BV1a26pBDE3J @ 00:56、BV1a26pBDE3J @ 01:00、BV1a26pBDE3J @ 01:09）。
- **抓完人别蹭线**：蹭线的同时会暴露视野，等于告诉对面"我两片野区都没刷，快点过来进我野区"（BV1a26pBDE3J @ 03:53、BV1a26pBDE3J @ 03:56）。
- **打野的活儿就是切后排**：只要能把对面后排切掉就完成任务，对面前排留给队友互殴（BV17v4y1w7Hw @ 08:06、BV17v4y1w7Hw @ 08:09）。
- **法相一结束就别接团**：这时候韧性归零，容易低估对面的爆发被反杀；韧性进度条有一半以上才适合打（BV1a26pBDE3J @ 08:02、BV1a26pBDE3J @ 08:16、BV1a26pBDE3J @ 08:19）。

## 4. 中后期 / 节奏

- **法相结束=疲软期**："如果法相刚刚好结束，就是杨戬的疲软期，这个时候最好就不要打了"（BV1a26pBDE3J @ 08:15、BV1a26pBDE3J @ 08:18）。
- **8 分钟龙团必须接**：视野被压缩也要抓这种打架节奏；接不住就撤，打野不能跟着一起掉点（BV1a26pBDE3J @ 08:22、BV1a26pBDE3J @ 08:26、BV1a26pBDE3J @ 08:41、BV1a26pBDE3J @ 08:43）。
- **逆风 10 分钟换资源**：黑豹难抢就往上路换龙、顺便拿蓝；抗性装出得多 CD 不够，不先拿蓝等会打团不好打（BV1a26pBDE3J @ 09:04、BV1a26pBDE3J @ 09:10、BV1a26pBDE3J @ 09:17、BV1a26pBDE3J @ 09:20）。
- **有优势先黑豹再拔塔**：先拿黑豹增加机动性和伤害，再把外塔尽可能拔掉（BV1a26pBDE3J @ 10:04、BV1a26pBDE3J @ 10:06、BV1a26pBDE3J @ 10:09）。
- **打团打完就往后拉**：技能打完不要站着，往后拉扯等下一波；可以用残血勾引，放狗瞬秒后再拿尸体当踏板摸另一个后排（BV1a26pBDE3J @ 11:04、BV1a26pBDE3J @ 11:08、BV1a26pBDE3J @ 11:21、BV1a26pBDE3J @ 11:24）。
- **绕后要开口**：有绕后位必须跟队友交流，不然"高分段以下很难有人会注意你的位置"（BV1HUcMz1EbY @ 06:42、BV1HUcMz1EbY @ 06:47）。
- **对抗路逆风先保经济**：保证自己经济不落后，再找机会翻盘（BV1HUcMz1EbY @ 04:45）。
