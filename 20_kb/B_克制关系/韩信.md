# 韩信（打野）：克谁、怕谁

> 英雄本身怎么玩看 `A_英雄教学/韩信.md`。

### K-B11 对刘备：前期一点优势都没有（数值 + 节奏双输）

- **适用版本**：S45
- **针对对手**：刘备（前期强势野核）
- **克制层级**：**数值克 + 节奏克**（两者同时成立，所以最难受）
  - 数值上：**伤害没有他高**
  - 节奏上：**抓人没有他强**
- **我该怎么做**：**换半区**，不是"小心点"。他去下路，我就去上路；离他远一点，不正面交战
- **反向反制**：韩信的优势是位移次数和野区穿梭。所以正确的打法不是"打赢他"，是**在他在的地方不去，在不在的地方吃满**——他清野慢、位移差，越到中后期越追不上你
- **同类的还有**：兰陵王这类前期强势打野，处理方式一样（BV1jd4y1373j @ 00:49）
- **来源**：BV1jd4y1373j @ 00:31、@ 00:49
- **可信度**：高（两个 UP 独立说到"韩信的伤害没到、结果输了，但思路是对的"这类对位感受）
- **状态**：active

### K-B12 被马超打：他专打「脱节的人」，所以你不脱节他就没法打

- **适用版本**：S45
- **针对对手**：马超（打野）
- **克制层级**：**机制克**——克的是"韩信喜欢单走"这个习惯，不是克韩信这个英雄
- **为什么成立**：马超的打架优势是**找脱节的能力非常强**。原话："我们只要看谁脱节就打谁，**千万不要去打对面没脱节的人**。对面没脱节，就意味着你是一打二或一打三。"（BV1tPbk6rEVH @ 00:50、@ 01:03）
- **我该怎么做**：
  - **不单走**：韩信吃野时离队友/塔近一点，脱节的窗口就没了
  - **他来找你时不要接**：马超的强势是**一对一**，所以只要你不是一个人，他就不会来
  - 反过来讲：**韩信的一对一不占优，二对二更不占优**（@ 01:16），所以你的赢法只有"不给他一对一的机会"
- **反向反制（马超视角的软肋）**：马超**必须先占住视野**才有优先动手权（@ 00:35）。所以韩信可以靠"不让他看见"来拖——但这是被动打法，等于放弃节奏
- **推广**：这条是本库少见的"**克制的是行为，不是英雄**"的案例。判断自己被不被克时，先问一句：他克的是我的数值，还是我的习惯？
- **来源**：BV1tPbk6rEVH @ 00:35、@ 00:50、@ 01:03、@ 01:16
- **可信度**：中高（单来源，但讲的是机制不是数值，稳定性好）
- **状态**：active
