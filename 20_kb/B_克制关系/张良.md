# 张良（游走）：克谁、怕谁

> 英雄本身怎么玩看 `A_英雄教学/`；这张卡只回答"对谁成立、为什么成立"。
> 素材：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）。

### K-B06 对廉颇：机制克——全游戏只有"压制"能断霸体

- **适用版本**：S45
- **针对对手**：廉颇（全身霸体，靠霸体顶控开团）
- **克制层级**：**机制克**（最稳的一层，改数值也不变）
- **我该怎么做**：廉颇**第三段击飞出来之前**把大捏住。捏住之后他的大招直接废，整套开团链断在第一段。
- **反向反制**：廉颇可以故意**拖时间不交第三段**，等你大交出去再开；也可以用位移把战场带走，让捏不到人。所以你捏的时机不是"看见他就捏"，而是"数到他要起第三段的那一下"。
- **为什么是机制克**：霸体挡控制是靠"免疫控制"这条规则，而"压制"是唯一不被这条规则豁免的控制类型。这是规则层的克制，不是数值层的。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：高（规则层判断，与版本无关）
- **状态**：active

### K-B07 张良被谁克：拆火、破隐、以及"让你捏死一条命不成立"

- **适用版本**：S45
- **针对对手**：阿古朵 / 武则天（强拆火）、鬼谷子（隐身接近）、太乙真人 / 复活甲（第二条命）
- **克制层级**：
  - 拆火 → **机制克**：你的大是"持续压制"，能被拆火打断，这是技能类型决定的
  - 鬼谷子 → **机制克**：隐身接近时你**捏不住**（看不到就没法指向），而且他大招破隐的视野会直接消解你"藏视野抓边"的威慑
  - 太乙/复活甲 → **机制克**：你的价值是"捏死一个人"，他的价值是"这条命不算数"
- **我该怎么做**：
  - 对面有强拆火 → **别把大当开团用**，改成"队友已经贴上去之后再捏"，让他拆不过来的那一秒
  - 对面有鬼谷子 → 别单独去边路藏视野，跟一个能反视野的队友
  - 对面有太乙/已经出复活甲 → 优先捏**没复活的那个**，或者捏完立刻撤，别在原地等
- **反例**：「张良是万能抓人点」——上面三种对手，任何一种都让你的核心动作直接作废。这是**被克得最彻底的一类**：不是打得难受，是**功能被删掉**。
- **推广**：判断自己被不被克，问一句"我的核心动作在对面这套阵容下还能不能做出来"。做不出来就是机制克。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active
