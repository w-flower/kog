# 苏烈：克谁、怕谁

> 英雄本身怎么玩看 `A_英雄教学/苏烈.md`。

### K-B01 对孙策：机制克——二技能能挡下他的船

- **适用版本**：S45
- **针对对手**：孙策（开大冲脸）
- **克制层级**：**机制克**
- **我该怎么做**：孙策开大的一瞬间，把二技能放在**他和自家 C 位之间**，用身位当墙。挡下来之后不要追，退回 C 位旁边。
- **反向反制**：孙策可以等你二技能交完再开船；所以**二技能不要提前交在别的地方**。
- **来源**：BV1yke26fEYB @ 03:48
- **可信度**：中（单来源实战解说）
- **状态**：active

### K-B02 对云缨：她的霸体期间你什么都做不了，等结束再推

- **适用版本**：S45
- **针对对手**：云缨（大招霸体）
- **克制层级**：**机制克（反向）**——这条是**苏烈被克**，不是克别人
- **我该怎么做**：云缨开大期间不要试图控制她，**等霸体结束**再往队友方向推。
- **反例**：「我是硬辅，控住就行」——霸体期间控制无效，你的三棍和大招全部白交，还把自己留在她身边。
- **来源**：BV1yke26fEYB @ 04:55；BV1yke26fEYB @ 04:57
- **可信度**：中高（解说里明确说了"他的大招有霸体，插不了火，等他结束往宫本那边推"）
- **状态**：active
