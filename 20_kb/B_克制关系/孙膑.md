# 孙膑（游走）：克谁、怕谁

### K-B10 被老夫子克：大闪捆五秒，二技能的拉扯价值直接归零

- **适用版本**：S45
- **针对对手**：老夫子（大闪捆人）
- **克制层级**：**机制克**
- **为什么成立**：孙膑的全部价值在"二技能让队伍拉开、再回来"——这是**运动战**打法。老夫子的大闪把一个人钉在地上五秒，运动战直接变成"定点挨打"，你的加速和回血全都用不上，因为你的人根本动不了。
- **我该怎么做**：
  - 站位**不要和自己的 C 位挤在一起**，否则老夫子一个大闪捆两个
  - 二技能在**他起手之前**就要开（预判），捆住之后再开已经晚了
  - 队友被捆时，你的作用是**把其他人拉走**，不是去救被捆的那个
- **反向反制**：孙膑可以靠**移速优势让老夫子摸不到人**（这就是为什么这条克制在高分段成立度会下降——会玩的孙膑不会被单点捆到）。属于"操作能削弱但机制上仍吃亏"的一类。
- **同类的次级克制**：金蝉理论能克孙膑，但**一技能飘到人身上要时间**，实际弱得多 —— 这条被 UP 明确降级，记在这里是为了说明"理论克制"和"实际克制"的差距。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active
