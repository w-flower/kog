# 04 分路推荐与克制选人

> 素材说明：四份素材里，只有两份能用。

> 3. **BV1Tqx76wE7c**，小弯为所欲为《完美克制老夫子》。**素材失效**：标题写的是老夫子克制，字幕全文是闽菜探店加猜价格，正文里"老夫子"出现 0 次。本卡未采用，也不代为补写。
> 4. **BV1PxxT6fErn**，青云ovq《粉丝对位1w9打野复盘》。**素材失效**：标题写的是打野对位复盘，字幕全文是试驾小米 SU7 的 vlog，没有任何一局对位内容。本卡未采用。
>
> 以上全部是**个人经验与单局复盘，不是官方数据**。所有胜率、禁用率都是 UP 口播或引用，没有口径、没有日期、没有样本量。本卡把它们当"方向"用，不当"结论"用。凡是"谁强、谁值得抢"的判断，可信度一律压低，并在条目里写明来源性质。
>
> 用法：判断顺序是从"你在哪个分段"往下推，不是从"谁是 T1"往下抄。

## 判断顺序

```
第 1 步  先锁分段，再念英雄名            → K-C11（两段胜率差 > 5 个点是分段特化，不是强弱）
第 2 步  分清"必抢"和"补位"              → K-C15（能"放出来就抢"的只有盾山这类，抢不到才是常态）
第 3 步  打野位先数对面前期强度点          → K-C14（中路没线权、辅助不跟，就别一抢老虎）
第 4 步  对抗路先划雷区，再挑容错型        → K-C12 → K-C13（名单缺失时退回"容错率"这一层）
第 5 步  要打克制，先问 BP 上克不克得动    → K-C16（大乔：克在"能不能开到她"，不在"选谁"）
第 6 步  把同一套克制换成分段收益          → K-C17（哪吒在低分段是克制，在高分段是配合）
第 7 步  最后过一遍榜单可信度              → K-C20 → K-C18 / K-C19（先问"谁在玩"，再问"适不适配"）
```

### K-C11 先定分段再定英雄：同一个英雄两个分段差 5 个点以上，就不是强弱问题而是适配问题

- **适用版本**：S45
- **触发条件**：你在选人时想"这个英雄到底强不强"，但还没确认这一局的实际分段
- **判断依据**：素材给每个英雄都报了两个数——"顶端巅峰赛胜率"和"全分段胜率"。**两个数的差值比数值本身信息量更大**：差值小说明英雄机制在全段位都站得住，差值大说明它的强度依赖特定分段的对局质量（@ 03:10）（@ 04:48）（@ 07:02）（@ 10:14）（@ 10:52）
- **决策分支**：
  - 两段差 < 2 个点且口径一致（影 49/51、小乔 48/48）→ 全段位可用，谁拿都不容易崩，可以放心当补位选择
  - 全分段明显高于顶端（赵云 48/54、哪吒 49/52）→ 低分段特化。素材对赵云的表述是"巅峰赛 1800 分以下，或者你想排位上分，强烈建议你玩赵云"（@ 10:56）
  - 顶端明显高于全分段（孙尚香 54/46、公孙离 51/42、关羽 52/46、裴擒虎 50/44）→ 高端局特化。低分段拿等于自己放弃数值
- **反例**：看到"孙尚香巅峰赛胜率 54%"就在低分段一手锁。素材同一条里的后半句是"全分段胜率只有 46%"（@ 04:51），UP 自己的解释是"高手和新手的差距"（@ 04:53）。同一段话里两个数，只抄对自己有利的那个，就是拿榜单骗自己。
- **来源**：BV1nPJk6uEiN @ 03:10
- **可信度**：低。单源个人经验；两段胜率均无统计口径、无日期、无样本量，UP 也没说明"顶端"具体是多少分以上。本条只用"差值方向"，不用绝对值。
- **状态**：draft

### K-C12 对抗路先用排除法划雷区，再谈选谁——但"四七兄弟"的名单素材里没有

- **适用版本**：S45
- **触发条件**：你在补对抗路，还没有明确人选，手上只有一份"推荐榜"
- **判断依据**：素材开口第一句不是排名，是排除法——"对抗路四七兄弟大家都听说过吗，只要你不玩这四个英雄呀，剩下的都挺好上分的"（@ 00:03），讲完这句才开始排第六到第一。也就是说它的推荐结构是**先划雷区、再排序**，不是"从上往下抄"。
- **决策分支**：
  - 你自己分段打过、心里有四七兄弟的名单 → 先划掉，剩下的按 K-C11 的分段适配挑
  - 你没有这份名单 → 这条对你只有方法没有内容，直接退回 K-C13，用"容错率"这一层挑
  - 看到榜单序号就当强度序 → 错，见反例
- **反例**：把"第六名到第一名"当成"从弱到强"的梯度。曹操排第六，却是 UP 第一个讲的（@ 00:08）；关羽排第一，同时是全分段胜率最低的 46%（@ 03:13）。他的序号是**上分推荐序**，不是强度序——第一名是最"吃队友"的那个，不是最"强"的那个。
- **来源**：BV1nPJk6uEiN @ 00:03
- **可信度**：低。单源个人经验，且**关键名单缺失**：素材全文只提了"四七兄弟"这个名字，从头到尾没说是哪四个英雄。本条只能给方法，不能给名单，不要自行补全。
- **状态**：draft

### K-C13 对抗路优先选"容错型"而不是"上限型"：打不过也不会崩，比打得过更重要

- **适用版本**：S45
- **触发条件**：对抗路候选里同时有吃手法的（司空震）和不怎么吃手法的（亚瑟、影、曹操）
- **判断依据**：素材给这几个人的推荐理由，全部落在"容错"上，而不是伤害上：
  - 曹操的抓手是新召唤师技能位移远、"卡墙位移的话更远"，能切到对面 C 位（@ 00:15）（@ 00:22）
  - 亚瑟"舍弃传统的暗影战斧，出装就出纯肉装……照样有伤害，而且容错还很高"（@ 00:44）
  - 影"大招自带复活甲，容错直接拉满了"（@ 02:11）
  - 司空震被单独挑出来说"胜率就没这么高了，主要是玩的人太多了，但水平参差不齐"，会玩的才在线上打出优势（@ 02:25）（@ 02:29）
- **决策分支**：
  - 你要稳一手、不想被单杀滚雪球 → 亚瑟 / 影。素材对亚瑟补了一句"用亚瑟上个 1800 分是绝对没有问题的"（@ 01:35）
  - 对面 C 位在后排、需要越墙才能摸到 → 曹操 + 悟行千山，"卡墙位移的话更远"，容易切到对面 C 位（@ 00:22）（@ 00:24）
  - 你有手法、就是要线上压制 → 司空震，远程普攻消耗 + 找时机单杀（@ 02:29）
  - 你选亚瑟但准备待在线上对线 → 错，素材明确说"亚瑟的精髓就是一定要多游走，往往你在线上是打不出什么优势的"（@ 00:49）（@ 00:53）
- **反例**：把"胜率高"当选人唯一标准。司空震顶端 49%、全分段 48%（@ 02:21）（@ 02:23），顶端值和影的 49%（@ 01:57）完全一样，但素材对司空震的评价明显保留——胜率数字没告诉你"是谁在玩这个英雄"。
- **来源**：BV1nPJk6uEiN @ 00:44
- **可信度**：低。单源个人经验；"容错高"是 UP 的主观归类，四件装备/技能的说法没有对局数据支撑。
- **状态**：draft

### K-C14 打野位一抢老虎的前提：对面数不出第二个前期强度点，且中路有线权

- **适用版本**：S45
- **触发条件**：你在高顺位考虑一抢裴擒虎；或对面打野已亮、你在判断要不要拿老虎对位
- **判断依据**：三条约束叠在一起才成立：
  - **曲线**：老虎"前期强、中期偏强、后期弱"（@ 00:57），后期"输出模式单一、团战作用低、带线还容易被抓"（@ 00:53）。所以它必须在前中期换出经济差或资源差，拖后期就是亏
  - **门槛**：能不能反野不看你想不想。"首先看中路有没有线权，再看你辅助的位置，你一个人进去打两个，那肯定是打不过的"（@ 10:31）（@ 10:35）
  - **读法**：顶分局是先"数前期强度点"再定走向——"我们老虎炸弹猫都是前期合（字幕转写如此，语境指前期强），而对面只有一个猪是前期有强度的，这么一整理，我们老虎的前期走向规划就清楚了，以中轴为主抢线打进攻人数差"（@ 01:20）（@ 01:27）（@ 01:29）
- **决策分支**：
  - 己方中路有线权 + 辅助能跟 + 对面前期强度点 ≤ 1 → 可以先抢。开局按素材的顺序走：不拿自己 Buff、卡中左草、抢中线、再反野、然后控边野（@ 01:32）（@ 02:13）
  - 中路是清线慢的法师，或辅助是软辅 → **不先抢**。老虎拿不到野区主动权就是个后期弱的白板
  - 对面已经亮出两个以上前期强势点 → 换人。素材给的替代方向是"全靠数值"的赵云（@ 11:02）
  - 对面缩塔不出来 → 别硬抓，"人抓不到咱就推塔呗，快速拔塔也是老虎的优势之一"（@ 10:42）（@ 10:45）
- **反例**：看视频里老虎反野很顺就跟着入侵。素材自己列了两条前提，还补了"敌方比较聪明猥琐在塔里"这种情况（@ 10:39）——反野是条件成立之后的结果，不是开局动作。条件不成立时一抢老虎，等于把胜负交给对面中路。
- **来源**：BV1ADbL6xEYJ @ 01:20；BV1nPJk6uEiN @ 10:31
- **可信度**：中。两个 UP 各出一份**个人经验**，非官方数据，但两处独立指向同一组约束（中路线权 / 辅助位置 / 前期强度点数量），构成交叉验证；晚风素材是单局复盘（n=1），样本仍不足。
- **状态**：draft

### K-C15 辅助位真正的"克制"在 ban 位：能被放出来就该抢，抢不到才是常态

- **适用版本**：S45
- **触发条件**：BP 阶段，你在辅助位；或对面辅助已亮，你在想要不要找 counter
- **判断依据**：
  - 盾山顶端 55%、全分段 53%（@ 15:16）。素材的评价是"你只要放出来抢到了，那基本上都能稳赢"，紧接着说"唯一的缺点就是不太容易放出来"（@ 15:20）（@ 15:40）
  - 元辅顶端 50%，**禁用率高达 80%**（@ 15:45）（@ 15:47）
  - 元辅那一段的收尾是"我实在想不出来什么英雄可以克制元辅了"（@ 16:12）——这句话本身就是对"靠选人解"的否定
- **决策分支**：
  - 你在 ban 位 → 优先处理这两个。素材给的判断是"放不出来"才是它们真正的限制，不是"打不过"
  - 对面放出来、你先选 → 直接锁，这一手不需要想克制
  - 对面已经锁了盾山 → 别指望用某个英雄反制。素材给的解法是配组合："如果队友再来一个鲁班 7 号，你俩组成僵王博士，那就更好了"（@ 15:25），不是找 counter
  - 你打算用元辅但分段不高 → 先想清楚。素材说"中低分段队友可能不太配合，不容易上分"，段位高一点才知道二技能是干什么的（@ 16:04）（@ 16:09）
- **反例**：在 ban 位纠结"我打不过谁就 ban 谁"，结果把 80% 禁用率的元辅放出来（@ 15:47）。ban 位是选人阶段唯一的确定性手段，把它花在个人对线阴影上，是最贵的一种浪费。
- **来源**：BV1nPJk6uEiN @ 15:40
- **可信度**：低。单源个人经验；"稳赢"是口播夸张词，55% 的胜率不等于稳赢；80% 禁用率没有数据口径和日期。
- **状态**：draft

### K-C16 克制关系怎么用：大乔"怕控制"克的是"能不能开到她"，不是"你选了谁"

- **适用版本**：S45
- **触发条件**：对面已锁大乔，你想在选人阶段拿一手"克她的"；或者你自己要拿大乔，对面有强开团
- **判断依据**：素材里这两句必须一起读，顺序很关键：
  - 先给结论："现在基本上也没什么阵容体系能克制大乔吧"（@ 18:33）
  - 再给机制："其实大乔主要是怕控制，遇到对面有什么苏烈关羽啥的，咱们最好还是带净化"（@ 18:36）（@ 18:38）
  - 最后给后果："不然被对面开到了，根本就没有机会坐天梯回家"（@ 18:41）
  - **克在哪个机制**：断的是**回城 / 传送这个动作**，不是伤害。控制命中 → 大乔被开 → 她坐不了电梯 → 整个运营体系停摆。所以判据是"你的控制能不能落到她身上"，不是"你的伤害够不够"。
- **决策分支**：
  - 你是克方，对面大乔 → 选强开团 + 硬控（素材点名苏烈、关羽），并且**必须确保能开到她**：她站在队伍最后排、或者手里有净化，你这手就是空的
  - 你是大乔方，对面有苏烈 / 关羽 → "最好还是带净化"（@ 18:40）。这是素材给的直接应对，带上净化，这个克制就不成立
  - 你是大乔方，不管对面有没有强开 → 别自己出去带线。"你千万别和玩中路大乔一样，老自己出去带线"（@ 18:44）；跟队友走才有牌（@ 18:40）
  - **失效条件（任一成立，这条克制就没了）**：① 大乔带净化（@ 18:40）；② 你的开团落不到她身上（她站后排 / 你被先手打断）；③ 她不单独行动、始终跟队友抱团——素材说的"只要你一直跟着队友走"（@ 18:40）
- **反例**：以为"选了苏烈就克大乔"，选完就不再管。素材的话序是"没什么体系能克制"在前、"怕控制"在后——它在说：**克制存在于执行层，不存在于阵容层**。你开不到她，克制一点没兑现，你只是多选了个前排。
- **来源**：BV1nPJk6uEiN @ 18:33（同段另见 @ 18:36、@ 18:38、@ 18:40、@ 18:41、@ 18:44）
- **可信度**：中。单源个人经验，但机制链条完整（控制 → 无法回城 → 断运营）、可局内验证，且与"位移/传送类英雄怕硬控"的通用认知一致；没有任何对局数据。
- **状态**：draft

### K-C17 同一套克制，分段不同收益不同：哪吒锁头克的是"没人保的 C 位"，不是"C 位"

- **适用版本**：S45
- **触发条件**：你在低分段对局，对面 C 位没有队友专门保护，你在考虑拿哪吒做强开点
- **判断依据**：素材把哪吒的强弱直接绑在分段上，而不是绑在英雄上："段位越低，玩哪吒越容易上分。因为低段位的一些人，他不知道哪吒该怎么处理，队友也不会保护 C 位，一被哪吒锁头基本上就没了"（@ 02:49）（@ 02:53）（@ 02:57）
- **决策分支**：
  - 低分段 + 对面队友不保 C 位 → 拿。克制点是"锁头强开单点"，对面既没意识也没手段反制
  - 高端局 → 仍然能玩，但**打法必须换**："就是要根据情况释放大招，尽量和队友沟通，发信号一起上，别你一个人冲进去献祭"（@ 03:01）（@ 03:05）。从"单点秒 C"变成"跟队友的第二手进场"
  - 触发失效：对面会保 C 位——素材给低分段的判据是"队友也不会保护 C 位"（@ 02:57），反过来，队友会保，这手锁头就进不去；进去打不死，克制就变成送人头
- **反例**：把低分段的"一锁头就没了"原样搬到高分段。同一个英雄，顶端 49%、全分段 52%（@ 02:45）——差的这 3 个点，就是"对面会不会保 C、你会不会等队友"。
- **来源**：BV1nPJk6uEiN @ 02:49
- **可信度**：低。单源个人经验；"低段位不知道处理"是 UP 的主观判断，没给具体分段区间；胜率无口径。
- **状态**：draft

### K-C18 射手位先看"新召唤师技能适配"，再看英雄本身：黄忠是这一版的直接受益者

- **适用版本**：S45
- **触发条件**：发育路选人，候选里有黄忠这类开大后原地输出、依赖站位的射手，也有孙尚香、公孙离这类自带位移的
- **判断依据**：
