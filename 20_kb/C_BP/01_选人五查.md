# 选人五查

> 素材来源是用户提供的《冲击巅峰千强·辅助篇》整理稿（原视频 BV1ydMZ6bE8n，UP：吾家李世公侯，6 小时 / 44 个分 P）。这是**方法论**，不是版本答案 —— 它不谈"谁强"，只谈"你这套阵容成不成立"，所以跨版本仍然有效。
>
> 用法：五条是**顺序检查**，不是清单。第 1 条不过，后面四条不用看了。

## 判断顺序

```
第 1 关：前排够不够？        → K-C01（≥1 个前排点，0.5+0.5 也算 1）
第 2 关：前期会不会五个人一起弱？→ K-C02（吃钱点已经四个了，就别再来软的）
第 3 关：有没有控？          → K-C03（零控可以六分投；保命技能不算控）
第 4 关：强度在不在 T1？      → K-C04（T2 只在克对面时拿）
第 5 关：你会不会？          → K-C05（所有克制都以熟练度为前提）
```

### K-C01 第一关查前排：软辅能不能选，取决于"0.5 + 0.5 够不够 1"

- **适用版本**：S45（判据本身跨版本）
- **触发条件**：你在四五楼，己方已有边路 + 打野 + 中路
- **判断依据**：把己方所有位置的"前排贡献"加起来，**健康阵容要 ≥ 1 个完整前排点**
- **决策分支**：
  - 边路是木兰（半前排）+ 打野是半肉铠（半前排）→ 0.5 + 0.5 = 1 → **这时才可以上软辅**
  - 边路是元歌这种 0 前排 → 软辅**绝对不能选**，哪怕对面阵容完美契合
  - 己方已有完整前排（张飞/牛魔/夏侯惇）→ 你可以自由选功能辅
- **反例**：「我这把孙膑特别好发挥」——好发挥的前提是有人替你吃第一波伤害。没有前排时，孙膑的二技能拉不出任何空间，因为队伍根本没人能站住。
- **为什么用"点数"而不是"有没有坦克"**：因为半肉战士补一半，两个半肉就等于一个坦。用点数算才不会漏掉「木兰 + 铠」这种看起来没坦其实够用的阵容。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n，BP 分 P）
- **可信度**：中高（UP 个人方法论；"点数相加"的算法是他自己提出的简化，逻辑自洽但无数据支撑）
- **状态**：active

### K-C02 第二关查发育点：辅助不吃钱，但"五个人前期都弱"会直接崩

- **适用版本**：S45
- **触发条件**：己方已选三个以上需要发育/需要等级的英雄
- **判断依据**：己方**吃钱点（需要经济和等级才能发力）的数量**。四个吃钱点已经是上限
- **决策分支**：
  - 已有四个吃钱点 → 你必须选**前期就能打**的（张飞、牛魔、苏烈、东皇）
  - 只有两三个吃钱点 → 可以选孙膑、大乔、明世隐这类"后期放大器"
- **反例**：「辅助又不吃钱，多一个发育点没关系」——辅助确实不吃钱，但辅助也**不产生前期强度**。四个吃钱点 + 一个软辅 = 前期五个人全是弱的，对面打野第一轮进野区就没有人能拦。
- **判据来源**：`K-L11`（游走的产出是人数差）+ 本条。两条合起来说一件事：**软辅的强度是借来的，借的是队友的前期**。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n，BP 分 P）
- **可信度**：中高
- **状态**：active

### K-C03 第三关查控制：零控可以六分投，但"保命技能不算控"

- **适用版本**：S45
- **触发条件**：选人最后一位，己方看起来"有位移有爆发"
- **判断依据**：能不能**主动开团**。区分标准：这个技能能不能"我先手按出去，然后队友跟上"
- **决策分支**：
  - 有硬开团（张飞大招、苏烈大闪、盾山二闪、钟馗勾）→ 合格
  - 只有软控（减速、短眩晕）→ 需要配一个有硬控的边路/打野补
  - 零硬控 → 这局只能打反手，BP 上已经输了半局
- **反例**：「鲁班二闪、虞姬一闪也是控」——这两个是**保命技能**，开不了团。射手和大法师的位移/闪避类技能一律不算控制点，别自我安慰。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n，BP 分 P）
- **可信度**：中高（"保命技能不算控"这个定义是全篇最实用的一句）
- **状态**：active

### K-C04 第四关查强度：T2 只在克对面时拿，T3 除非打战力不碰

- **适用版本**：S45（**每条强度榜必须挂日期，本条只给用法不给名单**）
- **触发条件**：你想玩的英雄不在当前版本强势区
- **判断依据**：T 度分级 + 对手阵容
- **决策分支**：
  - T1 及以上 → 直接玩
  - T2 → **只在明确克制对面某一环时拿**，否则换
  - T3 → 除了打战力/绝活，不碰
- **为什么不放名单**：强度榜 3 周就过时。本库的规矩是「名单类内容必须带统计日期」，所以这里只留判定方法，具体名单看 `90_版本变更台账.md`。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n，BP 分 P）
- **可信度**：中（分级标准是 UP 个人划分，无官方数据）
- **状态**：active

### K-C05 第五关查熟练度：所有克制关系都以"你会不会打"为前提

- **适用版本**：S45
- **触发条件**：你打算靠"克制"来选人
- **判断依据**：这个克制动作需要多长的反应窗口，你练过没有
- **决策分支**：
  - 动作已成本能（盾山二闪、张飞后段喷、钟馗勾前摇）→ 可以用克制关系选人
  - 还需要"在脑子里走一遍先二再闪"→ **这个克制对你不存在**，对面走位失误只有 0.5 秒，想完就没了
- **反例**：把克制表当护身符。表上写"钟馗克墨子"，但你反应不过来墨子二技能的前摇，这条克制就是不成立的 —— 文档里明确写了「这条有分段门槛」。
- **推广**：这一条把 `B_克制关系/` 整类的可信度前提说清楚了：**B 类记录的是"机制上成不成立"，不是"你能不能打出来"**。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n，BP 分 P）
- **可信度**：高（与 B 类 _说明.md 的「机制克 > 数值克 > 节奏克」分层一致）
- **状态**：active

## 这五关的排序为什么不能换

前排决定"你能不能选软辅"，前期强度决定"你会不会被打崩"，控制决定"你能不能主动开团"，强度决定"数值上亏不亏"，熟练度决定"以上四条你能不能兑现"。

前四条是**阵容层面**的，第五条是**人的层面**的。文档把熟练度放最后不是因为它最不重要，而是因为它是**否决权**：前四条全过，第五条不过，照样别选。
