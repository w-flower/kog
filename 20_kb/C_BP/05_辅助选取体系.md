# 05 辅助选取体系

> 素材说明：本卡只有一份素材，而且它**不是一份"辅助怎么选"的榜单**，是一个英雄的完整对局解说。按"能用来回答什么"拆三层：
>
> 1. **BV17hgK6kEas**，益达兄弟《想要上分不吃苦，那就玩九大神辅·第1期》。**单英雄全局解说**：标题挂的是"九大神辅"系列，全片约 15 分钟只完整打了一个英雄（素材里被转写成"原神大人 / 邵思源 / 少司员"，按上下文指同一个英雄），另外八个从头到尾没有点名，只在结尾预告里出现了"张飞"一个名字（@ 15:10）。真正可用的内容是三块：**出装分支**（@ 00:13–@ 00:57）、**开局野区与连体判断**（@ 01:05–@ 03:55）、**中后期的续航与压塔节奏**（@ 05:46–@ 14:11）。
> 2. **需要剔掉的段落**：@ 01:22–@ 02:01 是二手机广告（某回收平台的 iPhone 15 Pro），与选取无关；@ 15:17 之后是收尾口播。本卡未引用这两段作为判断依据。
> 3. **字幕质量**：转写错误密集，正文里按语境做了标注（"强补"当作强普、"前力"当作前期、"新意拳 / 兽拳 / 星拳"当作星泉、"尽会会"当作近卫、"火区"与"青岛"疑为站位/兵线误转）。凡是转写不清、无法还原原词的（例如开局公式"一野二鞭 344 中"@ 01:07），一律不拿来当结论，只进待补。
>
> 以上全部是**个人经验与单局复盘，不是官方数据**。素材没有标版本号、没有报胜率、没有报禁用率、没有说分段，连"九大神辅"的另外八个都不在素材里。所以本卡可信度整体压在"低"；K-C28 专门用来划这条边界：**这一期能教你一个英雄怎么打完整一局，教不了你辅助位怎么排。**
>
> 用法：判断顺序是从"有没有先出权"往下推，不是从"九大神辅是哪九个"往下抄。

## 判断顺序

```
第 1 步  先问放不放得出来，再问强不强            → K-C21（"不看阵容先出"是唯一待遇，不是通例）
第 2 步  选不出就落默认值：无脑近卫保容错          → K-C22（素材给的底座是容错，不是上限）
第 3 步  读双方前期强度，定近卫还是极影            → K-C22（对面前期强→近卫；我方前期强→极影滚雪球）
第 4 步  过一遍法抗与开团需求                    → K-C22 → K-C23（对面法抗多→近卫；要开团或逆风→弃圣杯出冰甲）
第 5 步  看自家打野开哪片，反向决定守哪片          → K-C24（去红守蓝、去蓝守红）
第 6 步  开局站位跟着队友动向改，不背固定点        → K-C24（素材自评"强普清线"是错误示范）
第 7 步  看自家法师吃不吃线权，决定连体还是中轴     → K-C25（吃线权的中法→压中轴，别无脑连体）
第 8 步  看这套阵容要不要"能回满再压"的续航        → K-C26 → K-C27（续航换压塔窗口；被动经济已不是卖点）
第 9 步  最后检查素材边界，别当九大神辅名单用      → K-C28（本期只覆盖一个英雄）
```

### K-C21 辅助位真正的"先出权"只有一个：放得出来 + 不吃阵容 + 版本仍在，三条同时成立才一抢

- **适用版本**：S45（素材未标版本，本条不主张它在 S45 仍成立，见可信度）
- **触发条件**：你在辅助位且顺位靠前；或你在想"有没有可以不看阵容、直接先手拿的辅助"
- **判断依据**：素材把这个英雄的两个标签分开说——先是"出道即T0、从未跌落神坛的原神大人"（@ 00:04），再是"作为九大神辅里唯一一个可以不看阵容先出的英雄"（@ 00:08）。**"强"和"能先出"在素材里是两句话**。而能不能先出，落点在三件事上：版本强度（"出道即T0"）、不依赖阵容（"不看阵容先出"）、ban 位放行（"只要没人 ban，直接一抢"@ 00:10）（@ 00:11）。
- **决策分支**：
  - 没人 ban + 你不知道辅助位该拿什么 → 一抢。素材给的定位就是"不看阵容"，这一手买的是容错，不是上限（@ 00:12）
  - 被 ban / 被对面先抢 → 这条直接失效。退回 K-C22 按阵容定出装、K-C25 按法师定打法，不要为了"它本来是 T0"去硬找一个替代位
  - 你不确定它在这个版本还成不成立 → 素材没给版本号和任何胜率口径，按 K-C28 的边界处理，别把"从未跌落神坛"当版本结论
- **反例**：把"T0"读成"谁都能不看阵容先出"。素材的原词是"**唯一一个**"（@ 00:08）——它说的是九大神辅里的唯一，不是辅助位的通例。你换个辅助去套"不看阵容先出"，失败的原因不是英雄弱，是你把特例当成了规则。
- **来源**：BV17hgK6kEas @ 00:08（同段 @ 00:04、@ 00:10、@ 00:11）
- **可信度**：低。单源、单英雄、口播；"T0""从未跌落神坛"没有任何胜率、禁用率或分段口径，UP 也没标素材版本。本条只取"先出权 = 强度 + 不吃阵容 + ban 放行"这个结构，不取"它现在还是 T0"这个结论。
- **状态**：draft

### K-C22 辅助装先落近卫，再看两件事决定要不要换极影：对面前期强度、我方前期强度

- **适用版本**：S45（素材未标版本）
- **触发条件**：辅助位已定，进入出装选择，手上只有"近卫圣杯流"和"极影"两套
- **判断依据**：素材把选择压成一个默认值加三条改写条件，顺序很清楚：
  - **默认**："如果你不知道怎么出，那就无脑近卫，搞容错"（@ 00:33）（@ 00:35）（@ 00:36）——近卫是底座，先保证不崩
  - **对面前期强 → 近卫**："这把对面前期强度大于我们阵容，所以我们选择近卫"（@ 00:42）（@ 00:44）
  - **对面法抗多 → 近卫**（@ 00:45）
  - **我方前期强 → 极影滚雪球**："如果是我们前期强，可以选择极影滚雪球"（@ 00:54）（@ 00:55）
  - **极影不能无脑出**："极影也要根据阵容去出"（@ 00:25），前置理由是"自从邵思源偷钱减少后，缩减的争议也降低了"（@ 00:21）（@ 00:23）
- **决策分支**：
  - 读不清对面阵容 / 不知道怎么选 → 近卫，这是素材明写的默认值（@ 00:35）
  - 对面前期强度高于我方 → 近卫（@ 00:44）
  - 对面法抗堆得多 → 近卫（@ 00:45）
  - 我方前期强、想把优势滚起来 → 极影（@ 00:55）
  - 两套之间还有第三条路（开团/逆风）→ 见 K-C23
- **反例**：知道"极影上限高"就每把都先出极影。素材的叙述顺序是**先给默认（无脑近卫）、再给极影的成立条件（我方前期强）**，极影是条件成立后的加速器，不是底座。反过来的错也一样：明明是前期强势阵容，还保守出近卫，等于把滚雪球窗口让掉（@ 00:55）。
- **来源**：BV17hgK6kEas @ 00:35（同段 @ 00:42、@ 00:45、@ 00:55）
- **可信度**：低。单源个人经验，且是单个英雄的装备判断；"对比于无相胜率都是高于他的"（@ 00:19）既没给数字，也没说口径，"无相"疑为转写误差，本条不把它当依据。
- **状态**：draft

### K-C23 圣杯与冰甲是互斥项：阵容要你开团、或者前期已经逆风，就弃圣杯出冰甲

- **适用版本**：S45（素材未标版本）
- **触发条件**：你在"续航装"和"打团装"之间选；或者这局开局已经掉节奏，在想要不要补输出/前排
- **判断依据**：素材把两条路并列给出来，触发条件写得比结论还清楚——"至于下面那一套，是阵容需要你开团，或者你前期逆风的情况，就舍弃圣杯，直接冰甲加强打团能力"（@ 00:47）（@ 00:49）（@ 00:50）（@ 00:51）（@ 00:52）。反过来，留在圣杯路线的隐含前提是：这局不需要你承担开团，而且也没崩。
- **决策分支**：
  - 阵容缺先手 / 你是唯一的开团点 → 冰甲，放弃圣杯（@ 00:49）
  - 前期逆风、续航也守不住塔 → 冰甲，转正面团找翻盘（@ 00:50）（@ 00:52）
  - 顺风、不需要你开团 → 留圣杯路线，续航换成压制窗口（与 K-C26 连读）
- **反例**：逆风了还抱着圣杯刷续航。素材把"前期逆风"直接列成弃圣杯的条件之一（@ 00:50）——逆风时你的问题是打不过正面团，不是蓝不够。用续航去补一个打团问题，方向就错了。
- **来源**：BV17hgK6kEas @ 00:49（同段 @ 00:47、@ 00:50、@ 00:51、@ 00:52）
- **可信度**：低。单源个人经验；冰甲、圣杯的具体属性与收益素材一句没提，只有"加强打团能力"这个方向性说法，也没给"逆风"的判定标准（经济差多少算逆风）。
- **状态**：draft

### K-C24 开局守哪片野是"反向守"：自家打野去哪片，就守另一边；但这条只在"对面打野更强"时被演示过

- **适用版本**：S45（素材未标版本）
- **触发条件**：开局约 30 秒，辅助在决定第一波站哪、要不要进野区
- **判断依据**：素材先问"是否要参与野区的进攻和防守"（@ 01:09），这一局的答案是要，理由是"对面打野是老虎"（@ 01:12）、"这把前期要帮典韦防守野区"（@ 01:14）。具体分工是**反向守**："典韦去红区我们就帮他看蓝，他去蓝区我们就得帮他看红"（@ 01:16）（@ 01:18）。更上一层的方法是"要根据队友的动向去变动"（@ 02:16）。
- **决策分支**：
  - 自家打野前期弱、对面打野前期强（素材对位：典韦 vs 老虎）→ 参与防守，守打野没去的那半边（@ 01:14）（@ 01:16）
  - 自家打野前期强 → 素材没讲要不要反打，别直接照抄"反向守"，进待补
  - 站位一律跟队友动向走；素材自评过一个错误示范："我们强普清线是错误示范……直接站红背占视野才是对的"（@ 02:10）（@ 02:14）
- **反例**：把"正常情况占中右"（@ 02:06）当成固定开局脚本。同一局里打野"选择占中左"（@ 02:09），辅助还按默认点位走，两个人就脱节了。点位是跟着打野动向算出来的，不是背下来的。
- **来源**：BV17hgK6kEas @ 01:16（同段 @ 01:09、@ 01:12、@ 01:14）
- **可信度**：低。单局复盘，n=1；"反向守"只在这一个对位里被演示过，素材没给"什么时候不参与野区""打野本身强势时怎么办"的条件，本条只覆盖防守一侧。
- **状态**：draft

### K-C25 连体还是打中轴，判据是"中路能不能拿到线权"，不是"射手需不需要保"

- **适用版本**：S45（素材未标版本）
- **触发条件**：辅助在决定这局跟射手连体，还是压中轴带节奏；自家中路是吃线权才能起节奏的法师
- **判断依据**：素材的原话把两个条件叠在一起——"下路是李信加上中路是火舞这种法师，对面打野是老虎，95% 的思路是打中轴的，千万不能无脑连体。打中轴，让火舞可以拿到线权，才能发挥火舞的节奏能力"（@ 03:46）（@ 03:49）（@ 03:50）（@ 03:52）（@ 03:53）（@ 03:54）（@ 03:55）。条件①是中法"火舞这种"靠线权起节奏；条件②是发育路能自理——后文印证了这点："李信下路兵线他自己可以快速清掉"（@ 05:00）。
- **决策分支**：
  - 中法吃线权 + 发育路能自己清线 → 打中轴，不连体（@ 03:52）
  - 发育路清不动线、需要人保 → 素材没给这一支，别硬套中轴，进待补
  - 中路是清线慢、不靠线权起节奏的法师 → 素材没给，进待补
- **反例**：把"辅助就该跟射手"当默认。素材在同一局里明确否掉了连体（@ 03:52），理由不是"射手很强"，而是"让火舞拿到线权才能发挥节奏能力"（@ 03:55）。连不连体取决于**谁能把线权换成节奏**，不取决于谁是射手。
- **来源**：BV17hgK6kEas @ 03:50（同段 @ 03:46、@ 03:52、@ 03:55）
- **可信度**：低。单局单英雄；"95% 的思路"是口播估计，没有统计支撑；只演示了"中法吃线权"这一种成立条件，反方向的两种分支素材都没写。
- **状态**：draft

### K-C26 续航型辅助的价值不在治疗量，在"打完一波能回满、立刻能压塔"

- **适用版本**：S45（素材未标版本）
- **触发条件**：你在判断续航型辅助这局值不值；或一波团刚打完，在决定压不压塔
- **判断依据**：素材把续航直接换算成进攻窗口——"我们是少选这种续航型辅助，打完一波状态可以回满，是可以尝试压塔的"（@ 11:44）（@ 11:46）（@ 11:48）。配套的装备路线也自洽：血包改版后"出近卫只需要一个法穿鞋，蓝量基本不缺"（@ 06:40）（@ 06:41）（@ 06:43）（@ 06:47）；顺风"还能出星泉来保证续航"（@ 06:45）（@ 07:02）；"中期可以把星泉换成救赎"（@ 09:57）。
- **决策分支**：
  - 队伍需要连续压塔、打人数差滚节奏 → 续航型有价值：状态能回满就别急着回城，接着压（@ 11:48）
  - 顺风 → 星泉保续航（@ 07:02）；中期团战变多 → 星泉换救赎（@ 09:57）
  - 逆风 / 需要开团 → 参考 K-C23，续航让位给打团装
- **反例**：把"治疗量高、评分高"当选取理由。素材确实提到"刷了很多治疗量""MVP 实至名归"（@ 14:49）（@ 14:54），但同片后段又否掉了刷数据本身："刷起来被动对于整局的胜负影响不是特别大，主要是你思路和连招"（@ 12:24）（@ 12:27）。续航的兑现方式是"能压塔"，不是"面板好看"。
- **来源**：BV17hgK6kEas @ 11:44（同段 @ 06:45、@ 07:02、@ 09:57、@ 11:48）
- **可信度**：低。单源个人经验；"状态回满"依赖血包与装备，素材没给回复量、冷却或蓝耗数字；星泉换救赎只有一个"中期"的模糊时点。
- **状态**：draft

### K-C27 这个英雄的旧卖点（刷被动经济）已被削：选它的理由要改成容错、续航和连招

- **适用版本**：S45（素材未标版本）
- **触发条件**：你选了素材里这个续航型辅助，还按"刻意刷被动、靠经济差"的老思路在打
- **判断依据**：同一处改动被素材提了两次，是这条最硬的证据：前段"自从邵思源偷钱减少后，缩减的争议也降低了"（@ 00:21）（@ 00:23）；后段"少司员自从偷钱少了之后，基本玩起来就可以不用刻意去刷钱，刻意会影响你的操作"（@ 12:12）（@ 12:14）（@ 12:16）。替代的重心在紧接着的一句："主要是你思路和连招，这些做对的才是比较重要的"（@ 12:27）（@ 12:28）。
- **决策分支**：
  - 玩这个英雄 → 不刻意刷被动，把精力放到思路和连招上（@ 12:16）（@ 12:27）
  - 还在按老版本刷钱 → 改。素材给的判断是"刻意会影响你的操作"，收益已经小于代价
  - 想据此说"偷钱型辅助整体变弱" → 素材只讲了一个英雄，别外推，进待补
- **反例**：把"能刷钱"当这个英雄的选取理由。改动后素材的态度是"不用刻意去刷"（@ 12:14），卖点已经从经济转到了容错、续航和连招。选人理由停在旧版本，就是拿过期卖点做决策。
- **来源**：BV17hgK6kEas @ 12:12（同段 @ 00:21、@ 12:14、@ 12:27）
- **可信度**：低。单源、单英雄；UP 只说"偷钱减少"，没说削了多少、哪个版本改的，也没有改前改后的胜率或出场率。本条的可用部分是"重心从经济转向思路连招"这个方向，不是"削了多少"这个量。
- **状态**：draft

### K-C28 素材边界：这是"九大神辅"的第 1 期，只完整打了一个英雄，不能当九大神辅名单用

- **适用版本**：不涉及版本判断，属于素材边界陈述
- **触发条件**：你想用这一期素材去回答"九大神辅是哪九个""辅助位该怎么排""功能辅和输出辅怎么选"
- **判断依据**：三条可逐句核对的事实：
