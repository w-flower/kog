# 组合补缺法

> 素材来源：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）。原 UP 的原则一句话：**组合只看"搭配能不能成立"，先不谈英雄强度** —— 这样内容才跨版本。

## 判断顺序

```
第 1 步：先看队友缺什么 → K-C06
第 2 步：缺口是不是"一个技能就能补" → K-C07
第 3 步：这个组合有没有"不能配的人" → K-C08
第 4 步：对面组合靠哪一环成立 → K-C09（破解）
第 5 步：这套组合的强度还在不在 → K-C10（版本折旧）
```

### K-C06 组合成立的唯一判据：它补上了队友的哪个缺口

- **适用版本**：S45
- **触发条件**：你在配一套"XX + YY 很强"的组合
- **判断依据**：把队友的短板说出来，再看这个辅助是不是正好补它。说不出来就别配
- **决策分支**：
  - 队友**缺开团**（刘邦、镜、司空震这类"能进但开不了团"）→ 配一个能主动开的
  - 队友**缺一秒爆发**（张良捏住只有一秒窗口）→ 配干将、安琪拉、李元芳
  - 队友**缺"再进一次场的能力"**（大招型英雄进场后没有第二个大）→ 配朵莉亚
  - 队友**缺位移/脱手**（短手慢速，开技能时被突）→ 配张飞反打
- **反例**：「两个 T1 拼一起肯定强」——强度不叠加。两个都需要开团时机的英雄配在一起，谁都开不出第一波。
- **为什么这条能跨版本**：缺口是**机制层**的（缺开团、缺爆发、缺第二次进场），数值怎么改都不影响"他缺这个"。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高（方法论自洽，且与 B 类「机制克 > 数值克」的分层一致）
- **状态**：active

### K-C07 双向适配比单向适配值钱：刘邦 × 司空震这类"互救"组合

- **适用版本**：S45
- **触发条件**：评估一个组合的稳定性
- **判断依据**：顺风和逆风两个方向，这套组合是不是都成立
- **决策分支**：
  - 只在一个方向成立 → 是"顺风组合"，逆风直接废
  - 两个方向都成立 → 才是可以当主体系的组合
- **例子（文档原例）**：刘邦 + 镜/司空震/宫本。顺风时刘邦落点控帮它留人；**逆风时刘邦开大上天能防它"坠机"**。同一个人，顺风是"雪球"，逆风是"保险"。
- **反例**：只看顺风的组合最容易骗人。你在匹配里用着很爽，一到逆风局就发现自己没有任何翻盘手段。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active

### K-C08 "不能配谁"比"能配谁"更该记：朵莉亚 × 马可波罗/海月

- **适用版本**：S45
- **触发条件**：你想用"刷大招"型辅助（朵莉亚、元辅、太乙）
- **判断依据**：队友**进场后还剩多少血**。刷出来的第二个大，他要不要再进一次场
- **决策分支**：
  - 队友开大进场后血量健康 → 刷大成立（吕布、铠、杨玉环、敖隐、后羿、夏侯惇；嬴政、王昭君这类大范围分割）
  - 队友进场后血已经掉一半 → **刷了也不敢再进**，这条组合不成立（马可波罗、海月）
- **反例**：「多给一个大总是好的」——多给一个大，但他不敢进场，等于这个技能只缩短了 CD，没有换来第二次入场。辅助的价值全在"第二次"上。
- **推广**：这条同样适用于太乙真人的复活、鲁班大师的链子 —— **任何"再来一次"型技能，都要问队友敢不敢再来。**
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active

### K-C09 破解对面组合：不看它多强，看它靠哪一环成立，掐那一环

- **适用版本**：S45
- **触发条件**：对面已经选出一套明显有配合的阵容
- **判断依据**：这套组合的**关键一环**是哪个技能/哪一秒
- **决策分支**：
  - 组合靠"一秒窗口"成立（张良捏人）→ 拿**能拆火**的（阿古朵、武则天），或让被捏的人提前出复活甲
  - 组合靠"霸体免控"成立（廉颇）→ 拿**压制**（张良），压制能断霸体
  - 组合靠"拉扯"成立（孙膑体系）→ 拿**能捆住的**（老夫子大闪五秒）
  - 组合靠"藏视野抓边"成立（张良、鬼谷子）→ 拿**破隐/反视野**的
- **反例**：「对面组合强，我们也堆一套组合」——两套组合对撞，赢的是"谁的关键一环先被掐"。先想掐，再想堆。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）。具体对位见 `B_克制关系/`
- **可信度**：中高
- **状态**：active

### K-C10 组合会折旧：养马流为什么掉了

- **适用版本**：S45
- **触发条件**：你在用一个"老版本很强"的体系
- **判断依据**：这套体系是靠**几个技能叠起来的**。叠的层数越多，被砍一层的损失越大
- **例子（文档原例）**：孙膑 + 马超的"养马流"。原本是"阿古朵一技能给队友加速 + 孙膑二技能叠移速"两层叠加；**阿古朵的一技能加速被取消后，只剩孙膑二技能还能叠移速，体系强度直接掉下来**。
- **决策分支**：
  - 体系只依赖一个技能 → 相对稳定
  - 体系依赖两三个技能的叠加 → 每个版本都要重新验证，别当默认答案
- **推广**：这条是本库 `90_版本变更台账.md` 存在的理由 —— 组合类结论必须记"它是靠几层叠起来的"，被砍时才知道掉了多少。
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active
