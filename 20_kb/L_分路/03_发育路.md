# 发育路：这波兵我敢不敢吃

> ⚠️ **这一路是全库最缺素材的一块。** 现有素材全部来自**辅助/指挥视角**（大乔的运营、盾山的 2v2），没有任何一条是射手第一视角的全局教学。下面三条是"从别人的镜头里能确认"的部分，**不是完整的射手大局观**。

## 1. 射手的位置特征：经济最贵，也最容易被开

射手是全场唯一"输出全靠经济堆"的位置——法师有技能基础伤害、战士有技能组，射手的伤害几乎等于装备。所以发育路的核心矛盾永远是同一句话：

> **这一波兵的钱，值不值得用"被开一次"的风险去换。**

别的路可以"打不过就发育"，射手不行——**不打钱就没有输出，打钱就暴露**。这个矛盾没有完美解，只有判断。

## 2. 判断顺序（不完整，见文末待补）

```
第 1 步：这波线在哪？我能不能安全过去？  → K-L21
第 2 步：对面 2v2 谁强？                → K-L22（看辅助，不看射手）
第 3 步：兵线过河了，我要不要跟？        → K-L23
```

### K-L21 射手的经济不是"待在下路"赚的，是"哪条线安全就去哪条"

- **适用版本**：S45
- **触发条件**：下路兵线被对面控住、或下塔已经掉了
- **判断依据**：哪条线的兵线位置安全（能吃到、不被越）
- **决策分支**：
  - 下路被压 → **去中路补线**（我方中单转线的空档），不要在下路硬顶
  - 上路出现空档 → 也可以去上路吃线，但要有队友接应
- **反例**：「射手就该待在下路」——素材里的指挥原话是"我们就叫射手去中路补线"、"把射手跟中单摇过来"。**射手是"被调度去吃安全线"的位置，不是"守着一条路"的位置。**
- **来源**：BV14VuVzWEBE @ 03:09、@ 03:26、@ 03:35
- **可信度**：中（**辅助/指挥视角**，看到的是"怎么安排射手"，不是"射手怎么想"）
- **状态**：active

### K-L22 2v2 的线权看辅助，不看射手

- **适用版本**：S45
- **触发条件**：下路 2v2 对线期
- **判断依据**：双方辅助的强度（能不能卡位、能不能吃伤害），而不是双方射手的伤害
- **决策分支**：
  - 我方辅助强 → 敢压，卡线压位置
  - 我方辅助弱 → 退塔下接，接受"掉几个兵换不掉人头"
- **反例**：「我伤害比他高，应该压」——2v2 的对线强度由**辅助的开团/承伤能力**决定，射手前期的伤害差距远小于"谁能先手控住"。
- **交叉**：同一条判据在游走位也有（`K-L18`），但两边的落点不同——辅助看"能不能卡住位置"，射手看"敢不敢跟上去输出"。
- **来源**：BV1i6n9z7EWH @ 02:39、@ 03:00
- **可信度**：中高（盾山视角，明确把 2v2 的胜负归因到辅助身上）
- **状态**：active

### K-L23 兵线过河前，先确认对面打野和中单的位置

- **适用版本**：S45
- **触发条件**：兵线要推过河道
- **判断依据**：对面打野/中单在小地图上的最后视野位置与消失时长
- **决策分支**：
  - 位置已知且不在附近 → 可以跟线
  - 消失超过 8 秒且方向不明 → **不跟**，把线放回来在塔前吃（和 `K-D01` 中路用的是同一个阈值）
- **反例**：「兵线过河才有压制力」——射手的压制力是拿"被抓一次"换的。被抓一次，掉的不只是这波兵，还有接下来两分钟的发育时间。
- **来源**：BV14VuVzWEBE @ 02:31（"我们射手被越"）；阈值沿用 `K-D` 主线地图 / `04_对线期` 的 8 秒判定
- **可信度**：**低**（现象来自素材，阈值是从中路判据平移过来的，**没有射手视角的验证**，用之前自己判一下）
- **状态**：active（置信度低，待补）

## 3. 交叉：发育路和谁会在同一件事上打架

| 对手方 | 争什么 | 去看 |
|---|---|---|
| 游走 | 开局跟不跟我、2v2 谁卡线 | `K-L12`、`K-L18` |
| 中路 | 我去中路补线，他正在转线 | `K-L02`（中单清完就走，空档正好给你） |
| 打野 | 下路打起来他来不来 | `K-L45`（看对面交了什么，不看谁喊了） |

## 4. 待补（这一路的真实缺口）

素材层面必须补的东西，按优先级：

1. **射手第一视角的全局教学**——现在 0 条。没有它，这一路永远只能写"从别人眼里看到的射手"。
2. **被越塔的判据**：什么阵容/什么时间点会被二包一，怎么提前撤。
3. **什么时候开始跟团**：射手从"吃线"切到"参团"的经济/时间阈值。
4. **不同射手的分类**（站桩型 vs 位移型 vs 消耗型）对站位的不同要求。

补法：按 `s8_harvest.py` 同一套链路，关键词换成「射手 全局思路」「发育路 教学」+ 标题点名射手的，取 3–5 个 UP 各 2 条即可开写。
