# 中路：清完这波线，我往哪个方向走

> 这是**位置**的结论，不是某个英雄的。英雄怎么玩看 `A_英雄教学/`；第几分钟看 `D_对局内/`。

## 1. 中路的位置特权：转线成本最低

中路是地图中心，**到三条路的距离最短**。所以中路的产出不是"我打了多少伤害"，而是**"我能在几个地方出现"**。

这条决定了中路的判断顺序：**先算线权（能不能走），再算方向（往哪走），最后才算操作（怎么打）**。顺序反了就会出现"我在中路打得很凶，但地图上什么都没发生"。

## 2. 判断顺序（不能跳步）

```
第 1 步：这波线，我有没有线权？        → K-L01
   ↓ 有
第 2 步：清完立刻走，还是再推一波？    → K-L02（判据：下一波兵到线时间）
   ↓ 走
第 3 步：往哪个方向走？                → K-L03（判据：对面中单消失方向 / 我方打野位置）
   ↓ 顺路
第 4 步：路过野区，蹭不蹭？            → K-L05（判据：能不能 3 秒内扫完）
   ↓
例外：打野差一级到四 → 中线让给他      → K-L04
```

### K-L01 线权不是"我血多"，是"对面多快能清完这一波"

- **适用版本**：S45
- **触发条件**：每波兵线交汇前（判断自己能不能走）
- **判断依据**：对面中路（含辅助）**一波兵需要几个技能**。一个技能清完 = 你无线权；要三个技能以上 = 你有线权
- **决策分支**：
  - 没线权 → 不硬抢，塔前接兵，改走"反方向拿资源"或等打野（见 `K-D01`）
  - 有线权 → 清完立刻产生一个"可动窗口"，详见 K-L02
- **反例**：「我血比对面多，所以我有线权」——血线是打架结果，不是线权来源。满血但清不动兵，照样是被压在塔下。
- **分路差异**：这条在对抗路也成立（`K-L31`），但中路的判据要多看一个人——**对面辅助会不会来帮清**，辅助一来清线速度直接翻倍。
- **来源**：BV1xEFGzoEYA @ 00:19（"大乔一技能直接秒兵线，我只有一个人……这波没有线权"）
- **可信度**：高（多英雄素材一致）
- **状态**：active

### K-L02 有线权就立刻走，别在中路站着——站着的每一秒都是白送的窗口

- **适用版本**：S45
- **触发条件**：刚清完一波兵，下一波兵还没到
- **判断依据**：下一波兵到线还要多久（正常约 30 秒一波）
- **决策分支**：
  - 到线 > 8 秒 → 够一次短游，按 K-L03 选方向
  - 到线 ≤ 8 秒 → 不动，把线再推一波更赚（见 `K-D04`）
- **反例**：「清完线在中路等下一波，顺便看有没有机会单杀」——单杀是低概率事件，转线是确定收益。**有线权却不走，等于把线权浪费掉。**
- **来源**：BV1K8gDzwEho @ 00:19（"玩海月这种有线权的中单法师，一定要想办法在四级前多去控一两个中立资源"）
- **可信度**：高（与 `K-D04` 的 8 秒阈值互相印证）
- **状态**：active

### K-L03 方向选"反方向"，不是"跟着走"

- **适用版本**：S45
- **触发条件**：决定要转线了，选往哪一路
- **判断依据**：① 对面中单小地图消失的方向 ② 我方打野当前所在的半区
- **决策分支**：
  - 对面中单往上 → **我往下**（拿河蟹、兵线、野区小资源）
  - 对面中单往下 → 我往上
  - 看不出方向 → 只占中轴草，不深入（`K-D06`）
  - 我方打野在同侧 → 跟他走同一侧（`K-D05`）
- **反例**：「对面去支援了，我赶紧跟」——你没有线权时跟过去比他慢，有线权时跟过去也是**同向撞车**，两边都打不出东西。反方向才有空位。
- **来源**：BV1xEFGzoEYA @ 00:38；`K-D01` 的判据（BV1i2n96AEvp @ 02:31 底层框架）
- **可信度**：高（D 类已独立验证过同一条）
- **状态**：active

### K-L04 中线归谁：打野差一级到四，中线让他

- **适用版本**：S45
- **触发条件**：打野走到中线想吃这波兵
- **判断依据**：打野当前等级离四级差多少
- **决策分支**：
  - 打野差一级到四 → **让**。他升四才有反打/进野区的能力，这一波线的收益远大于你自己多几十块
  - 打野已四级以上 → 不让，按 K-L02 自己清完转线
- **反例**：「我的线凭什么给他」——四级前的打野和四级后是两个英雄，这一波让出去，换的是他接下来 3 分钟的节奏权。
- **来源**：BV14kiYB8E7R @ 04:31、@ 04:39（"此时一定要先选择速推中线……利用中线升四级，才可能有反打的机会"）
- **可信度**：中高（打野视角的职业级素材，明确把中线当"升四资源"用）
- **状态**：active

### K-L05 顺路蹭野：用技能边缘扫一下就走，别站野区打完

- **适用版本**：S45
- **触发条件**：清完线、等下一波兵的间隙，路过野区
- **判断依据**：这组野还剩多少血、你打完要几秒
- **决策分支**：只有一个技能的时间 → 边缘扫一下立刻走；要站桩打完 → 不打，回线
- **反例**：「顺手把野清干净」——你多待 5 秒，中线就丢了，中塔掉一半血。**蹭野的收益上限是"顺路"，一旦需要绕路就不成立。**
- **分路差异**：对抗路也有"顺路刷野"，但对抗路可以合法地多待（见 `K-L31`）；中路不行，中塔是全图最重要的塔。
- **来源**：BV1g44y1F7aN @ 01:07（一技能边缘摸小猪，与直接转向相差约 0.3 秒）
- **可信度**：中
- **状态**：active

### K-L06 第一波线遇到钩子类辅助（钟馗），退到塔前接

- **适用版本**：S45
- **触发条件**：对面辅助是钟馗这类强制位移，且你在第一波线上
- **判断依据**：自己是否站在对方钩子的射程内
- **决策分支**：**退到塔前接兵**，不要站在兵线前沿；被勾进塔下等于直接脱节
- **反例**：「中单必须抢线权」——抢线权的前提是你能安全清完。被钩一次，掉的不只是血，还有整波线的经验。
- **分路差异**：这条对**清线慢的法师**尤其致命（抢不动又躲不开），清线快的法师可以用一波技能换掉这个风险。
- **来源**：BV1Fd4y1k7EY @ 00:24；@ 01:09（清线慢所以先拿河蟹）
- **可信度**：中
- **状态**：active

### K-L07 弱势法师没有线权：不尾随、反方向、塔后过线

- **适用版本**：S45
- **触发条件**：自己的清线速度明显慢于对面中单（弱势法），且第一波线抢不动
- **判断依据**：**我能不能在自己掉状态之前把这波兵清完**。不能 → 这条成立；能 → 走 K-L01 正常流程
- **决策分支**：
  1. **清线时只打后排兵**，不打人。目的不是消耗，是让对面**卡不住线**；被卡线 = 掉状态 = 丢闪现甚至丢野区（BV15EJk6fEwX @ 00:27）
  2. **对面去上路支援，你不跟**，往**反方向**去下路拿资源。理由：弱势法跟过去「作用不大」，留在原地只是多一个人看对面吃线（@ 00:39 / @ 00:40）
  3. **没线权就老老实实塔后过线**，别站兵线前沿（@ 01:04）
  4. **过完线不急着乱跑**：先占中轴视野（一般是中路边草），给下路打信号，再决定去哪（@ 01:43）
- **判据一句话**：弱势法**能和对面换状态就不算亏，让对面做不了事就是赚**（@ 00:47）。这是"弱势法"的收益公式，和强势法的"抢节奏"公式不一样。
- **反例**：「有线权才配游走」——这条对弱势法反着用：**正因为没线权，才更要往反方向拿资源**，否则整局只有挨压。
- **分路差异**：这条只在**中路**成立。对抗路的弱势方不能"反方向拿资源"，因为对抗路没有第二条资源线可换（对照 `K-L31`）。
- **来源**：BV15EJk6fEwX @ 00:25；@ 00:27；@ 00:39；@ 00:40；@ 01:04；@ 01:43；@ 03:37
- **可信度**：中（单来源，全局思路局，非英雄专精）
- **状态**：active

> 关于来源里的英雄名：原视频字幕写作「王维」，经核对 **S45「月照长安」新英雄王维（中路法师）**，字幕没听错。这条按"弱势法师"这一类写，王维只是样本之一；他的机制细节见 `A_英雄教学/王维.md`。同一条视频里对手是嫦娥，可作为"对面有强线权中单"的样本。

## 3. 本路最容易犯的三个错

1. **把线权当血量**（K-L01）→ 明明清不动兵还站前面，被压到塔下，然后怪打野不来。
2. **有线权但不走**（K-L02）→ 全场最贵的资源是"能动的中单"，站着等于放弃它。
3. **转线跟着对面走**（K-L03）→ 同向撞车，两个人的收益都变成零。

## 4. 交叉：中路和谁会在同一件事上打架

| 对手方 | 争什么 | 去看 |
|---|---|---|
| 打野 | 中线归谁 | `K-L04` / `K-L43` |
| 游走 | 开局第一波谁帮清中 | `K-D08`（游走排序里中线排第四）/ `K-L12` |
| 对抗路 | 你转线过去，他这波线让不让 | `K-L31` |
