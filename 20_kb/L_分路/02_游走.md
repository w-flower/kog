# 游走：第一步去哪

> 这是**位置**的结论。英雄怎么玩看 `A_英雄教学/`；第几分钟看 `D_对局内/04_对线期.md`（`K-D08`）。

## 1. 游走没有自己的线，靠别人的线吃饭

这是游走和另外四路最根本的区别：**你没有一条自己清的线，所以你的"活动资格"完全来自队友的线权**。队友被压在塔下，你就只能蹲在旁边；队友有压制力，你才有机会去野区、去别的路。

由此推出游走唯一的核心指标：**你这一波能不能让某个点上从 N 打 N 变成 N+1 打 N**。做不到，你在哪都是多余的。

这也是为什么"跟着射手走"是最常见的错误——**跟人不产生人数差，只有"到得比对面快"才产生人数差**。

## 2. 判断顺序

```
第 1 步：开局第一波去哪？          → K-L12（排「野→边→射→中」，中线排第四）
第 2 步：帮打野时，手要放在哪？    → K-L13（不抢尾刀）
第 3 步：帮中路抢线时，打谁？      → K-L14（连人带兵一起打）
第 4 步：中期，跟谁？              → K-L15（跟射手转线，不是围中路）
第 5 步：对面有强开团/钩子，站哪？ → K-L16（吃钩子是你的活）
第 6 步：要开团了，开不开？        → K-L17（队友不跟就不开）
```

### K-L11 游走唯一的产出是"人数差"，不是"保护"

- **适用版本**：S45
- **触发条件**：任何时刻，当你不知道自己去哪
- **判断依据**：你到那个点之后，那边的战斗会不会从 N 打 N 变成 N+1 打 N
- **决策分支**：
  - 会变成多打少 → 去，哪怕只是站在那吃伤害
  - 不会变 → 不去。这一趟的收益是零，还白送视野给对面
- **反例**：「辅助的职责是保护 C 位」——保护是一个**结果**，不是动作。真正的动作是"让这个点上我们的人比他们多"。跟着 C 位走一整局，人数差一次都没造出来，等于没打。
- **来源**：BV14VuVzWEBE @ 06:14（"用大招把队友传过来打一个人数差团战，这就是大乔"）
- **可信度**：中高（这是大乔的结论，但"人数差"本身是位置级的判据，不依赖传送这个技能）
- **状态**：active

### K-L12 开局别默认跟射手——「野 → 边 → 射 → 中」是排序，不是并列

- **适用版本**：S45（中野辅版本）
- **触发条件**：开局到 1 分钟，决定第一波去哪
- **判断依据**：① 打野要不要进攻/防守野区 ② 边路有没有线权可拿 ③ 发育路对线强度 ④ 中路要不要帮清
- **决策分支**：
  - 打野要偷野 → 去**对抗路**拿线权，再协同进野区
  - 打野不偷野 → 去边路尝试一血
  - 都不成立 → 回中帮清线
  - **发育路排在第三位**：只有前两条都不成立、且对面 2v2 压制明显时才直接去下
- **反例**：「辅助就该保射手」——按这个排序，开局直接去发育路等于放弃了野区节奏和边路一血，两条都比"保一个还没成型的射手"值钱。
- **判据来源**：`K-D08`（BV1yke26fEYB @ 00:47、@ 00:52，UP 主自创命名"一野二边三射四中"）
- **分路差异**：这条只对游走成立。中路/对抗路没有"选一个点去"的自由，他们被自己的线钉住了。
- **来源**：BV1M81kYpEPE @ 01:01、@ 01:51（大乔开局跟中路抢线，不跟射手）
- **可信度**：高（D 类独立写过同一判据，两个不同 UP 一致）
- **状态**：active

### K-L13 帮打野刷野：不补最后一刀

- **适用版本**：S45
- **触发条件**：开局帮打野清第一个野
- **判断依据**：打野是否已出打野刀、这组野是不是他的叠层来源
- **决策分支**：**只打不补**，最后一刀留给打野；自己拿助攻经验就走
- **反例**：「帮打野就是帮他打快」——抢了尾刀，他少一层、你多几十块。这笔账在四级前是亏的，因为打野的等级直接决定他能不能进野区。
- **分路差异**：这条**五路通用**，但收益最大的是游走（因为只有游走会主动站在野怪旁边）。
- **来源**：BV1yke26fEYB @ 02:28
- **可信度**：中（口播一句话，但与"打野要靠等级进野区"的 K-L44 逻辑一致）
- **状态**：active

### K-L14 帮中路抢线：连人带兵一起打，不要只清兵

- **适用版本**：S45
- **触发条件**：一级帮中路抢线
- **判断依据**：己方中单能不能跟上（有没有远程消耗手段）
- **决策分支**：不急着补兵，**先连人带兵一起打**，把对面中单磨成残血——即使他抢到线权，也打不动了
- **反例**：「帮中就是帮他把线清完」——线清完了但对面满血，下一波他照样压你家中单。**抢线权的目的是让对面失去打架能力，不只是让兵线过去。**
- **来源**：BV17Vp9zXEx2 @ 01:47（职业选手"大帅"的打法解析）
- **可信度**：中高
- **状态**：active

### K-L15 中期跟射手转线，不是围着中路转

- **适用版本**：S45
- **触发条件**：进入中期（约 10 分钟后）
- **判断依据**：射手是否已经能独立吃线、有没有被越塔风险
- **决策分支**：带射手快速转线发育 → 占上半图视野 → 龙坑草埋伏
- **反例**：「辅助要跟团」——中期最值钱的动作是**帮射手把线吃满 + 把视野推过去**，在中路蹲着既不吃线也不做视野。
- **分路差异**：这条的前提是你的英雄有"带人移动"的能力（大乔的传送、鲁班大师的链子）。纯坦辅只能"跟着走"，收益减半（见 `K-L18`）。
- **来源**：BV1eSTx6nEnY @ 07:26、@ 06:58
- **可信度**：中高
- **状态**：active

### K-L16 对面有钟馗这类钩子：**吃钩子是你的活**

- **适用版本**：S45
- **触发条件**：对面选出强制位移型辅助（钟馗为代表）
- **判断依据**：己方谁站在能被勾到的位置
- **决策分支**：
  - **由辅助去吃钩**，不要让它勾到 C 位；辅助被勾是"可以接受的结果"，C 位被勾是"这波没了"
  - 团战前**跟着钩子走**：他去哪你跟到哪，防他勾自家野区 Buff
  - 站位避开"中左"这类视野盲区的正面入口
- **反例**：「辅助要保护 C 位」——保护的具体动作就是**站在他和钩子之间**。躲在后面不叫保护。
- **来源**：BV1DGHx61EHn @ 11:08、@ 11:51、@ 14:35（"你辅助要去挡钟馗钩子呀"）；@ 03:37（"你跟着钟馗走就可以防止钟馗勾野了"）
- **可信度**：中高（这是一局实录里的指挥，说话人位置未确认，但内容是**明确对辅助下的指令**，可直接采）
- **状态**：active

### K-L17 开团前先确认队友跟不跟，不跟就不开

- **适用版本**：S45
- **触发条件**：任何要主动开团的时刻
- **判断依据**：队友是否知道你要开（信号/语音）、是否有输出位在射程内
- **决策分支**：先打信号确认；确认不到就不开，改打消耗
- **为什么这条属于游走**：另外四路开团失败最多是"死一个人"，游走开团失败是"全队没了"——因为游走是唯一"用控制换队友输出"的位置，队友没跟上，你的控制就是白交。
- **来源**：BV1i6n9z7EWH @ 13:09（"如果队友能很好配合，盾山 T0 强度是有的"）
- **可信度**：中
- **状态**：active

### K-L18 打连体（2v2）：卡线压位置，别急着换血

- **适用版本**：S45
- **触发条件**：下路 2v2 对线
- **判断依据**：己方 2v2 能不能打过、对面射手敢不敢压
- **决策分支**：
  - 打得过 → **卡线压位置**：对面过来就打状态，不过来就掉兵
  - 打不过 → 退塔下接，别硬换
- **反例**：「打不过就消耗」——打不过的时候消耗等于送，退塔下让对方"吃掉这波兵但不拿人头"才是最小损失。
- **交叉**：这条和发育路共用（`K-L22`），判据重心不同——**辅助看的是"能不能卡住位置"，射手看的是"敢不敢吃这波兵"**。
- **来源**：BV1i6n9z7EWH @ 02:39、@ 03:00
- **可信度**：中高
- **状态**：active

### K-L51 偷小野的四个窗口：5 秒 vs 10 秒这笔账

- **适用版本**：S45
- **触发条件**：你想去对面野区偷一组小野
- **判断依据**：**这一组野值 5 秒，对面回来要 10 秒**。反一组小野约 5 秒；敌方从线上赶回自家野区约 10 秒起（无位移还要绕墙，加时间）
- **四个成立的窗口**：
  1. 敌方**掉点**（刚死）
  2. 敌方打野**在线上露头**（小地图上看得见他）
  3. 打野**回城补状态**
  4. 残血打野躲在自家野区偷偷刷小野补状态（这时候反而要抓他，不是偷）
- **决策分支**：
  - 四个窗口任成立 → 反，且**只反一组就走**（多反一组，对面的 10 秒就追平你了）
  - 都不成立 → 别去。你在对面野区的时间，比对面回防的时间还长
- **反例**：为了偷一组野放弃中线 —— 5 秒的收益换掉一波线的窗口，亏（见 `K-L02` 的 8 秒阈值）
- **交叉**：这条和打野共用（`K-L44` 讲的是"进野区要领先两个野怪"，讲的是打野的资格；本条讲辅助的**短窗口**，门槛低得多）
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高（时间数字是口播估计，但"5 秒 vs 10 秒"这个量级关系可靠）
- **状态**：active

### K-L52 开局站位：走自家打野同侧的草，不是"跟着打野"

- **适用版本**：S45
- **触发条件**：开局 0:00–0:40
- **判断依据**：自家打野在哪半边开
- **决策分支**：
  - 站**和自家打野同侧**的草丛 → 对面来偷另一侧 Buff 时，你这一眼就能看见
  - 不确定该站哪 → **进红区**，站到能覆盖"对面卡视野偷野位"的那个点
  - 站好之后**再看一眼中路草丛**，顺手参与第一波中线
- **反例**：「开局跟着打野一起刷」——同侧站草的价值是**视野**，不是帮打。你贴着野怪站着，反而是最没信息量的位置
- **和 K-L12 的关系**：L12 回答"先去哪一路"，本条回答"**在去之前，第一步站哪**"。两条不冲突，是先后关系
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active

### K-L53 红隼博弈：判断链是「射辅强度 → 中射辅强度 → 中路线权」

- **适用版本**：S45
- **触发条件**：开局红隼（发育路资源点）刷了，双方都在争
- **判断依据（按顺序过）**：
  1. 己方**射辅 2v2** 打不打得过
  2. 打不过 → 对面**辅助在哪**（在中路还是在发育路）
  3. 都算完 → **中路线权**在谁手里（决定谁支援更快）
- **决策分支**：
  - 射辅弱于对面、但对面辅助在中路 → **拖着对面辅助不让他支援**，让自家强势射手单挑
  - 对面辅助已经下路 → **去二打一**，并且**顶着敌方射手伤害抢**（因为对面中路有线权，支援比你快，你不抢就没了）
  - 换不来 → **用赤甲换节奏**（放弃红隼，去拿对抗路的赤甲，别空手）
- **反例**：「资源点都要争」——红隼争不到是常态，关键是**争不到的时候有没有替代收益**。换赤甲就是替代收益
- **交叉**：这条是发育路（`K-L21`~`K-L30`）和游走共用的判断，但**执行的人不同**：射手负责打，辅助负责判断和卡位
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高（三段判断链是本条最有价值的部分，比"去抢红隼"这种结论实用）
- **状态**：active

### K-L54 河灵只需要多一个人：辅助卡线，中路去抢

- **适用版本**：S45
- **触发条件**：对抗路河灵（正常刷 3 只）刷新，双方都在争
- **判断依据**：人数差 + 谁能抬斩杀线
- **决策分支**：
  - **三打二就够，不要两个都扑上去**
  - **辅助去卡线**（挡对面过来的人），**中路去抢**（中路有伤害、能抬斩杀线）
  - 打野在帮对抗路抢四级线时 → 辅助**必须拉开经验区**（见 `K-L55`）
- **反例**：「人多抢得快」——两个人都扑到河灵上，对面一个人过来就能把你们俩都赶走，因为没人卡位
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active

### K-L55 打野帮对抗路抢四级线时，辅助必须让开经验区

- **适用版本**：S45
- **触发条件**：打野到对抗路帮抢四级线，你也在旁边
- **判断依据**：**打野刀会分经验**
- **决策分支**：**拉开距离，退出经验区**。你的作用只剩"卡位/防抓"，不是"一起打"
- **反例**：三个人挤在一条线上打同一波兵 —— 自家对抗路上不了四，这一波帮了等于没帮，还把打野的时间搭进去了
- **为什么这条容易被忽略**：辅助的直觉是"人多力量大"，但**经验是零和的**。多一个人分摊，对抗路的四级就晚一波，而四级线正是这一波的全部意义
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高（机制层判断：经验分配规则）
- **状态**：active

### K-L56 支援优先级：解线 > 抓压得深的 > 帮大哥 > 卡回援 > 帮打野提速

- **适用版本**：S45
- **触发条件**：你手上没有明确任务，不知道下一步去哪
- **判断依据**：按下面五级顺序，**从高到低**，命中第一条就走
  1. **解线**（百分百不亏：兵线进塔你去清，塔不掉、线不亏）
  2. **抓压得深的**（先给假视野再绕）
  3. **按阵容强度帮"大哥"**（**大哥不一定是射手**）
  4. **去卡对面回援位置**，抢下一波线权
  5. 都没事 → **帮打野提速**
- **节奏约束**：资源一般**两波中线刷一次**，所以平均**每两波只需要去一次**。不用每波都动
- **反例**：「跟着射手走一整局」——如果射手不是大哥（比如这局中路是干将、射手是后手位），你的"保护"就是在给错误的人加班
- **和 K-L15 的关系**：L15 说"中期跟射手转线"，本条说"**先确认射手是不是大哥**"。两条一起读：跟的是"大哥"，不是"射手"这个位置
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：高（五级排序 + "大哥不一定是射手"这句是本条的核心，纠正了 L15 的盲区）
- **状态**：active

### K-L57 三条纪律：不同时干两件事 / 半途平衡 / 统一决策

- **适用版本**：S45
- **触发条件**：任何一波决策
- **三条纪律**：
  1. **不同时干两件事**——要入侵就别让射手同时去拿红隼。分兵 = 两边都不够人
  2. **半途平衡**——另半张地图人多，你这半图就得缩。**宁可不吃线，也别被四人越塔**
  3. **统一决策**——队友白起空大两波，第三波他说开，**你也要跟**。你不跟，他开到了也是白输
- **为什么第三条反直觉**：因为它不是"最优决策"，是"**最优的执行**"。一个错误的决定被五个人执行，比五个正确的决定各执行一半强
- **反例**：「他空了两波大，这波我不跟」——你对了，但这波团输了。辅助的价值在"让队伍只做一个决定"，不在"每次都做对的决定"
- **推广**：第 2 条（半途平衡）和 `K-L11`（人数差）是同一条原理的两面：**永远不要让自己这一半地图上的人数处于劣势**
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：高（三条都被原 UP 反复强调，且第 2 条与 K-L11 互相印证）
- **状态**：active

## 3. 本路最容易犯的三个错

1. **把"跟人"当"保护"**（K-L12、K-L15）→ 跟人不产生人数差，站位才产生。
2. **帮打野时手贱补尾刀**（K-L13）→ 你赚 40 块，换他晚 30 秒到四。
3. **开团不看队友位置**（K-L17）→ 控制交出去了，队友还在清线。
