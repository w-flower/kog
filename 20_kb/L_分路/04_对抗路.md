# 对抗路：这一波我压线还是放线

> 这是**位置**的结论。英雄怎么玩看 `A_英雄教学/`。

## 1. 对抗路的位置特权：可以合法地不参团

对抗路离主战场最远，**跑一趟的成本最高**。所以这一路的核心不是"我什么时候去支援"，而是反过来——**"我能不能用不去支援，换到更多东西"**。

这让对抗路成了五路里**自主权最高**的位置：中路必须转线、游走必须到点、射手必须跟辅助，只有对抗路可以说"这波我不去，我把线带穿"。

代价也很清楚：**你不在，团战就是 4v5**。所以每一次"不去"都必须换来对等的东西——一座塔、两个野怪、或者对面一条线的经济。

## 2. 判断顺序

```
第 0 步：把收益分成两层——主要收益 / 额外收益    → K-L35
第 1 步：这一波，我要不要压线？                  → K-L31（判据：压完能不能安全撤）
第 2 步：压线的收益是什么？                      → K-L32（对面打野来不了 / 对面边路升不到四）
第 3 步：线权换来的钱，怎么花？                  → K-L33（立刻走，别刷上头）
第 4 步：额外收益要不要去拿？                    → K-L36（判据：会不会影响主要收益）
第 5 步：4 分半了，我达标了吗？                  → K-L37（一件成品装 + 鞋 / 0-0-0）
第 6 步：3:50 的暴君去不去？                     → K-L39（判据：有没有被抢的风险）
第 7 步：4 分钟之后，带哪条线？                  → K-L40（判据：对面打野位置）
   ↓
打不过怎么办？                                 → K-L34（闷头发育也是赢法）
   ↓
想放龙换别的东西？                             → K-L38（野区刷新同步的算法）
```

### K-L31 对抗路可以把线权直接换成钱——但必须先算好怎么撤

- **适用版本**：S45
- **触发条件**：拿到线权、把兵线推到对面塔前
- **判断依据**：① 你的撤离手段（传送/位移/疾跑）是否可用 ② 对面打野小地图能不能看到
- **决策分支**：
  - 有撤离手段 → **推完立刻走**，去中路吃一波线、或进野区刷钱，不要在自家线上原地站着
  - 没有撤离手段 → 只推到河道，不深入
- **反例**：「推完线回城补给」——回城是最亏的选项：你花了 8 秒什么都不做。推完线去做下一件事，才是把线权变现。
- **来源**：BV12wtr6cEMR @ 02:52、@ 04:06、@ 04:08（"没传送的时候一波清兵线吃野怪刷钱；有传送的时候，清完兵线就传送阵传送开西，保证自己用最快的速度刷最多的钱"）
- **可信度**：中高（司空震视角的完整一局，动作与口播一致）
- **分路差异**：中路也能推完线走，但**中路走的方向是"支援"**；对抗路走的方向是"再吃一份钱"。同一动作，目的不同。
- **状态**：active

### K-L32 卡线的双重收益：对面打野不敢来 + 对面边路升不到四

- **适用版本**：S45
- **触发条件**：你在线权上压制对面边路
- **判断依据**：兵线位置（能否卡在自家塔前）与对面打野的开局路线
- **决策分支**：把兵线**卡在我方塔前**——对面边路吃不到经验，同时对面打野第一波不敢来（因为来了也抓不到人）
- **反例**：「压线就是把兵推过去」——推到对面塔下等于把兵线送给对方，他还是能吃到经验。**卡线和推线是两个相反的动作。**
- **来源**：BV12wtr6cEMR @ 02:47（"因为我们的卡线，导致对面打野第一时间不敢来，哪吒也没升四，搞得对面一点战斗力都没有"）
- **可信度**：中高
- **交叉**：这条直接决定**打野能不能进对面野区**（`K-L44`）——我方边路卡住线，对面打野才不敢反蹲。
- **状态**：active

### K-L33 别刷上头：刷钱是为了能去支援，不是为了刷钱

- **适用版本**：S45
- **触发条件**：你已经经济领先，正在连续刷钱
- **判断依据**：地图上有没有正在打的团/即将刷新的资源点
- **决策分支**：
  - 队友在打 → **立刻传送/走过去**，能用传送就不用跑的（省赶路时间）
  - 没有事发生 → 继续带线刷钱，带完线顺手入侵野区
- **反例**：「我经济领先，先刷满再说」——原话是"千万不要一直刷钱，刷上头了"。经济领先的唯一用途是**在关键团里碾压**，不参团的领先是纸面数字。
- **来源**：BV12wtr6cEMR @ 05:30、@ 05:37、@ 06:24
- **可信度**：中高（UP 主自己在同一局里既示范了刷钱也示范了节制）
- **状态**：active

### K-L34 打不过就闷头发育——经济领先也是一种赢法

- **适用版本**：S45
- **触发条件**：对线期被压制、支援不出去
- **判断依据**：能不能稳定吃到兵线；对面是否已经开始转线
- **决策分支**：放弃支援，专注吃线 + 刷自家野区，把经济差控制在可接受范围；等对面走位失误再打
- **反例**：「打不过也要去支援，不然队友骂」——去支援等于送第二个人头。**对抗路最合法的止损就是"不去"。**
- **来源**：BV156QfBQEDd @ 01:14、@ 01:28（"支援不了就闷头发育，经济领先对面边路"）
- **可信度**：中高
- **状态**：active

### K-L35 对抗路前期的收益分两层：兵线+野怪是"主要收益"，其余全是"额外收益"

- **适用版本**：S45
- **触发条件**：开局到 4 分钟，决定这一分钟做什么
- **判断依据**：这件事属于哪一层
  - **主要收益**：一波兵线 + 一组野怪（自家赤甲/小鸟这类）
  - **额外收益**：对面的人头/助攻、对面野怪、中立资源（空间之灵）、中路兵线
- **决策分支**：
  - 主要收益没拿 → 先拿主要收益，其他全部推后
  - 主要收益已拿 → 再考虑额外收益（K-L36）
- **反例**：「哪里有东西就去哪」——对抗路最典型的崩法是追着额外收益跑，结果自己那波兵没吃到，4 分钟经济落后 800。
- **来源**：BV1kVAfzbEBj @ 00:16；BV1kVAfzbEBj @ 00:20；BV1kVAfzbEBj @ 00:50
- **可信度**：高（这条是整局打法的骨架，全程都在按它执行）
- **状态**：active

### K-L36 拿额外收益的前提：不影响主要收益

- **适用版本**：S45
- **触发条件**：看到一个额外收益（反小鸟、吃中线、抢空间之灵）
- **判断依据**：去拿它会不会让你错过下一波兵线/自家野怪
- **决策分支**：
  - 不影响 → 去拿
  - 会影响 → **先拿完主要收益再回头**，或者直接放弃
- **反例**：「顺手就去了」——原话把顺序说死了：拿额外收益的前提，应该是不影响主要收益，**或者拿完主要收益之后再去**。
- **来源**：BV1kVAfzbEBj @ 01:59；BV1kVAfzbEBj @ 02:00；BV1kVAfzbEBj @ 02:03；BV1kVAfzbEBj @ 02:06
- **可信度**：高
- **状态**：active

### K-L37 4 分半的自我校验线：一件成品装 + 一双鞋、0-0-0

- **适用版本**：S45
- **触发条件**：约 4:30
- **判断依据**：装备栏 + 战绩
- **决策分支**：
  - 达到 → 说明主要收益全吃到了，可以进入"看小地图带线"的阶段（K-L40）
  - 没达到 → 说明前面漏了主要收益，接下来补发育，别急着参团
- **反例**：「4 分钟该去参团了」——团战不看你到没到时间，看**你的装备到没到线**。0-0-0 也能达标，说明击杀不是这条线的考核项。
- **来源**：BV1kVAfzbEBj @ 04:26；BV1kVAfzbEBj @ 04:29；BV1kVAfzbEBj @ 04:30
- **可信度**：中高（UP 主明确把它当"标准"给出，但具体装备名随版本变，只取"一件成品装 + 鞋"这个量级）
- **状态**：active

### K-L38 对面打野从对抗路野区开 → 他的对抗路野区和暴君同时刷新

- **适用版本**：S45
- **触发条件**：开局判断出对面打野的开野侧
- **判断依据**：对面打野第一个 Buff 在哪（红开/蓝开）
- **决策分支**：
  - 对面从**对抗路侧**野区开 → 他的对抗路野区和暴君同时刷新；我方红区刷新时，他的红也快刷新了
  - 掌握这个时间差 → 暴君被抢风险低时，可以去反他的红**换节奏**
- **反例**：「反野靠猜」——野区刷新是可以用开野侧推出来的，不用猜。不知道刷新时间就去反野，等于送。
- **来源**：BV1kVAfzbEBj @ 03:10；BV1kVAfzbEBj @ 03:12；BV1kVAfzbEBj @ 03:21；BV1kVAfzbEBj @ 03:24
- **可信度**：中高（这条是全库少见的"可计算"判据）
- **交叉**：和打野的 `K-L44` 是一对——打野算"我领先几个野"，边路算"他的野什么时候刷"。
- **状态**：active

### K-L39 3:50 的暴君去不去，只看"有没有被抢的风险"

- **适用版本**：S45
- **触发条件**：3:50 左右，我方打野在打龙
- **判断依据**：对面打野在不在附近；我方上路有没有线权；对面阵容强度
- **决策分支**：
  - 打野能安稳拿 → **不去**，继续清线/吃野
  - 有被抢风险（对面打野在附近、我方没线权、对面强度高）→ 去，或者干脆**放龙去反他的红**
- **反例**：「龙团必须全员到」——原话：因为我们家打野是安稳拿龙的，对面打野没有去暴君，所以"我们也不用过去"。
- **来源**：BV1kVAfzbEBj @ 03:38；BV1kVAfzbEBj @ 03:40；BV1kVAfzbEBj @ 03:48；BV1kVAfzbEBj @ 03:50；BV1kVAfzbEBj @ 03:57
- **可信度**：高
- **交叉**：和 D 类 `K-D15`（没一次性资源就别硬接）方向一致，但视角不同：D 类问"我够不够资格"，这里问"这波有没有风险"。
- **状态**：active

### K-L40 4 分钟之后，注意力从兵线转到小地图：看打野位置决定带哪条线

- **适用版本**：S45
- **触发条件**：过了 4 分钟，进入中期
- **判断依据**：小地图上对面打野的位置 + 哪条线的兵线正在过来
- **决策分支**：
  - 打野在下半区 → 带**上路/对抗路线**（安全侧）
  - 打野在上半区且视野可见 → 带下半区线，或者干脆去中路吃线
  - 打野位置不明 → 只带"能立刻退回塔下"的那一段
- **反例**：「中期就是一直带线」——中期带线的安全性完全由对面打野的位置决定，不看他就是盲带。
- **来源**：BV1kVAfzbEBj @ 04:49；BV1kVAfzbEBj @ 04:52；BV1kVAfzbEBj @ 04:55；BV1kVAfzbEBj @ 05:00
- **可信度**：高
- **状态**：active

## 3. 本路最容易犯的三个错

1. **压线不会撤**（K-L31）→ 推完站在对面塔前，等对面打野来收。
2. **把卡线做成推线**（K-L32）→ 想让对面难受，结果把兵线送过去让他舒服。
3. **刷钱刷到不参团**（K-L33）→ 经济第一，团战 4v5，输了怪队友。

## 4. 交叉：对抗路和谁会在同一件事上打架

| 对手方 | 争什么 | 去看 |
|---|---|---|
| 打野 | 我卡线，你能不能进对面野区 | `K-L32` / `K-L44` |
| 中路 | 你转线过来，这波线谁吃 | `K-L03` / `K-L31` |
| 游走 | 边路一血要不要来帮 | `K-L12` |

## 5. 待补

- **传送/传送阵的 CD 与距离**没有素材，只能确定"优先用传送、少跑路"这个方向。
- 对抗路与打野的"二包一"配合（谁先手、怎么卡位）——无素材（打野视角的 `K-L48` 只讲了蹲回头点）。
- 坦克型边路 vs 战士型边路的大局观差异（现在所有结论都偏"能带线能刷钱"的战士/半肉）。
- **"额外收益"的取舍在逆风局是否反过来**（逆风可能需要主动抢额外收益搏一下）——无样本。
