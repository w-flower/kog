# 打野：现在该刷还是该抓

> 这是**位置**的结论。英雄怎么玩看 `A_英雄教学/`。

## 1. 打野是唯一按「时间差」算账的位置

另外四路的资源是**线**（有固定节奏，一波接一波），打野的资源是**野**（有刷新间隔，可以被"抢时间差"）。所以打野的核心概念不是"抓了几个人"，而是：

> **野区速率**——你清完自己野区的速度，决定你能不能"多出一次机会"。

原话：「很多人不理解野区速率这个概念。当双方野区刷新间隔比较短时，是很难直接进野区的，**进野区起码要领先对方两个野怪的时间差**。」

这条一旦立住，打野的所有判断都变成同一道算术题：**我这一趟出去，回来的时候会不会落后节奏？**

## 2. 判断顺序

```
第 1 步：这局我一级能不能反野？      → K-L42（不能 → 决定开局刷野路线）
第 2 步：我要不要蹭中线升四？        → K-L43（蹭了会拖野区速率，必须换来反打）
第 3 步：这波能不能进对面野区？      → K-L44（判据：有没有领先两个野怪 + 视野）
第 4 步：什么时候放弃自家野区去跟团？→ K-L45（判据：边路是否打出关键技能）
```

### K-L41 打野的 KPI 是「时间差」，不是「抓了几个人」

- **适用版本**：S45
- **触发条件**：每一次决定"现在去哪"
- **判断依据**：你这一趟出去，回来时会不会落后对面的野区节奏
- **决策分支**：
  - 这一趟不亏速率 → 可以抓
  - 这一趟要绕远/要蹲很久 → 不抓，保住速率
- **反例**：「打野不抓人就废了」——抓不到人的一趟，亏的是**两三个野怪的时间**，而这段时间对面打野正好在做事。抓人失败不是"没收益"，是"负收益"。
- **为什么是这一路的核心**：另外四路的资源是线（有固定节奏，不走就浪费），只有打野的资源是野（可以抢时间差）。这条判据在其他四路没有对应物。
- **来源**：BV14kiYB8E7R @ 07:36、@ 07:47（"很多人不理解野区速率这个概念……进野区起码要领先对方两个野怪的时间差"）
- **可信度**：高（唯一的完整打野视角素材，且它自己就在用这个概念算账）
- **状态**：active

### K-L42 开局路线由「一级能不能反野」决定，不是背固定路线

- **适用版本**：S45
- **触发条件**：开局读条结束前
- **判断依据**：① 一级对拼/惩戒能力（能否强反）② 对面打野是什么英雄（谁一级更强）
- **决策分支**：
  - 一级能反（有惩戒优势或对面一级弱）→ 直接进对面野区
  - 一级不好反 → **从发育路野区开，往对抗路刷**（把路线拉成一条单向线，刷完正好到能出节奏的位置）
- **反例**：「打野就按固定路线刷」——路线是**为了配合一级强弱**而存在的。一级反野失败的情况下还硬走入侵路线，等于把节奏送出去。
- **来源**：BV14kiYB8E7R @ 03:09、@ 03:12（"一级不好反野，这把就可以选择直接发育路野区开往对抗路"）
- **可信度**：中高（职业级对局拆解，明确给了"因为 A 所以 B"的因果关系）
- **状态**：active

### K-L43 蹭中线是「投资」，不是「顺手」——必须换来升四或反打

- **适用版本**：S45
- **触发条件**：路过中路，中单有线权/中单不在
- **判断依据**：① 自己离四级差多少 ② 蹭完这波能不能立刻做一件"四级才能做的事"
- **决策分支**：
  - 差一级到四 → **蹭，且优先速推中线**（升四之后才有反打能力）
  - 已经四级以上 → 不蹭，继续刷野保速率
- **反例**：「路过就吃一口」——原话紧接着就是"因为这波蹭中线耽误了片刻的野区速率"。**蹭线的成本是看得见的（速率），收益必须能兑现，否则纯亏。**
- **来源**：BV14kiYB8E7R @ 04:31、@ 04:39（升四才有反打机会）；@ 06:01（蹭中线拖慢速率）
- **可信度**：高（同一条视频里同时给了收益和成本，是全库最完整的一组权衡）
- **交叉**：这条要和 `K-L04` 对着看——**中单让不让，看的是打野差几级到四**。两边判据一致，才不会互相抢。
- **状态**：active

### K-L44 进对面野区：至少领先两个野怪的时间差，并且卡住视野

- **适用版本**：S45
- **触发条件**：想反对面野区
- **判断依据**：① 你比对面打野多刷了几个野（时间差）② 对面线上有没有人能支援过来（视野）
- **决策分支**：
  - 领先 ≥2 个野怪 → 可以进，且**边打边卡视野**（先探草再动野怪）
  - 领先不足 → 不进，稳稳刷完自家野区再出来找节奏
- **反例**：「对面打野在下路，我去反他蓝」——他去下路不代表他回不来，你的判断依据应该是**时间差**，不是"他刚露过视野"。
- **来源**：BV14kiYB8E7R @ 07:36、@ 07:47（"进野区起码要领先对方两个野怪的时间差"）；@ 09:45、@ 09:53（"卡好视野……全身而退"）
- **可信度**：高（这条是全库最硬的分路判据，有明确阈值）
- **状态**：active

### K-L45 放弃自家野区去跟团的条件：边路打出了关键技能

- **适用版本**：S45
- **触发条件**：正在刷野，边路/中路打起来了
- **判断依据**：那边有没有"已经交掉的关键技能"（大招、闪现、控制）
- **决策分支**：
  - 对面关键技能已交 → **立刻放弃野区去跟**（这时候的团是"低风险高收益"）
  - 只是互相消耗 → 继续刷，别被"打起来了"骗过去
- **反例**：「哪边打起来就去哪边」——没有关键技能交换的团，打野去了也只能蹭点伤害，回来还落后节奏。**打野参团的理由是对面交了什么，不是队友喊了什么。**
- **来源**：BV14kiYB8E7R @ 07:08、@ 07:24（"拉视野观察到影被夏洛特打出大招……我们就可以直接放弃中线来跟团"）
- **可信度**：中高
- **状态**：active

## 3. 本路最容易犯的三个错

1. **把"抓人"当 KPI**（K-L44）→ 抓不到人的时候你在亏速率，亏两次就再也进不去对面野区。
2. **蹭线不兑现**（K-L43）→ 蹭了线、没升四、没打成反打，纯亏速率。
3. **看到打架就去**（K-L45）→ 没有关键技能交换的团，去了就是陪打。

## 4. 交叉：打野和谁会在同一件事上打架

| 对手方 | 争什么 | 去看 |
|---|---|---|
| 中路 | 中线归谁 | `K-L43` / `K-L04`（两边判据必须一致） |
| 对抗路 | 我能不能进对面野区 | `K-L44` / `K-L32`（他卡住线我才敢进） |
| 游走 | 开局野区要不要人跟 | `K-L12`（游走第一顺位是野区） |
| 发育路 | 下路打起来要不要去 | `K-L45`（看对面交了什么） |

## 5. 待补

- **野怪刷新间隔的具体秒数**没有素材，只有"两个野怪的时间差"这个相对阈值。
- 不同打野类型（节奏型 vs 发育型）的路线差异——现在只有一条镜的对局。
- 打野的"逆风局"怎么打（野区被反穿之后的重启方式）——完全无素材。
