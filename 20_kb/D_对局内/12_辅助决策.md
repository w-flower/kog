# 12 辅助决策：这一波我该跟谁、去哪、开不开

> 素材说明：单一素材，B 站 UP「欺压ya」《顺风梦游？逆风等死？辅助如何根据局势做出决策【精讲课02期】》（BV1S8sn6zEJq，10:49，S45）。视角是**辅助位第一视角**，作者边打边讲自己怎么想，不是旁观解说；片中**没有交代分段**，也没给出对局质量，所以下面的判据只能保证"作者在这个局势里是这么想的"，不能保证"任何分段都成立"。视频无中文 CC，本文本由本地 faster-whisper medium 对中文原声做 ASR 后人工校订，时间戳可信（±2 秒），个别专有名词仍存疑，涉及处已在条目内标注。

## 判断顺序

```
第 1 步：先把"队友在催"和"局面需要"分开，把判断权收回自己手里 → K-D111、K-D112
第 2 步：读敌方这一波想干什么——空线、卡线、抱团，还是分带 → K-D113
第 3 步：算自家缺口——谁死了、谁不在、要缺多久 → K-D114、K-D115
第 4 步：定线权优先级——先补中再谈帮上，塔在血健康就可以先让 → K-D116、K-D117
第 5 步：看常规套路还走不走得通，走不通就换成"推线换视野" → K-D118、K-D119
第 6 步：拿到线权先施压逼对面回防，再把位置前压吃回河道 → K-D120、K-D121
第 7 步：要蹲人先算队友能不能跟上，就近开，反蹲敌方工具人 → K-D122、K-D123、K-D124
第 8 步：开不开——占必经之路、数前排身后几个人、数对面大招、算人数差 → K-D125、K-D126、K-D127、K-D128、K-D129、K-D130
第 9 步：开了之后怎么打——错开身位拉扯、远程拆火、分工明确、敢卖敢扛 → K-D131、K-D132、K-D133、K-D134
第 10 步：收尾——主动找对面失误，不等对面送 → K-D135
```

这个顺序不是视频顺序。素材是按六种局势一段一段讲的，本卡按"一波里辅助先想什么、后想什么"重排：先夺回判断权，再读意图，再算缺口，再定线权，最后才是开团与收尾。

### K-D111 先问"敌方想干什么"，再问"我该干什么"（@ 08:27）

- **适用版本**：S45
- **触发条件**：任何一波需要辅助自己拍板（跟谁、去哪、开不开），而队友同时在频道里给指令。
- **判断依据**：作者把整套教学定性为"过程型而非结论型"，要求先复现推理链——敌方意图 → 我方缺口 → 时间够不够 → 才轮到动作（@ 08:27）。
- **决策分支**：能说出这三问的答案 → 按答案走，哪怕和队友指令相反；说不出来 → 先别动，把线补上再判断。
- **反例**：只记结论（"辅助就该跟射手""逆风就该守"），敌方一换招就无处可套，正是作者说的"结论型"失效（@ 08:27）。
- **来源**：BV1S8sn6zEJq @ 08:27
- **可信度**：高——作者原话，且是全片的方法论基调，不依赖具体对局细节。
- **状态**：draft

### K-D112 队友的即时指挥，优先级低于线权与地图信息（@ 00:39）

- **适用版本**：S45

- **判断依据**：素材里射手要求"去跟队友打"时，作者的判断是"不用管射手说什么，心里要有自己的思路判断"，因为同一时间中路被蹲、上路被卡，局面已经不允许按射手的视角走（@ 00:39）。
- **决策分支**：队友指令与自己算出的线权一致 → 照做，省沟通成本；不一致 → 按线权走，事后补一句解释。
- **反例**：为了不被继续指挥，直接把射手屏蔽（@ 02:02）——这只适用于"指挥与判断冲突且当场说不通"，不能当默认操作，否则连队友的视野信息一起丢掉。
- **来源**：BV1S8sn6zEJq @ 00:39；@ 02:02
- **可信度**：高——作者明确表态，还给了具体做法。

### K-D113 对面放线不打，是"空线"，不是"怕了"（@ 00:22）

- **适用版本**：S45
- **触发条件**：敌方下路是「苍 + 射手」这类能放线游走的组合，对线期不跟你换血、把兵线放过来。
- **判断依据**：作者把这局的敌方打法直接定性为"空线打法"（@ 00:22）；后文补充"有了线权等于河道视野加先推先动"，空线换的是视野和先动权，不是补刀（@ 01:32）。
- **决策分支**：确认是空线 → 别在"中转上"这类常规节奏上和对面拼速度，改去处理自家被卡的那条线；对手仍在正常对线 → 按常规对线处理。
- **反例**：把放线理解成对面怂，继续压线吃兵，结果对面先推先动，反过来卡你的转线时间（@ 01:32）。
- **来源**：BV1S8sn6zEJq @ 00:22；@ 01:32
- **可信度**：中——"空线打法"这个判断本身清楚，但敌方下路组合名在 ASR 里无法确认，已按素材包存疑表只写成「苍 + 射手」。
- **状态**：draft

- **反例**：听射手的话直接去跟团，中线空出来，敌方顺势反蓝，等于拿一个蓝换一波没意义的跟团（@ 00:39、@ 00:48）。
- **来源**：BV1S8sn6zEJq @ 00:28；@ 00:48

### K-D115 对面法师一挂边，上路就得按"2 打 3"来算（@ 00:48）

- **适用版本**：S45

- **反例**：明明是 2 打 3 还硬要走"中转上"去抓上，多打少变成少打多，节奏直接送掉（@ 00:48）。
- **来源**：BV1S8sn6zEJq @ 00:48

### K-D116 塔还在、血还健康，这段被压是可以让的（@ 01:15）

- **适用版本**：S45
- **触发条件**：敌方把兵线压到塔前持续消耗，但塔没掉、射手血量健康。
- **判断依据**：作者的判据是两个可量化的东西——"防御塔有保护机制还好，射手的血量保持得很健康"，于是"上路被压一会儿很正常"，掉的血"可以回城"补（@ 01:15）。不是"感觉还能撑"。
- **决策分支**：塔在、血线健康 → 让线，把时间投到能拿线权的地方；塔血见底或射手要被越 → 必须回防，让线到此为止。
- **反例**：一被压塔就全员回上，中路没人补、蓝区没人看，用一条可以放的线换来两处失守（@ 00:48）。

### K-D118 常规套路对面也算得出来，必须换招（@ 02:02）

- **适用版本**：S45
- **触发条件**：你准备走的路线（比如先推中再转上）是路人局里人人都知道的常规节奏。

- **反例**：明知对面会先推中再转上，还按原计划走中左，等于自己走进埋伏（@ 02:02）。

### K-D119 破局第一步：用大招把两波线一起推过去（@ 03:00）

### K-D126 开团前先数"前排身后跟了几个人"（@ 05:03）

- **适用版本**：S45
