# 08 顺风推进

> 素材：燕十叁《王者打野公式的本质，从 0 学打野》（BV1NLHsexEPi，UP 主自述"燕13的替身SY"，
> 打野视角的教学口播 + 本人与国服老虎的实战复盘）。它讲的是**野区刷新节拍怎么变成一张时间表**：
> 90 秒一圈、一圈六拍、四片 Buff 一轮最多同时拿两片。下面每条判断都能在录像里对上时间点。
> **只覆盖打野视角**——其他分路的换算素材没讲，全部进「待补」。
> 另：任务包同时附了 BV1T8hG6FEtp，但该段转写经核对是一档综艺（分船、塑料瓶造船、浮力实验）的内容，
> 与王者荣耀无关，本卡**未从中取任何结论**，仅保留编号以备追溯。
> 上游接 `07_发育路推进公式.md`。

## 判断顺序

```
第 1 步：优势到手，是该"多做"还是该"换词"        → K-D53
第 2 步：这一波能做什么，由上一轮停在哪一拍决定  → K-D54
第 3 步：想同时压两片以上野区，先决定放掉哪些小野 → K-D55
第 4 步：龙/塔和野区撞在同一拍，用哪个换哪个      → K-D56
第 5 步：一段推进做完，回原点还是把舍弃的补回来  → K-D57
第 6 步：家里野区被对面换掉，这波推进停不停      → K-D58
第 7 步：要反复进对面野区，是"反"还是"等它刷"    → K-D59
```

### K-D53 顺风不是多做，是节拍数不变、换收益更高的词

- **适用版本**：S45
- **触发条件**：刚打出一波优势（反到 Buff、抓死一次、拔了一座塔），想"接下來该多做什么"
- **判断依据**：一个 90 秒循环大约只装得下六拍——一片野区算 2 拍、一座防御塔算 2 拍、蹭线抢线算 1 拍，加起来就是 6（@ 02:01~02:08）；作者给的用法原话是"在同样时间的节拍里，尽可能去填收益更高的词"（@ 02:14~02:18）
- **决策分支**：
  - 节拍还没填满 → 补**高收益**的词（龙、塔、对面野区），不要凭空加动作（@ 02:10~02:18）
  - 节拍已经填满 → 只能**换词**，不能加词；加了就一定挤掉别的（@ 13:05~13:11）
- **反例**：「顺风了，想到什么就做什么」——素材把这种状态直接排除在"节奏"之外：随心所欲做事不是节奏，知道一件事对规律的影响才是（@ 01:29~01:36）；另一种反例是野怪一刷新就跑回去复刻第一轮，作者形容"说实话有点像人机"（@ 01:00~01:04）
- **来源**：BV1NLHsexEPi @ 01:29~01:36、02:01~02:18、13:05~13:11
- **可信度**：高。判断依据是作者自建的框架，但六拍的时间成本（2/2/1）是他在片子里明确给出的换算口径，不是含糊带过
- **状态**：draft

### K-D54 下一步能做什么，由上一轮停在哪一拍决定

- **适用版本**：S45
- **触发条件**：推进卡住，不知道该压哪一路、该不该回头刷
- **判断依据**：作者把这条单独列为"第二点"——"打野公式是从上一波开始的，你下一件事能做什么，取决于你上一轮循环的节拍在哪里"（@ 04:21~04:32）；反过来，"节拍相同，填什么词都不会影响节奏"（@ 05:27~05:31）
- **决策分支**：
  - 上一轮把某个 Buff 位换成了蹭线 → 这个 Buff **本轮不再归你掌控**，别按旧表去等它（@ 08:13~08:28）
  - 上一轮只是把"刷一片野区"这个词换成了"刷对面野区" → 节拍没变，可以照原时间线继续压（@ 04:57~05:11）
- **反例**：「顺风了，哪里有钱去哪里」——把上一轮的参照物丢掉，下一轮就会出现空拍，因为"上一轮这里的节拍被我们从刷红替换成了蹭线，刷红已经不被我们所掌控"（@ 08:19~08:28）
- **来源**：BV1NLHsexEPi @ 04:21~04:32、04:57~05:11、08:13~08:28
- **可信度**：高。有老虎反红的具体推演作支撑：反红被明确定义为"置换了原本应该刷蓝区的时间"，所以节奏不断（@ 05:03~05:11）
- **状态**：draft

### K-D55 想同时压两片以上野区，先决定放掉哪些小野

- **适用版本**：S45
- **触发条件**：优势方想把野区压制扩成"四片野区"，或想一边控野一边控龙带线
- **判断依据**：全图四片 Buff，但一轮节奏里身上最多同时存在两个，所以"一轮节奏你只能同时拥有两片野区"（@ 05:43~05:51）；想吃到三片，推演里"一定会有小野怪是放掉的"（@ 06:25~06:30）；而小野 70 秒就刷一次，"很容易因为贪一个小野而打乱自己的节奏，导致节奏断裂"（@ 06:44~06:50）
- **决策分支**：
  - 要走正方形 → **主动**把小野算进"放弃项"，用它换跑图时间（@ 07:38~07:43）
  - 不放弃小野 → 老实拿两片，别宣称自己在做四片压制（@ 06:50~06:56）
- **反例**：「我全都要」——作者的原话反问是"你想把三片野区塞到一个循环里面，那你刷野的路上是瞬移的吗"（@ 06:32~06:36）；做不到的根因被点得很死："就是因为不懂得放掉小野怪占用的节拍，导致规划不及时"（@ 06:38~06:44）
- **来源**：BV1NLHsexEPi @ 05:43~05:51、06:25~06:50、07:38~07:43
- **可信度**：中高。结论本身有推演支撑，但"拆成两条节奏线来理解"是作者自己的表述（@ 07:29~07:32），属于他的解释框架，不是可外部验证的机制
- **状态**：draft

### K-D56 龙和塔能整块换掉一轮刷野时间

- **适用版本**：S45
- **触发条件**：龙刷了或塔能压，同时自家/对面野区也在刷，只能选一样
- **判断依据**：作者把"推塔控龙"和"刷野区"明确归为同一类节拍——"我在刷野区的时候并不是在刷野区，我只是在做节拍时间为二的事情；同时我在做其他节拍时间为二的事情的时候，例如推塔控龙，你也可以理解我此时在打野，他们是可以互相置换的"（@ 09:00~09:16）
- **决策分支**：
  - 龙能直接换成塔/视野 → 先龙。国服老虎的实录是：4 分钟开龙，"开完龙不刷蓝区，选择压上压了上路，等待红区刷新"再回去反红（@ 10:28~10:33）
  - 开龙 + 压塔大约占三拍 → 剩下的时间只够去**占点**对面红区，不够打完（@ 12:07~12:13）
  - 选择回去补刷蓝区 → 就要舍弃拦小野，但能赶上对面蓝 Buff 刷新，这是**取舍**不是错误（@ 13:19~13:24）
- **反例**：「开完龙再回去把蓝区补了，还要顺手拦两只小野」——这正是把两条线的收益同时要，作者在推演里点名这样会让整个节奏崩盘（@ 13:05~13:19）
- **来源**：BV1NLHsexEPi @ 09:00~09:16、10:28~10:33、12:07~12:13、13:19~13:24
- **可信度**：高。有带分钟级时间点的实战复盘（4 分钟开龙 → 压上塔 → 等红刷新 → 反红），不是纯口播
- **状态**：draft

### K-D57 一段推进做完就回时间原点，别把舍弃的节拍塞回来

- **适用版本**：S45
- **触发条件**：一波推进结束（拿了龙 + 塔，或连吃两片野区），还剩时间，想"再补点东西"
- **判断依据**："如果你填了蹭线等其他的事情，那你就需要舍弃掉一个 Buff，否则你的节拍会溢出，导致下一轮节奏线延迟或者混乱"（@ 07:50~07:58）；处置办法是"在节拍填满时间线的时候，及时回到时间原点，才不会影响循环节奏的时间"（@ 08:00~08:06）
- **决策分支**：
  - 还有空拍 → 回原点接下一循环，按原节拍走（@ 08:00~08:06）
  - 已经超拍 → 不要硬塞，**开一条新循环并声明新原点**；作者给的例子是把反红本身当成新原点，"反红刷蓝、反蓝控拍"（@ 08:30~08:43）
- **反例**：「刚才为了推塔没刷的那组野，现在补回来」——作者原话是把舍弃的节拍"强行再塞进来"，结果是"整个节奏就会崩盘，就会乱"（@ 13:13~13:19）
- **来源**：BV1NLHsexEPi @ 07:50~08:06、08:30~08:43、13:13~13:19
- **可信度**：高。同一判断在 07:50 和 13:13 两处独立出现，前后一致
- **状态**：draft

### K-D58 对面换掉你一片野区，只要这条节奏线收益做足就不算亏

- **适用版本**：S45
- **触发条件**：你在推优势，家里野区被对面偷/换
- **判断依据**：老虎开龙那波，"自家红是被对面的猪八戒换掉了，但这不重要，这并不影响老虎的节奏，老虎仍然做足了一条节奏线的收益——开龙推塔刷野区"（@ 14:04~14:12）；作者对交换方的评价是"猪八戒长途跋涉的跑去拿老虎的红，也算是没有办法的办法了"（@ 14:14~14:17）
- **决策分支**：
  - 你这条线已经拿到龙 + 塔 → **继续推，不回头**，被换掉的那片按 K-D57 开新原点处理（@ 14:04~14:12）
  - 你这条线只拿到一片野区、其余全空 → 才回头守，这时"顺风"其实已经名不副实
  - 判断不了自己这条线赚没赚 → 见 `09_逆风止损.md` 的 K-D60，先分清丢的是经济还是刷新规律的掌控
- **反例**：「他偷我红，我必须马上抢回来」——为了追回一片野区放弃已经在手的推进窗口，正是 `09` 开头要接的那条边（@ 14:12~14:21）
- **来源**：BV1NLHsexEPi @ 14:04~14:17、14:19~14:21
- **可信度**：中高。是单局案例 + 作者一句"不重要"的判断，**没有给出任何量化阈值**（比如被换几片才该回头），所以只能当方向用，不能当尺子
- **状态**：draft

### K-D59 反野的正确形态是"等它刷"，不是"进去找"

- **适用版本**：S45
- **触发条件**：想反复进对面野区做压制，判断这一脚值不值得迈
- **判断依据**：作者把反野的第一性条件讲得很直白——"反野的第一要素是什么？是要有野怪，你才可以反。野怪不刷，你怎么反？而如果你能让野怪在你反的时候正好刷新，那么你就控制了这片野区"（@ 09:45~09:57）；配合"老虎走到哪，那你的野区就会刷，从而可以提前规划"（@ 06:07~06:12）
- **决策分支**：
  - 能算出对面那片什么时候刷 → **按时走过去**，到了正好出生；实录里"稍后时间走过去，蓝 Buff 会刚好刷新"（@ 19:58~20:02）
  - 算不出 → 不进。进去是空的，还白送一趟跑图（@ 16:22~16:30）
- **反例**：队友喊"反红"就跟着进——作者当场否掉："我不进他红区没东西，他红开的……我们抢完中线的时候韩信肯定出红区了，所以队友说反红是不存在的"（@ 16:22~16:30）
- **来源**：BV1NLHsexEPi @ 06:07~06:12、09:45~09:57、16:22~16:30、19:58~20:02
- **可信度**：高。正反两面都有实战例子：一次是掐点反蓝成功，一次是明确拒绝了一次空反
- **状态**：draft

## 待补

- **其他分路的换算完全没有**：素材全程是打野视角，"一片野区 2 拍、一座塔 2 拍"是打野口径。射手/中路/对抗路的"节拍当量"素材没给，不能直接套
- **S45 的刷新数值未经核对**：素材里 90 秒（Buff）、70 秒（小野）是录制当时的数，片子没标版本（只提到"7 月 31 号"的实战视频）。S45 是否仍为这两个值，需要按当前版本核一遍
- **推进的"落地"环节缺失**：素材只有"压上塔""拆个中塔"两句，没有兵线怎么带、塔皮怎么磨、越塔条件是什么
- **团队层面缺失**：谁是主指挥、四个人怎么跟、视野谁做，素材里只有"让队友过去站点"一句带过（@ 20:24~20:25）
- **反面案例的披露不全**：作者自己说过"不要问我反红失败了怎么办，我会剪辑的"（@ 19:10~19:19），所以实战片段是成功样本，失败率不可考
- **素材一的可用性**：BV1T8hG6FEtp 与主题无关，建议向素材提供方确认是否贴错文件
