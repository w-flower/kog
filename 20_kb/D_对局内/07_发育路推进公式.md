# 07 发育路推进公式

> 素材：小居王者丶《射手的 13 分钟公式化推进思路》（BV1X2jV6KEiP，国服射手视角，S45）。
> 这是**发育路视角的对局运营全周期**教学（从开局对线 → 4 分钟 → 7 分钟 → 10 分钟 → 后期），
> 讲的是"什么时候该干什么、为什么"，不是连招。下面每条都是录像里明确讲出、可回看的判断。
> 上游接 `04_对线期`、`05_资源点与推进`、`06_中期`。

## 判断顺序

```
第 1 步：射手只发育赢不了游戏 → 想清楚"推进"才是目标（K-D29）
第 2 步：前期保状态，不是保命 → 别用闪现换血（K-D30）
第 3 步：清线前先看小地图 → 用看残血兵的时间看信息（K-D31）
第 4 步：4 分钟后兵线能不能吃 = 看中路线权（K-D32）
第 5 步：7 分钟前不盲目转线/推塔，循环发育等队友拔塔（K-D33）
第 6 步：要转线先做风险判定（K-D34）
第 7 步：中期进野区看对方复活时间，别贪（K-D35）
第 8 步：射手不追击（K-D36）；顺风不无脑进野区（K-D37）
第 9 步：逆风防守吃线等机会（K-D38）
第 10 步：后期团战核心是射手，开团位置选塔前（K-D39）
第 11 步：10 分钟后团战为推塔拿水晶，不为发育（K-D40）
```

### K-D29 核心论点：射手只发育赢不了游戏

- **适用版本**：S45
- **触发条件**：任何"我分均经济很高但还是输"的自我怀疑
- **判断依据**：低分段节奏慢，是因为"大家都热爱发育，唯一有推进能力的射手不去压塔"（@ 00:23~00:28）
- **决策分支**：
  - 经济高但赢不了 → 问题在**没把经济转成推进/压制**，不是经济不够
  - 分均 800 还一直输 → 把"刷钱"当成目标本身就是误区（@ 00:07~00:12 学员原话）
- **反例**：「分均 800 块了还输，是队友不行」——同一学员的误区；教练原话"这不纯扯淡吗"，根因是没推进
- **来源**：BV1X2jV6KEiP @ 00:01~00:28
- **可信度**：高（逻辑自洽，且和 `05` 的"资源点要转成压制"一致）
- **状态**：active

### K-D30 保状态 > 保命：前期别用闪现换血

- **适用版本**：S45
- **触发条件**：对线期要不要交闪现/保命技能
- **判断依据**：高分射手"时刻保证自己前期状态是好的"；低分射手"用闪现来保命，而不是保状态"
- **决策分支**：
  - 状态不好（残血/没技能）→ **撤，别用闪现硬保**（@ 04:26~04:31）
  - 为残血炮车/小野交闪现 → 错，等于把命交给对面（@ 04:19~04:22）
- **反例**：「残血了交闪现跑」——闪现是保**状态**的，交掉后下次被越塔就真没招了（@ 04:34 被多人越塔的根因）
- **来源**：BV1X2jV6KEiP @ 04:11~04:36
- **可信度**：高（直接对应"越塔风险来自残血"的机制）
- **状态**：active

### K-D31 清线前先看小地图：把看残血兵的时间用来看地图

- **适用版本**：S45
- **触发条件**：每一次准备清兵线之前
- **判断依据**：下路一个人时，清线前看一眼小地图，能决定"这波线清不清、去哪"
- **决策分支**：
  - 有人来抓 → 这波线不清，直接打旁边小野（@ 03:06~03:11）
  - 没人来抓 → 清完线，再去打小野（@ 03:11~03:13）
  - 对面射辅往中转了 → 兵线卡塔外吃就行（@ 03:35~03:37）
- **反例**：「盯着小兵残血补最后一下」——把注意力全放兵上，被抓时"刚好停了一下救了我的命"（@ 03:31~03:34 实录）
- **为什么重要**：意识=把花在兵线上的注意力挪到地图，下一步去哪自然清楚（@ 03:15~03:20）
- **来源**：BV1X2jV6KEiP @ 03:00~03:34
- **可信度**：高
- **状态**：active

### K-D32 4 分钟后兵线能不能吃 = 看自家中路线权

- **适用版本**：S45
- **触发条件**：4 分钟塔保护消失后，发育路每一波兵线
- **判断依据**：自家中路有没有线权，决定下路兵线进不进塔
- **决策分支**：
  - 中路线权在己方 → 下路兵线能正常处理
  - 中路被压在塔前 → 下路兵线进塔被越塔是**必然**（@ 04:48~04:57），不是队友不帮
- **反例**：「自己老是被越塔，是队友不帮」——很多时候队友也被压在塔前，同样动不了（@ 04:57~05:03）
- **来源**：BV1X2jV6KEiP @ 04:38~05:03
- **可信度**：高（机制：4 分钟塔保护消失 + 中路线权辐射下路）
- **状态**：active

### K-D33 7 分钟前：一组兵线 + 一只小野循环，不盲目转线/推塔

- **适用版本**：S45
- **触发条件**：优势方 7 分钟前的节奏安排
- **判断依据**：优势方"7 分钟之前不用到处乱走，也不用考虑去推塔"
- **决策分支**：
  - 一组兵线 + 一只小野的循环 → 直到队友过来帮你把下塔拔掉（@ 05:06~05:14）
  - 小野刷完"没事做"→ 转线？先想清楚收益（@ 05:16~05:19）
- **反例**：「小野刷完了转线吃更多经济」——转线收益提高，风险也同比例提高（@ 05:18~05:26）
- **来源**：BV1X2jV6KEiP @ 05:06~05:26
- **可信度**：高
- **状态**：active

### K-D34 转线前做风险判定：没线权就别转，真转卡队友开团第二时间进场

- **适用版本**：S45
- **触发条件**：想从发育路转中去吃线/参团
- **判断依据**：下路二打二有没有抢到线权
- **决策分支**：
  - 没抢到线权 → 转中比对方射手**来得晚**，转线收益抵消（@ 05:37~05:43）
  - 真要转 → 等"全场信息吃全"（对方开主宰等）后，卡在**队友开团时第二时间进场**（@ 05:55~06:05）
- **反例**：「清完线就转中再吃一波」——这波还有更好选择：利用对方以为能防守反击的心理，入侵蓝野区（@ 06:06~06:47）
- **为什么重要**：机遇和风险并存，转线时机选好但**不做风险判定**照样亏（@ 05:35~05:43）
- **来源**：BV1X2jV6KEiP @ 05:35~06:47
- **可信度**：高
- **状态**：active

### K-D35 中期进野区的时间 = 对方复活到线上的时间，别贪

- **适用版本**：S45
- **触发条件**：中期打完团后进对方野区发育
- **判断依据**：你在对方野区能发育多久，取决于**对方复活到线上的时间**
- **决策分支**：
  - 刷一个狼已是极限 → 别贪那只蜥蜴（@ 07:05~07:13）
  - 贪 → 大概率被对方打野抓到掉点（@ 07:09~07:13）
- **反例**：「顺风顺到野区多刷两只」——对方打野就在刚刷的位置，贪一手就被抓（@ 06:52~07:13 韩信案例）
- **来源**：BV1X2jV6KEiP @ 06:52~07:13
- **可信度**：高
- **状态**：active

### K-D36 射手不追击：追人 = 用掉保命技能 = 送人头

- **适用版本**：S45
- **触发条件**：团战后对方往回跑，要不要追
- **判断依据**：射手的机动性跟保命技能挂钩
- **决策分支**：
  - 对方在逃（追击战）→ 射手追不上，且追=用保命技能=没保命=送（@ 07:21~07:58）
  - 只有"双方前排/开团手缠斗"的团战，射手才有输出空间（@ 07:44~07:49）
- **反例**：「射手喜欢追人」——死亡率一定极高（@ 07:49~07:53）
- **来源**：BV1X2jV6KEiP @ 07:21~07:58
- **可信度**：高
- **状态**：active

### K-D37 顺风大忌：人不齐无脑进野区

- **适用版本**：S45
- **触发条件**：顺风局想扩大优势
- **判断依据**：进攻时站位应以**保命为主**，不是为输出贴近
- **决策分支**：
  - 人不齐 → 不进野区（@ 08:28~08:32）
  - 进野区 → 一旦掉点，逆风追赶机制一把追回 3500 经济（@ 08:53~08:59）
- **反例**：「顺风进野区收割」——"顺风最忌讳的翻盘点就是人不齐无脑进野区"（@ 08:28~08:34）
- **来源**：BV1X2jV6KEiP @ 08:09~08:59
- **可信度**：高
- **状态**：active

### K-D38 逆风射手：防守吃线等机会，95% 情况不找节奏

- **适用版本**：S45
- **触发条件**：己方逆风，射手想打开局面
- **判断依据**：逆风对射手"就一句话：防守吃线之中等一个机会"
- **决策分支**：
  - 正常情况下（95%）→ 不需要射手去找节奏，找了就是被平推（@ 09:20~09:23）
  - 例外：意识远大于当前分段（阿离"自由人"降维打法）→ 同分段几乎不可复制（@ 09:29~09:54）
- **反例**：「逆风让射手出去开节奏」——除非意识碾压，否则就是送（@ 09:21~09:23）
- **来源**：BV1X2jV6KEiP @ 09:11~09:54
- **可信度**：高（"95%"是经验比例，非精确数据）
- **状态**：active

### K-D39 后期团战核心是射手；开团位置选塔前，掩护撤退先找绕后位

- **适用版本**：S45
- **触发条件**：10 分钟后的团战站位
- **判断依据**：后期绝对核心是射手；射手利用地形（自家一塔在）被冲脸可闪现进野区跑，对方难追
- **决策分支**：
  - 开团位置选**塔前**，不是野区（@ 11:56~12:00）
  - 掩护队友撤退第一步 → 先找出对方**绕后位**（@ 10:28~10:32）
  - 提前支援把团战锁在对方二塔附近 → 容易被绕后偷（@ 10:24~10:46）
- **反例**：「一遇团战就结，打两下就想跑」——输出高但死亡率也高，没资格谈输赢（@ 11:02~11:09）
- **为什么重要**：没前排或前排前压时你没跟伤害 → 团战难输出（@ 13:05~13:19）；射手没前排也能用超远射程消耗（@ 13:30~13:35）
- **来源**：BV1X2jV6KEiP @ 10:24~10:46、11:29~12:00、13:02~13:35
- **可信度**：高
- **状态**：active

### K-D40 10 分钟后团战为推塔拿水晶，不为发育

- **适用版本**：S45
- **触发条件**：10 分钟之后的每一波团战
- **判断依据**：10 分钟前团战争经济；10 分钟后团战"完全有能力一两波结束对方"
- **决策分支**：
  - 这阶段团战目标 = 推塔/拿水晶，不是发育（@ 11:11~11:27）
  - 想通这点 → 终结比赛能力直线提升（@ 11:26~11:27）
- **反例**：「后期还在贪发育」——10 分钟后团战价值已变，继续发育=浪费窗口
- **来源**：BV1X2jV6KEiP @ 11:11~11:27
- **可信度**：高
- **状态**：active
