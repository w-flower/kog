# 05 第一波转线

> 素材：浅梦《打野教科书》（BV1oRJYzpEYb，12 位 KPL 职业打野第一视角）与《中路教科书》（BV1WkKzzUEtq，KPL 职业中路 + 顶端局实战解析），均为教练口播拆解，S45。
> 本节只回答一件事：**兵线清完、人已经能动的这一刻，先往哪一路走、凭什么这么判**。判断顺序里出现两个 K-D 号的，是同一步的两个分叉，不是两步。
> 上游接 `04`（第一波线权与开局落位）。

## 判断顺序

```
第 1 步：这一波线到底归不归你清 → K-D50（没线权）／K-D51（主动放线）
第 2 步：线清完了，这波中线接不接得起（中轴对抗强度 × 野区速率） → K-D41
第 3 步：接不起 → 放裂到塔下用塔伤接，不抢这波线权 → K-D42
第 4 步：接得起且中轴优 → 人不用走，节奏就留在中路 → K-D43
第 5 步：中路只是"过兵线" → 出节奏点不在中路，人转边 → K-D44
第 6 步：转两条边里的哪一条 → 先比边路对抗强度 → K-D45
第 7 步：手上没有对方打野信息时的默认方向 → 和打野反方向 → K-D46
第 8 步：走过去的路上 → 顺手把对方打野开局信息拿掉 → K-D47
第 9 步：到了边上 → 半靠还是完全靠 → K-D48；清完线发现自家打野亏了速率 → 先回野区提速 → K-D49
第 10 步：中后期同一问升级 → 能不能入侵／能不能推进，且必须留中 → K-D52
```

### K-D41 清完第一片野区，"去哪"之前先算这波中线接不接得起

- **适用版本**：S45
- **触发条件**：第一片野区收完、队友已经在往中路附近的中立资源点压，中路线同时到，要决定是接中还是继续刷
- **判断依据**：素材把这一步拆成两把尺——**中轴对抗强度**和**野区速率**（@ 01:40~01:43）。中轴 1V2 必定是裂的，就没必要抢这波中线权（@ 01:48~01:52）；打野单人接中线还会拖慢野区速率，且打野刀对兵线有减伤（@ 01:52~01:59），硬接容易变成残血 + 一边野区没刷、野区防守压力变重（@ 02:00~02:04）
- **决策分支**：
  - 中轴打得过、野区速率不吃亏 → 接中线，再接下一片野区
  - 中轴 1V2 必裂或野区速率本来就慢 → 先速刷野区，中线等队友传送回来再吃（@ 02:06~02:14）
- **反例**：两片野区刷完就出来蹭中线——素材直接点这是"大众路人局无意义的刷野方式"（@ 01:08~01:10）。职业局 vs 路人局的差别：职业局这波中线本来就有队友分掉（有人去抢中立资源），路人局没人替你压资源点，"不接中"要改成"先确认队友在不在"，不是默认放线
- **来源**：BV1oRJYzpEYb @ 01:40~02:14
- **可信度**：高（明确给了两个变量和各自后果，且同一逻辑在后文重复出现）
- **状态**：draft

### K-D42 中轴对抗劣 → 不抢线权，把线放裂到塔下用塔伤接

- **适用版本**：S45
- **触发条件**：中轴对抗明显劣（素材例：甄姬加四级前的镜），同时自己野区速率也慢
- **判断依据**：处理方式是"把兵线放裂塔下"再接，敌方不容易打掉我们的状态，因为有防御塔的伤害（@ 02:37~02:46）；中轴对抗烈就"故意把中线放裂塔下，接后刷野区"（@ 02:56~02:59）。另一处同理：人少打人多就是绝对的劣势线，线权是给对面推过来的，塔下接（@ 12:20~12:29）
- **决策分支**：
  - 线已经被对面推过来 → 塔下接，而且不急着清，留着和队友一起吃（@ 12:29~12:50）
  - 辅助或中单先来帮着清中 → 打野刀的减伤就可以忽略（@ 02:44~02:46）
- **反例**：中轴劣还上去抢线或者打人——素材原话"我们不可能上去抢线或者打人"（@ 02:33~02:35）。职业局 vs 路人局的差别：职业局"放裂"是团队设计，塔下这波线是留给传送回来的打野或中单吃的；路人局没人来接，放线就是白掉塔血，放之前必须先看到有人能来
- **来源**：BV1oRJYzpEYb @ 02:33~02:59、BV1WkKzzUEtq @ 12:20~12:50
- **可信度**：高（机制层理由清楚：塔伤换状态）
- **状态**：draft

### K-D43 中轴对抗优 → 人不用走，节奏就该留在中路

- **适用版本**：S45
- **触发条件**：清完线，中轴强度判为优（我方手长或人多），而第二轮野区还有一段时间才刷
- **判断依据**：素材要求同时想两件事，"中轴强度优还是劣"和"接下来的野区规划"（@ 03:06~03:09）；第二轮野区刷新在 2 分钟后，前期中立资源已争完，小地图上没有资源点也没野区刷新（@ 03:19~03:27），所以节奏继续在中路和对方摩擦（@ 03:27~03:31）
- **决策分支**：
  - 中轴优且正处在野区刷新的空窗 → 留在中路压状态、不用省技能，因为后续规划就是回野区刷野（@ 03:34~03:41）
  - 中轴优但自家野区马上刷 → 该回野区，不要再拿技能在中路换血
- **反例**：清完线就本能地往外走。这一段真正的收益是隐性的：把对方中线拖慢，他河道挤不出来，也就没法给双边施压（@ 03:43~03:49）。职业局 vs 路人局的差别：这条吃的是队友一起在中路压，路人局中路常常没人跟，一个人压过去等于送打野抓
- **来源**：BV1oRJYzpEYb @ 03:06~03:49
- **可信度**：高（"空窗期"这一判据在素材里有明确时间支撑：二轮野区 2 分钟后刷）
- **状态**：draft

### K-D44 中路只是"过兵线" → 出节奏点一定不在中路，人转边

- **适用版本**：S45
- **触发条件**：对方中单留在边路抢中立资源，中路只剩打野或清线快的人过线
- **判断依据**：素材判断"这波是没有中轴对抗的"，敌方中单留在对抗路抢空间灵、让打野出来接中线，我方中路仅仅过兵线就可以（@ 04:16~04:26）；结论是"接下来出节奏的地点一定不是中路，而是对抗路"（@ 04:26~04:29）
- **决策分支**：
  - 中路线交给清线速率更快的人（素材例：炸弹猫）接 → 自己速刷到对抗路（@ 04:37~04:41）
  - 抢速率赶到对抗路 → 一定有节奏点；对方打野还在接中线的时候，上路已经能做出四打二（@ 04:29~04:35、@ 04:51~04:53）
- **反例**：中路没人对抗还在中路纠缠等人齐——节奏窗口就是对方打野接线那几秒，等人齐窗口已经关了。职业局 vs 路人局的差别：职业局"让清线快的人接中线"是分工，路人局没人替你接，得先确认有人接再走
- **来源**：BV1oRJYzpEYb @ 04:16~04:53
- **可信度**：高
- **状态**：draft

### K-D45 转哪条边，先比两条边的对抗强度，再按强度选半图

- **适用版本**：S45
- **触发条件**：已经决定要转边，两条边都可能有节奏
- **判断依据**："提前看边路对抗强度是优还是劣"（@ 04:43~04:46）；哪怕对方中单不传走，也还是绝对的优势（@ 04:46~04:48）。边路对抗包含发育边和对抗边（@ 06:36~06:38），两条边要分别比
- **决策分支**：
  - 那条边对抗强度优 → 直接去，少打对面一个中单也是优势
  - 中轴没对抗但边路也打不过 → 就不存在这条边的对抗画面，换另一条（@ 05:31~05:42 发育路兵线一塔传过去会掉状态的例子）
  - 两条边都够呛、自己又刚好能升四 → 放一片小野换最快速率，赶在资源点刷之前到位（@ 05:13~05:24）
- **反例**：按"红开还是蓝开"的惯性选边。素材原话这"是一个很浅的说法"，真正该问的是发育路野区开还是对抗路野区开（@ 01:17~01:26）。职业局 vs 路人局的差别：职业局这两条边的强弱由 BP 和换线决定，路人局要靠开局一分钟的对线结果现看
- **来源**：BV1oRJYzpEYb @ 01:17~01:26、04:43~05:42
- **可信度**：高（判据与后文"边路对抗强度悬殊时也一定能出节奏"的案例一致）
- **状态**：draft

### K-D46 中单没有信息时的默认方向：和打野反方向走

- **适用版本**：S45
- **触发条件**：第一波中线清完，手上没有对方打野的位置
- **判断依据**：标准方法——"和打野反方向，打野上半图开局你就往下路去帮，下半图开局你就往上路去帮"，顺道看住另一边他还没打的野区，自家打野就不容易被反 Buff（@ 01:44~01:56）；素材明说这条"对于中低分段来说是很重要的"（@ 01:59~02:01）。实战对应：打野下半图开，所以往上半图跑（@ 09:53~09:58）
- **决策分支**：
  - 打野上半图开 → 往下路
  - 打野下半图开 → 往上路
  - 打野位置已经由辅助给出 → 不必再套默认方向，直接按信息走（@ 03:19~03:23）
- **反例**：凭感觉选一边、直直走过去。素材要求"不是无脑的直直的过去"，这段路要拿来收集信息（@ 02:03~02:06）。职业局 vs 路人局的差别：这是全篇少数明确说"中低分段很重要"的条目，路人局可以照抄；职业局方向会被辅助给的信息改写
- **来源**：BV1WkKzzUEtq @ 01:44~02:06、09:53~09:58
- **可信度**：高（给了默认规则、例外条件和适用分段）
- **状态**：draft

### K-D47 走过去的路上，顺手把对方打野的开局信息拿掉

- **适用版本**：S45
- **触发条件**：正在往某条边路移动，且开局没有对方打野位置
- **判断依据**：去上时看对方双猪，没人碰 → 对方打野大概率是蓝开（@ 02:08~02:13）；去下时透墙看对方有没有打蓝（@ 02:13~02:16）。实战走红背，看对面双猪和红 Buff，都没打就只能说明他蓝开（@ 10:05~10:12、@ 10:17~10:20）。辅助没给信息时，就和对方中路反方向去把信息补回来（@ 03:51~04:05）
- **决策分支**：
  - 双猪和红都没被碰 → 判蓝开，按蓝开的顺序估他进上半图的时间
  - 看到对面在上半区动 → 判红开，据此改自己落点，先一步靠过去形成人数差（@ 19:08~19:19）
- **反例**：把"去边路"当成纯赶路，走完全程还是不知道对方打野在哪，等于白送一段视野窗口。职业局 vs 路人局的差别：职业局这条通常由辅助和中单分担，素材原话是"开局辅助没能给到我们对方打野的位置信息，就需要我们在第一波兵线后去获取信息"（@ 03:52~03:58），路人局没人分担，只能自己补
- **来源**：BV1WkKzzUEtq @ 02:08~02:16、03:51~04:05、10:05~10:20
- **可信度**：高
- **状态**：draft

### K-D48 到了边上：默认半靠，只有打起来或能白拿一只小野才完全靠

- **适用版本**：S45
- **触发条件**：人已经走到"半靠中路 + 一条边路"的位置，要决定贴不贴过去
- **判断依据**：这个位置的定义就是"半靠中路以及其中一条边路"（@ 02:18~02:26）。完全靠过去的前提是"那个地方得打起来，或者能抢到对方的野区资源、拿掉对方的一只小野怪"——提高自己经济的同时削减敌方，比中路兵线更赚（@ 02:35~02:47）
- **决策分支**：
  - 那边打起来了，或者能抢一只小野 → 完全靠过去，不回中
  - 没打起来也没资源 → 回中路抢下一波兵线权（@ 02:54~02:56）
  - 实例：上路狂铁优了一波线、有线权能配合秒野怪 → 可以完全靠（@ 10:21~10:35）
- **反例**：每次都整个人贴过去。素材另一处给了反向纪律：经济被影响又补不回来时，就该每次去边路都只半靠，只在那有额外人头经济时才完全靠（@ 05:36~05:51）。职业局 vs 路人局的差别：素材自己说"不同分段用不同方式"（@ 05:55~05:58），路人局打野不让蹭野时，半靠是默认档
- **来源**：BV1WkKzzUEtq @ 02:18~02:56、05:36~05:58、10:21~10:35
- **可信度**：高（判据是"能不能拿到增量收益"，可当场验证）
- **状态**：draft

### K-D49 清完线先看自家打野亏没亏速率，亏了就先回野区提速

- **适用版本**：S45
- **触发条件**：这波线自己跑去边路处理、中线由打野补掉，或打野为了帮边丢了刷野时间
- **判断依据**：路过野区垫伤害能加快打野出野区，而且提速是可以反补自身的（@ 04:38~04:47）。实例：大司命在下路帮队友拿了资源还过了一波兵线，等于亏野区速率，所以"我们过完兵线首要的就是来帮大司命提速野区速率"（@ 14:33~14:46）；提完速他才有速率跟你一起抢下一波中线权（@ 14:51~15:01）
- **决策分支**：
  - 打野为了补中或帮边掉速 → 清完线先去野区垫伤害，再谈转边
  - 打野速率正常 → 直接按 K-D48 处理边路
  - 蹭野时要注意：不要乱蹭且不补刀，需要补经验和经济时再蹭（@ 04:53~05:00）
- **反例**：清完线直接奔下一条边，把自家打野的速率空档留给对面当入侵窗口。职业局 vs 路人局的差别：素材把这套叫协作打法，并明说"这种很难学，只是让大家了解一下比赛的一个协作打法"（@ 09:28~09:32），路人局打野常常不让蹭，按 K-D48 的半靠处理更稳
- **来源**：BV1WkKzzUEtq @ 04:38~05:00、09:28~09:32、14:33~15:01
- **可信度**：中（职业局的配合前提很强，路人局成功率取决于打野是否配合）
- **状态**：draft

### K-D50 没线权：先看对方中单去哪边，再按"有没有他打野的位置"决定跟还是反跑

- **适用版本**：S45
- **触发条件**：这波中路线被对面先清完，你动起来比他慢
- **判断依据**：没线权先看敌方中路往哪边走，两种选择——跟过去或去另一边（@ 03:02~03:11），判据是"有没有敌方打野的位置"（@ 03:12~03:15）。有信息就不必再找打野，慢慢跟过去，用技能探草、前后摇摆走位，防被蹲（@ 03:19~03:29）
- **决策分支**：
  - 对方中单完全靠过去了 → 看情况跟过去打架（@ 03:32~03:34）
  - 对方中单没完全过去 → 卡住他的位置，不给他舒服回中，下一波线就轮到你（@ 03:38~03:48）
  - 没有对方打野信息 → 和对方中路反方向去拿信息，再及时回中抢下一波（@ 03:51~04:10）
- **反例**：没线权就原地等下一波线。素材给出的正解是卡对方回中，直接把下一波线权抢回来，"转劣为优"（@ 14:17~14:21）。职业局 vs 路人局的差别：职业局辅助先给打野位置，多数时候走"慢慢跟"；路人局没信息，"先补信息"这条分支更常用
- **来源**：BV1WkKzzUEtq @ 03:02~04:10、14:17~14:21
- **可信度**：高
- **状态**：draft

### K-D51 想 GANK 边路：清完线再走 GANK 率低，要提前动就得放一波线

- **适用版本**：S45
- **触发条件**：想把中路优势转成边路人头，但清完线才动身
- **判断依据**：GANK 的逻辑是利用人数差，而三路兵线速度是一样的，中路清完再去 GANK，边路也差不多清完了，GANK 率肯定不高（@ 06:06~06:16）；所以可以选择放一波中路线不清，利用这个时间直接去边路，GANK 率会高很多（@ 06:16~06:21）
- **决策分支**：
  - 打野会补中线 → 放线，提前到边路打人数差
  - 打野不会补 → 不放线，改去帮对抗路，打完用传送阵回中，等于 GANK 对抗路 + 吃对抗路和中路两波线（@ 06:22~06:41）
- **反例**：按"清完线再走"的流程走，人是到了，边路那波线也没了。职业局 vs 路人局的差别：放线这条完全依赖打野补线，素材直接给了不需要配合的替代方案（去对抗路 + 传送阵），路人局不要照搬放线
- **来源**：BV1WkKzzUEtq @ 06:06~06:41
- **可信度**：高（给了不满足条件时的等价方案）
- **状态**：draft

### K-D52 中后期同一问升级成两问：能不能入侵、能不能推进，并且必须留中
