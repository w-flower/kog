# 03 前四分钟：第一条龙我争不争

> **依赖**：02 开局前90秒（结论：第一步站位由"本局核心是野还是中"决定）
> **被依赖**：04 对线期（本节产出的"我还在不在场上、状态够不够"是 04 判断树里 A2 分支的输入）

## 0. 上一节留下的问题

02 只解决了"第一步站哪"，它留下的是：**如果第一步没换到东西（一血没拿到、野没反成），接下来这三分钟怎么过？**

答案不是"补回来"，而是先把一个事实接住：**前四分钟逆风是常态，不是失误。** 素材里这一局在 3 分钟就已经 3v4 团灭过一次，原话是"前期逆风很正常"。

这一节要回答的，就是逆风之后第一个资源点该怎么处理。

## 1. 本节只回答一个决定

**4 分钟第一个资源点刷新，我这一波是去打，还是放？**

不是"怎么打赢这波团"，是**"我这波有没有资格站进去"**。

## 2. 判断树

```
资源点（4 分钟）刷新前 15 秒，清点自己这一侧的家底
│
├─ 我的"一次性资源"还在吗？（被动 / 大招 / 闪现）
│   ├─ 不在 → 【K-D15】放。别硬接，用这 40 秒去换别的东西
│   └─ 在 → 进下一判据
│
├─ 我方场上人数够吗？（刚复活的人能不能赶上）
│   ├─ 少人 → 【K-D15】放。少一个人不是"勉强能打"，是"必定打输"
│   └─ 齐 → 进下一判据
│
├─ 我方站位先到吗？（谁先占住龙坑侧的草）
│   ├─ 我方先到 → 【K-D16】争。先到的人决定这波团的形状
│   └─ 对面先到 → 不硬冲，改成"等他们打完/换另一侧资源"【K-D17】
│
└─ 以上任一条判"放"→ 复活/回线后的第一步，不要回自己的线
    → 【K-D18】先看小地图：谁在哪、谁状态不好
```

## 3. 判断依据

| 变量 | 在哪看 | 阈值 / 取值 | 影响哪个分支 |
|---|---|---|---|
| 一次性资源 | 被动图标 / 大招 CD / 闪现 | 有 / 无 | 第一个分叉 |
| 场上人数 | 复活计时 + 小地图 | 我方 < 对面 | 第二个分叉 |
| 龙坑侧草的归属 | 小地图视野 | 我方先占 | 第三个分叉 |
| 对面清完中线后的转向 | 兵线位置 + 小地图 | 大概率转向资源点 | K-D17 |
| 自己复活后的位置 | 小地图 | 谁在附近、谁状态差 | K-D18 |

## 4. 分支说明

### K-D14 前四分钟的逆风是常态，不要在落后时硬接团

- **适用版本**：S45
- **触发条件**：前四分钟内我方被团灭过一次 / 经济落后
- **判断依据**：落后量（一个人头以内算正常）+ 我方一次性资源是否还在
- **决策分支**：
  - 落后但资源在 → 只打"对面先交技能"的团，不主动开
  - 落后且资源不在 → 完全不打，先发育
- **反例**：「落后就要打回来」——前四分钟的经济差通常不到 500，硬接一次团灭会直接变成 2000，这才是真正拉开差距的地方。
- **依赖**：无；被 K-D15 依赖
- **来源**：BV1yke26fEYB @ 03:06；BV1yke26fEYB @ 03:08；BV1yke26fEYB @ 04:17
- **可信度**：中高（UP 主在团灭后立刻给出这句定调，并用自己的后续处理验证）
- **状态**：active

### K-D15 资源点争不争，先看自己有没有"一次性资源"

- **适用版本**：S45
- **触发条件**：4 分钟资源点刷新前
- **判断依据**：被动/大招/闪现是否可用；我方是否有人阵亡
- **决策分支**：
  - 资源在且人齐 → 可以争（见 K-D16）
  - 资源不在（如苏烈被动没装好）→ **放**，原话："没被动的时候就不要去硬接"
- **反例**：「龙不能放」——4 分钟的龙价值约等于一波半兵线，而一次团灭的价值远大于它。**放龙换 40 秒发育，是赚的。**
- **依赖**：依赖 K-D14；被 K-D17 依赖
- **来源**：BV1yke26fEYB @ 04:11；BV1yke26fEYB @ 04:13；BV1yke26fEYB @ 04:14
- **可信度**：中高
- **状态**：active

### K-D16 谁先占住龙坑侧的草，谁决定这波团的形状

- **适用版本**：S45
- **触发条件**：决定要争这个资源点
- **判断依据**：龙坑侧草的视野归属；我方是否有人能先手控
- **决策分支**：
  - 我方先占 → 让对面来冲，我们打反手（先到的人不用先交技能）
  - 对面先占 → 不要正面挤进去，改成拉边/等对面出来
- **反例**：「龙刷了五个人一起上」——五个人挤进一个口，等于把先手权交给对面。**先到不等于先打，先到是为了让别人先打你。**
- **依赖**：依赖 K-D15；被 K-D17 依赖
- **来源**：BV1yke26fEYB @ 03:47；BV1yke26fEYB @ 03:48；BV1yke26fEYB @ 03:51
- **可信度**：中（素材是"蹲草反打"的实战，结论方向明确但表述较口语）
- **状态**：active

### K-D17 争不到就换：对面全员在龙坑时，另一侧一定空着

- **适用版本**：S45
- **触发条件**：资源点被对面先占住，且我方人不齐/资源不在
- **判断依据**：对面几个人在龙坑附近；另一侧兵线在哪
- **决策分支**：
  - 对面 4 人以上在龙坑 → **不争**，去另一侧吃线/推塔/反野
  - 对面只有 2–3 人在 → 可以抢视野、逼他们分人
- **反例**：「他们打龙我们就去骚扰」——骚扰的收益是"可能抢到"，成本是"整队站位散在龙坑口"。换成另一侧的确定收益更划算。
- **依赖**：依赖 K-D16；与 `K-D01`（反方向拿资源）是同一条判据的不同时间尺度
- **来源**：BV1yke26fEYB @ 04:13（"到时候可以看情况选择放龙"）；BV1yke26fEYB @ 04:33
- **可信度**：中（"放"的动作有原话，"换什么"是从 `K-D01` 的框架推的，标中）
- **状态**：active

### K-D18 复活后的第一步不是回自己的线，是先读图

- **适用版本**：S45
- **触发条件**：阵亡后复活（前四分钟内最常发生）
- **判断依据**：小地图上 ① 谁在哪 ② 谁状态不好 ③ 哪条线正在被推
- **决策分支**：
  - 某一路我方有人且对面状态差 → **直接过去**，不要先回线
  - 全线都在安全位置 → 回自己的线，路过野区顺一下（不绕路才顺，见 `K-L05`）
- **反例**：「复活先回自己线补经济」——复活那 5 秒是你唯一"能选位置"的时刻，回线等于把这个选择权浪费掉。
- **依赖**：依赖 K-D15（放资源点之后的时间怎么用）
- **来源**：BV1yke26fEYB @ 04:17；BV1yke26fEYB @ 04:20；BV1yke26fEYB @ 04:23；BV1yke26fEYB @ 04:29
- **可信度**：中高（原话给了完整推理："小乔在下路、打野在野区、并且他状态不好，这时我们下一步一定是去下路"）
- **状态**：active

## 5. 本节的连锁错误（按节点挂）

- **在节点「一次性资源」上**：人会把"我血是满的"当成"我能打"，忽略被动/大招是否是这波的前提。苏烈没被动就是普通近战，盾山没能量就是一块木板。
- **在节点「人数」上**：人会用"他马上复活了"给自己找理由。差 3 秒也是少一个人。
- **在节点「先到」上**：人以为先到就要先开，于是把反手机会打成了正面硬冲。
- **在节点「放」上**：人放了龙却不知道去换什么，40 秒全队在中路晃——这是"放"最常见的执行失败。

## 6. 待验证 / 冲突

### 冲突 1：第一个资源点到底是 2 分钟还是 4 分钟

两条素材对不上，**必须挂在这里，不许挑一条当结论**：

| 来源 | 说法 | 时间 |
|---|---|---|
| BV1yke26fEYB @ 04:17（苏烈全局，S45 区间） | 「暴君刷新了」 | **4 分钟** |
| BV1X2jV6KEiP @ 03:47（射手教学） | 「马上也要来到我们的暴君团……4 分钟这个暴君」 | **4 分钟** |
| BV1fp4y1D7Wd @ 02:01（干货教练，五位置节奏） | 「2 分钟刷新的两条远古生物」 | **2 分钟** |

两条 6 月内的实战素材都说 4 分钟，只有那条理论框架视频说 2 分钟。**倾向按 4 分钟用**，但那条理论视频可能拍得更早（S44 或之前）。本节的所有判据与"几分钟"无关——它问的是"我有资格站进去吗"，所以结论不受影响。

### 干货教练给的"前期时间轴"（未与版本对齐，仅作参照）

BV1fp4y1D7Wd @ 01:44 起给了一串节点：中路第一波兵 → 30 秒第一轮野区 + 边路河蟹 → 第二波兵 + 1 分钟中路河道之灵 → 第三波兵 → 2 分钟远古生物 + 第四波兵。

**这套轴如果按"远古生物 2 分钟"成立，那么上文所有"4 分钟"的判断都要整体前移 2 分钟。** 用之前先在游戏里对一次刷新时间。

### 其他

- **4 分钟资源点的类型与数值**没有素材，本节只处理"争不争"的判断，不涉及打龙操作。
- 素材来自一局逆风局，**顺风局的前四分钟**（该不该加速、该不该越塔）没有样本。
- "对面先到就不冲"这条在强开团阵容下可能不成立（盾山/苏烈可以硬顶进去），需补一条阵容相关的分支。
