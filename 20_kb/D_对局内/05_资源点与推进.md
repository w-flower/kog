# 05 资源点与推进

> 素材：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）。这是**全位置通用**的一节 —— 资源刷新时间对五个人都一样，只是谁去争、谁去换不同。
> 上游是 `03_前四分钟.md`（第一条龙争不争），这一节接在它后面：**第一条龙之后，剩下的资源怎么排优先级**。

## 判断顺序

```
第 1 步：这局有哪些资源点可用？   → K-D19（先有一张时刻表，才有得选）
第 2 步：优势时，龙怎么拿才不翻车？→ K-D20（控血线，不拼惩）
第 3 步：劣势时，龙怎么换才不亏？  → K-D21（换 + 抢仇恨的时机）
第 4 步：打完团，推还是撤？        → K-D22（看前排还在不在）
第 5 步：要拆塔了，先拆哪座？      → K-D23（边塔 > 中塔，边路高地 > 中路高地）
第 6 步：大龙和主宰什么时候放？    → K-D24（把大小龙兵拉开距离）
```

### K-D19 资源点清单：记不住时间就别去偷

- **适用版本**：S45
- **触发条件**：任何时刻判断"现在有什么可争的"
- **清单（按刷新频率排）**：
  - **发育路红隼**（开局第一个可争点）
  - **对抗路河灵**（正常刷 3 只）
  - **双方赤甲**
  - **前期野区小野**（后期刷新速度不一致，**记不住时间就放弃偷**）
  - **Buff**
  - **2 / 4 / 8 / 10 分钟龙**，以及**风暴龙王**
- **决策分支**：
  - 你能说出下一个资源点**还有多久刷** → 可以围绕它打
  - 说不出来 → **放弃偷，去干确定的事**（解线、卡位）
- **反例**：「大概快刷了吧，我去看看」——"去看看"的成本是 10 秒 + 一次视野暴露，收益是零。资源点的全部价值在**提前 20 秒布置**，不在了才去就已经晚了
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：高（清单本身是客观事实；"后期小野刷新不一致"是版本特性，需定期复核）
- **状态**：active

### K-D20 优势方控龙：把龙血控在一万以上，别给对面拼惩的机会

- **适用版本**：S45
- **触发条件**：己方优势，正在打龙
- **判断依据**：龙的血量 vs 对面打野的位置
- **决策分支**：
  - 优势方 → **龙血控在一万以上**，慢慢打。**不要一路打到斩杀线**，那等于把龙交给一次 50/50 的拼惩
  - 对面打野不在（掉点/在另一侧）→ 可以直接打穿
- **反例**：「打得越快越安全」——快是给对面的机会。你打到 3000 血时，对面打野一个闪进来就是 50% 概率。控住血线，他进来只是送
- **为什么这条重要**：优势局的龙**不是资源，是陷阱**。你本来已经赢了，唯一输的方式就是在这里赌一次
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：高（与"优势不赌"的通用原则一致）
- **状态**：active

### K-D21 劣势方打龙：换，以及"抢仇恨"只在暴君放地震波时不行

- **适用版本**：S45
- **触发条件**：己方劣势，对面在打龙
- **决策分支**：
  - 首选 **换龙**（对面打这条，你去打另一条/去拆塔），不硬抢
  - 要抢 → 等**仇恨不转移的窗口过去**：**暴君放地震波期间仇恨不转移**，等波过完才能抢
- **反例**：「劣势也要抢龙翻盘」——劣势抢龙是 20% 成功率的事，换龙是 100% 拿到等值资源的事。翻盘靠的是**连续三次不亏**，不是一次赌赢
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高（"地震波期间仇恨不转移"是机制细节，需按版本复核）
- **状态**：active

### K-D22 团战打完之后：先看前排还在不在，再决定推还是撤

- **适用版本**：S45
- **触发条件**：一波团刚打完，双方都有阵亡
- **判断依据**：**己方前排还在不在**
- **决策分支**：
  - 杀了对面前排 → **先退，等 CD 再推**。这时候推塔等于替对面吸收伤害（他们的后排还有输出，你们的前排已经残了）
  - 自家前排掉点 → **立刻找对面开团**。前排一没，你们就再也开不了团了，只能被磨死
- **反例**：「团赢了就推」——赢的是人头，不是站位。前排残血时推塔，塔的伤害 + 对面后排的输出会把人头还回去
- **推广**：这条和第 3 节的"资源点"是同一个逻辑：**先看"我还有没有下一波的能力"，再决定要不要把这波收益最大化**
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active

### K-D23 压塔顺序：先边塔，假压高地转中；高地先清边线再清中

- **适用版本**：S45
- **触发条件**：优势方要拆塔
- **判断依据**：塔的价值 = 它后面能带出什么（超级兵/视野/进野区路线）
- **决策分支（按顺序）**：
  1. **先拆边塔**，再拆中塔
  2. 拆完边塔 → **假压高地，转中**（把对面的防守拉过去，再回头拆中）
  3. **上高地前先清边线，再清中线**，让三线同时到
  4. **边路高地优先于中路高地**——因为边路高地破了有**超级兵**
- **反例**：「中路是核心，先拆中塔」——中塔拆了只是打开地图，边塔拆了才有超级兵持续给压力。先拆中塔的收益是"能进野区"，先拆边塔的收益是"对面必须一直有人去清线"
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中高
- **状态**：active

### K-D24 主宰之镜的光：等小龙兵过一塔一点再放，把大小龙兵拉开距离

- **适用版本**：S45
- **触发条件**：己方拿了主宰之镜，准备放大龙兵
- **判断依据**：大小龙兵的**到达时间差**
- **决策分支**：**等小龙兵过一塔一点再放**大龙兵 → 两条线不会同时到，对面**必须交两轮技能**才能清完
- **反例**：「拿到就放，越早越好」——同时到 = 对面一波技能清两条。错开 10 秒 = 对面要交两次，而技能是有 CD 的
- **为什么这条是本节的收尾**：前面的 K-D19~D23 都在讲"什么时候动手"，这条讲"**动手的时机差本身就是收益**"。同一个资源，早放和晚放差一轮技能
- **来源**：冲击巅峰千强-辅助篇-总结.docx（BV1ydMZ6bE8n）
- **可信度**：中（单来源，且属操作细节，版本改动风险高）
- **状态**：active
