# 13 辅助：开局与对线设计：开局这四分钟，辅助的第一脚该往哪走

> 素材说明：三个视频。BV1ZYEx6nEKq 是 UP 主本人的高分局开局设计课（英文 AI 字幕，7:58），讲四类辅助的开局逻辑，是本节主骨架；BV19AQbBeEmX 是 S43 鲁班大师高分局实录（英文 AI 字幕，13:32），补对线与中后期站位；BV1uLsv6jErz 是粉丝投稿的张飞逐帧复盘（日语 AI 字幕，14:36，中低分段），专门暴露"贴人、只给盾、怕死让位"这类错误。时间戳整体可信（±2 秒），但三条字幕都是 AI 转写：英文线的英雄名有同音错写（Zephyrine、Yuan Fu、Zanis 等），日文线是二次转写、专名失真更重（盾山在不同段落被写成 Fortress 与 Dun Shan 两种）。凡拿不准的专名，本卡一律写"（听音疑似，待核）"或不指名，不当作事实。

## 判断顺序

```
第 1 步：先给自己和这局定性——我是四类辅助里的哪一类，
        敌方边路带的是闪现还是斩杀类召唤技。 → K-D136、K-D137

第 2 步：按定性选开局落点，只有五个选项：
        节奏边路抓 / 软辅边路 2v1 / 软辅对线压塔 /
        开团辅助中路或下路保线权 / 中辅双弱时的假视野+帮打野升 4。
        → K-D138、K-D139、K-D140、K-D146、K-D147、K-D149

第 3 步：决定对线期"贴人"还是"游走"，判据是对面辅助的类型，
        不是自己的习惯。 → K-D151、K-D152

第 4 步：对线期的固定动作链：换血 → 清线 → 吃中立 → 压塔 → 补视野，
        其中"只给盾不交一技能""没大位移进场"是两条硬禁令。
        → K-D141、K-D142、K-D153、K-D154

第 5 步：压塔时每一波都用地图和错位重新决定"打不打、退不退"，
        并把对方外塔当成诱饵去换对方中单的轮转。 → K-D143、K-D144、
        K-D145、K-D148、K-D150、K-D156

第 6 步：队友已经能独立推进后，辅助换岗位：做视野引诱、吃伤害、走侧翼。
        → K-D155、K-D157、K-D158

第 7 步：进入中期，站位按"半图"和"龙刷新时间"算，人数不够就不争龙。
        → K-D159、K-D160
```

### K-D136 开局第一步是给自己分类，不是先想"帮谁推线"

- **适用版本**：S45
- **触发条件**：BP 结束、进入开局读秒
- **判断依据**：素材把辅助分成开团（engage）、软辅（enchanter）、功能（utility）、节奏（Rhythm）四类；节奏辅助靠控制与锁敌技能定节奏，它的开局逻辑与前三类"完全不同"（@00:08、@00:12）。同时点明高分段的开局设计依据是阵容，不是单个英雄的打法习惯（@00:02）。
- **决策分支**：① 节奏类走边路抓机会，接 K-D138、K-D139；② 软辅走对线线权开局（K-D140）或边路 2v1（K-D139）；③ 开团类走 K-D146；④ 功能类素材只给了名字，没有落地，进「待补」。
- **反例**：把"开局＝帮中单推第一波线"当成通用答案。素材开篇就点名这是多数辅助的误区（@00:00）。
- **来源**：BV1ZYEx6nEKq @ 00:00 / 00:08
- **可信度**：高（UP 主本人讲解，四类框架在三个视频里都能对上；只有"功能辅助"没有展开）
- **状态**：draft

### K-D137 边路能不能直接抓，先看敌方边路带的是闪现还是斩杀

- **适用版本**：S45
- **触发条件**：准备选择"边路节奏开局"之前
- **判断依据**：素材给出的判据是"敌方边路有没有带闪现"（@00:29）；该局敌方边路亚瑟带的是斩杀（Execute）而不是闪现，因此可以直接执行边路开局（@00:35）。
- **决策分支**：① 不带闪现 → 一级控制链命中率高，走 K-D138；② 带闪现 → 一级控制可能被闪现化解，素材没有给替代方案，进「待补」。
- **反例**：不看召唤技就按固定套路进草丛，控制被闪现躲掉，等于白送一波线权，还暴露了自家打野的开野方向。
- **来源**：BV1ZYEx6nEKq @ 00:29 / 00:35
- **可信度**：中（"Execute"被 AI 译成"斩杀"，具体对应哪个召唤技要按游戏内核对；"边路带闪现"是判据本身，可直接用）
- **状态**：draft

### K-D138 节奏辅助的边路开局是一条八动作流水线，不是一次蹲草

- **适用版本**：S45
- **触发条件**：K-D137 判定敌方边路无闪现，且己方是节奏型辅助
- **判断依据**：八个动作在素材里逐条给出：从河道绕上去（@00:41）、等对方上来清线（@00:44）、从草丛突然出来交一级控制（@00:46-00:47）、拿一血（@00:50）、帮队友清线（@00:54）、吃对方野区资源（@00:55）、拿赤甲（@00:57）、清兵拿空间之灵（@00:58）、用传送阵回边路对射手（@01:00-01:02）。
- **决策分支**：① 一血拿到 → 继续走后半段资源；② 一血没拿到 → 同样走后半段，素材明确说不拿一血也不会在金币和整体发育上落后（@01:09-01:11）。
- **反例**：只蹲一血、不做后半段资源。一血失手就真的空手回线，而素材的兜底逻辑正是为"失手"准备的。
- **来源**：BV1ZYEx6nEKq @ 00:41 / 00:54 / 01:00
- **可信度**：高（流程逐帧可对；"赤甲/空间之灵"是 AI 译名，具体野怪机制按游戏内为准）
- **状态**：draft

### K-D139 节奏软辅的边路开局，是"假装骚扰中路、真实打边路 2v1"

- **适用版本**：S45
- **触发条件**：己方是带节奏能力的软辅，且双方中路前期都弱
- **判断依据**：素材说该局双方中路前期都很弱（@01:23），所以开局仍然打边路；操作是假装骚扰中路，真实目标是抓对方边路蒙恬，同时阻止对方打野入侵（@01:26-01:30）；等对方清线、利用其边路"二级强势反打"的心理，2v1 突然跳脸（@01:32-01:38）；貂蝉的传送也在计划内，不要被对方两人组吓退，因为貂蝉战斗很弱（@01:40-01:46）。
- **决策分支**：① 对方边路压线 → 等他交技能后 2v1；② 对方打野有入侵意图 → 这次开局同时兼作反入侵，先挡路径再打人。
- **反例**：真的把技能交在中路。等于用软辅最弱的前期去换对方最强的中路，边路那次 2v1 机会同时消失。
- **来源**：BV1ZYEx6nEKq @ 01:26 / 01:32 / 01:40
- **可信度**：中（"Zephyrine"为 AI 转写，具体英雄待核；战术逻辑本身清晰可执行）
- **状态**：draft

### K-D140 软辅既然选了对线开局，就必须拿绝对线权

- **适用版本**：S45
- **触发条件**：软辅开局不走边路抓，走标准对线
- **判断依据**：素材要求维持"绝对线权"，不能让敌人在线上舒服（@02:21-02:23）；执行是三步：先换血、再清线、然后立刻吃中立赤隼（@02:30-02:33）；依据是软辅自带强力增益，换血不吃亏（@02:35-02:37）。
- **决策分支**：① 对方前期无法争夺 → 按三步走，接 K-D141；② 对方能争 → 素材未讲处理方式，进「待补」。
- **反例**：选了对线开局却只站着给盾、不换血也不吃中立，等于把软辅唯一的先天优势扔掉，还让对面白拿线权。
- **来源**：BV1ZYEx6nEKq @ 02:21 / 02:30 / 02:35
- **可信度**：中高（战术清楚；"Yuan Fu"为 AI 转写，示范英雄待核）
- **状态**：draft

### K-D141 线权第二步是压塔，压塔有两个可量化动作

- **适用版本**：S45
- **触发条件**：己方已拿到线权、兵线正在推进
- **判断依据**：素材要求在塔的攻击范围外打塔（@02:54）；辅助白条（被动）在敌方塔下命中敌方英雄时，会打断其回血包的恢复（@03:06-03:13），这是持续施压的实招；同时保持磨塔节奏（@03:02）。
- **决策分支**：① 对方辅助去游走 → 无视，给队友打信号，继续拆（@03:00）；② 对方回防 → 立刻转 K-D145 的地图判读。
- **反例**：只把兵线推过去、不碰塔。素材的原话是，这样做就浪费了软辅的对线优势，而且要考虑到前面差点拿到人头（@05:56-06:02）。
- **来源**：BV1ZYEx6nEKq @ 02:54 / 03:02 / 03:06
- **可信度**：高（"白条打断回血"是可验证的机制描述，不是主观评价）
- **状态**：draft

### K-D142 压塔前先把视野铺到河道侧翼，控住塔前三个草丛

- **适用版本**：S45
- **触发条件**：准备进入持续压塔阶段
- **判断依据**：素材要求二技能必须从河道侧翼铺出去（@03:24），并在这三个前方草丛拿到视野（@03:28）；同时看小地图判断对方是否回防（@03:21）；对方其他路开打也不要慌，这段时间正是磨塔的黄金时间（@03:29-03:33）。
- **决策分支**：① 三个草丛有视野 → 可以持续压；② 视野缺失 → 先补视野再压，不补不压。
- **反例**：视野没铺就贴塔，被对方从河道侧翼绕后。压塔节奏一断，前面两分钟的线权白攒。
- **来源**：BV1ZYEx6nEKq @ 03:21 / 03:24 / 03:28
- **可信度**：高（"三个草丛""河道侧翼"都是可复现的位置指令）
- **状态**：draft

### K-D143 错位原则：ADC 回城、辅助还在线上，这两三秒就是开打窗口

- **适用版本**：S45
- **触发条件**：观察到对方双人组状态不同步
- **判断依据**：素材的原话是"敌方 ADC 回城、辅助还在线上"，此时直接过河开打、主动吸引注意（@03:59-04:06）；即使对方中单转过来，2v2 也不用怕（@04:08-04:11），因为对方中单的轮转已经被拖成后手（@04:13-04:15）；而一旦拿到这个关键节奏，对方上外塔很快就会掉（@04:21-04:22）。
- **决策分支**：① 对方双人组错位 → 开；② 对方双人齐、状态满 → 不开，退回 K-D142。
- **反例**：对方双人齐、满血满技能时硬开，错位原则立刻变成送双杀，还把刚拿到的推塔节奏交出去。
- **来源**：BV1ZYEx6nEKq @ 03:55 / 03:59 / 04:11
- **可信度**：高
- **状态**：draft

### K-D144 压塔的收益是"逼对方来支援"，拆塔只是副产品

- **适用版本**：S45
- **触发条件**：己方正在压塔，对方多人不在这一路
- **判断依据**：打塔的同时把伤害弹到对方 ADC 身上（@03:38-03:39），ADC 残血被迫回城（@03:50），对方全队因此必须来支援（@03:43-03:46），而他们来的时候正好踩进布置好的陷阱（@03:46-03:47）；反过来，对方放弃守塔（刘邦放掉下路、用大招支援）就直接拆（@05:50-05:54）。

- **反例**：只推线不压塔。对方不需要回防，你既没拿到塔，也没拿到对方的轮转时间，两头空。
- **来源**：BV1ZYEx6nEKq @ 03:38 / 03:43 / 05:50

### K-D145 压塔期间，对方中单出现在哪一路，直接决定继续压还是立刻退

- **反例**：不看地图、靠"感觉对面不会来"继续压。被抓一次就把前面三分钟的线权连本带利吐回去。
- **来源**：BV1ZYEx6nEKq @ 05:13 / 05:30 / 05:43
- **可信度**：高（判据是"某个具体英雄出现在地图上"，属于可量化的观察点）

### K-D147 中辅双弱时的第三种开局：假视野 + 帮打野加速到 4 级

- **适用版本**：S45
- **触发条件**：己方中单与辅助的前期对线都弱
- **判断依据**：素材明确这套一般用在中单和辅助前期对线弱的时候（@01:13-01:15）；操作是先假装去下路支援、实际只给假视野（@01:03-01:05），再转进野区帮打野清得更快，顺便吃经验（@01:07-01:11）；假视野的作用是让对方 ADC 和辅助不敢激进压上（@01:18-01:21）。
- **决策分支**：① 低分局 → 出野区后很容易直接开一波（@01:23-01:26）；② 高分局 → 对方大概率知道你在做什么，假视野只剩"拖时间"价值（@01:28-01:31）。
- **反例**：中辅都弱还去中路对拼。等于用自家两条最弱的线，去接对方最强的两波时间，野区还没人看。
- **来源**：BV19AQbBeEmX @ 01:03 / 01:07 / 01:18
- **可信度**：中高（操作描述完整；"分段越高效果越弱"是 UP 主自己给的边界，不是外部推测）
- **状态**：draft

### K-D148 推完线不要直接开中立野怪，先去拦对方中辅的进场路径

### K-D149 己方中路清得快，就反向利用对方"法师清线快不用帮"的心态

- **适用版本**：S45
- **触发条件**：己方中单清线速度不低于对方中单
- **判断依据**：素材说这种情况下开局可以直接去中路（@07:05），利用的是对方辅助认为"嫦娥清线快、不需要帮"的心理（@07:07-07:10）；2v1 时可以适当前压（@07:11），然后立刻回身用技能清线（@07:14）；不同阵容的清线速度差大约 2-3 秒（@07:16-07:18），这个差值就是压中的窗口。
- **决策分支**：① 有 2-3 秒以上的清线优势 → 压中；② 双方清线速度接近 → 本条不成立，回 K-D146。
- **反例**：双方清线速度接近时硬压中。2v1 打不出人数差，反而把中单原本稳定的补刀节奏打乱。
- **来源**：BV1ZYEx6nEKq @ 07:05 / 07:07 / 07:16
