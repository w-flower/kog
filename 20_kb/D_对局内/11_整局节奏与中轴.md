# 11 整局节奏与中轴

> 素材说明：唯一来源是 B 站 UP「离别-极致打野教学」的《十分钟精讲·王者底层逻辑》（BV1nMLQ6XE7j，10:01，AI 字幕 ai-zh，430 条 cue）。全分路讲解、打野视角为主，作者自述"2400 分以下通用、付费级全分路教学"，属单人观点而非实测数据。可信度边界有三条：① 4 分钟之后的细节，作者在 09:29–09:39 明确说"这期缺少的点下期再拆解"，所以本卡对 4–15 分钟只能给框架、给不了操作；② 字幕是 AI 转写，个别句子主语错位、专有名词被吃（如 04:14 的"B站开往发育路"），已在文末标注；③ 没有段位统计与对局样本，"2400 分以下通用"是作者自评。凡素材没有的，一律进「待补」，不靠常识补。

## 判断顺序

```
第 1 步：先报当前分钟数，确认自己在五段中的哪一段（0 / 0–4 / 4–7 / 7–10 / 10–15） → K-D91
第 2 步：0 分钟只做两件事——阵容分析、打法整体规划，并落成开局路线 → K-D92
第 3 步：0–4 分钟只认刷钱、人数差、资源点三件事，不把人头当 KPI → K-D93
第 4 步：判断中轴现在归谁：中线过了没、中草有没有视野、中野辅三点到了几个 → K-D95
第 5 步：用"过线速率 → 线权 → 视野 → 切双边"这条链决定要不要从中路转出去 → K-D96
第 6 步：打野按四象限选开局：边野强 → K-D98；中轴强 → K-D99；两片都强 → K-D100；两片都弱 → K-D101
第 7 步：0–4 的抓人由中辅承担，辅助跟中单动；中单空窗期先给打野提速再加压 → K-D102 / K-D103 / K-D104
第 8 步：任何一次想过线、放线、蹭线，先过"野区绝对安全"这道闸门 → K-D105 / K-D109
第 9 步：第一波中线过完选边，默认去另一片半图，出现三种局内变量再改道 → K-D106 / K-D107
第 10 步：3:47 龙团线按阵容强度三向分流；4 分钟后才转主动带节奏；4–15 的框架清单见 K-D94，弱势中单放线见 K-D108 → K-D110 / K-D97 / K-D94 / K-D108
```

### K-D91（全局视角） 先报分钟数，再谈该做什么

0–15 分钟按职业逻辑切成五段：0、0–4、4–7、7–10、10–15；每个分段落到每个位置的权重完全不同，所以"这一波该不该上"必须先由"现在第几分钟"来回答（@ 01:14）。

- **适用版本**：S45
- **触发条件**：开局读条时定一次，之后每次复活、回城出装、团战结束后重新报一次分钟数。
- **判断依据**：当前分钟数落在 `0`、`[0,4)`、`[4,7)`、`[7,10)`、`[10,15]` 哪一档（@ 01:23）；同理，同一个决策在中单身上和打野身上权重不同（@ 01:16）。
- **决策分支**：档位 0 → 只做 K-D92；0–4 → 只做 K-D93；4 分钟后 → 按 K-D94 的清单逐项推进，同时打野转主动带节奏（K-D97）。
- **反例**：用一套"抓人开节奏"的模板打满 15 分钟；或者 3 分钟就在边路蹲 15 秒等一个不确定的 GANK——0–4 的主线根本不是抓人（@ 04:18）。
- **来源**：BV1nMLQ6XE7j @ 01:14
- **可信度**：中高（五分法是素材开篇主干，表述明确；但只给了"每段包含哪些知识点"，没给每段的判定阈值）。
- **状态**：draft

### K-D92（全局视角） 0 分钟只产出两个东西：阵容结论 + 开局路线

开局阶段的知识点只有两块——阵容分析、打法思路的整体规划；开局路线是分析结果，不是习惯（@ 01:29）。

- **适用版本**：S45
- **触发条件**：BP 结束到第一波兵线交汇前。
- **判断依据**：己方强势点落在边野还是中轴（@ 03:21）；己方核心数量是否多于对面、是否存在明显克制关系（@ 09:16）。
- **决策分支**：强点=边野 → 走 K-D98；强点=中轴 → 走 K-D99；两片都强 → 走 K-D100；两片都弱 → 走 K-D101；核心多／被克制 → 直接进入保发育档（K-D110 的第三支）。
- **反例**：不看阵容，每把固定红开；或者分析完阵容只停在嘴上，没有兑换成一条具体路线。
- **来源**：BV1nMLQ6XE7j @ 01:29
- **可信度**：高（素材反复把"阵容分析决定开局"当作打野第一步，01:32、03:21、09:16 三处呼应）。
- **状态**：draft

### K-D93（全局视角） 0–4 分钟只结算三件事：刷钱、人数差、资源点

前期的核心是资源点争夺，争夺要靠人数差，人数差的前提是先刷出经济；人头只是这三件事的副产品（@ 01:51）。

- **适用版本**：S45
- **触发条件**：0:00–4:00 全程，每一次路线选择都用这三条过一遍。
- **判断依据**：每分钟经济是否在涨；局部是否形成多打少；资源点是否刷新（约 70 秒一轮，@ 05:24）；兵线 33 秒一波（@ 05:27）。
- **决策分支**：能顺手拿资源 → 拿；拿不到 → 回野区或回线继续刷；为一个人头要放弃半片野 → 不换。
- **反例**：0–4 把"抓到人"当 KPI，为蹲人漏掉整片野区，4 分钟龙团时经济不够、开不出团（@ 05:50）。
- **来源**：BV1nMLQ6XE7j @ 01:51
- **可信度**：高（"前期是围绕着刷钱以及人数差来进行的资源掠夺"是素材原句结构，@ 01:35）。
- **状态**：draft

### K-D94（全局视角） 4–15 分钟只有框架，没有操作——本卡不往下编

4–7 与 7–10 的关键词是龙团争夺、野区入侵、兵线运营、半图推进；10–15 的关键词是 10 分钟龙团、半图推进、上高地；作者只列了清单，没有展开（@ 01:38）。

- **适用版本**：S45
- **触发条件**：比赛进入 4 分钟以后，需要用"这个时间段该考虑什么"做自检时。
- **判断依据**：4 分钟后开始主动带节奏（@ 04:21）；7 分钟后把单点优势转成半图控制；10 分钟后围绕 10 分钟龙团决定推进方向（@ 01:43）。
- **决策分支**：4–7 → 先问"龙团能不能打、对面野区能不能进"；7–10 → 先问"哪一路兵线能被我运营成半图推进"；10–15 → 先问"10 分钟龙团赢不赢、赢了推哪条线"。
- **反例**：把这条当操作手册，5 分钟就照"上高地"的思路压塔——素材没有给这个时间点的推进阈值。
- **来源**：BV1nMLQ6XE7j @ 01:38
- **可信度**：低（纯框架列举，零操作细节；作者在 09:29–09:39 明说这部分留到下期，本卡不作补写）。
- **状态**：draft

### K-D95（全局视角） 中轴 = 中线 + 整个中草，责任人 = 中野辅三点

中轴不只是"一条中路兵线"，而是一整条中线向外扩散、包含整个中草；抢中轴从来不是中单一个人的事，是中野辅三个能频繁动起来的位置合起来才算数（@ 02:01）。

- **适用版本**：S45
- **触发条件**：任何需要判断"中轴在谁手里"的时刻——抢线前、进野前、开龙前。
- **判断依据**：中线是否先过完（过线速率）；中草有没有己方视野或站位（@ 02:05）；能动的三点（打野、辅助、中单）此刻有几个在中路半区（@ 02:37）。
- **决策分支**：三点齐 → 抢中轴并切双边；只有中单 → 不抢，退塔下等线（转 K-D108）；只有中野 → 可抢线，但不进中草深处。
- **反例**：中单一个人顶着对面中辅抢中草，被抓后怪打野不来——中轴本来就不是一个人的责任（@ 02:13）。
- **来源**：BV1nMLQ6XE7j @ 02:01
- **可信度**：高（素材对"中轴"的定义与责任人讲得最完整，02:01–02:39 连续铺陈）。
- **状态**：draft

### K-D96（中单视角） 抢中轴抢的是过线速率，链条终点是双边人数差

中线先过完的一方先落位、先切双边、先形成人数差；而线权的前提是视野，视野的前提是抢到草（@ 02:17）。

- **适用版本**：S45
- **触发条件**：每波中线即将交汇；或准备从中路转向双边、野区、龙坑前。
- **判断依据**：己方清线是否快于对面；中线过完后能否第一时间进中草（@ 04:51）；双边此刻是否同人数（同人数下先到的一方即人数差，@ 06:29）。
- **决策分支**：过线快 + 有视野 → 立刻切边；过线快但草里没视野 → 先拿草再切；过线慢 → 不放线，先守线（K-D105）。
- **反例**：线没过完就游走，双边没形成人数差、自己还漏一波线，等于两头空。
- **来源**：BV1nMLQ6XE7j @ 02:17
- **可信度**：中高（链条完整；但"多快算快"没有量化，只能靠实际清线对比，素材没给秒数）。
- **状态**：draft

### K-D97（打野视角） 打野 0–4 的主线是刷钱，4 分钟才轮到主动带节奏

0–4 分钟抓人不是打野的本职，主线是"在安全高效的刷钱路线上顺手捡节奏"；主动找节奏是 4 分钟以后的事（@ 03:08）。

- **适用版本**：S45
- **触发条件**：0:00–4:00 的每一次路线选择；4:00 后的每一次主动开节奏。
- **判断依据**：抓这一下会不会让自己少过一片野；有没有不用绕路、不用蹲的必杀机会（@ 03:14）；3 分钟时经济是否足以支撑 4 分钟龙团（@ 05:50）。
- **决策分支**：不绕路且有把握 → 顺手抓；要绕路或要蹲 → 放弃，继续刷；4:00 之后 → 转为主动带节奏（@ 04:21）。
- **反例**：0–4 为一个没控制的边路蹲 15 秒，回来发现自家半片已被对面刷完，龙团经济差一截。
- **来源**：BV1nMLQ6XE7j @ 03:08
- **可信度**：高（"四分分钟之后才需要主动考虑带节奏"是原句，@ 04:21）。
- **状态**：draft

### K-D98（打野视角） 边野强、中轴弱：发育路开，速刷到对抗路，控资源点与传送阵

当强势点在边野、弱势点在中轴，走当前版本的发育路线：发育路一侧开、速刷到对抗路，目标是对抗路的资源点和传送阵（@ 03:21）。

- **适用版本**：S45
- **触发条件**：BP 后判定己方边野强于对面、中轴弱于对面（@ 03:24）。
- **判断依据**：边野一侧是否有线权、至少不被越；中轴三点是否凑不齐（K-D95）；对抗路资源点与传送阵的刷新时间。
- **决策分支**：边野有线权 → 按此路线同时控资源点 + 传送阵；边野只有半优势 → 只控资源点，不强求传送阵。
- **反例**：中轴明明打不过还硬抢中草，把自己速刷路线打断，对抗路资源点反被对面拿走。
- **来源**：BV1nMLQ6XE7j @ 03:21
- **可信度**：中（路线描述具体；但"河灵节奏"是版本用语，S45 是否仍沿用这个叫法待核，素材也没给节点秒数）。
- **状态**：draft

### K-D99（打野视角） 中轴强、边野弱：以中轴为主线，抢出线权再让中路转边

中轴强势、边野劣势时，打野围绕中路线权提前落位，靠强度差 + 人数差把线权抢出来，目的是让中路能更好地游走支援（@ 03:33）。

- **适用版本**：S45
- **触发条件**：己方中野辅强度高于对面，双边对线打不过。
- **判断依据**：中野辅三点能否在兵线交汇前到位（K-D95）；抢出线权后，中路是否有可去的边（K-D106）。
- **决策分支**：三点齐 → 抢线权 → 中路立刻转边；只到两点 → 抢线但不转边，先保中塔。
- **反例**：中轴强却让打野去补弱势边路，中路线权一丢，唯一的强势点也没兑现。
- **来源**：BV1nMLQ6XE7j @ 03:33
- **可信度**：中（逻辑清楚；但同样缺时间阈值，且"强度差"没给量化标准）。
- **状态**：draft

### K-D100（打野视角） 两片都强：看英雄类型分边野或分中轴

中轴与边野都有优势时，开局路线改由所选打野的类型决定：速刷节奏型（盘古、玄策、大司命）优先边野；压制型（老虎、马超、"飞"）多切中轴抢线权、打状态（@ 03:41）。

- **适用版本**：S45
- **触发条件**：BP 后判定两片都不劣。
- **判断依据**：所选打野的强度兑现方式是"前中期小规模团战"还是"压状态、抢线权"（@ 03:45）；哪一片的资源点更值钱。
- **决策分支**：速刷型 → 边野速刷，多拿资源点、多顺路 GANK（@ 03:53）；压制型 → 切中轴抢线权 + 打状态，再用时间差/状态差切双边（@ 04:01）。
- **反例**：明明是速刷型，却在中路反复抢线，把前中期最强的边野小团窗口浪费掉。
- **来源**：BV1nMLQ6XE7j @ 03:41
- **可信度**：中（英雄举例明确；"飞"疑为 ASR 省略，原英雄名待核）。
- **状态**：draft

### K-D101（打野视角） 两片都弱：避开强势侧、往发育路一侧刷，用少亏换置换空间

中轴与边野都弱时，选择风险规避：避开对面强势侧、往发育路一侧刷，把目标从"拿资源"降级为"少亏 + 保置换可能"（@ 04:13）。

- **适用版本**：S45
- **触发条件**：BP 后判定两片都劣；或前 2 分钟已被对面压进野区。
- **判断依据**：对面打野的强势侧在哪（决定要避开哪片）；发育路一侧是否还能安全吃线、守塔。
- **决策分支**：弱侧能安全刷 → 刷完再找置换；连弱侧都不安全 → 主动放弃一片野，换对面另一片半图或一座塔（与 K-D110 第三支同源）。
- **反例**：两片都弱还按"边野强"的路线去对抗路控资源点，正面撞上对面强势打野。
- **来源**：BV1nMLQ6XE7j @ 04:13
- **可信度**：低（关键句"则可以选择B站开往发育路去刷"是明显 ASR 噪声，"B站"应为"避开/蓝开"一类，方向靠上下文推，原意待核，@ 04:14）。
- **状态**：draft

### K-D102（辅助视角） 0–4 的抓人是中辅的活，辅助不跟中单动，等于放弃前期 GANK

前期抓人的目的只有三个——打状态、拿资源、缓解对线压力；这三件事由能频繁动起来的中辅承担，不是打野（@ 04:26）。

- **适用版本**：S45
- **触发条件**：0–4 分钟，中路第一波兵线已过、双边处于同人数。
- **判断依据**：中单是否已过完线（@ 06:21）；辅助是否已把中草/河道视野踩住（@ 04:51）；边路此时是否同人数（多去一个人就是人数差，@ 06:29）。
- **决策分支**：中单过线 → 辅助跟中单进中草，再一起切边；中单没过线 → 辅助先站中草做视野，不单独深游。
- **反例**：辅助全程赖在发育路陪 ADC 对线，中单独自抢中草被抓，双边始终形不成人数差。
- **来源**：BV1nMLQ6XE7j @ 04:26
- **可信度**：中（"前期要抓人、要缓解对线压力，看的是中辅"表述明确；但辅助具体站位与到场秒数素材没给，05:00 那句主语混乱需核）。
- **状态**：draft

### K-D103（中单视角） 中单的空窗期用来给打野提速过野区，不是蹲边

中单前期有大量空余时间（资源点 70 秒一轮、兵线 33 秒一波，中间那段没人一直漏破绽），正确用法是切进野区帮打野提速，然后带着这个打野一起去抢视野与线权（@ 05:24）。

- **适用版本**：S45
- **触发条件**：中单已过完一波线、双边兵线不交汇、没有资源点可争（@ 05:28）。
- **判断依据**：打野还差多少野没收（差半片以上才值得提速）；对面中单是否也在同样空窗；无意义蹲伏的期望产出是否为零（@ 05:32）。
- **决策分支**：打野差半片以上 → 去提速；打野即将收完 → 直接跟打野抢中草；双边正在打、有明确人数差机会 → 守线待机。
- **反例**：空窗期去边路蹲 10 秒，对面没露破绽，自己漏了下一波线，打野还没刷完。
- **来源**：BV1nMLQ6XE7j @ 05:24
