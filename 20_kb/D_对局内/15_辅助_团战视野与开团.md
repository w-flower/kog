# 15 辅助：团战、视野与开团

> 素材说明：8 个视频均为 UP 主「欺压ya」的辅助（游走位）教学，主体是高分局/高 rank 的逐帧复盘与视野专题；视角以辅助第一人称决策为主，个别片段切到苏烈、张飞、空空儿、刘禅等具体英雄的操作。字幕为 AI 自动转写，时间戳整体可信（±2 秒），英雄名与专有名词存在同音错字，拿不准处按「不指名」或「（音译，待核）」处理。素材覆盖的是「高分局辅助怎么想」，不等于所有分段都适用；低分段与具体数值差异进「待补」。

## 判断顺序

```
第 1 步：开局先判断敌方打野前期强弱，决定第一波保野区/争中还是跟 ADC → K-D186
第 2 步：对线期结束（约 4 分钟龙标记）主动切换决策模式，不再按开局公式 → K-D187
第 3 步：布任何视野前先做预判（打野路线、中单游走、下一波团战地点），再选视野目的 → K-D189
第 4 步：按目的选视野打法：防 gank → K-D190；资源点进攻 → K-D191；钓鱼 → K-D192；落后预判进攻 → K-D193；中塔施压 → K-D194；抓落单 → K-D195；埋伏 → K-D196；十分钟龙 → K-D197；反蹲 → K-D198
第 5 步：四分钟龙团若已丢先手，改「后手入场」，不硬抢河道视野 → K-D188
第 6 步：十分钟龙前先控中路线权，辅助留中，不跟队友去边路 → K-D206
第 7 步：龙团用「开龙逼团」，不要等龙打完再打团 → K-D207
第 8 步：开团前确认阵型：辅助站最前，C 位不扎堆 → K-D199；辅助的职责是保阵型/找反开位，不是贴 C 位 → K-D205
第 9 步：确认开团信号：兵线交汇、敌方关键技能交掉、敌方密集/成直线 → K-D201；用假退/示弱掩盖意图 → K-D202；用零成本视野先确认 → K-D208
第 10 步：团战开打后判断先手/反手：队友先手→侧翼二手反开 → K-D203；C 位被抓救不了→放弃保 C 位换后排 → K-D204；目标优先级先锁前排/开团手 → K-D200
第 11 步：抓单/团战结束后立刻转化资源：转龙/转塔，辅助挡救援路线 → K-D209；落后时按「边路逼技能→冲中逼团」模板 → K-D210
```

### K-D186 开局先判断敌方打野前期强弱，再决定第一波跟谁

- **适用版本**：S45
- **触发条件**：开局 0:00–1:00，辅助选择第一波站位。
- **判断依据**：素材把「敌方打野前期强」作为分流条件：强则不直接跟 ADC，优先保护野区、帮抢视野或争中，或帮打野快速清野、gank、反蹲、在对抗路四级线争人数优势（@ 00:07）。素材只给定性条件，未给数值；落地时可观察为「敌方打野开局是否直接进野区、我方打野是否需要队友帮守 buff」。
- **决策分支**：敌方打野前期强 → 第一波靠野区/中路；敌方打野前期弱 → 可以按常规跟 ADC 压线。
- **反例**：敌方打野前期强却直接跟 ADC，野区被入侵时辅助不在，打野节奏断档。
- **来源**：BV19Ch462ELH @ 00:07
- **可信度**：中（单条概述，未给不同分段验证）
- **状态**：draft

### K-D187 对线期结束（约 4 分钟龙标记）必须主动切换决策模式

- **适用版本**：S45
- **触发条件**：对线期结束、约 4 分钟龙标记前后。
- **判断依据**：素材指出开局公式相对固定，但对线期结束后很多人不会判断整体节奏，问题常出现在 4 分钟龙标记之后（@ 00:41）。可观察信号为「一塔告破/第一条龙刷新/双方开始抱团」。
- **决策分支**：从「按开局公式跟 ADC」切换到「按下一波资源点、视野点、团战节点」决策；每次行动前先问「下一波资源在哪、我站哪能先看到」。
- **反例**：继续按开局公式跟 ADC，错过第一条龙或第一波中塔节奏。
- **来源**：BV19Ch462ELH @ 00:41
- **可信度**：中（作者经验总结，无量化验证）
- **状态**：draft

### K-D188 四分钟龙团已丢先手时，改「后手入场」，不硬抢河道视野

- **适用版本**：S45
- **触发条件**：4 分钟暴君刷新，敌方已先设伏/做好视野，己方打野不能立刻到。
- **判断依据**：素材说此时通常已丢先手，必须采用「后手入场」心态；不能直接进河道做视野；重点从「拿龙」变成「开团锁人」；可利用打野/上单延迟入场，从河道两侧先手（@ 00:14、@ 00:30、@ 00:44）。
- **决策分支**：ping 敌方 ADC/辅助动向 → 盯龙血量 → 等队友到位 → 从河道两侧先手；敌方不开龙则不硬接，保持后手。
- **反例**：明知敌方已设伏还直接进河道抢视野，被消耗后丢龙。
- **来源**：BV1814C61EQw @ 00:14
- **可信度**：中（单一视频，但步骤具体）
- **状态**：draft

### K-D189 视野的本质是「猜」：先预判再布视野

- **适用版本**：S45
- **触发条件**：每次决定插眼、蹲草、探草前。
- **判断依据**：素材把视野的本质定义为「不是看，是猜」：猜敌方打野路径、猜中单游走时机、猜下一波团战爆发点（@ 00:03）。另一条素材补充：敌方软辅阵容会主动避视野，提前绕边路，在下一波暴君刷新时抢占有利位置（BV1cL7V6HE8b @ 02:47）。可观察信号为「敌方打野最后露头的位置」「中单消失的方向」「边路兵线谁先动」。
- **决策分支**：先写预判（敌方最可能从哪来、什么时候来）→ 再选眼位/蹲点位；没有预判的「看草」只算被动。
- **反例**：只把眼插在草里等敌人来，不预判路径，视野拿不到信息。
- **来源**：BV1uMEx6BEvz @ 00:03；BV1cL7V6HE8b @ 02:47
- **可信度**：高（总纲，多个视频行为印证）
- **状态**：draft

### K-D190 防 gank 视野：敌方中单频繁游走时，不推塔、退河道草反蹲

- **适用版本**：S45
- **触发条件**：敌方中单机动高、频繁游走（素材例子：连续压上路）。
- **判断依据**：ADC 正常清线，辅助留技能看小地图观察游走路径；敌方一直抓上时绝对不要推塔；退到河道草附近等下一次 gank；敌人本能会用技能探草，辅助后撤一点装作草里没人，等敌人放松瞬间出手（@ 00:46）。这套打法成本低，即使被敌人发现，也只是决定「打不打」。
- **决策分支**：敌方中单游走 → 不推塔、退草反蹲；敌方不探草 → 放弃这波，不硬蹲。
- **反例**：敌方中单明显游走还压塔，被反包。
- **来源**：BV1uMEx6BEvz @ 00:46
- **可信度**：高（有完整操作链）
- **状态**：draft

### K-D191 资源点进攻视野：先藏视野，用野怪钓敌人出塔

## 冲突与条件差异

1. **四分钟龙团：先抢视野 vs 后手入场。** 一条素材主张辅助提前到、抢中左河道视野，认为「这个位置绝不能让」（BV18B7s6NESY @ 03:50–04:06）；另一条素材主张己方已丢先手时改「后手入场」，不要直接进河道（BV1814C61EQw @ 00:07–00:14）。差异在前提：己方阵容前期是否更强、打野能否先到、敌方是否已经设伏。不能把「后手入场」当成所有龙团的通用答案，也不能在已经丢先手时硬抢。
2. **开团目标：先锁前排 vs 放弃保 C 位换后排。** 一条素材明确「集火前排不是后排」（BV18B7s6NESY @ 03:03）；另一条素材在 ADC 被东皇闪抓、已经救不回时，主张放弃保 C 位、直接冲敌方后排（BV1RChB6LE5i @ 00:56）。差异在「C 位是否已经被抓且救不回来」：正常团战先锁前排；C 位已死局时换后排。
3. **辅助是否跟 ADC：不跟 vs 贴身保。** 素材主张敌方打野前期强时不直接跟 ADC（BV19Ch462ELH @ 00:07），并明确「辅助不需要一直贴着 C 位」（BV1bcuX6REUG @ 01:53）；这与「辅助就该贴身保射手」的常见直觉冲突。差异在任务：前期要保野区/争中，团战要保阵型/找反开位，只有 C 位确实需要贴身保护时才贴。
