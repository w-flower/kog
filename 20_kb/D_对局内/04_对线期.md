# 04 对线期：这波线清完，我该往哪走

> **依赖**：03 前四分钟（结论：线权来自第一波谁先清完）
> **被依赖**：05 第一波转线（本节产出的「可动窗口」是 05 的输入）；09 逆风止损（本节判定"没线权"且持续到 4 分钟，直接跳 09）

## 0. 上一节留下的问题

03 结尾留下的是：**"你先到 2 级了，然后呢？"**

先到 2 级只说明你**有了一次清线优势**，不等于你能走。这一节要回答的，是这次优势能不能换成地图上的东西——换不成，优势会在 90 秒内自己蒸发。

## 1. 本节只回答一个决定

**这一波线清完之后，我是往河道走、往边路走，还是退回塔后等下一波？**

不是"怎么打得更好"，是"这一步该不该动"。操作的差距在这个决定面前是次要的。

## 2. 判断树

```
中线清完 / 即将清完（判断起点）
│
├─ 判据 A：我有没有线权？（看谁的小兵更多、谁先推过去）
│   ├─ 没有（我方兵线被压回塔前，或我每波都在塔下补刀）
│   │   ├─ 判据 A1：对面法师是否已经离开中线？（小地图 8 秒内无其视野）
│   │   │   ├─ 是 → 【K-D01】不尾随，往反方向去拿资源
│   │   │   └─ 否 → 【K-D02】塔后过线，同时给边路打信号
│   │   └─ 判据 A2：我这一波掉了多少状态？（血量 <60% 且无闪现）
│   │       ├─ 是 → 【K-D03】回城，不要为了保线硬撑
│   │       └─ 否 → 留在塔后等下一波
│   └─ 有（我方小兵更多，或对面被迫交技能补刀）
│       ├─ 判据 B：下一波兵到线还需多久？
│       │   ├─ >8 秒 → 够一次短游，进判据 C
│       │   └─ ≤8 秒 → 【K-D04】不动，把线再推一波更赚
│       └─ 判据 C：我方打野在哪？
│           ├─ 在我方半区/河道 → 【K-D05】跟他走同一侧，去做视野或反野
│           └─ 位置未知/在对面半区 → 【K-D06】只占中轴草，不深入
└─ 判据 D：这波我死了或刚复活
    └─ 【K-D07】先回中线过线，不要先参团
```

每个叶子都对应下面一个 K 条目。**树里没有"视情况而定"这种分支**——出现这三个字说明判据没写清。

## 3. 判断依据

| 变量 | 在哪看 | 阈值 / 取值 | 影响哪个分支 |
|---|---|---|---|
| 线权 | 双方小兵数量与位置 | 我方小兵 ≥ 对方且未进塔 | 判据 A |
| 对面法师视野 | 小地图 | 消失 >8 秒 | A1 |
| 自身血量 / 召唤师技能 | 血条 + 技能栏 | 血量 <60% 且无闪现 | A2 |
| 下一波兵到线时间 | 兵线节奏（约 30 秒一波） | >8 秒 | B |
| 我方打野位置 | 小地图 | 己方半区 / 未知 | C |
| 是否刚复活 | 复活计时 | — | D |

**底层判据（适用于全库）**：判断"能不能打"看的不是经济差，是**战斗力差 × 能不能及时到达**。信息不足时这条压过一切技巧性结论——这条来自 `BV1i2n96AEvp` 的框架，原文是"速度的真正含义就是看战斗力的影响是否能够及时达到目标区域"。

## 4. 分支说明

### K-D01 没线权，对面法师走了——我不跟，去反方向

- **适用版本**：S45（2026-09-23 起）；S46 待复核
- **触发条件**：我方中路无线权（兵线被压回塔前）；对面法师小地图消失 >8 秒
- **判断依据**：对面法师的消失方向（看小地图最后视野朝向哪一路）；我方另一路是否有可拿资源
- **决策分支**：
  - 对面法师去上 → **我去下路**，拿河蟹/兵线/野区小资源
  - 对面法师去下 → **我去上路**，同理
  - 完全看不出方向 → 不动，塔后过线
- **反例**：「对面法师去支援了，我赶紧跟过去」——你没有线权，走过去比他慢 5 秒以上，到了正好接他一套技能，还把中线白送。**尾随强势法师作用不大，不如反方向拿资源。**
- **依赖**：依赖 K-D02（先要能安全过线）
- **来源**：BV15EJk6fEwX @ 00:38；BV15EJk6fEwX @ 00:41
- **可信度**：高（全局思路复盘，非剪辑集锦；与《一野二边三射四中》的开局逻辑一致）
- **状态**：active

### K-D02 没线权时的过线方式：塔后过，不打信号就完事

- **适用版本**：S45
- **触发条件**：判定为无线权状态，且需要继续吃中线经济
- **判断依据**：对面法师的消耗距离；我方塔的血量
- **决策分支**：
  - 站在**塔后**过线（不是塔前补刀），同时观察对面法师动向
  - 给边路打信号，说明"我这路被压，你们注意对面中单可能来"
- **反例**：「我打个信号让队友别打就行了」——这条被明确否掉了：对面法师+打野一起进你们野区，或者四包二越你们下路，一个信号拦不住。**打信号不能替代你到场**。
- **依赖**：无
- **来源**：BV15EJk6fEwX @ 01:03；BV15EJk6fEwX @ 01:10
- **可信度**：高
- **状态**：active

### K-D03 血线被打到 60% 以下且没闪现——回家，别保线

- **适用版本**：S45
- **触发条件**：中路对线期，血量 <60%，闪现已交或在冷却
- **判断依据**：对面法师的技能冷却与斩杀线；我方塔下是否安全
- **决策分支**：
  - 直接回城，接受掉 1–2 个兵
  - 若对面法师蓝量也不健康且无法越塔 → 可以再撑一波，但要站在塔后
- **反例**：「我血少但不能掉线，硬吃一波」——**掉状态之后轻则被单杀、丢闪现，重则丢野区**。这是"为了一波兵输掉整条线"的典型。
- **依赖**：无
- **来源**：BV15EJk6fEwX @ 00:30；BV15EJk6fEwX @ 00:31
- **可信度**：高
- **状态**：active

### K-D04 有线权但下一波兵 8 秒内到——别走，再推一波

- **适用版本**：S45
- **触发条件**：有明确线权；下一波兵线到线时间 ≤8 秒
- **判断依据**：兵线节奏（约 30 秒一波）；当前小兵数量
- **决策分支**：留在线上再推一波，把兵线送进对面塔，让对面疲于补塔刀
- **反例**：「有线权就立刻游走」——走到一半兵线回来，你既没拿到资源也没吃到线，两头空。
- **依赖**：无
- **来源**：BV15EJk6fEwX @ 00:53
- **可信度**：中（阈值为 8 秒的推算值，UP 主未给具体秒数，需实战校准）
- **状态**：active

### K-D05 有线权且打野在同侧——跟他走，别自己单走

- **适用版本**：S45
- **触发条件**：有线权；我方打野位于己方半区或河道
- **判断依据**：打野位置与行进方向；对面打野是否已在小地图暴露
- **决策分支**：与打野走同一侧，做视野或反野；两人一起才有交换价值
- **反例**：「我自己先去探一下」——单人进野区在无视野情况下大概率被抓，而这次被抓会把刚拿到的线权一起吐出去。
- **依赖**：依赖 K-D04（先确认可动窗口）
- **来源**：BV15EJk6fEwX @ 02:11；BV15EJk6fEwX @ 02:14
- **可信度**：中高
- **状态**：active

### K-D06 打野位置不明——只占中轴草，不深入

- **适用版本**：S45
- **触发条件**：有线权，但打野位置未知或在对面上半区
- **判断依据**：小地图打野最后出现位置与时间
- **决策分支**：站在中路两侧草丛占视野（UP 主原话"一般是站在这个草"），只做视野不进场
- **反例**：「反正有线权，去对面野区找个机会」——打野位置不明时进对面野区，等于把命交给概率。
- **依赖**：依赖 K-D04
- **来源**：BV15EJk6fEwX @ 01:43；BV15EJk6fEwX @ 01:47
- **可信度**：中高
- **状态**：active

### K-D07 死了刚复活——先回中线过线，不要先参团

- **适用版本**：S45
- **触发条件**：复活后场上正在发生团战或资源争夺
- **判断依据**：兵线位置；团战距离；自身大招冷却
- **决策分支**：
  - 中线有兵且没人清 → **先过线**，再决定是否进场
  - 中线已空 → 直接进场
- **反例**：「团战开始了必须去」——线不过，你到场也是白给经济，而且下一波还要被压。**兵线大于团战**这条在低分段尤其反直觉。
- **依赖**：无
- **来源**：BV15EJk6fEwX @ 03:24；BV15EJk6fEwX @ 03:26
- **可信度**：中（"兵线大于团战"是 UP 主的口号式结论，需在 06/07 用其他来源交叉验证）
- **状态**：active

### K-D08 对线期的辅助：按「野→边→射→中」的顺序决定第一步

- **适用版本**：S45（中野辅版本）
- **触发条件**：开局到 1 分钟，辅助决定第一波去哪
- **判断依据**：① 我方打野是否要进攻/防守野区 ② 边路是否有线权可拿 ③ 发育路对线强度 ④ 中路是否需要帮清
- **决策分支**：
  - 打野要偷野 → 去**对抗路**拿线权，再协同进野区
  - 打野不偷野 → 去边路尝试一血
  - 都不成立 → 回中帮清线
- **反例**：「辅助就该跟着射手」——这是四个判据里排第三的一条，不是第一条。开局直接去发育路，等于放弃了野区节奏。
- **依赖**：无
- **来源**：BV1yke26fEYB @ 00:47；BV1yke26fEYB @ 00:52
- **可信度**：中（该公式为 UP 主自创命名"一野二边三射四中"，非官方；顺序逻辑与 K-D01 的反方向拿资源一致，故采信）
- **状态**：active

## 5. 本节的连锁错误（按节点挂，不单列）

- **在节点「判据 A 线权」上**：把"我先到 2 级"当成"我有线权"。到 2 级只是一次，线权是持续状态，看的是**这一波谁的小兵更多**。
- **在节点「判据 A1 对面法师消失」上**：把"小地图没有他"当成"他走了"。消失 8 秒内可能只是在草丛里，直接跟过去会撞脸。
- **在节点「判据 C 打野位置」上**：把"打野刚露头"当成"打野在附近"。露头的位置决定他能不能到，不能到就等于不在。
- **在节点「判据 D 刚复活」上**：默认"团战优先级最高"。低分段最常见的死法就是复活后直奔团战，回来发现自己中线已经掉两波。
