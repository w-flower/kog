# 07 团战

> 素材说明：四份素材，四个位置、四个分段，互相不能替代。
> **打野视角**：浅梦《打野教科书》（BV1oRJYzpEYb），12 位 KPL 职业打野第一视角，教练口播拆解，全篇按"前 2 分钟→前 4 分钟→龙团→野区入侵→兵线运营→高地推进"推进，团战部分集中在 26:33 之后。
> **射手视角 A**：小居王者丶（BV1X2jV6KEiP），巅峰万强实战解析，讲的是"射手如何去偷国服射手的推进思维"，团战段的落点是站位与进场。
> **中路视角**：王者荣耀听说《昭君细节对线思路》（BV1uu4y197Sr），2100 中等分段，主体是对线与转线，团战段只在压塔那一段集中讲了 09:07~09:31。
> **射手视角 B**：赵伽蒙《伽罗前中后期思路》（BV1ssxz6SEGo），1900 分学员对局复盘，团战段是逐帧挑错，反例密度最高。
> 本节只回答一件事：**这一波团我该站在哪、什么时候进、进了打谁**。
> 需要提前说明的是：**"打谁"这一问，四份素材合起来也只给了打野一侧的答案（跨前排摸后排），射手和中路都没有给出正面集火的优先级**，这一块进「待补」，不注水。
> 上游接 `06`。

## 判断顺序

```
第 1 步：先数人——己方已经倒了两个及以上，这波团就不是团，是送 → K-D88
第 2 步：人齐了，先认自己站哪个位置：打野找夹位／射手等前排缠斗／中单找射手侧后 → K-D79、K-D84、K-D89
第 3 步：打野——夹位从"敌方分几个人去守哪座塔"反推，推不出夹位这波不该由你开 → K-D80
第 4 步：射手——判断这是缠斗还是追击，追击不跟；要跟就卡在队友开团那一刻第二时间进 → K-D84、K-D85
第 5 步：射手已经进团——落点以保命为第一，不以接近输出为第一，站自家塔侧 → K-D86
第 6 步：10 分钟以后——开团点锁死在塔前，不追进野区；要退就跟队友走同一个角度 → K-D87
第 7 步：中单——站侧面，不和射手同点，位置要能随时盖到射手 → K-D89
第 8 步：团战前置是视野——压塔前先站住中路视野点，蹲人等到对面辅助探草那一瞬间 → K-D90
第 9 步：龙团单独一套——4 分钟先判兵线权再定战场，10 分钟判正面强弱决定接还是换 → K-D81、K-D82
第 10 步：高地团——打野护线优先于切入，推进优先选边高 → K-D83
```

### K-D79 野核"什么时候进"取决于有没有夹位，不取决于团开没开（打野视角）

- **适用版本**：S45
- **触发条件**：中后期野核英雄要参与正面团，队已经在往一起靠
- **判断依据**：素材原话「野核英雄一旦到了中后期，团战切入思路就是找夹击位」（@ 26:37~26:41）；夹位的定义是「跨过前排，直接摸对方的后排」（@ 26:45~26:47）；结论句是「团战能不能打，就看负责切 C 的位置能不能找到一个很好的夹位」（@ 26:49~26:52）。这条思路成熟之后「野核就可以稳定 C 中后期」（@ 27:26~27:29）
- **决策分支**：
  - 有夹位 → 进，从侧后接敌方后排，不从正面挤
  - 没有夹位 → 这一波不作为自己的开团点，只做正面牵扯；素材只说了"能不能打看夹位"，"找不到就不开"是据此推的一支，可信度按中处理
- **反例**：从正面跨前排。素材特意说明夹位的价值就是"跨过前排"（@ 26:45~26:47），反过来说正面是过不去的
- **来源**：BV1oRJYzpEYb @ 26:37~26:52、27:26~27:29
- **可信度**：中（"夹位决定能不能打"是原话；"没有夹位就不开"这一步推理没有原话支撑）
- **状态**：draft

### K-D80 夹位从"敌方分几个人去守哪座塔"反推，敌方堆人的一侧不是夹口（打野视角）

- **适用版本**：S45
- **触发条件**：想给野核找夹位，但地图上没有现成的侧翼口
- **判断依据**：素材给了敌方两种应对和各自对应的夹位。敌方"多人防守下二塔"，澜就和队友「把中线顶出去，推中一」（@ 27:01~27:06）；敌方"正常应对，中路放更多人来顶中下二，放一到两人协防"，「这一波的夹位自然就是中路」，可以和队友形成包夹，敌方出来顶走队友后腹背受敌，夹位让澜「第一时间摸敌方的后排」（@ 27:08~27:24）
- **决策分支**：
  - 敌方堆人去守某座二塔 → 那一侧不是夹口，改从中路正面顶出去
  - 敌方把中路堵满、边塔只留一到两人 → 中路就是夹口，等队友把对方顶出来再摸后排
- **反例**：不看敌方分布、固定从同一侧绕后。素材两段案例里，夹位随敌方人数分布变化而变（@ 27:04~27:24），固定一侧就等于把夹位让给对方
- **来源**：BV1oRJYzpEYb @ 26:54~27:24
- **可信度**：中（两个分支都是原话，"反推"这个提炼动作是把两段案例并起来读的）
- **状态**：draft

### K-D81 4 分钟龙团先判兵线权，再决定战场立在中轴还是发育路（打野视角）

- **适用版本**：S45
- **触发条件**：3 分 48 前后兵线对接，4 分钟暴君即将刷
- **判断依据**：龙团前的布置「在于兵线权」（@ 16:28~16:30）；中线和发育路线都清完，「中路和发育路的人会来的比对方更快」，就直接秒龙（@ 16:40~16:49）；只有一条有线权的情况，素材拆成两支：中优发育劣「就要开始部署，立足于中轴的龙团战场，草丛易守难攻」（@ 16:53~16:59）；中劣发育优则「龙头就是往发育路的方向拉」，用发育路河道的草丛（@ 17:52~17:56）
- **决策分支**：
  - 中线 + 发育路线权都有 → 直接秒龙
  - 中优发育劣 → 战场立中轴，队友把中轴那几个草站住，"不让对方进来"，靠过来抢龙就被打状态（@ 16:59~17:05）
  - 中劣发育优 → 战场立发育路河道一侧
- **反例**：不判兵线权就开龙。素材在 10 分钟那波给了同逻辑的失败案例：澜先想过中线做优、被火舞打掉状态，接着 Buff 和龙同时出现，只能二选一（@ 19:23~19:44）
- **来源**：BV1oRJYzpEYb @ 16:24~17:05、17:52~17:56、19:23~19:44
- **可信度**：高（判据、分支、失败案例三者齐全）
- **状态**：draft

### K-D82 10 分钟龙团：正面打得过就既赚龙也赚线，打不过就顶中线换龙，双边都劣就龙坑拉扯（打野视角）

- **适用版本**：S45
- **触发条件**：9 分半到 10 分钟，远端线和近端线要有人带出去，龙要开
- **判断依据**：顺风做法是 9 分半后打野落位在远端线，提前清掉 10 分钟前的兵线，敌方分人来管这波远端劣势线，「就可以直接开黑暗暴君，敌方人少来不及打龙团」（@ 29:16~29:32）。逆风做法看双边兵线：「单边劣可以接龙团，打正面对抗」，「双边劣就要做龙坑拉扯了」（@ 29:37~29:52）。总原则是「前置要优暴君的远端线，敌方接线我方打暴君；敌方全员打暴君，正面打得过既赚暴君也赚兵线，正面打不过顶，中线利用兵线优势做换龙」（@ 30:47~31:01）
- **决策分支**：
  - 远端线带出去、敌方分人来管 → 直接开龙
  - 敌方全员来打龙、正面打得过 → 接，既赚龙也赚线
  - 敌方全员来打龙、正面打不过 → 不接，顶中线换龙
  - 双边都劣 → 龙坑拉扯，等兵线缓和（@ 29:48~29:56）
- **反例**：10 分钟前掉点。素材原话「路人局 10 分钟前掉点，是不是都掉在野区或者中路，因为都是无头苍蝇，不知道现在优先干什么」（@ 29:29~29:35）
- **来源**：BV1oRJYzpEYb @ 29:07~31:01
- **可信度**：高（判断链完整，正反两面都有）
- **状态**：draft

### K-D83 高地团打野只有"切入"和"护线"两个出发点，线有被摸的风险就护线优先；推进优先选边高（打野视角）

- **适用版本**：S45
- **触发条件**：两路推进线已经推到高地，打野要决定这波是绕后切人还是留在正面
- **判断依据**：素材原话「一旦有两路推进线，对于打野来说就只有两个出发点：切入以及护线」（@ 31:45~31:48）。案例里「墨子在后方卡位不好做切入，狂铁身位想顶前摸线，切入难度高；哪怕成功切了后排，而线被狂铁顶掉了，推进依旧是失败的」（@ 31:50~32:00），所以「这一手一定是护线优先」（@ 32:00~32:03），做法是「在兵线进塔前防止狂铁摸线，大招逼退狂铁」（@ 32:03~32:08）。选推进目标时「优先推边高，因为边路高地推进是最安全高效的」，原因是推中高会被两面夹击、五人阵型会散（@ 31:23~31:30）
- **决策分支**：
  - 对方前排能顶到兵线 → 护线，大招/控制逼退摸线的人
  - 对方摸不到线、后排又露出夹位 → 才轮到切入
  - 选推哪一路 → 边高优先于中高
- **反例**：只想着切后排。「敌方是后裔，大部分打野玩家想的都会是我要切后排」（@ 31:39~31:45），素材说这波切了也白切，线一被顶掉推进就失败（@ 31:56~32:00）
- **来源**：BV1oRJYzpEYb @ 31:23~32:25
- **可信度**：高（护线优先有完整因果链：切人成功但线丢了仍等于推进失败）
- **状态**：draft

### K-D84 射手只在双方前排/开团手还在缠斗的团里有输出空间，变成追击战就不跟（射手视角）

- **适用版本**：S45
- **触发条件**：队友已经在打，要决定这一波跟不跟
- **判断依据**：素材先给现象「自家是在追着对方打，既然是追击，那就意味着对方在往回跑，以你的追击能力是不可能追得上的」（@ 07:26~07:32）；再给原因「双方的开团手已经全部倒地」（@ 07:34~07:39）；结论是「只有双方的前排或者开团手在缠斗的团战，射手才有输出空间，而不是你追我打的一个追逐战」（@ 07:41~07:45）。机制层理由是「射手的机动性是跟他的保命技能挂钩的，你想快速追上对手，就必须用掉保命技能，一个没有保命技能的射手去追人，和送人头又有什么区别」（@ 07:53~08:02）
- **决策分支**：
  - 双方前排还在缠斗 → 跟，正面输出
  - 已经变成单方面追击 → 不跟，回头吃线或刷野
- **反例**：追着残血跑。素材原话「如果你的射手老是喜欢追人，那说明你的死亡率一定极高」（@ 07:47~07:51）
- **来源**：BV1X2jV6KEiP @ 07:16~08:02
- **可信度**：高（判据 + 机制 + 反例齐全）
- **状态**：draft

### K-D85 射手的进场时机是"第二时间"，卡在队友开团那一刻；进之前先找对方绕后位（射手视角）

- **适用版本**：S45
- **触发条件**：团战即将开始，射手还在侧翼或后方
- **判断依据**：素材原话「转线刚好卡在队友开团的时候，第二时间进场」（@ 06:01~06:05）。站位两难说得很清楚：「下路的三个队友是肯定不能卖的，但是进场太早的话，容易被绕后，导致跑不掉」（@ 10:20~10:24）；对应的动作是「想要掩护队友撤退的第一步，就是先找出对方的绕后位」（@ 10:27~10:30）
- **决策分支**：
  - 队友先开 → 第二时间进，进之前先把对方绕后位的位置找出来
  - 对方绕后位还在（素材例：达摩蹲在蓝草）→ 先站自家塔侧，不提前压上去
- **反例**：提前支援。「如果你提前进行支援，把团战的位置锁定在对方的下路二塔附近，你这波一定偷不了」（@ 10:41~10:45）
- **来源**：BV1X2jV6KEiP @ 06:01~06:05、10:20~10:52
- **可信度**：高（给了"为什么不能早"的机制：绕后位）
- **状态**：draft

### K-D86 射手落点的第一优先级是保命，不是接近输出；人不齐不进野区（射手视角）

- **适用版本**：S45
- **触发条件**：已经进团，要选具体站位
- **判断依据**：素材自己复盘「我犯了一个顺风射手的大忌，进攻的时候站位竟然不是以保命为主，而是为了能够更好的接近对方去打出输出」（@ 08:17~08:23），代价是被蓝草里的达摩击杀（@ 08:13~08:26）；顺风最大的翻盘点被点成「在人不齐的情况下，无脑进野区」（@ 08:28~08:32）。正面的正解是「自家下路一塔是在的，打起来了被冲脸，直接一个闪现往野区跑，对方是很难追到你的」（@ 10:36~10:40）
- **决策分支**：
  - 自家一塔还在 → 站塔这一侧，被冲脸就往野区闪
  - 人不齐（有人没复活或没到位）→ 不进野区，等
  - 已经决定要打 → 宁可少打一段输出，也不站到能被侧翼摸到的位置
- **反例**：为多打一段输出往前站。素材为此付出了本局最大的一次掉点（@ 08:24~08:32）
- **来源**：BV1X2jV6KEiP @ 08:13~08:32、10:36~10:40
- **可信度**：高
- **状态**：draft

### K-D87 10 分钟后的开团点只能在塔前、不能在野区；要退就跟队友走同一个角度，不单独走（射手视角，两素材互补）

- **适用版本**：S45
- **触发条件**：10 分钟以后（或后期大龙团前后）要决定在哪接团、打不赢怎么退
- **判断依据**：先定性质——「10 分钟之后所发生的团战是完全有能力一到两波直接结束对方的」「目前这个阶段你的团战是为了推塔、拿对方的水晶，而不是为了获得更高的发育」（@ 11:11~11:26）。所以拿掉对方貂蝉后想继续接团时，「一定要确定好接下来开团的一个位置，一定是塔前，不是野区」（@ 11:53~12:00）。撤退侧由另一份射手素材补上：「正常跟着队友从蓝区那个角度撤了，不说能打赢吧，最起码你能安全撤离；对面要追上头，防御塔也在，还能反打一波」（@ 12:27~12:38）
- **决策分支**：
  - 要接下一波 → 把团拖到自家塔前再开
  - 打不赢要退 → 跟队友走同一个角度（素材例：蓝区），不从另一边单独走
  - 已经有人被留下 → 被留下的是前排（素材例：钟馗）可以考虑接输出，被留下的是打野（素材例：猴子）就直接跑（@ 12:56~13:02）
- **反例**：野区接团 + 单独走。素材对单独走那一句的评价是「真的是太夸张了」「连点脑子都不用」（@ 12:16~12:27）
- **来源**：BV1X2jV6KEiP @ 11:11~12:00、12:56~13:02；BV1ssxz6SEGo @ 12:16~12:38
- **可信度**：中（"塔前不开野区"明确；"跟队友走同一角度"只有赵伽蒙一例，且是复盘语境）
- **状态**：draft

### K-D88 己方已经倒两个，这波团就不是团——转中清线保中一塔，不在原处死守（射手视角·赵伽蒙）

- **适用版本**：S45
- **触发条件**：团战开打前或刚开打，己方已经掉人
- **判断依据**：素材逐帧数人「队友倒了一个……那钟馗当着咱们的面也倒了——现在的中线团战打不了了吗」「队友已经明白倒两个，赶紧去中路准备清中了，不要再来上路这里了」「你三打五，你怎么打」（@ 10:47~11:05）。正解是「如果跟着猴子在中，或者你去到中，猴子刚好在那，我可以跟猴子配合先手清线；或者趁他们在上路打架的时候后手清线，把我们这个重要的战略点能让他晚掉一会儿」（@ 11:12~11:29），这个战略点素材前文点过是「双方第一道防线的中一塔」「谁先掉谁先难受」（@ 04:52~05:03）
- **决策分支**：
  - 己方少人 → 不接正面，转中清线，让中一塔晚掉
  - 中路有队友 → 先手清；中路没人 → 趁对面在上路打架时后手清
- **反例**：人不齐还在原地「死守」（@ 11:06~11:08）
- **来源**：BV1ssxz6SEGo @ 10:43~11:29、04:52~05:03
- **可信度**：高（人数条件、处置、目的三层都有）
- **状态**：draft

## 待补

- **"进了打谁"这一问，四份素材合起来只覆盖了打野一侧**：素材给的是"跨前排摸后排"（@ 26:45~26:47）和"夹位摸后排"（@ 27:21~27:24），没有系统讲正面集火优先级——先打对面前排还是先切对方 C、残血目标和关键目标的取舍，一概没有。射手与中路两份素材从头到尾没有出现"先打谁"的判断，只有"打不打、站哪、什么时候进"。
- **对抗路/坦克视角完全缺失**：「前排什么时候开团」这一半是全节的空白。射手视角只是转述「低分段最常见的情况就是玩个坦边一直带线，或者说玩一个承伤能力比较强的打野一直在那边刷野区」（@ 13:20~13:29），这是从射手侧看前排，不是前排自己的判断。
- **辅助视角完全缺失**：四份素材里辅助只以"对方的绕后位""探草的辅助"出现，没有一份是辅助第一视角。
- **量化阈值全无**：没有血线标准、没有技能 CD 判断标准、没有"几个人可以打几个人"的通用公式。素材里最接近的只有「你三打五，你怎么打」（@ 11:04）这样的反问，不构成阈值。
- **逆风局的"谁来开团"没有答案**：射手视角明确说逆风不主动开节奏（@ 09:11~09:32），但逆风该由谁开、开在哪，素材只说"等一个机会"，没有展开。
