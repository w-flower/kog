# 09 逆风止损

> 素材：同 `08_顺风推进.md`（BV1NLHsexEPi，燕十叁，打野视角）。素材一 BV1T8hG6FEtp 与王者无关，
> 本卡同样未从中取任何结论。
>
> 本节接 `08_顺风推进.md` 留下的**两条边**：
> ① **K-D58**「对面换掉你一片野区，只要这条节奏线收益做足就不算亏」——这条反过来做，就是"非要把那片抢回来"；
> ② **K-D57**「一段推进做完就回时间原点」——没回去、硬把舍弃的节拍塞回来，节拍溢出，下一轮延迟或混乱。
>
> 这两条走错，局面就从顺风滑成"顺风没推出去、被反打"。**本节只回答一件事：已经逆风了，怎么把损失按住。**
> 上游接 `08_顺风推进.md`。

## 判断顺序

```
第 1 步：先分清丢的是经济，还是野区刷新规律的掌控 → K-D60
第 2 步：没有野区可刷的时候，人会怎么死           → K-D61
第 3 步：只剩一片能刷，怎么用它把循环接回来       → K-D62
第 4 步：对面 Buff 马上刷，抢还是放               → K-D63
第 5 步：掉点之后刷新时间已经偏了，怎么重设原点   → K-D64
第 6 步：队友没到位，还进不进野区                 → K-D65
第 7 步：为一只小野绕路，值不值                   → K-D66
```

### K-D60 逆风先分清：丢的是经济，还是刷新规律的掌控权

- **适用版本**：S45
- **触发条件**：落后了，想止损，但不知道第一步该修什么
- **判断依据**：素材把顺逆的分水岭落在"谁掌握刷新区间"上——老虎压制的收尾原话是"他家的游戏刷新规律已经被老虎掌握了，他掌握不了"（@ 14:19~14:21）；反过来看对面打野的失误，也是同一把尺子："又是一个不知道自己野区刷新规律的打野，我们直接接管"（@ 17:07~17:12）
- **决策分支**：
  - 经济落后，但自家每片野什么时候刷你算得出 → 说明节奏线还在，按 `08` 的节拍继续填词就行，不需要额外动作（@ 06:04~06:11）
  - 连自己野区什么时候刷都算不出 → **先停手**，重建时间原点，见 K-D64（@ 08:06~08:43）
- **反例**：不知道刷新时间还往对面野区走——进去是空的，白跑一趟还暴露位置（@ 16:22~16:30）
- **来源**：BV1NLHsexEPi @ 14:19~14:21、16:22~16:30、17:07~17:12
- **可信度**：中。"谁掌握刷新规律 = 谁占优"是作者的核心论断，逻辑自洽且有正反案例；但**素材没有给"落后多少算逆风"的任何刻度**，经济差、塔差、龙差都没提，所以只能当优先级判断，不能当止损阈值
- **状态**：draft

### K-D61 逆风最危险的不是穷，是没有野区可刷还乱跑

- **适用版本**：S45
- **触发条件**：自家野区被清空/被反，地图上看不到能打的东西
- **判断依据**：素材里韩信那次死亡，归因讲得极清楚——"韩信的死就是因为他的蓝还没有刷，所以他没有地方去，漫无目的的来到了我的红区"（@ 15:21~15:27）；作者的补充是"如果他懂得野区刷新规律，那么他就应该知道他的蓝区刷新是有时间差的，就不会在这个时候乱跑"（@ 15:31~15:37）
- **决策分支**：
  - 还有一片能刷 → 直奔那一片，用 K-D62 的接法（@ 15:46~15:57）
  - 一片都没有 → 去线上吃兵/等刷新，**不要进对面野区瞎逛**（@ 15:27~15:31）
- **反例**：「没野可刷，去对面逛逛找机会」——正好撞在对方算好的时间线上，被顺手带走（@ 15:17~15:21 击杀就发生在"传送去中路准备反蓝，顺手在这个地方击杀了韩信"）
- **来源**：BV1NLHsexEPi @ 15:17~15:37
- **可信度**：高。死因链条完整（蓝没刷 → 没地方去 → 乱跑 → 走进对方红区 → 被杀），不是事后归因的模糊说法
- **状态**：draft

### K-D62 保住"还剩下的那一片"，用它把循环接回来

- **适用版本**：S45
- **触发条件**：野区只剩一片能刷，或者刚被反完只剩残羹
- **判断依据**：作者反蓝那波的自述是"你会发现我反蓝的过程当中，地图上只有这一片野区是可以刷的；我刷完蓝，我家的红也刷了，我不会像韩信一样没有野区刷；并且后续刷了红，我家的蓝也会刷，我可以继续循环"（@ 15:46~15:57）
- **决策分支**：
  - 按顺序刷完这一片 → 下一片正好接上（红完蓝、蓝完红），循环自然闭合（@ 15:52~15:57）
  - 接不上、中间有真空 → 用一拍线上的事（清线/跟一波）填空，别硬等（@ 15:57~16:00）
- **反例**：手里明明还剩一片，却先去追对面的人——等于把唯一的接续点也丢了，回头两片都不在（@ 15:21~15:31 韩信既没有自己的蓝，也没守住时间线）
- **来源**：BV1NLHsexEPi @ 15:46~16:00
- **可信度**：高。这条是作者在实战里边打边讲的，且和 K-D61 构成同一段的因果正反面
- **状态**：draft

### K-D63 对面 Buff 快刷了，人不占优就放，放是止损不是让

- **适用版本**：S45
- **触发条件**：算到对面蓝/红马上刷，自己状态或人数不占优
- **判断依据**："但是我们这波先不进蓝 Buff，我们放给他刷"（@ 18:35~18:37）；放掉之后的替代动作是"本来想的是这波先偷他小野，然后利用他刷蓝的时间差，去看看能不能推塔或者控龙"（@ 18:44~18:48）
- **决策分支**：
  - 人不齐或状态差 → **放 Buff，改偷小野/换推塔控龙**（@ 18:35~18:48）
  - 人齐、状态好、算得准刷新点 → 按 K-D59 的掐点进（@ 19:58~20:02）
- **反例**：人不齐还硬进——同一段素材里作者的选择是"本来刷完蓝区也想反蓝的，但是辅助没来，所以我们正常刷红"（@ 17:01~17:06），这是他自己给出的正确处置
- **来源**：BV1NLHsexEPi @ 17:01~17:06、18:35~18:48、19:58~20:02
- **可信度**：高。放与不放两种选择在素材里都出现过，并且各自给了理由
- **状态**：draft

### K-D64 掉点之后刷新时间已经偏了，要重设时间原点

- **适用版本**：S45
- **触发条件**：自己刚复活，或对面/队友刚掉点，旧的时间表已经不准
- **判断依据**：己方掉点的后果被讲成机制——"他上一波死了，所以红区的刷新是比蓝区有延迟的；Buff 有延迟，说明小野会在 Buff 该刷的时候刷"（@ 18:36~18:40）；卡顿之后作者的操作是"所以我们再重置一下时间，原点刷了蓝区的小野之后，先不去红区"（@ 16:57~17:00）；更上一层的原则是"时间原点是可以改变的，我们需要记住上一轮节奏的参照物"（@ 08:06~08:11）
- **决策分支**：
  - 自己死了 → 以复活后碰到的**第一片野区**为新原点，往后重排（@ 16:57~17:00）
  - 对面死了 → 他的下一片会**延迟**，小野却按原时间刷，这正好是你提前布局的窗口（@ 16:36~16:41）
- **反例**：拿死之前那张表继续算——每一个点都是错的，还会误判"他这片应该空了"然后一头撞进去（@ 16:22~16:30）
- **来源**：BV1NLHsexEPi @ 08:06~08:11、16:36~16:41、16:57~17:00、18:36~18:40
- **可信度**：高。"Buff 延迟但小野不延迟"这条在素材里被单独强调过两次，是可操作的区分
- **状态**：draft

### K-D65 队友没到位就不进野区，默认动作是刷自家

- **适用版本**：S45
- **触发条件**：计划反野，但辅助/队友不在位，或沟通没落地
- **判断依据**：作者的原话决策是"本来刷完蓝区也想反蓝的，但是辅助没来，所以我们正常刷红"（@ 17:01~17:06）——注意这里没有纠结，直接切到默认动作
- **决策分支**：
  - 辅助在、信息对得上 → 按 K-D59 掐点进（@ 19:58~20:02）
  - 辅助不在 → **正常刷自家，把反野推到下一拍**，不要改成"一个人去试试"（@ 17:01~17:06）
- **反例**：人不齐、信息还是错的，就跟着喊反红——"队友说反红是不存在的"，因为对面红开的，进去根本没东西（@ 16:22~16:30）
- **来源**：BV1NLHsexEPi @ 16:22~16:30、17:01~17:06
- **可信度**：高。这是素材里少见的、明确写出"因为 X 所以我不做 Y"的决策句，不是事后描述
- **状态**：draft

### K-D66 止损时别为一只小野赔掉整条循环

- **适用版本**：S45
- **触发条件**：逆风时看到一只小野，但要绕路或多花一拍才能拿到
- **判断依据**：小野的刷新周期只有 70 秒，作者的原话是"很容易因为贪一个小野而打乱自己的节奏，导致节奏断裂"（@ 06:44~06:50）；同一套框架里，想吃下超量的野区"一定会有小野怪是放掉的"（@ 06:25~06:30）
- **决策分支**：
  - 小野**就在当前节拍线上**（顺路 1 拍内）→ 拿（@ 07:38~07:43）
  - 要绕路、要多花一拍 → 放掉，把那一拍留给接续循环（@ 06:44~06:50）
- **反例**：逆风时把"偷他小野 + 用时间差推塔控龙"一起做（@ 18:44~18:48）——这套加法在素材里是**顺风**语境下的操作，逆风时同样的绕路会直接掐断你仅剩的那条线
- **来源**：BV1NLHsexEPi @ 06:25~06:50、07:38~07:43、18:44~18:48
- **可信度**：中。素材讲的是顺风/均势下的节奏管理，"逆风时贪小野更致命"是**推论**，素材没有直接给逆风案例，所以只作方向参考
- **状态**：draft

## 待补

- **素材没有"逆风"的判定标准**：经济差多少、掉几座塔、丢几条龙算逆风，全片没有数字。本节的 K-D60 只能给出"先看刷新规律"这个优先级，给不出阈值
- **守家/守高地/清线拖延完全缺失**：素材的逆风只到"野区被压制"这一层，没有高地防守、没有兵线处理、没有被破塔之后怎么办
- **团战打输之后怎么收**：素材里出现过"团战还是没打过"（@ 18:51~18:52），但作者一笔带过，没有拆解残局处理
- **视野与站位**：逆风最需要的视野布置、绕后位防范，素材零覆盖
- **非打野分路的逆风止损**：射手/中路/对抗路在逆风里做什么，素材没讲；`07` 的 K-D38 有射手视角的一条（"防守吃线等机会"），但两者没有在素材层面对齐过
- **与 K-D58 的边界需要人复核**：`08` 说"被换一片野区不重要"，`09` 说"被换之后容易滑向抢回来"。什么情况下该按 08 走、什么情况下该按 09 走，素材只给了方向、没给分界，建议由懂版本的人补一条硬判据
- **S45 数值待核**：90 秒 / 70 秒是素材录制时的口径，版本未标注
