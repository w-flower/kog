# 02 开局前90秒：第一步我站在哪

> **依赖**：01 选人（尚未写）——它要交出的是"这局前期以谁为核心"
> **被依赖**：03 前四分钟（本节产出的"第一步站位"决定了第一波线谁先到、谁先有线权）

## 0. 上一节留下的问题

01 选人还没写成条目，但它必须回答的问题是：**这局前期该围绕谁打？**

这一节不等 01 写完就先给出当前版本的主流答案——素材里的原话是：

> 「双方中路小乔和嫦娥……在这个中野辅的版本，我们这局前期要以野中为合，保证宫本的野区节奏以及小乔的中线权。」

也就是说，**S45 的默认答案是"野 + 中"**，不是任何一个单独的人。这个默认值有两个例外（见判断树），例外只看一件事：**我方打野一级能不能动对面野区**。

## 1. 本节只回答一个决定

**读条结束那 20 秒，我第一步往哪走？**

不是"我要不要反野"（那是打野的事），是**"我这一步走出去，会不会让本局的核心（野或中）多出一次机会"**。

## 2. 判断树

```
读条结束前，先答一个问题：我方打野一级能不能动对面野区？
│
├─ 能（打野是强反型 / 有惩戒优势 / 对面打野一级弱）
│   → 本局核心 = 打野的野区节奏
│   ├─ 我是辅助 → 去对抗路抢线权，抢完直接协同进野区   【K-D10】
│   ├─ 我是中路 → 兵线交汇立刻清，清完帮看另一片野区   【K-D11】
│   └─ 我是对抗路 → 一级先上手，把对面边路钉在线上     【K-D13】
│
└─ 不能（打野一级弱 / 对面打野压制）
    → 本局核心 = 中路线权
    ├─ 我是辅助 → 回中帮清，把中线权保住               【K-D10 分支 B】
    ├─ 我是中路 → 不硬抢 2v2，改成"清完就走"           【K-D11 分支 B】
    └─ 我是边路 → 只做安全对线，不主动换血             【K-D13】

无论哪支：一级出现击杀窗口（对面边路走位冒进）→ 先拿一血，拿不到立刻转野区 【K-D13】
```

## 3. 判断依据

| 变量 | 在哪看 | 阈值 / 取值 | 影响哪个分支 |
|---|---|---|---|
| 我方打野一级强度 | 英雄本身（能否强反/双惩戒） | 能与不能 | 根的第一次分叉 |
| 对面打野一级强度 | 同上 | 比我方弱 → 能反 | 同上 |
| 中路 2v2 强度 | 双方中单+辅助的清线速度 | 明显打不过 | K-D11 分支 B |
| 对面边路是否"皮"（敢出塔） | 一级 30 秒内的站位 | 出塔且我方有控制 | K-D13 |
| 打野是否已出野刀 | 装备栏 | 未出 → 尾刀让 | K-D12 的细节 |

## 4. 分支说明

### K-D09 开局的默认核心是「野 + 中」，不是任何一个人

- **适用版本**：S45（中野辅版本）；S46 待复核
- **触发条件**：读条结束，全队要定第一步
- **判断依据**：版本节奏（中野辅）+ 双方阵容
- **决策分支**：
  - 默认 → 所有开局动作服务于两件事：**打野的野区节奏 + 中单的中线权**
  - 只有当打野一级完全动不了野区时（见判断树），核心才切到"中路线权"单点
- **反例**：「开局各走各的，辅助跟射手、边路自己发育」——这类打法在"中野辅"版本里等于主动放弃前两条资源。素材原话把这条定为**开局分析的第一句**，位置在"谁拿一血"之前。
- **依赖**：无；被 K-D10、K-D11、K-D12 依赖
- **来源**：BV1yke26fEYB @ 00:34；BV1yke26fEYB @ 00:38；BV1yke26fEYB @ 00:40
- **可信度**：中高（职业向全局教学的定调句，且后续所有动作都与它自洽）
- **状态**：active

### K-D10 打野要偷野时，辅助去的是对抗路，不是中路也不是发育路

- **适用版本**：S45
- **触发条件**：开局确认打野要偷对面野区
- **判断依据**：打野进草等对面动向（能不能偷成）；对抗路我方是否有先手
- **决策分支**：
  - 打野要偷 → **去对抗路抢线权**，抢完带着边路一起进野区
  - 打野不偷 → 回中帮清（分支 B）
- **反例**：「辅助开局跟射手」——这是四个判据里排第三的一条（`K-D08`），不是第一条。开局直接去发育路，等于放弃野区节奏。
- **依赖**：依赖 K-D09（核心是野区）；与 `K-L12` 是同一条判据的位置级版本
- **来源**：BV1yke26fEYB @ 00:52；BV1yke26fEYB @ 00:54；BV1yke26fEYB @ 01:29
- **可信度**：中高
- **状态**：active

### K-D11 中路 2v2 打不过就不要抢，改去帮看野区

- **适用版本**：S45
- **触发条件**：一级中路 2v2，我方清线明显慢
- **判断依据**：双方中单+辅助的清线速度差（一个技能能不能清完一波）
- **决策分支**：
  - 打不过 → **不硬抢**，把中线放掉，转去另一片野区看一眼（对面打野动不动我们的红/蓝）
  - 抢得过 → 立刻清完，清完立刻走（`K-L02`）
- **反例**：「中单必须抢线权」——抢不过还去抢，是把自己钉在中路挨打，同时野区被反了也没人看。素材里这一波的处理就是"中路抢线 2V2 打不过对面的组合 → 要协同打野的反野，就得去另外一边拿线权"。
- **依赖**：依赖 K-D09；与 `K-L01` 互为位置级/环节级版本
- **来源**：BV1yke26fEYB @ 00:31；BV1yke26fEYB @ 01:33；BV1yke26fEYB @ 01:34
- **可信度**：中高
- **状态**：active

### K-D12 反完野的 30 秒，是给打野提速的窗口

- **适用版本**：S45
- **触发条件**：我方反野成功、对面野区清完
- **判断依据**：打野野区里还剩几组野；打野有没有出野刀
- **决策分支**：
  - 打野野区里有剩 → **立刻过去帮打**（三组小野一起提速），尾刀不抢
  - 打野已清空 → 回中线，不要陪他蹲
- **反例**：「反完野就去帮下路」——反野换来的经济优势只有在他把自家野也吃完时才成立。你走了，他一个人清三组野，优势就摊薄了。
- **依赖**：依赖 K-D09；尾刀细节见 `K-L13`
- **来源**：BV1yke26fEYB @ 02:16；BV1yke26fEYB @ 02:25；BV1yke26fEYB @ 02:27；BV1yke26fEYB @ 02:28
- **可信度**：中高
- **状态**：active

### K-D13 一级的一血窗口只看一件事：对面边路敢不敢出塔

- **适用版本**：S45
- **触发条件**：开局 0–60 秒，边路第一次兵线交汇
- **判断依据**：对面边路站位是否越过自家塔前；我方有没有硬控（如带晕眩的边路）
- **决策分支**：
  - 他出塔且我方有控 → **打**，这是开局性价比最高的一次击杀
  - 他稳在塔后 → 立刻转"快速抢线 + 进野区"，不要在线上磨
  - 偷野被对面发现 → **不打了，直接快速抢线转进野区**（原话：被发现了，那就直接快速抢线，带着队友去进对面野区）
- **反例**：「一级要稳」——一级恰恰是唯一"对面还没有技能"的窗口，稳到二级，这个机会就永久消失。
- **依赖**：依赖 K-D09；被 K-D12 依赖（一血拿不到 → 转反野）
- **来源**：BV1yke26fEYB @ 00:59；BV1yke26fEYB @ 01:01；BV1yke26fEYB @ 01:40；BV1yke26fEYB @ 01:42
- **可信度**：中高
- **状态**：active

## 5. 本节的连锁错误（按节点挂）

- **在节点「核心定给谁」上**：人会跳过这一步，直接按自己的习惯走位（辅助跟射手、边路单带），结果前 90 秒全队四条线各打各的，一个资源都没拿到。
- **在节点「打野能不能动野区」上**：人会默认"我的打野很强"，不去看双方一级强弱，于是辅助白跑一趟对抗路，野区还是没反成。
- **在节点「一血窗口」上**：人会因为"这波不一定杀得掉"而放弃，转而去清兵——但清兵的收益是确定的、随时都有的，一血窗口不是。
- **在节点「被发现了怎么办」上**：人会继续蹲，怕浪费这一趟。原话的处理是立刻转"抢线 + 进野区"，把偷换成明抢。

## 6. 待验证 / 冲突

- **"中野辅版本"这个前提本身没有版本号**。素材是 S45 区间录的，但 UP 主说的是"这个中野辅的版本"，属于体感表述。S46 若节奏改动，K-D09 要重审。
- **射手视角缺失**：本节五路里，发育路的分支（"边路只做安全对线"）是从辅助视角反推的，没有射手第一视角素材验证（见 `L_分路/03_发育路.md` 的缺口说明）。
- 一级一血窗口的判据只有一条边路样本（孙策 vs 关羽），换阵容是否成立未验证。
